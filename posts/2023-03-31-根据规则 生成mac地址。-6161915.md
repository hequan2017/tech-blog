> **内容介绍**
>
> 本文是一段 Go 小示例：先用 `math/rand` 向 6 字节的 `net.HardwareAddr` 填满
> 随机数，再按规则改写——首字节固定为 0x00，第二、三段各由两个 0~9 的随机数
> 拼接（保证这两段十六进制显示为纯数字），最后用 `%02x` 格式化为冒号分隔的
> MAC 地址字符串并打印。

> **技术备注**
>
> MAC 地址共 48 位（6 字节），常写成冒号分隔的 12 个十六进制数。首字节最低位为
> I/G 位（0=单播，1=组播），次低位为 U/L 位（0=全局管理，1=本地管理）；示例将
> 首字节固定为 0x00，两个标志位均为 0，属于自定义取值，若想显式标记为本地管理
> 地址，可改用 0x02 一类 U/L 位为 1 的首字节。另外 `rand.Seed` 自 Go 1.20 起
> 已废弃（全局随机数默认自动播种），新代码可直接删去该行。

---

```go
package main

import (
	"fmt"
	"math/rand"
	"net"
	"time"
)

func main() {
	ppp := struct{ Mac string }{""}

	if ppp.Mac == "" {
		rand.Seed(time.Now().UnixNano()) // 使用当前时间为随机数生成器设置种子
		mac := make(net.HardwareAddr, 6)
		_, _ = rand.Read(mac)
		fmt.Println(mac)
		// 修改前三项为您所需的格式
		mac[0] = 0x00
		// 生成第二段和第三段为纯数字
		mac[1] = byte(rand.Intn(10))*16 + byte(rand.Intn(10))
		mac[2] = byte(rand.Intn(10))*16 + byte(rand.Intn(10))

		macString := fmt.Sprintf("%02x:%02x:%02x:%02x:%02x:%02x", mac[0], mac[1], mac[2], mac[3], mac[4], mac[5])
		ppp.Mac = macString
	}

	fmt.Println("Generated MAC address:", ppp.Mac)

}
```
