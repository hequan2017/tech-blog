> **内容介绍**
>
> 本文用 Go 求解 LeetCode 第 1 题「两数之和」：在整数数组中找出相加等于
> 目标值 target 的两个数，返回它们的下标。解法是一边遍历一边用 map 记录
> 已出现的数值，查找 target 与当前值之差是否出现过；命中后回扫数组把两
> 个数值替换为对应下标返回，时间复杂度 O(n)。文末为完整可运行代码，对
> 示例数组与 target=17 输出 [4 5]。

> **技术备注**
>
> 此实现命中后再回扫数组换取下标，若数组含重复元素（如 [3,3] 目标 6）
> 下标会被后出现的同值覆盖而出错；标准写法是直接取 map 中存的下标与
> 当前下标组成答案。代码兼容当前 Go 版本，go run 即可运行。

---

## 1. 思路

- 遍历数组，用 `map[int]int` 记录「数值 -> 下标」；
- 每步计算 `member := target - value`，若 map 中已有该值则命中；
- 命中后把 `[member, value]` 回扫替换为各自下标，返回 `[2]int`。

## 2. 完整代码

```go
package main

import (
	"fmt"
)

func main() {
	nums := []int{1, 3, 4, 6, 7, 10}

	target := 17
	newArr := twoSum(nums, target)
	fmt.Println(newArr)
}

func twoSum(nums []int, target int) [2]int {
	maps := make(map[int]int)
	for index, value := range nums {
		member := target - value
		if _, ok := maps[member]; ok {
			subscript := [...]int{member, value}
			for i, v := range subscript {
				for i1, v1 := range nums {
					if v == v1 {
						subscript[i] = i1
					}
				}
			}
			return subscript
		} else {
			maps[value] = index
		}
	}
	return [2]int{}
}
```
