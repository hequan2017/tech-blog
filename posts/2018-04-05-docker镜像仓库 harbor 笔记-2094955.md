> **内容介绍**
>
> 部署 Harbor 1.4.0 私有镜像仓库的实操笔记：下载离线安装包，用 openssl 自签 CA 与服务器证书启用 HTTPS，修改 harbor.cfg 后执行 prepare 与 install.sh 启动，最后在客户端分发证书、docker login 并演示 tag/push/pull 镜像的完整流程。

> **技术备注**
>
> Harbor 1.4 早已停止维护，新版 Harbor（2.x）配置从 harbor.cfg 改为 harbor.yml，安装脚本为 `install.sh`，并已内置镜像扫描、机器人账号等企业特性，新装请用当前稳定版。Harbor 项目也已从 vmware 组织迁移到 CNCF 的 goharbor 组织（github.com/goharbor/harbor）。docker-compose 1.x 二进制已被 Docker 内置的 `docker compose` 子命令取代。

### 安装 docker-compose 与 Harbor

```shell
curl -L https://github.com/docker/compose/releases/download/1.21.0/docker-compose-`uname -s`-`uname -m` -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose

wget https://storage.googleapis.com/harbor-releases/release-1.4.0/harbor-offline-installer-v1.4.0.tgz

tar xf  harbor-offline-installer-v1.4.0.tgz
```

### 自签 TLS 证书

参考文档： https://github.com/goharbor/harbor/blob/master/docs/configure_https.md

```shell
cd harbor/
mkdir ssl
cd ssl
openssl req \
    -newkey rsa:4096 -nodes -sha256 -keyout ca.key \
```

### 配置并启动 Harbor

```shell
vim harbor.cfg
hostname =
ui_url_protocol = https
ssl_cert = ./ssl/.crt
ssl_cert_key = ./ssl/.key
harbor_admin_password = 12345

./prepare
./install.sh

docker-compose  ps
```

### Web 端操作

修改 `C:\Windows\System32\drivers\etc\hosts`，添加 `192.168.1.112 <你的Harbor域名>`，浏览器访问后登录（admin / 12345），创建仓库、创建用户，并在 项目-成员-新建成员 中授权。

### 客户端访问

```shell
mkdir /etc/docker/certs.d/  -p
echo 192.168.1.112     >> /etc/hosts

scp  root@:/data/harbor/ssl/.crt  /etc/docker/certs.d/

# 登录
docker login
Username: hequan
Password:
Login Succeeded

# 或者  docker  login     -u hequan  -p 12345

# 在项目中标记镜像：
docker tag SOURCE_IMAGE[:TAG] /test/IMAGE[:TAG]

# 推送镜像到当前项目：
docker push /test/IMAGE[:TAG]

docker tag centos /test/centos:v1
docker push /test/centos:v1

docker pull /test/centos:v1
```
