> **内容介绍**
>
> 用阿里云 Go SDK 查询指定地域下的 ECS 实例列表：通过 AK/SK 创建客户端，调用 `DescribeInstances` 接口获取实例信息并打印实例 ID，适合作为采集云资产信息的入门示例。

> **技术备注**
>
> 示例基于阿里云旧版 `alibaba-cloud-sdk-go`（2020 年）；阿里云已推出 V2.0 Go SDK（`alibabacloud-go/ecs-20140526` 等模块化包），建议新项目使用 V2.0。原文 import 路径被截断，实际应为 `github.com/aliyun/alibaba-cloud-sdk-go/services/ecs`。硬编码 AK/SK 仅适合测试，生产环境建议通过 RAM 角色或环境变量注入。

---

```go
import (
	"fmt"
	"time"

	"github.com/aliyun/alibaba-cloud-sdk-go/services/ecs"
)

client, _ := ecs.NewClientWithAccessKey("cn-beijing", "11111111111111", "222222222222222222222")
request := ecs.CreateDescribeInstancesRequest()
response, _ := client.DescribeInstances(request)

r := response.Instances
```
