> **内容介绍**
>
> 集群系列第三篇：编译安装 PHP 5.6.22（先装 libiconv/libmcrypt/mhash/
> mcrypt 依赖库），用 NFS 将 /data/web 目录共享给四台后端；源码安装
> Memcached 1.4.33（依赖 libevent）及 PHP 的 memcache 扩展，再用 magent +
> keepalived 做主备 VIP（192.168.50.199:12000）代理两台 memcached，并特别
> 说明故障节点恢复时的缓存穿透风险与防火墙连接跟踪表问题；最后发布
> Discuz 开启 memcache 支持，用 telnet stats 验证命中数。

> **技术备注**
>
> CentOS 7 已于 2024 年 6 月 30 日停止维护(EOL),建议迁移至 Rocky Linux 9 /
> AlmaLinux 9 或国产 openEuler；PHP 5.6 也已于 2018 年 12 月底结束安全
> 维护，`--enable-safe-mode`、`--enable-magic-quotes` 选项自 PHP 5.4 起
> 已移除，5.6 下编译会出现 unrecognized options 警告，建议直接删除。
>
> magent 长期无人维护，故障切换会丢主节点数据，新架构建议直接用
> memcached 自身的一致性哈希客户端或换 Redis + 集群方案。

## 4. 安装 Memcached 1.4.33

下载并编译 libevent、memcached：

```shell
cd /tmp
wget http://downloads.sourceforge.net/levent/libevent-2.0.22-stable.tar.gz
wget http://www.memcached.org/files/memcached-1.4.33.tar.gz

tar zxvf libevent-2.0.22-stable.tar.gz
cd libevent-2.0.22-stable
./configure --prefix=/usr/local/
make && make install
ls -al /usr/local/lib | grep libevent-

cd /tmp
tar zxvf memcached-1.4.33.tar.gz
cd memcached-1.4.33
./configure --with-libevent=/usr/local/ --enable-64bit --enable-threads
make && make install
ls -al /usr/local/bin/memcached
```

创建运行用户与目录：

```shell
groupadd memcached
useradd -g memcached memcached

cd /var/run
mkdir memcached
chown -R memcached.memcached memcached
```

配置 SysV 服务脚本：

```shell
cp /tmp/memcached-1.4.33/scripts/memcached.sysv /etc/init.d/memcached
chown memcached.memcached /etc/init.d/memcached
chmod 755 /etc/init.d/memcached
vim /etc/init.d/memcached
```

```ini
PORT=11211
USER=memcached
MAXCONN=1024
CACHESIZE=128
OPTIONS=""
```

启动命令行改为：

```shell
/usr/local/bin/memcached -d -p $PORT -u $USER -m $CACHESIZE -c $MAXCONN -P /var/run/memcached/memcached.pid $OPTIONS
```

启动：

```shell
chkconfig --add memcached
chkconfig --level 235 memcached on
chkconfig --list memcached

service memcached start
ps -ef | grep memcached
service memcached stop
```

## 6. keepalived + magent 高可用

主 memcache 节点（开机不启动 keepalived、memcached）的
`/etc/keepalived/keepalived.conf`：

```ini
! Configuration File for keepalived
global_defs {
 router_id  mem1
}
vrrp_script chk_magent {
  script "/opt/magent.sh"
  interval 2
}
vrrp_script chk_memcached {
   script "killall -0 memcached"
   interval 1
   weight -20
}
vrrp_instance VI_1 {
    state MASTER
    interface eth0
    virtual_router_id  101
    priority 100
    advert_int 1
    authentication {
        auth_type PASS
        auth_pass 1111
    }
    virtual_ipaddress {
        192.168.50.199/24
    }
    track_script {
        chk_magent
        chk_memcached
        }
   notify_master  "/etc/keepalived/changemail.py master"
   notify_backup  "/etc/keepalived/changemail.py backup"
   notify_fault   "/etc/keepalived/changemail.py fault"
}
```

`/opt/magent.sh`（keepalived 存活即拉起 magent）：

```bash
#!/bin/bash
k=`ps -ef |grep keepalived |grep -v grep |wc -l`
if [ $k -gt 0 ];then
    /usr/local/magent/magent -u root -n 51200 -l 192.168.50.199 -p 12000 -s 192.168.50.63:11211 -b 192.168.50.64:11211
else
    pkill -9 magent
fi
```

备用 memcache 节点的 `/etc/keepalived/keepalived.conf`：

```ini
! Configuration File for keepalived
global_defs {

}
vrrp_script chk_magent {

```

`/opt/magent.sh`（本机持有 VIP 才拉起 magent）：

```bash
#!/bin/bash
k=`ip a |grep 192.168.50.199 |wc -l`
if [ $k -gt 0 ];then
        /usr/local/magent/magent -u root -n 51200 -l 192.168.50.199 -p 12000 -s 192.168.50.53:11211 -b 192.168.50.64:11211
else
    pkill -9 magent
fi
```

### 注意事项

如果将故障的 memcached 节点修复后，缓存是不会再通过到已修复的节点上的。
如果是 magent 指定的主节点故障，那么主节点的缓存数据会丢失，修复后不能
立刻重启 memcached 服务：如果重启，客户端会去查询主节点的数据，并发高的
网站会拖死数据库。因此，建议一般业务低峰期的时候再启动 memcached 主节点
服务，然后通过 magent 再指定主缓存节点和备缓存节点。

1. 若 memcached 读写的数据多，一定要关掉防火墙或将防火墙设置为不使用
   连接跟踪表，否则会导致 /var/log/message 报错
   `kernel: nf_conntrack: table full, dropping packet`，
   详情参考 http://blog.csdn.net/yanggd1987/article/details/45886913
   及 https://my.oschina.net/kisops/blog/150995 。
2. 使用 `service iptables stop` 关掉之后，不能用 `iptables -L -vnx` 查看，
   因为该命令会将防火墙重新开启——虽然规则是清空的，但仍会记录连接跟踪表。

## 7. PHP memcache 扩展

```shell
cd /tmp
tar zxvf /software/memcache-3.0.8.tgz -C /tmp
cd memcache-3.0.8
/usr/local/php/bin/phpize
./configure --enable-memcache --with-php-config=/usr/local/php/bin/php-config --with-zlib-dir
make
make install
```

`vim /usr/local/php/etc/php.ini`：

```ini
extension_dir = "/usr/local/php/lib/php/extensions/no-debug-non-zts-20131226/"
extension = "memcache.so"
[Memcache]
memcache.allow_failover = 1
memcache.max_failover_attempts = 20
memcache.chunk_size = 8192
```
