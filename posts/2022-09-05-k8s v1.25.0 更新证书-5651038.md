> **内容介绍**
>
> 本文介绍使用第三方脚本 `update-kubeadm-cert.sh` 一键续期 kubeadm 集群证书的方法。该脚本通过 `kubeadm certs renew` 重新生成 API Server、Controller Manager 等组件证书，解决证书过期导致集群不可用的问题。
>
> **技术备注**
>
> 脚本依赖 kubeadm 1.19+ 的证书续期机制；Kubernetes v1.25 及以后版本证书默认有效期仍为 1 年，生产环境建议结合 `kubeadm certs check-expiration` 定期检查，或使用自动化工具（如 kubeasz、sealos）管理证书。

---

```shell
git clone https:///yuyicai/update-kube-cert.git
cd update-kube-cert
chmod 755 update-kubeadm-cert.sh
./update-kubeadm-cert.sh all
```
