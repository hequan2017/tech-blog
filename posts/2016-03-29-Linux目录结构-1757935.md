> **内容介绍**
>
> 本文梳理 Linux 文件系统层次结构（FHS）：根目录下各一级目录（/etc、/bin、/usr、/var、
> /proc、/boot、/home 等）的作用，哪些目录必须与根目录在同一分区，以及运维中最常打交道的
> 关键文件——网络配置（ifcfg-eth0 / resolv.conf / hosts）、账号与权限
> （passwd / shadow / sudoers）、日志（messages / secure）、定时任务、开机自启
> （rc.local）等，并附磁盘分区格式化挂载的基础命令。

> **技术备注**
>
> 目录结构至今基本稳定，但两点注意：CentOS 7+ 中网卡配置文件名从 `ifcfg-eth0`
> 变为 `ifcfg-ens33` 等一致性命名，且 8/9 代改用 NetworkManager 的 keyfile 格式
> （`/etc/NetworkManager/system-connections/`）；`/etc/rc.local` 在新发行版需
> 手动赋予可执行权限并启用 rc-local.service 才会生效，推荐改用 systemd unit。

## 1. 一级目录速览

查看根目录结构与块设备：

```shell
tree -L 1 /          # 查看根目录第一层
ls /dev/sd* -l       # 查看块设备
cat /etc/fstab       # 查看开机挂载配置
```

最重要的三大目录：

- `/`（root，根目录）：与开机系统有关
- `/usr`（unix software resource）：与软件安装/执行有关
- `/var`（variable）：与系统运行过程中变动的数据有关

### 必须与根目录同分区的 5 个目录

开机过程中必须用到，**不可单独挂载到其他分区**：

- `/etc`：配置文件、服务启动脚本（`/etc/init.d`）
- `/bin`：重要可执行文件（二进制命令）
- `/dev`：设备文件（如 `/dev/null`）
- `/lib`：可执行文件所需的函数库与内核模块
- `/sbin`：系统管理员（root）使用的重要系统命令

### 其他常见目录

- `/usr/local`：本机自行编译安装的软件建议装到这里，便于管理
- `/usr/share`：共享的文档与数据
- `/usr`：系统程序及数据、帮助文件（目录结构与 `/` 类似）
- `/boot`：内核与引导文件
- `/home`：普通用户的家目录
- `/lost+found`：意外关机时找回的临时文件
- `/mnt`：临时挂载点
- `/proc`：进程与内核信息（虚拟文件系统）
- `/tmp`：临时文件目录
- `/var`：经常变动的数据（日志、缓存、队列等）

`/proc` 下常用信息文件：

```shell
cat /proc/cpuinfo      # CPU 信息
cat /proc/meminfo      # 内存信息
cat /proc/loadavg      # 系统负载
cat /proc/interrupts   # 中断信息
```

## 2. 磁盘分区、格式化与挂载

```shell
fdisk -l                       # 查看磁盘分区
mkfs.ext4 /dev/sdb1            # 格式化为 ext4(注意:一般先 fdisk 分区再格式化分区)
mount /dev/sdb1 /mnt           # 挂载到 /mnt
```

> ⚠️ 直接 `mkfs.ext4 /dev/sdb` 会清空整块磁盘，生产环境务必先 `fdisk` / `parted`
> 分区并确认设备名无误后再操作。

## 3. 网络相关重要文件

```shell
/etc/sysconfig/network-scripts/ifcfg-eth0   # 网卡配置(也可用 setup 配置)
/etc/resolv.conf                            # DNS 配置
/etc/sysconfig/network                      # 主机名/网络全局配置
/etc/hosts                                  # 本地域名解析
```

网卡重启：

```shell
ifdown eth0 && ifup eth0
```

## 4. 账号与权限相关文件

```shell
/etc/passwd        # 用户账号信息
/etc/group         # 用户组
/etc/shadow        # 用户密码(加密)
/etc/gshadow       # 组密码
/etc/sudoers       # sudo 授权(用 visudo 编辑)
```

## 5. 日志与登录审计

```shell
/etc/rsyslog.conf        # rsyslog 日志配置
/var/log/messages        # 系统综合日志
/var/log/secure          # 登录/认证日志
last                     # 最近登录记录
lastlog                  # 所有用户最近登录详情
```

## 6. 其他常用文件 / 目录

```shell
/var/spool/cron              # 各用户 crontab 存放目录
/var/spool/clientmqueue      # 邮件临时队列目录
/etc/rc.local                # 开机自启命令
/etc/exports                 # NFS 共享配置
/etc/profile                 # 全局环境变量
```
