> **内容介绍**
>
> 本文介绍内存分配器 Jemalloc 5.0.1 的编译安装,以及让 Nginx、MySQL 两个
> 服务用上它的方法:jemalloc 编译安装到 /usr/local/jemalloc 并注册动态库;
> Nginx 侧在编译时通过 --with-ld-opt="-ljemalloc" 链接;MySQL 侧复制
> libjemalloc.so 到系统库目录,并在 my.cnf 的 [mysqld_safe] 段配置
> malloc-lib,最后用 lsof 验证是否生效。适用于多线程服务降低内存碎片、
> 减少长跑内存膨胀的场景。

> **技术备注**
>
> Jemalloc 现已发展到 5.3 系列,仍是 Redis 官方推荐的分配器,也早已是
> FreeBSD/Fedora 等系统的默认 malloc;MySQL 8.0 中 mysqld_safe 与
> malloc-lib 的用法有调整(相关参数已弱化/移除),8.0 请改用 LD_PRELOAD
> 方式并核对官方文档。原文有三处被网页转义/编辑器吃掉的内容已补全:下载
> 地址补回 github.com;configure 的 `-prefix` 补为 `--prefix`;cp 与
> malloc-lib 后被吃掉的库文件名补为 libjemalloc.so.2。

## 1. 安装 Jemalloc

```shell
cd /usr/local/src
wget       https://github.com/jemalloc/jemalloc/releases/download/5.0.1/jemalloc-5.0.1.tar.bz2
tar     -xjvf     jemalloc-5.0.1.tar.bz2

cd jemalloc-5.0.1/
./configure  --prefix=/usr/local/jemalloc    --libdir=/usr/local/lib
make  && make install

echo /usr/local/lib >> /etc/ld.so.conf
ldconfig
```

## 2. Nginx 使用 jemalloc

Nginx 在编译的时候添加这个参数即可:

```shell
nginx:     --with-ld-opt="-ljemalloc"   ##编译的时候添加这个参数
```

## 3. MySQL 使用 jemalloc

安装之后,修改 my.cnf:

```shell
cp /usr/local/lib/libjemalloc.so.2  /usr/lib

vim  /etc/my.cnf
[mysqld_safe]
malloc-lib=/usr/lib/libjemalloc.so.2

/etc/init.d/mysqld restart
```

验证是否生效:

```shell
lsof -n | grep jemalloc
```
