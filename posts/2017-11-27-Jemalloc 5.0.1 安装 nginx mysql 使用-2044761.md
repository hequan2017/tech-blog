> **技术备注**
>
> Nginx 配置在不同大版本间略有差异,建议以当前稳定版(1.24+/1.26+)官方文档为准。

---

```shellcd
/usr/local/src
wget       https:///jemalloc/jemalloc/releases/download/5.0.1/jemalloc-5.0.1.tar.bz2
tar     -xjvf     jemalloc-5.0.1.tar.bz2

cd jemalloc-5.0.1/
./configure  -prefix=/usr/local/jemalloc    --libdir=/usr/local/lib
make  && make install

echo /usr/local/lib >> /etc/ld.so.conf
ldconfig
```

```shellnginx
:     --with-ld-opt="-ljemalloc"   ##编译的时候添加这个参数
```

```shellmysql
:   ##安装之后  修改 my.cnf

cp /usr/local/lib/  /usr/lib

vim  /etc/my.cnf
[mysqld_safe]
malloc-lib=/usr/lib/

/etc/init.d/mysqld restart

lsof -n | grep jemalloc                                 验证是否生效
```
