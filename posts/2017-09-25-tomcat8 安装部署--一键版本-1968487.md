> **内容介绍**
>
> 本文记录 Tomcat 8 在 Linux 下的一键式安装部署:先从 Oracle 官网(需点选接受
> 协议)下载 JDK 8,解压至 /usr/local/jdk8.0,并把 JAVA_HOME、JAVA_BIN、PATH、
> CLASSPATH 写入 /etc/profile;再从清华镜像下载 apache-tomcat-8.0.46,解压到
> /usr/local/tomcat8.0 并做软链接 /usr/local/tomcat,追加 CATALINA_HOME、
> 赋予脚本执行权限后用 startup.sh 启动,整个过程命令一气呵成。

> **技术备注**
>
> Tomcat 8.0 已于 2018 年 6 月停止维护,8.5 也在 2024 年 3 月底 EOL,生产环境
> 建议改用 Tomcat 9/10;旧版本安装包可从 archive.apache.org 获取,清华镜像已
> 不再保留 8.0.46。Oracle JDK 8 现需登录账号才能下载且生产使用受许可限制,可用
> OpenJDK(如 Adoptium Temurin)替代。另:原文 `echo "CATALINA_HOME=..." >>`
> 行尾的重定向目标被吞掉,已补全为 `>> /etc/profile`。

---

## 1. JDK 8 安装与环境变量

```bash
wget http://www.oracle.com/technetwork/java/javase/downloads/jdk8-downloads-2133151.html  ##需要进去，点介绍协议，下载jdk8

tar zxvf jdk-8u144-linux-x64.tar.gz

mv jdk1.8.0_144/   /usr/local/jdk8.0

echo "JAVA_HOME=/usr/local/jdk8.0
JAVA_BIN=/usr/local/jdk8.0/bin
PATH=$PATH:$JAVA_BIN
CLASSPATH=$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar
export JAVA_HOME JAVA_BIN PATH CLASSPATH " >> /etc/profile

source /etc/profile
```

## 2. Tomcat 8 安装与启动

```bash
wget http://mirrors.tuna.tsinghua.edu.cn/apache/tomcat/tomcat-8/v8.0.46/bin/apache-tomcat-8.0.46.tar.gz

tar zxvf apache-tomcat-8.0.46.tar.gz

mv apache-tomcat-8.0.46  /usr/local/tomcat8.0

ln -s /usr/local/tomcat8.0/ /usr/local/tomcat

cd /usr/local/tomcat/bin/

echo "CATALINA_HOME=/usr/local/tomcat8.0/"  >> /etc/profile

chmod +x   *.sh

./startup.sh
```
