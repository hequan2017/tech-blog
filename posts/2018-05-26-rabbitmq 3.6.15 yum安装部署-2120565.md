> **内容介绍**
>
> 本文记录 CentOS 7 下以 RPM 方式部署 RabbitMQ 3.6.15：先安装 EPEL 源与 Erlang
> 运行环境，再安装官方 el7 noarch 包，用 systemctl 设置开机自启并启动；随后启用
> rabbitmq_management Web 管理插件，创建 admin 管理员账号并授予 vhost / 的配置、
> 读、写全权限，删除默认 guest 用户，最后浏览器访问 15672 端口进入管理控制台。

> **技术备注**
>
> RabbitMQ 3.6 系列早已停止维护，生产环境建议使用 3.12+/3.13+ 现行版本（需配套
> 对应版本 Erlang/OTP）；
> 文中 www.rabbitmq.com/releases 下载目录已迁移下线，历史版本包需从 GitHub
> rabbitmq-server 的 releases 页面获取；
> CentOS 7 已于 2024-06-30 EOL，新环境建议 Rocky/Alma 9 配合官方 Package Cloud 源安装。

---

## 1. 安装 Erlang 与 RabbitMQ

```shell
yum install epel-release  -y

yum install erlang   -y

wget https://www.rabbitmq.com/releases/rabbitmq-server/v3.6.15/rabbitmq-server-3.6.15-1.el7.noarch.rpm

yum install rabbitmq-server-3.6.15-1.el7.noarch.rpm  -y
```

## 2. 启动服务并启用管理插件

```shell
systemctl enable rabbitmq-server.service
systemctl start rabbitmq-server.service

rabbitmq-plugins enable rabbitmq_management
```

## 3. 创建管理员并删除默认账号

```shell
rabbitmqctl add_user admin admin
rabbitmqctl set_user_tags admin administrator
rabbitmqctl set_permissions -p / admin ".*" ".*" ".*"

rabbitmqctl delete_user guest
```

## 4. 访问管理控制台

浏览器打开 `http://<rabbitmq服务器IP>:15672/`，使用上一步创建的 admin 账号登录。
