## 1. 正则表达式简介

正则表达式是一套处理字符串的规则和方法，以行为单位对字符串进行处理；
通过特殊符号的辅助，可以快速过滤、替换某些特定的字符串。

常用工具：grep、sed、awk。

## 2. 基本正则（BRE）

| 符号 | 含义 |
| --- | --- |
| `^word` | 以 word 开头 |
| `word$` | 以 word 结尾 |
| `.` | 代表任意一个字符 |
| `\` | 转义符号，取消原来字符的特殊意义 |
| `*` | 重复 0 个或多个前面的一个字符 |
| `.*` | 任意多个任意字符 |
| `[字符集合]` | 字符集合，匹配集合内任一字符 |
| `[^word]` | 匹配不包括 ^ 后面所列字符的任意字符 |

示例：

```shell
# grep "^I" hequan
# grep -i "^i" hequan            # 不区分大小写
# grep -i ".$" hequan
# grep "li.e" hequan
# grep -n "\." hequan
# grep "490*448" hequan
49000000000000048,49448
# grep "49.*448" hequan
# grep ".*" hequan               # 匹配所有行
# grep "^.*" hequan
# grep "h[ex]quan" hequan        # 查找 hequan 或 hxquan
# grep "[^not boog]" hequan --color=auto
# grep -E "[^0-9|,]" hequan --color=auto
```

测试文件 hequan 的内容：

```text
I  am   hequan  linux   teacher.
I   like  chinese   chess, table  tennis.
111111111111111
49000000000000048,49448
```

重复次数 `\{n,m\}`（重复前一个字符 n 到 m 次）：

```shell
# grep "490\{2,3\}" hequan          # 重复 n 到 m 次
# grep "490\{1,\}" hequan           # 至少 n 次
# grep "490\{4\}" hequan --color=auto   # 恰好 n 次
```

## 3. 扩展正则（ERE）

| 符号 | 含义 |
| --- | --- |
| `+` | 重复一个或一个以上前面的字符 |
| `?` | 重复 0 个或一个前面的字符 |
| `\|` | 用或的方式查找多个字符串 |
| `()` | 找出"用户组"字符串 |

```shell
# egrep "490+" hequan
# grep -E "h(ex|equa)n" hequan
```

man 手册定位：`man grep` 后输入 `/REGULAR` 搜索。

## 4. 用 grep/sed/awk 提取 IP 与 MAC

```shell
# ifconfig eth0 | grep "inet addr" | cut -d ":" -f2 | cut -d " " -f1
192.168.10.10
# ifconfig eth0 | grep "inet addr" | awk -F ":" '{print $2}' | awk '{print $1}'
# ifconfig eth0 | grep "inet addr" | awk -F "[: ]" '{print $13}'
192.168.10.10
# ifconfig eth0 | grep "inet addr" | awk -F "[: ]+" '{print $4}'
# echo ---1:----2 | awk -F '[-:]+' '{print $3}'
2
# ifconfig eth0 | sed -n '2p'
```

awk 字段变量：`$1` 第一列、`$NF` 最后一列、`$0` 整行，NF 为列数、NR 为行号。

sed 替换提取：

```shell
# ifconfig eth0 | sed -n '/inet addr/p'
# ifconfig eth0 | sed -n '/inet addr/p' | sed 's#^.*addr:##g'
# ifconfig eth0 | sed -n '/inet addr/p' | sed 's#^.*addr:##g' | sed 's#  Bc.*$##g'
# ifconfig eth0 | grep "HWaddr" | awk -F "[ ]+" '{print $5}'
00:0C:29:E1:35:13
```

`.*` 配合后向引用 `\1`：

```shell
# ifconfig eth0 | sed -n 's#^.*addr:\(.*\)  Bcast.*$#\1#gp'
192.168.10.10
# ifconfig eth0 | sed -n 's#^.*HWaddr \(.*\)#\1#gp'
00:0C:29:E1:35:13
# sed 's#\(dd\) \(xx\)#\1#g' a.txt
dd
# ifconfig eth0 | sed -n 's#^.*dr:\(.*\)  Bcast:\(.*\)  Ma.*$#\1 \2#gp'
192.168.10.10 192.168.10.255
# ifconfig eth0 | sed -n 's#^.*HWaddr \(.*\)#\1#gp'
00:0C:29:E1:35:13
```

## 5. 从 stat 提取权限位

```shell
# stat /xx | sed -n 4p | awk -F "[/(]" '{print $2}'
0644
# stat /xx | head -4 | tail -1 | awk -F "[/(]" '{print $2}'
0644
# stat /xx | sed -n 's#^.*ess: (0\(.*\)/-.*$#\1#gp'
644
# stat /xx | sed -n 's#^.*(\(.*\)/-.*$#\1#gp'
0644
# stat /xx | sed -n '4p' | awk -F "[(/]" '{print $2}'
0644
```

用 `stat -c` 直接取：

```shell
# stat -c %a /xx
644
# stat -c %A /xx
-rw-r--r--
# stat -c %B /xx
512
# stat -c %b /xx
0
```

rwx 转 421 后拼接（并置为字符串拼接得到 644）：

```shell
# ll /xx | cut -c 2-10 | tr rwx- 4210 | awk -F "" '{print $1+$2+$3 $4+$5+$6 $7+$8+$9}'
644
```

## 6. echo 与 date

```shell
# echo -n hequan;echo hequan          # 不换行
hequanhequan
# echo -e "hequan\thequan"            # \t 插入 tab
hequan  hequan
# echo -e "hequan\nhequan"
hequan
hequan
# LANG=en
# date '+%y-%m-%d'
16-03-30
# date '+%Y-%m-%d'
2016-03-30
# date +%w
3
# date +%u
3
# echo `date +%F\ %T`
2016-03-30 17:06:52
# date +%F --date='3 day ago'
2016-03-24
```
