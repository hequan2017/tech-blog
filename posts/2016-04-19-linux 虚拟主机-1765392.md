## 1. 概述

部署多个站点,用不同的域名和站点目录,也可以用不同的端口、不同的 IP。

即虚拟主机的三种方式:**基于域名、端口、IP**。

## 2. 创建站点目录与测试页面

```shell
mkdir /var/html/{www,blog,bbs} -p
for name in www blog bbs; do echo "http://$name" > /var/html/$name/index.html; done
```

## 3. 配置虚拟主机

编辑虚拟主机配置文件:

```shell
vim conf/extra/httpd-vhosts.conf
```

（原文中的域名与邮箱后缀缺失,ServerName/ServerAlias/ServerAdmin 的值需自行补全:）

```apache
<VirtualHost *:80>
    ServerAdmin     hequan@
    DocumentRoot    "/var/html/www"
    ServerName
    ServerAlias
    ErrorLog    "logs/www-error_log"
    CustomLog   "logs/www-access_log" common
</VirtualHost>

<VirtualHost *:80>
    ServerAdmin     hequan@
    DocumentRoot    "/var/html/blog"
    ServerName
    ErrorLog    "logs/blog-error_log"
    CustomLog   "logs/blog-access_log" common
</VirtualHost>

<VirtualHost *:80>
    ServerAdmin     hequan@
    DocumentRoot    "/var/html/bbs"
    ServerName
    ErrorLog    "logs/bbs-error_log"
    CustomLog   "logs/bbs-access_log" common
</VirtualHost>
```

## 4. 主配置文件启用与目录权限

编辑主配置文件:

```shell
vi httpd.conf
```

启用虚拟主机配置,并为站点目录设置访问权限:

```apache
Include conf/extra/httpd-vhosts.conf

<Directory "/var/html">              # 目录权限
    Options FollowSymLinks
    AllowOverride None
    Order allow,deny
    Allow from all
</Directory>
```

## 5. 排错提示

出问题看日志（logs/ 目录下各虚拟主机的 error_log、access_log）。

FQDN 域名:若启动时提示无法可靠地确定服务器域名,需在 httpd.conf 中设置
ServerName。官方配置文件中的说明:

```apache
# If your host doesn't have a registered DNS name, enter its IP address here.
#
#ServerName www.example.com:80
```
