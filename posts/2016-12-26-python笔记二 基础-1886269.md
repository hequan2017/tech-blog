## 1. 一切皆对象（10/24）

**对于 Python，一切事物都是对象，对象基于类创建，对象所有的功能都是去类里面找的。**

变量名 = 对象（值）——重复的功能创建一个类，然后对象去引用。

整数：

```python
age = 18
print(type(age))
```

输出 `<class 'int'>`；如果是其他的类型，会在下面显示类地址。

常用内建方法：

```python
age.__abs__()          # 绝对值

all_item = 95
pager = 10
result = all_item.__divmod__(10)
print(result)          # (9, 5)

age.__add__(7)         # 加法
age.__rdivmod__(7)
```

`5/6` 与 `5//6`：真除法与整除两种写法。

浮点型 float 有 `as_integer_ratio` 等方法。

常用方法速记：

- `__contains__` 包含：`print(name.__contains__('er'))` → `True`

- `center` 居中；`count(self, sub, start=None, end=None)` 计数



- `expandtabs`：一个 tab 等于 8 个空格




## 4. set 集合与 collections 系列（10/31）

**set：无序不重复的元素集合**

```python
s1 = set([11, 22, 33])
s2 = set([22, 44])

ret0 = s1.intersection(s2)           # 交集
ret1 = s1.difference(s2)             # 差集
ret2 = s1.symmetric_difference(s2)   # 对称差集

print(ret0)    # {22}
print(ret1)    # {33, 11}
print(ret2)    # {33, 11, 44}
```

集合运算思路：

```python
update_set = old.intersection(new)                  # 交集
delete_set = old.symmetric_difference(update_set)   # 差集
add_set = new.symmetric_difference(update_set)      # 新增部分
```

collections 系列：

```python
import collections

# 计数器：统计每个字符重复了多少次
obj = collections.Counter('sdafsdafsdafsdafsdaf')
print(obj)     # Counter({'f': 5, 'd': 5, 'a': 5, 's': 5})
```

```python
# OrderedDict 有序字典
dic = collections.OrderedDict()
dic['k1'] = ['v1']
dic['k2'] = ['v2']
print(dic)     # OrderedDict([('k1', ['v1']), ('k2', ['v2'])])

# defaultdict 默认字典
dic = collections.defaultdict(list)
dic['k1'].append('alex')

# namedtuple 可命名元组
mytuple = collections.namedtuple('mytuple', ['x', 'y', 'z'])
obj = mytuple(11, 22, 33)
print(obj.x)   # 11
```
