> **内容介绍**
>
> 本文记录 MySQL 5.7 传统 binlog 位点方式的主从复制搭建：从库直接克隆
> 主库后需修改 server-id、auto.cnf 中的 UUID 与 pid 文件名；通过
> binlog-do-db / replicate-do-db 指定只复制 autoops 库；主库开启
> log-bin、创建 rep 复制账号，用 mysqldump --master-data=2 +
> --single-transaction 导出；从库导入后 CHANGE MASTER 指定
> MASTER_LOG_FILE/POS，start slave 并确认双 Yes。

> **技术备注**
>
> 1. MySQL 5.7 已于 2023 年 10 月停止官方支持(EOL),建议规划升级至 MySQL 8.0。
> 2. `GRANT ... IDENTIFIED BY` 建号方式在 MySQL 8.0 已废弃,需改为先
>    `CREATE USER` 再 `GRANT`;`CHANGE MASTER TO` 也已被
>    `CHANGE REPLICATION SOURCE TO` 取代。
> 3. 更推荐启用 GTID 复制(`gtid_mode=ON`),免去找 binlog 位点的手工步骤。

## 1. 克隆后需修改的参数

安装忽略，参考我前面的博客。从库克隆主库，克隆主数据库后，需要修改 server-id 和 /data/mysql/auto.cnf 中的 UUID，修改 pid 文件名字。

## 2. 主从复制过滤配置（my.cnf）

```ini
master:  # 只发送
binlog-do-db=autoops

slave:   # 只接受
replicate-do-db=autoops
```

## 3. 主库操作

配置文件开启 `log-bin=mysql-bin`（从库一般不开启）：

```sql
mysql> show variables like 'log_bin%';
+---------------------------------+-------+
| Variable_name                   | Value |
+---------------------------------+-------+
| log_bin                         | ON    |
+---------------------------------+-------+

mysql> grant replication slave on *.* to 'rep'@'192.168.10.%' identified by '123456';
mysql> flush privileges;
```

导出数据（InnoDB 用 --single-transaction，MyISAM 需用 --lock-all-tables）：

```bash
mysqldump -uroot -p -B autoops --events --master-data=2 --single-transaction > rep.sql
```

在 rep.sql 中记录 MASTER_LOG_FILE 和 MASTER_LOG_POS：

```sql
22 -- CHANGE MASTER TO MASTER_LOG_FILE='mysql-bin.000009', MASTER_LOG_POS=1564447;
```

传到从库：

```bash
scp rep.sql root@192.168.10.36:/root
```

## 4. 从库操作

导入数据：

```bash
mysql -uroot -p123456 < /opt/rep.sql
```

指定主库与复制位点：

```sql
CHANGE MASTER TO
MASTER_HOST='192.168.10.29',
MASTER_PORT=3306,
MASTER_USER='rep',
MASTER_PASSWORD='123456',
MASTER_LOG_FILE='mysql-bin.000009',
MASTER_LOG_POS=1486295;
```

启动复制并验证（会生成 /data/master.info 文件）：

```sql
mysql> start slave;
mysql> show slave status\G;
```

两个线程均为 Yes 即成功：

```text
Slave_IO_Running: Yes
Slave_SQL_Running: Yes
```

中继日志与复制位点信息（show slave status 输出片段）：

```text
relay-bin.index

/data/3307/relay-bin.000001
/data/3307/relay-bin.000002
                                        # 中继日志

427
mysql-bin.000005
591
```
