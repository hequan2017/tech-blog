> **内容介绍**
>
> 本文把一台多网卡的 CentOS 7 服务器配置成「网络中转」：外网口
> enp1s0 做 MASQUERADE 地址伪装转发上网；三个内网口 enp2s0、
> eno1、enp4s0 分别对应 192.168.2/3/4 网段，由 dhcpd 自动分发
> 地址。正文先给出分步手动配置，再附一键自动化脚本。

> **技术备注**
>
> - CentOS 7 已于 2024 年 6 月 30 日停止维护（EOL），建议迁移至
>   Rocky Linux 9 / AlmaLinux 9 或国产 openEuler。
> - CentOS 7 默认启用 firewalld，与本文的裸 iptables 规则会互相干扰，
>   实操前需先 `systemctl disable --now firewalld`。
> - 转发依赖内核参数 `net.ipv4.ip_forward=1`；RHEL 8/9 起 firewalld
>   底层已改为 nftables，`iptables-services` 持久化与 `network`
>   网络脚本也逐步被 NetworkManager/nmcli 取代，迁移时需相应改写。
> - 配置中的 8.8.8.8 / 8.8.4.4 为 Google 公共 DNS，可按需替换为
>   223.5.5.5 等更贴近环境的地址。

---

## 1. 准备工作：确认内外网网卡

确保您的计算机已连接到 Internet。根据您提供的信息，您的计算机已通过
`enp1s0` 接口连接到 Internet，IP 地址为 192.168.1.226。

选择一个未使用的网络接口用于连接其他设备。您可以选择 `enp2s0`、`eno1`
或 `enp4s0` 中的任何一个，因为它们的状态都显示为 DOWN。

## 2. 安装 iptables 并开启内核转发

在终端中安装 iptables 工具（如果尚未安装）：

```shell
sudo yum install iptables
```

启用 IPv4 转发。运行以下命令以在当前会话中启用它：

```shell
sudo sysctl -w net.ipv4.ip_forward=1
```

要使其在重启后生效，请编辑 `/etc/sysctl.conf` 文件，取消以下行的注释
（如果有），或添加该行（如果没有）：

```text
net.ipv4.ip_forward = 1
```

## 3. 配置 iptables 转发规则并保存

配置 iptables 规则以转发数据包。假设您选择了 `enp2s0` 作为局域网接口，
请运行以下命令：

```shell
sudo iptables -t nat -A POSTROUTING -o enp1s0 -j MASQUERADE
sudo iptables -A FORWARD -i enp1s0 -o enp2s0 -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A FORWARD -i enp2s0 -o enp1s0 -j ACCEPT
```

保存 iptables 规则，以便在重启后仍然生效：

```shell
sudo yum install iptables-services
sudo systemctl enable iptables
sudo iptables-save > /etc/sysconfig/iptables
```

## 4. 安装并配置 DHCP 服务器

首先安装 DHCP 服务器软件：

```shell
sudo yum install dhcp
```

备份原始的 DHCP 配置文件，然后创建一个新的配置文件：

```shell
sudo cp /etc/dhcp/dhcpd.conf /etc/dhcp/dhcpd.conf.bak
sudo vim /etc/dhcp/dhcpd.conf
```

在新的配置文件中，添加以下内容：

```text
subnet 192.168.2.0 netmask 255.255.255.0 {
    range 192.168.2.10 192.168.2.250;
    option domain-name-servers 8.8.8.8, 8.8.4.4;
    option routers 192.168.2.1;
    option broadcast-address 192.168.2.255;
    default-lease-time 600;
    max-lease-time 7200;
}
```

## 5. 内网口静态 IP 与启动服务

为局域网接口（假设为 `enp2s0`）分配静态 IP 地址。编辑
`/etc/sysconfig/network-scripts/ifcfg-enp2s0` 文件，添加以下内容：

```ini
DEVICE=enp2s0
TYPE=Ethernet
ONBOOT=yes
NM_CONTROLLED=no
BOOTPROTO=static
IPADDR=192.168.2.1
NETMASK=255.255.255.0
```

这里，我们将 `enp2s0` 接口的 IP 地址设置为 192.168.2.1。

重启网络服务以应用更改：

```shell
sudo systemctl restart network
```

启动并启用 DHCP 服务器服务：

```shell
sudo systemctl start dhcpd
sudo systemctl enable dhcpd
```

现在，当其他设备连接到您选择的局域网接口（本例中为 `enp2s0`）时，
它们应该能够从 DHCP 服务器自动获取 IP 地址并通过您的计算机访问 Internet。

## 6. 一键自动化脚本

把上述步骤整合成脚本，一次覆盖 `enp2s0`、`eno1`、`enp4s0` 三个内网口
（对应 192.168.2/3/4 三个网段），并顺带放行 8909 端口：

```shell
#!/bin/bash

# 安装必要的软件包
sudo yum install iptables dhcp iptables-services -y

# 启用IPv4转发
sudo sysctl -w net.ipv4.ip_forward=1
echo "net.ipv4.ip_forward = 1" | sudo tee -a /etc/sysctl.conf

# 配置iptables规则
sudo iptables -t nat -A POSTROUTING -o enp1s0 -j MASQUERADE
sudo iptables -A FORWARD -i enp1s0 -o enp2s0 -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A FORWARD -i enp1s0 -o eno1 -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A FORWARD -i enp1s0 -o enp4s0 -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A FORWARD -i enp2s0 -o enp1s0 -j ACCEPT
sudo iptables -A FORWARD -i eno1 -o enp1s0 -j ACCEPT
sudo iptables -A FORWARD -i enp4s0 -o enp1s0 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 8909 -j ACCEPT

# 保存iptables规则
sudo systemctl enable iptables
sudo iptables-save > /etc/sysconfig/iptables

# 配置网络接口
cat > /tmp/enp2s0_config << EOF
DEVICE=enp2s0
TYPE=Ethernet
ONBOOT=yes
NM_CONTROLLED=no
BOOTPROTO=static
IPADDR=192.168.2.1
NETMASK=255.255.255.0
EOF

cat > /tmp/eno1_config << EOF
DEVICE=eno1
TYPE=Ethernet
ONBOOT=yes
NM_CONTROLLED=no
BOOTPROTO=static
IPADDR=192.168.3.1
NETMASK=255.255.255.0
EOF

cat > /tmp/enp4s0_config << EOF
DEVICE=enp4s0
TYPE=Ethernet
ONBOOT=yes
NM_CONTROLLED=no
BOOTPROTO=static
IPADDR=192.168.4.1
NETMASK=255.255.255.0
EOF

sudo mv /tmp/enp2s0_config /etc/sysconfig/network-scripts/ifcfg-enp2s0
sudo mv /tmp/eno1_config /etc/sysconfig/network-scripts/ifcfg-eno1
sudo mv /tmp/enp4s0_config /etc/sysconfig/network-scripts/ifcfg-enp4s0

# 配置DHCP服务器
sudo cp /etc/dhcp/dhcpd.conf /etc/dhcp/dhcpd.conf.bak
cat > /tmp/dhcpd.conf << EOF
subnet 192.168.2.0 netmask 255.255.255.0 {
    range 192.168.2.10 192.168.2.250;
    option domain-name-servers 8.8.8.8, 8.8.4.4;
    option routers 192.168.2.1;
    option broadcast-address 192.168.2.255;
    default-lease-time 600;
    max-lease-time 7200;
}

subnet 192.168.3.0 netmask 255.255.255.0 {
    range 192.168.3.10 192.168.3.250;
    option domain-name-servers 8.8.8.8, 8.8.4.4;
    option routers 192.168.3.1;
    option broadcast-address 192.168.3.255;
    default-lease-time 600;
    max-lease-time 7200;
}

subnet 192.168.4.0 netmask 255.255.255.0 {
    range 192.168.4.10 192.168.4.250;
    option domain-name-servers 8.8.8.8, 8.8.4.4;
    option routers 192.168.4.1;
    option broadcast-address 192.168.4.255;
    default-lease-time 600;
    max-lease-time 7200;
}
EOF

sudo mv /tmp/dhcpd.conf /etc/dhcp/dhcpd.conf

sudo systemctl restart network

sudo systemctl start dhcpd
sudo systemctl enable dhcpd
```
