> 本文是「运维基础架构」系列第 2 篇：使用 Docker 部署 Nexus3 私有仓库。

> **技术备注**
>
> Nexus Repository 3 自 3.70.0 起要求 Java 17 运行环境；官方 sonatype/nexus3 镜像已内置适配的 JRE，Docker 部署无需单独安装 JVM。
> 镜像以 UID 200 运行，示例中对数据目录执行 chown -R 200 即为此准备。
> 新版本已弃用 OrientDB 存储，社区版默认使用内嵌 H2，旧实例升级前需按官方指引完成数据迁移。

## 1. Docker 部署 Nexus3

```shell
mkdir /data1/nexus-data -p && chown -R 200 /data1/nexus-data
docker run -d -p 8081:8081 --name nexus -v /data1/nexus-data:/nexus-data sonatype/nexus3
docker logs -f nexus
```

登录密码 查看 `/data1/nexus-data/admin.password`
