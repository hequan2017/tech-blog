> **内容介绍**
>
> 本文用一段 Shell 脚本估算容器网卡的实时网速：先读取
> /sys/class/net/eth0/statistics 下的 rx_bytes、tx_bytes 累计
> 计数器，间隔 60 秒再采样一次，两次差值除以时间间隔，即得
> eth0 入口与出口的平均网速（字节/秒）。

> **技术备注**
>
> - 容器内的 eth0 是 veth pair 在容器网络命名空间中的一端；
>   /sys/class/net 只展示当前网络命名空间可见的网卡，脚本需
>   `docker exec` 进容器（或进入其 netns）执行。
> - statistics/ 下各计数器由内核维护，自网卡启用起累计、读取
>   不会清零，与 `ip -s link` 同源，只能差分求增量。
> - 若 time_interval 为 0 会除零报错；示例固定 `sleep 60` 不会
>   触发，改成参数化间隔时需自行加保护。
> - 多网卡容器可先 `ls /sys/class/net/ | grep -v lo` 列出接口，
>   对每张网卡分别统计后再相加。

---

## 1. 确认要统计的网卡

列出除 lo 以外的所有网卡，容器内通常就是 eth0：

```shell
ls /sys/class/net/ | grep -v lo
```

## 2. 两次采样计算网速

记录初始时间戳和初始的接收、发送字节数，等待 60 秒后再次
读取，用差值除以时间间隔得到平均网速：

```shell
# 获取初始时间戳和初始的接收、发送字节数
start_time=$(date +%s)
start_rx_bytes=$(cat /sys/class/net/eth0/statistics/rx_bytes)
start_tx_bytes=$(cat /sys/class/net/eth0/statistics/tx_bytes)

# 等待一段时间（例如60秒）
sleep 60

# 获取新的时间戳和对应的接收、发送字节数
end_time=$(date +%s)
end_rx_bytes=$(cat /sys/class/net/eth0/statistics/rx_bytes)
end_tx_bytes=$(cat /sys/class/net/eth0/statistics/tx_bytes)

# 计算时间间隔和网速
time_interval=$((end_time - start_time))
rx_speed=$(( (end_rx_bytes - start_rx_bytes) / time_interval ))
tx_speed=$(( (end_tx_bytes - start_tx_bytes) / time_interval ))

# 打印结果
echo "入口网速：$rx_speed 字节/秒"
echo "出口网速：$tx_speed 字节/秒"
```
