> **内容介绍**
>
> 本文讲 Apache 的 MPM 并发模型与防盗链配置:用 apachectl -l 判断当前是 worker 还是
> prefork(编译时 --with-mpm 指定,默认 prefork);分别给出 httpd-mpm.conf 中 prefork
> (StartServers、MaxClients、MaxRequestsPerChild 等)与 worker(ThreadsPerChild、
> MaxSpareThreads 等)参数的含义、MaxClients 计算与整除关系,附 httpd-default.conf 的
> 超时/KeepAlive 项与查看并发连接数的命令;最后给出 Apache mod_rewrite 与 nginx
> valid_referers 两种图片防盗链写法。

> **技术备注**
>
> Nginx 配置在不同大版本间略有差异,建议以当前稳定版(1.24+/1.26+)官方文档为准。
> 补充:文中 Apache 2.2 已于 2017 年初停止维护,2.4 起 MaxClients 更名为
> MaxRequestWorkers、MaxRequestsPerChild 更名为 MaxConnectionsPerChild,新部署推荐
> event MPM;nginx valid_referers 防盗链语法沿用至今。

## 1. 查看/指定 Apache MPM(worker/prefork)

```shell
/application/apache/bin/apachectl -l | sed -n '/worker\|prefork/p'
```

```text
worker.c
Server MPM:     Worker
```

```shell
./configure --with-mpm=worker    # 编译时指定,默认是 prefork
```

## 2. prefork(默认)

使用多个子进程,每个子进程只有一个线程。效率高、稳定、安全,比 worker 消耗资源多。

```shell
vim /application/apache/conf/extra/httpd-mpm.conf
```

```apache
<IfModule mpm_prefork_module>
    StartServers         10       # 服务启动进程数
    MinSpareServers      10       # 最小空闲数量
    MaxSpareServers      15       # 最大空闲数量
    ServerLimit       2000
    MaxClients         1000       # 最大进程,并发
    MaxRequestsPerChild 5000      # 子进程处理的最大请求数,0=不限制
</IfModule>
```

```shell
ps -ef | grep http | grep -v grep | wc -l    # 查看进程数
```

```text
6
```

## 3. worker(线程与进程的结合)

```shell
vim /application/apache/conf/extra/httpd-mpm.conf
```

```apache
<IfModule mpm_worker_module>
    StartServers          2       # 启动进程数
    MaxClients         2000       # 并发的客户端连接数量
    ServerLimit          25       # 总进程数
    MinSpareThreads      50
    MaxSpareThreads     200
    ThreadLimit         200
    ThreadsPerChild     100       # 每个服务进程配置的常驻工作线程数
    MaxRequestsPerChild  0        # 单个子进程累计最多处理多少个请求,默认 0 不限制
</IfModule>
```

约束关系:

```text
MaxClients <= ServerLimit * ThreadsPerChild
MaxClients % ThreadsPerChild = 0   # 需整除
```

## 6. Apache web 服务防盗链

```apache
<Directory "/usr/local/apache2/htdocs/cfan/pic/">
    RewriteEngine on
    RewriteCond %{HTTP_REFERER} !^http://网站域名/.*$ [NC]
    RewriteRule .*\.(gif|jpg)$  http://代替图标 [R,NC]
</Directory>
```

## 7. Nginx 防盗链的配置

```nginx
location ~* \.(gif|jpg|png|swf|flv|bmp)$ {
    valid_referers none blocked *.hequan.com;
    if ($invalid_referer) {
        #rewrite ^/ http://www.hequan.com/403.html;
        return 403;
    }
}
```
