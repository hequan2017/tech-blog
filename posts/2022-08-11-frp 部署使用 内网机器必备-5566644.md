> **内容介绍**
>
> 本文记录 frp 内网穿透的快速部署：服务端用一键脚本安装 frps，客户端
> 下载二进制包并编辑 frpc.ini，把内网 SSH 端口映射到公网服务器上，
> 实现从外网直接 SSH 登录内网机器。

> **技术备注**
>
> 文中 frp 0.44.0 仍使用 ini 配置格式；frp 自 v0.52.0 起支持 toml /
> yaml / json，ini 已弃用，且参数更名（如 server_addr → serverAddr、
> bind_port → bindPort），升级后旧配置需按新格式改写。
>
> 文中的 frps 一键脚本另有 GitHub 仓库 MvsCode/frps-onekey（及 Gitee
> 镜像），原文的 code.aliyun.com 地址未必长期可用。
>
> CentOS 7 已于 2024 年 6 月 30 日停止维护（EOL），建议迁移至 Rocky Linux 9 / AlmaLinux 9 或国产 openEuler。

---

## 1. 服务端部署

```shell
wget https://code.aliyun.com/MvsCode/frps-onekey/raw/master/install-frps.sh -O ./install-frps.sh
chmod 700 ./install-frps.sh
./install-frps.sh install
```

## 2. 客户端部署

```shell
wget https://github.com/fatedier/frp/releases/download/v0.44.0/frp_0.44.0_linux_amd64.tar.gz
tar xf frp_0.44.0_linux_amd64.tar.gz

vim frpc.ini
```

```ini
[common]
server_addr = www.hequan.xyz
server_port = 5443
token = 123456

[ssh-123456]
type = tcp
local_ip = 127.0.0.1
local_port = 22
remote_port = 12345
```

```shell
nohup /root/frp_0.44.0_linux_amd64/frpc -c /root/frp_0.44.0_linux_amd64/frpc.ini &

ssh -o "StrictHostKeyChecking no" -p 12345 root@www.hequan.xyz
```
