> **内容介绍**
>
> 本文演示了在 Django 中基于 django-pure-pagination 0.3.0 实现分页的完整流程：安装配置（INSTALLED_APPS 与 PAGINATION_SETTINGS）、在视图中用 Paginator 对查询集分页、以及在模板中渲染"首页/上一页/页码/下一页/尾页"的分页导航条，其中借助 pure_pagination 提供的 querystring 属性保留原有 GET 查询参数。

> **技术备注**
>
> django-pure-pagination 0.3.0 发布于 2015 年，项目已多年不更新，且不兼容新版 Django（4.x/5.x）与 Python 3.10+。新项目建议直接使用 Django 内置的 django.core.paginator.Paginator，或在使用 DRF 时采用 rest_framework.pagination 提供的 PageNumberPagination。

---

### django 分页例子

#### 安装

```shell
python -m pip install django-pure-pagination==0.3.0
```

#### 设置

```python
INSTALLED_APPS = [
    'pure_pagination',
]

PAGINATION_SETTINGS = {
    'PAGE_RANGE_DISPLAYED': 3,
    'MARGIN_PAGES_DISPLAYED': 2,
    'SHOW_FIRST_PAGE_WHEN_INVALID': True,
}

DISPLAY_PER_PAGE = 15
```

#### 应用

```python
from pure_pagination import PageNotAnInteger
from pure_pagination import Paginator
```

```python
try:
            page = self.request.GET.get('page', 1)
        except PageNotAnInteger as e:
            page = 1
        p = Paginator(self.queryset, getattr(settings, 'DISPLAY_PER_PAGE'), request=self.request)
        asset_list = p.page(page)

        context = {
            "ecs_list": asset_list,
		     }
```

```html
<div style="text-align:center;">
			<nav class="pagination">

					<li><a rel="nofollow" href="{% url "asset:ecs_list" %}?page=1">首页 </a></li>

					{% if ecs_list.has_previous %}
							<li class="long"><a
											href="?{{ ecs_list.previous_page_number.querystring }}">上一页</a>
							</li>
					{% endif %}

					{% for page in ecs_list.pages %}
							{% if page %}
									{% ifequal page ecs_list.number %}
											<li class="active"><a rel="nofollow" href="?{{ page.querystring }}">{{ page }}</a>
											</li>
									{% else %}
											<li><a rel="nofollow" href="?{{ page.querystring }}" class="page">{{ page }}</a>
											</li>
									{% endifequal %}
							{% else %}
									<li class="none"><a rel="nofollow" href="">...</a></li>
							{% endif %}
					{% endfor %}
					{% if ecs_list.has_next %}
							<li class="long"><a
											href="?{{ ecs_list.next_page_number.querystring }}">下一页</a>
							</li>
					{% endif %}
					<li>
							<a rel="nofollow" href="{% url "asset:ecs_list" %}?page={{ ecs_list.paginator.num_pages }}">尾页 </a>
					</li>
					<li><span
									style="color: #0a0a0a">总:  {{ ecs_list.paginator.num_pages }} 页</span>
					</li>
					<li><span
									style="color: #0a0a0a">  ECS数量: {{ ecs_count }}</span>
					</li>
			</nav>
	</div>
```
