> **内容介绍**
>
> 本文提供一个 Python 批量发送邮件的完整脚本:从 1.csv 逐行读取客户名单(第一列
> 客户名称、第二列抄送人、第三列起为收件人),用 MIMEMultipart 组装带 Word 附件
> 的节日祝福邮件,经 SMTP STARTTLS 登录后逐条发送,每封间隔 7 秒防止被限流。
> 文中着重说明抄送(Cc)的两种写法差异——抄送一人时直接写字符串、多人时需像
> To 一样用 COMMASPACE 拼接,并在 sendmail 收件人列表中并入抄送人;文末记录了
> 中文附件名在手机客户端显示「未命名」的已知问题。

> **技术备注**
>
> 代码为 Python 2 写法:`open('1.csv', 'U')` 的通用换行模式在 Python 3.11+ 已移除,
> 直接 `open('1.csv')` 即可。原文 `'Content-Disposition'` 的值被博客平台转义成了
> `p_w_upload`(即 attachment),已修正——文末「中文附件名显示未命名」的 BUG 根源
> 正在于此;Python 3 下更稳妥的写法是用 MIMEApplication 并对中文 filename 做
> Header 编码。另:如今 163 等邮箱 SMTP 登录需使用授权码而非账号密码。

## 1. 完整脚本

```python
# !/usr/bin/env python
# -*- coding: UTF-8 -*-
import csv
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.application import MIMEApplication
from email.utils import COMMASPACE, formatdate
from email.mime.base import MIMEBase
from email import encoders
import time

def send_mail(server, fro, to, subject, text, chao):
    assert type(server) == dict
    assert type(to) == list
    msg = MIMEMultipart()
    msg['From'] = fro
    msg['Subject'] = subject
    msg['To'] = COMMASPACE.join(to)  # COMMASPACE==', '
    msg['Cc'] = chao  # 抄送(单人是字符串,多人需同 To 一样拼接)
    msg['Date'] = formatdate(localtime=True)

    xlsxpart = MIMEBase("application", "msword")
    xlsxpart.set_payload(open(u'通知.docx','rb').read(), 'utf-8')
    xlsxpart.add_header('Content-Disposition', 'attachment', filename="通知.docx")
    msg.attach(xlsxpart)

    import smtplib
    smtp = smtplib.SMTP(server['name'], server['port'])
    smtp.ehlo()
    smtp.starttls()
    smtp.ehlo()
    smtp.login(server['user'], server['passwd'])
    smtp.sendmail(fro, to+[chao], msg.as_string())
    smtp.close()


if __name__ == '__main__':
    server = {'name': '', 'user': 'xxxxx', 'passwd': 'xxx', 'port': 25}
    fro = 'xxxxxxxx'
    subject = 'xxxxx'
    with open('1.csv', 'U') as csvfile:
        # reader = csv.DictReader(csvfile)
        reader = csv.reader(csvfile)
        l = []
        for row in reader:
            l.append(row)
    print("开始")
    for i in l:
        name = i[0]
        mail = i[2:10]
        chao = i[1]
        b = '''
        您好！
        值此“八一”建军节之际，祝愿贵公司蓬勃发展，建军节快乐！

            '''
        a = "尊敬的{0}:".format(name)
        text = a + b
        while '' in mail:
            mail.remove('')
        to = mail
        print('to', to, 'ok', 'chao', chao, 'ok')
        time.sleep(7)
        send_mail(server, fro, to, subject, text, chao)
```

## 2. CSV 格式

第一列是客户名称，第二列是抄送的人，第三列和后面的是要发送的人。

## 3. 抄送(Cc)的注意事项

```python
msg['To'] = COMMASPACE.join(to)  # COMMASPACE==', '
msg['Cc'] = chao  # COMMASPACE==', '
```

```python
smtp.sendmail(fro, to+[chao], msg.as_string())
```

需要特别注意的是上面，抄送的是 1 个人。

Cc 是指要抄送，要注意抄送的是一个人还是多个。如果是多个，需要按照 To 的格式（用 `COMMASPACE.join()` 拼接）处理。

## 4. 已知 BUG

本脚本有 BUG，就是收附件的时候，如果附件是中文名字，手机客户端收的时候会显示一个「未命名」，电脑客户端没有问题。

> 原文此处写「暂未解决」。后查:根源即上文 `'Content-Disposition'` 的值在发布时
> 被转义为 `p_w_upload`,客户端无法识别该附件描述符才显示「未命名」;修正为
> `attachment` 后中文附件名即可正常显示,详见技术备注。
