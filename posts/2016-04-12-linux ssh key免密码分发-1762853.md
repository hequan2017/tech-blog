> **内容介绍**
>
> 本文实操演示 SSH 密钥免密码登录与数据分发：创建 hequan 用户后用
> ssh-keygen 生成 dsa 密钥，用 ssh-copy-id 把公钥分发到目标机并验证免密
> ssh / scp；随后给出 scp -rp 互拷文件与目录、连接慢时关闭 UseDNS 与
> GSSAPIAuthentication 的优化、批量分发的 shell 脚本，最后解决批量分发的
> 权限问题：visudo 授权 sudo cp、rsync 加 suid、直接用 root 三种方案。

> **技术备注**
>
> - 文中环境为 CentOS 6。DSA 密钥（ssh-dss）自 OpenSSH 7.0 起默认禁用，
>   如今生成密钥请改用 `ssh-keygen -t rsa` 或 `-t ed25519`。
> - `passwd --stdin` 仅 RHEL/CentOS 系支持，Debian/Ubuntu 需用 `chpasswd`；
>   批量分发公钥现多配合 sshpass、ansible 等工具。
> - 给 rsync 加 suid 属临时手段，权限过大有安全风险，生产环境建议用
>   sudoers 精细授权（文中推荐的第 2 种方案）。

## 1. 需求与准备

具体需求：在同一用户 **hequan** 下，实现 A 机从本地分发数据到 B 机，过程中不需要密码提示。

创建用户：

```shell
# useradd hequan
# id hequan
# echo 123456 | passwd --stdin hequan
# su - hequan
```

密钥算法说明：RSA 既可以加密，也可以数字签名；DSA 只能用于数字签名。

## 2. 创建密钥

```shell
[hequan@A ~]$ ssh-keygen -t dsa       # 不加 -t 默认生成 RSA
```

```text
Generating public/private dsa key pair.
Enter file in which to save the key (/home/hequan/.ssh/id_dsa):
Created directory '/home/hequan/.ssh'.
Enter passphrase (empty for no passphrase):
```

查看生成的密钥（私钥保留，公钥用于分发）：

```shell
[hequan@A ~]$ ll -l .ssh/
总用量 8
-rw------- 1 hequan hequan 668 3月  28 04:07 id_dsa          # 私钥 保留
-rw-r--r-- 1 hequan hequan 598 3月  28 04:07 id_dsa.pub      # 公钥 分发

[hequan@A ~]$ ll -ld .ssh/
drwx------ 2 hequan hequan 4096 3月  28 04:07 .ssh/
```

## 3. 分发公钥并验证

格式：`ssh-copy-id [-i [identity_file]] [user@]machine`

```shell
[hequan@A ~]$ ssh-copy-id -i .ssh/id_dsa.pub hequan@192.168.10.11   # 分发
Are you sure you want to continue connecting (yes/no)? yes
```

```text
  .ssh/authorized_keys
to make sure we haven't added extra keys that you weren't expecting.
```

到 B 机上确认公钥已写入：

```shell
[hequan@B ~]$ ll -l .ssh/
-rw------- 1 hequan hequan 598 4月   4 04:49 authorized_keys
```

验证免密码登录：

```shell
[hequan@A ~]$ ssh hequan@192.168.10.11      # 不要密码
[hequan@B ~]$
```

## 4. scp 分发文件与目录

测试发文件：

```shell
[hequan@A ~]$ echo hequan > hequan.txt
[hequan@A ~]$ scp hequan.txt hequan@192.168.10.11:~
```

目录互拷：

```shell
[hequan@A ~]$ scp -rp /etc/ hequan@192.168.10.11:~             # 发送目录到 ~
[hequan@A ~]$ scp -rp hequan@192.168.10.11:~/etc/ /tmp/        # 把 B 的 /etc/ 拷到本机 /tmp
```

## 5. 连接慢的优化

如果测试时 ssh 特别慢，可以修改如下参数：

```shell
# vi /etc/ssh/sshd_config
```

```ini
UseDNS no
GSSAPIAuthentication no
```

```shell
# /etc/init.d/sshd restart
```

## 6. 免密码登录小结

- 免密码验证是**单向**的；
- 是**基于用户**的，最好不要跨用户；
- 连接慢（可以看上面的解决办法）；
- 批量分发初始都需要输入一次密码，并且第一次连接要确认（可用 expect 解决）。

调试命令：

```shell
[root@A ~]# ssh -v root@192.168.10.11     # -v 调试整个连接过程
```

## 7. 批量分发测试脚本

```shell
#!/bin/sh
if [ $# -ne 1 ]
then
    echo "/bin/sh $0 arg1"
    exit 1
fi
for n in 11
do
    scp -rp $1 hequan@192.168.10.$n:~;
done
```

## 8. 批量分发的权限问题

普通用户无权直接写远端系统目录，有三种解决思路。

方案一：利用 root。

方案二：利用 visudo（推荐，原文推荐第 2 种）：

```shell
# visudo
hequan ALL=(ALL) NOPASSWD:/bin/cp

# visudo -c
/etc/sudoers：解析正确
```

远程 sudo 时注意 sudoers 里的 `Defaults requiretty`（或者注释掉这一条）：

```text
# Disable "ssh hostname sudo <cmd>", because it will show the password in clear.
#         You have to run "ssh -t hostname sudo <cmd>".
Defaults    requiretty
```

用法：

```shell
$ scp -rp quan hequan@192.168.10.11:~                  # 先把 quan 拷贝到家目录
$ ssh hequan@192.168.10.11 -t sudo /bin/cp ~/quan /tmp # 然后拷贝 quan 到 /tmp，用的是 root 权限
```

方案三：利用 rsync（加 suid，使其有 root 权限）：

```shell
# chmod u+s `which rsync`       # suid
-rwsr-xr-x 1 root root 415000 10月 31 2013 /usr/bin/rsync
```

```shell
ssh hequan@192.168.10.11 /usr/bin/rsync ~ /yy /tmp
```

小结：批量分发的权限问题——利用 root、利用 visudo（推荐）、利用 rsync。
