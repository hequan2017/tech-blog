> **内容介绍**
>
> 本文汇总 zabbix-agent 3.0.3（CentOS 6 版 RPM）启动与运行期的两例典型报错
> 及解决办法：一是日志报 `no active checks on server ... host [Zabbix test]
> not found`，原因是 Web 端主机名称与 agent 配置文件里的 Hostname 不一致，
> 两边改成一致即可；二是 agentd 启动时报无法创建 PID 文件 `Permission
> denied`，通过新建 /var/run/zabbix 目录并 chown 给 zabbix 用户解决。文中
> 附 dashboard 主机配置截图与对应命令。

> **技术备注**
>
> zabbix 3.0 已于 2019 年停止支持，当前 LTS 为 6.0（支持至 2027）与 7.0；
> el6 的 agent 包亦随 CentOS 6 EOL，新系统请安装对应发行版的 agent。
> 主动模式检查要求 zabbix_agentd.conf 的 Hostname 与 Web 端"主机名称"完全
> 一致（区分大小写），可用 `zabbix_agentd -t system.hostname` 核对。
> 新版官方包通过 systemd 的 RuntimeDirectory 自动创建 /var/run/zabbix，
> 一般不会再遇到 PID 文件权限问题。

## 1. 环境与日志查看

```shell
[root@shell ~]# rpm -qa zabbix-agent
zabbix-agent-3.0.3-1.el6.x86_64
```

启动 zabbix_agentd 报错，查看日志：

```shell
tail -f /var/log/zabbix/zabbix_agentd.log
```

## 2. 报错一：host not found（Hostname 不一致）

报错：

```text
1261:20160627:185115.613 no active checks on server [192.168.10.41:10051]: host [Zabbix test] not found
```

解决：hostname 名字不一致导致的，要一致：

```ini
Hostname=Zabbix test
```

![Zabbix 主机配置页，主机名称填写 Zabbix test](assets/1794376/01_wKioL1dz3EehOq1iAAAL4MOlA7k080.png)

## 3. 报错二：PID 文件权限拒绝

报错：

```text
zabbix_agentd [1316]: cannot create PID file [/var/run/zabbix/zabbix_agentd.pid]: [13] Permission denied
```

解决：

```shell
mkdir -p /var/run/zabbix/
chown zabbix.zabbix /var/run/zabbix/
```
