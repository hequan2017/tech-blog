> **内容介绍**
>
> 本文记录 Redis 4.0.1 原生 Cluster 集群的完整搭建过程：两台机器各起
> 3 个实例（192.168.10.44 的 7000~7002 为 master，.45 的 7003~7005 为
> slave），共 3 主 3 从。先编译安装 Redis，再逐实例修改 redis.conf
> （端口、bind 本机 IP、daemonize、cluster-enabled、cluster-config-file、
> 开启 AOF），然后用 rvm 装 ruby 2.3.3 + gem 装redis，借助
> redis-trib.rb create --replicas 1 创建集群，最后 redis-cli -c 跨节点
> set/get 验证 slot 重定向，并强调存活主节点不得少于半数。

> **技术备注**
>
> 1. CentOS 7 已于 2024 年 6 月 30 日停止维护(EOL),建议迁移至 Rocky Linux 9 / AlmaLinux 9 或国产 openEuler。
> 2. Redis 4.x 已停止维护,生产建议使用 Redis 6/7 系列并启用 ACL 与 TLS。
> 3. `redis-trib.rb` 在 Redis 5.0 起已废弃,新版直接用
>    `redis-cli --cluster create ... --cluster-replicas 1`,无需再安装 ruby。
> 4. 原文 mkdir 命令丢失 `redis_cluster/` 路径前缀,已按上下文(cp 与
>    redis-server 启动路径)补全。

## 1. 安装

```bash
cd /opt
wget http://download.redis.io/releases/redis-4.0.1.tar.gz
tar zxf redis-4.0.1.tar.gz
cd redis-4.0.1
make
```

## 2. 集群搭建（2 台机器，3 master + 3 slave）

### master 节点（192.168.10.44，端口 7000/7001/7002）

```bash
cd src
cp redis-trib.rb /usr/local/bin/
mkdir redis_cluster
mkdir redis_cluster/7000 redis_cluster/7001 redis_cluster/7002
cp redis.conf redis_cluster/7000
cp redis.conf redis_cluster/7001
cp redis.conf redis_cluster/7002
```

修改各实例配置：

```ini
port  7000                                //端口7000,7001,7002
bind 本机ip                               //默认ip为127.0.0.1 需要改为其他节点机器可访问的ip 否则创建集群时无法访问对应的端口，无法创建集群
daemonize    yes                          //redis后台运行
pidfile  /var/run/redis_7000.pid          //pidfile文件对应7000,7001,7002
cluster-enabled  yes                      //开启集群  把注释#去掉
cluster-config-file  nodes_7000.conf      //集群的配置  配置文件首次启动自动生成 7000,7001,7002
cluster-node-timeout  15000               //请求超时  默认15秒，可自行设置
appendonly  yes                           //aof日志开启  有需要就开启，它会每次写操作都记录一条日志
```

启动三个实例：

```bash
/opt/redis-4.0.1/src/redis-server redis_cluster/7000/redis.conf
/opt/redis-4.0.1/src/redis-server redis_cluster/7001/redis.conf
/opt/redis-4.0.1/src/redis-server redis_cluster/7002/redis.conf
```

### slave 节点（192.168.10.45，端口 7003/7004/7005）

```bash
mkdir redis_cluster/7003 redis_cluster/7004 redis_cluster/7005
cp redis.conf redis_cluster/7003
cp redis.conf redis_cluster/7004
cp redis.conf redis_cluster/7005
```

修改各实例配置：

```ini
port  7003                                //端口7003,7004,7005
bind 本机ip                               //默认ip为127.0.0.1 需要改为其他节点机器可访问的ip 否则创建集群时无法访问对应的端口，无法创建集群
daemonize    yes                          //redis后台运行
pidfile  /var/run/redis_7003.pid          //pidfile文件对应7003,7004,7005
cluster-enabled  yes                      //开启集群  把注释#去掉
cluster-config-file  nodes_7003.conf      //集群的配置  配置文件首次启动自动生成 7003,7004,7005
cluster-node-timeout  15000               //请求超时  默认15秒，可自行设置
appendonly  yes                           //aof日志开启  有需要就开启，它会每次写操作都记录一条日志
```

启动三个实例：

```bash
/opt/redis-4.0.1/src/redis-server redis_cluster/7003/redis.conf
/opt/redis-4.0.1/src/redis-server redis_cluster/7004/redis.conf
/opt/redis-4.0.1/src/redis-server redis_cluster/7005/redis.conf
```

## 3. 创建集群（master 上执行）

redis-trib.rb 依赖 ruby，先通过 rvm 安装：

```bash
yum -y install ruby ruby-devel rubygems rpm-build  curl
curl -sSL https://rvm.io/mpapis.asc | gpg2 --import -
curl -L get.rvm.io | bash -s stable
source /usr/local/rvm/scripts/rvm
rvm list known
rvm install 2.3.3
rvm use 2.3.3
rvm remove 2.0.0
ruby --version
gem install redis
```

创建集群，提示时输入 `yes` 确认：

```bash
/opt/redis-4.0.1/src/redis-trib.rb create --replicas 1 \
  192.168.10.44:7000 192.168.10.44:7001 192.168.10.44:7002 \
  192.168.10.45:7003 192.168.10.45:7004 192.168.10.45:7005
```

## 4. 测试

```bash
/opt/redis-4.0.1/src/redis-cli -h 192.168.10.44 -c -p 7000
192.168.10.44:7000> set hello world
OK
192.168.10.44:7000> keys *
1) "hello"

/opt/redis-4.0.1/src/redis-cli -h 192.168.10.45 -c -p 7005
192.168.10.45:7005> get hello
-> Redirected to slot [866] located at 192.168.10.44:7000
"world"
```

## 5. 注意事项

必须要 3 个或以上的主节点，否则在创建集群时会失败；并且当存活的主节点数小于总节点数的一半时，整个集群就无法提供服务了。
