## 1. 模块分类与目录结构

nginx.conf 中 `root html;` 指定网站目录。模块分类:

- core module:Main、Events
- Standard HTTP modules:Core、Access、FastCGI、Gzip、Log、Proxy、
  Rewrite、Upstream

模块帮助可通过官方文档查看:http://nginx.org/en/docs/

安装目录结构:

```text
.
├── client_body_temp
├── conf
│   ├── fastcgi.conf            # 动态配置
│   ├── fastcgi.conf.default
│   ├── fastcgi_params          # 参数
│   ├── fastcgi_params.default
│   ├── koi-utf
│   ├── koi-win
│   ├── mime.types
│   ├── mime.types.default
│   ├── nginx.conf              # 静态配置文件
│   ├── nginx.conf.default
│   ├── scgi_params
│   ├── scgi_params.default
│   ├── uwsgi_params
│   ├── uwsgi_params.default
│   └── win-utf
├── fastcgi_temp
├── html
│   ├── 50x.html                # 出错页
│   └── index.html
├── logs
│   ├── access.log
│   ├── error.log
│   └── nginx.pid
├── proxy_temp
├── sbin
│   └── nginx
├── scgi_temp
└── uwsgi_temp
```

## 2. 默认主配置文件解读

```shell
egrep -v "#|^$" nginx.conf | cat -n
```

```nginx
 1  worker_processes  1;             # 和 CPU 核心数相当,效率高
 2  events {
 3      worker_connections  1024;    # 每个 worker 可接受的最大连接数
 4  }
 5  http {
 6      include       mime.types;
 7      default_type  application/octet-stream;
 8      sendfile        on;
 9      keepalive_timeout  65;
10      server {
11          listen       80;
12          server_name  localhost;              # 域名
13          location / {
14              root   html;
15              index  index.html index.htm;
16          }
17          error_page   500 502 503 504   /50x.html;   # 指定错误页面
18          location = /50x.html {
19              root   html;
20          }
21      }
22  }
```

## 3. 虚拟主机配置

开始配置多个站点:

```nginx
server {
    listen       80;
    server_name  ;          # 填写自己的域名
    root   html/www;
    index  index.html index.htm;
}

server {
    listen       80;
    server_name  ;          # 填写自己的域名
    root   html/blog;
    index  index.html index.htm;
}
```

改完重载:

```shell
/application/nginx/sbin/nginx -s reload
```

## 4. 301 跳转

```nginx
server {
    listen       80;
    server_name  ;          # 填写自己的域名
    rewrite ^/(.*)  http:///$1   permanent;   # 目标域名按需补全
}
```

## 5. 解决恶意 IP 绑定

未匹配到任何 server_name 的请求直接拒绝,防止别人把域名恶意解析到本机:

```nginx
server {
    listen       80;
    location / {
        deny all;
    }
}
```

## 6. 日志切割

```shell
cd /application/nginx/logs && \
/bin/mv www_access.log www_access_$(date +%F -d -1day).log
/application/nginx/sbin/nginx -s reload
```

写入 crontab,每天 0 点执行切割脚本:

```shell
crontab -e
00 00 * * * /bin/sh /application/nginx/logs/xx.sh >/dev/null 2>&1
```

日志相关分析可用 awstats。

## 7. 常见 HTTP 状态码

- 200 正常
- 301 永久跳转
- 403 禁止访问
- 404 找不到请求的页面
- 500 内部服务器错误
- 502 坏的网关
- 503 服务当前不可用
