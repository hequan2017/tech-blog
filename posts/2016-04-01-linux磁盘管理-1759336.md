> **内容介绍**
>
> 本文是 Linux 磁盘管理笔记，覆盖内存查看（free）、磁盘与分区查看（fdisk -l）、fdisk 交互式分区（主分区/扩展分区/逻辑分区）、partprobe 通知内核重读分区表、大于 2TB 磁盘使用 parted + GPT 分区、mkfs 格式化、mount/umount 挂载、dd 备份 MBR，以及 tune2fs/dumpe2fs 调整 ext 文件系统参数等常用操作。

> **技术备注**
>
> 文中命令在 2026 年依然基本适用，但需注意：fdisk 自 util-linux 2.23 起已原生支持 GPT，"大于 2T 必须用 parted" 的说法已过时；新磁盘更推荐使用 GPT 分区表（MBR 单分区上限 2TB）；ext4 仍是主流，但 XFS 是 RHEL/Rocky/Alma 默认文件系统；`partprobe` 可用 `udevadm settle` 或 `blockdev --rereadpt` 替代。CentOS 7 已于 2024-06-30 EOL。

## 1. 内存与磁盘概览

```shell
free -m    # 以 MB 为单位查看内存/交换分区使用情况
fdisk -l   # 列出所有磁盘及分区信息
```

## 2. fdisk 分区（MBR，≤2TB）

分区类型概念：主分区（最多 4 个）、扩展分区（占 1 个主分区名额）、逻辑分区（建在扩展分区内，编号从 5 开始）。

进入交互式分区：

```shell
fdisk /dev/sdb
```

fdisk 内部命令菜单：

```text
Command action
   a   toggle a bootable flag        # 设置启动标志
   b   edit bsd disklabel
   c   toggle the dos compatibility flag
   d   delete a partition            # 删除分区
   l   list known partition types    # 列出已知分区类型 ID
   m   print this menu               # 打印帮助
   n   add a new partition           # 新建分区
   o   create a new empty DOS partition table
   p   print the partition table     # 打印分区表
   q   quit without saving changes   # 不保存退出
   s   create a new empty Sun disklabel
   t   change a partition's system id  # 修改分区类型 ID
   u   change display/entry units
   v   verify the partition table
   w   write table to disk and exit  # 保存并退出
   x   extra functionality (experts only)
```

新建分区示例（主分区 500MB + 扩展分区）：

```text
Command (m for help): n
Command action
   e   extended
   p   primary partition (1-4)
p
Partition number (1-4): 1
Last cylinder, +cylinders or +size{K,M,G} (1-130, default 130): +500M
```

分区结果：

```text
Device Boot      Start         End      Blocks   Id  System
/dev/sdb1              1          20      160618+  83  Linux
/dev/sdb2             21         130      883575    5  Extended
```

用 `t` 命令修改分区类型为 LVM（ID 8e），可用 `l` 查看全部类型 ID：

```text
/dev/sdb1              1          20      160618+  8e  Linux LVM
```

分区完成后通知内核重读分区表（避免重启）：

```shell
partprobe /dev/sdb   # 通知系统内核分区表已改变
```

## 3. parted 分区（GPT，支持 >2TB）

parted 是 GNU 磁盘分区工具，传统上用于大于 2TB 的磁盘（需配合 GPT 分区表）：

```shell
parted /dev/sdb
```

交互过程：

```text
GNU Parted 2.1
使用 /dev/sdb
Welcome to GNU Parted! Type 'help' to view a list of commands.

(parted) rm                # 删除已有分区
分区编号？ 1

(parted) mklabel gpt       # 创建 GPT 分区表（会销毁磁盘所有数据！）
警告: The existing disk label on /dev/sdb will be destroyed and all data
on this disk will be lost. Do you want to continue?
是/Yes/否/No? yes

(parted) p                 # 打印分区表
Model: VMware, VMware Virtual S (scsi)
Disk /dev/sdb: 1074MB
Sector size (logical/physical): 512B/512B
Partition Table: gpt

(parted) mkpart primary 0 500    # 新建分区 0~500MB
警告: The resulting partition is not properly aligned for best performance.
忽略/Ignore/放弃/Cancel? Ignore

(parted) mkpart logical 501 1024
(parted) p
Number  Start   End     Size   File system  Name     标志
 1      17.4kB  500MB   500MB               primary
 2      501MB   1024MB  523MB               logical
```

> 注：GPT 分区表下没有主/扩展/逻辑分区之分，parted 中的 `primary`/`logical` 此时只是分区名称标签（原文示例沿用了 MBR 的习惯叫法）。

也可以非交互方式一条命令完成：

```shell
parted /dev/sdb mklabel gpt                 # 创建 GPT 分区表
parted /dev/sdb mkpart primary 0 500        # 新建分区
parted /dev/sdb mkpart logical 501 1024
parted /dev/sdb p                           # 查看分区表
```

## 4. 格式化与挂载

```shell
mkfs.ext4 /dev/sdb1        # 格式化为 ext4
mount /dev/sdb1 /mnt       # 挂载到 /mnt
df -hT                     # 查看挂载情况（-T 显示文件系统类型）
```

mount 完整语法与强制卸载：

```shell
mount -t 文件系统类型 -o 挂载选项 设备 挂载点
mount -a                   # 按 /etc/fstab 挂载全部
umount -lf /mnt            # 强制卸载（lazy + force）
```

## 5. tune2fs 调整文件系统参数

ext 文件系统默认每挂载 22 次或 180 天会自动 fsck 检查：

```text
This filesystem will be automatically checked every 22 mounts or
180 days, whichever comes first.  Use tune2fs -c or -i to override.
```

关闭按挂载次数检查：

```shell
tune2fs -c -1 /dev/sdb1    # -c -1 表示不做挂载次数检查
# tune2fs 1.41.12 (17-May-2010)
# Setting maximal mount count to -1
```

## 6. dd 备份 MBR

```shell
dd if=/dev/sda of=mbr.bin bs=512 count=1   # 备份 sda 的 MBR（前 512 字节）
```

## 7. 磁盘占用查看

```shell
du -sh /etc        # 查看目录总大小，h 人类可读
du -sh /etc/*      # 查看 /etc 下各条目大小
# 27M     /etc
```

## 8. 其他相关工具

- `tune2fs`：调整 ext2/ext3/ext4 文件系统的可调参数。
- `dumpe2fs`：导出 ext2/ext3/ext4 文件系统的详细信息（superblock、块组等）。
