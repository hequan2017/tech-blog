> **内容介绍**
>
> CentOS 7 下 MariaDB 的两类密码问题处理:首次修改 root 密码的两种方法——
> mysqladmin -u root -p[旧密码] password 新密码(注意旧密码与 -p 之间不能有
> 空格),或执行 mysql_secure_installation 初始化向导按提示设置;忘记密码的
> 两种救援方式——mysqld_safe --skip-grant-tables 免授权模式进入后 update
> user 表改密码并 flush privileges,或直接在 /etc/my.cnf 的 [mysqld] 段加
> skip-grant-tables 重启后修改。

> **技术备注**
>
> CentOS 7 已于 2024 年 6 月 30 日停止维护(EOL),建议迁移至 Rocky Linux 9 /
> AlmaLinux 9 或国产 openEuler。
>
> 新版 MariaDB(10.4+)root 默认启用 unix_socket 认证,且 `mysql.user` 表
> 密码列并入 `authentication_string`,重置密码的 SQL 需按新版语法调整。

## 1. 首次修改密码

### 方法一:mysqladmin

```shell
mysqladmin -u root -p[oldpass] password newpass
```

注意 `oldpass`(老密码)可选,如果 root 默认密码为空,则不需要输入。如果
需要更改老密码,请注意老密码与 `-p` 之间不要有空格,否则会报错;另外
`password` 和 `newpass`(新密码)之间以空格分隔。

### 方法二:初始化数据库

```shell
/usr/local/mysql/bin/mysql_secure_installation
# yum 安装时路径为 /usr/bin/mysql_secure_installation
```

之后开始初始化,依次按提示操作即可。

## 2. 忘掉密码的处理

### 方法一:mysqld_safe 免授权模式

```shell
systemctl stop mariadb              # 停止 mariadb 数据库
mysqld_safe --skip-grant-tables &   # 进入单机模式
mysql
```

```sql
use mysql;      -- 进入 mysql 库
update user set password=password('新密码') where user='root' and host='localhost';  -- 设置新密码
flush privileges;   -- 刷新
```

新开窗口用新密码测试关闭数据库,成功关闭就证明修改成功:

```shell
mysqladmin -uroot -p shutdown
systemctl restart mariadb            # 重启服务
```

### 方法二:配置文件加 skip-grant-tables

```ini
vim /etc/my.cnf

[mysqld]
skip-grant-tables    # 添加这一行,保存后重启服务
```

重启后 `mysql` 可以直接进去修改,方式同上。

另:原文附变量 `skip_name_resolve = ON`(跳过主机名反解析,与重置密码无直接
关系)。
