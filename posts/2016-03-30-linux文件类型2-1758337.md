## 1. 软链接与硬链接

```shell
# ln 源文件 链接文件           # 硬链接
# ln -s 源文件 链接文件        # 软链接
# ln -s /application/apache2.2.17/ /application/apache
```

观察 inode 与链接数：

```shell
# ll -li a b c
402871 -rw-r--r-- 2 root root 3 3月  27 19:10 a
402872 lrwxrwxrwx 1 root root 1 3月  27 19:16 b -> a
402871 -rw-r--r-- 2 root root 3 3月  27 19:10 c
```

对目录只能创建软链接。

## 2. 文件删除的条件

2 个条件同时具备，文件才会真正被删除：

- 硬链接数 i_link=0：创建一个文件 i_link=1，创建硬链接 i_link=2，
  i_link=0 就被删除了
- 无进程占用：有进程占用这个文件时 i_count+1，i_count=0 才真正删除

## 3. 实验：删除被进程占用的日志文件

安装 httpd 并把日志改到独立小分区上：

```shell
# yum -y install httpd
# grep log httpd.conf --color=auto
# sed -i 's@CustomLog logs/access_log combined@CustomLog /app/log/access_log combined@g' /etc/httpd/conf/httpd.conf
# mkdir /app/log -p
# dd if=/dev/zero of=/dev/sdc bs=8k count=10
# mkfs -t ext3 /dev/sdc
# mount /dev/sdc /app/log/ -o loop
# df -h
# tail -f access_log
```

制造访问量后删除日志：

```shell
# rm -f access_log
# lsof | grep del
# /etc/init.d/httpd restart
```

处理办法：

1. 删除文件，重启服务
2. 清空文件，不删除
3. 不要删当天的被进程占用的文件，删更早的

```shell
# for n in `seq 100000`; do curl -s 192.168.10.10 > /dev/null; done
# > access_log          # 清空文件
# lsof -i :22
```

## 5. 三种时间与 stat

- access（atime）：最后访问时间
- modify（mtime）：修改时间，`ls -lt` 默认按它排序
- change（ctime）：状态改变时间（权限、属主等元数据变化时更新）

```shell
# stat a
# ls -l --time-style=long-iso
```
