> **内容介绍**
>
> 本文是 Linux 入门命令速查笔记，按用途分组整理了日常运维最常用的命令：
> 文件与目录操作（mkdir / touch / cp / mv / rm）、文本查看与处理
> （head / tail / grep / sed / awk）、查找与批量处理（find / xargs）、
> 别名与帮助（alias / man）、用户与权限（passwd / su / sudo / visudo）、
> 环境变量、网络状态查看（netstat / lsof）以及关机等，适合新手对照练习。

> **技术备注**
>
> 这些基础命令在 2026 年的各主流发行版中长期稳定可用，仅几点提醒：
> `netstat` 属 net-tools 套件，已停止维护多年，新发行版建议改用 iproute2 的 `ss`
> （如 `ss -lntup`）；`echo 密码 | passwd --stdin` 仅适用于 RHEL/CentOS 系，
> Debian/Ubuntu 请用 `chpasswd`；`init 0` / `halt` 在 systemd 系统上是
> `systemctl poweroff` / `systemctl reboot` 的兼容封装。

## 1. 文件与目录操作

```shell
mkdir /data                 # 创建目录
mkdir -p /xx/xxx            # 递归创建多级目录（父目录不存在也不报错）
ls -ld /data                # 查看目录本身的属性（而非目录内容）
cd /                        # 切换目录
touch hequan.txt            # 创建空文件（或更新已有文件时间戳）
vi hequan.txt               # 编辑文件（vim 同理）
cat hequan.txt              # 查看文件内容
echo "hequan" >> hequan.txt # 追加写入一行
cat >> xx << EOF            # here-doc 方式交互追加多行，输入 EOF 结束
cp -a hequan.txt /tmp       # 复制并保留权限/属主/时间戳等属性
mv /data /root              # 移动或改名
rm -f xx                    # 强制删除文件（不提示）
rmdir /data                 # 删除空目录
rm -rf /data                # 递归强制删除（高危，慎用！）
tree xx                     # 树状查看目录结构（需 yum install tree）
```

## 2. 文本查看与处理

```shell
head -2 xxx                 # 查看前 2 行
tail -2 xxx                 # 查看后 2 行
head -30 xxx | tail -10     # 取第 21~30 行
grep -v 关键字 xxx           # 反向过滤（不显示匹配行）
grep -E "连续的字符串" xxx    # 使用扩展正则
grep -i 关键字 xxx           # 不区分大小写
sed -n '/he/p' xxx          # 打印含 he 的行
sed '/hequan/d' xxx         # 删除含 hequan 的行（仅输出，不改原文件）
sed -n '20,30p' xxx         # 打印第 20~30 行
sed -i 's#hequan#quanhe#g' he          # 全文替换并直接写入文件
awk '/[^hequan]/' xxx                  # 按正则过滤行
awk '{if(NR>19&&NR<31) print $0}' xxx  # 打印第 20~30 行
awk -F ":" '{print $1}' /etc/passwd    # 按冒号分列取第 1 列（所有用户名）
tac xxx                     # 倒序显示文件（cat 反过来拼）
seq 100                     # 生成 1~100 数字序列
seq -s " " 5                # 生成 "1 2 3 4 5"（-s 指定分隔符）
diff a b                    # 比较两个文件差异
vimdiff a b                 # 用 vim 可视化比较
```

## 3. 查找与批量处理

```shell
find / -type f -name "cat" -exec ls -l {} \;   # 查找文件并对每个结果执行 ls -l
find / -type f -mtime +5                        # 查找修改时间超过 5 天的文件
find / -type f -name he | xargs cat             # 查找后批量查看内容
find / -type f -name he | xargs sed -i 's#hequan#quanhe#g'   # 查找后批量替换内容
echo {a..z}                                     # 花括号展开输出 a~z
echo {1..6}                                     # 花括号展开输出 1~6
```

## 4. 帮助与别名

```shell
man mkdir                   # 查看命令完整手册
mkdir --help                # 查看简要帮助
which cp                    # 查看命令实际路径
alias 1=xx                  # 设置临时别名
unalias 1                   # 取消别名
cat ~/.bashrc               # 永久别名通常写在这个文件里
\cp /tmp/xx /xxx            # 命令前加反斜杠，绕过别名使用原始命令
```

## 5. 用户与权限

```shell
echo 123456 | passwd --stdin hequan   # 非交互修改密码（仅 RHEL/CentOS 系支持）
history                               # 查看历史命令
history -c                            # 清空当前会话历史
whoami                                # 显示当前用户名
su - root                             # 切换到 root（- 表示加载其环境变量）
sudo su -                             # 普通用户提权为 root
visudo                                # 安全地编辑 sudo 授权文件
```

`visudo` 授权示例：

```shell
hequan  ALL=(ALL)       /usr/sbin/useradd    # 仅允许 hequan 执行 useradd
hequan  ALL=(ALL)       NOPASSWD:ALL         # 免密执行所有命令（谨慎使用）
```

授权后即可：

```shell
sudo useradd xx   # 以 root 权限添加用户
```

> 备注：`passwd --stdin` 在 Debian/Ubuntu 上不存在，等价写法是
> `echo 'hequan:123456' | chpasswd`。

## 6. 环境变量

```shell
vi /etc/profile                            # 全局环境变量配置文件
echo 'PATH=/hequan:$PATH' >> /etc/profile  # 追加自定义 PATH
source /etc/profile                        # 使配置立即生效（不用重新登录）
```

## 7. 网络状态

```shell
netstat -an                # 查看所有连接与监听
netstat -lntup             # 查看监听端口及对应进程
netstat -lntup | grep ssh  # 过滤 ssh 相关端口
lsof -i:22                 # 查看 22 端口被哪个进程占用
```

> 备注：net-tools 已停止维护，新系统建议用 `ss -lntup` 替代 netstat，
> 输出更快且信息一致。

## 8. 关机与重启

```shell
halt              # 停机（systemd 系统上等同 systemctl halt）
init 0            # 关机（运行级别 0）
reboot            # 重启
shutdown -r now   # 立即重启
shutdown -h now   # 立即关机
```
