> **内容介绍**
>
> 本文是 Linux 入门命令速查笔记，按用途分组整理了日常运维最常用的命令：
> 文件与目录操作（mkdir / touch / cp / mv / rm）、文本查看与处理
> （head / tail / grep / sed / awk）、查找与批量处理（find / xargs）、
> 别名与帮助（alias / man）、用户与权限（passwd / su / sudo / visudo）、
> 环境变量、网络状态查看（netstat / lsof）以及关机等，适合新手对照练习。

> **技术备注**
>
> 这些基础命令在各发行版中长期稳定可用，仅两点提醒：
> `netstat` 在新发行版中建议改用 `ss`（如 `ss -lntup`）；
> `echo 密码 | passwd --stdin` 仅适用于 RHEL/CentOS 系，Debian/Ubuntu 请用 `chpasswd`。

## 1. 文件与目录操作

```shel
l
mkdir /data                 # 创建目录
mkdir -p /xx/xxx            # 递归创建多级目录
ls -ld /data                # 查看目录本身属性
cd /                        # 切换目录
touch hequan.txt            # 创建空文件
vi/vim hequan.txt           # 编辑文件
cat hequan.txt              # 查看文件内容
echo "hequan" >> hequan.txt # 追加写入
cat >> xx << EOF            # here-doc 方式追加多行
cp -a hequan.txt /tmp       # 复制(保留属性)
mv /data /root              # 移动/改名
rm -f xx                    # 强制删除文件
rmdir /data                 # 删除空目录
rm -rf /data                # 递归强制删除(高危,慎用)
tree xx                     # 树状查看目录结构
```

## 2. 文本查看与处理

```shel
l
head -2 xxx                 # 查看前 2 行
tail -2 xxx                 # 查看后 2 行
head -30 xxx | tail -10     # 取第 21~30 行
grep -v 关键字 xxx          # 反向过滤(不显示匹配行)
grep -E "连续的字符串" xxx   # 扩展正则
grep -i 关键字 xxx          # 不区分大小写
sed -n '/he/p' xxx          # 打印含 he 的行
sed '/hequan/d' xxx         # 删除含 hequan 的行
sed -n '20,30p' xxx         # 打印第 20~30 行
sed -i 's#hequan#quanhe#g' he          # 全文替换
awk '/[^hequan]/' xxx                  # 按正则过滤
awk '{if(NR>19&&NR<31) print $0}' xxx  # 打印第 20~30 行
awk -F ":" '{print $1}' /etc/passwd    # 按 : 分列取第 1 列
tac xxx                     # 倒序显示(cat 反过来)
seq 100                     # 生成 1~100 序列
seq -s " " 5                # 生成 1 2 3 4 5(指定分隔符)
diff a b                    # 比较两个文件差异
vimdiff a b                 # vim 可视化比较
```

## 3. 查找与批量处理

```shel
l
find / -type f -name "cat" -exec ls -l {} \;   # 查找并执行命令
find / -type f -mtime +5                        # 查找 5 天前修改的文件
find / -type f -name he | xargs cat             # 查找后批量查看
find / -type f -name he | xargs sed -i 's#hequan#quanhe#g'   # 查找后批量替换
echo {a..z}                                     # 花括号展开 a~z
echo {1..6}                                     # 花括号展开 1~6
```

## 4. 帮助与别名

```shel
l
man mkdir                   # 查看命令手册
mkdir --help                # 查看简要帮助
which cp                    # 查看命令路径
alias 1=xx                  # 设置别名
unalias 1                   # 取消别名
cat ~/.bashrc               # 别名常写在这里
\cp /tmp/xx /xxx            # 前加反斜杠,绕过别名使用原命令
```

## 5. 用户与权限

```shel
l
echo 123456 | passwd --stdin hequan   # 非交互修改密码(RHEL/CentOS)
history                               # 查看历史命令
history -c                            # 清空历史
whoami                                # 当前用户
su - root                             # 切换到 root(带环境变量)
sudo su -                             # 普通用户提权为 root
visudo                                # 编辑 sudo 授权
```

`visudo` 授权示例：

```shel
l
hequan  ALL=(ALL)       /usr/sbin/useradd    # 仅允许执行 useradd
hequan  ALL=(ALL)       NOPASSWD:ALL         # 免密执行所有命令(谨慎)
```

授权后即可：

```shel
l
sudo useradd xx
```

## 6. 环境变量

```shel
l
vi /etc/profile                        # 全局环境变量
echo 'PATH=/hequan:$PATH' >> /etc/profile   # 追加 PATH
source /etc/profile                    # 使配置立即生效
```

## 7. 网络状态

```shel
l
netstat -an                # 查看所有连接
netstat -lntup             # 查看监听端口及进程
netstat -lntup | grep ssh  # 过滤 ssh 端口
lsof -i:22                 # 查看 22 端口被谁占用
```

## 8. 关机与重启

```shel
l
halt            # 停机
init 0          # 关机
reboot          # 重启
shutdown -r now # 立即重启
shutdown -h now # 立即关机
```
