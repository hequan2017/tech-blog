## 1. Nginx 的优势与 LNMP 架构

Nginx 优点:配置简单、更灵活、高并发(静态小文件)、占用资源少、功能种类
多、支持 epoll 模型;配合动态服务的方式与 Apache 有区别,还可以对 IP 限速、
限制连接数。

LNMP 实现原理/架构:

- nginx(80)通过 `fastcgi_pass` 转发到 PHP FCGI 服务(9000 端口)
- Apache 是模块方式(DSO / apxs),select 模型
- nginx 是起 CGI 方式,epoll 网络 I/O 模型

## 2. 安装准备

```shell
ntpdate cn.pool.ntp.org    # 更新系统时间
```

安装 pcre(PCRE,Perl 兼容正则表达式库,为了支持 http rewrite 伪静态)与
openssl:

```shell
yum -y install pcre* openssl openssl-devel
useradd -s /sbin/nologin -M nginx
```

## 3. 编译安装 Nginx 1.9.15

源码地址:http://nginx.org/

```shell
wget http://nginx.org/download/nginx-1.9.15.tar.gz
tar xf nginx-1.9.15.tar.gz
cd nginx-1.9.15
./configure --user=nginx --group=nginx \
    --prefix=/application/nginx1.9.15 \
    --with-http_stub_status_module \
    --with-http_ssl_module
make && make install
ln -s /application/nginx1.9.15/ /application/nginx
```

## 4. 启动与验证

```shell
/application/nginx/sbin/nginx -t    # 检查配置
/application/nginx/sbin/nginx       # 启动
netstat -lntup | grep nginx
tcp        0      0 0.0.0.0:80      0.0.0.0:*      LISTEN      12590/nginx
```

浏览器访问见到 Welcome to nginx! 即安装成功。
