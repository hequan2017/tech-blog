> **内容介绍**
>
> 本文记录 vue-element-admin 前后端联调登录的三个要点：
> utils/request.js 中给请求头附加 Authorization: Token，并统一拦截
> 非 200 响应；vue.config.js 中把开发代理 target 指向本地后端
> 127.0.0.1:8000；api 中封装 /auth 登录与 /api/v1/userInfo 两个接口。

> **技术备注**
>
> vue-element-admin 基于 Vue 2 + Element UI，而 Vue 2 已于 2023-12-31
> 停止维护（EOL），该模板也已多年未更新，新项目建议改用 Vue 3 生态的
> 管理端模板；开发代理在 Vite 项目中对应 server.proxy，与 vue-cli 的
> devServer.proxy 思路一致。请求头 `Token ` 前缀是 Django REST
> framework TokenAuthentication 的鉴权格式，如今更常用 JWT；前端本地
> 登录调试也普遍改用 MSW、vite-plugin-mock 等 mock 方案。

---

## 1. utils/request.js

请求拦截中给请求头附加 Token，响应处理里按 code 拦截非 200 的情况：

```javascript
config.headers['Authorization'] = 'Token ' + getToken()

if (res.code !== 200) {
```

## 2. vue.config.js

开发环境代理指向本地后端：

```javascript
target: 'http://127.0.0.1:8000'
```

## 3. api

封装登录与获取用户信息两个接口：

```javascript
import request from '@/utils/request'

export function login(data) {
  return request({
    url: '/auth',
    method: 'post',
    data
  })
}

export function getInfo(token) {
  return request({
    url: '/api/v1/userInfo',
    method: 'get',
    params: { token }
  })
}
```
