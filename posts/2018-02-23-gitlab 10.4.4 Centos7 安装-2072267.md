> **内容介绍**
>
> 在 CentOS 7.4 上用清华 TUNA 镜像源 yum 安装 GitLab CE 10.4.4 的笔记：配置 gitlab-ce.repo 仓库、修改 external_url 后 reconfigure，随后用 xhang/gitlab 的 10.4.4-zh 分支 diff 打补丁实现汉化，最后给出 SMTP 邮箱配置、gitlab-rails console 发测试邮件的方法和 gitlab-ctl 常用运维命令。

> **技术备注**
>
> GitLab 10.x 已停止维护多年且存在多个高危漏洞，新装请用当前 16/17/18 系列；从 12.x 起官方内置了简体中文界面，不再需要手动打汉化补丁。CentOS 7 已于 2024 年 6 月 30 日停止维护(EOL)，建议迁移至 Rocky Linux 9 / AlmaLinux 9 或国产 openEuler。新版 GitLab 默认 Web 服务由 Unicorn 换成 Puma，`gitlab-ctl tail unicorn` 应改为 `gitlab-ctl tail puma`。

### 环境：

```shell
centos 7.4
gitlab 10.4.4
```

### 设置防火墙：

```shell
sudo yum install curl openssh-server openssh-clients cronie
sudo lokkit -s http -s ssh
```

### 安装

```shell
vim /etc/yum.repos.d/gitlab-ce.repo
[gitlab-ce]
name=Gitlab CE Repository
baseurl=https://mirrors.tuna.tsinghua.edu.cn/gitlab-ce/yum/el$releasever/
gpgcheck=0
enabled=1

yum makecache
yum install gitlab-ce

vim /etc/gitlab/gitlab.rb
# 修改变量
external_url 'http://192.168.1.20'

# 重新加载配置文件
gitlab-ctl reconfigure
```

### 汉化

```shell
cat /opt/gitlab/embedded/service/gitlab-rails/VERSION
10.4.4

git clone https://gitlab.com/xhang/gitlab.git
gitlab-ctl stop
cd gitlab/
git fetch
git diff v10.4.4 v10.4.4-zh > ../10.4.4-zh.diff
cd ..
patch -d /opt/gitlab/embedded/service/gitlab-rails -p1 <  10.4.4-zh.diff
gitlab-ctl start
```

### 邮箱

```shell
vim /etc/gitlab/gitlab.rb

gitlab_rails['gitlab_email_from'] = 'user1@'
gitlab_rails['smtp_enable'] = true
gitlab_rails['smtp_address'] = "smtp."
gitlab_rails['smtp_port'] = 465
gitlab_rails['smtp_user_name'] = "user1@"
gitlab_rails['smtp_password'] = "password"
gitlab_rails['smtp_domain'] = "smtp."
gitlab_rails['smtp_authentication'] = "login"
gitlab_rails['smtp_enable_starttls_auto'] = true
gitlab_rails['smtp_tls'] = true
gitlab_rails['gitlab_email_from'] = 'hequan@'

#重新加载配置
gitlab-ctl reconfigure

#测试配置是否成功
gitlab-rails console

# 稍等几分钟
Notify.test_email('9278718999@', '测试主题', '测试内容').deliver_now
```

### 常用命令

```shell
gitlab-ctl status   查看GitLab的运行状态
gitlab-ctl restart   重新启动
gitlab-ctl tail unicorn  查看unicorn日志; 按 Ctrl-C 退出
gitlab-ctl tail gitlab-rails 拉取/var/log/gitlab下子目录的日志
gitlab-ctl tail nginx/gitlab_error.log  拉取某个指定的日志
gitlab-ctl tail 查看所有的logs; 按 Ctrl-C 退出
```
