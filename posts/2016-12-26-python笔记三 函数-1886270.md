## 1. 函数基础（原文 11/1）

函数：是指将一组语句的集合通过一个名字（函数名）封装起来，要想执行这个函数，
只需调用其函数名就可以了。

```python
def sayhi():          # sayhi 为函数名
    print("hello , i'm hequan")

sayhi()               # 调用
```

### 函数的返回值

```python
def calc(x, y):
    res = x**y
    return res        # 返回函数执行结果
```

默认返回 None。

## 2. 参数（原文 11/2）

形参与实参：

```python
def mail(形式参数):
    ret = mail(实际参数)
    if ret:
        print("发送成功")
```

默认参数必须放在最后：

```python
def mail(a1, a2=11):
    ...
```

关键参数（指定参数赋值，在位置参数后面）：

```python
def mail(a1, a2):
    ...

mail(a2=123, a1=321)   # 指定参数
```

### 动态参数

`*` 把参数转换成元组：

```python
def show(*arg):        # * 把参数转换成元组
    print(arg, type(arg))    # 原文首行误作 agr，已修正

show(11, 22, 33, 44)
```

`**` 把参数转换成字典：

```python
def show(**arg):       # ** 把参数转换成字典
    print(arg, type(arg))

show(n1=11, n2=22, n3=33, n4=44)
```

两者混合（原文命名与惯例相反：`*kwargs` 收到元组、`**arg` 收到字典）：

```python
def show(*kwargs, **arg):
    print(arg, type(arg))
    print(*kwargs, type(kwargs))

show(11, 22, 33, 44, n1=11, n2=22, n3=33, n4=44)
```

输出：

```text
{'n3': 33, 'n4': 44, 'n1': 11, 'n2': 22} <class 'dict'>
11 22 33 44 <class 'tuple'>
```

已有变量也可以直接解包传入：`show(*a, **b)`。

## 3. format 与 lambda（原文 11/3）

字符串格式化支持 `{0}` 位置占位符，也支持 `{name}` 命名占位符：

```python
s1 = "{0} is {1}"
xx = s1.format('hequan', '2b')
print(xx)
# hequan is 2b
```

lambda 表达式，用于简单函数：

```python
he = lambda a: a+1
print(he(1))
```

## 4. open 函数与文件模式

内置函数 open 用于文件处理：

- `r` 只读，`w` 只写，`a` 追加
- `r+` 可读写，`w+` 写读，`a+` 同 a
- `u` 自动转换成 `\n`（Python 2 的 universal newlines）
- `b` 表示处理二进制文件
- `close` 关闭文件
- `tell()` 查看当前指针位置
- `seek()` 设置指针位置
- `read` 读取
- `truncate()` 只保留指针位置之前的字节并保存到文件里
- `write` 写入

## 5. 小结

参数种类：形式参数、实际参数、默认参数、关键参数（在位置参数后面）、
非固定参数 `*args`/`**kwargs`（收元组/字典，原文「元祖」为笔误）。

变量：局部变量、全局变量。

函数特性：返回值 return（函数执行中只要遇到 return 语句就会停止执行并返回
结果，return 标志着函数的结束；如果没有 return，返回值就是 None）、
嵌套函数、递归、匿名函数。

## 6. map / reduce / filter

map 可用于对可遍历结构的每个元素执行同样的操作：

```python
map(lambda x: x**2, [1, 2, 3, 4])                # [1, 4, 9, 16]

map(lambda x, y: x + y, [1, 2, 3], [5, 6, 7])    # [6, 8, 10]
```

reduce 则是对可遍历结构的元素按顺序进行两个输入参数的操作，并且每次的结果
保存作为下次操作的第一个输入参数，还没有遍历的元素作为第二个输入参数。
这样的结果就是把一串可遍历的值，减少成一个对象：

```python
reduce(lambda x, y: x + y, [1, 2, 3, 4])         # ((1+2)+3)+4=10
```

filter 根据条件对可遍历结构进行筛选：

```python
filter(lambda x: x % 2, [1, 2, 3, 4, 5])         # 筛选奇数，[1, 3, 5]
```

## 7. 列表生成式与 zip

```python
[x**2 for x in [1, 2, 3, 4, 5]]
```

zip 函数可以把多个列表关联起来：

```python
[sum(x) for x in zip([1, 2, 3], [5, 6, 7])]      # [6, 8, 10]
```

生成器表达式：

```python
iter_odd = (x for x in [1, 2, 3, 4, 5] if x % 2)
print(type(iter_odd))   # <type 'generator'>（Python 2 输出）
```

字典生成式：

```python
square_dict = {x: x**2 for x in range(5)}        # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
```

## 8. 文件操作与 pickle

open() 的第一个参数是文件名，第二个参数是模式。文件的模式一般有四种：读取
（r）、写入（w）、追加（a）和读写（r+）。如果希望按照二进制数据读取，则将
文件模式和 b 一起使用（wb、r+b……）。

```python
with open('xx.txt', 'r') as f:
    lines = f.readlines()
    for line in lines:
        name, age = line.rstrip().split(',')
        print('{} is {} years old'.format(name, age))
```

pickle 序列化读写：

```python
import pickle

lines = [
    "I'm like a dog chasing cars.",
    "I wouldn't know what to do if I caught one...",
    "I'd just do things."
]

with open('lines.pkl', 'wb') as f:
    pickle.dump(lines, f)

with open('lines.pkl', 'rb') as f:
    lines_back = pickle.load(f)
    print(lines_back)
```
