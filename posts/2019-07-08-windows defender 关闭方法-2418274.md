> **内容介绍**
>
> 本文给出用注册表关闭 Windows Defender 的方法:以管理员身份打开
> cmd,执行 reg add 向
> HKLM\SOFTWARE\Policies\Microsoft\Windows Defender 写入
> DisableAntiSpyware=1(REG_DWORD),即可禁用 Windows Defender 的
> 防护。

> **技术备注**
>
> 此法在 Win10 旧版本有效;较新的 Windows 10/11 中,Defender 的防篡改
> 保护(Tamper Protection)会拦截或回滚该键值,建议改走「Windows 安全
> 中心 → 病毒和威胁防护 → 管理设置」关闭实时保护,或用组策略
> (gpedit.msc → 计算机配置 → 管理模板 → Windows 组件 → Windows
> Defender 防病毒程序)。安装第三方杀毒软件接管时 Defender 也会自动停用。

---

## 1. 关闭方法

以管理员身份运行 cmd,执行:

```bat
reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows Defender" /v "DisableAntiSpyware" /d 1 /t REG_DWORD /f
```
