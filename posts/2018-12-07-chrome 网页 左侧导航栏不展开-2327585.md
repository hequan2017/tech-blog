> **内容介绍**
>
> 本文排查一个前端兼容性问题：Bootstrap 3 风格的多级侧边导航在 360、
> 火狐浏览器中可正常展开，唯独 Chrome 点击无反应。F12 检查发现三级菜单
> ul 上的 collapse 类没有切换为 in；最终在 window.onload 中给各级 li
> 手动 addClass("active") 并对其子 ul addClass("in")，绕过该问题。

> **技术备注**
>
> 根源是 Bootstrap 3 的 collapse 需 jQuery 插件正确初始化才会把
> collapse 切换成 in，Chrome 下脚本加载时序不同导致未触发。Bootstrap 5
> 已移除 jQuery 依赖，collapse 改由 data-bs-toggle 属性驱动，本文手动
> addClass 的做法只适用于维护 Bootstrap 3.x 旧项目。

---

## 1. 现象

多级导航的 HTML 结构（Bootstrap 3 风格，one / second / third 三级 li 嵌套，子菜单 ul 带 collapse 类）：

```html
<li class="one">
    <a rel="nofollow" href="#"><i class="fa fa-sitemap"></i>
        <span class="nav-label">菜单 </span><span class="fa arrow"></span></a>
    <ul class="nav nav-second-level collapse">
        <li class="second">
            <a rel="nofollow" href="#" id="damian">二级菜单1 <span class="fa arrow"></span></a>
            <ul class="nav nav-third-level">
                <li class="third">
                    <a rel="nofollow" href="#">三级菜单1</a>
                </li>
                <li><a rel="nofollow" href="#">三级菜单2</a></li>
                <li><a rel="nofollow" href="#">三级菜单3</a></li>
            </ul>
        </li>
        <li><a rel="nofollow" href="#">二级菜单2</a></li>
        <li><a rel="nofollow" href="#">二级菜单3</a></li>
        <li><a rel="nofollow" href="#">二级菜单4</a></li>
    </ul>
</li>
```

初始脚本只给各级 li 加了 active：

```javascript
window.onload = function () {
    $(".one").addClass("active");
    $(".second").addClass("active");
    $(".third").addClass("active");
};
```

## 2. 测试与排查

其中 360、火狐浏览器可正常展开，在 Chrome 中无法展开。

F12 查看源码，三级菜单的 ul 是：

```html
<ul class="nav nav-third-level collapse ">
</ul>
```

发现 collapse 没有变成 in，再具体的原因当时暂未查找到。

## 3. 解决办法

手动添加 in：各级 li 置为 active 的同时，把其子 ul 也加上 in 类。

```javascript
window.onload = function () {
    $(".one").addClass("active");
    $(".one").children('ul').addClass('in');
    $(".second").addClass("active");
    $(".second").children('ul').addClass('in');
    $(".third").addClass("active");
};
```
