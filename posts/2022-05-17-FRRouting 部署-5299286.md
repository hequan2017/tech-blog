> **内容介绍**
>
> 本文在 CentOS 6/7/8 上通过 rpm.frrouting.org 的 frr-stable
> 仓库部署 FRRouting（FRR）：按 EL 版本下载并安装仓库 RPM 后
> yum 安装 frr 与 frr-pythontools；再写入 IPv4/IPv6 内核转发
> 参数并用 sysctl -p 生效，设置 frr 服务开机自启，最后进入
> vtysh 交互界面配置路由。

> **技术备注**
>
> CentOS 6 已于 2020 年 11 月停止维护（EOL），生产环境建议迁移至
> Rocky Linux / AlmaLinux / Ubuntu LTS；CentOS 8（2021 年 12 月）
> 与 CentOS 7（2024 年 6 月）也已相继 EOL。撰写时 frr-stable 仓库
> 对应 FRR 8.x 稳定版，如今已迭代至更高版本，仓库 RPM 面向的 EL
> 版本以官网为准（el6 安装包已成历史）。vtysh 只能管理
> /etc/frr/daemons 中设为 yes 的守护进程（默认仅启用 zebra），
> 使用 BGP/OSPF 等协议前需开启对应守护进程并重启 frr。

---

## 1. 添加官方 RPM 仓库并安装 FRR

```shell
FRRVER="frr-stable"

# add RPM repository on CentOS 6
curl -O https://rpm.frrouting.org/repo/$FRRVER-repo-1-0.el6.noarch.rpm
sudo yum install ./$FRRVER*

# add RPM repository on CentOS 7
curl -O https://rpm.frrouting.org/repo/$FRRVER-repo-1-0.el7.noarch.rpm
sudo yum install ./$FRRVER*

# add RPM repository on CentOS 8
curl -O https://rpm.frrouting.org/repo/$FRRVER-repo-1-0.el8.noarch.rpm
sudo yum install ./$FRRVER*

# install FRR
sudo yum install frr frr-pythontools
```

## 2. 开启内核转发并启动服务

```shell
echo "net.ipv4.conf.all.forwarding=1" >> /etc/sysctl.conf

echo "net.ipv6.conf.all.forwarding=1" >> /etc/sysctl.conf

sysctl -p

systemctl enable frr.service

systemctl start frr.service

vtysh
```
