> **内容介绍**
>
> 本文用一段 Go 示例演示如何循环分页请求 API 接口：共 150 条数据、每页取
> 10 条，借助 `goto LOOP` 标签跳回循环起点重复执行，每请求一次 repeat 加一、
> count 减十，直到取完为止。文中附完整源码与 15 次请求的运行输出。

> **技术备注**
>
> Go 虽保留 goto，但限制比 C 更严：只能在本函数内跳转，且不允许跳过变量
> 声明进入其作用域。社区惯用法是优先用 for 循环与函数封装代替 goto，它一般
> 只用于从深层嵌套中一次性跳出。本例用一个普通 for 循环即可等价表达，如今
> 做分页请求或接口重试，惯用 for 循环配合退避（backoff）来实现。

---

## 1. 示例代码：goto 循环分页请求

```go
package main

import "fmt"

func main() {
  repeat := 0
  pagesize := 10
  count := 150

  /* 循环 */
LOOP:
  firstResult := repeat * pagesize
  for repeat < 1000 {
    fmt.Println("一共150个数据，一次请求10个， 本次是第", repeat, "请求", " firstResult 是: ", firstResult)
    // 这里可以去获取 count的 数据量
    if count > pagesize {
      count = count - pagesize
      repeat = repeat + 1
      goto LOOP
    } else {
      break
    }
  }
}
```
