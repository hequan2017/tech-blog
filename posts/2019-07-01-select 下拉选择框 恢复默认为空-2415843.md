> **内容介绍**
>
> 一个 jQuery 小技巧：点击"重置"按钮时，把指定 select 下拉框（这里配合 select2 类插件）的值恢复为空——关键是 `.val(null)` 之后手动 `trigger("change")`，否则插件的选中态不会刷新。

> **技术备注**
>
> `.val(null).trigger("change")` 是 select2 3.x/4.x 的经典清空写法，至今通用。若项目已迁移到 Vue/React 等框架，表单控件的清空直接改绑定的数据即可，无需手动触发 DOM 事件。

---

```html
<a class="btn btn-danger reset">重置</a>
```

```javascript
$(document).on('click', '.reset', function () {
	$("#id_name").val(null).trigger("change");
})
```
