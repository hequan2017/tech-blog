> **内容介绍**
>
> 本文是系列第一篇(下),继续为 PHP 编译安装三个扩展:memcache 客户端插件(与服务器端
> memcached 配合做数据库缓存,编译 memcache-2.2.5)、PDO_MYSQL-1.0.2(通过
> --with-pdo-mysql 连接本地 MySQL),以及先安装 ImageMagick-6.5.1-2 图像库(CentOS 6.5
> 需先 yum 安装 perl-devel 否则报错)再编译 imagick-2.3.0 PHP 扩展;均为 phpize +
> configure + make install 的标准流程,软件包可从文内网盘链接下载。

> **技术备注**
>
> CentOS 6 已于 2020 年 11 月停止维护(EOL),生产环境建议迁移至 Rocky Linux / AlmaLinux / Ubuntu LTS。
> 补充:memcache-2.2.5 不兼容 PHP 7+,新环境需用 3.x 分支或改用 php-memcached;
> PDO_MYSQL 后期 PHP 版本已随源码提供,编译 PHP 时加 --with-pdo-mysql 即可,无需再
> 单独装 1.0.2;ImageMagick/imagick 现可直接用 yum/dnf 安装。文中百度网盘链接可能已失效。

## 1. 安装 memcache 客户端扩展

memcache 数据库缓存扩展模块分为**服务器端 memcached** 和**客户端插件 memcache**,这里装客户端插件。软件可到[网盘](http://pan.baidu.com/s/1qYDwiDI)下载。

```shell
tar xf memcache-2.2.5.tgz
cd memcache-2.2.5

/application/php/bin/phpize

./configure --with-php-config=/application/php/bin/php-config

make && make install

ls /application/php5.3.27/lib/php/extensions/no-debug-zts-20090626/
```

## 2. 安装 PDO_MYSQL 扩展

```shell
tar zxvf PDO_MYSQL-1.0.2.tgz
cd PDO_MYSQL-1.0.2

/application/php/bin/phpize

./configure --with-php-config=/application/php/bin/php-config \
    --with-pdo-mysql=/application/mysql

make && make install
```

安装完成后生成 `pdo_mysql.so`。

## 3. 安装 ImageMagick 图像软件

先安装此软件(给 imagick 提供 C 底层库):

```shell
tar zxf ImageMagick.tar.gz
cd ImageMagick-6.5.1-2/

./configure

yum -y install perl-devel    # 安装此软件,不然 6.5 有报错

make && make install
```

## 4. 安装 imagick 扩展

```shell
tar zxf imagick-2.3.0.tgz
cd imagick-2.3.0

/application/php/bin/phpize

./configure --with-php-config=/application/php/bin/php-config

make

make install
```
