> **内容介绍**
>
> 一套基于 Jenkins 2.89.4 的 Java 项目持续部署流程：把 jenkins.war 丢进 Tomcat 运行，编译安装 Git 2.9.5 与 Maven 3.5.2，配合 GitLab 管理代码（zrlog 项目为例），装好 Git/Maven Integration/Deploy to container 三个插件后新建 Maven 项目任务，构建成功后自动把 war 包部署到远程 Tomcat 8。

> **技术备注**
>
> Jenkins 2.89.4 是 2018 年的 LTS 版本，早已停止支持，且官方更新站已强制 HTTPS（update-center.json 需用 https://updates.jenkins.io/update-center.json）。新装请使用当前 LTS（要求 JDK 17/21）。"Deploy to container" 插件方式已被更常见的 Pipeline + SSH/容器镜像方式取代；Git 与 Maven 也建议直接用发行版包管理器安装，不必源码编译。

#### 登录，初始化

#### git安装

```shell
yum install curl-devel expat-devel gettext-devel openssl-devel zlib-devel gcc-c++ perl-ExtUtils-MakeMaker wget autoconf -y
wget https://www.kernel.org/pub/software/scm/git/git-2.9.5.tar.gz
tar xf git-2.9.5.tar.gz
cd git-2.9.5
make configure
./configure --prefix=/usr/local/git
make
make install
echo "export PATH=$PATH:/usr/local/git/bin" > /etc/profile.d/git.sh
source /etc/profile.d/git.sh
```

#### maven安装

```shell
cd /usr/local/ &&  wget https://archive.apache.org/dist/maven/maven-3/3.5.2/binaries/apache-maven-3.5.2-bin.tar.gz    && \
tar -zxf apache-maven-3.5.2-bin.tar.gz && mv apache-maven-3.5.2 maven && mv apache-maven-3.5.2-bin.tar.gz   /usr/local/src \
&&  echo "export PATH=$PATH:/usr/local/maven/bin" > /etc/profile.d/maven.sh   &&
source /etc/profile.d/maven.sh
mvn --version
```
