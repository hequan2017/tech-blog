> **内容介绍**
>
> 介绍用 Python 的 dramatiq 库（Celery 的轻量替代品）编写异步任务：以 Redis 作为 broker，定义 `@dramatiq.actor` 装饰的任务函数并通过 `.send()` 投递，最后用 `dramatiq example --watch .` 启动 worker 并监听代码变更自动重启。
>
> **技术备注**
>
> dramatiq 至今仍活跃维护，API 与文中基本一致；新版官方推荐 `pip install 'dramatiq[redis, watch]'` 写法不变，但 Python 2 已完全停止支持，需 Python 3.8+。注意原文安装行中 "redi s" 为笔误。

### python 异步程序 dramatiq

#### 安装

需要先有 Redis（原文 "redi s" 为笔误），然后安装：

```shell
pip3 install 'dramatiq[redis, watch]'
```

#### 代码

##### example.py

```python
import dramatiq
import requests
from dramatiq.brokers.redis import RedisBroker

redis_broker = RedisBroker(host="127.0.0.1", port=6379)
dramatiq.set_broker(redis_broker)

@dramatiq.actor
def count_words(url):
    print(url)

count_words.send("http://example.com")
```

##### 执行

```shell
// watch . 代码 动态检测 代码是否更新，然后自动重启
dramatiq example --watch .
```
