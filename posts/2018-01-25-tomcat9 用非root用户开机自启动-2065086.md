> **内容介绍**
>
> 让 Tomcat 以非 root 的 tomcat 用户开机自启动的两种办法之一：编译 commons-daemon 的 jsvc，复用 bin/daemon.sh 作为 /etc/init.d/tomcat 启动脚本，chkconfig 注册开机启动，并在脚本里通过 JAVA_OPTS 调 JVM 堆内存与 CMS GC 参数。

> **技术备注**
>
> 写法适用于 CentOS 6/7 的 SysV init。在 RHEL 8+/Rocky 8+ 上 chkconfig/init.d 已不主流，建议改用 systemd unit（`User=tomcat` + `ExecStart=/usr/local/tomcat/bin/startup.sh`）。JDK 8 之后 PermSize/MaxPermSize 已被 MetaspaceSize 取代（JDK 8 起），CMS GC 在 JDK 14 起被移除，现代版本推荐 G1 或 ZGC。

### 用tomcat用户开机启动

#### 创建用户

```shell
groupadd tomcat
useradd -g tomcat   tomcat   -s /sbin/nologin
chown tomcat.tomcat -R /usr/local/tomcat/*
```

#### 编译 jsvc

```shell
cd /usr/local/tomcat/bin/
tar xf commons-daemon-native.tar.gz
cd commons-daemon-1.1.0-native-src/unix/
./configure --with-java=$JAVA_HOME
make

cp jsvc /usr/local/tomcat/bin/
cp /usr/local/tomcat/bin/daemon.sh    /etc/init.d/tomcat
```

#### 修改启动文件，内存优化

```shell
vim /etc/init.d/tomcat
#!/bin/sh
# chkconfig: 2345 81 91
# description: Start and Stop  tomcat

JAVA_HOME=/usr/local/jdk8.0
JAVA_BIN=/usr/local/jdk8.0/bin
CLASSPATH=$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar
CATALINA_BASE=/usr/local/tomcat
CATALINA_HOME=/usr/local/tomcat

JAVA_OPTS="-server
-Xms1024m
-Xmx1536m
-XX:PermSize=256m
-XX:MaxPermSize=512m
-XX:+UseConcMarkSweepGC
-XX:+UseCMSCompactAtFullCollection
-XX:CMSFullGCsBeforeCompaction=0
-XX:-PrintGC
-XX:-PrintGCDetails
-XX:-PrintGCTimeStamps
-Xloggc:../logs/gc.log "

## -Xmx1536m     堆内存最大允许大小，一般不要大于物理内存的80%

/etc/init.d/tomcat start

chkconfig tomcat on
```
