## 2. 更改 nginx 版本信息

```shell
curl -I 192.168.10.11
```

```text
Server: nginx/1.6.3
```

### 第一种:修改版本及版本号(编译前改源码)

```c
// src/core/nginx.h
#define nginx_version      1008001
#define NGINX_VERSION      "1.8.1"        # 修改想要显示的版本,如:2.2.23
#define NGINX_VER          "nginx/" NGINX_VERSION   # 将 nginx 改成想要显示的软件名称
#define NGINX_VAR          "NGINX"        # 将 nginx 改成想要显示的软件名称(Evan Web Server)
#define NGX_OLDPID_EXT     ".oldbin"
```

```c
// src/http/ngx_http_header_filter_module.c
static char ngx_http_server_string[] = "Server: nginx" CRLF;   # 将 nginx 改为想要的版本
```

```c
// src/http/ngx_http_special_response.c
"<hr><center>nginx</center>" CRLF    # 将 nginx 改为想要的版本信息
```

### 第二种:隐藏版本号

在 nginx 配置文件里增加 `server_tokens off;`。server_tokens 作用域是 http、server、
location 语句块,默认值 on 表示显示版本信息,设为 off 即可在所有地方隐藏 nginx 版本号。

```nginx
http {
    server_tokens off;
}
```

```shell
/application/nginx/sbin/nginx -s reload
```

之后响应头里 `nginx/1.6.3` 变成 `nginx`,404 Not Found 页面同理。

## 3. 更改 nginx 的运行用户

```shell
# grep "#user" nginx.conf.default    # 默认文件
```

```nginx
#user  nobody;
```

两种方式:

```shell
# 1. 修改配置文件
vim nginx.conf
```

```nginx
user nginx nginx;
```

```shell
# 2. 编译时指定
./configure --user=nginx --group=nginx
```

```shell
ps -ef | grep nginx
```

```text
root      56512      1  0 02:35 ?        00:00:00 nginx: master process
nginx     57470  56512  0 04:04 ?        00:00:00 nginx: worker process
```

主进程默认用 root 运行(监听 80 端口需要);worker 进程用 nginx 用户运行。

## 4. 配置 worker 进程个数

```nginx
worker_processes  1;   # 等于 CPU 的核心数,cat /proc/cpuinfo | grep -c processor 查看
```

更改为 `worker_processes 2;` 后查看进程:

```text
nginx      1822   1784  0 04:14 ?        00:00:00 nginx: worker process
nginx      1823   1784  0 04:14 ?        00:00:00 nginx: worker process
```

## 5. 配置 worker_cpu_affinity

把每个 worker 进程分配到单独的 CPU 核上:

```nginx
worker_processes 2;
worker_cpu_affinity 0101 1010;

worker_processes 4;
worker_cpu_affinity 0001 0010 0100 1000;

worker_processes 8;
worker_cpu_affinity 0001 0010 0100 1000 0001 0010 0100 1000;
```

## 7. taskset 指定进程 CPU 亲和

taskset 可以查看或设置进程的 CPU 亲和性:

```shell
taskset -c 1,2,3 /etc/init.d/mysql start    # 让某个进程跑在指定 CPU 上
```

## 8. 事件处理模型优化

Linux 下使用 epoll 模型:

```nginx
events {                            # 设定 nginx 工作模式及连接数上限
    use epoll;
    worker_connections 20480;       # 每个进程的最大连接数,默认 1024
}
```

最大客户端连接数 **Max_client = worker_processes \* worker_connections**。

进程的最大连接数受系统进程最大打开文件数限制,执行 `ulimit -HSn 65535`,或配合:

```nginx
worker_rlimit_nofile 65535;    # 每个进程最大文件打开数
```

## 9. 优化服务器名字 hash 表大小

```nginx
# http://hequan.blog.51cto.com/  泛解析场景
http {
    server_names_hash_bucket_size 64;
    server_names_hash_max_size 512;    # 默认为 512,一般为 CPU L1 的 4-5 倍
}
```

## 10. 开启高效的文件传输模式

```nginx
sendfile   on;
tcp_nopush on;
```

## 11. 连接超时时间

php 服务建议使用短连接:

```nginx
keepalive_timeout      60;    # 客户端连接保持会话的超时时间
tcp_nodelay            on;
client_header_timeout  15;    # 客户端请求头读取超时,超时不发送数据返回 408 错误
client_body_timeout    15;    # 客户端主体读取超时
send_timeout           15;    # 响应客户端的超时时间
```

## 12. 上传文件大小限制(动态应用)

```nginx
client_max_body_size 10m;    # 客户端最大上传,超过报 413 错误;0 是不检查;php 默认 2m
```

## 13. fastcgi 调优

```nginx
location ~ .*\.(php|php5)?$ {
    fastcgi_pass   127.0.0.1:9000;
    fastcgi_index  index.php;
    include        fastcgi.conf;
}
```

```nginx
fastcgi_connect_timeout 300;          # 连接
fastcgi_send_timeout    300;          # 传送请求
fastcgi_read_timeout    300;          # 应答
fastcgi_buffer_size     64k;          # 缓冲区
fastcgi_buffers         4 64k;        # 多少个多大的缓冲区
fastcgi_busy_buffers_size 128k;
fastcgi_temp_file_write_size 128k;

fastcgi_cache hequan_nginx;
fastcgi_cache_valid 200 302 1h;
fastcgi_cache_valid 301 1d;
fastcgi_cache_valid any 1m;
fastcgi_cache_min_uses 1;
```
