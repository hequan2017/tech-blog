> **内容介绍**
>
> 本文介绍 GeoIP 的最快捷安装方式：下载 GeoIP/GeoLiteCity/GeoIPASNum
> 数据包并解压，同时通过 EPEL 源 yum 安装 GeoIP、GeoIP-devel 与
> perl-Geo-IP，并说明各数据文件分别对应国家、城市与组织信息。

> **技术备注**
>
> 文中 wget 链接已失效，且 MaxMind 已于 2019 年停止 GeoLite 旧版数据
> 下载；CentOS 6 已于 2020 年 EOL，EPEL 6 仓库亦不再维护，建议改用
> GeoLite2 数据库与 geoipupdate 工具。

---

下载GeoIP数据包

mkdir /GeoIP
cd /GeoIP

wget http:///download/geoip/database/GeoLiteCountry/GeoIP.dat.gz
wget http:///download/geoip/database/GeoLiteCity.dat.gz
wget http:///download/geoip/database/asnum/GeoIPASNum.dat.gz

gunzip GeoIP.dat.gz
gunzip GeoIPASNum.dat.gz

gunzip GeoLiteCity.dat.gz

// GeoIP 是国家数据，GeoLiteCity 是城市数据，GeoIPASNum 是组织数据

安装程序

rpm -ivh   [http:///pub/epel/6/x86_64/epel-release-6-8.noarch.rpm](http:///pub/epel/6/x86_64/epel-release-6-8.noarch.rpm)

```bash
vim /etc/yum.repos.d/epel.repo      ## 注释mirrorlist url(包含https) ,然后取消注释baseurl

yum -y install GeoIP GeoIP-devel perl-Geo-IP

Verifying  : GeoIP-devel-1.6.5-1.el6.x86_64                                  1/5
Verifying  : geoipupdate-2.2.1-2.el6.x86_64                                  2/5
Verifying  : GeoIP-GeoLite-data-2015.12-1.el6.noarch                         3/5
Verifying  : GeoIP-1.6.5-1.el6.x86_64                                        4/5
Verifying  : GeoIP-GeoLite-data-extra-2015.12-1.el6.noarch                   5/5
```
