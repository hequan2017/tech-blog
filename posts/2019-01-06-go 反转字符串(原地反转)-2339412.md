> **内容介绍**
>
> 演示 Go 中原地反转字符串的方法：由于 Go 字符串不可直接按索引赋值且中文等多字节字符按 byte 反转会乱码，需先转成 `[]rune` 再双指针两两交换。这是一个常见的算法面试小题，适合理解 string 与 rune 的区别。
>
> **技术备注**
>
> Go 1.18 之后也可借助泛型封装切片反转，但 `[]rune` 交换法至今仍是标准做法，内容通用。

---

```go
package main

import (
	"fmt"
)

func reverse(s string) string {
	s1 := []rune(s)
	for i := 0; i < len(s1)/2; i++ {
		tmp := s1[i]
		s1[i] = s1[len(s1)-1-i]
		s1[len(s1)-1-i] = tmp
	}
	return string(s1)
}

func main() {
	s := "123456"
	fmt.Println(reverse(s))
}
```
