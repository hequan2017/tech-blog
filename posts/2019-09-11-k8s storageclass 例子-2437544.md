> **内容介绍**
>
> 本文通过一组 YAML 清单演示 Kubernetes StorageClass + NFS 动态
> 供给：部署 nfs-client-provisioner（ServiceAccount + Deployment，
> 指定 NFS 服务器 192.168.100.111、共享目录 /data1）；创建
> ClusterRole / ClusterRoleBinding 完成授权；定义名为 nfs 的
> StorageClass；最后创建 PVC（test-claim）测试自动供给 PV。

> **技术备注**
>
> 本文写于 2019 年：Deployment 使用的 extensions/v1beta1 在
> k8s 1.16+ 已移除，现代版本需改用 apps/v1 并补充 selector；
> nfs-client-provisioner（external-storage）项目已归档，社区现
> 维护 kubernetes-sigs/nfs-subdir-external-provisioner；PVC 中的
> volume.beta.kubernetes.io/storage-class 注解已被
> spec.storageClassName 取代；ClusterRole 中的 podsecuritypolicies
> 授权随 PSP 在 k8s 1.25 一并移除。

## 1. 部署 nfs-client-provisioner

> 需要提前搭建一个 nfs

```yaml
apiVersion: v1
kind: ServiceAccount
metadata:
  name: nfs-client-provisioner
---
kind: Deployment
apiVersion: extensions/v1beta1
metadata:
  name: nfs-client-provisioner
spec:
  replicas: 1
  strategy:
    type: Recreate
  template:
    metadata:
      labels:
        app: nfs-client-provisioner
    spec:
      serviceAccount: nfs-client-provisioner
      containers:
        - name: nfs-client-provisioner
          image: registry.cn-hangzhou.aliyuncs.com/open-ali/nfs-client-provisioner
          volumeMounts:
            - name: nfs-client-root
              mountPath: /persistentvolumes
          env:
            - name: PROVISIONER_NAME
              value: hequan.com/nfs
            - name: NFS_SERVER
              value: 192.168.100.111
            - name: NFS_PATH
              value: /data1
      volumes:
        - name: nfs-client-root
          nfs:
            server: 192.168.100.111
            path: /data1
```

## 2. RBAC 授权

```shell
vim clusterrole.yaml   # 创建 ClusterRole
```

```yaml
kind: ClusterRole
apiVersion: rbac.authorization.k8s.io/v1
metadata:
  name: nfs-provisioner-runner
rules:
  - apiGroups: [""]
    resources: ["persistentvolumes"]
    verbs: ["get", "list", "watch", "create", "delete"]
  - apiGroups: [""]
    resources: ["persistentvolumeclaims"]
    verbs: ["get", "list", "watch", "update"]
  - apiGroups: ["storage.k8s.io"]
    resources: ["storageclasses"]
    verbs: ["get", "list", "watch"]
  - apiGroups: [""]
    resources: ["events"]
    verbs: ["watch", "create", "update", "patch"]
  - apiGroups: [""]
    resources: ["services", "endpoints"]
    verbs: ["get"]
  - apiGroups: ["extensions"]
    resources: ["podsecuritypolicies"]
    resourceNames: ["nfs-provisioner"]
    verbs: ["use"]
```

```shell
vim clusterrolebinding.yaml   # 创建 ClusterRoleBinding
```

```yaml
kind: ClusterRoleBinding
apiVersion: rbac.authorization.k8s.io/v1
metadata:
  name: run-nfs-provisioner
subjects:
  - kind: ServiceAccount
    name: nfs-client-provisioner
    namespace: default
roleRef:
  kind: ClusterRole
  name: nfs-provisioner-runner
  apiGroup: rbac.authorization.k8s.io
```

## 3. StorageClass

```yaml
kind: StorageClass
apiVersion: storage.k8s.io/v1
metadata:
  name: nfs
provisioner: hequan.com/nfs
parameters:
  archiveOnDelete: "false"
```

## 4. 测试

创建 PVC（test-claim）测试自动供给 PV：

```yaml
kind: PersistentVolumeClaim
apiVersion: v1
metadata:
  name: test-claim
  annotations:
    volume.beta.kubernetes.io/storage-class: "nfs"
spec:
  accessModes:
    - ReadWriteMany
  resources:
    requests:
      storage: 1Mi
```
