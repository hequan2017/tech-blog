> **内容介绍**
>
> Python 3 用 Pillow（PIL 的分支）把一段文本渲染成图片的最小示例：安装 pillow、
> 在 fonts 目录准备微软雅黑 msyh.ttf 字体，然后 Image.new 建白色画布、
> ImageFont.truetype 加载字体、ImageDraw.Draw 将带变量的字符串画上去，
> 最后 im.show() 预览并保存为 t.png。

> **技术备注**
>
> Pillow 至今仍是 Python 的标准图像库，持续维护中。注意：微软雅黑 msyh.ttf 为
> 商业字体，Linux 服务器上自行复制有版权风险，建议改用思源黑体、文泉驿等开源
> 字体；本例 `ImageFont.truetype` 首个参数是相对当前工作目录的路径，换目录执行
> 时需改为绝对路径。

---

## 1. 安装与字体准备

python3 下的 PIL 叫做 pillow：

```bash
python -m pip install pillow
```

创建目录 fonts，把微软雅黑字体放到下面，即 `fonts/msyh.ttf`。

## 2. 代码示例

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
import os
from PIL import Image, ImageFont, ImageDraw

l = [1, 23, 4]
text = u"这是一段测试文本，test 123。{}\n ".format(l[1])
im = Image.new("RGB", (300, 50), (255, 255, 255))
dr = ImageDraw.Draw(im)
font = ImageFont.truetype(os.path.join("fonts", "msyh.ttf"), 14)
dr.text((10, 5), text, font=font, fill="#000000")
im.show()
im.save("t.png")
```
