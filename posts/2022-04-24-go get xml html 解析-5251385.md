> **内容介绍**
>
> 用 Go 发起 HTTP 请求抓取网页，用 goquery 以 jQuery 风格解析 HTML，
> 提取 pre 标签中的文本，再交给 encoding/xml 反序列化到结构体。
> 全文以一段示例代码为主，属于片段式笔记。

> **技术备注**
>
> `io/ioutil` 自 Go 1.16 起已废弃，`ioutil.ReadAll` 对应的新写法是 `io.ReadAll`；
> `encoding/xml` 至今仍在标准库中，API 长期稳定；goquery 也仍是 Go 生态中最常用的
> jQuery 风格 HTML 解析库（底层基于 golang.org/x/net/html）。

## 1. 示例代码

```go
package jielv

import (
  "encoding/xml"
  "github.com/PuerkitoBio/goquery"
  "io/ioutil"
  "log"
  "net/http"
  "strings"
)

func getXML() []byte {
  url := "http://"
  resp, _ := http.Get(url)
  defer resp.Body.Close()
  data, _ := ioutil.ReadAll(resp.Body)
  return data
}

type Test struct {

}

func main() {

  re := getXML()
  dom, err := goquery.NewDocumentFromReader(strings.NewReader(string(re)))
  if err != nil {
    log.Fatalln(err)
  }
  var s string
  dom.Find("pre").Each(func(i int, selection *goquery.Selection) {
    s = s + selection.Text()
  })
  var city Test
  xml.Unmarshal([]byte(s), &city)
}
```
