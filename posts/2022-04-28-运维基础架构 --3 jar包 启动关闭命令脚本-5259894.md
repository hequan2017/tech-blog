> **内容介绍**
>
> 本文是「运维基础架构」系列第 3 篇：用一份 shell 脚本管理 jar 包服务的启停。
> 脚本以当前目录名作为项目名，提供 start/stop/restart 三个子命令。
> 启动前检测重复进程，nohup 后台拉起并记录 pid，停止时按 pid 强杀并清理。

> **技术备注**
>
> 项目名取自执行脚本时的当前目录名，jar 路径为 /data/app/<项目名>/<项目名>.jar。
> Usage 提示含 update，但脚本仅实现 start/stop/restart 三个分支（原文如此）。
> stop 采用 kill -9 强制结束进程，Java 应用不会执行优雅停机钩子。

## 1. jar 包启动/关闭/重启脚本

```shell
#!/bin/sh

project="`pwd | awk -F'/' '{print $NF}'`"

APP_BASE=/data/app
echo "工作目录:"$APP_BASE/${project}

case "$1" in
  start)
    cd ${APP_BASE}/${project}
    ps aux | egrep -v '\bvi\b|\bvim\b|\bgrep\b|\btail\b|\bcat\b|\bhead\b' | grep java | grep -q "${project}"
    if [ $? -eq 0 ]; then
      echo "   ${project}.jar is running !"
      exit 12
    fi
    nohup java -jar -XX:MetaspaceSize=256m -XX:MaxMetaspaceSize=256m -XX:+HeapDumpOnOutOfMemoryError -Xms256m -Xmx512m ${APP_BASE}/${project}/${project}.jar > /dev/null 2>&1 &
    echo $! > ${project}.pid
    ;;

  stop)
    cd ${APP_BASE}/${project}
    ps aux | egrep -v '\bvi\b|\bvim\b|\bgrep\b|\btail\b|\bcat\b|\bhead\b' | grep java | grep -q "${project}"
    if [ $? -eq 0 ]; then
      processId=$(cat ${project}.pid)
      echo $processId
      kill -9 $processId
      rm -f ${project}.pid
      echo "    ${project} is stopped !"
    else
      echo "    ${project} is not start !"
    fi
    ;;

  restart)
    cd ${APP_BASE}/${project}
    sh $0 stop
    sleep 1
    sh $0 start
    ;;

  *)
    echo "Usage: $0 {start|stop|restart|update}"
    ;;

esac

exit 0
```
