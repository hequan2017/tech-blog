> **内容介绍**
>
> 本文给出一小段 Go 程序：向 STUN 服务器（默认端口 3478）发起探测，
> 采集本机出口的 NAT 类型与公网 IP，属 PCDN 场景下的基础采集能力。
> 代码仅十几行，依赖 `github.com/ppma/nat-type` 封装的 Query 接口。

> **技术备注**
>
> STUN 的原理是本机向公网服务器发送 UDP 请求，依据返回的映射地址
> 判断出口 NAT 行为；按 RFC 3489 的经典分类，NAT 分为全锥形、
> IP 限制锥形、端口限制锥形与对称型四类，越靠后对 P2P 打洞越不利。
> `stun.qq.com` 是腾讯提供的公共 STUN 服务器，3478 为 STUN 默认端口。

---

```go
package main

import (
	"fmt"
	stun "github.com/ppma/nat-type"
)

const (
	STUN_SERVER = "stun.qq.com"
	STUN_PORT   = 3478
)

func main() {
	localAddr := fmt.Sprintf("%s:%d", "192.168.8.109", 8569)
	stunAddr := fmt.Sprintf("%s:%d", STUN_SERVER, STUN_PORT)
	result, err := stun.Query(stunAddr, localAddr)
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println("Nat type: ", result.GetNatType())

	fmt.Println("Public IP: ", result.GetIpAddr())
}
```
