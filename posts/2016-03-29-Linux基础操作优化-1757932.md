> **内容介绍**
>
> 本文是 CentOS 6 时代的系统初始化优化笔记，涵盖 yum 包管理（update / upgrade 区别、
> 常用运维工具安装）、关闭 SELinux、精简开机自启服务（仅保留 sshd / crond / network / rsyslog）、
> 设置中文语言环境、配置 ntp 定时校时、调大文件描述符上限（ulimit）、锁定关键账号文件等
> 一系列装机后的基础加固与优化操作。

> **技术备注**
>
> 本文基于 CentOS 6：`chkconfig` / `ntsysv` / `setup` / `/etc/inittab` / `/etc/sysconfig/i18n`
> 等在 CentOS 7+ 已分别被 `systemctl`、`/etc/systemd/system/default.target`、`localectl`
> 和 `/etc/locale.conf` 取代。CentOS 6/7 均已停止维护（EOL），新环境建议使用
> Rocky Linux / AlmaLinux，并将服务管理命令替换为 systemd 写法；时间同步建议改用
> chrony（`chronyd` + `chronyc sources`），cron 里跑 ntpdate 的做法在 systemd 系统上
> 已由 `systemd-timesyncd` 或 chrony 替代。

## 1. yum 包管理

查看可安装的软件包组 / 按组安装：

```shell
yum grouplist                          # 列出所有软件包组
yum groupinstall "Development Tools"   # 安装开发工具组（gcc、make 等）
```

系统升级的两个常用命令：

```shell
yum -y update    # 升级全部软件包（含内核），处理 obsolete 关系
yum -y upgrade   # 等同 yum update --obsoletes，行为与 update 基本一致
```

- `yum -y update`：升级所有软件包和系统内核，会处理软件包的废弃（obsolete）关系。
- `yum -y upgrade`：等同于 `yum update --obsoletes`，行为与 update 基本一致
  （旧文档中"upgrade 不换内核"的说法并不准确，实际二者差异很小）。

安装常用运维工具：

```shell
yum install tree telnet dos2unix sysstat lrzsz -y  # tree目录树 / telnet测端口 / dos2unix转格式 / sysstat性能监控 / lrzsz上传下载
```

> 备注：新系统（RHEL 8+/Rocky/Alma）中用 `dnf` 替代 `yum`，参数兼容；
> 测端口更推荐 `nc`（nmap-ncat），telnet 协议本身已因明文传输被淘汰。

## 2. 关闭 SELinux

```shell
sed -i 's#SELINUX=enforcing#SELINUX=disabled#g' /etc/selinux/config  # 永久关闭（需重启）
getenforce   # 查看当前 SELinux 状态
```

修改配置文件后需重启生效；若只想临时关闭，可用 `setenforce 0`。

## 3. 运行级别与文本配置工具（仅 CentOS 6 适用）

```shell
runlevel            # 查看当前运行级别
vi /etc/inittab     # 配置默认运行级别（CentOS 6；CentOS 7+ 已废弃该文件）
init 3              # 切换到运行级别 3（多用户字符界面）
setup               # 文本界面综合配置工具
ntsysv              # 文本界面开机自启管理
```

> 备注：CentOS 7+ 已无运行级别概念，对应命令为
> `systemctl get-default` / `systemctl set-default multi-user.target`。

## 4. 精简开机自启服务

查看运行级别 3 下启用的服务：

```shell
chkconfig --list | grep "3:on"   # 列出级别 3 下所有开机自启的服务
```

一键关闭所有自启服务：

```shell
for hequan in `chkconfig --list | grep "3:on" | awk '{print $1}'`; do
  chkconfig $hequan off
done
```

只保留 4 个必要服务（crond、network、rsyslog、sshd）：

```shell
for hequan in sshd crond network rsyslog; do
  chkconfig $hequan on
done
```

或者：关闭除这 4 个以外的全部服务：

```shell
for hequan in `chkconfig --list | grep "3:on" | awk '{print $1}' | grep -vE "crond|network|sshd|rsyslog"`; do
  chkconfig $hequan off
done
```

> 备注：systemd 系统上等价命令为 `systemctl list-unit-files --state=enabled`
> 和 `systemctl enable/disable 服务名`。

## 5. SSH 配置

```shell
vi /etc/ssh/sshd_config   # 编辑 SSH 服务端配置
```

常改项：修改默认端口（`Port`）、禁止 root 直连（`PermitRootLogin no`）、
关闭 DNS 反解（`UseDNS no`，可加快登录速度）等，改完执行 `service sshd restart`
（systemd 系统为 `systemctl restart sshd`）。

## 6. 中文语言环境

查看 / 设置系统语言（CentOS 6）：

```shell
cat /etc/sysconfig/i18n                        # 查看当前语言配置
echo 'LANG="zh_CN.UTF-8"' > /etc/sysconfig/i18n  # 设置为中文 UTF-8
```

临时切换为英文（仅当前会话生效，排错时很实用）：

```shell
LANG=en_US.UTF-8
```

> 备注：CentOS 7+ 语言配置文件改为 `/etc/locale.conf`，推荐用
> `localectl set-locale LANG=zh_CN.UTF-8` 修改。

## 7. 时间同步

手动校时：

```shell
/usr/sbin/ntpdate ntp1.aliyun.com   # 使用阿里云 NTP 服务器立即校时
```

写入 crontab，每 5 分钟自动校时：

```shell
echo '*/5 * * * * /usr/sbin/ntpdate ntp1.aliyun.com > /dev/null 2>&1' >> /var/spool/cron/root  # 追加定时任务
crontab -l   # 确认任务已写入
```

> 备注：ntpdate 已被官方标记为废弃（deprecated），新系统请改用 chrony：
> `chronyc -a makestep` 立即校时，或直接启用 chronyd 守护进程持续同步。

## 8. 调整资源限制

查看 / 调大进程可打开文件数：

```shell
ulimit -n                                          # 查看当前 fd 上限（默认 1024）
echo '* - nofile 65535' >> /etc/security/limits.conf  # 所有用户软硬限制均设为 65535
```

内核参数优化：

```shell
vi /etc/sysctl.conf   # 编辑内核参数（如 net.core.somaxconn、net.ipv4.tcp_tw_reuse 等）
sysctl -p             # 使配置立即生效
```

## 9. 登录提示与账号文件保护

登录前 / 登录后的提示信息：

```shell
cat /etc/issue   # 本地登录前的提示（建议清空，避免泄露系统版本）
vi /etc/motd     # 登录成功后的欢迎信息
```

锁定关键账号文件，防止被误改（即使是 root 也无法写入）：

```shell
chattr +i /etc/passwd   # 添加 immutable 属性锁定文件
lsattr /etc/passwd      # 查看文件特殊属性
```

需要修改时先 `chattr -i /etc/passwd` 解锁，改完再加回。生产环境对
`/etc/passwd`、`/etc/shadow`、`/etc/group`、`/etc/gshadow`、`/etc/inittab`
做此保护可有效防止误操作与部分提权篡改。
