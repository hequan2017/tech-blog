> **内容介绍**
>
> 本文是 CentOS 6 时代的系统初始化优化笔记，涵盖 yum 包管理（update / upgrade 区别、
> 常用运维工具安装）、关闭 SELinux、精简开机自启服务（仅保留 sshd / crond / network / rsyslog）、
> 设置中文语言环境、配置 ntp 定时校时、调大文件描述符上限（ulimit）、锁定关键账号文件等
> 一系列装机后的基础加固与优化操作。

> **技术备注**
>
> 本文基于 CentOS 6：`chkconfig` / `ntsysv` / `setup` / `/etc/inittab` / `/etc/sysconfig/i18n`
> 等在 CentOS 7+ 已分别被 `systemctl`、`/etc/systemd/system/default.target`、`localectl`
> 和 `/etc/locale.conf` 取代。CentOS 6/7 均已停止维护（EOL），新环境建议使用
> Rocky Linux / AlmaLinux，并将服务管理命令替换为 systemd 写法；时间同步建议改用 chrony。

## 1. yum 包管理

查看可安装的软件包组 / 按组安装：

```shell
yum grouplist
yum groupinstall "Development Tools"
```

系统升级的两个常用命令：

```shell
yum -y update
yum -y upgrade
```

- `yum -y update`：升级所有软件包和系统内核，会处理软件包的废弃（obsolete）关系。
- `yum -y upgrade`：等同于 `yum update --obsoletes`，行为与 update 基本一致
  （旧文档中"upgrade 不换内核"的说法并不准确，实际二者差异很小）。

安装常用运维工具：

```shell
yum install tree telnet dos2unix sysstat lrzsz -y
```

## 2. 关闭 SELinux

```shell
sed -i 's#SELINUX=enforcing#SELINUX=disabled#g' /etc/selinux/config
getenforce
```

修改后需重启生效，`getenforce` 用于查看当前状态。

## 3. 运行级别与文本配置工具

```shell
runlevel            # 查看当前运行级别
vi /etc/inittab     # 配置默认运行级别(CentOS 6)
init 3              # 切换运行级别
setup               # 文本界面综合配置工具
ntsysv              # 文本界面开机自启管理
```

## 4. 精简开机自启服务

查看运行级别 3 下启用的服务：

```shell
chkconfig --list | grep "3:on"
```

一键关闭所有自启服务：

```shell
for hequan in `chkconfig --list | grep "3:on" | awk '{print $1}'`; do
  chkconfig $hequan off
done
```

只保留 4 个必要服务（crond、network、rsyslog、sshd）：

```shell
for hequan in sshd crond network rsyslog; do
  chkconfig $hequan on
done
```

或者：关闭除这 4 个以外的全部服务：

```shell
for hequan in `chkconfig --list | grep "3:on" | awk '{print $1}' | grep -vE "crond|network|sshd|rsyslog"`; do
  chkconfig $hequan off
done
```

## 5. SSH 配置

```shell
vi /etc/ssh/sshd_config
```

常改项：端口、禁止 root 直连、关闭 DNS 反解（`UseDNS no`）等。

## 6. 中文语言环境

查看 / 设置系统语言（CentOS 6）：

```shell
cat /etc/sysconfig/i18n
echo 'LANG="zh_CN.UTF-8"' > /etc/sysconfig/i18n
```

临时切换为英文：

```shell
LANG=en_US.UTF-8
```

## 7. 时间同步

手动校时：

```shell
/usr/sbin/ntpdate ntp1.aliyun.com
```

写入 crontab，每 5 分钟自动校时：

```shell
echo '*/5 * * * * /usr/sbin/ntpdate ntp1.aliyun.com > /dev/null 2>&1' >> /var/spool/cron/root
crontab -l
```

## 8. 调整资源限制

查看 / 调大进程可打开文件数：

```shell
ulimit -n
echo '* - nofile 65535' >> /etc/security/limits.conf
```

内核参数优化：

```shell
vi /etc/sysctl.conf
sysctl -p
```

## 9. 登录提示与账号文件保护

登录前 / 登录后的提示信息：

```shell
cat /etc/issue     # 本地登录前的提示
vi /etc/motd       # 登录成功后的欢迎信息
```

锁定关键账号文件，防止被误改：

```shell
chattr +i /etc/passwd
lsattr /etc/passwd
```

需要修改时先 `chattr -i /etc/passwd` 解锁，改完再加回。
