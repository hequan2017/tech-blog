> **About this post**
>
> Notes on installing Go with yum on Linux (CentOS) and setting up the development environment: configuring GOPATH, enabling GO111MODULE, setting the GOPROXY China mirror, and using git clone mirrors to fill in common golang.org/x dependency packages such as sys/net/text/tools/crypto.
>
> **Technical notes**
>
> This content is clearly outdated: since Go 1.16, modules are enabled by default and `GO111MODULE=on` no longer needs to be set; goproxy.io still works, but `https://goproxy.cn,direct` is recommended; with Go Modules, there is no need to manually clone the golang.org/x repositories into GOPATH — `go mod tidy` fetches them automatically. The Go version in yum repositories is usually very old; downloading the official binaries from go.dev is recommended.

---

Install Go and configure environment variables:

```shell
yum install go -y

mkdir -p /data/go
echo export GO111MODULE=on >> /etc/profile
echo export GOPATH=/data/go >> /etc/profile
echo export GOPROXY=https://goproxy.io >> /etc/profile
source /etc/profile
```

Fill in the common golang.org/x packages (no longer needed in the Go Modules era):

```shell
git clone https://github.com/golang/sys.git $GOPATH/src/github.com/golang/sys
git clone https://github.com/golang/net.git $GOPATH/src/github.com/golang/net
git clone https://github.com/golang/text.git $GOPATH/src/github.com/golang/text
git clone https://github.com/golang/lint.git $GOPATH/src/github.com/golang/lint
git clone https://github.com/golang/tools.git $GOPATH/src/github.com/golang/tools
git clone https://github.com/golang/crypto.git $GOPATH/src/github.com/golang/crypto
git clone https://github.com/golang/sync.git $GOPATH/src/github.com/golang/sync
git clone https://github.com/golang/time.git $GOPATH/src/github.com/golang/time
git clone https://github.com/golang/image.git $GOPATH/src/github.com/golang/image

mkdir -p $GOPATH/src/golang.org
ln -s $GOPATH/src/github.com/golang/ $GOPATH/src/golang.org/x
```
