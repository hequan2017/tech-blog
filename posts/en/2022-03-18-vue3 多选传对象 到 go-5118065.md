> **About this post**
>
> In Vue3, el-select binds whole objects directly via value-key in multiple-select mode.
> This post shows the object structure of a selected product, the core front-end code for the
> multi-select dropdown, and how the Go back end clears and queries the associated Products with gorm.

> **Technical notes**
>
> The code comes from the gin-vue-admin scaffold (global.GVA_DB, the autocode package). element-ui
> only supports Vue 2, and official maintenance has shifted to Element Plus; the el-select usage in
> this post belongs to the latter: when binding objects in multiple mode, value-key specifies the
> unique key, and that usage is unchanged to this day. On the Go side, Preload /
> Association().Clear() remain the officially recommended approach in GORM v2; batch deletion can
> also be written as Delete(&Asset{}, ids) or Where("id IN ?", ids).Delete(&Asset{}).

## 1. The object

```json
{
  "ID": 541,
  "CreatedAt": "2022-03-18T14:30:51.125+08:00",
  "UpdatedAt": "2022-03-18T14:30:51.125+08:00",
  "name": "前端1",
  "other": ""
}
```

## 2. Code

```vue
<el-form-item label="产品线" prop="products">
  <el-select v-model="formData.products" placeholder="请选择下拉选择产品线" multiple clearable value-key="ID"
             :style="{width: '100%'}">
    <el-option v-for="(item, index) in productsOptions" :key="item.ID" :label="item.name"
               :value="item" :disabled="item.disabled"></el-option>
  </el-select>
</el-form-item>

const productsOptions = ref([])

const getProductsOptions = async() => {
  const table = await getProductList({ page: page.value, pageSize: 1000 })
  if (table.code === 0) {
    table.data.list.forEach(function(val, index, arr){
      productsOptions.value.push(val)
    });
  }
}
```

## 3. Back end

```go
_ = global.GVA_DB.Model(&asset).Association("Products").Clear()
// Multi-select deletion
_ = global.GVA_DB.Delete(&[]autocode.Asset{}, "id in ?", ids.Ids).Association("Products").Clear()
// Query
err = global.GVA_DB.Where("id = ?", id).Preload("Products").First(&asset).Error
```
