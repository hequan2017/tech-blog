> **About this post**
>
> Integrating the FreeIPA LDAP account system into a Django 2.1 project: use django-auth-ldap to configure LDAPSearch, user attribute mapping (uid → username, etc.), group syncing and group permissions, so the Django admin can log in directly with FreeIPA domain accounts. Companion piece to the previous post on FreeIPA server deployment.

> **Technical notes**
>
> Both Django 2.1 and django-auth-ldap 1.7.0 are outdated (Django 2.1 reached end of life in 2019), but this configuration approach remains largely compatible with Django 3.x/4.x + django-auth-ldap 4.x; just note that newer versions recommend using a list for `AUTHENTICATION_BACKENDS`. Compiling python-ldap requires the system openldap development libraries; on Windows you can use a prebuilt wheel.

### ldapconfig.py

```python
# https:///django-auth-ldap/django-auth-ldap

# FreeIPA domain name

import ldap
from django_auth_ldap.config import LDAPSearch, LDAPSearchUnion, GroupOfNamesType

AUTHENTICATION_BACKENDS = (
      'django_auth_ldap.backend.LDAPBackend',
      'django.contrib.auth.backends.ModelBackend',
)

AUTH_LDAP_SERVER_URI = 'ldap://192.168.100.23'
AUTH_LDAP_BIND_DN = 'uid=admin,cn=users,cn=accounts,dc=zhuxu,dc=co'
AUTH_LDAP_BIND_PASSWORD = '123456'

AUTH_LDAP_GROUP_TYPE = GroupOfNamesType(name_attr="cn")  # Type of the returned groups, used to determine user-group membership
AUTH_LDAP_USER_SEARCH = LDAPSearch("cn=accounts,dc=zhuxu,dc=co", ldap.SCOPE_SUBTREE, "(uid=%(user)s)")
AUTH_LDAP_GROUP_SEARCH = LDAPSearch("dc=zhuxu,dc=co", ldap.SCOPE_SUBTREE,"(objectClass=groupofnames)")

AUTH_LDAP_USER_ATTR_MAP = {
    "username": "uid",
    "password": "userPassword",
    "first_name": "givenName",
    "last_name": "sn",
    "email": "mail",
}

AUTH_LDAP_ALWAYS_UPDATE_USER = True  # Whether to sync LDAP changes
AUTH_LDAP_MIRROR_GROUPS = True       # Import the user's group info: on login, the user's domain group relations are synced over. On every login the group relations are deleted and re-synced from LDAP
AUTH_LDAP_FIND_GROUP_PERMS = True    # Compute group permissions from LDAP group membership.

AUTHENTICATION_BACKENDS = (
    'django_auth_ldap.backend.LDAPBackend',
    'django.contrib.auth.backends.ModelBackend',
)

AUTH_LDAP_CACHE_TIMEOUT = 3600
```
