> Python study notes, day 7, the advanced object-oriented part: the differences
> among the three kinds of class members — fields (regular/static), methods
> (regular/class methods/static methods), and properties (regular/private) — with

> **Technical notes**
>
> The classic class / new-style class distinction only exists in Python 2 (in
> Python 3 all classes are new-style classes, and inheriting from object can be
> omitted); moreover, the multiple-inheritance order in Python 3 has been unified
> to the C3 linearization algorithm and is no longer simply "new-style classes are
> breadth-first"; you can inspect the actual lookup order with `ClassName.__mro__`;
> the `__metaclass__` attribute syntax has been removed in Python 3, replaced by
> the `class Foo(metaclass=type)` form.

## 1. The three kinds of class members

Class

- Fields
  - Regular fields
  - Static fields
- Methods
  - Regular methods
  - Class methods
  - Static methods
- Properties
  - Regular properties
  - Private properties

### Fields

- Regular field: belongs to the object, an instance variable, stored in every instance; an instance object is allocated upon instantiation
- Static field: belongs to the class, a class variable, stored in the class in memory; it exists even without instantiation

### Methods

```python
class Animal:
    def __init__(self, name):
        self.name = name
    hobbie = 'meat'
    @classmethod  ## class method; cannot access instance variables
    def talk(self):
        print("{}  is   talking".format(self.hobbie))
    @staticmethod  ## static method; cannot access class or instance variables, rarely used, a toolbox of the class
    def walk():
        print(" is   talking")
    @property  ## property; what follows is no longer a method but a property, yet it can still access instance and class variables
    def habit(self):
        print("{}  habit  is  xxoo".format(self.name))


d = Animal("Hequan")
Animal.talk()
d.talk()
d.walk()
d.habit
```

Output:

```text
meat  is   talking
meat  is   talking
 is   talking
Hequan  habit  is  xxoo
```

## 2. Classic classes and new-style classes

- Classic class (Python 2, not inheriting from object): multiple-inheritance lookup is **depth-first**
- New-style class: **breadth-first**

## 3. Special members of a class

1. `__doc__`: prints the comment (docstring)
2. `__module__`: indicates which module the currently operated object belongs to
3. `__class__`: indicates the class of the currently operated object
4. `__init__`: constructor, triggered automatically when an object is created from the class
5. `__del__`: destructor, triggered automatically when the object is released from memory; destroyed collectively after execution
6. `__call__`: triggered when parentheses are appended after the object
7. `__dict__`: views all members in a class or object
8. `__new__` / `__metaclass__`: class creation; the call order is `__new__` --> `__call__` --> `__init__`

## 4. Reflection

Mapping or modifying the state, properties, and methods of a program at runtime through strings; there are 4 functions:

1. hasattr
2. getattr
3. setattr
4. delattr

Typical usage — dynamically calling an object's method based on a command-line argument:

```python
if __name__ == "__main__":
    server = WebServer('localhost', 3306)

    if hasattr(server, sys.argv[1]):
        func = getattr(server, sys.argv[1])  ## get the method name passed in from the command line, e.g. start
        func()
```
