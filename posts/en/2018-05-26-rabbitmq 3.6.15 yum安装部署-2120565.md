> **About this post**
>
> This post documents deploying RabbitMQ 3.6.15 on CentOS 7 via RPM packages:
> first install the EPEL repository and the Erlang runtime, then install the
> official el7 noarch package, and use systemctl to enable the service at boot
> and start it. Next, enable the rabbitmq_management web management plugin,
> create an admin account and grant it full configure, read, and write
> permissions on vhost /, and delete the default guest user. Finally, visit
> port 15672 in a browser to enter the management console.

> **Technical notes**
>
> The RabbitMQ 3.6 series is long out of maintenance; for production
> environments, current versions such as 3.12+/3.13+ are recommended (with a
> matching Erlang/OTP version).
> The www.rabbitmq.com/releases download directory has been migrated and taken
> offline; older packages must be obtained from the releases page of
> rabbitmq-server on GitHub.
> CentOS 7 reached EOL on 2024-06-30, so new environments are advised to use
> Rocky/Alma 9 with the official Package Cloud repository.

---

## 1. Install Erlang and RabbitMQ

```shell
yum install epel-release  -y

yum install erlang   -y

wget https://www.rabbitmq.com/releases/rabbitmq-server/v3.6.15/rabbitmq-server-3.6.15-1.el7.noarch.rpm

yum install rabbitmq-server-3.6.15-1.el7.noarch.rpm  -y
```

## 2. Start the Service and Enable the Management Plugin

```shell
systemctl enable rabbitmq-server.service
systemctl start rabbitmq-server.service

rabbitmq-plugins enable rabbitmq_management
```

## 3. Create an Administrator and Delete the Default Account

```shell
rabbitmqctl add_user admin admin
rabbitmqctl set_user_tags admin administrator
rabbitmqctl set_permissions -p / admin ".*" ".*" ".*"

rabbitmqctl delete_user guest
```

## 4. Access the Management Console

Open `http://<rabbitmq-server-IP>:15672/` in a browser and log in with the admin account created in the previous step.
