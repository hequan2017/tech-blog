> **About this post**
>
> This post demonstrates how to read and modify an ini configuration file with Go's ini library (gopkg.in/ini.v1):
> it prepares a grafana-style my.ini, loads it and reads keys from the default section and the [paths] and [server]
> sections, shows candidate-value restriction with In() and automatic type conversion with MustInt() / MustBool(),
> and finally uses SetValue to change app_mode to production and save the result as my.ini.local,
> with the run output attached.

> **Technical notes**
>
> The ini library gopkg.in/ini.v1 is still actively maintained; Go 1.16+ enables module mode by default,
> and go get must be run inside a module initialized with go mod init. The original post pasted the contents of
> both my.ini and main.go into a single code block; they have been split into two files with languages annotated.
> The path in the code uses Windows style (\src\test\tmp\); on Linux, remember to adjust the separators.

---

## 1. Installation

Official website: https://ini.unknwon.io/docs/intro/getting_started

```shell
go get gopkg.in/ini.v1
```

## 2. Configuration file my.ini

```ini
# possible values : production, development
app_mode = development

[paths]
# Path to where grafana can store temp files, sessions, and the sqlite3 db (if that is used)
data = /home/git/grafana

[server]
# Protocol (http or https)
protocol = http

# The http port  to use
http_port = 9999

# Redirect to correct domain if host header does not match domain
# Prevents DNS rebinding attacks
enforce_domain = true
```

## 3. Code main.go

```go
package main

import (
	"fmt"
	"os"

	"gopkg.in/ini.v1"
)

func main() {
	dir, _ := os.Getwd()
	fmt.Println(dir)
	path := dir + "\\src\\test\\tmp\\" // Windows-style path; adjust as needed, defaults to GOPATH
	path_name := path + "my.ini"
	cfg, err := ini.Load(path_name)
	if err != nil {
		fmt.Printf("Fail to read file: %v", err)
		os.Exit(1)
	}

	// Typical read operations; the default section can be referred to with an empty string
	fmt.Println("App Mode:", cfg.Section("").Key("app_mode").String())
	fmt.Println("Data Path:", cfg.Section("paths").Key("data").String())

	// We can restrict a value to a list of candidates
	fmt.Println("Server Protocol:",
		cfg.Section("server").Key("protocol").In("http", []string{"http", "https"}))
	// If the value read is not in the candidate list, it falls back to the provided default
	fmt.Println("Email Protocol:",
		cfg.Section("server").Key("protocol").In("smtp", []string{"imap", "smtp"}))

	// Try the automatic type conversion
	fmt.Printf("Port Number: (%[1]T) %[1]d\n", cfg.Section("server").Key("http_port").MustInt(9999))
	fmt.Printf("Enforce Domain: (%[1]T) %[1]v\n", cfg.Section("server").Key("enforce_domain").MustBool(false))

	// Almost done; modify a value and save
	cfg.Section("").Key("app_mode").SetValue("production")
	cfg.SaveTo(path + "my.ini.local")
}
```

## 4. Run output

```text
App Mode: development
Data Path: /home/git/grafana
Server Protocol: http
Email Protocol: smtp
Port Number: (int) 9999
Enforce Domain: (bool) true
```
