> **About this post**
>
> Documents the process of deploying a FreeIPA 4.7.0 server on Fedora 28: installing ipa-server, bind, and ipa-server-dns; running `ipa-server-install --setup-dns` to initialize the domain controller; then obtaining a Kerberos ticket with `kinit admin` and verifying it with `ipa user-find`; also covers the ports that need to be opened. FreeIPA can serve as a unified account source for systems such as JumpServer to integrate via LDAP.

> **Technical notes**
>
> This post uses Fedora 28 (long past EOL), and the author notes that deployment on CentOS 7.5 failed. Today, FreeIPA 4.10+ can be installed directly on Rocky Linux 9 / AlmaLinux 9 with `dnf install ipa-server`, and the deployment process is essentially the same; CentOS 7 reached EOL in June 2024 and is no longer recommended for new deployments. Note that the command `ipa -server-install` should read `ipa-server-install` (a typo by the original author, corrected in the body).

### About FreeIPA

```text
Key features
* An integrated security information management solution combining Linux (Fedora), 389 Directory Server, MIT Kerberos, NTP, DNS, the Dogtag certificate system, SSSD, and more.
* Built on well-known open source components and standard protocols
* Focus on ease of management and automated installation and configuration tasks
* Full multi-master replication for higher redundancy and scalability
* Extensible management interfaces (CLI, Web UI, XMLRPC and JSONRPC APIs) and a Python SDK
```

It is mainly intended for managing users across systems; other platforms can fetch account information over the LDAP protocol, for example JumpServer.

### Deployment

- System requirements: Fedora 28 (this deployment used it; deployment on CentOS 7.5 failed, so this system is strongly recommended. It is just like CentOS)
- FreeIPA: version 4.7
- IP: 192.168.100.23

This deployment uses the local machine as the DNS server (you could also use an external DNS or a self-hosted one; the commands below would then differ, so pay attention).

#### Install Packages

```shell
# Deploying on Fedora is simple.

hostnamectl set-hostname    ##Change this name as needed; do not include "-"

cat /etc/hosts
192.168.100.23   server

yum install -y ipa-server bind bind-dyndb-ldap ipa-server-dns

cat /etc/resolv.conf
search n
nameserver 127.0.0.1
```
