> **About this post**
>
> This is part 1 of the "Ops Infrastructure" series: deploying OpenVPN Access Server on CentOS 7.
> It is a hands-on walkthrough: environment notes, software downloads (network disk and official links), replacing the license file and restarting the service.
> Once deployed, it is accessed through the web page on port 943, providing remote access for the environments in the rest of the series.

> **Technical notes**
>
> CentOS 7 reached end of life (EOL) on June 30, 2024; migrating to Rocky Linux 9 / AlmaLinux 9 or openEuler is recommended.
> OpenVPN AS 2.9.2 and its companion rpm packages in this post are old releases no longer maintained by the vendor; to reproduce the setup, prefer the current official version and repositories.
> The web service on port 943 uses a self-signed certificate by default, so browser warnings about it being untrusted are expected.
> Replacing pyovpn-*.egg is a crack that bypasses official licensing and is only recommended for personal learning environments.

### 1.3 Deployment

```shell
yum install <software>  # install the rpm packages downloaded above
passwd openvpn

# visit https://192.168.1.2:943
mv pyovpn-2.0-py3.6.egg /usr/local/openvpn_as/lib/python/pyovpn-2.0-py3.6.egg

systemctl restart openvpnas.service
systemctl status openvpnas.service
```
