> **About this post**
>
> A complete record of manually building the LNMP stack: compiling and
> installing Nginx 1.9.15; deploying MySQL 5.5.32 from a binary package
> (mysql_install_db initialization, the mysqld service script, PATH setup,
> setting the root password, removing extra accounts); installing the PHP
> dependency libraries libiconv/libmcrypt/mhash/mcrypt from source; compiling
> PHP 5.3.27 with --enable-fpm and fixing the missing libmysqlclient.so.18
> link error; php-fpm.conf pool parameters; auto-start via /etc/rc.local; and
> adding the PHP fastcgi forwarding to nginx.conf, until all three ports
> (80/9000/3306) are listening and phpinfo verifies success.

> **Technical notes**
>
> CentOS 6 reached end of life (EOL) in November 2020; for production
> environments, migrating to Rocky Linux / AlmaLinux / Ubuntu LTS is
> recommended.
>
> MySQL 5.5 (EOL 2018-12) and PHP 5.3 (EOL 2014-08) are both past their
> security maintenance window and must no longer be used in production. In
> MySQL 5.7+, the `mysql_install_db` initialization script has been replaced
> by `mysqld --initialize`.

## 1. Compiling and Installing Nginx 1.9.15

```shell
yum -y install pcre* openssl openssl-devel
useradd -s /sbin/nologin -M nginx
wget http://nginx.org/download/nginx-1.9.15.tar.gz
tar xf nginx-1.9.15.tar.gz
cd nginx-1.9.15
./configure --user=nginx --group=nginx \
    --prefix=/application/nginx1.9.15 \
    --with-http_stub_status_module \
    --with-http_ssl_module
make && make install
ln -s /application/nginx1.9.15/ /application/nginx
/application/nginx/sbin/nginx
```

## 2. Installing MySQL 5.5.32 from a Binary Package

mysql-5.5.32-linux2.6-x86_64.tar.gz is a precompiled binary package:

```shell
useradd mysql -s /sbin/nologin -M
tar xf mysql-5.5.32-linux2.6-x86_64.tar.gz
mv mysql-5.5.32-linux2.6-x86_64 /application/mysql
cd /application/mysql/
chown -R mysql.mysql /application/mysql/data/
./scripts/mysql_install_db --user=mysql \
    --basedir=/application/mysql/ \
    --datadir=/application/mysql/data/
cp support-files/mysql.server /etc/init.d/mysqld
```

Modify the paths in the startup script:

```shell
vim /etc/init.d/mysqld
```

```ini
basedir=/application/mysql
datadir=/application/mysql/data
```

```shell
cp support-files/my-small.cnf /etc/my.cnf
/etc/init.d/mysqld start
ln -s /application/mysql/bin/mysql /usr/local/bin/
mysql
./mysqladmin -u root password "123456"    # Run from the bin directory
mysql -uroot -p123456
```

Add MySQL to the PATH:

```shell
vim /etc/profile
PATH=/application/mysql/bin:$PATH
. /etc/profile
```

If startup fails, check the error log:

```shell
cat bogon.err    # View errors (located under /application/mysql/data/)
```

## 4. Installing PHP Dependency Libraries

```shell
yum -y install zlib libxml libjpeg freetype libpng gd curl libcurl libiconv \
    zlib-devel libxml2-devel libjpeg-devel freetype-devel libpng-devel \
    gd-devel curl-devel libxslt* \
    openldap openldap-devel nss_ldap openldap-clients openldap-servers
```

libiconv:

```shell
tar zxf libiconv-1.14.tar.gz
cd libiconv-1.14
./configure --prefix=/usr/local/libiconv
make
make install
cd ../
/sbin/ldconfig
```

libmcrypt (including ltdl):

```shell
tar zxf libmcrypt-2.5.8.tar.gz
cd libmcrypt-2.5.8
./configure
make
make install
/sbin/ldconfig
cd libltdl/
./configure --enable-ltdl-install
make
make install
cd ../../
```

mhash:

```shell
tar -zxvf mhash-0.9.9.9.tar.gz
cd mhash-0.9.9.9
./configure
make
make install
```

Installing mcrypt:

```shell
tar -zxvf mcrypt-2.6.8.tar.gz
cd mcrypt-2.6.8
/sbin/ldconfig
./configure LD_LIBRARY_PATH=/usr/local/lib
make
make install
```

## 5. Compiling and Installing PHP 5.3.27

```shell
tar xf php-5.3.27.tar.gz
cd php-5.3.27
./configure \
--prefix=/application/php5.3.27 \
--with-mysql=/application/mysql \
--with-xmlrpc \
--with-openssl \
--with-zlib \
--with-freetype-dir \
--with-gd \
--with-jpeg-dir \
--with-mhash \
--enable-pcntl \
--with-png-dir \
--with-iconv=/usr/local/libiconv \
--enable-xml \
--disable-rpath \
--enable-safe-mode \
--enable-bcmath \
--enable-shmop \
--enable-inline-optimization \
--enable-fpm \
--with-fpm-user=nginx \
--with-fpm-group=nginx \
--enable-short-tags \
--enable-sockets \
--enable-zend-multibyte \
--enable-soap \
--enable-mbstring \
--enable-static \
--enable-gd-native-ttf \
--with-curl \
--with-curlwrappers \
--with-xsl \
--enable-ftp \
--enable-zip \
--with-libxml-dir=/usr
```

The configure step finishes with `Thank you for using PHP.`, but the make
stage reports an error:

```text
/hequan/php-5.3.27/sapi/cli/php: error while loading shared libraries:
libmysqlclient.so.18: cannot open shared object file: No such file or directory
make: *** [ext/phar/phar.php] 错误 127
```

libmysqlclient.so.18 is missing; create a symlink and retry:

```shell
ln -s /application/mysql/lib/libmysqlclient.so.18 /usr/lib64/
mkdir -p ext/phar/phar.phar
make && make install
ln -s /application/php5.3.27/ /application/php
cp php.ini-production /application/php/lib/php.ini
```

## 6. php-fpm Configuration

Copy php-fpm.conf from the default template and edit it (you can use
`vimdiff php-fpm.conf php-fpm.conf.default` to compare the differences):

```shell
cp /application/php/etc/php-fpm.conf.default /application/php/etc/php-fpm.conf
vim /application/php/etc/php-fpm.conf
```

```ini
pid = /app/logs/php-fpm.pid
error_log = /app/logs/php-fpm.log
log_level = error
rlimit_files = 32768
listen.owner = nginx
listen.group = nginx
pm.max_children = 1024
pm.start_servers = 16
pm.min_spare_servers = 5
pm.max_spare_servers = 20
pm.process_idle_timeout = 15s;
pm.max_requests = 2048
slowlog = /app/logs/$pool.log.slow
request_slowlog_timeout = 10
```

Start and verify:

```shell
mkdir -p /app/logs
/application/php/sbin/php-fpm -t
/application/php/sbin/php-fpm
ps -ef | grep php-fpm
netstat -lntup | grep php-fpm
tcp        0      0 127.0.0.1:9000   0.0.0.0:*      LISTEN      53284/php-fpm
```

## 7. Auto-Start on Boot and Nginx Integration

```shell
vim /etc/rc.local
```

```shell
/etc/init.d/mysqld start
/application/php/sbin/php-fpm
/application/nginx/sbin/nginx
```

Confirm the three service ports:

```shell
netstat -lntup | egrep "nginx|php-fpm|mysql"
tcp        0      0 0.0.0.0:80       0.0.0.0:*      LISTEN      1847/nginx
tcp        0      0 127.0.0.1:9000   0.0.0.0:*      LISTEN      1829/php-fpm
tcp        0      0 0.0.0.0:3306     0.0.0.0:*      LISTEN      1797/mysqld
```

Modify `nginx.conf`: add index.php to the homepage index list, and add a new
fastcgi forwarding block for PHP:

```nginx
index  index.php  index.html index.htm;

location ~ .*\.(php|php5)?$ {
    fastcgi_pass   127.0.0.1:9000;
    fastcgi_index  index.php;
    include        fastcgi.conf;
}
```

```shell
/application/nginx/sbin/nginx -s reload
```
