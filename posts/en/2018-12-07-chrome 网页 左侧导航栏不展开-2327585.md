> **About this post**
>
> This post troubleshoots a frontend compatibility issue: a Bootstrap 3-style multi-level
> sidebar navigation expands normally in 360 Browser and Firefox, but Chrome alone shows
> no response on click. Inspecting with F12 revealed that the collapse class on the
> third-level menu ul was never switched to in; the workaround was to manually
> addClass("active") on each level of li and addClass("in") on its child ul inside
> window.onload, bypassing the problem.

> **Technical notes**
>
> The root cause is that Bootstrap 3's collapse only switches collapse to in when the
> jQuery plugin is properly initialized; in Chrome the script loading order differs, so
> the switch never fires. Bootstrap 5 has removed the jQuery dependency, and collapse is
> now driven by the data-bs-toggle attribute. The manual addClass approach in this post
> only applies to maintaining legacy Bootstrap 3.x projects.

---

## 1. Symptom

The HTML structure of the multi-level navigation (Bootstrap 3 style, with one / second / third li nested at three levels, and the submenu ul carrying the collapse class):

```html
<li class="one">
    <a rel="nofollow" href="#"><i class="fa fa-sitemap"></i>
        <span class="nav-label">Menu </span><span class="fa arrow"></span></a>
    <ul class="nav nav-second-level collapse">
        <li class="second">
            <a rel="nofollow" href="#" id="damian">Second-level menu 1 <span class="fa arrow"></span></a>
            <ul class="nav nav-third-level">
                <li class="third">
                    <a rel="nofollow" href="#">Third-level menu 1</a>
                </li>
                <li><a rel="nofollow" href="#">Third-level menu 2</a></li>
                <li><a rel="nofollow" href="#">Third-level menu 3</a></li>
            </ul>
        </li>
        <li><a rel="nofollow" href="#">Second-level menu 2</a></li>
        <li><a rel="nofollow" href="#">Second-level menu 3</a></li>
        <li><a rel="nofollow" href="#">Second-level menu 4</a></li>
    </ul>
</li>
```

The initial script only added active to each level of li:

```javascript
window.onload = function () {
    $(".one").addClass("active");
    $(".second").addClass("active");
    $(".third").addClass("active");
};
```

## 2. Testing and Troubleshooting

It expanded normally in 360 Browser and Firefox, but would not expand in Chrome.

Viewing the source with F12, the third-level menu's ul was:

```html
<ul class="nav nav-third-level collapse ">
</ul>
```

I found that collapse had not become in; the more specific cause was not identified at the time.

## 3. Solution

Manually add in: while setting each level of li to active, also add the in class to its child ul.

```javascript
window.onload = function () {
    $(".one").addClass("active");
    $(".one").children('ul').addClass('in');
    $(".second").addClass("active");
    $(".second").children('ul').addClass('in');
    $(".third").addClass("active");
};
```
