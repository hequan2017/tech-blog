> **About this post**
>
> On servers with multiple network ports, NIC names such as eth0 and eth1 often do not
> match the physical order of the ports on the chassis.
> This post provides a Shell script: it extracts the MAC address of each PCIe NIC from dmesg,
> then looks up the interface name by MAC address with ifconfig, and prints the mapping
> between the physical port order and the NIC names.

> **Technical notes**
>
> `ethtool -p <interface-name>` makes the link LED of the corresponding physical port blink,
> which is a quick way to verify the mapping;
> the `/sys/class/net/<interface-name>/device` symlink points to the PCI bus address, and combined with `lspci`
> you can also confirm the order from the bus topology. The dmesg output format varies with the kernel version, so the
> column positions need to be adjusted according to the actual output; if net-tools is not installed,
> you can use `ip link` to view MAC addresses.

---

```shell
#!/bin/bash

mac_addresses=($(dmesg | grep "eth" | grep "PCIe" | awk -F' ' '{print $8}'))
count=0
for mac in "${mac_addresses[@]}"; do
  ((count++))
  interface=$(ifconfig | grep -B 4 "$mac" | grep -oE "^[^ ]+" | head -n 1 | awk -F":" '{print $1}')
  echo "第$count个口   MAC地址: $mac   对应的物理端口: $interface"
done
```
