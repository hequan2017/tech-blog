> **About this post**
>
> Operation notes for switching the Tomcat 9 connector from the default NIO to APR (Apache Portable Runtime) mode: first compile apr / apr-iconv / apr-util, then compile the tomcat-native bundled with Tomcat, and finally change the Connector protocol in server.xml to `org.apache.coyote.http11.Http11AprProtocol`, with configuration examples for thread counts, compression, and other parameters.

> **Technical notes**
>
> APR was the "top pick for high performance" before Tomcat 8.5, but since Tomcat 8.5, NIO/NIO2 has been good enough — the project even removed BIO, and APR only needs to be compiled separately in a few rare scenarios. The wget mirror URLs in this post (Apache mirror sites) no longer work; use https://archive.apache.org or the official dlcdn instead. Parameters such as `maxThreads/acceptCount` still apply in Tomcat 9/10; note that Tomcat 10 moved the Servlet packages from `javax.servlet` to `jakarta.servlet`.

---

Tomcat supports three ways of processing incoming requests: BIO, NIO, and APR.

```shell
1. BIO creates a thread for every request, so the thread overhead is high; it is no longer suitable for high-concurrency scenarios and delivers the lowest performance.
2. NIO is a buffer-based Java API that provides non-blocking I/O operations, with better concurrency performance than traditional BIO.
3. APR (Apache Portable Run-time libraries), simply put, solves asynchronous I/O at the operating system level, greatly improving the server's processing and response performance. It is also the preferred mode for running high-concurrency applications on Tomcat.
```

Required software

```shell
* apr
* apr-iconv
* apr-util
* tomcat-native
```

---

### Install the software

```shell
yum install -y apr-devel openssl-devel gcc make expat-devel libtool
```

```shell
cd /usr/local/src
wget  https://archive.apache.org/dist/apr/apr-1.6.3.tar.gz

tar xf apr-1.6.3.tar.gz
cd apr-1.6.3/
./configure --prefix=/usr/local/apr
make && make install

cd /usr/local/src
wget https://archive.apache.org/dist/apr/apr-iconv-1.2.2.tar.gz
tar xf apr-iconv-1.2.2.tar.gz
cd apr-iconv-1.2.2/
./configure   --with-apr=/usr/local/apr  --prefix=/usr/local/apr-iconv
make && make install

cd /usr/local/src
wget  https://archive.apache.org/dist/apr/apr-util-1.6.1.tar.gz
tar xf apr-util-1.6.1.tar.gz
cd apr-util-1.6.1/
./configure --prefix=/usr/local/apr-util  --with-apr=/usr/local/apr   --with-apr-iconv=/usr/local/apr-iconv/bin/apriconv
make && make install

cd /usr/local/tomcat/bin/
tar xf tomcat-native.tar.gz
cd  /usr/local/tomcat/bin/tomcat-native-1.2.16-src/native

./configure --with-apr=/usr/local/apr  --with-java-home=/usr/local/jdk8.0
make && make install

echo 'export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/usr/local/apr/lib
export LD_RUN_PATH=$LD_RUN_PATH:/usr/local/apr/lib' >> /etc/profile

source /etc/profile
```

### Modify the configuration

```html
vim /usr/local/tomcat/conf/server.xml

<Connector      port="80"        protocol="org.apache.coyote.http11.Http11AprProtocol"
                maxThreads="1000"
                minSpareThreads="100"
                acceptCount="900"
                disableUploadTimeout="true"
                connectionTimeout="20000"
                URIEncoding="UTF-8"
                enableLookups="false"
                redirectPort="8443"
                compression="on"
                compressionMinSize="1024"
               />


<!-- Define an AJP 1.3 Connector on port 8009 -->  ## Comment out the line below if you are not using Apache
<!-- <Connector port="8009" protocol="AJP/1.3" redirectPort="8443" />  -->
```
