> paths under the installation directory is for; a line-by-line annotated

## 1. Module Classification and Directory Structure

In nginx.conf, `root html;` specifies the website directory. Module
classification:

- core modules: Main, Events
- Standard HTTP modules: Core, Access, FastCGI, Gzip, Log, Proxy, Rewrite,
  Upstream

Module documentation is available in the official docs:
http://nginx.org/en/docs/

Installation directory layout:

```text
.
├── client_body_temp
├── conf
│   ├── fastcgi.conf            # dynamic config
│   ├── fastcgi.conf.default
│   ├── fastcgi_params          # parameters
│   ├── fastcgi_params.default
│   ├── koi-utf
│   ├── koi-win
│   ├── mime.types
│   ├── mime.types.default
│   ├── nginx.conf              # static config file
│   ├── nginx.conf.default
│   ├── scgi_params
│   ├── scgi_params.default
│   ├── uwsgi_params
│   ├── uwsgi_params.default
│   └── win-utf
├── fastcgi_temp
├── html
│   ├── 50x.html                # error page
│   └── index.html
├── logs
│   ├── access.log
│   ├── error.log
│   └── nginx.pid
├── proxy_temp
├── sbin
│   └── nginx
├── scgi_temp
└── uwsgi_temp
```

## 2. Understanding the Default Main Configuration File

```shell
egrep -v "#|^$" nginx.conf | cat -n
```

```nginx
 1  worker_processes  1;             # roughly equal to the CPU core count for efficiency
 2  events {
 3      worker_connections  1024;    # max connections each worker can accept
 4  }
 5  http {
 6      include       mime.types;
 7      default_type  application/octet-stream;
 8      sendfile        on;
 9      keepalive_timeout  65;
10      server {
11          listen       80;
12          server_name  localhost;              # domain name
13          location / {
14              root   html;
15              index  index.html index.htm;
16          }
17          error_page   500 502 503 504   /50x.html;   # custom error pages
18          location = /50x.html {
19              root   html;
20          }
21      }
22  }
```

## 3. Virtual Host Configuration

Start configuring multiple sites:

```nginx
server {
    listen       80;
    server_name  ;          # fill in your own domain
    root   html/www;
    index  index.html index.htm;
}

server {
    listen       80;
    server_name  ;          # fill in your own domain
    root   html/blog;
    index  index.html index.htm;
}
```

Reload after editing:

```shell
/application/nginx/sbin/nginx -s reload
```

## 4. 301 Redirect

```nginx
server {
    listen       80;
    server_name  ;          # fill in your own domain
    rewrite ^/(.*)  http:///$1   permanent;   # fill in the target domain as needed
}
```

## 5. Handling Malicious IP Binding

Requests that match no server_name are rejected outright, preventing others
from maliciously pointing their domains at this machine:

```nginx
server {
    listen       80;
    location / {
        deny all;
    }
}
```

## 6. Log Rotation

```shell
cd /application/nginx/logs && \
/bin/mv www_access.log www_access_$(date +%F -d -1day).log
/application/nginx/sbin/nginx -s reload
```

Write it into crontab so the rotation script runs daily at midnight:

```shell
crontab -e
00 00 * * * /bin/sh /application/nginx/logs/xx.sh >/dev/null 2>&1
```

awstats can be used for log-related analysis.
