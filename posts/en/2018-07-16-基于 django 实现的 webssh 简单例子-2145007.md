> **About this post**
>
> Build a WebSSH terminal in the browser with Django + Channels + paramiko: the frontend connects to the backend over WebSocket, and the backend uses paramiko to log into a remote host and push the output of the SSH channel in real time to the xterm terminal on the web page. The article provides complete minimal examples of the consumers, routing, and frontend page, and points out the problem that Chinese usernames raise errors when a channel group is created per username.

> **Technical notes**
>
> This post is based on channels 2.0.2 + channels-redis 2.1.0; the Channels API changed considerably after 3.x (e.g., AsyncWebsocketConsumer became the mainstream and routing was written differently). xterm.min.js reflects the xterm.js 2.x/3.x era usage; today's xterm.js 5.x needs to be used together with plugins such as AttachAddon. The paramiko usage remains largely compatible to this day.

### Notes

> Create a new django project; in this post it is chain.

> User login is required. The channel is created using the username from the channels layer.

> The following is only a simple example; in a real application you can adapt it to your own platform.

> After opening the home page, you need to enter 1; the backend then logs into the host and returns the login result.

> A normal project could POST the host and the login account, perform permission checks, then read the account password from the backend and log in.

---

> Special note: the test user should be set to English; the example in this post cannot be Chinese. Because the username is used as the group name, a Chinese group name raises an error, which causes this problem. If the actual name is Chinese, it is recommended to replace `group` with something else.  async_to_sync(self.channel_layer.group_add)(self.scope['user'].username, self.channel_name)

#### consumers.py

```python
from asgiref.sync import async_to_sync
from channels.generic.websocket import WebsocketConsumer

import paramiko
import threading
import time

from channels.layers import get_channel_layer
channel_layer = get_channel_layer()

class MyThread(threading.Thread):
    def __init__(self, id, chan):
        threading.Thread.__init__(self)
        self.chan = chan

    def run(self):
        while not self.chan.chan.exit_status_ready():
            time.sleep(0.1)
            try:
                data = self.chan.chan.recv(1024)
                async_to_sync(self.chan.channel_layer.group_send)(
                    self.chan.scope['user'].username,
                    {
                        "type": "user.message",
                        "text": bytes.decode(data)
                    },
                )
            except Exception as ex:
                print(str(ex))
        self.chan.sshclient.close()
        return False

class EchoConsumer(WebsocketConsumer):

    def connect(self):
        # Create a channels group named after the username, and write it to redis via channel_layer
        async_to_sync(self.channel_layer.group_add)(self.scope['user'].username, self.channel_name)
        # Handed to the receive method for processing

        path = self.scope['path']

        self.accept()

    def receive(self, text_data):

        if text_data == '1':
            self.sshclient = paramiko.SSHClient()
            self.sshclient.load_system_host_keys()
            self.sshclient.set_missing_host_key_policy(paramiko.AutoAddPolicy())
            self.sshclient.connect('47.104.140.38', 22, 'root', '123456')
            self.chan = self.sshclient.invoke_shell(term='xterm')
            self.chan.settimeout(0)
            t1 = MyThread(999, self)
            t1.setDaemon(True)
            t1.start()
        else:
            try:
                self.chan.send(text_data)
            except Exception as ex:
                print(str(ex))

    def user_message(self, event):
        # Consume
        self.send(text_data=event["text"])

    def disconnect(self, close_code):
        async_to_sync(self.channel_layer.group_discard)(self.scope['user'].username, self.channel_name)
```

#### routing.py

```python

from channels.routing import URLRouter, ProtocolTypeRouter
from django.urls import path

from .consumers import EchoConsumer

application = ProtocolTypeRouter({
    "websocket": AuthMiddlewareStack(
        URLRouter([
            path(r"ws/", EchoConsumer),
            # path(r"stats/", StatsConsumer),
        ])
    )
})
```
