> **About this post**
>
> This is the first post of the PHP cache acceleration optimization series (Part 1): it first presents the lab environments for LAMP (Apache 2.2.27 + MySQL 5.1.72 + PHP 5.3.27) and LNMP (nginx 1.6.3 + MySQL 5.5.32 + PHP 5.5.32), along with the commands for viewing each component's build parameters (apachectl -V, config.nice, mysqlbug, php -i, nginx -V); it then demonstrates using phpize to compile and install two PHP opcode cache acceleration modules, eaccelerator and xcache (choose one of the two), and explains that the no-debug-zts and no-debug-non-zts extension directories correspond to Apache and nginx respectively.

## 1. Environment Overview and Version Check

PHP web engine cache acceleration optimization — preparing the base web environment.

### LAMP

Environment: CentOS 6.5_64 + Apache/2.2.27 (Unix) + MySQL 5.1.72 + PHP 5.3.27.

```shell
/application/apache/bin/apachectl -V
```

```text
Server version: Apache/2.2.27 (Unix)
```

```shell
cat /application/apache/build/config.nice       # View Apache build parameters
grep CONFIGURE /application/mysql/bin/mysqlbug  # View MySQL build parameters
/application/php/bin/php -i | grep configure    # View PHP build parameters
```

### LNMP

Environment: CentOS 6.5_64 + nginx/1.6.3 + MySQL 5.5.32 + PHP 5.5.32.

```shell
# /application/nginx/sbin/nginx -V
```

```text
nginx version: nginx/1.6.3
```

## 2. Install the eaccelerator Cache Acceleration Module

eaccelerator-0.9.6, cache optimization and acceleration:

```shell
tar jxf eaccelerator-0.9.6.tar.bz2
cd eaccelerator-0.9.6

/application/php/bin/phpize     # Build the PHP loadable module

./configure --enable-eaccelerator=shared \
    --with-php-config=/application/php/bin/php-config

make && make install

ls /application/php5.3.27/lib/php/extensions/no-debug-zts-20090626/
```

## 3. Install the xcache Cache Acceleration Module

xcache-1.3.2, a PHP opcode cacher with better results; choose one of it and eaccelerator:

```shell
tar jxf xcache-1.3.2.tar.bz2
cd xcache-1.3.2

/application/php/bin/phpize

./configure --enable-xcache \
    --with-php-config=/application/php/bin/php-config

make && make install

ls /application/php5.3.27/lib/php/extensions/no-debug-non-zts-20090626/
```

## 4. Difference Between the Two Extension Directories

```shell
ls /application/php5.3.27/lib/php/extensions/no-debug-zts-20090626/         # ===== apache
ls /application/php5.3.27/lib/php/extensions/no-debug-non-zts-20090626/     # ===== nginx
```
