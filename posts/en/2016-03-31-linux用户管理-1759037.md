> **About this post**
>
> This post summarizes Linux user and group management: UID categories
> (0 for root, 1-499 virtual (system) users, 500-65535 regular users),
> /etc/passwd and /etc/shadow; useradd defaults come from
> /etc/login.defs and /etc/default/useradd; common options of
> useradd/passwd/chage/usermod (account expiry, lock/unlock, password
> aging, --stdin for non-interactive password changes); plus a shell
> script that creates 100 users in batch; and finally a detailed look
> at the sudo/visudo authorization format and the four alias types
> User/Host/Runas/Cmnd.

> **Technical notes**
>
> UIDs 1-499 for system users are the CentOS 6 convention; CentOS 7+
> changes the system user range to 1-999; /etc/sysconfig/i18n has been
> replaced by /etc/locale.conf on CentOS 7+; `passwd --stdin` is a
> RHEL-specific option; sudoers should always be edited via visudo and
> validated with `visudo -c`.

## 1. User Categories and Key Files

- 0: root
- 1-499: virtual users (system users)
- 500-65535: regular users

```text
root:x:0:0:root:/root:/bin/bash
```

Related files: /etc/passwd, /etc/shadow.

Common commands: useradd, userdel, passwd, chage, usermod, id, su, sudo,
visudo, pwck, finger.

Home directory template: the hidden files in /etc/skel are copied to the
user's home directory:

```shell
# ll /etc/skel/ -al
# cp -a .bash* /home/xx/
# chown xx:xx -R /home/xx
# rm -f .*
```

If the terminal shows garbled text, adjust the character set:

```shell
# vi /etc/sysconfig/i18n
#LANG="zh_CN.UTF-8"
LANG="zh_CN.GB2312"
# . /etc/sysconfig/i18n
# source /etc/sysconfig/i18n
```

## 2. useradd Default Configuration

/etc/login.defs (password-related settings):

```shell
# less /etc/login.defs | grep -vE "^$|^#"
MAIL_DIR        /var/spool/mail
PASS_MAX_DAYS   99999
PASS_MIN_DAYS   0
PASS_MIN_LEN    5
PASS_WARN_AGE   7
UID_MIN                   500
UID_MAX                 60000
GID_MIN                   500
GID_MAX                 60000
CREATE_HOME     yes
UMASK           077
USERGROUPS_ENAB yes
ENCRYPT_METHOD SHA512
```

/etc/default/useradd:

```ini
# useradd defaults file
GROUP=100
HOME=/home
INACTIVE=-1
EXPIRE=
SHELL=/bin/bash
SKEL=/etc/skel
CREATE_MAIL_SPOOL=yes
```

## 3. Common useradd Options

- -e: set the account expiry date; omitting it means the account never
  expires
- -g: primary group; -G: multiple groups
- -m: create the home directory; -M: do not create the home directory
- -u: uid; -s: shell

`useradd -D` directly modifies the options, changing the default user
configuration (/etc/default/useradd):

```shell
# useradd -u 808 -g sa -M -s /sbin/nologin old
# id
# useradd -D -s /bin/sh
SHELL=/bin/sh
# useradd -D -e "2017/04/01"
EXPIRE=2017/04/01
```

Message shown when an account has expired:

```text
Your account has expired; please contact your system administrator
```

Adjust the system time to verify the expiry:

```shell
# date -s "2014/08/08 15:15"
2014年 08月 08日 星期五 15:15:00 CST
```

Check the expiry with chage:

```shell
# chage -l xxx
# chage xxx -l
```

userdel -r deletes the user's home directory and all files in it:

```shell
# userdel -r heq3      # delete the home directory
```

Available shells:

```shell
# cat /etc/shells
/bin/sh
/bin/bash
/sbin/nologin
/bin/dash
/bin/tcsh
/bin/csh
```

Group management:

```shell
# groupadd -g gid
# tail -1 /etc/group
k1:x:1000:
```

## 4. Password Management with passwd

What allows passwd to change passwords for regular users is its setuid
bit:

```shell
# ls -l `which passwd`
-rwsr-xr-x. 1 root root 30768 2月 22 2012 /usr/bin/passwd
```

Non-interactive password change with --stdin:

```shell
# echo "123123" | passwd --stdin root
```

Locking and unlocking:

```shell
# passwd -l hequan
锁定用户 hequan 的密码 。
passwd: 操作成功
$ passwd hequan
passwd： 只有根用户才能指定用户名称。
# passwd -u hequan
解锁用户 hequan 的密码 。
```

Password aging options:

```shell
# passwd -n 7 -x 60 -w 10 -i 30 hequan
```

That is: the password cannot be changed for 7 days, must be changed
after 60 days, the user is warned 10 days before expiry, and login is
disabled 30 days after expiry (adjusting the password aging data for
user hequan).

echo -e handles special characters; \t inserts a tab.

## 5. Creating 100 Users in Batch

```bash
#!/bin/sh
userchars="heq"
for num in `seq 100`
do
    useradd $userchars$num;
    passwd=`date | md5sum | cut -c3-20`
    echo "$passwd" | passwd --stdin $userchars$num
    echo -e "user:$userchars$num\tpasswd:$passwd" >>/tmp/user.log
done
```

```shell
# which passwd
/usr/bin/passwd
```

## 6. usermod and User Queries

usermod: -l changes the login name (everything else unchanged), -c
comment, -s /bin/bash, -d home directory, -e expiry date, -L lock,
-U unlock.

User and login queries (dynamic passwords): id, w, who, last, lastlog,
groups.

su runs a command as the specified user:

```shell
# su - hequan -c ls -l /home/hequan/
xx
```

Start the script as this user at boot:

```shell
# vi /etc/rc.local
su - hequan -c /bin/sh /server/scripts/
```

## 7. sudo and visudo

Authorization format of /etc/sudoers:

```ini
root    ALL=(ALL)       ALL
hequan  ALL=(ALL)  NOPASSWD: /usr/sbin/useradd,/bin/rm
```

Usage and verification:

```shell
# su - hequan
$ sudo useradd
[sudo] password for hequan:
# ll /var/db/sudo/hequan/
-rw------- 1 root hequan 48 3月  27 19:30 0
# man sudoers
$ sudo -l
用户 hequan 可以在该主机上运行以下命令：
(ALL) /usr/sbin/useradd, (ALL) /bin/rm
# visudo -c
/etc/sudoers：解析正确
# visudo
%groupname    ALL=(ALL)         ALL      # \ line continuation
```

The sudoers file contains two kinds of content: alias definitions and
authorization rules.

```ini
# Host_Alias     FILESERVERS = fs1, fs2
# Host_Alias     MAILSERVERS = smtp, smtp2
```

In the authorization line `root (User_Alias)  ALL=(ALL)  ALL`, the
first ALL is the Host_Alias, the second the Runas_Alias, and the third
the Cmnd_Alias.

The four alias types:

- User_Alias: users
- Host_Alias: define host aliases
- Runas_Alias: user roles to switch to
- Cmnd_Alias: command aliases

Full example:

```ini
User_Alias    ADMINS = hequan
Host_Alias    SERS = f1,f2,localhost
Runas_Alias   OP = root
Cmnd_Alias    COMMMAND = /usr/sbin/useradd,/usr/sbin/userdel

ADMINS  SERS = (OP)  COMMMAND
```
