> **About this post**
>
> This post covers Apache's MPM concurrency model and hotlink protection configuration: use apachectl -l to determine whether the current MPM is worker or prefork (specified at compile time with --with-mpm; the default is prefork). It explains the meaning of the prefork parameters in httpd-mpm.conf (StartServers, MaxClients, MaxRequestsPerChild, etc.) and the worker parameters (ThreadsPerChild, MaxSpareThreads, etc.), how MaxClients is calculated and its divisibility relationship, plus the timeout/KeepAlive settings in httpd-default.conf and commands for viewing the number of concurrent connections. Finally, it presents two ways to implement image hotlink protection: Apache mod_rewrite and nginx valid_referers.

> **Technical notes**
>
> Nginx configuration differs slightly between major versions; for the current stable releases (1.24+/1.26+), defer to the official documentation. Additional note: Apache 2.2 ceased maintenance in early 2017. Starting with 2.4, MaxClients was renamed MaxRequestWorkers and MaxRequestsPerChild was renamed MaxConnectionsPerChild; the event MPM is recommended for new deployments. The nginx valid_referers hotlink protection syntax remains in use to this day.

## 1. View/Specify the Apache MPM (worker/prefork)

```shell
/application/apache/bin/apachectl -l | sed -n '/worker\|prefork/p'
```

```text
worker.c
Server MPM:     Worker
```

```shell
./configure --with-mpm=worker    # specified at compile time; default is prefork
```

## 2. prefork (default)

It uses multiple child processes, each of which has only one thread. It is efficient, stable, and safe, but consumes more resources than worker.

```shell
vim /application/apache/conf/extra/httpd-mpm.conf
```

```apache
<IfModule mpm_prefork_module>
    StartServers         10       # number of server processes started at startup
    MinSpareServers      10       # minimum number of idle servers
    MaxSpareServers      15       # maximum number of idle servers
    ServerLimit       2000
    MaxClients         1000       # maximum processes, concurrency
    MaxRequestsPerChild 5000      # max requests a child process serves; 0 = unlimited
</IfModule>
```

```shell
ps -ef | grep http | grep -v grep | wc -l    # count the number of processes
```

```text
6
```

## 3. worker (a combination of threads and processes)

```shell
vim /application/apache/conf/extra/httpd-mpm.conf
```

```apache
<IfModule mpm_worker_module>
    StartServers          2       # number of processes started at startup
    MaxClients         2000       # number of concurrent client connections
    ServerLimit          25       # total number of processes
    MinSpareThreads      50
    MaxSpareThreads     200
    ThreadLimit         200
    ThreadsPerChild     100       # number of resident worker threads per server process
    MaxRequestsPerChild  0        # max requests a single child process serves in total; default 0 = unlimited
</IfModule>
```

Constraints:

```text
MaxClients <= ServerLimit * ThreadsPerChild
MaxClients % ThreadsPerChild = 0   # must be evenly divisible
```

## 6. Apache Web Service Hotlink Protection

```apache
<Directory "/usr/local/apache2/htdocs/cfan/pic/">
    RewriteEngine on
    RewriteCond %{HTTP_REFERER} !^http://your-domain/.*$ [NC]
    RewriteRule .*\.(gif|jpg)$  http://replacement-icon [R,NC]
</Directory>
```

## 7. Nginx Hotlink Protection Configuration

```nginx
location ~* \.(gif|jpg|png|swf|flv|bmp)$ {
    valid_referers none blocked *.hequan.com;
    if ($invalid_referer) {
        #rewrite ^/ http://www.hequan.com/403.html;
        return 403;
    }
}
```
