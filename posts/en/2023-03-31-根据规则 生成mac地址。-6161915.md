> **About this post**
>
> This post is a small Go example: it first fills a 6-byte `net.HardwareAddr`
> with random numbers using `math/rand`, then rewrites bytes according to
> specific rules — the first byte is fixed at 0x00, and the second and third
> segments are each built by concatenating two random digits 0-9 (ensuring that
> these two segments display as pure decimal digits in hex). Finally, it formats
> the result with `%02x` into a colon-separated MAC address string and prints it.

> **Technical notes**
>
> A MAC address is 48 bits (6 bytes), usually written as 12 hexadecimal digits
> separated by colons. The least significant bit of the first byte is the I/G
> bit (0 = unicast, 1 = multicast), and the next bit is the U/L bit (0 =
> universally administered, 1 = locally administered). This example fixes the
> first byte at 0x00, so both flag bits are 0 — a custom choice. If you want to
> explicitly mark the address as locally administered, use a first byte with the
> U/L bit set, such as 0x02. Also, `rand.Seed` has been deprecated since Go 1.20
> (the global random number generator is seeded automatically by default), so
> new code can simply drop that line.

---

```go
package main

import (
	"fmt"
	"math/rand"
	"net"
	"time"
)

func main() {
	ppp := struct{ Mac string }{""}

	if ppp.Mac == "" {
		rand.Seed(time.Now().UnixNano()) // Seed the random number generator with the current time
		mac := make(net.HardwareAddr, 6)
		_, _ = rand.Read(mac)
		fmt.Println(mac)
		// Change the first three fields to the format you need
		mac[0] = 0x00
		// Generate the second and third segments as pure digits
		mac[1] = byte(rand.Intn(10))*16 + byte(rand.Intn(10))
		mac[2] = byte(rand.Intn(10))*16 + byte(rand.Intn(10))

		macString := fmt.Sprintf("%02x:%02x:%02x:%02x:%02x:%02x", mac[0], mac[1], mac[2], mac[3], mac[4], mac[5])
		ppp.Mac = macString
	}

	fmt.Println("Generated MAC address:", ppp.Mac)

}
```
