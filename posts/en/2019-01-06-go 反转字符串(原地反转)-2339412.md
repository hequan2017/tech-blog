> **About this post**
>
> Demonstrates how to reverse a string in place in Go: since Go strings cannot be assigned to by index directly, and reversing multi-byte characters such as Chinese byte by byte produces garbled output, you must first convert the string to `[]rune` and then swap elements pairwise with two pointers. This is a common little algorithm interview question, useful for understanding the difference between string and rune.
>
> **Technical notes**
>
> Since Go 1.18, slice reversal can also be wrapped with generics, but the `[]rune` swap approach remains the standard practice to this day, so the content is generally applicable.

---

```go
package main

import (
	"fmt"
)

func reverse(s string) string {
	s1 := []rune(s)
	for i := 0; i < len(s1)/2; i++ {
		tmp := s1[i]
		s1[i] = s1[len(s1)-1-i]
		s1[len(s1)-1-i] = tmp
	}
	return string(s1)
}

func main() {
	s := "123456"
	fmt.Println(reverse(s))
}
```
