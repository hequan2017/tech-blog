> **About this post**
>
> A collection of Linux operations interview questions — 31 questions in total, each with a brief answer. Topics covered: checking MySQL master-slave replication sync and locating locks, the TCP three-way handshake and time_wait, XSS and SQL injection prevention, nginx multi-site configuration, IP statistics from access logs, a batch user-creation script, the three LVS modes and an lvs/nginx/haproxy comparison, Docker's four network modes, keepalived high-availability principles, and other common interview topics.

> **Technical notes**
>
> Most of the topics (TCP, load balancing, awk/sed usage) are still generally applicable today. Time-sensitive differences to note: MySQL 8.0 removed the `PASSWORD()` function — use `ALTER USER ... IDENTIFIED BY` to reset passwords instead; `show slave status` was renamed to `show replica status` as of MySQL 8.4; besides Docker's bridge/host/none/container modes, overlay and macvlan networks are also used in swarm/overlay scenarios.

1. How can you tell whether MySQL master-slave replication is in sync? How do you bring it back into sync?
Check:

```shell
show slave status;
```

```
Slave_IO_Running yes
Slave_SQL_Running yes
```

12. Count the top ten IPs with the most visits in the /var/log/nginx/access.log log


14. Write a script that adds 20 users in batch, named user1-20, with a password of user followed by 5 random characters or digits

```shell
for i in `seq 1 20`
do
pw=`echo $[$RANDOM]|md5sum|cut -c 1-5`
useradd user$i
echo "user$i $pw" >> /root/pw.txt
echo "user$pw" |passwd --stdin user$i
done
```

15. You see ip-conntrack: table full, dropping packet in the dmesg output — how do you resolve it?

Change the ip_conntrack size (/proc/sys/net/netfilter/nf_conntrack_max)

16. Pros and cons of varnish, nginx, and squid caching

- squid: most feature-complete, moderate performance, no multi-core support
- Varnish: memory-based caching, strong performance
- nginx: caching via plugins, limited features

19. Pros and cons of lvs/nginx/haproxy

- LVS: works at layer 4, stable
- nginx: works at layer 7, high concurrency, only through ports
- haproxy: supports session and URL rules
