> **About this post**
>
> This is part 3 of the "Ops Infrastructure" series: managing the start and stop of a jar-packaged service with a single shell script.
> The script uses the current directory name as the project name and provides three subcommands: start/stop/restart.
> Before starting, it checks for duplicate processes; it launches the service in the background with nohup and records the pid; on stop, it kills the process by pid and cleans up.

> **Technical notes**
>
> The project name is taken from the current directory name at execution time; the jar path is /data/app/<project>/<project>.jar.
> The usage hint mentions update, but the script only implements the start/stop/restart branches (as in the original).
> stop uses kill -9 to force-terminate the process, so the Java application will not run its graceful-shutdown hooks.

---

## 1. Start/Stop/Restart Script for a Jar Package

```shell
#!/bin/sh

project="`pwd | awk -F'/' '{print $NF}'`"

APP_BASE=/data/app
echo "工作目录:"$APP_BASE/${project}

case "$1" in
  start)
    cd ${APP_BASE}/${project}
    ps aux | egrep -v '\bvi\b|\bvim\b|\bgrep\b|\btail\b|\bcat\b|\bhead\b' | grep java | grep -q "${project}"
    if [ $? -eq 0 ]; then
      echo "   ${project}.jar is running !"
      exit 12
    fi
    nohup java -jar -XX:MetaspaceSize=256m -XX:MaxMetaspaceSize=256m -XX:+HeapDumpOnOutOfMemoryError -Xms256m -Xmx512m ${APP_BASE}/${project}/${project}.jar > /dev/null 2>&1 &
    echo $! > ${project}.pid
    ;;

  stop)
    cd ${APP_BASE}/${project}
    ps aux | egrep -v '\bvi\b|\bvim\b|\bgrep\b|\btail\b|\bcat\b|\bhead\b' | grep java | grep -q "${project}"
    if [ $? -eq 0 ]; then
      processId=$(cat ${project}.pid)
      echo $processId
      kill -9 $processId
      rm -f ${project}.pid
      echo "    ${project} is stopped !"
    else
      echo "    ${project} is not start !"
    fi
    ;;

  restart)
    cd ${APP_BASE}/${project}
    sh $0 stop
    sleep 1
    sh $0 start
    ;;

  *)
    echo "Usage: $0 {start|stop|restart|update}"
    ;;

esac

exit 0
```
