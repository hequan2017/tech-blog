> **About this post**
>
> Sharing a workspace formatting configuration for developing Vue projects in VS Code: the vetur + ESLint + Prettier combo enables format-on-save, single quotes, no semicolons, 2-space tabs, Stylus style formatting, and more, with the complete settings.json plus a comment explaining each option.
>
> **Technical notes**
>
> This configuration dates from the vetur era; Vue 3 + Volar is now the official recommendation (vetur is no longer maintained), and options such as `eslint.autoFixOnSave` have been superseded by `editor.codeActionsOnSave`. For new projects, follow the current official ESLint/Prettier guides.

---

### VS Code Formatting Setup for Vue Development

#### Open Settings

`Preferences: Open Workspace Settings`

#### Modify the Configuration File

```jsonc
{
  "workbench.colorTheme": "One Dark Pro",
  "explorer.confirmDelete": false,
  "terminal.integrated.shell.windows": "C:\\Program Files\\Git\\bin\\bash.exe",
  "editor.minimap.enabled": true,
  "explorer.confirmDragAndDrop": false,
  "tslint.autoFixOnSave": true,
  "python.jediEnabled": false,
  "eslint.autoFixOnSave": false,
  "editor.detectIndentation": false,
  // Reset the tab size
  "editor.tabSize": 2,
  // Format automatically on every save
  "editor.formatOnSave": true,
  // Fix code to ESLint style on every save
  // Add vue support
  "eslint.validate": [
    "javascript",
    "javascriptreact",
    {
      "language": "vue",
      "autoFix": true
    }
  ],
  // Let Prettier validate using ESLint's code style
  "prettier.eslintIntegration": true,
  // Remove semicolons at the end of code
  "prettier.semi": false,
  // Use single quotes instead of double quotes
  "prettier.singleQuote": true,
  // Add a space between a function name and its parentheses
  "javascript.format.insertSpaceBeforeFunctionParenthesis": true,
  // Choose this according to your own preference
  "vetur.format.defaultFormatter.html": "js-beautify-html",
  // Format js in vue files with the editor's built-in ts formatter
  "vetur.format.defaultFormatter.js": "vscode-typescript",
  "vetur.format.defaultFormatterOptions": {
    "js-beautify-html": {
      "wrap_attributes": "force-aligned"
      // HTML formatting style for vue components
    }
  },
  // Format stylus; requires the Manta's Stylus Supremacy extension
  "stylusSupremacy.insertColons": false, // Whether to insert colons
  "stylusSupremacy.insertSemicolons": false, // Whether to insert semicolons
  "stylusSupremacy.insertBraces": false, // Whether to insert braces
  "stylusSupremacy.insertNewLineAroundImports": false, // Whether to add a newline after imports
  "stylusSupremacy.insertNewLineAroundBlocks": false // Whether to add a newline between selectors
}
```
