> **About this post**
>
> Documents how Nacos versions before 1.4.1 could still bypass authentication by forging the User-Agent header even with `nacos.core.auth.enabled=true`, presents the 1.4.1 fix configuration: disable `userAgentAuthWhite` and set the server identity `server.identity.key/value`, and closes with an example showing that the Go SDK must carry a username and password once authentication is enabled.

> **Technical notes**
>
> This vulnerability corresponds to Nacos CVE-2021-29442, fixed upstream in 1.4.1; production environments are advised to upgrade directly to the latest stable 2.x release and enable authentication. The `nacos-sdk-go` import path was truncated in the original; it should actually be `github.com/nacos-group/nacos-sdk-go/...`.

### 1.4.1

```shell
nacos .core.auth.enabled=true

### Since 1.4.1, Turn on/off white auth for user-agent: nacos-server, only for upgrade from old version.
nacos.core.auth.enable.userAgentAuthWhite=false

### Since 1.4.1, worked when nacos.core.auth.enabled=true and nacos.core.auth.enable.userAgentAuthWhite=false.
### The two properties is the white list for auth and used by identity the request from other server.
nacos.core.auth.server.identity.key=aaa
nacos.core.auth.server.identity.value=bbb

When requesting the URL, include:

key :         value
```

### sdk-go

> You need to add the username and password to fetch the information

```go
package main

import (
	"fmt"

	"github.com/nacos-group/nacos-sdk-go/clients"
	"github.com/nacos-group/nacos-sdk-go/common/constant"
	"github.com/nacos-group/nacos-sdk-go/vo"
)

func main()  {

	clientConfig := constant.ClientConfig{

		TimeoutMs:           5000,
		NotLoadCacheAtStart: true,
		RotateTime:          "1h",
		MaxAge:              3,
		LogLevel:            "debug",
		Username:			"nacos",
		Password:			"nacos",
	}

	// At least one ServerConfig
	serverConfigs := []constant.ServerConfig{
		{
			IpAddr:      "192.168.100.100",
			ContextPath: "/nacos",
			Port:        8848,
			Scheme:      "http",
		},
	}
	// Another way to create the config client (recommended)
	configClient, _ := clients.NewConfigClient(
		vo.NacosClientParam{
			ClientConfig:  &clientConfig,
			ServerConfigs: serverConfigs,
		},
	)
	content, _ := configClient.GetConfig(vo.ConfigParam{
		DataId: "1",
		Group:  "DEFAULT_GROUP"})

	fmt.Println(content)

}
```
