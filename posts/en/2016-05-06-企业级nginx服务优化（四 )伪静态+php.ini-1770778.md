> **About this post**
>
> This is the fourth article in the LNMP/LAMP web optimization series: it first enables
> mod_rewrite in Apache, changes AllowOverride to All, provides complete pseudo-static
> rewrite rules for the Discuz forum under both Apache and Nginx, and summarizes nginx
> rewrite regex matching (~ / ~* / -f / -d, etc.) and the meaning of the flags
> (last / break / redirect / permanent). It then walks through the php.ini security and
> performance directives one by one (disabling dangerous functions, turning off version
> disclosure, limiting execution time and uploads), gives a php-fpm.conf process pool
> tuning example together with the nginx fastcgi_pass integration configuration, and
> finally uses diagrams to illustrate the C/S working principle of FastCGI.

> **Technical notes**
>
> The `safe_mode`, `register_globals`, and `magic_quotes_gpc` directives shown in this
> article's php.ini were removed starting with PHP 5.4 and are no longer supported in
> modern PHP 7/8; the remaining directives such as `disable_functions`, `expose_php`,
> and `cgi.fix_pathinfo` are still valid. Under Apache 2.4 the usage of mod_rewrite is
> unchanged, but directory authorization needs `Require all granted` instead of the old
> Order/Allow combination. For nginx configuration, follow the official documentation of
> the current stable version (1.24+/1.26+).

## 1. Enabling Pseudo-Static Support in Apache

Open the Apache configuration file httpd.conf:

1. Remove the `#` in front of `#LoadModule rewrite_module modules/mod_rewrite.so`;
2. Locate the following block and change `AllowOverride None` to `AllowOverride All`:

```apache
# AllowOverride controls what directives may be placed in .htaccess files.
# It can be "All", "None", or any combination of the keywords:
#   Options FileInfo AuthConfig Limit
#
AllowOverride None
```

## 2. Discuz Pseudo-Static Rules (Apache)

Apache Web Server (dedicated server users):

```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteCond %{QUERY_STRING} ^(.*)$
    RewriteRule ^(.*)/topic-(.+)\.html$ $1/portal.php?mod=topic&topic=$2&%1
    RewriteCond %{QUERY_STRING} ^(.*)$
    RewriteRule ^(.*)/article-([0-9]+)-([0-9]+)\.html$ $1/portal.php?mod=view&aid=$2&page=$3&%1
    RewriteCond %{QUERY_STRING} ^(.*)$
    RewriteRule ^(.*)/forum-(\w+)-([0-9]+)\.html$ $1/forum.php?mod=forumdisplay&fid=$2&page=$3&%1
    RewriteCond %{QUERY_STRING} ^(.*)$
    RewriteRule ^(.*)/thread-([0-9]+)-([0-9]+)-([0-9]+)\.html$ $1/forum.php?mod=viewthread&tid=$2&extra=page\%3D$4&page=$3&%1
    RewriteCond %{QUERY_STRING} ^(.*)$
    RewriteRule ^(.*)/group-([0-9]+)-([0-9]+)\.html$ $1/forum.php?mod=group&fid=$2&page=$3&%1
    RewriteCond %{QUERY_STRING} ^(.*)$
    RewriteRule ^(.*)/space-(username|uid)-(.+)\.html$ $1/home.php?mod=space&$2=$3&%1
    RewriteCond %{QUERY_STRING} ^(.*)$
    RewriteRule ^(.*)/blog-([0-9]+)-([0-9]+)\.html$ $1/home.php?mod=space&uid=$2&do=blog&id=$3&%1
    RewriteCond %{QUERY_STRING} ^(.*)$
    RewriteRule ^(.*)/(fid|tid)-([0-9]+)\.html$ $1/index.php?action=$2&value=$3&%1
    RewriteCond %{QUERY_STRING} ^(.*)$
    RewriteRule ^(.*)/([a-z]+[a-z0-9_]*)-([a-z0-9_\-]+)\.html$ $1/plugin.php?id=$2:$3&%1
</IfModule>
```

## 3. Nginx Rewrite Syntax Quick Reference

Regular expression matching, where:

- `~` is a case-sensitive match
- `~*` is a case-insensitive match
- `!~` and `!~*` denote a case-sensitive mismatch and a case-insensitive mismatch respectively

File and directory matching, where:

- `-f` and `!-f` test whether a file exists
- `-d` and `!-d` test whether a directory exists
- `-e` and `!-e` test whether a file or directory exists
- `-x` and `!-x` test whether a file is executable

The flags are:

- `last` is equivalent to the [L] mark in Apache and indicates the rewrite is complete
- `break` stops matching; the rules after it are no longer matched
- `redirect` returns a 302 temporary redirect; the address bar shows the redirected URL
- `permanent` returns a 301 permanent redirect; the address bar shows the redirected URL

## 4. Discuz Pseudo-Static Rules (Nginx)

Nginx Web Server:

```nginx
rewrite ^([^\.]*)/topic-(.+)\.html$ $1/portal.php?mod=topic&topic=$2 last;

rewrite ^([^\.]*)/forum-(\w+)-([0-9]+)\.html$ $1/forum.php?mod=forumdisplay&fid=$2&page=$3 last;

rewrite ^([^\.]*)/space-(username|uid)-(.+)\.html$ $1/home.php?mod=space&$2=$3 last;
```

## 5. php.ini Security and Performance Directives

The relationship among php, php.ini, and php-fpm.conf: under an nginx + fcgi architecture,
nginx hands dynamic requests over the FastCGI protocol to php-fpm, which manages the php
interpreter for processing.

```ini
; The leading numbers are php.ini line numbers noted in the original text
338  safe_mode = On                                ; Turn on safe mode
344  safe_mode_gid = Off
385  disable_functions = system,passthru,exec,shell_exec,popen,phpinfo   ; Disable dangerous functions; unnecessary if safe mode is on
435  expose_php = Off                              ; Stop leaking the PHP version in HTTP headers
703  register_globals = Off                        ; Disable global environment variables by default
756  magic_quotes_gpc = On                         ; Turn on to prevent SQL injection
538  display_errors = Off                          ; Turn error messages off; enable when testing
643  error_log = /app/logs/php_errors.log          ; Only works when the option above is on
444  max_execution_time = 30                       ; Maximum execution time allowed per script (seconds)
465  memory_limit = 128M                           ; Maximum memory in bytes a script may claim
454  max_input_time = 60                           ; Maximum time a script may wait for input data
891  upload_max_filesize = 2M                      ; Maximum upload file size
894  max_file_uploads = 20                         ; Maximum number of files uploaded per request
902  allow_url_fopen = Off                         ; Forbid opening remote URLs
854  cgi.fix_pathinfo = 0                          ; Prevent the nginx file-type misparse vulnerability
1461 session.save_handler = memcache
1490 session.save_path = "tcp://192.168.10.11:11211"   ; IP and port of the memcached cache
```

## 6. php-fpm.conf Process Pool and nginx Integration

The upgraded replacement for CGI (Common Gateway Interface) is FastCGI, which corresponds
to php-fpm. Compile options: for PHP 5.3 and above use `--enable-fpm`; in the PHP 5.2 era
use `--enable-fastcgi --enable-fpm --enable-force-cgi`.

Edit `/application/php/etc/php-fpm.conf`:

```ini
pm = dynamic
pid = /app/logs/php-fpm.pid
error_log = /app/logs/php-fpm.log
log_level = error
rlimit_files = 32768
listen.owner = nginx
listen.group = nginx
pm.max_children = 1024
pm.start_servers = 16
pm.min_spare_servers = 5
pm.max_spare_servers = 20
pm.process_idle_timeout = 15s
pm.max_requests = 2048
slowlog = /app/logs/$pool.log.slow
request_slowlog_timeout = 10
```

The nginx side, integrating with FastCGI:

```nginx
location ~ .*\.(php|php5)?$ {
    fastcgi_pass   127.0.0.1:9000;
    fastcgi_index  index.php;
    include        fastcgi.conf;
}
```
