> **About this post**
>
> An introduction to writing asynchronous tasks in Python with the dramatiq library (a lightweight alternative to Celery): use Redis as the broker, define task functions decorated with `@dramatiq.actor` and dispatch them via `.send()`, then start a worker with `dramatiq example --watch .`, which watches for code changes and restarts automatically.
>
> **Technical notes**
>
> dramatiq is still actively maintained and its API remains essentially the same as described here; the officially recommended `pip install 'dramatiq[redis, watch]'` is unchanged, but Python 2 is no longer supported at all and Python 3.8+ is required. Note that "redi s" in the original installation line is a typo.

### Python Asynchronous Programs with dramatiq

#### Installation

You need Redis first ("redi s" in the original is a typo), then install:

```shell
pip3 install 'dramatiq[redis, watch]'
```

#### Code

##### example.py

```python
import dramatiq
import requests
from dramatiq.brokers.redis import RedisBroker

redis_broker = RedisBroker(host="127.0.0.1", port=6379)
dramatiq.set_broker(redis_broker)

@dramatiq.actor
def count_words(url):
    print(url)

count_words.send("http://example.com")
```

##### Execution

```shell
# watch . dynamically detects code changes and restarts automatically
dramatiq example --watch .
```
