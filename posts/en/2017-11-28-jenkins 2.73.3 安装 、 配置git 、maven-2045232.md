> **About this post**
>
> This post records the process of deploying Jenkins 2.73.3 (as a war package)
> on Tomcat and setting up a complete Java CI environment: download jenkins.war
> into webapps and use initialAdminPassword to finish initialization and install
> the basic plugins; then build Git 2.15.0 from source, deploy Maven 3.5.2 and
> configure the environment variables; then register the actual paths of
> JDK/Git/Maven in Jenkins' "Global Tool Configuration", install the Maven
> Integration, Deploy to container and other plugins, and finally configure
> email notification based on sina SMTP, with a successful test send.

> **Technical notes**
>
> Jenkins 2.73.3 is a 2017 release, long outdated; for new environments install
> the current LTS (2.4xx series). Deploying a war into Tomcat is rarely used
> nowadays; the official recommendation is a standalone service or Docker.
> The jenkins path structure on the Tsinghua mirror has since been adjusted;
> verify it before downloading. Two download URLs lost to web-page escaping in
> the original have been restored: github.com was added back for git, and maven
> was pointed to the Tsinghua tuna mirror per the author's usual practice (the
> original domain is no longer traceable); the code block fence mistakenly
> written as ```` ```shell ```` at its end was also fixed. The Git 2.15 +
> Jenkins combination cannot run on newer JDKs; upgrading requires a full
> version overhaul.

## 1. Installing Jenkins

After Tomcat and Java are set up, download the war package into webapps:

```shell
wget https://mirrors.tuna.tsinghua.edu.cn/jenkins/war-stable/2.73.3/jenkins.war
cp jenkins.war  /usr/local/tomcat/webapps/
```

Log in at `0.0.0.0:8080/jenkins` to start the installation:

```shell
cat    /root/.jenkins/secrets/initialAdminPassword       ## the installation and login password is here
```

Choose to install the basic plugins.

## 2. Installing Git

Overall idea: git for the code repository, Maven for building the code, Tomcat for running the code.

```shell
yum install curl-devel expat-devel gettext-devel openssl-devel zlib-devel gcc perl-ExtUtils-MakeMaker

wget https://github.com/git/git/archive/v2.15.0.tar.gz

tar zxvf v2.15.0.tar.gz
cd git-2.15.0

make configure
./configure --prefix=/usr/local/git --with-iconv=/usr/local/libiconv
make all doc
make install install-doc install-html

vim /etc/profile
export PATH=/usr/local/git/bin:$PATH

source /etc/profile
git --version
```

## 3. Installing Maven

```shell
wget https://mirrors.tuna.tsinghua.edu.cn/apache/maven/maven-3/3.5.2/binaries/apache-maven-3.5.2-bin.tar.gz
tar zxvf apache-maven-3.5.2-bin.tar.gz
mv apache-maven-3.5.2  /usr/local/maven

vim /etc/profile
export M2_HOME=/usr/local/maven
export M2=$M2_HOME/bin
export PATH=$M2:$PATH

source /etc/profile
mvn -version
```

## 4. Jenkins Global Tool and Plugin Configuration

Go to Manage Jenkins -- Global Tool Configuration and register the actual
installation paths of JDK, Git, and Maven (uncheck automatic installation):

![Global Tool Configuration page: JDK alias JDK1.8 and Git installation path](../assets/2045232/01_00b075ee07a1b7592f16ece5b5f2a904.png)

![Global Tool Configuration page: Maven entry and MAVEN_HOME path](../assets/2045232/02_6cd7a0ebf81915d6f706f212d9d4698c.png)

Go to Manage Jenkins -- Manage Plugins -- Available plugins and install the following plugins:

- Maven Integration plugin
- Deploy to container Plugin
- GitHub Authentication plugin
- SSH plugin

## 5. Email Settings
