> **About this post**
>
> This post uses a short Shell script to estimate the real-time network speed of a
> container's network interface: it first reads the rx_bytes and tx_bytes cumulative
> counters under /sys/class/net/eth0/statistics, samples again after a 60-second
> interval, and divides the difference by the elapsed time to obtain the average
> inbound and outbound speed of eth0 (bytes/sec).

> **Technical notes**
>
> - Inside a container, eth0 is one end of a veth pair in the container's network
>   namespace; /sys/class/net only shows the interfaces visible in the current network
>   namespace, so the script must `docker exec` into the container (or enter its
>   netns) to run.
> - The counters under statistics/ are maintained by the kernel; they accumulate from
>   the moment the interface is brought up and are never reset by reading. They come
>   from the same source as `ip -s link`, so increments can only be obtained by
>   differencing.
> - If time_interval is 0, a division-by-zero error occurs; the example always does
>   `sleep 60`, so it never triggers, but add your own guard when making the interval
>   a parameter.
> - For a container with multiple interfaces, first run `ls /sys/class/net/ | grep -v lo`
>   to list the interfaces, measure each one separately, then sum the results.

---

## 1. Identify the network interface to measure

List all interfaces except lo; inside a container this is usually just eth0:

```shell
ls /sys/class/net/ | grep -v lo
```

## 2. Take two samples to compute the speed

Record the initial timestamp and the initial received/transmitted byte counts, wait
60 seconds, read them again, then divide the differences by the time interval to get
the average speed:

```shell
# Get the initial timestamp and the initial received/transmitted byte counts
start_time=$(date +%s)
start_rx_bytes=$(cat /sys/class/net/eth0/statistics/rx_bytes)
start_tx_bytes=$(cat /sys/class/net/eth0/statistics/tx_bytes)

# Wait for a while (e.g., 60 seconds)
sleep 60

# Get the new timestamp and the corresponding received/transmitted byte counts
end_time=$(date +%s)
end_rx_bytes=$(cat /sys/class/net/eth0/statistics/rx_bytes)
end_tx_bytes=$(cat /sys/class/net/eth0/statistics/tx_bytes)

# Compute the time interval and the speeds
time_interval=$((end_time - start_time))
rx_speed=$(( (end_rx_bytes - start_rx_bytes) / time_interval ))
tx_speed=$(( (end_tx_bytes - start_tx_bytes) / time_interval ))

# Print the results
echo "Inbound speed: $rx_speed bytes/sec"
echo "Outbound speed: $tx_speed bytes/sec"
```
