> **About this post**
>
> A small jQuery trick: when the "Reset" button is clicked, restore the value of a given select dropdown (here used together with a select2-style plugin) to empty — the key is to manually `trigger("change")` after `.val(null)`, otherwise the plugin's selected state will not refresh.

> **Technical notes**
>
> `.val(null).trigger("change")` is the classic way to clear a select2 3.x/4.x control, and it still works today. If the project has migrated to a framework such as Vue/React, clearing a form control is simply a matter of changing the bound data — no need to manually trigger DOM events.

---

```html
<a class="btn btn-danger reset">Reset</a>
```

```javascript
$(document).on('click', '.reset', function () {
	$("#id_name").val(null).trigger("change");
})
```
