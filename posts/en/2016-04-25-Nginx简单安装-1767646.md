> **About this post**
>
> This post first covers the advantages of Nginx over Apache: simple and
> flexible configuration, high concurrency (for small static files), low
> resource usage, support for the epoll model, and per-IP rate limiting and
> connection limits. It then explains how the LNMP architecture works —
> nginx listens on port 80 and forwards PHP requests via fastcgi_pass to the
> PHP FCGI service on port 9000, unlike Apache's DSO module approach. It then
> walks through compiling and installing Nginx 1.9.15: the pcre/openssl
> dependencies, creating the nginx user, configure flags, and a symlink,
> finishing with nginx -t to check the configuration, starting the service,
> and verifying that the port is listening with netstat.

>

> `ntpdate cn.pool.ntp.org` command used here to sync the system time is
> deprecated; on CentOS 7+ prefer `chronyd` or `timedatectl` instead.

## 1. Advantages of Nginx and the LNMP Architecture

Nginx advantages: simple configuration, more flexibility, high concurrency
(for small static files), low resource usage, a rich feature set, and support
for the epoll model. It handles dynamic content differently from Apache, and
can also rate-limit by IP and limit the number of connections.

How LNMP works / its architecture:

- nginx (port 80) forwards requests via `fastcgi_pass` to the PHP FCGI
  service (port 9000)
- Apache uses modules (DSO / apxs) and the select model
- nginx spawns CGI processes and uses the epoll network I/O model

## 2. Installation Preparation

```shell
ntpdate cn.pool.ntp.org    # Update the system time
```

Install pcre (PCRE, the Perl-compatible regular expression library, needed to
support http rewrite pseudo-static URLs) and openssl:

```shell
yum -y install pcre* openssl openssl-devel
useradd -s /sbin/nologin -M nginx
```

## 3. Compiling and Installing Nginx 1.9.15

Source download: http://nginx.org/

```shell
wget http://nginx.org/download/nginx-1.9.15.tar.gz
tar xf nginx-1.9.15.tar.gz
cd nginx-1.9.15
./configure --user=nginx --group=nginx \
    --prefix=/application/nginx1.9.15 \
    --with-http_stub_status_module \
    --with-http_ssl_module
make && make install
ln -s /application/nginx1.9.15/ /application/nginx
```

## 4. Starting and Verifying

```shell
/application/nginx/sbin/nginx -t    # Check the configuration
/application/nginx/sbin/nginx       # Start
netstat -lntup | grep nginx
tcp        0      0 0.0.0.0:80      0.0.0.0:*      LISTEN      12590/nginx
```

If you see "Welcome to nginx!" when visiting the site in a browser, the
installation succeeded.
