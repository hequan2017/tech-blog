> **About this post**
>
> This post demonstrates how to collect per-core CPU usage in Go with the gopsutil library.
> The program first uses cpu.Counts to get the number of logical CPUs, then calls
> cpu.Percent per core inside an infinite loop, printing the usage of each core one by one.
>
> **Technical notes**
>
> - gopsutil is a cross-platform library for collecting system information; on Linux, CPU data comes from /proc/stat.
> - `cpu.Counts(true)` returns the number of logical CPUs, which maps one-to-one onto the slice returned by `cpu.Percent(interval, true)`; use `Counts(false)` instead if you need the number of physical cores.
> - Passing a positive interval to `cpu.Percent` blocks for that duration to complete one sample; combined with the `time.Sleep` in the loop, each round actually takes about 2×interval. Using `cpu.Percent(0, true)` is non-blocking and returns the average since the last call.
> - In the newer gopsutil v3, the import path is `github.com/shirou/gopsutil/v3/cpu`.

---

```go
package main

import (
	"fmt"
	"log"
	"time"

	"github.com/shirou/gopsutil/cpu"
)

func main() {
	// Get the number of CPU cores
	cpuCount, err := cpu.Counts(true)
	if err != nil {
		log.Fatal("Failed to get CPU core count:", err)
	}

	// Set the collection interval
	interval := time.Second

	for {
		// Collect CPU usage for each core
		cpuPercent, err := cpu.Percent(interval, true)
		if err != nil {
			log.Println("Failed to get CPU usage:", err)
			continue
		}

		// Display the usage of each core
		for i := 0; i < cpuCount; i++ {
			fmt.Printf("CPU Core %d Usage: %.2f%%\n", i, cpuPercent[i])
		}

		fmt.Println("------------------")

		// Wait for a while
		time.Sleep(interval)
	}
}
```
