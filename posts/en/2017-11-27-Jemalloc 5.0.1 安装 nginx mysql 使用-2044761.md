> **About this post**
>
> This post covers building and installing the memory allocator Jemalloc 5.0.1, and how to make both Nginx and MySQL use it: jemalloc is compiled and installed to /usr/local/jemalloc and its dynamic library registered; on the Nginx side it is linked at compile time via --with-ld-opt="-ljemalloc"; on the MySQL side, libjemalloc.so is copied to the system library directory and malloc-lib is configured in the [mysqld_safe] section of my.cnf, with lsof used at the end to verify that it took effect. Suitable for multi-threaded services that need to reduce memory fragmentation and curb memory bloat during long runs.

> **Technical notes**
>
> Jemalloc has since evolved to the 5.3 series; it remains the allocator officially recommended by Redis, and has long been the default malloc on systems such as FreeBSD/Fedora. In MySQL 8.0, the usage of mysqld_safe and malloc-lib has changed (the relevant option has been deprecated/removed); for 8.0, use the LD_PRELOAD approach instead and check the official documentation. Three pieces of content that the web page escaping or the editor had swallowed in the original have been restored: github.com added back to the download URL; configure's `-prefix` corrected to `--prefix`; and the library filename swallowed after cp and malloc-lib restored as libjemalloc.so.2.

## 1. Install Jemalloc

```shell
cd /usr/local/src
wget       https://github.com/jemalloc/jemalloc/releases/download/5.0.1/jemalloc-5.0.1.tar.bz2
tar     -xjvf     jemalloc-5.0.1.tar.bz2

cd jemalloc-5.0.1/
./configure  --prefix=/usr/local/jemalloc    --libdir=/usr/local/lib
make  && make install

echo /usr/local/lib >> /etc/ld.so.conf
ldconfig
```

## 2. Using jemalloc with Nginx

For Nginx, just add this parameter when compiling:

```shell
nginx:     --with-ld-opt="-ljemalloc"   ##add this parameter when compiling
```

## 3. Using jemalloc with MySQL

After the installation, modify my.cnf:

```shell
cp /usr/local/lib/libjemalloc.so.2  /usr/lib

vim  /etc/my.cnf
[mysqld_safe]
malloc-lib=/usr/lib/libjemalloc.so.2

/etc/init.d/mysqld restart
```

Verify that it took effect:

```shell
lsof -n | grep jemalloc
```
