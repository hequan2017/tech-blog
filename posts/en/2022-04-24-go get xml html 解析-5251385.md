> **About this post**
>
> Use Go to make HTTP requests and fetch web pages, parse HTML in jQuery style with goquery,
> extract the text inside pre tags, then hand it to encoding/xml to unmarshal into a struct.
> The post centers on a single sample code snippet; it reads like a fragment-style note.

> **Technical notes**
>
> `io/ioutil` has been deprecated since Go 1.16; the new replacement for `ioutil.ReadAll` is `io.ReadAll`.
> `encoding/xml` is still in the standard library to this day and its API has long been stable; goquery also remains
> the most widely used jQuery-style HTML parsing library in the Go ecosystem (built on top of golang.org/x/net/html).

## 1. Sample Code

```go
package jielv

import (
  "encoding/xml"
  "github.com/PuerkitoBio/goquery"
  "io/ioutil"
  "log"
  "net/http"
  "strings"
)

func getXML() []byte {
  url := "http://"
  resp, _ := http.Get(url)
  defer resp.Body.Close()
  data, _ := ioutil.ReadAll(resp.Body)
  return data
}

type Test struct {

}

func main() {

  re := getXML()
  dom, err := goquery.NewDocumentFromReader(strings.NewReader(string(re)))
  if err != nil {
    log.Fatalln(err)
  }
  var s string
  dom.Find("pre").Each(func(i int, selection *goquery.Selection) {
    s = s + selection.Text()
  })
  var city Test
  xml.Unmarshal([]byte(s), &city)
}
```
