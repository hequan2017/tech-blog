> **About this post**
>
> This post describes how to use the third-party script `update-kubeadm-cert.sh` to renew kubeadm cluster certificates with a single command. The script regenerates certificates for components such as the API Server and Controller Manager via `kubeadm certs renew`, resolving cluster outages caused by expired certificates.
>
> **Technical notes**
>
> The script relies on the certificate renewal mechanism available in kubeadm 1.19+. In Kubernetes v1.25 and later, certificates still default to a one-year validity period. In production, it is recommended to check expiration regularly with `kubeadm certs check-expiration`, or to manage certificates with automation tools such as kubeasz or sealos.

---

```shell
git clone https:///yuyicai/update-kube-cert.git
cd update-kube-cert
chmod 755 update-kubeadm-cert.sh
./update-kubeadm-cert.sh all
```
