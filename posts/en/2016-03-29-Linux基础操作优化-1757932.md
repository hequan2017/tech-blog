> **About this post**
>
> This post is a set of system initialization and optimization notes from the CentOS 6 era, covering
> yum package management (update vs. upgrade, installing common ops tools), disabling SELinux,
> trimming boot-time services (keeping only sshd / crond / network / rsyslog), setting a Chinese
> locale, configuring ntp for scheduled time sync, raising the file descriptor limit (ulimit),
> locking key account files, and other basic hardening and optimization steps to run right after
> installing a system.

> **Technical notes**
>
> This post is based on CentOS 6: `chkconfig` / `ntsysv` / `setup` / `/etc/inittab` / `/etc/sysconfig/i18n`
> and their like were replaced in CentOS 7+ by `systemctl`, `/etc/systemd/system/default.target`,
> `localectl`, and `/etc/locale.conf` respectively. CentOS 6/7 are both end-of-life (EOL); for new
> environments, Rocky Linux / AlmaLinux are recommended, with service management commands replaced by
> their systemd equivalents. For time sync, prefer chrony (`chronyd` + `chronyc sources`); running
> ntpdate from cron has been superseded on systemd systems by `systemd-timesyncd` or chrony.

## 1. yum Package Management

List installable package groups / install by group:

```shell
yum grouplist                          # List all package groups
yum groupinstall "Development Tools"   # Install the development tools group (gcc, make, etc.)
```

Two common commands for system upgrades:

```shell
yum -y update    # Upgrade all packages (kernel included), handling obsoletes
yum -y upgrade   # Same as yum update --obsoletes; behavior basically identical to update
```

- `yum -y update`: upgrades all packages and the system kernel, and handles package obsoletes.
- `yum -y upgrade`: equivalent to `yum update --obsoletes`; its behavior is basically the same as update
  (the old claim that "upgrade does not change the kernel" is inaccurate — in practice the difference is minimal).

Install common ops tools:

```shell
yum install tree telnet dos2unix sysstat lrzsz -y  # tree: dir tree / telnet: port test / dos2unix: format conversion / sysstat: perf monitoring / lrzsz: upload/download
```

> Note: on newer systems (RHEL 8+/Rocky/Alma), `dnf` replaces `yum` with compatible options.
> For port testing, `nc` (nmap-ncat) is a better choice; telnet itself has been phased out
> because it transmits in plaintext.

## 2. Disabling SELinux

```shell
sed -i 's#SELINUX=enforcing#SELINUX=disabled#g' /etc/selinux/config  # Disable permanently (reboot required)
getenforce   # Show the current SELinux status
```

A reboot is required for the config change to take effect; to disable it only temporarily, use `setenforce 0`.

## 3. Runlevels and Text-Mode Configuration Tools (CentOS 6 Only)

```shell
runlevel            # Show the current runlevel
vi /etc/inittab     # Set the default runlevel (CentOS 6; obsolete in CentOS 7+)
init 3              # Switch to runlevel 3 (multi-user text mode)
setup               # Text-mode all-in-one configuration tool
ntsysv              # Text-mode boot service manager
```

> Note: CentOS 7+ has no runlevel concept; the corresponding commands are
> `systemctl get-default` / `systemctl set-default multi-user.target`.

## 4. Trimming Boot-Time Services

List the services enabled at runlevel 3:

```shell
chkconfig --list | grep "3:on"   # List all services enabled at boot for runlevel 3
```

Disable all auto-start services in one go:

```shell
for hequan in `chkconfig --list | grep "3:on" | awk '{print $1}'`; do
  chkconfig $hequan off
done
```

Keep only the 4 essential services (crond, network, rsyslog, sshd):

```shell
for hequan in sshd crond network rsyslog; do
  chkconfig $hequan on
done
```

Alternatively: disable everything except those 4 services:

```shell
for hequan in `chkconfig --list | grep "3:on" | awk '{print $1}' | grep -vE "crond|network|sshd|rsyslog"`; do
  chkconfig $hequan off
done
```

> Note: the systemd equivalents are `systemctl list-unit-files --state=enabled`
> and `systemctl enable/disable <service>`.

## 5. SSH Configuration

```shell
vi /etc/ssh/sshd_config   # Edit the SSH server configuration
```

Common changes: a non-default port (`Port`), disabling direct root login (`PermitRootLogin no`),
turning off DNS reverse lookup (`UseDNS no`, which speeds up login), and so on. After editing, run
`service sshd restart` (`systemctl restart sshd` on systemd systems).

## 6. Chinese Locale

View / set the system language (CentOS 6):

```shell
cat /etc/sysconfig/i18n                        # Show the current language configuration
echo 'LANG="zh_CN.UTF-8"' > /etc/sysconfig/i18n  # Set to Chinese UTF-8
```

Temporarily switch to English (current session only; handy for troubleshooting):

```shell
LANG=en_US.UTF-8
```

> Note: on CentOS 7+ the language config file is `/etc/locale.conf`; prefer
> `localectl set-locale LANG=zh_CN.UTF-8` to change it.

## 7. Time Synchronization

Manual time sync:

```shell
/usr/sbin/ntpdate ntp1.aliyun.com   # Sync time now from the Aliyun NTP server
```

Add it to crontab to sync automatically every 5 minutes:

```shell
echo '*/5 * * * * /usr/sbin/ntpdate ntp1.aliyun.com > /dev/null 2>&1' >> /var/spool/cron/root  # Append the cron job
crontab -l   # Confirm the job was written
```

> Note: ntpdate has been officially deprecated; use chrony on new systems instead:
> `chronyc -a makestep` steps the time immediately, or simply enable the chronyd daemon
> for continuous synchronization.

## 8. Adjusting Resource Limits

View / raise the number of files a process may open:

```shell
ulimit -n                                          # Show the current fd limit (default 1024)
echo '* - nofile 65535' >> /etc/security/limits.conf  # Set soft and hard limits for all users to 65535
```

Kernel parameter tuning:

```shell
vi /etc/sysctl.conf   # Edit kernel parameters (e.g. net.core.somaxconn, net.ipv4.tcp_tw_reuse)
sysctl -p             # Apply the configuration immediately
```

## 9. Login Banners and Account File Protection

Pre-login / post-login banner messages:

```shell
cat /etc/issue   # Pre-login banner on the local console (clear it to avoid leaking the OS version)
vi /etc/motd     # Welcome message shown after login
```

Lock the key account files to prevent accidental modification (even root cannot write to them):

```shell
chattr +i /etc/passwd   # Set the immutable attribute to lock the file
lsattr /etc/passwd      # Show the file's special attributes
```

To make changes, unlock first with `chattr -i /etc/passwd`, then re-lock when done. In production,
applying this protection to `/etc/passwd`, `/etc/shadow`, `/etc/group`, `/etc/gshadow`, `/etc/inittab`
effectively prevents accidental edits and some privilege-escalation tampering.
