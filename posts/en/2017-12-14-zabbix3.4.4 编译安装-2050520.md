> **About this post**
>
> This post documents deploying Zabbix 3.4.4 from source on an LNMP environment: after installing dependencies with yum, run configure --enable-server --enable-agent and make install; create the zabbix database and account, then import the three SQL files schema/images/data in order; adjust the database connection settings in zabbix_server.conf and the agentd configuration, create the zabbix user, register the /etc/services ports, copy the fedora init scripts and enable them with chkconfig; finally, copy frontends/php into the nginx directory, adjust the seven php.ini parameters required by Zabbix, log in with the default account Admin/zabbix, and fix the garbled Chinese fonts in graphs.

> **Technical notes**
>
> 1. CentOS 7 reached end of maintenance (EOL) on June 30, 2024; migrating to Rocky Linux 9 / AlmaLinux 9 or the homegrown openEuler is recommended.
> 2. Support for Zabbix 3.4 ended in 2019; upstream currently maintains the 6.0/7.0 LTS releases.
>    For new deployments, installing directly from the official yum repository or via containers is recommended.
> 3. Typos corrected: the init script path should be /etc/init.d/zabbix_agentd (the original omitted the
>    trailing d); the font step keeps only the backup command, with the explanation completed: you also need to upload
>    a Chinese font (e.g. simkai.ttf) renamed to DejaVuSans.ttf to resolve the garbled text.

## 1. Environment

An LNMP environment is used; refer to my earlier posts for the installation, then proceed with the deployment.

## 2. Compiling and Installing

```shell
yum -y install libevent libevent-devel net-snmp-devel

cd /usr/local/src/zabbix-3.4.4

./configure --enable-server  --prefix=/usr/local/zabbix   --enable-agent --with-mysql --enable-ipv6 --with-net-snmp --with-libcurl --with-libxml2

make install
```

## 3. Database Initialization

```sql
create database zabbix character set utf8 collate utf8_bin;
grant all privileges on zabbix.* to 'zabbix'@'%' identified by 'zabbixpass';
flush privileges;
```

Import the three SQL files in order:

```shell
cd /usr/local/src/zabbix-3.4.4/database/mysql
cat schema.sql | mysql -uroot -p  zabbix
cat images.sql  | mysql -uroot -p  zabbix
cat data.sql  | mysql -uroot -p  zabbix
```

## 4. Modifying the Configuration Files

zabbix_server.conf:

```ini
DBHost=localhost
DBName=zabbix
DBUser=zabbix
DBPassword=zabbixpass
```

zabbix_agentd.conf:

```ini
Server=127.0.0.1     # Monitors the server itself by default; these three lines need no change
ServerActive=127.0.0.1
Hostname=Zabbix server
UnsafeUserParameters=1       # Allows all characters in user-defined parameters, i.e. supports parameter passing
```

## 5. User, Ports, and Init Scripts

Create the runtime user:

```shell
useradd -u 8005 -M -s /sbin/nologin zabbix
```

In `vim /etc/services`, append the following lines at the end:

```text
zabbix-agent 10050/tcp # Zabbix Agent
zabbix-agent 10050/udp # Zabbix Agent
zabbix-trapper 10051/tcp # Zabbix Trapper
zabbix-trapper 10051/udp # Zabbix Trapper
```

Copy the init scripts and modify `BASEDIR=/usr/local/zabbix` in them:

```shell
cd  /usr/local/src/zabbix-3.4.4/misc/init.d/
cp fedora/core/zabbix_server  /etc/init.d/
cp fedora/core/zabbix_agentd  /etc/init.d/

vim /etc/init.d/zabbix_server
BASEDIR=/usr/local/zabbix

vim /etc/init.d/zabbix_agentd
BASEDIR=/usr/local/zabbix
```

Start the services and enable them at boot:

```shell
/etc/init.d/zabbix_server start
/etc/init.d/zabbix_agentd start

chkconfig  zabbix_server on
chkconfig  zabbix_agentd on
```

## 6. Web Frontend Deployment

```shell
cp /usr/local/src/zabbix-3.4.4/frontends/php/* -rf /etc/nginx/html/

systemctl restart nginx.service
```

Modify `vim /usr/local/php/etc/php.ini` per Zabbix's hard requirements:

```ini
max_execution_time = 300
max_input_time = 300
post_max_size = 16M

memory_limit = 128M
upload_max_filesize = 2M
date.timezone = Asia/Shanghai
always_populate_raw_post_data = -1
```

```shell
/etc/init.d/php-fpm restart
```

The default login account is `Admin` with the password `zabbix`.

## 7. Fixing Garbled Chinese Fonts in Graphs

```shell
cd /etc/nginx/html/fonts
mv DejaVuSans.ttf  DejaVuSans.ttf.bak
```

After backing up the original font, upload a Chinese font (e.g. the Windows simkai.ttf) and rename it to `DejaVuSans.ttf`; Chinese in graphs then displays correctly.
