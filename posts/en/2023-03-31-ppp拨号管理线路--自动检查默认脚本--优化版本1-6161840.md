> **About this post**
>
> Optimized version 1 of the "auto default-route check script" for PPP dial-up lines: compared with the previous version, the connectivity probe is wrapped into a check_ping function; before switching the default route it now checks whether a default route already exists (replace if present, add if not), and it validates that the management-port gateway is non-empty. The switching order is unchanged — if the network is fine, the gateway is left untouched; if not, it first switches to the management port specified in /root/iface.txt, and if that fails, tries each PPP dial-up port in turn.

> **Technical notes**
>
> The probe address 223.5.5.5 is Alibaba Public DNS; the management-port gateway is taken from the existing default route on that port (`awk '/^default/{print $3}'`), and if it cannot be obtained, the switch is skipped and the script falls straight through to the PPP dial-up ports as a fallback; after every default-route switch, the script re-verifies with ping and exits as soon as it succeeds.

## 1. Full Script

```shell
#!/bin/bash

PppCheck() {
    ppp_interfaces=$(ip r | grep -o "\<ppp[0-9]\+\>" | awk -F'ppp' '{print $2}' | sort -n |uniq | awk 'BEGIN{ORS=" "}{print "ppp"$NF}')
    for iface in $ppp_interfaces; do
        if ping -I $iface -W 5 -c 2  223.5.5.5 >/dev/null 2>&1; then
            dial_ip=$(ip route show dev $iface  | awk '{print $1}')
            echo "Setting default gateway to $dial_ip (via $iface)"

            # Check whether a default route already exists
            if ip route | grep -q '^default'; then
                ip route replace default via $dial_ip dev $iface
            else
                ip route add default via $dial_ip dev $iface
            fi

            if ping -W 5 -c 2  223.5.5.5 >/dev/null 2>&1; then
                echo "Network is up; default gateway changed successfully"
                return 0
            else
                echo "Network is down; failed to change the default gateway"
            fi
        fi
    done
    echo "Network is down; failed to change the default gateway"
    return 1
}

check_ping() {
    if ping -W 5 -c 2  223.5.5.5 >/dev/null 2>&1; then
        echo "Network is up; not changing the default gateway"
        return 0
    else
        echo "Network is down; changing the default gateway"
        return 1
    fi
}

if check_ping; then
    exit 0
fi

mgmt_iface="$(cat /root/iface.txt 2>/dev/null)"
if [ -n "$mgmt_iface" ]; then
    if ip link show "$mgmt_iface" | grep -q "state UP"; then
        mgmt_ip=$(ip route show dev "$mgmt_iface" | awk '/^default/{print $3}')
        if [ -n "$mgmt_ip" ]; then
            echo "Setting default gateway to $mgmt_ip (via $mgmt_iface)"
            # Check whether a default route already exists
            if ip route | grep -q '^default'; then
                ip route replace default via "$mgmt_ip" dev "$mgmt_iface"
            else
                ip route add default via "$mgmt_ip" dev "$mgmt_iface"
            fi
        fi
        if check_ping; then
            exit 0
        fi
    else
        echo "$mgmt_iface interface is not up"
    fi
else
    echo "/root/iface.txt is empty"
fi

PppCheck
```
