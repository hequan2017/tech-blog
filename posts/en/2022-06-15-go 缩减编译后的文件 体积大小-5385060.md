> **About this post**
>
> This post documents how to shrink the size of a compiled Go binary: pass
> -ldflags "-s -w" to go build to strip symbols and debug information, then
> use upx to compress the executable again, and finally pack it into a tar archive.

> **Technical notes**
>
> `-s` removes the symbol table and `-w` removes DWARF debug information; both
> are Go linker flags that can be used individually or together. After stripping,
> source-level debugging with gdb/delve is no longer possible.
> upx has a high compression ratio and can further reduce the size dramatically,
> but packed binaries are prone to false positives from antivirus software, and
> they must be unpacked at runtime, which adds a slight startup overhead.

---

When building a program with go build, you can pass build options via -ldflags: `-s` strips symbol information, and `-w` strips debug information.

```shell
go build -ldflags "-s -w" main.go
```

Compress it further:

```shell
upx main
```

Finally, pack it into an archive:

```shell
tar zcvf main.tar.gz main
```
