> **About this post**
>
> This post walks through the Linux Filesystem Hierarchy Standard (FHS): the roles of the
> top-level directories under the root directory (/etc, /bin, /usr, /var,
> /proc, /boot, /home, etc.), which directories must stay on the same partition as root, and the
> key files that ops teams deal with most often — network configuration (ifcfg-eth0 / resolv.conf / hosts), accounts and
> permissions (passwd / shadow / sudoers), logs (messages / secure), scheduled jobs, boot-time startup
> (rc.local), and more, plus the basic commands for disk partitioning, formatting, and mounting.

> **Technical notes**
>
> The directory layout has remained largely stable to this day, but note two things: on CentOS 7+ the NIC
> config file name changed from `ifcfg-eth0` to consistent naming such as `ifcfg-ens33`, and versions 8/9 switched to NetworkManager's keyfile format
> (`/etc/NetworkManager/system-connections/`); on newer distributions `/etc/rc.local` needs to
> be given execute permission manually and rc-local.service enabled to take effect — a systemd unit is recommended instead.

## 1. Top-Level Directories at a Glance

Check the root directory structure and block devices:

```shell
tree -L 1 /          # Show the first level of the root directory
ls /dev/sd* -l       # List block devices
cat /etc/fstab       # Show boot-time mount configuration
```

The three most important directories:

- `/` (root): related to the system boot
- `/usr` (unix software resource): related to software installation/execution
- `/var` (variable): related to data that changes while the system is running

### 5 Directories That Must Share a Partition with Root

Required during the boot process, so they **must not be mounted on separate partitions**:

- `/etc`: configuration files and service startup scripts (`/etc/init.d`)
- `/bin`: essential executables (binary commands)
- `/dev`: device files (e.g. `/dev/null`)
- `/lib`: libraries and kernel modules required by executables
- `/sbin`: essential system commands used by the administrator (root)

### Other Common Directories

- `/usr/local`: recommended location for locally compiled software, for easier management
- `/usr/share`: shared documentation and data
- `/usr`: system programs, data, and help files (directory layout similar to `/`)
- `/boot`: kernel and boot files
- `/home`: home directories of regular users
- `/lost+found`: files recovered after an unexpected shutdown
- `/mnt`: temporary mount point
- `/proc`: process and kernel information (virtual filesystem)
- `/tmp`: temporary file directory
- `/var`: frequently changing data (logs, caches, queues, etc.)

Common information files under `/proc`:

```shell
cat /proc/cpuinfo      # CPU information
cat /proc/meminfo      # Memory information
cat /proc/loadavg      # System load
cat /proc/interrupts   # Interrupt information
```

## 2. Disk Partitioning, Formatting, and Mounting

```shell
fdisk -l                       # List disk partitions
mkfs.ext4 /dev/sdb1            # Format as ext4 (note: usually partition with fdisk first, then format the partition)
mount /dev/sdb1 /mnt           # Mount to /mnt
```

> ⚠️ Running `mkfs.ext4 /dev/sdb` directly wipes the entire disk. In production, always partition with `fdisk` / `parted`
> first and verify the device name before proceeding.

## 3. Key Network-Related Files

```shell
/etc/sysconfig/network-scripts/ifcfg-eth0   # NIC configuration (can also be configured with setup)
/etc/resolv.conf                            # DNS configuration
/etc/sysconfig/network                      # Hostname / global network configuration
/etc/hosts                                  # Local name resolution
```

Restart the NIC:

```shell
ifdown eth0 && ifup eth0
```

## 4. Account and Permission Files

```shell
/etc/passwd        # User account information
/etc/group         # User groups
/etc/shadow        # User passwords (encrypted)
/etc/gshadow       # Group passwords
/etc/sudoers       # sudo authorization (edit with visudo)
```

## 5. Logs and Login Auditing

```shell
/etc/rsyslog.conf        # rsyslog logging configuration
/var/log/messages        # General system log
/var/log/secure          # Login/authentication log
last                     # Recent login records
lastlog                  # Last login details for all users
```

## 6. Other Common Files / Directories

```shell
/var/spool/cron              # Directory storing per-user crontabs
/var/spool/clientmqueue      # Temporary mail queue directory
/etc/rc.local                # Commands run at boot
/etc/exports                 # NFS share configuration
/etc/profile                 # Global environment variables
```
