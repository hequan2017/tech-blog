> **About this post**
>
> A minimal example of querying ClickHouse from Go: using the `mailru/dbr` query builder together with the HTTP driver `mailru/go-clickhouse` to open a connection (`http://name:password@host:8123/db`), building a query with `Select(...).From(...).Where(...)` and loading the results into a slice of structs, then looping over them to print the output.

> **Technical notes**
>
> The `mailru/go-clickhouse` repository (HTTP driver) used in this example has been archived and is no longer maintained. The officially recommended Go client is now `github.com/ClickHouse/clickhouse-go` (v2), which supports both the Native (TCP) and HTTP protocols; new projects are advised to migrate to it directly. The import paths in the original post were truncated — they should actually be `github.com/mailru/dbr` and `github.com/mailru/go-clickhouse`, which have been fixed here. The final `log.Printf` statement in the original code was corrupted during scraping (missing a closing quote and an argument) and has been completed as well.

---

```go
package main

import (
  "fmt"
  "log"

  "github.com/mailru/dbr"
  _ "github.com/mailru/go-clickhouse"
)

func main() {
  connect, err := dbr.Open("clickhouse", "http://name:password@192.168.1.2:8123/test", nil)
  if err != nil {
    log.Fatal(err)
  }
  type items struct {
    Test string `json:"test" db:"test"`
  }
  var it []items
  sess := connect.NewSession(nil)

  _, err = sess.Select("test").From("test").Where("test = ?", "test").Load(&it)
  if err != nil {
    fmt.Println(err)
    return
  }

  for _, item := range it {
    log.Printf("test: %s", item.Test)
  }
}
```
