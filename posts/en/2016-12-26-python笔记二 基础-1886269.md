## 1. Everything Is an Object (10/24)

**In Python, everything is an object. Objects are created from classes, and all of an object's functionality is found in its class.**

A variable name = an object (a value) — repeated functionality is wrapped into a class, and objects then reference it.

Integers:

```python
age = 18
print(type(age))
```

The output is `<class 'int'>`; for other types, the class address is shown below.

Common built-in methods:

```python
age.__abs__()          # absolute value

all_item = 95
pager = 10
result = all_item.__divmod__(10)
print(result)          # (9, 5)

age.__add__(7)         # addition
age.__rdivmod__(7)
```

`5/6` vs. `5//6`: true division and floor division, two ways to divide.

The float type offers methods such as `as_integer_ratio`.

Quick reference for common methods:

- `__contains__` containment: `print(name.__contains__('er'))` → `True`
- `capitalize` uppercases the first letter; `casefold` converts to lowercase
- `center` centers a string; `count(self, sub, start=None, end=None)` counts occurrences

```python
print(name.center(40, '*'))
# ******************eric******************
```

- `encode` encodes a string:

```python
name = '何全'
print(name.encode('gbk'))    # b'\xba\xce\xc8\xab'
```

- `expandtabs`: one tab equals 8 spaces

```python
name = 'h\tlex'
print(name.expandtabs())
```

- `find` and `index`: find returns -1 when the substring is not found, while index raises an error
- `format` for formatting:

```python
name = "he {0} is {1}"
print(name.format('a', 'b'))    # he a is b
```

- `join` concatenation:

```python
h = ['h', 'e', 'q', 'u', 'a', 'n']
print(''.join(h))              # hequan
```

- `partition` splits a string
- `replace('a', 'b', 1)` replaces 1 occurrence
- `split` splits by a given character; `rsplit` starts from the right
- `splitlines()` splits by line breaks, equivalent to `split('\n')`
- `swapcase` turns uppercase into lowercase and vice versa

## 4. Sets and the collections Family (10/31)

**set: an unordered collection of non-repeating elements**

```python
s1 = set([11, 22, 33])
s2 = set([22, 44])

ret0 = s1.intersection(s2)           # intersection
ret1 = s1.difference(s2)             # difference
ret2 = s1.symmetric_difference(s2)   # symmetric difference

print(ret0)    # {22}
print(ret1)    # {33, 11}
print(ret2)    # {33, 11, 44}
```

The idea behind these set operations:

```python
update_set = old.intersection(new)                  # intersection
delete_set = old.symmetric_difference(update_set)   # difference
add_set = new.symmetric_difference(update_set)      # newly added part
```

The collections family:

```python
import collections

# Counter: count how many times each character repeats
obj = collections.Counter('sdafsdafsdafsdafsdaf')
print(obj)     # Counter({'f': 5, 'd': 5, 'a': 5, 's': 5})
```

```python
# OrderedDict: ordered dictionary
dic = collections.OrderedDict()
dic['k1'] = ['v1']
dic['k2'] = ['v2']
print(dic)     # OrderedDict([('k1', ['v1']), ('k2', ['v2'])])

# defaultdict: dictionary with a default factory
dic = collections.defaultdict(list)
dic['k1'].append('alex')

# namedtuple: named tuple
mytuple = collections.namedtuple('mytuple', ['x', 'y', 'z'])
obj = mytuple(11, 22, 33)
print(obj.x)   # 11
```
