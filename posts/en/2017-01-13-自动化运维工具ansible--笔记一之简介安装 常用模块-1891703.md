> **About this post**
>
> The first half of these introductory notes on Ansible: it first shows the architecture of SSH-based push management, then demonstrates installation via yum, passwordless login (ssh-copy-id), disabling host_key_checking in ansible.cfg, and group configuration in the hosts inventory. The second half walks through the common modules one by one: command, cron, user, copy, file, service, shell, ping, yum, setup, template, synchronize, and get_url, with an ad-hoc invocation example for each.

> **Technical notes**
>
> The Ansible version used in this post is an early 2.x release. After Ansible 2.9, the community edition was renamed to ansible-core plus collections; module paths changed from `ansible.modules` to `ansible.builtin.*`, and some modules (such as synchronize/get_url) moved into collections. Command-line arguments and module behavior are largely compatible, but the ansible-core documentation should be treated as authoritative.

**Introduction and Installation:**

![Ansible architecture diagram: the control node manages hosts over SSH](../assets/1891703/01_wKioL1h4T_Oz4OcRAAHQU5MdAwM786.png)

```shell
yum -y install ansible
ssh-keygen -t rsa
ssh-copy-id -i .ssh/id_rsa.pub root@192.168.xx.xx
```

```shell
ansible -m  module  -a arguments to pass to the module  -f concurrency -k defaults to key-based auth; use this for password-based authentication -i PATH : path to the host inventory file to use
```

```ini
# vim ansible.cfg
host_key_checking = False
```

```ini
# cat hosts
[web]
192.168.50.101 ansible_ssh_pass=123456
```

**Common Modules:**

- command: the command module (does not support variables or pipes)

```shell
ansible web   -m command -a 'date'
```

- cron: the recurring scheduled-task module

```shell
ansible websrvs -m cron -a 'name="sync time" minute="*/3" job="/usr/sbin/ntpdate  &> /dev/null"'
ansible web   -m cron  -a 'name="sync time" state=absent'   ##delete   present/absent  create/remove
```

- user: manages users (common parameters)

  - name
  - state   present / absent
  - force   also remove the home directory when deleting
  - system   create a system user
  - uid / shell / home

```shell
openssl passwd -1 -salt `openssl rand -hex 4`   # generate the encrypted string
ansible web -m user -a 'name=xx password=$1$1ba6487f$gEZ7LEbftHcJo9lNoWY9p/'
ansible web -m user -a 'name=xx state=absent'
```

- copy: copies files

  - src: path of the local source file
  - content: the destination file is generated directly from the content specified here
  - dest: path of the remote destination file
  - force: when set to yes, if the file already exists on the target host but with different content, it is overwritten. Defaults to yes
  - backup: back up the source file before overwriting, yes/no

```shell
ansible all -m copy -a 'src=/root/test.ansible dest=/tmp/'
ansible all -m copy -a 'src=/root/test.ansible dest=/tmp/  owner=root group=root mode=644 backup=yes'
```

- file: sets file attributes

  - force: needed to force creation of a symlink in two cases: one, the source file does not exist yet but will be created later; two, the destination symlink already exists, so the old link must be removed before creating the new one. Two options: yes|no
  - group: defines the group owner of the file/directory
  - mode: defines the permissions of the file/directory
  - owner: defines the owner of the file/directory
  - path: required; defines the path of the file/directory
  - recurse: set file attributes recursively; only valid for directories
  - src: path of the source file to be linked; only applies to state=link
  - dest: the path being linked to; only applies to state=link
  - state:
    - directory: creates the directory if it does not exist
    - file: the file will not be created even if it does not exist
    - link: creates a symlink
    - hard: creates a hard link
    - touch: creates a new file if it does not exist; if the file or directory already exists, updates its last modification time
    - absent: removes directories or files, or unlinks symlinks

```shell
ansible all -m file -a 'src=/tmp/test.ansible path=/tmp/test.link state=link'
```

- service: controls the running state of services

  - enabled: whether to start automatically at boot   true  false
  - state   state value  started  stopped  restarted  reloaded

```shell
ansible web -m service -a 'name=httpd state=started enabled=true'
```

- shell: copies a local script to the remote host and executes it

```shell
ansible web -m shell -a 'echo $TERM'
```

- ping:

```shell
ansible all -m ping
```

- yum:

  - name
  - state= present, latest: install;  absent: uninstall

```shell
ansible all -m yum -a 'name=httpd  state=absent'
```

- setup: collects the host's facts

```shell
ansible  all -m setup -a 'filter=ansible_eth0'
```

- template: sets variables

```shell
vim /root/httpd.conf
# ...
# ServerName {{ ansible_fqdn }}
ansible websrvs -m template -a 'src=/root/httpd.conf dest=/etc/httpd/conf/httpd.conf'
```

- synchronize: pushes the specified directory

```shell
ansible all -m synchronize -a 'src=/usr/local/src/ dest=/usr/local/src/ delete=yes compress=yes'
```

- get_url: downloads a URL onto the remote host

```shell
ansible all -m get_url -a 'url=http://example.com/pub/epel/6/x86_64/epel-release-6-8.noarch.rpm dest=/tmp'
```
