## 1. Process/Thread Basic Concepts

**Process**

A program cannot run on its own; it only runs once it has been loaded into memory and the system has allocated resources to it, and a program being executed this way is called a process. The difference between a program and a process is: a program is a collection of instructions, a static textual description of how a process runs; a process is one execution activity of a program, a dynamic concept.

**Thread**

A thread is the smallest unit of execution that an operating system can schedule. It is contained within a process and is the unit that actually runs inside it. A thread refers to a single, sequential flow of control within a process; one process can run multiple threads concurrently, with each thread executing a different task in parallel.

## 2. GIL (Global Interpreter Lock)

Direct invocation: 2 threads appear at the same time, in parallel:

```python
import threading
import time


def sayhi(num):  # the function each thread runs
    print("running on number:%s" % num)
    time.sleep(3)


if __name__ == '__main__':
    t1 = threading.Thread(target=sayhi, args=(1,))  # create a thread instance
    t2 = threading.Thread(target=sayhi, args=(2,))  # create another thread instance
    t1.start()  # start the thread
    t2.start()  # start the other thread
    print(t1.getName())  # get the thread name
    print(t2.getName())
```

## 3. Two Ways to Create Threads

Direct invocation is shown in the example above; subclassing:

```python
import threading
import time


class MyThread(threading.Thread):
    def __init__(self, num):
        threading.Thread.__init__(self)
        self.num = num

    def run(self):  # the function each thread runs
        print("running on number:%s" % self.num)
        time.sleep(3)


if __name__ == '__main__':
    t1 = MyThread(1)
    t2 = MyThread(2)
    t1.start()
    t2.start()
```

## 4. Join and Daemon

**Multiple threads calling join**: wait for the threads to finish before moving on.

```python
import threading
import time


def sayhi(num):  # the function each thread runs
    print("running on number:%s" % num)
    time.sleep(3)


if __name__ == '__main__':
    t_list = []
    for i in range(10):
        t = threading.Thread(target=sayhi, args=(i,))  # create a thread instance
        t.start()
        t_list.append(t)
    for i in t_list:
        i.join()  ## wait for the threads to finish
    print('---------main----------')  ## the 3rd thread
```

**Daemon**: a daemon thread exits together with the main thread.

```python
import time
import threading


def run(n):
    print('[%s]------running----\n' % n)
    time.sleep(2)
    print('--done--')


def main():
    for i in range(5):
        t = threading.Thread(target=run, args=[i, ])
        t.start()
        print('starting thread', t.getName())


m = threading.Thread(target=main, args=[])
m.setDaemon(True)  # set the main thread as a Daemon thread: it serves as a daemon of the program's main thread; when the main thread exits, the m thread exits too, and the child threads started by m exit at the same time, whether or not they have finished their tasks
m.start()
m.join(timeout=2)
print("---main thread done----")
```

## 5. Thread Lock (Mutex)

Multiple threads can be started under one process, and multiple threads share the parent process's memory space, which means every thread can access the same data:

```python
import time
import threading


def addNum():
    global num  # get this global variable in each thread
    print('--get num:', num)
    time.sleep(1)
    lock.acquire()  # acquire the lock before modifying the data
    num -= 1  # decrement this shared variable by 1
    lock.release()  # release after the modification


num = 100  # set up a shared variable
thread_list = []
lock = threading.Lock()  # create a global lock

for i in range(100):
    t = threading.Thread(target=addNum)
    t.start()
    thread_list.append(t)

for t in thread_list:  # wait for all threads to finish
    t.join()

print('final num:', num)
```

## 6. RLock (Recursive Lock)

```python
import threading
import time


def run1():
    print("grab the first part data")
    lock.acquire()
    global num
    num += 1
    lock.release()
    return num


def run2():
    print("grab the second part data")
    lock.acquire()
    global num2
    num2 += 1
    lock.release()
    return num2


def run3():
    lock.acquire()
    res = run1()
    print('--------between run1 and run2-----')
    res2 = run2()
    lock.release()
    print(res, res2)


if __name__ == '__main__':
    num, num2 = 0, 0
    lock = threading.RLock()
    for i in range(10):
        t = threading.Thread(target=run3)
        t.start()

    while threading.active_count() != 1:
        print(threading.active_count())
    else:
        print('----all threads done---')

    print(num, num2)
```

## 7. Semaphore

A mutex lock allows only one thread at a time to modify data, while a Semaphore allows a certain number of threads to modify data at the same time:

```python
import threading
import time


def run(n):
    semaphore.acquire()
    time.sleep(1)
    print("run the thread: %s\n" % n)
    semaphore.release()


if __name__ == '__main__':
    num = 0
    semaphore = threading.BoundedSemaphore(3)  # allow at most 3 threads to run at the same time
    for i in range(20):
        t = threading.Thread(target=run, args=(i,))
        t.start()

    while threading.active_count() != 1:
        pass  # print(threading.active_count())
    else:
        print('----all threads done---')

    print(num)
```

## 8. Event

Use Event to coordinate between two or more threads; a traffic light simulation:

```python
import threading
import time
import random


def light():
    if not event.isSet():
        event.set()  # wait() no longer blocks; green light state
    count = 0
    while True:
        if count < 10:
            print('\033[42;1m--green light on---\033[0m')
        elif count < 13:
            print('\033[43;1m--yellow light on---\033[0m')
        elif count < 20:
            if event.isSet():
                event.clear()
            print('\033[41;1m--red light on---\033[0m')
        else:
            count = 0
            event.set()  # turn the green light on
        time.sleep(1)
        count += 1


def car(n):
    while 1:
        # time.sleep(random.randrange(10))
        time.sleep(1)
        if event.isSet():  # green light
            print("car [%s] is running.." % n)
        else:
            print("car [%s] is waiting for the red light.." % n)
            event.wait()


if __name__ == '__main__':
    event = threading.Event()
    light = threading.Thread(target=light)
    light.start()
    for i in range(3):
        t = threading.Thread(target=car, args=(i,))
        t.start()
```

## 9. Multiprocessing and Inter-Process Communication

### Multiprocessing (Process)

```python
from multiprocessing import Process
import os


def info(title):
    print(title)
    print('module name:', __name__)
    print('parent process:', os.getppid())
    print('process id:', os.getpid())
    print("\n\n")


def f(name):
    info('\033[31;1mfunction f\033[0m')
    print('hello', name)


if __name__ == '__main__':
    info('\033[32;1mmain process line\033[0m')
    p = Process(target=f, args=('bob',))
    p.start()
    p.join()
```

### Queues

```python
from multiprocessing import Process, Queue


def f(q):
    q.put([42, None, 'hello'])


if __name__ == '__main__':
    q = Queue()
    p = Process(target=f, args=(q,))
    p.start()
    print(q.get())  # prints "[42, None, 'hello']"
    p.join()
```

### Pipes (rarely used)

```python
from multiprocessing import Process, Pipe


def f(conn):
    conn.send([42, None, 'hello'])
    conn.close()


if __name__ == '__main__':
    parent_conn, child_conn = Pipe()
    p = Process(target=f, args=(child_conn,))
    p.start()
    print(parent_conn.recv())  # prints "[42, None, 'hello']"
    p.join()
```

### Managers

```python
from multiprocessing import Process, Manager


def f(d, l):
    d[1] = '1'
    d['2'] = 2
    d[0.25] = None
    l.append(1)
    print(l)


if __name__ == '__main__':
    with Manager() as manager:
        d = manager.dict()
        l = manager.list(range(5))
        p_list = []
        for i in range(10):
            p = Process(target=f, args=(d, l))
            p.start()
            p_list.append(p)
        for res in p_list:
            res.join()
        print(d)
        print(l)
```

## 10. Process Synchronization and Process Pools

### Process synchronization

```python
from multiprocessing import Process, Lock


def f(l, i):
    l.acquire()
    try:
        print('hello world', i)
    finally:
        l.release()


if __name__ == '__main__':
    lock = Lock()
    for num in range(10):
        Process(target=f, args=(lock, num)).start()
```

### Process pool

```python
from multiprocessing import Process, Pool, freeze_support
import time


def Foo(i):
    time.sleep(2)
    return i + 100


def Bar(arg):
    print('-->exec done:', arg)


if __name__ == '__main__':
    freeze_support()
    pool = Pool(5)
    for i in range(10):
        pool.apply_async(func=Foo, args=(i,), callback=Bar)
        # pool.apply(func=Foo, args=(i,))
    print('end')
    pool.close()
    pool.join()  # close only after the processes in the pool finish; if you comment this out, the program exits immediately
```
