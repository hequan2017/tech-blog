> **About this post**
>
> This post is a collection (part one) of nginx configuration and tuning essentials: it first
> lists nginx's strengths such as high concurrency, low resource consumption, load balancing,
> caching, and async network I/O; then covers splitting virtual hosts into include extra/*.conf
> files and the stub_status status page; error log level choices and custom log_format, plus the
> gzip+buffer form of access_log; a cut_nginx_log.sh script for daily access-log rotation driven
> by crontab, along with purging logs older than 7 days; the three autoindex directives;
> location match modifiers and regex precedence; the permanent/last/break/redirect rewrite flags;
> auth_basic+htpasswd directory authentication, and a closing review of the LNMP request path.

> **Technical notes**
>
> The examples date from the nginx 1.9/1.10 era; location matching and autoindex behavior are
> essentially the same in later versions. PHP 5.x is fully end-of-life; pair PHP 8.x with a
> recent nginx stable branch instead.
> The `worker_processes 1` and `worker_connections 1024` values here are conservative; modern
> practice is `worker_processes auto;` with the connection limit raised per ulimit. In production,
> log rotation is more commonly done with the system's built-in logrotate; stub_status requires
> building with --with-http_stub_status_module (already included in official packages).

## 2. nginx Virtual Hosts

In the main nginx.conf, split each site out into the extra/ directory:

```nginx
worker_processes  1;

events {
    worker_connections  1024;
}

http {
    include       mime.types;
    default_type  application/octet-stream;
    sendfile        on;
    keepalive_timeout  65;

    include  extra/www.conf;
    include  extra/blog.conf;
    include  extra/status.conf;
}
```

`vim ../conf/extra/www.conf`:

```nginx
server {
    listen       80;
    server_name     ;
    location / {
        root   html/www;
        index  index.html index.htm;
    }
}

server {
    listen       80;
    server_name  status.;
    location / {
        stub_status  on;     # turn on the status info switch
        access_log  off;
    }
}
```

(Note: the domain characters in the two server_name directives above were lost when the original was scraped.)

## 3. nginx Logs

Error log, official documentation <http://nginx.org/en/docs/ngx_core_module.html#error_log>:

```nginx
# keyword  log file  level: usually warn|error|crit; crit logs the fewest error details
error_log    logs/error.log     error;
error_log    /dev/null   crit;           # disable error logging
```

Access log, <http://nginx.org/en/docs/http/ngx_http_log_module.html>:

```nginx
log_format  main  '$remote_addr - $remote_user [$time_local] "$request" '
                  '$status  $body_bytes_sent  "$http_referer" '
                  '"$http_user_agent" "$http_x_forwarded_for"';

# valid in http, server, location, if in location, limit_except
access_log logs/access.log main  gzip  buffer=32k   flush=5s;
```

## 4. Log Rotation

Script-based rotation: rename the nginx log to a new date-stamped file, then gracefully reload nginx so a fresh log is generated.

`vim cut_nginx_log.sh`:

```shell
#!/bin/sh
Dateformat=`date +%Y%m%d`
Basedir="/application/nginx"
Nginxlogdir="$Basedir/logs"
Logname="access"

[ -d $Nginxlogdir ] && cd $Nginxlogdir || exit 1
[ -f ${Logname}.log ] || exit 1
/bin/mv ${Logname}.log ${Logname}_${Dateformat}.log
$Basedir/sbin/nginx  -s reload
```

Add a cron job that runs daily at midnight:

```shell
cat >> /var/spool/cron/root <<EOF
#cut  nginx   access log by hequan
00 00 * * *  /bin/sh  /hequan/sh/cut_nginx_log.sh >/dev/null  2>&1
EOF
```

Additionally, delete logs older than 7 days:

```shell
find . -mtime +7 -name "20[1-9][1-9]*" | xargs rm -f
```

## 5. Enabling Directory Listing (autoindex)

By default nginx serves its welcome page, i.e. the /nginx/html/index.html file. To show every file under the /html/ directory, you need to enable directory listing; just add a block of configuration to the http or location context in the main nginx.conf:

```nginx
http {
    include       mime.types;
    default_type  application/octet-stream;

    autoindex on;
    autoindex_exact_size off;
    autoindex_localtime on;
}
```

- `autoindex on;` lists directories automatically
- `autoindex_exact_size off;` defaults to on, showing exact file sizes in bytes; when set to off, approximate sizes in kB, MB, or GB are shown
- `autoindex_localtime on;` defaults to off, showing file times in GMT; when set to on, the file times shown are the server's local time

## 6. location Matching Rules

A location is: match modifier + the site URL to match + the configuration block executed once the URI matches:

- `~` case-sensitive
- `~*` case-insensitive
- `^~` after a regular match, skip regex checking

```nginx
location  ^~   /images/ {
    return  404;
}

location  ~*  \.(gif|jpg|jpeg)$  {    # regex match
    return 500;
}

location = / {}              # exact match
location  /documents/ {}     # regular string match; if regexes exist, they are checked first
location / {}                # fallback when no other location matches
```

## 7. URL Rewriting with nginx rewrite

```nginx
server    ;
rewrite   ^/(.*)  http:///$1  permanent;    # $1=(.*)
```

`permanent` is the permanent 301 redirect flag; with `last`, matching continues downward after a match; `break` stops once the configuration is applied; `redirect` returns a 302 temporary redirect.

## 8. Access Authentication (auth_basic)

```nginx
location  / {
    auth_basic               "Prompt text";
    auth_basic_user_file     conf/htpasswd;
}    # the password file can be generated with Apache's htpasswd
```

```shell
yum -y install httpd-tools
htpasswd   -c  -m /application/nginx/conf/htpasswd  hequan
```
