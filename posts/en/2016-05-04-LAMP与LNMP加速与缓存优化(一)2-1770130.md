> **About this post**
>
> This post is the second half of Part 1 of the series, continuing to compile and install three PHP extensions: the memcache client plugin (paired with the server-side memcached for database caching, compiling memcache-2.2.5), PDO_MYSQL-1.0.2 (connecting to the local MySQL via --with-pdo-mysql), and the imagick-2.3.0 PHP extension, which is compiled after first installing the ImageMagick-6.5.1-2 image library (on CentOS 6.5 you must first yum install perl-devel, otherwise an error occurs). All of them follow the standard phpize + configure + make install flow; the packages can be downloaded from the cloud-drive links in this post.

> **Technical notes**
>
> CentOS 6 reached end of life (EOL) in November 2020; for production environments, migrating to Rocky Linux / AlmaLinux / Ubuntu LTS is recommended.
> Note: memcache-2.2.5 is incompatible with PHP 7+; newer environments should use the 3.x branch or switch to php-memcached.
> In later PHP versions, PDO_MYSQL ships with the PHP source itself: just add --with-pdo-mysql when compiling PHP, with no need to install 1.0.2 separately. ImageMagick/imagick can now be installed directly via yum/dnf. The Baidu cloud-drive links in this post may no longer be valid.

## 1. Installing the memcache client extension

The memcache database caching extension comes in two parts: the **server-side memcached** and the **client plugin memcache**; here we install the client plugin. The software can be downloaded from this [cloud drive](http://pan.baidu.com/s/1qYDwiDI).

```shell
tar xf memcache-2.2.5.tgz
cd memcache-2.2.5

/application/php/bin/phpize

./configure --with-php-config=/application/php/bin/php-config

make && make install

ls /application/php5.3.27/lib/php/extensions/no-debug-zts-20090626/
```

## 2. Installing the PDO_MYSQL extension

```shell
tar zxvf PDO_MYSQL-1.0.2.tgz
cd PDO_MYSQL-1.0.2

/application/php/bin/phpize

./configure --with-php-config=/application/php/bin/php-config \
    --with-pdo-mysql=/application/mysql

make && make install
```

After the installation completes, `pdo_mysql.so` is generated.

## 3. Installing ImageMagick

First install this software (it provides the underlying C libraries for imagick):

```shell
tar zxf ImageMagick.tar.gz
cd ImageMagick-6.5.1-2/

./configure

yum -y install perl-devel    # Install this package, otherwise 6.5 reports errors

make && make install
```

## 4. Installing the imagick extension

```shell
tar zxf imagick-2.3.0.tgz
cd imagick-2.3.0

/application/php/bin/phpize

./configure --with-php-config=/application/php/bin/php-config

make

make install
```
