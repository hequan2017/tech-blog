> **About this post**
>
> The author uses gopsutil to collect network interface traffic on a schedule:
> first save the cumulative bytes sent/received for the current minute
> (skipping lo and docker0), then subtract the records from 60~300 seconds
> earlier stored in the database, and convert the difference over the time
> interval into each interface's upload/download speed (Mbps).

> **Technical notes**
>
> On Linux, gopsutil's `net.IOCounters(pernic=true)` reads
> `/proc/net/dev`, whose BytesSent/BytesRecv are the cumulative byte counts
> since boot and contain no rate information by themselves. This post
> computes the rate from the delta "current value - historical value,
> divided by the interval in seconds", multiplies by 8 to convert to bits,
> then divides by 1 million to get Mbps. The calculation is performed only
> when the current counter is larger, which avoids negative deltas caused
> by counters resetting to zero after a reboot.

---

First save the traffic data for the current minute, then subtract the data saved one minute earlier; the difference is the network speed for the current minute.

## 1. Save the traffic data for the current minute

Call gopsutil's `IOCounters(true)` to get the cumulative bytes sent/received for each interface,
skip `lo` and `docker0`, and assemble a record together with the timestamp, hostname, and so on:

```go
IOCountersStat, _ := gopsutil.IOCounters(true)
    loc, _ := time.LoadLocation("Asia/Shanghai")
    now := time.Now()
    NewNow := now.In(loc).Format("2006-01-02 15:04:00")
    NewDt, _ := time.ParseInLocation("2006-01-02 15:04:05", NewNow, loc)
    NewDtNumber := NewDt.Unix()

    var data []Net
    for _, v := range IOCountersStat {
        if v.Name == "lo" || v.Name == "docker0" {
            continue
        }
        var d Net
        d.Time = uint64(NewDtNumber)
        d.Hostname = name
        d.Machineid = machineid
        d.BytesSent = v.BytesSent
        d.BytesRecv = v.BytesRecv
        d.PName = v.Name
        d.IsUpdate = false
        data = append(data, d)
    }
```

## 2. Compute the network speed by subtracting historical records

Look backward step by step starting from 60 seconds (60/120/180/240/300 seconds). Once a record
from t seconds ago is found in the database, subtract the historical value from the current
cumulative value to get the delta over that period, divide by the interval in seconds, then
multiply by 8 to convert to bits, yielding the speed in Mbps (rounded to two decimal places):

```go
timeList := []int64{60, 120, 180, 240, 300}

    for _, t := range timeList {
        var readPppData []Net
        _ = db.Find(&readPppData, "time = ?", NewDtNumber-t)
        if len(readPppData) == 0 {
            continue
        } else {
            for _, v := range readPppData {
                if v.Time == uint64(NewDtNumber-t) {
                    for i, v1 := range data {
                        if v.PName == v1.PName {
                            if data[i].BytesSent > v.BytesSent {
                                data[i].Outbytes = data[i].BytesSent - v.BytesSent
                                out, _ := strconv.ParseFloat(fmt.Sprintf("%.2f", float64(data[i].BytesSent-v.BytesSent)/float64(t)/1000/1000*8), 64)
                                data[i].Outflow = out
                            }
                            if data[i].BytesRecv > v.BytesRecv {
                                data[i].Inbytes = data[i].BytesRecv - v.BytesRecv
                                in, _ := strconv.ParseFloat(fmt.Sprintf("%.2f", float64(data[i].BytesRecv-v.BytesRecv)/float64(t)/1000/1000*8), 64)
                                data[i].Inflow = in
                            }
                        }
                    }
                }
            }
            return data
        }
    }
```
