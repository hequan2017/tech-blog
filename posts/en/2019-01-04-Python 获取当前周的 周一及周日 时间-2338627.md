> **About this post**
>
> Use the Python standard library `datetime` to compute the dates of Monday and Sunday of the current week: use `weekday()` to find out what day of the week it is, then step backward or forward one day at a time with `timedelta` until reaching Monday and Sunday. Suitable for computing time boundaries in scenarios such as weekly report statistics and per-week data queries.

---

```python
import datetime

def get_current_week():
    monday, sunday = datetime.date.today(), datetime.date.today()
    one_day = datetime.timedelta(days=1)
    while monday.weekday() != 0:
        monday -= one_day
    while sunday.weekday() != 6:
        sunday += one_day

    return monday, sunday

print(get_current_week())
```
