> **About this post**
>
> This post documents the full process of building and installing Inception, a MySQL audit tool, on CentOS 7.4:
> after installing the build dependencies, it installs m4 1.4.18 and bison 2.4 from source (the system's bundled
> bison must be removed first), downloads the inception source code and builds it with inception_build.sh; it then
> writes inc.cnf (audit rules such as port 6669, the backup database, and OSC parameters), starts it with nohup, and
> verifies it with the mysql client via `inception get variables`. It also covers the python3 adaptation: since
> pymysql is incompatible with the version string returned by Inception, server_version must be faked in
> connections.py, and an example script for auditing a CREATE TABLE statement is provided along with two audit
> outputs (warnings such as table already exists, missing primary key/comment/non-null default value, etc.).

> **Technical notes**
>
> 1. CentOS 7 reached end of maintenance (EOL) in June 2024; production environments are advised to migrate to Rocky Linux / AlmaLinux / Ubuntu LTS.
> 2. The Inception project has long been unmaintained and its GitHub repository is archived; for new projects,
>    consider actively maintained SQL audit platforms such as Yearning / Archery instead.
> 3. Two links in the original post had their domains swallowed; they have been restored to github.com. A stray
>    garbled character "f" left at the beginning of the body has been removed; the bison build steps were
>    truncated, and `make && make install` has been added following the same three-step sequence as m4.

## 1. System environment setup

On a CentOS 7.4 system, set up the environment:

```bash
yum install cmake   ncurses-devel gcc gcc-c++  openssl-devel
yum  remove bison -y
```

## 2. Build and install m4 and bison

```bash
cd /usr/local/src/
wget http://ftp.gnu.org/gnu/m4/m4-1.4.18.tar.gz
tar -zxvf m4-1.4.18.tar.gz
cd m4-1.4.18
./configure && make && make install

wget  http://ftp.gnu.org/gnu/bison/bison-2.4.tar.gz
tar -zxvf bison-2.4.tar.gz
cd bison-2.4/
./configure && make && make install
```

## 3. Build Inception

```bash
cd /usr/local/
wget https://github.com/mysql-inception/inception/archive/master.zip
unzip master.zip
mv inception-master/  inception
mv master.zip inception.zip
mv inception.zip   /usr/local/src/
sh inception_build.sh builddir  linux
```

## 4. Configuration file

`vim inc.cnf`:

```ini
[inception]
general_log=1
general_log_file=inception.log
port=6669
socket=/tmp/mysql.sock
character-set-client-handshake=0
character-set-server=utf8
inception_remote_system_password=root
inception_remote_system_user=123456
inception_remote_backup_port=3306
inception_remote_backup_host=127.0.0.1
inception_support_charset=utf8mb4
inception_enable_nullable=0
inception_check_primary_key=1
inception_check_column_comment=1
inception_check_table_comment=1
inception_osc_min_table_size=1
inception_osc_bin_dir=/data/temp
inception_osc_chunk_time=0.1
inception_enable_blob_type=1
inception_check_column_default_value=1
```

## 5. Start and test

```bash
nohup    /usr/local/inception/builddir/mysql/bin/Inception  --defaults-file=inc.cnf   >/dev/null  2>&1   &

mysql -uroot -h127.0.0.1 -P6669

inception get variables;
```

The installation test is complete.

## 6. python3 adaptation (pymysql)

Since the pymysql module used by python3 does not support the server information returned by Inception, you need to edit /path/to/python3/lib/python3.4/site-packages/pymysql/connections.py:

Add the following line before `if int(self.server_version.split('.', 1)[0]) >= 5:` and save; remember to indent with 4 spaces instead of the Tab key:

```python
self.server_version = '5.6.24-72.2-log'
```

## 7. Example audit script

```python
#/usr/bin/python
#_*_ coding:utf-8  _*_
import pymysql.cursors
sql='/*--user=root;--password=123456;--host=192.168.10.81;--execute=1;--port=3306;*/\
inception_magic_start;\
use hequan;\
CREATE TABLE adaptive_office(id int);\
inception_magic_commit;'
try:
    conn=pymysql.connect(host='127.0.0.1',user='',passwd='',db='',port=6669)
    cursor=conn.cursor()
    cursor.execute(sql)
    results = cursor.fetchall()
    column_name_max_size=max(len(i[0]) for i in cursor.description)
    row_num=0
    for result in results:
        row_num=row_num+1
        print('*'.ljust(27,'*'),row_num,'.row', '*'.ljust(27,'*'))
        row = map(lambda x, y: (x,y), (i[0] for i in cursor.description), result)
        for each_column in row:
            if each_column[0] != 'errormessage':
                print(each_column[0].rjust(column_name_max_size),":",each_column[1])
            else:
                print(each_column[0].rjust(column_name_max_size),':',each_column[1].replace('\n','\n'.ljust(column_name_max_size+4)))
    cursor.close()
    conn.close()
except pymysql.Error as e:
     print("Mysql Error %d: %s" % (e.args[0], e.args[1]))
```
