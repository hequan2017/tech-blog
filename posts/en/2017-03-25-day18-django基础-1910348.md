## 1. JS regex: test and exec

`test` — checks whether a string matches a given regex; returns true if it does:

```javascript
rep = /\d+/;
rep.test("asdfoiklfasdf89asdfasdf")     // true, the string contains digits

rep = /^\d+$/;
rep.test("asdfoiklfasdf89asdfasdf")     // false, not purely numeric (source wrongly said true; corrected)
```

`exec` — extracts the matched data:

```javascript
str = "wangshen_67_houyafa_20"
rep = /\d+/;
rep.exec(str)
// ["67"]

// JavaScript is more fun than Java or JavaBeans!
var pattern = /\bJava(\w*)\b/;
// ["JavaScript", "Script"]

// global flag g: each exec continues from the last match position
// JavaScript is more fun than Java or JavaBeans!
var pattern = /\bJava\w*\b/g;
// returns in sequence: ["JavaScript"]  ["Java"]  ["JavaBeans"]  null

// JavaScript is more fun than Java or JavaBeans!
var pattern = /\bJava(\w*)\b/g;
// returns in sequence: ["JavaScript",'Script']  ["Java", ""]  ["JavaBeans", "Beans"]  null
```

Multi-line matching: matching is multi-line by default, with `^$`.

## 4. Django installation and project structure

```shell
pip3 install django            # after install, the scripts are in C:\Python35\Scripts
cd /d d:\Python\www
c:\Python35\Scripts\django-admin.exe startproject hello   # create a Django project
# django-admin startproject [project-name]
```

Project directory:

- mysite: configuration for the whole program
  - settings: configuration file
  - url: URL mappings
  - wsgi: follows the WSGI spec, uwsgi + nginx
- manage.py: manages the Django program

```shell
python manage.py startapp xx             # create an app
python manage.py makemigrations          ### generate the database
python manage.py migrate
python manage.py runserver 127.0.0.1:8001    # run Django
```

Using chouti ("drawer") as an example, a single project can contain at the same time: the
configuration, a main-site app, and a back-end admin app:

```shell
python manage.py startapp cmdb
python manage.py startapp openstack
python manage.py startapp xxoo....
```

Purpose of each file in an app directory:

| File | Purpose |
|------|------|
| migrations | records of data/schema changes |
| admin | the admin back end provided by Django |
| apps | configures the current app |
| models | ORM: write the specified classes; the database structure can be created via commands |
| tests | unit tests |
| views | business code |

## 6. Eight-step development outline

1. Create a Django project: `django-admin startproject project_name`

2. Create an APP:

```shell

python manage.py startapp cmdb
```

```python

    os.path.join(BASE_DIR, "static"),
```

```python
from cmdb.views import login, index
```

## 7. Template language

```python
from django.shortcuts import render, redirect
```

{{ variable name }}:

```python
def func(request):
    return render(request, "index.html", {'current_user': "alex"})
```

index.html:

```html
<html>
<body>
    <div>{{ current_user }}</div>
</body>
</html>
```

====> The final generated string:

```html
<html>
<body>
    <div>alex</div>
</body>
</html>
```

For loop:

```python
def func(request):
    return render(request, "index.html",
                  {'current_user': "alex", 'user_list': ['alex', 'eric']})
```

```html
<html>
<body>
    <div>{{ current_user }}</div>
    <ul>
        {% for row in user_list %}
            {% if row == "alex" %}
                <li>{{ row }}</li>
            {% endif %}
        {% endfor %}
    </ul>
</body>
</html>
```

Indexing:

```python
def func(request):
    return render(request, "index.html", {
        'current_user': "alex",
        'user_list': ['alex', 'eric'],
        'user_dict': {'k1': 'v1', 'k2': 'v2'}})
```

```html
<html>
<body>
    <div>{{ current_user }}</div>
    <a> {{ user_list.1 }} </a>
    <a> {{ user_dict.k1 }} </a>
    <a> {{ user_dict.k2 }} </a>
</body>
</html>
```

Conditionals:

```python
def func(request):
    return render(request, "index.html", {
        'current_user': "alex",
        "age": 18,
        'user_list': ['alex', 'eric'],
        'user_dict': {'k1': 'v1', 'k2': 'v2'}})
```

```html
<html>
<body>
    <div>{{ current_user }}</div>
    {% if age %}
        <a>Has an age</a>
        {% if age > 16 %}
            <a>Old man</a>
        {% else %}
            <a>Fresh meat</a>
        {% endif %}
    {% else %}
        <a>No age</a>
    {% endif %}
</body>
</html>
```
