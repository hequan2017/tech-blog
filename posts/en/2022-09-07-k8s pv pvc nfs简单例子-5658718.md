> **About this post**
>
> This post walks through the complete workflow of using NFS as persistent storage in Kubernetes: installing nfs-utils and configuring /etc/exports on the storage node, verifying and mounting the shared directory from every node via showmount, and finally providing YAML examples of PV, PVC, and Pod to demonstrate static provisioning.
>
> **Technical notes**
>
> The PV in this post uses the `hostPath` type, which is only suitable for single-node testing; in production, use the `nfs` volume type instead, or pair it with nfs-subdir-external-provisioner for dynamic provisioning. The `Recycle` reclaim policy has been deprecated since Kubernetes 1.20+; use `Retain` or `Delete` instead.

---

yum install -y nfs-utils  rpcbind

Storage node:
vim /etc/exports
/data1 192.168.100.0/24(rw,async,no_root_squash,no_all_squash)
mkdir -p /data1

systemctl start rpcbind
systemctl enable rpcbind

exportfs  -arv

All nodes
showmount -e 192.168.209.128

systemctl start nfs-server.service
systemctl enable nfs-server.service

mount -t nfs 192.168.209.128:/data1 /data1

```shell
pvc _test.yaml

apiVersion: v1
kind: PersistentVolume
metadata:
  name: task-pv-volume
  labels:
    type: local
spec:
  storageClassName: manual
  capacity:
    storage: 10Gi
  accessModes:
    - ReadWriteOnce
  persistentVolumeReclaimPolicy: Recycle
  hostPath:
    path: "/data1"

---

apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: task-pv-claim
spec:
  storageClassName: manual
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 3Gi

---

apiVersion: v1
kind: Pod
metadata:
  name: task-pv-pod
spec:
  volumes:
    - name: task-pv-storage
      persistentVolumeClaim:
        claimName: task-pv-claim
  containers:
    - name: task-pv-container
      image: nginx
      ports:
        - containerPort: 80
          name: "http-server"
      volumeMounts:
        - mountPath: "/usr/share/nginx/html"
          name: task-pv-storage
```
