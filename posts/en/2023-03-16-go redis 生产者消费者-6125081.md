> **About this post**
>
> This article demonstrates a Redis Pub/Sub based "producer-consumer" in Go:
> the producer goroutine publishes 1000 messages to the queue:message channel in a loop;
> the consumer subscribes to that channel with Subscribe and keeps receiving and printing messages from Channel();
> the full example code is attached at the end, based on github.com/go-redis/redis/v8.

> **Technical notes**
>
> Although the example is named producer-consumer, it actually uses Pub/Sub: message delivery is "fire-and-forget" — messages are only delivered to subscribers that are online at publish time, are not persisted, and come with no acknowledgment or retry. Messages are lost if a subscriber is offline or drops mid-way, so this is not suitable as a reliable queue.
> The idiomatic way to build a reliable queue is List's LPUSH + BRPOPLPUSH (blocking pop with an atomic write to a backup queue, so unfinished work can be recovered from the backup after a crash). On Redis 5.0+ you can also use Streams instead (XADD/XREADGROUP, which support consumer groups and ACK).
> The outer for{} in the consumer re-subscribes after the subscription drops (Channel() is closed), so consumption continues.
> Since v8, go-redis's module path is github.com/go-redis/redis/v8 and all commands require an explicit context; v9 has moved to github.com/redis/go-redis/v9.

## 1. Complete Example Code

```go
package main

import (
    "context"
    "github.com/go-redis/redis/v8"
    "log"
)

var ctx = context.Background()

func ProducerMessageList(rdb *redis.Client, queueListKey string) {
    for i := 0; i < 1000; i++ {
        _, err := rdb.Publish(ctx, queueListKey, i).Result()
        if err != nil {
            log.Println(err)
        }
    }
}

func ConsumerMessageList(rdb *redis.Client, queueListKey string) {
    for {
        pubSub := rdb.Subscribe(ctx, queueListKey)
        ch := pubSub.Channel()
        for msg := range ch {
            log.Printf("consumed data, channel:%s; message:%s\n", msg.Channel, msg.Payload)
        }
    }
}

func main() {

    rdb := redis.NewClient(&redis.Options{
        Addr:     "192.168.117.129:6379",
        Password: "foobared", // no password set
        DB:       0,          // use default DB
    })
    // Check whether the connection succeeds
    _ = rdb.Ping(context.Background()).Err()

    go ProducerMessageList(rdb, "queue:message")

    ConsumerMessageList(rdb, "queue:message")

}
```
