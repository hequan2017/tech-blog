> **About this post**
>
> This post records a one-click installation and deployment of Tomcat 8 on Linux: first download JDK 8 from the Oracle website (you need to click through to accept the license agreement), extract it to /usr/local/jdk8.0, and write JAVA_HOME, JAVA_BIN, PATH, and CLASSPATH into /etc/profile; then download apache-tomcat-8.0.46 from the Tsinghua mirror, extract it to /usr/local/tomcat8.0 and create the symlink /usr/local/tomcat, append CATALINA_HOME, grant execute permissions on the scripts, and start it with startup.sh — the whole process runs through in one go.

> **Technical notes**
>
> Tomcat 8.0 ended maintenance in June 2018, and 8.5 reached EOL at the end of March 2024; for production environments, Tomcat 9/10 is recommended instead. Older release packages can be obtained from archive.apache.org — the Tsinghua mirror no longer carries 8.0.46. Oracle JDK 8 now requires signing in with an account to download, and its production use is restricted by licensing terms; OpenJDK (e.g., Adoptium Temurin) can be used as a replacement. Note: in the original text, the redirect target at the end of the `echo "CATALINA_HOME=..." >>` line was swallowed; it has been completed as `>> /etc/profile`.

---

## 1. JDK 8 Installation and Environment Variables

```bash
wget http://www.oracle.com/technetwork/java/javase/downloads/jdk8-downloads-2133151.html  ## go to the page, click to accept the agreement, and download JDK 8

tar zxvf jdk-8u144-linux-x64.tar.gz

mv jdk1.8.0_144/   /usr/local/jdk8.0

echo "JAVA_HOME=/usr/local/jdk8.0
JAVA_BIN=/usr/local/jdk8.0/bin
PATH=$PATH:$JAVA_BIN
CLASSPATH=$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar
export JAVA_HOME JAVA_BIN PATH CLASSPATH " >> /etc/profile

source /etc/profile
```

## 2. Tomcat 8 Installation and Startup

```bash
wget http://mirrors.tuna.tsinghua.edu.cn/apache/tomcat/tomcat-8/v8.0.46/bin/apache-tomcat-8.0.46.tar.gz

tar zxvf apache-tomcat-8.0.46.tar.gz

mv apache-tomcat-8.0.46  /usr/local/tomcat8.0

ln -s /usr/local/tomcat8.0/ /usr/local/tomcat

cd /usr/local/tomcat/bin/

echo "CATALINA_HOME=/usr/local/tomcat8.0/"  >> /etc/profile

chmod +x   *.sh

./startup.sh
```
