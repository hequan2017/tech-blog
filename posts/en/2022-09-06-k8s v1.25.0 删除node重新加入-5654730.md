> **About this post**
>
> This post demonstrates how to rejoin a node after it has been deleted from a Kubernetes v1.25 cluster: on the master node, generate a new token with `kubeadm token create` and compute the CA certificate hash, then run `kubeadm join` on the target node with the new token and hash to complete registration.
>
> **Technical notes**
>
> Tokens expire after 24 hours by default; if you forget to save the token, you can recreate it on the master. In production, use proper hash verification instead of `kubeadm join --discovery-token-unsafe-skip-ca-verification` to prevent man-in-the-middle attacks.

---

#### Master node

```shell
kubeadm token create
kubeadm token list
openssl x509 -pubkey -in /etc/kubernetes/pki/ca.crt | openssl rsa -pubin -outform der 2>/dev/null | openssl dgst -sha256 -hex | sed 's/^.* //'
```

#### Worker node

```shell
kubeadm join 192.168.209.128:6443 --token ydt239.zdza2unu6nj2wdou \
    --discovery-token-ca-cert-hash sha256:18d09ae702b558269aa4f0fe901b0cac1a9b78e0dd9d9e5c1b3f3899632a2cd7
```
