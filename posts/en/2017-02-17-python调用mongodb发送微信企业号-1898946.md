> **About this post**
>
> A small Python 2 utility: it first takes two fields from the first record in a MongoDB collection and assembles them into a text message, then calls the WeChat Enterprise Account API (gettoken + message/send) to push it to designated members. A `Weixin` class wraps two methods: fetching the access_token and sending a text message.

> **Technical notes**
>
> The code uses Python 2 syntax (the `print` statement, `except Exception, e`, `sys.setdefaultencoding`). Python 2 reached end of maintenance in January 2020; migrating to Python 3 requires switching to the `print()` function and the `except ... as` syntax. In addition, the "WeChat Enterprise Account" has since been upgraded and renamed to "WeCom": the API domain and some parameters (such as the agentid type) have changed, so adjust accordingly against the latest WeCom documentation.

class Weixin(object):

        self.token_url = 'https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid=%s&corpsecret=%s' %(corp_id, corp_secret)
        self.send_url = 'https://qyapi.weixin.qq.com/cgi-bin/message/send?access_token='
    def get_token(self):
        try:
            r = requests.get(self.token_url, timeout=10)
        except Exception as e:
            print e
            sys.exit(1)
        if r.status_code == requests.codes.ok:
            data = r.json()
            if data.get('errcode'):
                print data['errmsg']
                sys.exit(1)
            return data['access_token']
        else:
            print r.status_code
            sys.exit(1)
    def send(self,message):
        url = self.send_url + self.get_token()
        data = {
           "touser": "hequan2011",
           "msgtype": "text",
           "agentid": "0",
           "text": {
               "content": message
           },
           "safe":"0"
        }
        send_data = json.dumps(data,ensure_ascii=False)
        try:
            r = requests.post(url, send_data)
        except Exception, e:
            print e
            sys.exit(1)
        if r.status_code == requests.codes.ok:
            print r.json()
        else:
            print r.code
