> **About this post**
>
> This post records the entire process of a single-node minikube deployment as a command checklist:
> downloading and installing minikube and kubectl, creating a test user and adding it to the docker group;
> starting the cluster with China mirror parameters and enabling the ingress and dashboard addons;
> accessing the Dashboard via kubectl proxy and port-forward, and deploying httpbin as a test.

> **Technical notes**
>
> Viewed from a 2026 perspective, parts of this content have become dated:
>
> - minikube and Kubernetes iterate quickly; kubectl should stay within ±1 minor version of the cluster
>   version. The official kubectl download now recommends dl.k8s.io; storage.googleapis.com in this post
>   is the legacy address.
> - minikube uses the docker driver by default (Docker must already be installed on the host); the China
>   mirror parameter --image-mirror-country='cn' still works, but mirror sources change from time to time.
>   If image pulls fail, switch to --image-repository (e.g., the Aliyun google_containers mirror).
> - Newer Kubernetes versions use containerd as the default container runtime; operations such as the
>   docker group in this post only apply to the docker driver scenario.

## 1. Install minikube and kubectl

```shell
curl -Lo minikube https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64 && chmod +x minikube && sudo mv minikube /usr/local/bin/

curl -LO https://storage.googleapis.com/kubernetes-release/release/$(curl -s https://storage.googleapis.com/kubernetes-release/release/stable.txt)/bin/linux/amd64/kubectl
chmod +x ./kubectl
sudo mv ./kubectl /usr/local/bin/kubectl
```

## 2. Create a user and start the cluster

```shell
useradd test
sudo usermod -a -G docker test
newgrp docker
echo "1" >/proc/sys/net/bridge/bridge-nf-call-iptables

su test
minikube start --image-mirror-country='cn'
minikube addons enable ingress
minikube dashboard
```

## 3. Access the Dashboard

```shell
kubectl cluster-info

minikube ssh
docker ps

kubectl get svc,pods -n kubernetes-dashboard

kubectl proxy --address='0.0.0.0' --accept-hosts='^*$' --port=8009
```

Access it from a browser through the proxy above:

```text
http://192.168.209.128:8009/api/v1/namespaces/kubernetes-dashboard/services/http:kubernetes-dashboard:/proxy/#/workloads?namespace=default
```

## 4. Deploy the httpbin test service

```shell
kubectl create deployment httpbin --image=kennethreitz/httpbin:1.0
kubectl describe deployment httpbin

kubectl expose deployment httpbin --type=ClusterIP --port=80
kubectl describe service httpbin
```

## 5. Cluster status and port forwarding

```shell
minikube start
minikube status

kubectl proxy --address='0.0.0.0' --accept-hosts='^*$' --port=8009 &
kubectl port-forward service/nginx-service 8080:80 -n ns-test --address='0.0.0.0' &
```
