> **About this post**
>
> A minimal example of building a callback service for a WeChat Enterprise account with Python3 and the itchatmp framework: enable callback mode in the admin console to obtain the four credentials (Token/EncodingAESKey/CorpID/AppSecret) and write them into the itchatmp configuration; register a TEXT message handler that checks whether the user's message matches a specified name and replies with "Name: xxx"; finally, it demonstrates how to change the port (8888) and open the iptables firewall.

> **Technical notes**
>
> The "WeChat Enterprise Account" has been upgraded to "WeCom", and the callback configuration and API parameters have changed; the itchatmp framework has not been maintained for years, so for production environments the official WeCom callback SDK or wechatpy is recommended. `iptable` is a typo; the correct command is `iptables`.

1 I will skip the steps for registering a WeChat Enterprise account. It is very simple.

Select the App Center below, choose Enterprise Assistant, and select callback mode.

![WeChat Enterprise account admin console with callback mode enabled for the app](../assets/1899902/01_wKiom1iuTvGi6RgbAADSZJAhRuw490.png)

Choose to randomly generate the token and AES key. For the URL, enter your server address.

![WeChat Enterprise account callback URL and key configuration page, with Token and encryption key](../assets/1899902/02_wKioL1iuTz-guhB2AAAaoyDCnOE021.jpg)

Go to Settings, create a new management group, and then you will see the CorpID and Secret.

![WeChat Enterprise account permission management page, with red arrows marking the CorpID and Secret](../assets/1899902/03_wKioL1iuT86R-cgbAACR53Vm9FU959.jpg)

Write the four parameters above into the following file.

Install the dependency (see the official itchatmp documentation for details):

```shell
python3 -m pip  install  itchatmp    ###install the module with python3
```

```python
# vim main.py

import itchatmp
from itchatmp.content import TEXT
itchatmp.update_config(itchatmp.WechatConfig(
    token='xxxxxxxxxxxx',
    copId = 'xxxxxxxxxxxxx',
    appSecret = 'xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx',
    encryptMode=itchatmp.content.SAFE,
    encodingAesKey='xxxxxxxxxxxxxxxxxxxxxxxxxxxx',))

i='何全'
@itchatmp.msg_register(itchatmp.content.TEXT)
def text_reply(msg):
    if msg['Content'] == i :
         msg['Content'] = '姓名:{}'.format(i)
         return msg['Content']
    else:
         print(23333)
itchatmp.run()
```

```shell
python  main.py  ##run the test....
```

Change the port number and open the firewall:

```python
itchatmp.run(port=8888)
```

```shell
# Remember to modify the firewall; I got tripped up by this. The WeChat callback mode supports x.x.x.x:8888
iptables -A INPUT -p tcp -m tcp --dport 8888 -j ACCEPT
```

Result:

When the WeChat Enterprise account receives the message `何全` (Hequan), it returns `姓名:何全` (Name: Hequan).
