> **About this post**
>
> This post records a DingTalk approval script that can be embedded into a
> Jenkins build pipeline: at build time it first sends an actionCard message
> to a DingTalk group robot (with "Approve/Reject" buttons), then polls a
> local Go service to read the click result — if the approval passes, the
> rest of the build continues; if it fails, it does not. A go/gin service
> example that receives the callback and returns the approval result is
> attached at the end.

> **Technical notes**
>
> Both the button actionURLs and the polling address point to
> localhost:8080, so the Go service must be deployed on the same machine as
> the script: a DingTalk custom robot only displays the message in the
> group, and clicking a button merely opens that URL — the approval result
> is not sent back automatically. Moreover, on "reject" the script only
> echoes a message and exits normally (no non-zero exit code), so when
> wiring it into Jenkins you must decide build success or failure yourself
> based on the result. DingTalk later required custom robots to configure
> security settings (custom keywords / signature / IP allowlist), and the
> webhook needs to be adapted accordingly. For this kind of manual gate
> before a build, Jenkins pipelines now more commonly use the `input` step.

---

## 1. DingTalk Approval Script (Pluggable into Jenkins)

Here is a DingTalk approval script that can be plugged into Jenkins: during
the Jenkins build process, run this script first. The actionURL can be
served by a small Go service listening on a local port, which parses the URL
parameters. In the end, if the approval fails, subsequent build steps are
not triggered; if the approval succeeds, they are.

```shell
#!/bin/bash
if [ $# != 2 ];then
    echo "Invalid arguments";
    exit 1
fi

title=$1
text=$2
# DingTalk robot webhook URL
webhook_url="https://oapi.dingtalk.com/robot/send?access_token=your-dingtalk-token"

# Request body
data='{
    "msgtype": "actionCard",
    "actionCard": {
        "title": "20'"$title"'",
        "text":  "'"$text"'",
        "hideAvatar": "0",
        "btnOrientation": "0",
        "btns": [
            {
                "title": "Approve",
                "actionURL": "http://localhost:8080/request?action=agree&text='"$text"'"
            },
            {
                "title": "Reject",
                "actionURL": "http://localhost:8080/request?action=reject&text='"$text"'"
            }
        ]
    }
}'

# Send the message
curl -sS ${webhook_url} \
    -H 'Content-Type: application/json' \
    -d "${data}" > /dev/null

# Poll for the approval result, at most 1000 times
for i in {1..1000}; do
    approve_url="http://localhost:8080/recent"
    result=$(curl -s $approve_url)
    if [ "$result" == "agree" ]; then
        echo "Approval passed"
        break
    elif [ "$result" == "reject" ]; then
        echo "Approval rejected"
        break
    fi

    sleep 5
done

if [ $i -eq 1000 ]; then
    echo "Polling timed out; please check the approval status."
fi
```

> Note: the `20` prefix in the `title` field is kept verbatim from the
> original.

## 2. Go Example: Parsing the Approval Callback

> Note: the original embedded the Go example as `#` comments inside the same
> code block; here it is restored as a standalone go code block, with the
> `github.com` import prefix (swallowed by the original) filled back in.

```go
package main

import (
	"net/http"
	"strconv"

	"github.com/gin-gonic/gin"
)

func main() {
	r := gin.Default()

	var recent string

	r.GET("/request", func(c *gin.Context) {
		action := c.Query("action")
		text := c.Query("text")

		recent = "action=" + action + "&text=" + text

		c.JSON(http.StatusOK, gin.H{
			"action": action,
			"text":   text,
		})
	})

	r.GET("/recent", func(c *gin.Context) {
		// Escape special characters in the string
		quoted := strconv.QuoteToASCII(recent)

		var content string
		if recent == "" {
			content = "No recent visit"
		} else {
			content = quoted[1 : len(quoted)-1] // strip the surrounding quotes added by escaping
		}

		// Change the response header to return plain text
		c.Header("Content-Type", "text/plain; charset=utf-8")
		c.String(http.StatusOK, content)
	})

	r.Run()
}
```
