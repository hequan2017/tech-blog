> **About this post**
>
> This post uses a Go example to demonstrate how to request a paginated API in a
> loop: with 150 records in total and 10 per page, the `goto LOOP` label jumps
> back to the start of the loop to repeat execution; each request increments
> repeat by one and decrements count by ten, until all data is fetched. The full
> source code and the output of the 15 requests are included.

> **Technical notes**
>
> Although Go keeps goto, it is more restricted than in C: jumps may only target
> labels within the same function, and a jump is not allowed to skip a variable
> declaration and enter its scope. The community idiom is to prefer for loops
> and function encapsulation over goto; goto is generally used only to break out
> of deep nesting in one shot. The example here can be expressed equivalently
> with a plain for loop; nowadays paginated requests or API retries are
> typically implemented with an idiomatic for loop combined with backoff.

---

## 1. Example Code: Paginated API Requests in a Loop with goto

```go
package main

import "fmt"

func main() {
  repeat := 0
  pagesize := 10
  count := 150

  /* loop */
LOOP:
  firstResult := repeat * pagesize
  for repeat < 1000 {
    fmt.Println("一共150个数据，一次请求10个， 本次是第", repeat, "请求", " firstResult 是: ", firstResult)
    // here you can fetch the data for count
    if count > pagesize {
      count = count - pagesize
      repeat = repeat + 1
      goto LOOP
    } else {
      break
    }
  }
}
```
