> **About this post**
>
> A small pandas example: summing and merging the values of dict records that share the same name — build a DataFrame, aggregate with `groupby().sum()`, then convert back to a dict. Demonstrates column selection with `df.ix` and the usage of `result.T.to_dict('list')`.

> **Technical notes**
>
> `df.ix[:, cols]` as used in this post was removed in pandas 1.0 (deprecated since 0.20); use `df.loc[:, cols]` instead. The remaining groupby aggregation usage still works today.

---

### Requirement

Sum the `value` fields of items with the same name in a list.

```python
name = [
    {'name': 'he', 'value': 100, 'ps': 'test1'},
    {'name': 'quan', 'value': 150, 'ps': 'test2'},
    {'name': 'he', 'value': 100, 'ps': 'test3'},
    {'name': 'quan', 'value': 200, 'ps': 'test4'}
]
```

### Code

```shell
pip install pandas
```

```python
import pandas as pd

df = pd.DataFrame(name)
cols = ['name', 'value']
df = df.loc[:, cols]   # df.ix from the original was removed in pandas 1.0; use loc instead
result = df.groupby(['name']).sum()
dict_country = result.T.to_dict('list')
print(dict_country)
```

### Result

```python
{'he': [200], 'quan': [350]}
```
