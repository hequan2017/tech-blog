> **About this post**
>
> This article demonstrates Redis Pub/Sub "group subscription" and concurrent consumption in Go:
> a producer goroutine Publishes 100 messages to the group1 channel, while the main goroutine Subscribes to group1
> and uses PSubscribe to match group1:*. It then launches 10 goroutines that continuously receive and print
> messages from pubSub.Channel(), waiting for them with sync.WaitGroup.

> **Technical notes**
>
> Pub/Sub messages are "fire and forget": they are delivered only to subscribers that are online at publish time, with no persistence, acknowledgment, or retry, so Pub/Sub is not suitable as a reliable queue;
> for reliable consumption, use List's BLPOP instead, or Stream in Redis 5.0+ (XADD/XREADGROUP, with consumer groups and ACK support).
> Each call to pubSub.Channel() creates a new Go channel and starts a companion internal forwarding goroutine, so it should be called only once outside the loop;
> in this example, multiple goroutines share its output, and each message is handed to only one of them, forming a concurrent fan-out.
> The code calls both Subscribe("group1") and PSubscribe("group1:*"), but the pattern group1:* does not match group1 itself, and publishing only targets group1, so either one alone would suffice.
> Since v8, go-redis uses the module path github.com/go-redis/redis/v8, and all commands require an explicit context; v9 has moved to github.com/redis/go-redis/v9.

## 1. Complete Example Code

```go
package main

import (
    "context"
    "github.com/go-redis/redis/v8"
    "log"
    "sync"
)

var ctx = context.Background()

func ProducerMessageList(rdb *redis.Client, queueListKey string) {
    for i := 0; i < 100; i++ {
        _, err := rdb.Publish(ctx, queueListKey, i).Result()
        if err != nil {
            log.Println(err)
        }
    }
}

func ConsumerMessageList(pubSub *redis.PubSub, node int) {
    for {
        ch := pubSub.Channel()
        for msg := range ch {
            log.Printf("消费者 %d ------------------ channel:%s；message:%s\n", node, msg.Channel, msg.Payload)
        }
    }
}

func main() {

    rdb := redis.NewClient(&redis.Options{
        Addr:     "192.168.117.129:6379",
        Password: "foobared", // no password set
        DB:       0,          // use default DB
    })
    // Test whether the connection succeeds
    _ = rdb.Ping(context.Background()).Err()

    go ProducerMessageList(rdb, "group1")

    pubSub := rdb.Subscribe(context.Background(), "group1")
    _ = pubSub.PSubscribe(context.Background(), "group1:*")

    var wg sync.WaitGroup
    for i := 0; i < 10; i++ {
        wg.Add(1)
        go ConsumerMessageList(pubSub, i)
    }
    wg.Wait()

}
```
