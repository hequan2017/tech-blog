> **About this post**
>
> Making GitLab 11.2.3 authenticate against FreeIPA domain accounts via LDAP: configure `gitlab_rails['ldap_servers']` in `gitlab.rb`, specifying the host, bind_dn, base, and attribute mappings, then run reconfigure for the changes to take effect. This post goes together with the earlier two articles on FreeIPA deployment and GitLab installation.

> **Technical notes**
>
> GitLab 11.2.3 is a 2018 release that is now severely outdated and has multiple known security vulnerabilities; upgrading to a currently supported version is recommended. The LDAP configuration format in newer GitLab versions is largely the same as this, but production environments should use `start_tls`/`simple_tls` instead of `plain` encryption. Do not write the configuration key as `gitlab _rails` (with a space, a typo in the original; corrected in the body) — it should be `gitlab_rails`; likewise, the command should be `gitlab-ctl`.

---

For setting up FreeIPA and GitLab, refer to my previous blog posts.

FreeIPA domain name (for internal testing, modify the GitLab hosts file: IP FreeIPA domain name)

```shell
vim /etc/gitlab/gitlab.rb
```

```ruby
gitlab_rails['ldap_enabled'] = true
gitlab_rails['ldap_servers'] = YAML.load <<-'EOS'
   main: # 'main' is the GitLab 'provider ID' of this LDAP server
     label: 'LDAP'
     host: '192.168.100.23'
     port: 389
     uid: 'uid'
     bind_dn: 'uid=admin,cn=users,cn=accounts,dc=zhuxu,dc=co'
     password: '123456'
     encryption: 'plain' # "start_tls" or "simple_tls" or "plain"
     verify_certificates: true
     active_directory: true
     allow_username_or_email_login: true
     lowercase_usernames: false
     block_auto_created_users: false
     base: 'dc=zhuxu,dc=co'
     user_filter: ''
     attributes:
       username: ['uid', 'userid', 'sAMAccountName']
       email:    ['mail', 'email', 'userPrincipalName']
       name:       'cn'
       first_name: 'givenName'
       last_name:  'sn'
     admin_group: 'cn=admins'
     sync_ssh_keys: true
EOS
```

```shell
gitlab-ctl reconfigure
gitlab-ctl restart
```
