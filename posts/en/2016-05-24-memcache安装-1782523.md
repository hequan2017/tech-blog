> **About this post**
>
> This post records the complete installation process for the Memcached server and the PHP client: first compile libevent, then install memcached and launch multiple instances; the client builds the memcache extension with phpize and loads it by editing php.ini; finally, it gives a session sharing configuration and an nc-based liveness monitoring script.

> **Technical notes**
>
> The examples are based on CentOS 6/7 with memcached 1.4.x and PHP 5.3; CentOS 7 reached EOL in 2024 and memcached 1.4.x is no longer maintained either, so version 1.6.x or Redis is recommended instead; PHP 5.3 is no longer supported, and the extension directory and configuration approach differ considerably in newer versions.

---

## 1. Server Installation

A NOSQL database. libevent needs to be installed first:

```shell
wget http://120.52.73.43/jaist.dl.sourceforge.net/project/levent/release-2.0.22-stable/libevent-2.0.22-stable.tar.gz
tar -zxvf libevent-2.0.22-stable.tar.gz
cd libevent-2.0.22-stable
./configure
make
make install
```

Perform this step, otherwise memcache fails to start with an error:

```shell
echo "/usr/local/lib/" > /etc/ld.so.conf.d/libevent.conf
ldconfig -v
```

Install memcache (server side, memcached-1.4.25.tar.gz):

```shell
wget http://www.memcached.org/files/memcached-1.4.25.tar.gz
tar zxvf memcached-1.4.25.tar.gz
cd memcached-1.4.25
./configure
make && make install
```

## 2. Startup and Read/Write Test

Run `memcached -h` for the command help. Common options: `-m` memory, `-p` port, `-d` start in the background, `-u root` specify the user, `-c 8192` number of concurrent connections.

```shell
memcached -m 16m -p 11211 -d -u root -c 8192
memcached -m 16m -p 11212 -d -u root -c 8192    # multiple instances
```

```shell
netstat -lntup | grep mem
```

```text
tcp        0      0 0.0.0.0:11211              0.0.0.0:*                          LISTEN      10785/memcached
tcp        0      0 :::11211                    :::*                               LISTEN      10785/memcached
udp        0      0 0.0.0.0:11211              0.0.0.0:*                                       10785/memcached
udp        0      0 :::11211                     :::*                                            10785/memcached
```

Command format:

```shell
printf "set key008  0 0 10\r\nhequan1234\r\n" | nc 127.0.0.1 11211
# STORED                          stored successfully

printf "get  key008\r\n" | nc 127.0.0.1 11211    # likewise for delete
# VALUE key008 0 10
# hequan1234
# END                            retrieved successfully
```

You can also use `telnet 127.0.0.1 11211`.

## 3. PHP Client Extension

```shell
wget http://pecl.php.net/get/memcache-3.0.8.tgz
tar zxvf memcache-3.0.8.tgz
cd memcache-3.0.8
/application/php/bin/phpize
./configure --enable-memcache --with-php-config=/application/php/bin/php-config
make
make install
```

Check the directory:

```shell
ls /application/php5.3.27/lib/php/extensions/no-debug-non-zts-20090626/
```

Load it:

```ini
; vim /application/php/lib/php.ini
extension_dir = "/application/php5.3.27/lib/php/extensions/no-debug-non-zts-20090626/"
extension = memcache.so    ; add a line
```

Restart:

```shell
/application/nginx/sbin/nginx -t
/application/nginx/sbin/nginx -s reload
pkill php-fpm
/application/php/sbin/php-fpm
```

## 4. Test Page and Session Sharing

You can write a test PHP page:

```php
<?php
$memcache = new Memcache;                                              // create a memcache object
$memcache->connect('127.0.0.1', 11211) or die ("Could not connect");   // connect to the Memcached server
$memcache->set('key001', 'oldboy001');                                 // set a variable in memory, named key001 with value oldboy001
$memcache->set('key002', 'oldboy002');                                 // set a variable in memory, named key002 with value oldboy002
$get_value01 = $memcache->get('key001');                               // get the value of key001 from memory
$get_value02 = $memcache->get('key002');                               // get the value of key002 from memory
echo $get_value02."<br>";
echo $get_value01;
?>
```

Cluster session sharing, which solves the hard problem of multiple servers sharing sessions:

```ini
session.save_handler = memcache
session.save_path = "tcp://192.168.10.11:11211"
```

## 5. Monitoring Script

```shell
#!/bin/sh
[ $# -ne 2 ] && {
    echo "$0 ip port"
    exit
}
export oldboy=key
export wwwServerIp=$1
export wwwServerPort=$2
cmd="nc $wwwServerIp $wwwServerPort"

printf "delete $oldboy\r\n" | $cmd >/dev/null 2>&1
sleep 1
printf "set $oldboy 0 0 6\r\noldboy\r\n" | $cmd >/dev/null 2>&1

if [ `printf "get $oldboy\r\n" | $cmd | grep oldboy | wc -l` -eq 1 ]
then
    echo "mc is alive."
    exit 0
else
    echo "mc is dead."
    exit 2
fi
```
