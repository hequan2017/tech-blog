> **About this post**
>
> This post is a hands-on exercise note on basic Linux commands. Built around common
> tasks such as "listing only directories / filtering out comment lines / counting lines",
> it collects practical command combinations for grep, sed, awk, find, tar, cut, ps, and more,
> along with key points about grep regex such as `[^xx]`, `^$` for empty lines, and the
> escape character `\`. Great for practicing along as you type.

> **Technical notes**
>
> The command usage is still applicable today. Only two caveats: `egrep` has been marked
> as deprecated in newer coreutils versions, so prefer `grep -E` throughout; the old-style
> `tail -l` no longer works on modern systems, use `tail -1` instead.

---

## 1. Several Ways to List Only Directories

```shell
ls -l | grep "^d"              # filter by first character
ls -Fl | grep "/$"             # -F appends / to directories, then filter
ls -l | sed -n '/^d/p'
ls -l | awk '/^d/'
ls -lF | sed -n '/\/$/p'
find . -type d ! -name "."
find . -type d ! -name "." -prune
tree -Ld 1                     # directories only, depth 1
```

> Tip: when a command's output already contains what we want, first consider whether
> the command itself has an option to display it directly (e.g. `tree -L` / `ls -F`)
> instead of blindly filtering.

## 2. Filtering Comments and Blank Lines

```shell
cat /etc/ssh/sshd_config | grep -v ^#          # strip comment lines
grep -Ev "^#|^$" /etc/ssh/sshd_config          # strip comments and blank lines at once (-E makes | mean "or")
grep -v -e "^#" -e "^$" /etc/ssh/sshd_config   # equivalent without -E
grep -Ev "^#|^$" /etc/inittab
```

Regex essentials:

- `[^xx]` matches characters that are **not** xx
- `^$` matches an empty line
- `\` escapes special characters

## 3. Common Viewing and Paging

```shell
cat -n file            # show line numbers
more / less file       # page through; in vim, :set nu shows line numbers, :set nonu turns it off
ll -lrt /etc/          # sort by modification time, oldest first (most recent last)
grep hequan --color=auto 1.txt   # highlight matches
cd -                   # go back to the previous directory
```

## 4. Archiving and Compression

```shell
tar zcvf /tmp/etc.tar.gz /etc/                    # pack and compress
tar tf etc.tar.gz                                 # list archive contents
tar vxf hequan.tar.gz -C /tmp/                    # extract to a given directory
tar zcfv hequan.tar.gz --exclude=/etc/ssh /etc/   # exclude a directory
tar zcvfX hequan.tar.gz a.txt /etc/               # pack per the file list in a.txt
tar jcvf xx.tar.bz2 /etc/                         # bzip2 compression
tar jxvf xx.tar.bz2                               # bzip2 extraction
# -N <date> enables incremental archiving
```

## 5. Text Processing Combinations

```shell
awk '{print $3 " " $6}' hequan.txt               # print columns 3 and 6
cut -c 6-12,21- hequan.txt                        # cut by character ranges
sed 's#,##g' hequan.txt | awk '{print $3" "$6}'   # replace , with spaces first, then pick columns
cut -d ":" -f1 /etc/passwd                        # take field 1 split by :
# cut: -d sets the delimiter, -f selects fields, -c cuts by characters
```

## 6. Counting Lines

```shell
wc -l hequan.txt
cat -n /etc/services | tail -1                    # get the max line number (tail -l in the original is a typo)
sed -n '$=' /etc/services
awk '{print NR}' /etc/services | tail -1
```

## 7. Viewing Processes

```shell
ps -ef
ps -ef | grep sshd
ps -ef | grep sshd | wc -l
ps -ef | grep -v grep | grep sshd     # exclude grep itself
```

## 8. Miscellaneous Commands

```shell
runlevel                                # show the runlevel
ls /etc/rc.d/rc3.d/ | grep sshd         # check the sshd startup script
vi /etc/sysconfig/i18n                  # configure the language (CentOS 6)
source /etc/profile                     # apply aliases/variables immediately
echo / source / export                  # variable-related commands
ln source_file target_file              # create a hard link
ln -s source_file target_file           # create a soft link (wording in the original is incorrect)
find ./ -type f -name "*.log" -mtime +7 | xargs rm -f   # clean up logs older than 7 days
for n in `seq 100`; do sleep 1; echo $n >> /var/log/messages; done   # simulate log writing
```
