> **About this post**
>
> This article deploys FRRouting (FRR) on CentOS 6/7/8 via the frr-stable
> repository on rpm.frrouting.org: after downloading and installing the
> repository RPM for the matching EL version, install frr and
> frr-pythontools with yum; then write the IPv4/IPv6 kernel forwarding
> parameters and apply them with sysctl -p, enable the frr service to start
> at boot, and finally enter the vtysh interactive interface to configure
> routing.

> **Technical notes**
>
> CentOS 6 reached end of maintenance (EOL) in November 2020; production
> environments are advised to migrate to Rocky Linux / AlmaLinux / Ubuntu
> LTS. CentOS 8 (December 2021) and CentOS 7 (June 2024) have also since
> gone EOL. At the time of writing, the frr-stable repository corresponded
> to the FRR 8.x stable release; it has since iterated to higher versions,
> and the EL versions targeted by the repository RPM are per the official
> website (the el6 package is now history). vtysh can only manage the
> daemons set to yes in /etc/frr/daemons (only zebra is enabled by default);
> before using protocols such as BGP/OSPF, the corresponding daemon must be
> enabled and frr restarted.

## 1. Add the Official RPM Repository and Install FRR

```shell
FRRVER="frr-stable"

# add RPM repository on CentOS 6
curl -O https://rpm.frrouting.org/repo/$FRRVER-repo-1-0.el6.noarch.rpm
sudo yum install ./$FRRVER*

# add RPM repository on CentOS 7
curl -O https://rpm.frrouting.org/repo/$FRRVER-repo-1-0.el7.noarch.rpm
sudo yum install ./$FRRVER*

# add RPM repository on CentOS 8
curl -O https://rpm.frrouting.org/repo/$FRRVER-repo-1-0.el8.noarch.rpm
sudo yum install ./$FRRVER*

# install FRR
sudo yum install frr frr-pythontools
```

## 2. Enable Kernel Forwarding and Start the Service

```shell
echo "net.ipv4.conf.all.forwarding=1" >> /etc/sysctl.conf

echo "net.ipv6.conf.all.forwarding=1" >> /etc/sysctl.conf

sysctl -p

systemctl enable frr.service

systemctl start frr.service

vtysh
```
