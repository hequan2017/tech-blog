> **About this post**
>
> This post explains how to switch CentOS to a China-based yum mirror: first back up the
> default `CentOS-Base.repo`, then download the repo file for your system version into
> `/etc/yum.repos.d/`, and finally run `yum clean all && yum makecache` to rebuild the
> cache, which significantly improves package download speeds. The steps are minimal,
> making this a handy quick-reference memo for switching mirrors.

> **Technical notes**
>
> As of 2026, the NetEase 163 mirror (mirrors.163.com) no longer provides CentOS repo
> downloads, and CentOS 5/6/7/8 are all end-of-life (EOL); the official historical
> archives have moved to vault.centos.org. In practice, prefer a still-maintained mirror
> such as Alibaba Cloud `mirrors.aliyun.com` or Tsinghua TUNA
> `mirrors.tuna.tsinghua.edu.cn`, or migrate directly to an actively maintained
> distribution such as Rocky Linux / AlmaLinux (new systems use `dnf` instead of `yum`;
> the commands are largely compatible).

---

## 1. Back Up the Default Repo

First back up `/etc/yum.repos.d/CentOS-Base.repo` so you can roll back if the switch fails:

```shell
mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.backup  # rename to back up the default repo
```

## 2. Download the repo File for Your Version

Download the repo file matching your system version and place it in `/etc/yum.repos.d/`
(make proper backups before proceeding):

- CentOS 7: `http://mirrors.163.com/.help/CentOS7-Base-163.repo`
- CentOS 6: `http://mirrors.163.com/.help/CentOS6-Base-163.repo`
- CentOS 5: `http://mirrors.163.com/.help/CentOS5-Base-163.repo`

Download example (using CentOS 7):

```shell
# download the 163 CentOS7 repo and overwrite the default source (163 mirror is deprecated, kept for historical reference only)
wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.163.com/.help/CentOS7-Base-163.repo
```

> Note: the 163 mirror links in the original post are no longer accessible (deprecated).
> To switch a legacy CentOS 7 system to another mirror, use Alibaba Cloud instead:
> `wget -O /etc/yum.repos.d/CentOS-Base.repo https://mirrors.aliyun.com/repo/Centos-7.repo`.

## 3. Rebuild the yum Cache

Run the following commands to clear the old cache and regenerate it:

```shell
yum clean all   # clear old package caches and metadata
yum makecache   # rebuild the cache from the new source
```

Once this is done, `yum install` works as usual, and download speeds will be noticeably
faster than with the default overseas source.
