> **About this post**
>
> This post records the full process of building and installing Nginx 1.12.2 from source on CentOS 7: first install the build dependencies,
> create the nginx user and the various temporary directories, then run configure with a custom installation prefix while enabling common
> modules such as ssl, stream, and http_v2; it then writes a systemd nginx.service for boot-time autostart and service
> management, presents a complete nginx.conf featuring gzip compression, fastcgi proxying, image/JS caching, a status page, and a hidden
> version number, and finally uses a shell script together with crontab to rotate and back up the access log on a daily basis.

> **Technical notes**
>
> Nginx 1.12.x has long been end-of-life; the current stable releases are the 1.26/1.28 series, but the configuration approach still applies.
> Two caveats: `--with-ipv6` has been removed since 1.11.5 (IPv6 is enabled by default), and reusing
> that option on newer versions will report invalid option; the original title says 1.12.2, but the command actually downloads the 1.12.1 package,
> so be careful to substitute the version number when using it. Two typos in the original script have been fixed: in the log rotation script,
> `"#path"` should be `"$path"`, and the crontab redirection `2&1` should be `2>&1` (variables are escaped when written into the heredoc,
> to prevent them from being expanded to empty prematurely while the script is generated); the word `images`,
> which the blog editor had escaped into `p_w_picpaths`, has also been restored.

## 1. Installing Dependencies

```bash
yum groupinstall "Development Tools"   -y
```

## 2. Build and Installation

```bash
cd /usr/local/src
wget http://nginx.org/download/nginx-1.12.1.tar.gz
tar zxvf nginx-1.12.1.tar.gz
cd nginx-1.12.1
groupadd -g 58 nginx
useradd -u 58 -g 58 -M nginx -s /sbin/nologin
mkdir -p /var/tmp/nginx/{client,proxy,fastcgi,uwsgi,scgi}
mkdir -p /var/cache/nginx/client_temp
./configure \
--user=nginx --group=nginx \
--prefix=/etc/nginx   \
--sbin-path=/usr/sbin/nginx \
--conf-path=/etc/nginx/nginx.conf \
--error-log-path=/var/log/nginx/error.log \
--http-log-path=/var/log/nginx/access.log \
--pid-path=/var/run/nginx.pid \
--lock-path=/var/run/nginx.lock \
--http-client-body-temp-path=/var/cache/nginx/client_temp \
--http-proxy-temp-path=/var/cache/nginx/proxy_temp \
--http-fastcgi-temp-path=/var/cache/nginx/fastcgi_temp \
--http-uwsgi-temp-path=/var/cache/nginx/uwsgi_temp \
--http-scgi-temp-path=/var/cache/nginx/scgi_temp \
--user=nginx \
--group=nginx \
--with-http_ssl_module \
--with-http_realip_module \
--with-http_addition_module \
--with-http_sub_module \
--with-http_dav_module \
--with-http_flv_module \
--with-http_mp4_module \
--with-http_gunzip_module \
--with-http_gzip_static_module \
--with-http_random_index_module \
--with-http_secure_link_module \
--with-http_stub_status_module \
--with-http_auth_request_module \
--with-threads \
--with-stream \
--with-stream_ssl_module \
--with-http_slice_module \
--with-mail \
--with-mail_ssl_module \
--with-file-aio \
--with-http_v2_module \
--with-ipv6
make && make install
nginx -V
```

## 3. The systemd Startup File

```bash
cat  >> /lib/systemd/system/nginx.service  <<EOF
[Unit]
Description=nginx - high performance web server
Documentation=http://nginx.org/en/docs/
After=network.target remote-fs.target nss-lookup.target
[Service]
Type=forking
PIDFile=/run/nginx.pid
ExecStartPre=/usr/sbin/nginx -t -c /etc/nginx/nginx.conf
ExecStart=/usr/sbin/nginx -c /etc/nginx/nginx.conf
ExecReload=/bin/kill  -s  HUP  $MAINPID
ExecStop=/bin/kill -s QUIT $MAINPID
PrivateTmp=true
[Install]
WantedBy=multi-user.target
EOF
systemctl enable nginx.service
systemctl start  nginx.service

netstat -lntup  | grep 80
```

## 5. Log Rotation

Rotation script plus a crontab schedule (runs daily at midnight; in the original script, `"#path"` was a typo for `"$path"`, already corrected):

```bash
cat >> /var/log/nginx/log.sh <<EOF
#!/bin/bash
path=/var/log/nginx/backup
if [ ! -d  "\$path"  ]; then
    mkdir -p \$path
fi
cd  /var/log/nginx
mv access.log   backup/\$(date +%F -d -1day).log
systemctl reload  nginx.service
EOF
chmod +x /var/log/nginx/log.sh
crontab -e
00 00 * * * /var/log/nginx/log.sh  > /dev/null 2>&1
```
