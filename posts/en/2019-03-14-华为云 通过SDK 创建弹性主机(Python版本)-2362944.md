> **About this post**
>
> Use the Python version of the Huawei Cloud SDK to fully create an Elastic Cloud Server (ECS): first list availability zones, VPC routers, subnets, images, and security groups to obtain the required IDs, then assemble parameters such as imageRef/flavorRef/vpcid/nics/root_volume/extendparam and call `create_server_ext` to place the order; it also demonstrates injecting a base64-encoded initialization script via user_data to change the root password.
>
> **Technical notes**
>
> The SDK used here (huaweicloud-sdk-python, OpenStack-style) is a legacy version; the officially recommended package is now `huaweicloudsdk-python`. In addition, injecting the root password in plaintext via user_data is for demonstration only; in production, use a key pair (key_name) or a more secure initialization method instead.
