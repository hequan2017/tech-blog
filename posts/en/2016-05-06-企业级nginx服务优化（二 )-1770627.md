> **About this post**
>
> This is the second post in the series: it covers nginx gzip compression (the meaning of
> parameters such as gzip_min_length, gzip_buffers, gzip_comp_level, gzip_types, and
> gzip_vary) and expires client-side caching (images 3650d, js/css 30d, robots.txt 7d
> without logging 404s), plus the mime.types type table; it also shows the Apache side,
> enabling mod_deflate and compiling mod_expires as a DSO via apxs; and it covers hardening
> items such as returning 403 for crawler user agents, a log-rotation script with crontab,
> access_log off for static assets, minimizing directory and file permissions, restricting
> IP access with location, error_page 50x pages, mounting /tmp as tmpfs, and disabling PHP
> parsing with php_flag.

> **Technical notes**
>
> This series is based on CentOS 6 (EOL since November 2020); for production, migrating to
> Rocky Linux / AlmaLinux / Ubuntu LTS is recommended.
> Note: Apache 2.2 as used in this post is no longer maintained, and 2.4 already ships with
> mod_deflate/mod_expires by default, so manual apxs compilation is no longer needed;
> nginx's gzip/expires/valid-UA syntax is still in use today; robots.txt's Crawl-delay is
> only supported by some crawlers, and Google no longer uses it.

## 1. Configuring nginx gzip Compression

```nginx
gzip on;
gzip_min_length 1k;        # compress only files larger than 1K
gzip_buffers 4 32k;        # compression buffer size
gzip_http_version 1.1;
gzip_comp_level 9;         # compression ratio 1-9
gzip_types text/css text/xml application/javascript;   # types to compress; they differ between versions
gzip_vary on;              # Vary header support
```

## 5. nginx expires Caching

Specifies how long resources are kept locally on the client; write it inside the server block:

```nginx
location ~ .*\.(gif|jpg|jpeg|png|bmp|swf)$ {
    expires 3650d;
}

location ~ .*\.(js|css)?$ {
    expires 30d;
}
```

Example — cache robots.txt for 7 days without logging 404s:

```nginx
location ~(robots.txt) {
    log_not_found off;
    expires 7d;
    break;
}
```

## 6. Compiling Apache mod_expires as a DSO

```shell
./configure --enable-expires

cd /httpd-2.2.22/modules/metadata/    # switch to the apache software directory

/application/apache/bin/apxs -c -i -a mod_expires.c   # compile into apache as a DSO

ll /application/apache2.2.22/modules/mod_expires.so   # verify
```

## 7. robots.txt and Blocking Crawler User Agents

Write a file like this (<http://www.51cto.com/robots.txt>):

```text
User-agent: *
Crawl-delay: 500
Disallow: /wuyou/
Disallow: /php/
Disallow: /wuyou_admin/
Disallow: /actions/
```

Modify nginx.conf to block web crawler user agents and return 403:

```nginx
server {
    listen 80;
    server_name 127.0.0.1;

    # adding the following is enough to block crawlers
    if ($http_user_agent ~* "qihoobot|Baiduspider|Googlebot|Googlebot-Mobile|Googlebot-Image|Mediapartners-Google|Adsbot-Google|Feedfetcher-Google|Yahoo! Slurp|Yahoo! Slurp China|YoudaoBot|Sosospider|Sogou spider|Sogou web spider|MSNBot|ia_archiver|Tomato Bot")
    {
        return 403;    # you could also list browsers above to block browser access
    }
}
```

## 8. nginx Log Rotation

```shell
# cut_nginx_log.sh
cd /application/nginx/logs && \
/bin/mv www_access.log www_access_$(date +%F -d -1day).log
/application/nginx/sbin/nginx -s reload
```

```shell
crontab -e
00 00 * * * /bin/sh /server/scripts/cut_nginx_log.sh >/dev/null 2>&1
```

Use together with syslog for log analysis.

## 9. Not Logging Unneeded Access

```nginx
location ~ .*\.(js|jpg|JPG|jpeg|JPEG|css|bmp|gif|GIF)$ {
    access_log off;
}
```

```text

```

## 10. Minimizing Apache Directory and File Permissions

- The user and group of all site directories should be root
- All directories should have 755 permissions
- All files should have 644 permissions
- The user running the website service must not be root

## 11. Restricting Access by IP

```nginx
location ~ ^/hequan/ {
    allow 192.168.10.0/24;
    deny all;
}
```

## 13. The tmpfs In-Memory File System

tmpfs is a memory-based file system:

```shell
# vim /etc/rc.local
mount -t tmpfs -o size=16m tmpfs /tmp
```

```shell

# df -hT
```
