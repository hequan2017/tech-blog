> **About this post**
>
> This post explains how to configure bash auto-completion for the kubectl command: install the bash-completion package, use the script generated by `kubectl completion bash` to enable Tab completion of resource names and subcommands, and finally append it to ~/.bashrc to make it permanent.

> **Technical notes**
>
> This applies to the bash shell. If you use zsh, use `kubectl completion zsh` instead. The approach is based on the general kubectl 1.x mechanism and still works with all recent versions.

---

```shell
yum install -y epel-release bash-completion
source /usr/share/bash-completion/bash_completion
source <(kubectl completion bash)
echo "source <(kubectl completion bash)" >> ~/.bashrc
```
