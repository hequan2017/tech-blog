> **About this post**
>
> This is the first article in the enterprise-grade nginx optimization series: it first
> lists the configuration files of each LAMP/LNMP component, then walks through nginx
> tuning item by item — hiding or faking the version number (editing source files such
> as nginx.h before compiling, or setting server_tokens off), specifying the user that
> workers run as, sizing worker_processes by CPU core count, pinning cores with
> worker_cpu_affinity, use epoll and worker_connections in the events block, the
> server_names_hash table size, sendfile/tcp_nopush, keepalive and the various
> read/write timeouts, the client_max_body_size upload limit, and fastcgi buffering
> plus fastcgi_cache configuration, closing with webbench stress-test and taskset
> core-pinning commands.

> **Technical notes**
>
> CentOS 6 reached end of life (EOL) in November 2020; production environments are
> advised to migrate to Rocky Linux / AlmaLinux / Ubuntu LTS.
> Note: nginx 1.6.3 is also no longer maintained; current stable releases auto-select
> epoll by default on Linux, so an explicit use is unnecessary; newer versions of
> worker_cpu_affinity accept CPU numbers or auto directly; the webbench download
> source blog.s135.com in this article is dead — use stress-testing tools such as
> ab / wrk instead.

## 2. Changing the nginx Version Information

```shell
curl -I 192.168.10.11
```

```text
Server: nginx/1.6.3
```

### First Method: Modify the Version and Version Number (Edit the Source Before Compiling)

```c
// src/core/nginx.h
#define nginx_version      1008001
#define NGINX_VERSION      "1.8.1"        # Change to the version to display, e.g. 2.2.23
#define NGINX_VER          "nginx/" NGINX_VERSION   # Change nginx to the product name to display
#define NGINX_VAR          "NGINX"        # Change nginx to the product name to display (Evan Web Server)
#define NGX_OLDPID_EXT     ".oldbin"
```

```c
// src/http/ngx_http_header_filter_module.c
static char ngx_http_server_string[] = "Server: nginx" CRLF;   # Change nginx to the desired version
```

```c
// src/http/ngx_http_special_response.c
"<hr><center>nginx</center>" CRLF    # Change nginx to the desired version info
```

### Second Method: Hide the Version Number

Add `server_tokens off;` to the nginx configuration file. The scope of server_tokens is
the http, server, and location blocks; the default value on shows version information,
and setting it to off hides the nginx version number everywhere.

```nginx
http {
    server_tokens off;
}
```

```shell
/application/nginx/sbin/nginx -s reload
```

Afterwards `nginx/1.6.3` in the response header becomes `nginx`; the same applies to
the 404 Not Found page.

## 3. Changing the nginx Runtime User

```shell
# grep "#user" nginx.conf.default    # default file
```

```nginx
#user  nobody;
```

Two approaches:

```shell
# 1. Edit the configuration file
vim nginx.conf
```

```nginx
user nginx nginx;
```

```shell
# 2. Specify at compile time
./configure --user=nginx --group=nginx
```

```shell
ps -ef | grep nginx
```

```text
root      56512      1  0 02:35 ?        00:00:00 nginx: master process
nginx     57470  56512  0 04:04 ?        00:00:00 nginx: worker process
```

The master process runs as root by default (required to listen on port 80); worker
processes run as the nginx user.

## 4. Configuring the Number of Worker Processes

```nginx
worker_processes  1;   # Equal to the CPU core count; check with cat /proc/cpuinfo | grep -c processor
```

After changing it to `worker_processes 2;`, check the processes:

```text
nginx      1822   1784  0 04:14 ?        00:00:00 nginx: worker process
nginx      1823   1784  0 04:14 ?        00:00:00 nginx: worker process
```

## 5. Configuring worker_cpu_affinity

Assign each worker process to its own CPU core:

```nginx
worker_processes 2;
worker_cpu_affinity 0101 1010;

worker_processes 4;
worker_cpu_affinity 0001 0010 0100 1000;

worker_processes 8;
worker_cpu_affinity 0001 0010 0100 1000 0001 0010 0100 1000;
```

## 7. Pinning Process CPU Affinity with taskset

taskset can view or set the CPU affinity of a process:

```shell
taskset -c 1,2,3 /etc/init.d/mysql start    # Run a given process on specific CPUs
```

## 8. Optimizing the Event Processing Model

Use the epoll model on Linux:

```nginx
events {                            # Set the nginx working mode and connection limit
    use epoll;
    worker_connections 20480;       # Max connections per process, default 1024
}
```

Maximum client connections: **Max_client = worker_processes \* worker_connections**.

The per-process connection limit is capped by the system's maximum number of open
files; run `ulimit -HSn 65535`, or pair it with:

```nginx
worker_rlimit_nofile 65535;    # Max open files per process
```

## 9. Tuning the Server Names Hash Table Size

```nginx
# http://hequan.blog.51cto.com/  wildcard DNS scenario
http {
    server_names_hash_bucket_size 64;
    server_names_hash_max_size 512;    # Default 512, usually 4-5x the CPU L1 cache
}
```

## 10. Enabling Efficient File Transfer Mode

```nginx
sendfile   on;
tcp_nopush on;
```

## 11. Connection Timeouts

Short connections are recommended for PHP services:

```nginx
keepalive_timeout      60;    # How long a client connection stays alive
tcp_nodelay            on;
client_header_timeout  15;    # Request header read timeout; returns 408 if no data arrives in time
client_body_timeout    15;    # Request body read timeout
send_timeout           15;    # Timeout for sending the response to the client
```

## 12. Upload File Size Limit (Dynamic Applications)

```nginx
client_max_body_size 10m;    # Max client upload size; exceeding it returns 413; 0 disables the check; PHP defaults to 2m
```

## 13. fastcgi Tuning

```nginx
location ~ .*\.(php|php5)?$ {
    fastcgi_pass   127.0.0.1:9000;
    fastcgi_index  index.php;
    include        fastcgi.conf;
}
```

```nginx
fastcgi_connect_timeout 300;          # Connection
fastcgi_send_timeout    300;          # Send request
fastcgi_read_timeout    300;          # Response
fastcgi_buffer_size     64k;          # Buffer size
fastcgi_buffers         4 64k;        # How many buffers of what size
fastcgi_busy_buffers_size 128k;
fastcgi_temp_file_write_size 128k;

fastcgi_cache hequan_nginx;
fastcgi_cache_valid 200 302 1h;
fastcgi_cache_valid 301 1d;
fastcgi_cache_valid any 1m;
fastcgi_cache_min_uses 1;
```
