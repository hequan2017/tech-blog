> **About this post**
>
> Deploy Rancher v2.7.9 as a single Docker container: pull the image from the Alibaba Cloud
> container registry and retag it, start the container, retrieve the Bootstrap Password,
> and include an image list for components such as the agent and webhook.

> **Technical notes**
>
> The Rancher 2.7 series is end-of-life (EOL); upgrading to 2.8/2.9/2.10 is recommended for production;
> for production deployments, the Helm method is recommended (cert-manager must be installed first);
> the single-container `docker run` approach in this post is suited for a quick try-out — persistence
> and high availability need separate planning.

---

```shell
docker pull registry.cn-hangzhou.aliyuncs.com/rancher/rancher:v2.7.9

docker tag registry.cn-hangzhou.aliyuncs.com/rancher/rancher:v2.7.9 rancher/rancher:v2.7.9

docker run --privileged --name rancher -d --restart=unless-stopped -p 80:80 -p 443:443 rancher/rancher:stable

docker ps|grep rancher

docker logs rancher 2>&1 | grep "Bootstrap Password:"

rancher/rancher-agent:v2.7.9
rancher/rancher-webhook:v0.3.6
rancher/shell:v0.1.21

# The following two commands were incomplete in the original (the registry address was stripped by the platform); restored with the same registry as above
docker pull registry.cn-hangzhou.aliyuncs.com/rancher/rancher-agent:v2.7.9

docker tag registry.cn-hangzhou.aliyuncs.com/rancher/rancher-agent:v2.7.9 rancher/rancher-agent:v2.7.9
```
