> **About this post**
>
> Hands-on notes on deploying a private Harbor 1.4.0 image registry: download the offline installer, use openssl to self-sign a CA and server certificates to enable HTTPS, edit harbor.cfg and run prepare and install.sh to start it, and finally distribute the certificates on the client, run docker login, and demonstrate the full tag/push/pull image workflow.

> **Technical notes**
>
> Harbor 1.4 is long past end of maintenance. In newer Harbor (2.x), configuration moved from harbor.cfg to harbor.yml, the installer script is `install.sh`, and enterprise features such as image scanning and robot accounts are built in; use the current stable release for new installations. The Harbor project has also moved from the vmware organization to CNCF's goharbor organization (github.com/goharbor/harbor). The docker-compose 1.x standalone binary has been superseded by Docker's built-in `docker compose` subcommand.

Harbor is an enterprise-grade Docker Registry project open-sourced by VMware. Project URL: https://github.com/goharbor/harbor (this post was written before the project migration; the old address was github.com/vmware/harbor)

### Install docker-compose and Harbor

```shell
curl -L https://github.com/docker/compose/releases/download/1.21.0/docker-compose-`uname -s`-`uname -m` -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose

wget https://storage.googleapis.com/harbor-releases/release-1.4.0/harbor-offline-installer-v1.4.0.tgz

tar xf  harbor-offline-installer-v1.4.0.tgz
```

### Self-signed TLS Certificates

Reference documentation: https://github.com/goharbor/harbor/blob/master/docs/configure_https.md

```shell
cd harbor/
mkdir ssl
cd ssl
openssl req \
    -newkey rsa:4096 -nodes -sha256 -keyout ca.key \
    -x509 -days 365 -out ca.crt
```

### Configure and Start Harbor

```shell
vim harbor.cfg
hostname =
ui_url_protocol = https
ssl_cert = ./ssl/.crt
ssl_cert_key = ./ssl/.key
harbor_admin_password = 12345

./prepare
./install.sh

docker-compose  ps
```

### Web UI Operations

Edit `C:\Windows\System32\drivers\etc\hosts` and add `192.168.1.112 <your Harbor domain>`. Open it in a browser, log in (admin / 12345), create repositories and users, and grant permissions under Project - Members - New Member.

### Client Access

```shell
mkdir /etc/docker/certs.d/  -p
echo 192.168.1.112     >> /etc/hosts

scp  root@:/data/harbor/ssl/.crt  /etc/docker/certs.d/

# Log in
docker login
Username: hequan
Password:
Login Succeeded

# Or: docker login -u hequan -p 12345

# Tag an image in the project:
docker tag SOURCE_IMAGE[:TAG] /test/IMAGE[:TAG]

# Push the image to the current project:
docker push /test/IMAGE[:TAG]

docker tag centos /test/centos:v1
docker push /test/centos:v1

docker pull /test/centos:v1
```
