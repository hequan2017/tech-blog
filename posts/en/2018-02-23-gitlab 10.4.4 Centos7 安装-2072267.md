> **About this post**
>
> Notes on installing GitLab CE 10.4.4 via yum from the Tsinghua TUNA mirror on CentOS 7.4: configure the gitlab-ce.repo repository, change external_url and reconfigure, then apply the 10.4.4-zh branch diff from xhang/gitlab as a patch for Chinese localization, and finally the SMTP email configuration, how to send a test email from the gitlab-rails console, and common gitlab-ctl operations commands.

> **Technical notes**
>
> GitLab 10.x has been unmaintained for years and contains multiple high-severity vulnerabilities; for new installations use the current 16/17/18 series. Since 12.x, a Simplified Chinese UI has been built in officially, so the manual localization patch is no longer needed. CentOS 7 reached end of life (EOL) on June 30, 2024; migrating to Rocky Linux 9 / AlmaLinux 9 or the domestic openEuler is recommended. In newer GitLab versions the default web server changed from Unicorn to Puma, so `gitlab-ctl tail unicorn` should be changed to `gitlab-ctl tail puma`.

### Environment:

```shell
centos 7.4
gitlab 10.4.4
```

### Configure the firewall:

```shell
sudo yum install curl openssh-server openssh-clients cronie
sudo lokkit -s http -s ssh
```

### Installation

```shell
vim /etc/yum.repos.d/gitlab-ce.repo
[gitlab-ce]
name=Gitlab CE Repository
baseurl=https://mirrors.tuna.tsinghua.edu.cn/gitlab-ce/yum/el$releasever/
gpgcheck=0
enabled=1

yum makecache
yum install gitlab-ce

vim /etc/gitlab/gitlab.rb
# Change the variable
external_url 'http://192.168.1.20'

# Reload the configuration
gitlab-ctl reconfigure
```

### Chinese localization

```shell
cat /opt/gitlab/embedded/service/gitlab-rails/VERSION
10.4.4

git clone https://gitlab.com/xhang/gitlab.git
gitlab-ctl stop
cd gitlab/
git fetch
git diff v10.4.4 v10.4.4-zh > ../10.4.4-zh.diff
cd ..
patch -d /opt/gitlab/embedded/service/gitlab-rails -p1 <  10.4.4-zh.diff
gitlab-ctl start
```

### Email

```shell
vim /etc/gitlab/gitlab.rb

gitlab_rails['gitlab_email_from'] = 'user1@'
gitlab_rails['smtp_enable'] = true
gitlab_rails['smtp_address'] = "smtp."
gitlab_rails['smtp_port'] = 465
gitlab_rails['smtp_user_name'] = "user1@"
gitlab_rails['smtp_password'] = "password"
gitlab_rails['smtp_domain'] = "smtp."
gitlab_rails['smtp_authentication'] = "login"
gitlab_rails['smtp_enable_starttls_auto'] = true
gitlab_rails['smtp_tls'] = true
gitlab_rails['gitlab_email_from'] = 'hequan@'

# Reload the configuration
gitlab-ctl reconfigure

# Test whether the configuration works
gitlab-rails console

# Wait a few minutes
Notify.test_email('9278718999@', 'Test subject', 'Test content').deliver_now
```

### Common commands

```shell
gitlab-ctl status   Check the running status of GitLab
gitlab-ctl restart   Restart
gitlab-ctl tail unicorn  View the unicorn logs; press Ctrl-C to exit
gitlab-ctl tail gitlab-rails Fetch logs from subdirectories under /var/log/gitlab
gitlab-ctl tail nginx/gitlab_error.log  Fetch a specific log file
gitlab-ctl tail View all logs; press Ctrl-C to exit
```
