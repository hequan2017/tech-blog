> **About this post**
>
> Iterate over all buckets under the account with oss2, then call the CloudMonitor (CMS) `QueryMetricList` API to query the `MeteringStorageUtilization` metric of each bucket, and aggregate the total OSS storage usage (TB) of the whole account. It is an automation script for OSS usage statistics.

> **Technical notes**
>
> The legacy Alibaba Cloud CloudMonitor SDK (aliyun-python-sdk-cms) has been superseded by the new CMS SDK / OpenAPI; a simpler approach today is to call the OSS `GetBucketStat` API directly, or use the new CloudMonitor SDK to get the storage usage, with no need to hand-write Datapoints string parsing. Note that the `%S`/`%M` order in `strftime("%Y-%m-%d %H:%S:%M")` in the code is a typo (it should be `%H:%M:%S`); it only affects the printed log time format.

### Dependency modules

### Script

```python
import oss2
from aliyunsdkcore import client
from aliyunsdkcms.request.v20180308 import QueryMetricListRequest
import datetime
import time
import json

def BusinessOssTask():
    auth = oss2.Auth('key', 'secret')
    service = oss2.Service(auth, 'http://oss-region.aliyuncs.com')
    name_list = [b.name for b in oss2.BucketIterator(service)]
    now = datetime.datetime.now()
    oss_size = []
    for name in name_list:
        clt = client.AcsClient('key', 'secret', 'region')
        request = QueryMetricListRequest.QueryMetricListRequest()
        request.set_accept_format('json')  # the response is in JSON format
        request.set_Project('acs_oss')
        request.set_Metric('MeteringStorageUtilization')  # the value returned is in bytes
        start_time = (now - datetime.timedelta(hours=4)).strftime("%Y-%m-%d %H:%S:%M")
        end_time = (now - datetime.timedelta(hours=3)).strftime("%Y-%m-%d %H:%S:%M")
        print(start_time, end_time)
        timestamp_start = int(time.mktime(time.strptime(start_time, "%Y-%m-%d %H:%M:%S"))) * 1000
        timestamp_end = int(time.mktime(time.strptime(end_time, "%Y-%m-%d %H:%M:%S"))) * 1000
        request.set_StartTime(timestamp_start)
        request.set_EndTime(timestamp_end)
        request.set_Dimensions({'BucketName': name})  # this is where the bucket name goes
        request.set_Period('3600')  # for metering metrics like this one, note the aggregation granularity is 3600s.
        result = clt.do_action_with_exception(request)
        res = json.loads(result)
        res_list = res['Datapoints'][1:-1].split(":")
        oss_size.append(float(res_list[-1][:-1]))

    print(round(sum(oss_size) / 1024 / 1024 / 1024 / 1024, 2),'Tb')
```
