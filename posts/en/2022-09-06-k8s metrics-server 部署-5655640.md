> **About this post**
>
> This post describes a quick deployment of metrics-server on a Kubernetes v1.25 cluster: download the official components.yaml, replace the image address with a mirror accessible from within China, add `--kubelet-insecure-tls` to skip kubelet certificate verification, and finally use `kubectl top node` to verify that CPU/memory metrics are being collected correctly.
>
> **Technical notes**
>
> `--kubelet-insecure-tls` is only suitable for test environments; in production, configure kubelet certificate signing or use `--kubelet-preferred-address-types` to specify InternalIP. It is recommended to replace the metrics-server image with one from the Alibaba Cloud container registry to avoid GitHub access restrictions.

---

```shell
Monitoring  metrics-server

wget  https:///kubernetes-sigs/metrics-server/releases/latest/download/components.yaml

sed -i "s#/metrics-server#/chenby#g" components.yaml

vim +140 components.yaml

- --kubelet-insecure-tls

kubectl apply -f components.yaml

[root@k8s-master ~]# kubectl top node k8s-node1
NAME        CPU(cores)   CPU%   MEMORY(bytes)   MEMORY%
k8s-node1   113m         2%     1035Mi          61%
```
