> **About this post**
>
> An introduction to implementing dependency injection in Go with the facebookgo/inject library: dependency fields are marked with the struct tag `inject:""`, objects are registered via `inject.Graph`, and assignments are wired up automatically, avoiding manual layer-by-layer component assembly. The post presents a complete example of a four-layer dependency chain: DBEngine → UserDB → UserService → App.

> **Technical notes**
>
> The facebookgo repository family, including facebookgo/inject, has been
> archived and unmaintained since around 2020; new projects should not adopt it.
> Modern Go alternatives: google/wire (compile-time code generation), uber/fx
> (runtime container), or the simplest option — manual constructor-based wiring.
> Reflection-plus-struct-tag injection surfaces errors only at runtime, which
> gets hard to debug as the dependency graph grows.

### Go Dependency Injection

#### Overview

> The core of software construction is managing complexity. — *Code Complete*

The purpose of dependency injection is to decouple the dependencies between components, so you don't have to configure each component's dependencies by hand.

#### Library

It uses the library `github.com/facebookgo/inject`.

#### Example

```go
package main

import (
	"fmt"

	"github.com/facebookgo/inject"
)

type DBEngine struct {
	Name string
}

type UserDB struct {
	Db *DBEngine `inject:""`
}

type UserService struct {
	Db *UserDB `inject:""`
}

type App struct {
	Name string
	User *UserService `inject:""`
}

func (a *App) Create() string {
	return "create app, in db name:" + a.User.Db.Db.Name + " app name :" + a.Name
}

type Object struct {
	App *App
}

func Init() *Object {
	db := DBEngine{Name: "db1"}
	var g inject.Graph
	app := App{Name: "go-app"}

	_ = g.Provide(
		&inject.Object{Value: &app},
		&inject.Object{Value: &db},
	)
	_ = g.Populate()
	return &Object{
		App: &app,
	}

}

func main() {
	obj := Init()
	fmt.Println(obj.App.Create())
}
```

#### Output

```text
create app, in db name:db1 app name :go-app
```
