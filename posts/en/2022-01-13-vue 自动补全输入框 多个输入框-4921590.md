> **About this post**
>
> This post is a Vue 3 front-end practice note: implementing an autocomplete
> input box based on the element `el-autocomplete` component, adapted to a
> scenario with multiple input boxes (iterated via `v-for`).
> It presents the component template, together with a Composition API
> implementation combining the `querySearch` suggestion query, the
> `createFilter` filter, and the `handleSelect` selection callback.

> **Technical notes**
>
> - The code in this post is written with the Vue 3 Composition API, and the
>   component corresponds to Element Plus; element-ui for Vue 2 ended official
>   maintenance together with Vue 2 on December 31, 2023; new projects are
>   advised to use Element Plus directly.
> - In the original text, `:value-key="测试"` would evaluate "测试" as a JS
>   variable; it has been corrected to the static attribute `value-key="测试"`,
>   matching the "测试" field name in the candidate objects.

---

## 1. Based on element

### Component template

```html
<el-autocomplete
    class="inline-input"
    v-model="item.content"
    :key="index"
    :fetch-suggestions="querySearch"
    placeholder="请输入内容"
    @select="handleSelect"
    style="width: 769px"
    value-key="测试"

```
