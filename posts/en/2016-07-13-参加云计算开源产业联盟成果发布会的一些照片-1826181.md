> **About this post**
>
> This post is a collection of on-site photos (22 in total) taken by the author at the
> Cloud Computing Open Source Industry Alliance Achievements Release Event on July 13, 2016.
> It covers close-ups of the released outcomes such as the China Cloud Computing Open Source
> Industry Development White Paper, the conference theme screen, and presentation slides from
> various vendors: OpenStack global enterprise user growth, public cloud market size,
> the China Mobile cloud platform, Tianyi Cloud 3.0, Smart Hubei, FitCloud cloud-network
> convergence, a trusted-cloud healthcare case, data center architecture, the DC/OS ecosystem
> and roadmap, the trusted cloud certification system, open-source solution evaluation targets,
> and more. It also mentions that the conference materials and the white paper can be
> downloaded from the alliance's GitHub account (opensourcecloud).

> **Technical notes**
>
> A news/essay-style post with no time-sensitive technical content. The GitHub link in the
> original post lost its domain during scraping (only https:///opensourcecloud remained; it
> should be github.com/opensourcecloud, and that organization is now inactive). The external
> image-hosting URLs of the original photo post are no longer valid; this post keeps the
> locally archived images.
