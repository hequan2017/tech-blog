> **About this post**
>
> This post reviews the classification of SQL statements and basic MySQL SQL: statements are first classified into
> DQL/DML/TPL/DCL/DDL/CCL, pointing out the select, insert, update, delete and grant, revoke commands most used
> by ops; it then demonstrates specifying the character set and collation when creating a database (create database
> ... default character set gbk/utf8 collate ...), presetting the character set when compiling from source, and
> basic usage such as show databases, use/select database(), select version()/user()/now(), and show tables; the
> focus is on the grant syntax (database.table, user@client host, identified by password), granting by network
> segment, revoking privileges with revoke, the privilege fields of mysql.user (switching N to Y) and the principle
> of least privilege; it closes with examples of creating tables with create table and inspecting table structure
> with desc and show create table.

> **Technical notes**
>
> Since MySQL 8.0, `GRANT ... IDENTIFIED BY` no longer creates the user automatically; run `CREATE USER` first and
> then grant. The `Password` column of `mysql.user` was renamed to `authentication_string` in 5.7+. For new
> databases, prefer utf8mb4 (the default since MySQL 8.0) over the three-byte utf8.

## 1. SQL Statement Classification

- Data Query Language (DQL)
- Data Manipulation Language (DML): `select insert update delete` ← ops
- Transaction Processing Language (TPL)
- Data Control Language (DCL): `grant revoke commit rollback` ← ops
- Data Definition Language (DDL): `create drop alter`
- Cursor Control Language (CCL)

## 2. Creating Databases and Character Sets

```sql
mysql> create database hequan;

mysql> show create database hequan\G
```

```text
Database: hequan
Create Database: CREATE DATABASE `hequan` /*!40100 DEFAULT CHARACTER SET latin1 */
1 row in set (0.00 sec)
```

The default character set is latin1 (Latin). You can also specify the character set and collation when creating a database:

```sql
mysql> create database hequan_gbk default character set gbk collate gbk_chinese_ci;
mysql> create database hequan_utf8 default character set utf8 collate utf8_general_ci;
```

Specify the default character set when compiling from source:

```shell
-DDEFAULT_CHARSET=utf8 \
-DDEFAULT_COLLATION=utf8_general_ci \
```

If a specific character set was specified at compile time, you no longer need to specify one when creating databases afterwards.

Enterprise practice: determine the character set based on the application being developed (UTF-8), specify it at compile time, and simply create databases with the default; if a different character set is needed, specify it when creating the database.

## 3. Basic Usage

```sql
mysql> show databases;
mysql> use hequan;
mysql> select database();      -- show the currently connected database
mysql> drop database hequan_gbk;
mysql> help drop database;
mysql> select version();
mysql> select user();
mysql> select now();
mysql> show tables;
mysql> show tables from mysql;
mysql> select user,host from mysql.user;
mysql> drop user ''@'';        -- remove redundant accounts
mysql> flush privileges;
```

## 4. Granting Privileges with GRANT

```sql
mysql> grant all on db1.* to 'hequan'@'localhost' identified by '123123';
```

The syntax elements map to: database.table / username / client host / password.

```sql
mysql> show grants for he@'localhost';      -- view user privileges

mysql> create user hexx@localhost identified by '123123';
mysql> grant all on test.* to hexx@'localhost';
mysql> grant all on test.* to hexx@'192.168.10.%';
mysql> grant all on test.* to hexx@'192.168.10.0/255.255.255.0';

mysql> create user quan@'192.168.10.%' identified by '123456';   -- create a remote login user
```

When logging in remotely, specify the host with -h:

```shell
mysql -uquan -p123456 -h192.168.10.11
```

Revoking the insert privilege:

```sql
mysql> revoke insert on *.* from 'quan'@'192.168.10.%';
```

## 5. Privilege Table and Least Privilege

```sql
mysql> desc user;                  -- view the table
mysql> select * from mysql.user\G  -- granting is just switching N to Y
```

```text
Host: localhost
User: root
Password: *6BB4837EB74329105EE4568DDA7DC67ED2CA2AD9
Select_priv: Y
Insert_priv: Y
Update_priv: Y
Delete_priv: Y
Create_priv: Y
Drop_priv: Y
```

Principle of least privilege: select, insert, update and delete are the commonly used privileges; revoke create and drop once installation is complete.

## 6. Creating Tables

```sql
mysql> create database oldboy;
```

Table creation syntax:

```sql
create table <table_name>(<field_name1><type1>,...<field_namen><typen>);
```

```sql
create table student(
id int(4) not null,
name char(20) not null,
age tinyint(2) NOT NULL default '0',
dept varchar(16) default NULL
);
```

Viewing the table structure:

```sql
mysql> desc student;
mysql> show create table student\G
```

```text
| student | CREATE TABLE `student` (
  `id` int(4) NOT NULL,
  `name` char(20) NOT NULL,
  `age` tinyint(2) NOT NULL DEFAULT '0',
  `dept` varchar(16) DEFAULT NULL
) ENGINE=InnoDB DEFAULT CHARSET=latin1 |
```

Here InnoDB is the storage engine and latin1 is the default character set.

```sql
mysql> show tables from oldboy;
```
