> **About this post**
>
> This article uses Go to work with Redis and implements a minimal message queue:
> the producer uses LPush to write 10,000 messages into the queue:message list;
> the consumer uses BRPop to pop messages with blocking, a 5-second timeout, and dedicated handling of redis.Nil;
> the full example code is included at the end, based on github.com/go-redis/redis/v8.

> **Technical notes**
>
> Since v8, go-redis has changed its module path to github.com/go-redis/redis/v8, and every command requires an explicit context.Context (context.Background() is used throughout this article); v9 has moved to github.com/redis/go-redis/v9.
> BRPop returns redis.Nil when it times out without retrieving any data; this is a normal case and should be handled separately from real errors.
> The rand.Seed call used in this article is deprecated as of Go 1.20; modern code no longer needs manual seeding.

## 1. Full Example Code

```go
package main

import (
    "context"
    "github.com/go-redis/redis/v8"
    "log"
    "math/rand"
    "time"
)

var ctx = context.Background()

func ProducerMessageList(rdb *redis.Client, queueListKey string) {
    rand.Seed(time.Now().UnixNano())
    log.Println("开启生产者。。。。")

    for i := 0; i < 10000; i++ {
        score := time.Now().Unix()
        log.Println("正在生产一条消息...", score, i)
        _, err := rdb.LPush(ctx, queueListKey, i).Result()
        if err != nil {
            log.Println(err)
        }
        //time.Sleep(time.Duration(rand.Intn(3)) * time.Second)
    }
}

func ConsumerMessageList(rdb *redis.Client, queueListKey string) {
    for {
        // Set a 5-second timeout
        value, err := rdb.BRPop(ctx, 5*time.Second, queueListKey).Result()
        if err == redis.Nil {
            time.Sleep(1 * time.Second)
            continue
        }
        if err != nil {
            time.Sleep(1 * time.Second)
            continue
        }
        log.Println("消费到数据：", value, "当前时间是：", time.Now().Unix())
        //time.Sleep(time.Second)
    }
}

func main() {

    rdb := redis.NewClient(&redis.Options{
        Addr:     "192.168.117.129:6379",
        Password: "foobared", // no password set
        DB:       0,          // use default DB
    })
    // Test whether the connection succeeds
    _ = rdb.Ping(context.Background()).Err()

    //_ = rdb.Set(ctx, "key", "123", 0).Err()
    //
    //val, _ := rdb.Get(ctx, "key").Result()
    //
    //fmt.Println("key", val)

    go ProducerMessageList(rdb, "queue:message")
    ConsumerMessageList(rdb, "queue:message")

}
```
