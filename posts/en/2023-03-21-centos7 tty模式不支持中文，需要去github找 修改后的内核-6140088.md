> **About this post**
>
> This post documents the issue where the tty console mode of CentOS 7 cannot display Chinese.
> The author points out that you need to look on GitHub for a modified kernel that supports Chinese display,
> and the QQ group number is attached at the end of the post.

> **Technical notes**
>
> CentOS 7 reached end of maintenance (EOL) on June 30, 2024; migrating to Rocky Linux 9 / AlmaLinux 9 or the domestic openEuler is recommended.
>
> The Linux tty uses the fbcon framebuffer console, whose built-in bitmap fonts contain no Chinese glyphs, so it cannot display Chinese natively;
> modified kernels on GitHub are mostly personal builds that lack continuous security updates, and the risks must be assessed on your own before using them in production.
