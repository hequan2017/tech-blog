> **About this post**
>
> This post documents a quick deployment of frp for NAT traversal: on the
> server side, install frps with a one-click script; on the client side,
> download the binary package and edit frpc.ini to map an intranet SSH port
> to a public server, enabling direct SSH access to machines behind NAT
> from the outside.

> **Technical notes**
>
> frp 0.44.0 used in this post still uses the ini configuration format;
> since v0.52.0, frp supports toml / yaml / json, and ini has been
> deprecated with renamed parameters (e.g. server_addr → serverAddr,
> bind_port → bindPort). After upgrading, old configurations must be
> rewritten in the new format.
>
> The frps one-click script in this post also has a GitHub repository,
> MvsCode/frps-onekey (plus a Gitee mirror); the code.aliyun.com URL in
> the original post may not remain available long-term.
>
> CentOS 7 reached end of life (EOL) on June 30, 2024; migrating to
> Rocky Linux 9 / AlmaLinux 9 or the domestic openEuler is recommended.

## 1. Server-Side Deployment

```shell
wget https://code.aliyun.com/MvsCode/frps-onekey/raw/master/install-frps.sh -O ./install-frps.sh
chmod 700 ./install-frps.sh
./install-frps.sh install
```

## 2. Client-Side Deployment

```shell
wget https://github.com/fatedier/frp/releases/download/v0.44.0/frp_0.44.0_linux_amd64.tar.gz
tar xf frp_0.44.0_linux_amd64.tar.gz

vim frpc.ini
```

```ini
[common]
server_addr = www.hequan.xyz
server_port = 5443
token = 123456

[ssh-123456]
type = tcp
local_ip = 127.0.0.1
local_port = 22
remote_port = 12345
```

```shell
nohup /root/frp_0.44.0_linux_amd64/frpc -c /root/frp_0.44.0_linux_amd64/frpc.ini &

ssh -o "StrictHostKeyChecking no" -p 12345 root@www.hequan.xyz
```
