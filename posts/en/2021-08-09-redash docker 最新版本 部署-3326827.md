> **About this post**
>
> Deploy Redash 10.0.0-beta with Docker Compose: orchestrate seven services — server, scheduler, scheduled_worker, adhoc_worker, Redis, PostgreSQL, and Nginx — configure the database, Redis, cookie secret, and mail parameters through an environment file, then initialize the database and start everything up.

> **Technical notes**
>
> The example is based on Redash 10.0.0-beta and Docker Compose v1 syntax; the stable Redash 10.0.0 release and later versions have since shipped, and Docker Compose v2 recommends `docker compose` (without the hyphen). The original `docker -compose` was a typo; the correct command is `docker-compose` or `docker compose`. Both PostgreSQL 9.6 and Redis 5.0 are EOL; upgrading is recommended for production environments.

### Installation Files

```yaml
version: "3.4"
x-redash-service: &redash-service
  image: redash/redash:10.0.0-beta.b49597
  depends_on:
    - postgres
    - redis
  env_file: /opt/redash/env
  restart: always
services:
  server:
    <<: *redash-service
    command: server
    ports:
      - "5000:5000"
    environment:
      REDASH_WEB_WORKERS: 4
  scheduler:
    <<: *redash-service
    command: scheduler
    environment:
      QUEUES: "celery"
      WORKERS_COUNT: 1
  scheduled_worker:
    <<: *redash-service
    command: worker
    environment:
      QUEUES: "scheduled_queries,schemas"
      WORKERS_COUNT: 1
  adhoc_worker:
    <<: *redash-service
    command: worker
    environment:
      QUEUES: "queries"
      WORKERS_COUNT: 2
  redis:
    image: redis:5.0-alpine
    restart: always
  postgres:
    image: postgres:9.6-alpine
    env_file: /opt/redash/env
    volumes:
      - /opt/redash/postgres-data:/var/lib/postgresql/data
    restart: always
  nginx:
    image: redash/nginx:latest
    ports:
      - "80:80"
    depends_on:
      - server
    links:
      - server:redash
    restart: always
```

### Startup

```shell
docker-compose up -d

docker-compose -f docker-compose.yml run --rm server create_db
```
