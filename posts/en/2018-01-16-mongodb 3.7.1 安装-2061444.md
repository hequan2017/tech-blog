> **About this post**
>
> A brief walkthrough of installing MongoDB 3.7.1 on CentOS with the official tgz package: extract and deploy to /usr/local/mongodb, write mongodb.conf (fork/port/bind_ip/dbpath/logpath), create the admin account and an account for the business database autoops after startup, then enable auth=true, restart, and demonstrate authenticated login.

> **Technical notes**
>
> The MongoDB 3.6/4.0 series has long been EOL; 3.7.1 was a development release at the time (never officially released), and 6.x/7.x/8.x is recommended for production today. Configuration files now use the YAML format (`storage.dbPath`, `net.bindIp`, etc.); the old-style `fork = true` and `bind_ip` key-value syntax has been deprecated since 2.6. The fastdl.mongodb.org links still work, but the version number needs to be replaced.

---

```shell
cd /usr/local/src/
wget https://fastdl.mongodb.org/linux/mongodb-linux-x86_64-3.7.1.tgz
tar -zxvf mongodb-linux-x86_64-3.7.1.tgz
mv mongodb-linux-x86_64-3.7.1   /usr/local/mongodb
echo "PATH=/usr/local/mongodb/bin:$PATH"  >> /etc/profile
source  /etc/profile

groupadd mongo
useradd  -rg mongo mongo
mkdir -p /data/db
chown -R mongo mongo  /usr/local/mongodb

cat >>  /usr/local/mongodb/bin/mongodb.conf  <<EOF
fork = true
port = 27017
bind_ip = 0.0.0.0
dbpath = /data/db
logpath = /data/db/mongodb.log
EOF

##Start
mongod --config  /usr/local/mongodb/bin/mongodb.conf
```

```shell
> use admin
switched to db admin
> db.createUser({user:"admin",pwd:"password",roles:["root"]})
Successfully added user: { "user" : "admin", "roles" : [ "root" ] }
> db.getCollectionNames()
[ "system.users", "system.version" ]

echo auth = true  >>  /usr/local/mongodb/bin/mongodb.conf      ##restart mongodb

##Log in with username and password
> db.auth("admin", "password")
```

```shell
#Create database
> use autoops

> db.createUser({user: "autoops", pwd: "autoops", roles: [{ role: "dbOwner", db: "autoops" }]})
Successfully added user: {
        "user" : "autoops",
        "roles" : [
                {
                        "role" : "dbOwner",
                        "db" : "autoops"
                }
        ]
}
```

mongo -u admin -p password  127.0.0.1:27017/admin
