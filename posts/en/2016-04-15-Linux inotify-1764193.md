> **About this post**
>
> This post introduces inotify, the asynchronous filesystem event monitoring
> mechanism on Linux, and how to pair it with an rsync daemon to achieve
> real-time backup: "write a file, notify rsync to run a command and sync."
> It covers checking the three parameters under /proc/sys/fs/inotify, building
> and installing inotify-tools from source, inotifywait usage such as
> -mrq/--timefmt/--format/-e create together with monitoring tests, writing a
> while read script that pushes changed files to rsync in real time, and closes
> with a complete parameter quick reference for inotify and rsync.

> **Technical notes**
>
> CentOS 6 reached end of life (EOL) in November 2020; production environments
> are advised to migrate to Rocky Linux / AlmaLinux / Ubuntu LTS. inotify-tools
> 3.13/3.14 were released long ago and the sourceforge direct links are no
> longer stable; on newer systems you can simply run `yum install inotify-tools`
> to use the distribution package. When monitoring large directories, if you get
> an error about insufficient watches, increase the kernel parameter
> `fs.inotify.max_user_watches`.

## 1. What Is inotify

inotify is an asynchronous filesystem event monitoring mechanism. The idea of pairing it with an rsync daemon:

```text
inotify process monitors /data/  --a file is written-->  notify rsync, run a command to sync
                                            rsync -avz /data/xx rsync_backup@192.168.10.10::hequan
                                            (synced to the /data/ served by the rsync daemon)
```

Commonly used implementations: inotify, sersync, lsyncd.

Prerequisite: have the rsync daemon server side deployed first.

## 3. Install inotify-tools from Source

Download the source package and build and install it:

```shell
wget http://tenet.dl.sourceforge.net/project/inotify-tools/inotify-tools/3.13/inotify-tools-3.13.tar.gz
tar zxvf inotify-tools-3.13.tar.gz
cd inotify-tools-3.13
./configure --prefix=/usr/local/inotify-tools-3.14
make && make install
cd ../
ln -s /usr/local/inotify-tools-3.14 /usr/local/inotify
```

Directories created after installation:

```text
drwxr-xr-x 2 root root 4096 4月   6 23:21 bin       commands
drwxr-xr-x 3 root root 4096 4月   6 23:21 include   header files
drwxr-xr-x 2 root root 4096 4月   6 23:21 lib       shared libraries
drwxr-xr-x 4 root root 4096 4月   6 23:21 share     help documentation
```

Main commands under the bin directory:

```text
|-- bin
|   |-- inotifywait
|   `-- inotifywatch
```

View the help:

```shell
./bin/inotifywait --help
```

## 4. Monitoring Test

Monitor create events on the /data directory:

```shell
/usr/local/inotify-tools-3.14/bin/inotifywait -mrq --timefmt '%d/%m/%y %H:%M' \
    --format '%T %w%f' -e create /data
```

Sample output:

```text
06/04/16  23:39 /data/xxx
```

`-e` can also listen for multiple events at once, monitoring them in parallel:

```text
-e create,delete,close_write
```

Simplified form (dropping the time format):

```shell
/usr/local/inotify-tools-3.14/bin/inotifywait -mrq --format '%w%f' -e create /data
```

## 5. Monitoring and Sync Script

```shell
#!/bin/sh
he="/usr/local/inotify-tools-3.14/bin/inotifywait"
$he -mrq --format '%w%f' -e create,close_write,delete /data | \
while read line
do
    rsync -az $line rsync_backup@192.168.10.10::hequan --password-file=/etc/rsync.password
done
```

Handy little commands for debugging and generating test data:

```shell
sh -x scriptname              # run with debugging
echo {a..d} | tr " " "\n"     # generate four lines: a b c d
paste a b                     # merge two files line by line
split -l 2 a                  # split out a file every 2 lines
```

## 6. inotify Parameters

- `-m` means keep listening forever
- `-r` means recurse into directories
- `-q` means print out events
- `-e create,move,delete,modify,attrib` means listening for "create, move, delete, write, attribute" events

## 7. rsync Parameter Quick Reference

- `-v, --verbose` verbose mode output
- `-q, --quiet` quiet output mode
- `-c, --checksum` turn on the checksum switch, forcing verification of file transfers
- `-a, --archive` archive mode, meaning transfer files recursively and preserve all file attributes; equivalent to -rlptgoD
- `-r, --recursive` process subdirectories recursively
- `-R, --relative` use relative path information
- `-b, --backup` create backups, that is, when a file with the same name already exists at the destination, rename the old file to ~filename. You can use the --suffix option to specify a different backup file prefix.
- `--backup-dir` store the backup files (such as ~filename) under a directory.
- `--suffix=SUFFIX` define the backup file prefix
- `-u, --update` update only, that is, skip all files that already exist on the DST side and whose timestamps are newer than the files to be backed up. (does not overwrite newer files)
- `-l, --links` preserve symlinks
- `-L, --copy-links` handle symlinks like regular files
- `--copy-unsafe-links` copy only links pointing outside the SRC path directory tree
- `--safe-links` ignore links pointing outside the SRC path directory tree
- `-H, --hard-links` preserve hard links
- `-p, --perms` preserve file permissions
- `-o, --owner` preserve file owner information
- `-g, --group` preserve file group information
- `-D, --devices` preserve device file information
- `-t, --times` preserve file timestamp information
- `-S, --sparse` handle sparse files specially to save space on the DST side
- `-n, --dry-run` show which files would be transferred
- `-W, --whole-file` copy whole files without delta detection
- `-x, --one-file-system` do not cross filesystem boundaries
- `-B, --block-size=SIZE` the block size used by the checksum algorithm, 700 bytes by default
- `-e, --rsh=COMMAND` specify rsh or ssh for data synchronization
- `--rsync-path=PATH` specify the path of the rsync command on the remote server
- `-C, --cvs-exclude` auto-ignore files the same way CVS does, to exclude files you do not want transferred
- `--existing` update only the files that already exist on the DST side, and do not back up newly created files
- `--delete` delete the files on the DST side that the SRC side does not have
- `--delete-excluded` also delete on the receiving side the files excluded by these options
- `--delete-after` delete only after the transfer finishes
- `--ignore-errors` delete even if I/O errors occur
- `--max-delete=NUM` delete at most NUM files
- `--partial` keep files that were not fully transferred for some reason, to speed up the next transfer
- `--force` force directory deletion, even if not empty
- `--numeric-ids` do not map numeric user and group IDs to user names and group names
- `--timeout=TIME` IP timeout, in seconds
- `-I, --ignore-times` do not skip files that have the same time and length
- `--size-only` when deciding whether to back up a file, look only at the file size and ignore the file time
- `--modify-window=NUM` the timestamp window used to decide whether file times are the same, 0 by default
- `-T, --temp-dir=DIR` create temporary files in DIR
- `--compare-dest=DIR` also compare against the files in DIR to decide whether a backup is needed
- `-P` equivalent to --partial
- `--progress` show the backup process
- `-z, --compress` compress the files being backed up during transfer
- `--exclude=PATTERN` specify patterns of files to exclude from transfer
- `--include=PATTERN` specify patterns of files not to exclude, i.e., to transfer
- `--exclude-from=FILE` exclude files matching the patterns specified in FILE
- `--include-from=FILE` do not exclude files matching the patterns specified in FILE
- `--version` print version information
- `--address` bind to a specific address
- `--config=FILE` specify a different configuration file instead of the default rsyncd.conf
- `--port=PORT` specify a different rsync service port
- `--blocking-io` use blocking I/O for the remote shell
- `--stats` give the transfer status of certain files
- `--progress` show the transfer process during transfer
- `--log-format=formAT` specify the log file format
- `--password-file=FILE` get the password from FILE
- `--bwlimit=KBPS` limit the I/O bandwidth, KBytes per second
- `-h, --help` show help information
