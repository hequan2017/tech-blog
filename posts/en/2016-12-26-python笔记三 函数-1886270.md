> **About this post**
>
> This is the third installment of my Python study notes, on the topic of
> functions. It starts with function definitions (def sayhi) and return values
> (return; None is returned by default), then goes through formal/actual
> parameters, default parameters, keyword arguments, and dynamic arguments
> (*args collects a tuple, **kwargs collects a dict). It then covers string
> format, lambda anonymous functions, the file modes of open (r/w/a/r+/b, etc.)
> and tell/seek/truncate; summarizes the kinds of arguments and local/global
> variables; explains map/reduce/filter, list and dict comprehensions, zip,
> and generator expressions with examples; and finally demonstrates
> line-by-line text-file processing with with open and pickle serialization.

> **Technical notes**
>
> These notes are based on Python 2.7: the `<type 'generator'>` output and
> `reduce` being directly available are both 2.x traits. In Python 3, reduce
> has moved into functools (`from functools import reduce`), and map/filter
> return iterators rather than lists. The naming in the dynamic-argument
> examples below runs counter to convention (`*kwargs` collects a tuple,
> `**arg` collects a dict); the usual convention is `*args` for tuples and
> `**kwargs` for dicts. The `u` file mode (universal newlines) was removed in
> Python 3, where universal newlines are the default.

## 1. Function basics (original: 11/1)

A function wraps a group of statements together under a single name (the
function name); to execute it, you simply call that name.

```python
def sayhi():          # sayhi is the function name
    print("hello , i'm hequan")

sayhi()               # call
```

### Return values

```python
def calc(x, y):
    res = x**y
    return res        # returns the result of the function
```

By default, a function returns None.

## 2. Arguments (original: 11/2)

Formal and actual parameters:

```python
def mail(formal_parameter):
    ret = mail(actual_parameter)
    if ret:
        print("Sent successfully")
```

Default parameters must come last:

```python
def mail(a1, a2=11):
    ...
```

Keyword arguments (assigning values to specified parameters, placed after
positional arguments):

```python
def mail(a1, a2):
    ...

mail(a2=123, a1=321)   # keyword arguments
```

### Dynamic arguments

`*` packs the arguments into a tuple:

```python
def show(*arg):        # * packs the arguments into a tuple
    print(arg, type(arg))    # the original first line had a typo, "agr", corrected here

show(11, 22, 33, 44)
```

`**` packs the arguments into a dict:

```python
def show(**arg):       # ** packs the arguments into a dict
    print(arg, type(arg))

show(n1=11, n2=22, n3=33, n4=44)
```

Mixing the two (the original naming runs counter to convention: `*kwargs`
receives a tuple and `**arg` receives a dict):

```python
def show(*kwargs, **arg):
    print(arg, type(arg))
    print(*kwargs, type(kwargs))

show(11, 22, 33, 44, n1=11, n2=22, n3=33, n4=44)
```

Output:

```text
{'n3': 33, 'n4': 44, 'n1': 11, 'n2': 22} <class 'dict'>
11 22 33 44 <class 'tuple'>
```

Existing variables can also be unpacked and passed in directly: `show(*a, **b)`.

## 3. format and lambda (original: 11/3)

String formatting supports `{0}` positional placeholders as well as `{name}`
named placeholders:

```python
s1 = "{0} is {1}"
xx = s1.format('hequan', '2b')
print(xx)
# hequan is 2b
```

lambda expressions, for simple functions:

```python
he = lambda a: a+1
print(he(1))
```

## 4. The open function and file modes

The built-in open function is used for file handling:

- `r` read-only, `w` write-only, `a` append
- `r+` read/write, `w+` write/read, `a+` same as a
- `u` automatic conversion to `\n` (universal newlines in Python 2)
- `b` for handling binary files
- `close` closes the file
- `tell()` shows the current pointer position
- `seek()` sets the pointer position
- `read` reads
- `truncate()` keeps only the bytes before the pointer position and saves them to the file
- `write` writes

## 5. Summary

Types of arguments: formal parameters, actual parameters, default parameters,
keyword arguments (placed after positional arguments), and variable-length
arguments `*args`/`**kwargs` (receiving a tuple/dict; the typo for "tuple" in
the original has been corrected here).

Variables: local variables and global variables.

Function features: return values via return (as soon as execution hits a
return statement, the function stops and returns the result; return marks the
end of the function; without a return, the value is None), nested functions,
recursion, and anonymous functions.

## 6. map / reduce / filter

map can apply the same operation to every element of an iterable:

```python
map(lambda x: x**2, [1, 2, 3, 4])                # [1, 4, 9, 16]

map(lambda x, y: x + y, [1, 2, 3], [5, 6, 7])    # [6, 8, 10]
```

reduce performs a two-input operation on the elements of an iterable in order,
storing each result to serve as the first input of the next operation, with
the not-yet-traversed element as the second input. The effect is to reduce a
sequence of iterable values into a single object:

```python
reduce(lambda x, y: x + y, [1, 2, 3, 4])         # ((1+2)+3)+4=10
```

filter selects from an iterable according to a condition:

```python
filter(lambda x: x % 2, [1, 2, 3, 4, 5])         # keeps the odd numbers, [1, 3, 5]
```

## 7. List comprehensions and zip

```python
[x**2 for x in [1, 2, 3, 4, 5]]
```

The zip function ties multiple lists together:

```python
[sum(x) for x in zip([1, 2, 3], [5, 6, 7])]      # [6, 8, 10]
```

Generator expressions:

```python
iter_odd = (x for x in [1, 2, 3, 4, 5] if x % 2)
print(type(iter_odd))   # <type 'generator'> (Python 2 output)
```

Dict comprehensions:

```python
square_dict = {x: x**2 for x in range(5)}        # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
```

## 8. File operations and pickle

The first argument of open() is the file name and the second is the mode.
There are generally four file modes: read (r), write (w), append (a), and
read/write (r+). To read the file as binary data, combine the mode with b
(wb, r+b, ...).

```python
with open('xx.txt', 'r') as f:
    lines = f.readlines()
    for line in lines:
        name, age = line.rstrip().split(',')
        print('{} is {} years old'.format(name, age))
```

Serializing and reading back with pickle:

```python
import pickle

lines = [
    "I'm like a dog chasing cars.",
    "I wouldn't know what to do if I caught one...",
    "I'd just do things."
]

with open('lines.pkl', 'wb') as f:
    pickle.dump(lines, f)

with open('lines.pkl', 'rb') as f:
    lines_back = pickle.load(f)
    print(lines_back)
```
