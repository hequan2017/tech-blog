> **About this post**
>
> This post compiles and deploys LNMP from source on CentOS 6.8 (minimal install): nginx 1.11.0 + MySQL 5.7.12 +
> PHP 5.6.22. It first clarifies the LNMP request chain (fastcgi_pass → FastCGI → mysql_connect() →
> DBMS), then completes in turn: installing the build dependencies and downloading the source packages, the nginx
> configure options and the /application symlink, the MySQL 5.7 cmake + boost 1.59 build, the --initialize
> initialization and changing the root password from the temporary one, building and symlinking the PHP prerequisite
> libraries libiconv/libmcrypt/mhash/mcrypt, compiling and installing php-fpm and registering it as a boot-start
> service; the post ends with a quick-reference table of what each dependency library is for.

> **Technical notes**
>
> CentOS 6 reached end of maintenance (EOL) in November 2020; production environments are advised to migrate to Rocky Linux / AlmaLinux / Ubuntu LTS.
> Version currency: nginx 1.11 was a development branch; MySQL 5.7 reached end of maintenance in October 2023; PHP 5.6
> official security support ended at the end of 2018 — use PHP 8.x now (--with-mysql has been removed; use mysqli/PDO throughout).
> MySQL 5.7's cmake no longer has the -DMYSQL_USER option; it is a leftover parameter from older versions and can be dropped.

## 1. LNMP Architecture and Request Chain

```text
nginx                            PHP5                                             mysql

fastcgi_pass → FastCGI ←→ mysql_connect()  → connect DBMS →
mysql_select_db() → connect Database → data
```

## 3. Compiling and Installing nginx 1.11.0

```shell
useradd -s /sbin/nologin   -M nginx

tar xf nginx-1.11.0.tar.gz
cd nginx-1.11.0

./configure   --user=nginx   --group=nginx  --prefix=/application/nginx1.11.0  \
--with-http_ssl_module \
--with-http_flv_module \
--with-http_stub_status_module \
--with-http_gzip_static_module \
--http-client-body-temp-path=/var/tmp/nginx/client/ \
--http-proxy-temp-path=/var/tmp/nginx/proxy/ \
--http-fastcgi-temp-path=/var/tmp/nginx/fcgi/ \
--http-uwsgi-temp-path=/var/tmp/nginx/uwsgi \
--http-scgi-temp-path=/var/tmp/nginx/scgi \
--with-pcre

make  &&  make install

mkdir -p /var/tmp/nginx/client
ln -s /application/nginx1.11.0/  /application/nginx
/application/nginx/sbin/nginx
```

## 4. Compiling and Installing MySQL 5.7.12

Install the build dependencies and prepare the account and directories:

```shell
yum -y install  gcc gcc-c++ autoconf automake zlib* flex* libxml* ncurses-devel libmcrypt* libtool-ltdl-devel* make cmake  libaio libaio-devel autoconf bzr bison libtool

groupadd mysql
useradd -r -g mysql mysql  -M  -s /sbin/nologin

tar -zxvf mysql-5.7.12.tar.gz

mkdir -p /application/mysql/data
chown -R mysql.mysql /application/mysql/data/
chown -R mysql:mysql  /application/mysql
```

Download and extract boost (a build dependency of MySQL 5.7):

```shell
wget    http://sourceforge.net/projects/boost/files/boost/1.59.0/boost_1_59_0.tar.gz
tar zxvf boost_1_59_0.tar.gz -C /application/boost
```

Build and install with cmake:

```shell
cd mysql-5.7.12

cmake \
-DCMAKE_INSTALL_PREFIX=/application/mysql \
-DMYSQL_DATADIR=/application/mysql/data \
-DMYSQL_UNIX_ADDR=/tmp/mysql.sock \
-DDEFAULT_CHARSET=utf8 \
-DMYSQL_USER=mysql \
-DDEFAULT_COLLATION=utf8_general_ci \
-DEXTRA_CHARSETS=all \
-DMYSQL_TCP_PORT=3306  \
-DSYSCONFDIR=/etc \
-DENABLED_LOCAL_INFILE=1 \
-DDOWNLOAD_BOOST=1 \
-DWITH_BOOST=/application/boost/

make -j 2 && make install
```

Initialize and register the service:

```shell
cd /application/mysql/bin

./mysqld --initialize   --user=mysql --datadir=/application/mysql/data --basedir=/application/mysql --socket=/tmp/mysql.sock

cd /application/mysql/support-files/

cp mysql.server /etc/init.d/mysqld
cp my-default.cnf /etc/my.cnf

chmod 755 /etc/init.d/mysqld

chkconfig --add mysqld
chkconfig mysqld on

sed -i "/# port = */c port = 3306"  /etc/my.cnf
sed -i "/# basedir = */c basedir= /application/mysql"  /etc/my.cnf
sed -i "/# datadir = */c datadir= /application/mysql/data"  /etc/my.cnf
sed -i "/# socket = */c socket = /tmp/mysql.sock"  /etc/my.cnf

/etc/init.d/mysqld start

echo "PATH=/application/mysql/bin:/application/mysql/lib:$PATH" >> /etc/profile
echo "export PATH " >> /etc/profile
source  /etc/profile
```

Key settings in `/etc/my.cnf`:

```ini
[mysqld]
port=3306
basedir=/application/mysql
datadir=/application/mysql/data
socket=/tmp/mysql.sock
```

### Change the root password using the temporary password

The `--initialize` initialization generates a default password when it completes:

```shell
2016-05-30T05:06:59.388996Z 1 [Note] A temporary password is generated for root@localhost: %+TbbU<FV3sZ
```

```shell
mysql -uroot -p'%+TbbU<FV3sZ'
```

```sql
set password=password('yourpassword');
alter user 'root'@'localhost' password expire never;
flush privileges;
```

## 6. Compiling and Installing PHP 5.6.22 and php-fpm

```shell
cd /hequan/
tar -jxvf php-5.6.22.tar.bz2
cd php-5.6.22

./configure --prefix=/application/php --with-config-file-path=/application/php/etc --enable-fpm --with-fpm-user=www --with-fpm-group=www --with-mysql=mysqlnd --with-mysqli=mysqlnd --with-pdo-mysql=mysqlnd --with-iconv-dir --with-freetype-dir --with-jpeg-dir --with-png-dir --with-zlib --with-libxml-dir=/usr --enable-xml --disable-rpath --enable-magic-quotes --enable-safe-mode --enable-bcmath --enable-shmop --enable-sysvsem --enable-inline-optimization --with-curl --with-curlwrappers --enable-mbregex --enable-mbstring --with-mcrypt --enable-ftp --with-gd --enable-gd-native-ttf --with-openssl --with-mhash --enable-pcntl --enable-sockets --with-xmlrpc --enable-zip --enable-soap --without-pear --with-gettext --disable-fileinfo --enable-maintainer-zts

make ZEND_EXTRA_LIBS='-liconv'
make install
```

Copy the configuration files and register the boot-start service:

```shell
cp php.ini-production /application/php/etc/php.ini
cp sapi/fpm/init.d.php-fpm /etc/init.d/php-fpm
chmod u+x /etc/init.d/php-fpm
chkconfig --add php-fpm
chkconfig php-fpm on
```

Create the fpm runtime account and start it:

```shell
groupadd www
useradd -s /sbin/nologin -g www -M www

mv /application/php/etc/php-fpm.conf.default /application/php/etc/php-fpm.conf

ln -s /application/php/etc/php.ini /etc/php.ini
ln -s /application/php/etc/php-fpm.conf /etc/php-fpm.conf

/application/php/sbin/php-fpm
```

## 7. Quick Reference for the Dependency Libraries

- zlib ====> library providing data compression functions
- pcre ====> support library for rewrite
- openssl ====> support library for https
- libiconv ====> character encoding conversion library
- libxml ====> XML library
- libpng ====> image library
- freetype ====> font library
- libmcrypt ====> encryption algorithms
- mhash ====> encryption/hashing library
- curl ====> URL transfer
- gd ====> drawing
