> **About this post**
>
> This post summarizes two typical errors of zabbix-agent 3.0.3 (the CentOS 6
> RPM build) at startup and during runtime, along with their solutions. The
> first is the log message `no active checks on server ... host [Zabbix test]
> not found`, caused by a mismatch between the host name configured on the web
> frontend and the Hostname in the agent configuration file; making the two
> identical resolves it. The second is a `Permission denied` failure to create
> the PID file when agentd starts, resolved by creating the /var/run/zabbix
> directory and chown-ing it to the zabbix user. A screenshot of the dashboard
> host configuration and the corresponding commands are included.

> **Technical notes**
>
> zabbix 3.0 reached end of support in 2019; the current LTS releases are 6.0
> (supported until 2027) and 7.0. The el6 agent package ended with CentOS 6's
> EOL as well, so install the agent for the matching distribution on new
> systems. Active checks require the Hostname in zabbix_agentd.conf to match
> the frontend "host name" exactly (case-sensitive); use
> `zabbix_agentd -t system.hostname` to verify. Recent official packages
> create /var/run/zabbix automatically via systemd's RuntimeDirectory, so the
> PID file permission issue rarely occurs anymore.

## 1. Environment and Checking the Log

```shell
[root@shell ~]# rpm -qa zabbix-agent
zabbix-agent-3.0.3-1.el6.x86_64
```

Starting zabbix_agentd reports an error; check the log:

```shell
tail -f /var/log/zabbix/zabbix_agentd.log
```

## 2. Error 1: host not found (Hostname mismatch)

The error:

```text
1261:20160627:185115.613 no active checks on server [192.168.10.41:10051]: host [Zabbix test] not found
```

Solution: this is caused by mismatched hostnames; make them identical:

```ini
Hostname=Zabbix test
```

![Zabbix host configuration page, with the host name set to Zabbix test](../assets/1794376/01_wKioL1dz3EehOq1iAAAL4MOlA7k080.png)

## 3. Error 2: Permission denied on the PID file

The error:

```text
zabbix_agentd [1316]: cannot create PID file [/var/run/zabbix/zabbix_agentd.pid]: [13] Permission denied
```

Solution:

```shell
mkdir -p /var/run/zabbix/
chown zabbix.zabbix /var/run/zabbix/
```
