> **About this post**
>
> This post summarizes common mysqldump backup and recovery methods: backing up and
> restoring a single database, multiple databases (-B), and multiple tables within a
> database; the roles of the DROP TABLE IF EXISTS and LOCK/UNLOCK TABLES statements in
> the backup file; the extra database-creation statements that -B adds to the backup;
> and gzip-compressed backup with decompression for restore. The focus is a sed-plus-pipe
> one-liner that generates per-database backup commands and a for-loop script for
> per-database backups; -d for schema only, -t for data only, and full backup with
> -A --events plus handling of the mysql.event warning; binlog-related topics (-F to
> flush logs, --master-data to record the log position, viewing with mysqlbinlog); the
> source and input-redirect recovery methods; passwordless login via .my.cnf; batch
> restore of multiple per-database files; and finally an analysis of the cause of
> ERROR 1046 No database selected, with troubleshooting commands such as show processlist.

> **Technical notes**
>
> Since MySQL 8.0, mysqldump enables `--set-gtid-purged` by default; when importing in a
> GTID environment, add `--set-gtid-purged=OFF` as needed. Older options such as `-l`
> (read-only lock) are deprecated in newer releases; for large production databases,
> prefer xtrabackup/physical backups. Plaintext passwords on the command line risk
> leakage; ~/.my.cnf or mysql_config_editor is recommended.

## 1. Basic Backup and Restore Commands

```shell
mysqldump -uroot -p123456 --default-character-set=utf8 quan > /opt/quan.sql    # backup
grep -Ev "#|\/|--|^$" quan.sql    # view file contents (filter out comments and empty lines)
```

Key statements in the backup file:

```sql
DROP TABLE IF EXISTS `test`;    # drop the old table
LOCK TABLES `test` WRITE;       # lock
UNLOCK TABLES;                  # unlock
```

```shell
mysql -uroot -p123456 quan < /opt/quan.sql    # restore
```

With -B, the backup gains the following two extra lines (create the database, switch to it):

```sql
CREATE DATABASE /*!32312 IF NOT EXISTS*/ `quan` /*!40100 DEFAULT CHARACTER SET gbk */;
USE `quan`;
```

No need to create the database before restoring; just restore directly:

```shell
mysql -uroot -p123456 < /opt/quan_B.sql
```

For debugging you can use `--compact`: fewer output comments, a smaller backup, and no locks added.

## 2. Compressed Backup and Multi-Database/Multi-Table Backup

```shell
mysqldump -uroot -p123456 quan | gzip > /opt/quan.sql.gz    # compressed backup
gunzip quan.sql.gz    # decompress, then restore
```

--databases, -B: backs up multiple databases. Without this option, mysqldump treats the first name argument as a database name and the rest as table names; with this option, mysqldump treats every name as a database name.

```shell
mysqldump -uroot -p123456 -B quan he | gzip > /opt/quan.sql.gz       # back up multiple databases
mysqldump -uroot -p123456 quan test test1 | gzip > /opt/quan.sql.gz  # back up tables within a database
```

## 3. Per-Database Backup Command

First generate the per-database backup commands (printed, not executed):

```shell
mysql -uroot -p123456 -e "show databases;" | grep -Evi "database|infor|perfor" | sed 's#^#mysqldump -uroot -p123456 -B #g'
```

Append `| bash` to execute directly, packing each database separately:

```shell
mysql -uroot -p123456 -e "show databases;" | grep -Evi "database|infor|perfor" | sed -r 's#^([a-z].*$)#mysqldump -uroot -p123456 -B \1 | gzip > /opt/\1.sql.gz#g' | bash
```

## 4. Loop Script for Per-Database Backup

```shell
#!/bin/bash
for name in `mysql -uroot -p123456 -e "show databases;" | grep -Evi "database|infor|perfor"`
do
mysqldump -uroot -p123456 --events --ignore-table=mysql.event -B $name | gzip > /opt/${name}.sql.gz
done
```

## 5. Schema / Data / Full Backup

```shell
mysqldump -uroot -p123456 -d quan > /opt/quan1.sql    # --no-data, -d: export table schema only
mysqldump -uroot -p123456 -t quan > /opt/quan1.sql    # -t = --no-create-info, back up data only
```

- Export all databases: `--all-databases`, -A
- Export all tablespaces: `--all-tablespaces`, -Y

```shell
mysqldump -uroot -p123456 -A -B --events > /opt/quan1.sql    # back up everything
```

A full export runs into the following warning (by default the event table is not backed up; the warning goes away only when --events is added):

```text
Warning: Skipping the data of table mysql.event. Specify the --events option explicitly
```

Solution: `--events --ignore-table=mysql.event`.

## 6. binlog

```ini
# vim /etc/my.cnf
#log-bin=mysql-bin    # commented out = disabled
```

binlog files live in the data directory, e.g. mysql/data/mysql-bin.000001.

- mysqldump `-F`: flush the bin-log
- `--master-data=2`/1: add the binlog file name and corresponding position to the backup file (2 = as a comment, 1 = executable form)

Before using it for the first time, comment out `default-character-set=utf8` in the [client] section of my.cnf, then view:

```shell
mysqlbinlog /application/mysql/data/mysql-bin.000001
```

## 8. Restore Methods and Passwordless Login

Method one, source after logging in:

```sql
use quan;
mysql> source /root/quan.sql
```

Method two, standard input redirection:

```shell
mysql -uroot -p123456 hequan < /opt/hequan.sql
```

Set up passwordless login by writing `~/.my.cnf`:

```ini
[client]
user=root
host=localhost
password=123456
```

## 9. Batch Restore of Per-Database Files

```shell
for name in `ls *.sql | sed 's#.sql##g'`; do mysql -uroot -p123456 < ${name}.sql; done
```

## 10. Troubleshooting ERROR 1046

```text
ERROR 1046 (3D000) at line 22: No database selected
```

Cause: the SQL file being restored does not select a database. Solution: edit the .sql file and add `use db_name;` before line 22.
