> **About this post**
>
> Implement DingTalk QR code login for a Django site: the frontend embeds the DingTalk ddLogin.js QR code; after the user scans it, DingTalk calls back with a code; the backend then calls sns/gettoken, sns/get_persistent_code, sns/get_sns_token, and sns/getuserinfo in turn to fetch user information, and finally looks up the user in the Django User table by unionid — creating the account automatically if it does not exist — and completes the login.

> **Technical notes**
>
> The old DingTalk sns API series used in this post (oapi.dingtalk.com/sns/*) has been superseded by the new "QR code login for third-party websites" API (api.dingtalk.com v1.0); the old APIs still work but are no longer recommended for new integrations. Also, writing a plaintext password directly via `User.objects.create(password=...)` as in the original example is incorrect usage; the code in this post has been corrected to use `set_password`.

### Django DingTalk Login

#### Principle

> First fetch the DingTalk user information; after that, check whether the user exists in the Django User table — if not, create it; if it exists, log in as usual.
> The check is based on the unique ID.

##### views.py

> appId and appSecret are the DingTalk app credentials

```python
import requests
import random

def login_dingding(request):
    if request.method == "GET":
        code = request.GET.get('code', )
        state = request.GET.get('state', )

        appId = 'xxxxxxxxxxxxxxxxxxxxxxxxxxx'
        appSecret = 'xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx'

        token = requests.get(f'https://oapi.dingtalk.com/sns/gettoken?appid={appId}&appsecret={appSecret}')
        access_token = token.json()["access_token"]

        tmp_auth_code = requests.post(f"https://oapi.dingtalk.com/sns/get_persistent_code?access_token={access_token}",
                                      json={
                                          "tmp_auth_code": code
                                      })
        tmp_code = tmp_auth_code.json()
        print(tmp_code)
        openid = tmp_code['openid']
        persistent_code = tmp_code['persistent_code']

        sns_token_request = requests.post(f"https://oapi.dingtalk.com/sns/get_sns_token?access_token={access_token}",
                                          json={
                                              "openid": openid,
                                              "persistent_code": persistent_code
                                          })

        sns_token = sns_token_request.json()['sns_token']

        user_info_request = requests.get(f'https://oapi.dingtalk.com/sns/getuserinfo?sns_token={sns_token}')

        user_info = user_info_request.json()['user_info']
        print(user_info)

        try:
            user = User.objects.get(first_name=user_info['unionid'])
        except Exception as e:
            password = f'hequan{random.randint(1000,9999)}'
            try:
                user = User(username=user_info['nick'], first_name=user_info['unionid'])
                user.set_password(password)
                user.save()
            except Exception as e:
                user = User(username=f"{user_info['nick']}{random.randint(0,9999)}", first_name=user_info['unionid'])
                user.set_password(password)
                user.save()

        finally:
            login(request, user)
            request.session['is_login'] = True
            login_ip = request.META['REMOTE_ADDR']
            LoginLogs.objects.create(user=request.user, ip=login_ip)

        return redirect('/index.html')
```
