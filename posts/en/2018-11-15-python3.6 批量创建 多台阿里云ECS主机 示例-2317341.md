> **About this post**
>
> This post is a follow-up to the earlier post on creating a single ECS instance. It switches to the Alibaba Cloud RunInstances API to batch-create multiple ECS instances in one call (up to 100 at a time, with UniqueSuffix support for automatically appending hostname suffixes), avoiding the API throttling problems caused by creating instances one by one in a for loop. It provides a complete AliyunEcsCreate wrapper class covering queries for regions, available resources, images, VPCs, vSwitches, and security groups, along with methods such as CreateInstance / RunInstances / AllocatePublicIpAddress / StartInstance.

> **Technical notes**
>
> The legacy Alibaba Cloud Python SDK used in this post (aliyun-python-sdk-core-v3 / aliyun-python-sdk-ecs 4.x, V1-style RPC) has entered maintenance mode. Alibaba Cloud has officially released the V2.0 SDK (alibabacloud_ecs20140526), with improvements to signing, async support, and exception handling; new code is advised to migrate. Python 3.6 reached end of life at the end of 2021, so please upgrade your runtime environment as well.

### RunInstances

#### Introduction

See the previous post: [Python 3.6 Example of Creating an Alibaba Cloud ECS Instance via the API (SDK)](http://blog.51cto.com/hequan/2174407) (link to the old site, may no longer work)

The previous post created a single instance; creating multiple instances required a for loop, which is cumbersome and prone to API throttling. With RunInstances you can batch-create multiple instances at once. Note the following when calling this API:

- A single call can create up to 100 instances.
- You can specify the AutoReleaseTime parameter to set when instances are automatically released.
- On success, the API returns a list of instance IDs; you can query the state of the new instances via the DescribeInstances API.
- Before creating instances, make sure you already have an available security group. For more details, see CreateSecurityGroup.
- Instances are started automatically upon creation, until their state becomes Running.
- Before creating a VPC-type instance, you must first create a VPC in the corresponding Alibaba Cloud region.
- Compared with CreateInstance, instances created via RunInstances are automatically assigned a public IP when the InternetMaxBandwidthOut parameter is greater than 0.
- After the creation task is submitted, an error is reported if the parameters are invalid or inventory is insufficient; see the error codes for the specific cause.
