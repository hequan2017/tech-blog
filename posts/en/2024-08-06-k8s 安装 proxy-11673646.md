> **About this post**
>
> This post documents the process of deploying a ClashForLinux (Clash) proxy on a k8s node:
> after starting Clash, a systemd drop-in is used to configure an HTTP proxy
> (port 7890) for Docker and containerd, so that operations such as pulling images go through the proxy.

> **Technical notes**
>
> CentOS 7 reached end of life (EOL) on June 30, 2024; migrating to Rocky Linux 9 / AlmaLinux 9 or the domestic openEuler is recommended.
>
> Clash's default HTTP proxy port is 7890 (9090 is the admin dashboard port). The containerd proxy configuration
> in this post does not set NO_PROXY; if your cluster contains internal network segments or a private image registry, append them as needed to keep internal traffic off the proxy.

---

## 1. Install Clash

```shell
git clone https://github.com/AFanSKyQs/ClashForLinux.git
cd ClashForLinux
bash StartRun.sh
```

## 2. Start Manually

```shell
/home/k8s/ClashForLinux/bin/clash-linux-amd64 -d /home/k8s/ClashForLinux/conf
```

## 3. Configure the Proxy for Docker and containerd

```shell
export http_proxy=http://192.168.123.190:7890
export https_proxy=http://192.168.123.190:7890

mkdir -p /etc/systemd/system/docker.service.d

tee /etc/systemd/system/docker.service.d/http-proxy.conf << EOF
[Service]
Environment="HTTP_PROXY=http://192.168.123.190:7890"
Environment="HTTPS_PROXY=http://192.168.123.190:7890"
Environment="NO_PROXY=localhost,127.0.0.1"
EOF

mkdir -p /etc/systemd/system/containerd.service.d/

tee /etc/systemd/system/containerd.service.d/http-proxy.conf <<EOF
[Service]
Environment="HTTP_PROXY=http://192.168.123.190:7890"
Environment="HTTPS_PROXY=http://192.168.123.190:7890"
EOF
```

## 4. Restart to Apply

```shell
systemctl daemon-reload && systemctl restart containerd
```
