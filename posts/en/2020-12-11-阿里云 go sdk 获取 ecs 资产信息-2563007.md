> **About this post**
>
> Query the list of ECS instances in a specified region using the Alibaba Cloud Go SDK: create a client with an AK/SK pair, call the `DescribeInstances` API to fetch instance information and print the instance IDs. A good introductory example for collecting cloud asset information.

> **Technical notes**
>
> The example is based on Alibaba Cloud's legacy `alibaba-cloud-sdk-go` (2020); Alibaba Cloud has since released the V2.0 Go SDK (modular packages such as `alibabacloud-go/ecs-20140526`), which is recommended for new projects. The import path in the original post was truncated; it should actually be `github.com/aliyun/alibaba-cloud-sdk-go/services/ecs`. Hard-coded AK/SK credentials are suitable only for testing; in production, it is recommended to inject them via a RAM role or environment variables.

---

```go
import (
	"fmt"
	"time"

	"github.com/aliyun/alibaba-cloud-sdk-go/services/ecs"
)

client, _ := ecs.NewClientWithAccessKey("cn-beijing", "11111111111111", "222222222222222222222")
request := ecs.CreateDescribeInstancesRequest()
response, _ := client.DescribeInstances(request)
```
