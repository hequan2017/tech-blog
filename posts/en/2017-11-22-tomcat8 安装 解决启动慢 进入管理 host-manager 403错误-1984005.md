> **About this post**
>
> This post documents how to install Tomcat 8.5.23 on CentOS and the common
> pitfalls: first install JDK 8 and configure JAVA_HOME and the other
> environment variables, then deploy Tomcat with a symlink and a setenv.sh;
> for the slow startup problem it offers two fixes, adding the urandom
> parameter to catalina.sh and editing java.security; next it configures
> manager.xml and tomcat-users.xml to allow logins to the Manager pages from
> all IPs, fixing the host-manager 403; finally it shows how to change the
> port to 80, set the default site path, and define the welcome page.

> **Technical notes**
>
> Tomcat 8.5 reached end of maintenance on March 31, 2024 (final release
> 8.5.100); choose 9.x/10.x for new deployments. JDK 8 requires an Oracle
> login to download; OpenJDK works as a direct substitute. The root cause of
> the slow startup is entropy starvation (securerandomsource blocking); besides
> the urandom change shown here, installing haveged or rng-tools also fixes it.
> Content swallowed by the original editor has been restored: the
> `echo ... >>` line now includes the redirect target setenv.sh; "add a line
> to" is now specified as bin/catalina.sh; and the non-breaking spaces (NBSP)
> copied in from the web page were normalized to regular spaces.

## 1. Install JDK 8

Go to the Oracle page, accept the agreement, and download JDK 8 (the wget URL
is the download page, so a browser is required):

```bash
cd /usr/local/src
wget http://www.oracle.com/technetwork/java/javase/downloads/jdk8-downloads-2133151.html
##Go in, accept the agreement, download jdk8

tar zxvf jdk-8u144-linux-x64.tar.gz
mv jdk1.8.0_144/   /usr/local/jdk8.0

vim /etc/profile
JAVA_HOME=/usr/local/jdk8.0
JAVA_BIN=/usr/local/jdk8.0/bin
PATH=$PATH:$JAVA_BIN
CLASSPATH=$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar
export JAVA_HOME JAVA_BIN PATH CLASSPATH
export CATALINA_BASE=/usr/local/tomcat
export CATALINA_HOME=/usr/local/tomcat

source /etc/profile
```

## 2. Install Tomcat 8.5

```bash
cd /usr/local/src/
wget https://mirrors.tuna.tsinghua.edu.cn/apache/tomcat/tomcat-8/v8.5.23/bin/apache-tomcat-8.5.23.tar.gz
tar zxvf apache-tomcat-8.5.23.tar.gz
mv apache-tomcat-8.5.23  /usr/local/tomcat8.5

ln -s /usr/local/tomcat8.5/ /usr/local/tomcat
cd /usr/local/tomcat/bin/
echo "CATALINA_HOME=/usr/local/tomcat8.5/"  >> setenv.sh
chmod +x   *.sh
./startup.sh
```

## 3. Fixing the slow startup

Option 1: add this line to `bin/catalina.sh`:

```bash
JAVA_OPTS="-Djava.security.egd=file:/dev/./urandom"
```

Option 2: open `$JAVA_PATH/jre/lib/security/java.security` and find the
following:

```properties
securerandom.source=file:/dev/urandom
```

Replace it with:

```properties
securerandom.source=file:/dev/./urandom
```

## 4. Accessing the Manager pages

Create a manager.xml file under `conf/Catalina/localhost/` with the following
content (allows access from all IPs):

```xml
<Context privileged="true" antiResourceLocking="false"
         docBase="${catalina.home}/webapps/manager">
    <Valve className="org.apache.catalina.valves.RemoteAddrValve" allow="^.*$" />
</Context>
```

Adding users: inside the `<tomcat-users></tomcat-users>` tags in
`conf/tomcat-users.xml`, add the following:

```xml
<role rolename="manager-gui"/>
<role rolename="manager-script"/>
<role rolename="manager-jmx"/>
<role rolename="manager-status"/>
<role rolename="admin-gui"/>
<role rolename="admin-script"/>

<user username="admin" password="admin" roles="manager-gui,manager-script,manager-jmx,manager-status,admin-gui,admin-script"/>
<user username="deploy" password="deploy" roles="manager-script"/>
```

## 5. host-manager 403 error

host-manager still returns 403; the fix is the same, allowing all IPs:

```xml
vim /usr/local/tomcat/webapps/host-manager/META-INF/context.xml
<Context antiResourceLocking="false" privileged="true" >
     <Valve className="org.apache.catalina.valves.RemoteAddrValve"
     allow="^.*$" /> # modify here
</Context>
```

## 6. Changing the port and the default site

Change the port to 80:

```xml
vim conf/server.xml
<Connector port="80" protocol="HTTP/1.1"
               connectionTimeout="20000"
               redirectPort="8443" />
```

Change the default webapp path (`docBase` is the path you want to visit):

```xml
vim conf/server.xml
<Host name="localhost"  appBase="webapps"
            unpackWARs="true" autoDeploy="true">

<Context path="" docBase="/usr/local/tomcat/webapps/shyt/" debug="0"/>   ### add this line

</Host>
```

Change the default welcome file:

```xml
vim conf/web.xml
<welcome-file-list>
    <welcome-file>index.html</welcome-file>
    <welcome-file>index.htm</welcome-file>
    <welcome-file>index.jsp</welcome-file>
</welcome-file-list>
```
