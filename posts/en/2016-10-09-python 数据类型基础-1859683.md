## 2. Number

Python 3 supports **int, float, and complex**.

In Python 3 there is only one integer type, `int`, represented as a long integer; the `Long` of Python 2 no longer exists.

**bool** has two values: `True` and `False`.

---

## 3. String

Strings in Python are enclosed in single quotes (`'`) or double quotes (`"`), and the backslash (`\`) is used to escape special characters ("饭斜杠" in the original is a typo for "backslash").

Formatting strings (old-style `%` notation):

```python
# %d int  %f float  %s string  %x hex
'Hello, %s' % 'world'

>>> '%2d-%02d' % (3, 1)
' 3-01'

>>> '%.2f' % 3.1415926
'3.14'

s1 = 72
s2 = 85
r = (s2 - s1) * 100 / s1
print("%.1f%%" % (r))   # print the growth rate with 1 decimal place
```

> Note: For Python 3.6+, f-strings are recommended, e.g. `print(f"{r:.1f}%")`.

---

## 4. List

Lists can implement most collection-like data structures. The elements of a list may have different types: it supports numbers and strings, and can even contain lists (nesting).

A list is written between square brackets `[]`, with elements separated by commas:

```python
list = ['he', 213]
```

**Slice syntax: `variable[head index:tail index]`**

Indexing starts at 0, and -1 means the position counting from the end. `+` is the list concatenation operator, and `*` is the repetition operator.

Common operations:

```python
list.append(x)      # append to the end
list.insert(1, x)   # insert at index 1
list.pop(1)         # pop the element at index 1
list[1] = x         # assign by index
```

---

## 5. Tuple

A tuple is similar to a list, except that the elements of a tuple cannot be modified. Tuples are written inside parentheses `()`, with elements separated by commas.

The element types in a tuple can also differ.

```python
tuple = ('he', 12345)

tup1 = ()      # empty tuple
tup2 = (20,)   # one-element tuple; a comma must follow the element (typo "子啊" in the original)
```

## 6. Set

A set is an unordered sequence of non-repeating elements.

Its basic uses are membership testing and removing duplicate elements.

You can create a set with braces `{}` or the `set()` function:

```python
s = {1, 2, 3}
s.add(4)      # add an element
s.remove(2)   # remove an element; raises KeyError if it does not exist
```

## 7. Dictionary

A dictionary is a very useful built-in mapping type in Python.

A list is an ordered collection of objects, while a dictionary in Python 3.6 and earlier is an unordered collection of objects (from 3.7+ dictionaries preserve insertion order). The difference between the two is that dictionary elements are accessed by key, not by offset.

A dictionary is denoted by `{}` and is a collection of key: value pairs:

```python
dictionary = {'name': 'hequan', 'age': 1, 'site': 'www.hequan.lol'}
```

Keys must use immutable types; within the same dictionary, keys must be unique.

Additional notes:

- Both dict and set require keys to be immutable
- In the tuple `(1, 2, 3)`, 1, 2, and 3 are all immutable
- In `(1, [2, 3])`, the `[2, 3]` (list) has mutable values

## 8. Operators

1. Arithmetic: `+  -  *  /  %  **  //`
2. Comparison: `==  !=  >  <  >=  <=`
3. Assignment: `=  +=  -=  *=  /=  %=  **=  //=` (the original "/+" is a typo for "/="), e.g. `c += a` is equivalent to `c = c + a`

### Bitwise Operators (treating numbers as binary)

- `&` AND: the result bit is 1 only if both corresponding bits are 1, otherwise 0
- `|` OR: the result bit is 1 if either of the corresponding binary bits is 1
- `^` XOR: the result bit is 1 when the two corresponding binary bits differ
- `~` NOT: inverts every binary bit of the data
- `<<` left shift: shifts all binary bits left by several positions, discarding the high bits and padding the low bits with 0
- `>>` right shift: shifts all binary bits right by several positions

### Logical / Membership / Identity Operators

Logical: `and`, `or`, `not`.

Membership (applies to strings, lists, or tuples):

- `in`: returns True if the value is found in the specified sequence, otherwise False
- `not in`: returns True if the value is not found, otherwise False (the original omitted "in" here; corrected)

Identity (compares the memory locations of two objects):

- `is`: checks whether two identifiers refer to the same object
- `is not`: checks whether two identifiers refer to different objects

Precedence (from highest to lowest; the symbols in the original were garbled here, corrected according to Python's official precedence):

```
**  →  ~ + - (unary)  →  * / % //  →  + -  →  >> <<  →  &  →  ^ |  →
<= < > >=  →  == !=  →  = %= /= //= -= += *= **=  →  is / is not  →
in / not in  →  not  →  and  →  or
```

## 9. Conditionals and Loops

```python
if <condition1>:
    <action1>
else:
    <action2>

for x in <iterable>:
    <loop body>

while <condition>:
    <loop body>
```

Loop control statements:

1. `break`: breaks out of the loop
2. `continue`: skips the remaining statements in the current loop block
3. `pass`: an empty statement (placeholder)
