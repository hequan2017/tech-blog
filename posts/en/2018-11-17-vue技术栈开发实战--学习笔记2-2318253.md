#### 2 Routing Basics

- `<router-link>` maps to `<a>`, and `<router-view/>` renders components.

Common properties of the route object:

```js
{
  path: '',
  component: {},        // or components
  children: [
    { /* children */ }
  ],
  name: 'about',        // named, used with :to="{ name: 'about' }"
  alias: '/about',
  redirect: to => '/'   // redirect
}
```

Dynamic segments: `path: '/argu/:name'`, accessed inside the component via `$route.params.name`.

Programmatic navigation with `this.$router`:

```js
this.$router.back()          // or .go(-1)

this.$router.push({
  name: 'argu',
  params: {
    name: 'lison'
  }
})

this.$router.push({
  path: `/argu/${name}`
})

this.$router.replace({ /* same as above */ })
```

#### 3 Advanced Routing

Passing props to route components:

```js
// Boolean mode: pass params as props to the component
props: true

// Object mode
props: {
  food: 'banana'
}

// Function mode: /?food=xxxx
props: route => ({
  food: route.query.food
})
```

The complete navigation resolution flow:

* 1. Navigation is triggered
* 2. beforeRouteLeave is called in the deactivating component (the page component about to leave)
* 3. The global beforeEach guard is called
* 4. beforeRouteUpdate is called in the reused component
* 5. The route-exclusive beforeEnter guard is called
* 6. Asynchronous route components are resolved
* 7. beforeRouteEnter is called in the activating component (the page component about to enter)
* 8. The global beforeResolve guard is called
* 9. Navigation is confirmed
* 10. The global afterEach hook is called
* 11. DOM updates are triggered
* 12. The callback passed to next in the beforeRouteEnter guard is invoked with the created instance

meta metadata and a global guard example:

```js
// route config
meta: {
    title: 'meta info'
}

router.beforeEach((to, from, next) => {
    to.meta && setTitle(to.meta.title)
})
// to   object  the page being navigated to
// from object  the page being left
// next function  proceed with the navigation
```

#### 6 vuex-mutation_action_module

```js
import { mapMutations, mapActions } from 'vuex'

const mutations = {
  SET_APP_NAME (state, params) {
    state.appName = params
  },
}

// action
async updateAppName ({ commit }) {
  try {
    const { info: { appName } } = await getAppName()
    commit('SET_APP_NAME', appName)
  } catch (err) {
    console.log(err)
  }
}

methods: {
  ...mapMutations([  // synchronous
    'SET_APP_NAME'
  ]),
  ...mapActions([    // asynchronous
    'updateAppName'
  ]),
  handleChangeAppName () {
    this.$store.commit({
      type: 'SET_APP_NAME',
      appName: 'newAppName'
    })
    this.SET_APP_NAME({
      appName: 'newAppName'
    })
    this.$store.dispatch('updateAppName', '123')
  }
}

// If the variable does not exist in the initial state, use set so that reactive getters/setters are added
vue.set(state, 'appVersion', 'v2.0')
```

#### 15 Responsive Layout

iview-loader.

* Layout: the layout container; it can nest Header, Sider, Content, Footer, or Layout itself, and can be placed inside any parent container.
* Header: the top layout, with default styles; it can nest any elements and can only be placed inside Layout.
* Sider: the sidebar, with default styles and basic features; it can nest any elements and can only be placed inside Layout.
* Content: the content area, with default styles; it can nest any elements and can only be placed inside Layout.
* Footer: the bottom layout, with default styles; it can nest any elements and can only be placed inside Layout.

Grid:

* Use row to create a row in the horizontal direction
* Insert a group of cols into the row
* Type your own content inside each col
* Set the span parameter of a col to specify how many columns it spans; the range is 1 to 24
* The cols in each row should add up to 24 in total

#### 22 Access Control

Route-based control. Permission data structure:

```js
data: {
  token: 'xxx',
  rules: {
    page: {
      home: true    // page
    },
    component: {
      edit_button: true,
      publish_button: false
    }
  }
}

export const routes = [
  {
    path: '/login',
    name: 'login',
    component: () => import('@/views/login.vue')
  },
  {
    path: '*',
    component: () => import('@/views/error_404.vue')
  }
]
```

The user module: fetch permissions after login and store component-level permissions:

```js
import { login, authorization } from '@/api/user'
import { setToken } from '@/lib/util'

const state = {
  userName: 'Lison',
  rules: {}   // component-level permission storage
}

const mutations = {
  SET_RULES (state, rules) {
    state.rules = rules
  }
}

const actions = {
  authorization ({ commit }, token) {
    return new Promise((resolve, reject) => {
      authorization().then(res => {
        if (parseInt(res.code) === 401) {
          reject(new Error('token error'))
        } else {
          setToken(res.data.token)
          resolve(res.data.rules.page)
          commit('SET_RULES', res.data.rules.component)
        }
      }).catch(error => {
        reject(error)
      })
    })
  }
}
```

The router module: filter and merge routes according to permissions:

```js
import { routes, routerMap } from '@/router/router'

const state = {
  routers: routes,
  hasGetRules: false
}

const mutations = {
  CONCAT_ROUTES (state, routerList) {
    state.routers = routerList.concat(routes)    // merge routes
    state.hasGetRules = true   // route permissions have been fetched
  }
}

const getAccesRouterList = (routes, rules) => {
  return routes.filter(item => {
    if (rules[item.name]) {
      if (item.children) item.children = getAccesRouterList(item.children, rules)
      return true
    } else return false
  })
}

const actions = {
  concatRoutes ({ commit }, rules) {
    return new Promise((resolve, reject) => {
      try {
        let routerList = []
        if (Object.entries(rules).every(item => item[1])) {
          routerList = routerMap
        } else {
          routerList = getAccesRouterList(routerMap, rules)  // list of accessible routes
        }
        commit('CONCAT_ROUTES', routerList)   // set the routes
        resolve(routerList)
      } catch (err) {
        reject(err)
      }
    })
  }
}
```

Dynamically adding routes in the global guard:

```js
if (!store.state.router.hasGetRules) {

}
```
