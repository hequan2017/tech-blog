> **About this post**
>
> An example of using Python 3's native urllib + http.cookiejar to simulate a browser login to the Zabbix web UI: first GET the login page to obtain cookies, then build the name/password/autologin/enter form fields based on captured packets, POST to index.php to complete the login, and finally print the response body. Suitable for scraping page data from older Zabbix versions that have no API token.

> **Technical notes**
>
> This "simulated login" approach is no longer recommended: Zabbix 3.0+ provides a JSON-RPC API (see the companion post "Using python3--zabbixapi"), and 5.4+ introduced API token authentication; both are more stable than scraping pages. In the code, `hosturl`/`posturl` and the Referer in the headers must point to the same Zabbix address.

---

## 1. Approach

1. Set up an opener with a cookie handler and open the login home page first, in order to download cookies from the page; that way the cookies are already available when the POST data is sent, otherwise the request fails;
2. From the captured packets, work out the URL that handles the POST request along with the required headers and form fields;
3. Build and encode the POST data, then send the request to complete the login.

## 2. Complete Code

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
import urllib.request
import http.cookiejar
import urllib.parse

# Login home page
hosturl = 'http://xxxxx'  # fill in yourself
# Page that receives and handles the POST data (we send our constructed POST data to this page)
posturl = 'http://xxxxxxxxxxxxxxx/index.php'  # URL that handles the POST request, taken from the captured packet

# Set up a cookie handler that downloads cookies from the server locally and sends them along with requests
cj = http.cookiejar.LWPCookieJar()
cookie_support = urllib.request.HTTPCookieProcessor(cj)
opener = urllib.request.build_opener(cookie_support, urllib.request.HTTPHandler)
urllib.request.install_opener(opener)
# Open the login home page (its purpose is to download cookies from the page, so the cookies are there when we send the POST data; otherwise the request fails)
h = urllib.request.urlopen(hosturl)

# Build the headers; these two items are usually the minimum required. Both were taken from the captured packet.
headers = {'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; WOW64; rv:52.0) Gecko/20100101 Firefox/52.0',
          'Referer': 'http://xxxxxxxxxxxx/index.php'}

# Build the POST data, also taken from the captured packet.
postData = {"name": 'Admin',
             "password": 'xxxxxxx',
             "autologin": 1,
             "enter": "Sign in"}

# The POST data needs to be encoded
postData = urllib.parse.urlencode(postData).encode('utf-8')
# Use the request method to send our constructed data to the given URL and complete the login
request = urllib.request.Request(posturl, postData, headers)
response = urllib.request.urlopen(request)
text = response.read().decode()
print(text)
```
