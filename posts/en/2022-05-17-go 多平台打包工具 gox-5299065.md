> **About this post**
>
> This post records the minimal usage of gox, a cross-platform
> packaging tool for Go: after installing gox, specify the target
> platform and architecture with the `-osarch` flag, and a single
> command completes the cross-compilation. The example only builds
> an executable for the linux/amd64 platform.

> **Technical notes**
>
> gox is a small cross-compilation tool by Mitchell Hashimoto. The
> original repository, mitchellh/gox, was archived as read-only on
> 2023-10-31 and no longer evolves with new Go releases. Since Go 1.5,
> GOOS/GOARCH cross-compilation has been built in officially
> (e.g. `GOOS=linux GOARCH=amd64 go build`), and `go tool dist list`
> can list all supported platform combinations, so most scenarios no
> longer need third-party tools like gox.

---

Install and view the help:

```shell
$ go get github.com/mitchellh/gox
# ... (installation output omitted)
$ gox -h
# ... (help output omitted)
```

Build only for the linux platform:

```shell
# Build only for linux/amd64
gox -osarch="linux/amd64"
```
