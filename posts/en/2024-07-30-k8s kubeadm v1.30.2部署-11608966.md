> **About this post**
>
> This post documents the complete process of deploying a Kubernetes v1.30.2
> two-node cluster (1 master + 1 node) with kubeadm on CentOS 7.9: system
> initialization covering hostname/hosts, packages, firewall, and timezone;
> kernel parameter tuning, journald log persistence, and ipvs prerequisites;
> then installing Docker and containerd (registry mirror, systemd cgroup,
> pause image address), and installing kubeadm/kubelet/kubectl from the
> Alibaba Cloud kubernetes-new repository; finally, running kubeadm init to
> initialize the master, generating a token to join the node, deploying
> flannel, and verifying the cluster state.

> **Technical notes**
>
> CentOS 7 reached end of maintenance (EOL) on June 30, 2024; migrating to
> Rocky Linux 9 / AlmaLinux 9 or the domestic openEuler is recommended.
> Kubernetes v1.30 was released in April 2024, with official support through
> the end of June 2025. kubeadm removed dockershim starting with v1.24; this
> post installs both containerd and Docker, and the runtime actually used is
> containerd (`SystemdCgroup` and `sandbox_image` in config.toml are its
> configuration). To use Docker as the runtime, cri-dockerd must be installed
> additionally. The default kubeadm image source registry.k8s.io is hard to
> access from mainland China, so this post uniformly switches to the Alibaba
> Cloud image registry and the kubernetes-new yum repository.

## 1. Preparation

The system version is CentOS Linux release 7.9. Set the hostnames on the two machines:

```shell
hostnamectl set-hostname k8s-master
hostnamectl set-hostname k8s-node1
```

Write to /etc/hosts:

```text
192.168.117.224 k8s-master
192.168.117.225 k8s-node1
```

Install the base packages, disable the firewall, and unify the timezone:

```shell
yum -y install wget jq psmisc vim net-tools nfs-utils telnet yum-utils device-mapper-persistent-data lvm2 git network-scripts tar curl -y
systemctl stop firewalld && systemctl disable firewalld
systemctl stop iptables && systemctl disable iptables

timedatectl set-timezone Asia/Shanghai
timedatectl set-local-rtc 0
systemctl restart rsyslog
systemctl restart crond
```

## 2. Kernel Parameters and System Configuration

Write the sysctl configuration and apply it:

```shell
cat > kubernetes.conf<<EOF
# Enable bridge mode [important]
net.bridge.bridge-nf-call-iptables=1
# Enable bridge mode [important]
net.bridge.bridge-nf-call-ip6tables=1
net.ipv4.ip_forward=1
net.ipv4.tcp_tw_recycle=0
# Disable swap; it may only be used when the system is OOM
vm.swappiness=0
# Do not check whether physical memory is sufficient
vm.overcommit_memory=1
# Enable OOM
vm.panic_on_oom=0
fs.inotify.max_user_instances=8192
fs.inotify.max_user_watches=1048576
fs.file-max=52706963
fs.nr_open=52706963
# Disable IPv6 [important]
net.ipv6.conf.all.disable_ipv6=1
net.netfilter.nf_conntrack_max=2310720
EOF

cp kubernetes.conf /etc/sysctl.d/kubernetes.conf
modprobe ip_conntrack
sysctl -p /etc/sysctl.d/kubernetes.conf
```

Persist journald logs:

```shell
mkdir /etc/systemd/journal.conf.d
cat >/etc/systemd/journal.conf.d/99-prophet.conf <<EOF
[Journal]
# Persist logs to disk
Storage=persistent
# Compress historical logs
Compress=yes
SyncIntervalSec=5m
RateLimitInterval=30s
RateLimitBurst=1000
# Maximum disk usage 10G
SystemMaxUse=10G
# Maximum size of a single journal file 200M
SystemMaxFileSize=200M
# Log retention time 2 weeks
MaxRetentionSec=2week
# Do not forward logs to syslog
ForwardToSyslog=no
EOF

systemctl restart systemd-journald
```

Prerequisites for enabling ipvs in kube-proxy:

```shell
yum install -y ipset ipvsadm
for i in $(ls /usr/lib/modules/$(uname -r)/kernel/net/netfilter/ipvs|grep -o "^[^.]*");do echo $i; /sbin/modinfo -F filename $i >/dev/null 2>&1 && /sbin/modprobe $i;done
```

## 3. Install Docker and containerd

```shell
yum install -y yum-utils device-mapper-persistent-data lvm2
yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo
yum install -y docker-ce docker-ce-cli containerd.io
```

containerd configuration:

```shell
cat << EOF > /etc/modules-load.d/containerd.conf
overlay
br_netfilter
EOF

modprobe overlay
modprobe br_netfilter

mkdir -p /etc/containerd
containerd config default > /etc/containerd/config.toml
```

Edit /etc/containerd/config.toml and change two places (the leading numbers are line numbers in the default configuration):

```text
127 SystemdCgroup = true
63 sandbox_image = "registry.aliyuncs.com/google_containers/pause:3.9"
```

```shell
systemctl restart containerd
systemctl enable containerd
```

The contents of /etc/docker/daemon.json (the comments on each line are explanatory notes):

```text
{
  # Docker registry mirror configuration. The mirror address can be obtained by logging in to the Alibaba Cloud website
  "registry-mirrors": ["https://"],
  # Specifies the cgroup driver used by Docker containers, managed by systemd
  "exec-opts": ["native.cgroupdriver=systemd"],
  # This option specifies the log driver for Docker containers
  "log-driver": "json-file",
  # Specifies the maximum size of a single container log file as 100m
  "log-opts": {
    "max-size": "100m"
  }
}
```

```shell
systemctl daemon-reload
systemctl restart docker.service
systemctl enable docker.service
```

## 4. Install kubeadm / kubelet / kubectl

Configure the Alibaba Cloud Kubernetes repository:

```shell
sudo cat <<EOF | tee /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://mirrors.aliyun.com/kubernetes-new/core/stable/v1.30/rpm/
enabled=1
gpgcheck=0
gpgkey=https://mirrors.aliyun.com/kubernetes-new/core/stable/v1.30/rpm/repodata/repomd.xml.key
EOF
yum clean all
yum makecache
```

Install and enable kubelet:

```shell
yum install kubectl kubeadm kubelet -y

cat > /etc/sysconfig/kubelet <<EOF
KUBELET_EXTRA_ARGS="--cgroup-driver=systemd"
EOF
systemctl enable kubelet.service
```

## 5. Deploy the master

First check the list of required images, then initialize the cluster:

```shell
kubeadm config images list

kubeadm init \
--apiserver-advertise-address=192.168.117.224 \
--image-repository registry.aliyuncs.com/google_containers \
--kubernetes-version v1.30.2 \
--service-cidr=10.1.0.0/16 \
--pod-network-cidr=10.244.0.0/16 --v=6
```

If initialization fails, run:

```shell
kubeadm reset -f
journalctl -u kubelet
```

Configure kubectl credentials:

```shell
mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config
export KUBECONFIG=/etc/kubernetes/admin.conf

echo "export KUBECONFIG=/etc/kubernetes/admin.conf" >> ~/.bashrc
```

## 6. Add the node

Check the token and the CA certificate hash; generate a new token for the node to join:

```shell
kubeadm token list

# View the password
openssl x509 -pubkey -in /etc/kubernetes/pki/ca.crt | openssl rsa -pubin -outform der 2>/dev/null | openssl dgst -sha256 -hex | sed 's/^.* //'

# Generate a new token and join the node
kubeadm token create --print-join-command
```

## 7. Deploy the flannel network plugin and verify

```shell
kubectl apply -f https://raw.githubusercontent.com/coreos/flannel/master/Documentation/kube-flannel.yml

kubectl get nodes
kubectl get pods -n kube-system

sudo systemctl restart kubelet
```
