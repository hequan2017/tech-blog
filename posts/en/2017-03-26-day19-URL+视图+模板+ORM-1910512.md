> and the project creation workflow, then systematically covers the URL routing system —

## 2. The Routing System (URL)

```python
# 1.
url(r'^index/', views.index),
url(r'^home/', views.Home.as_view()),

# 2.
url(r'^detail-(\d+).html', views.detail),

# 3. not by order, but by id
url(r'^detail-(?P<nid>\d+)-(?P<uid>\d+).html', views.detail)
```

PS:

```python
def detail(request, *args, **kwargs):
    pass
```

In practice:

a. Positional groups: parameters are passed by position:

```python
url(r'^detail-(\d+)-(\d+).html', views.detail),

def func(request, nid, uid):
    pass

def func(request, *args):
    args = (2, 9)      # tuple

def func(request, *args, **kwargs):
    args = (2, 9)
```

b. Named groups: parameters are passed by name:

```python
url(r'^detail-(?P<nid>\d+)-(?P<uid>\d+).html', views.detail)

def func(request, nid, uid):
    pass

def funct(request, **kwargs):
    kwargs = {'nid': 1, 'uid': 3}
    xiangxi_info = test_list[kwargs['nid']]

def func(request, *args, **kwargs):
    args = (2, 9)
```

### 2.1 Name-Based Reverse Resolution

(The original note here says: "come back to this later — didn't get it".) Name the URL
routing relationships so that from then on you can generate any URL you want from its
name:

```python
url(r'^asdfasdfasdf/', views.index, name='i1'),
url(r'^yug/(\d+)/(\d+)/', views.index, name='i2'),
url(r'^buy/(?P<pid>\d+)/(?P<nid>\d+)/', views.index, name='i3'),
```

```python
def func(request, *args, **kwargs):
    from django.urls import reverse
    url1 = reverse('i1')                               # asdfasdfasdf/
    url2 = reverse('i2', args=(1, 2,))                 # yug/1/2/
    url3 = reverse('i3', kwargs={'pid': 1, "nid": 9})  # buy/1/9/
```

xxx.html:

```html
{% url "i1" %}              # asdfasdfasdf/
{% url "i2" 1 2 %}          # yug/1/2/
{% url "i3" pid=1 nid=9 %}  # buy/1/9/
```

Note: for the current URL, use `request.path_info`.
