## 1. Introduction

Python was created by Guido van Rossum. In the October (2016) TIOBE index, Python ranked fifth with a share of 3.775% (note: this is historical data; by 2026 Python has firmly held first place).

Python is a **dynamically interpreted, strongly typed** language.

When executing a `.py` file, the Python interpreter compiles → interprets line by line, then runs it.

`PyCodeObject` is the result of compilation; once the run finishes it is saved to `.pyc`, so that next time the pyc file can be executed directly.

- **Dynamic typing**: a language that checks data types only at runtime.
- **Strongly typed language**: once a variable has been assigned a data type, it remains that type forever unless it is explicitly converted.

**Pros**: elegant, clear, and simple; high development efficiency; a high-level language; portability, extensibility, and embeddability.

**Cons**: slow; code cannot be encrypted; threads cannot utilize multiple CPUs (limited by the GIL; "cannot reason" in the original was a typo).

Python interpreters: **CPython** is the most widely used interpreter. On Windows, PyCharm can be used to write Python programs (in 2026, VS Code is also an option).

Everything that follows is based on **Python 3**.

## 2. Basic Understanding

### 2.1 The First Program

```python

```

How to run it:

```shell
python hello.py        # run via the interpreter specified on the command line
```

```python

```

### 2.2 Variables

```python
name = 'he quan'
```

Naming rules:

- A variable name can only be any combination of letters, digits, or underscores
- The first character of a variable name cannot be a digit
- Python keywords cannot be declared as variable names (a typo in the original):

```python
>>> import keyword
>>> keyword.kwlist
['and', 'as', 'assert', 'break', 'class', 'continue', 'def', 'del',
 'elif', 'else', 'except', 'finally', 'for', 'from', 'global', 'if',
 'import', 'in', 'is', 'lambda', 'not', 'or', 'pass', 'raise',
 'return', 'try', 'while', 'with', 'yield']
# Note: in Python 3.9+, 'exec' and 'print' are no longer in kwlist (they are built-in functions)
```

Naming conventions:

- **Constants**: for global variables that never change, use uppercase with underscores, e.g. `USER_CONSTANT`
- **Private variables**: for internal use only, lowercase with a single leading underscore, e.g. `_private_value`
- **Built-in variables**: lowercase, with double leading and double trailing underscores, e.g. `__class__`

### 2.6 Interactive Interpreter Tab Completion Setup

The following is an example Python interactive startup file (`PYTHONSTARTUP`) that provides tab completion and command history:

```python
#!/usr/bin/env python
# python startup file
import sys
import readline
import rlcompleter
import atexit
import os

# tab completion
readline.parse_and_bind('tab: complete')

# history file
histfile = os.path.join(os.environ['HOME'], '.pythonhistory')
try:
    readline.read_history_file(histfile)
except IOError:
    pass

atexit.register(readline.write_history_file, histfile)
del os, histfile, readline, rlcompleter
```

## 3. Types

Python 3 has six standard data types: Number, String, List, Tuple (mistyped in the original), Set, and Dictionary.

### 3.1 Number

Python 3 supports `int`, `float`, and `complex`.

In Python 3 there is only one integer type, `int`, which acts as a long integer; Python 2's `Long` no longer exists.

`bool` has two values: `True` and `False`.

### 3.2 String

Strings in Python are enclosed in single quotes (`'`) or double quotes (`"`), with the backslash (`\`) used to escape special characters (a typo in the original).

Encoding conversion relationship (diagram from the original):

```text
Notepad (Unicode encoding)
   ↓        ↑
UTF-8 ←→ Unicode
   ↓        ↑
File abc.txt (the original "abc.tx" is missing a "t" — a typo)
```

String formatting: `%d` for numbers, `%f` for floats, `%s` for strings, `%x` for hexadecimal (f-strings are recommended in 2026).

### 3.3 List

Lists can implement most collection-style data structures. The elements of a list can be of different types; numbers, strings, and even lists (nesting) are supported.

```python
list = ['he', 213]
```

**Slice syntax: `variable[start index:end index]`** — indexes start at 0, and -1 counts from the end. `+` is the concatenation operator and `*` is the repetition operator.

```python
list.append(x)      # append
list.insert(1, x)   # insert
list.pop(1)         # remove
list[1] = x         # modify
```

### 3.4 Tuple

A tuple is similar to a list; the difference is that the elements of a tuple cannot be modified (the original contains several typos here). Tuples are written inside parentheses `()`, with elements separated by commas.

```python
tuple = ('he', 12345)

tup1 = ()      # empty tuple
tup2 = (20,)   # single-element tuple; a comma is required after the element
```

### 3.5 Set

A set is an unordered sequence of non-repeating elements (a typo in the original). Its basic functions are membership testing and removing duplicate elements.

```python
s = {1, 2, 3}   # or create with set()
s.add(4)        # add
s.remove(2)     # remove
```

### 3.6 Dictionary

The dictionary is a very useful built-in mapping type in Python. Lists are ordered collections of objects, whereas dictionaries in Python 3.6 and earlier are unordered collections (3.7+ preserve insertion order). Elements in a dictionary are accessed by key, not by offset.

```python
dictionary = {'name': 'hequan', 'age': 1, 'site': 'www.hequan.lol'}
```

- Keys must use immutable types; keys within the same dictionary must be unique
- Both dict and set require immutable keys
- The elements of the tuple `(1, 2, 3)` are all immutable; the list `[2, 3]` inside `(1, [2, 3])` has mutable values

### 3.7 Operators

1. Arithmetic: `+  -  *  /  %  **  //`
2. Comparison: `==  !=  >  <  >=  <=`
3. Assignment: `=  +=  -=  *=  /=  %=  **=  //=` (the original `/+` was a typo); for example, `c += a` is equivalent to `c = c + a`

Bitwise operators (computing with numbers treated as binary):

- `&` bitwise AND: the result bit is 1 only when both corresponding bits are 1, otherwise 0
- `|` bitwise OR: the result bit is 1 when either corresponding bit is 1
- `^` bitwise XOR: the result bit is 1 when the corresponding bits differ
- `~` bitwise NOT: inverts every bit
- `<<` left shift: shifts all bits left by several positions; high bits are discarded, low bits are filled with 0
- `>>` right shift: shifts all bits right by several positions

Logical: `and`, `or`, `not`. Membership (applies to strings, lists, or tuples):

- `in`: True if the value is found, otherwise False
- `not in`: True if the value is not found, otherwise False (the original omitted "in"; corrected here)

Identity (compares the memory units of two objects):

- `is`: whether the two identifiers refer to the same object
- `is not`: whether they refer to different objects

Precedence (the symbols in the original were garbled; corrected according to the official precedence, from highest to lowest):

```text
** → ~ + - (unary) → * / % // → + - → >> << → & → ^ | →
<= < > >= → == != → = %= /= //= -= += *= **= → is/is not →
in/not in → not → and → or
```

## 4. Basic Operations Quick Reference

- `strip`: removes whitespace from both ends
- `split`: splits, `str.split(sep, maxsplit)`
- `len(obj)`: length
- `obj[1]`: indexing
- `obj[1:]`, `obj[1:10]`: slicing

```python
ll = [1, 2, 3, 4, 5]
# Common list operations: index / append / del / remove / pop / len
# Loops: for / while; control flow: break (end the loop), continue (skip one iteration),
#       pass (placeholder), return (return), exit (quit)
```

Tuple elements cannot be modified, but the internals of mutable elements inside a tuple can be:

```python
t1 = (1, 2, {'h1': 123})
t1[2]['h1'] = 'h2'   # modifying a dictionary value inside the tuple is legal
print(t1)            # (1, 2, {'h1': 'h2'})
```

Dictionary views:

```python
D.keys()    # keys
D.values()  # values
D.items()   # key-value pairs
```

File opening modes: `r` (read-only), `r+` (read/write), `w` (write, truncates the file), `a` (append), `b` (binary; can be combined with the above).
