> **About this post**
>
> A minimal example of recognizing license plates with the open-source library
> HyperLPR: first install opencv-python, opencv-contrib-python, and hyperlpr
> with pip, then read the image with OpenCV and call
> HyperLPR_plate_recognition to get the recognition result.

> **Technical notes**
>
> The usage shown here corresponds to the classic hyperlpr 0.0.2 released in
> December 2019, and that package has not been updated since; the project is
> now developed mainly as HyperLPR3 (pip install hyperlpr3, based on ONNX
> Runtime, with a changed API). opencv-python==3.4.2.16 is the pinned version
> commonly seen in tutorials of that era; newer Python versions have no
> matching wheel, so nowadays you can simply install 4.x. HyperLPR was trained
> on mainland China license plates (blue plates, yellow plates, new-energy
> green plates, etc.) and is only suitable for Chinese license plate scenarios.

---

```shell
pip3 install opencv-python==3.4.2.16
pip3 install opencv-contrib-python==3.4.2.16
pip3 install hyperlpr
```

```python
from hyperlpr import *
# Import the OpenCV library
import cv2
# Read the image
image = cv2.imread("1.png")
# Recognition result
print(HyperLPR_plate_recognition(image))
```
