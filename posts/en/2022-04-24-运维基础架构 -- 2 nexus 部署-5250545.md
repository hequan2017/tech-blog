> **About this post**
>
> This is part 2 of the "Ops Infrastructure" series: deploying a private Nexus3 repository with Docker.
> The post is a hands-on operation log: create the data directory and grant permissions, start the sonatype/nexus3 container, and follow the startup logs.
> Finally, it gives the location of the initial admin password (admin.password) for the first login.

> **Technical notes**
>
> Nexus Repository 3 requires a Java 17 runtime as of 3.70.0; the official sonatype/nexus3 image ships with a compatible JRE built in, so a Docker deployment needs no separate JVM installation.
> The image runs as UID 200; the example runs chown -R 200 on the data directory for exactly this reason.
> Newer versions have deprecated the OrientDB storage, and the community edition defaults to embedded H2; before upgrading an old instance, complete the data migration following the official guide.

---

## 1. Deploy Nexus3 with Docker

```shell
mkdir /data1/nexus-data -p && chown -R 200 /data1/nexus-data
docker run -d -p 8081:8081 --name nexus -v /data1/nexus-data:/nexus-data sonatype/nexus3
docker logs -f nexus
```

To get the login password, see `/data1/nexus-data/admin.password`
