> **About this post**
>
> This post demonstrates AES encryption and decryption with the GoFrame (gf)
> `crypto/gaes` package: a 16-byte key encrypts the string "hequan" into a
> hex string, and the same key decrypts it back to plaintext — a quick
> example for password / token encryption in Go backends.

> **Technical notes**
>
> The example is based on GoFrame v2's `crypto/gaes` (AES-GCM mode); the key
> must be 16/24/32 bytes, and 16 bytes here means AES-128. The ciphertext is
> hex-encoded for easier storage and display, and must be hex-decoded before
> decryption. Note that the key is hardcoded in the source for demo purposes
> only; in real projects, load it from configuration or a key management
> service, and never commit real keys into code.

---

```go
package main

import (
	"encoding/hex"
	"fmt"

	"github.com/gogf/gf/v2/crypto/gaes"
)

func main() {
	key := []byte("B4OcDhdFwIyDdjFz") // 16 bytes (AES-128)
	res, _ := gaes.Encrypt([]byte("hequan"), key)
	res2 := hex.EncodeToString(res)
	fmt.Println(res2) // 650d7f2e5aff02da85ff4af9ae36b052

	res3, _ := hex.DecodeString(res2)
	res4, _ := gaes.Decrypt(res3, key)
	fmt.Println(string(res4)) // hequan
}
```
