> **About this post**
>
> The second post in the "Getting Started with Django: CMDB System" series, focusing on bringing in the
> front-end templates and building the basic template layout: it uses the inspinia 2.9 template with the
> bootstrap3 front-end framework, creates the static directory and copies static assets such as
> css/fonts/js into it, configures STATICFILES_DIRS in settings, and installs the requirements.txt
> dependencies with pip3; it then breaks down the file structure of the base template (navigation,
> top bar, footer, CSS/JS loading), explains the include and block mechanisms in base.html, and
> provides an index.html example.

> **Technical notes**
>
> 1. The environment in this post corresponds to Django 2.x (part 1 of the series used 2.2): official support for Django 2.2 LTS ended in April 2022, so use a still-supported Django version for new projects.
> 2. `{% load staticfiles %}` was deprecated in Django 2.1 and removed in 3.0; nowadays `{% load static %}` is the standard. Both appear in this post because that was the style at the time, and they are kept as-is.
> 3. `{% load bootstrap3 %}` comes from the third-party library django-bootstrap3; Bootstrap 3 officially ended maintenance in 2019, so Bootstrap 5 is recommended for new projects (using the corresponding django-bootstrap5 library).
> 4. inspinia is a commercially licensed admin template, which the original post distributed via QQ group file sharing; today the mainstream for admin dashboards has shifted to front-end/back-end separation (Vue/React), i.e., the mvvc direction the author announced (part 6 of the series).
> 5. Corrections to the original: the GitHub link and QQ group number in the preface were truncated to https:///××× when scraped and have been restored from doc/2.md in the author's husky repository; "pip 3" was corrected to "pip3"; the typo in the phrase for "left navigation bar" was fixed; the settings code block was labeled python; and the shell fence mistakenly closing the base.html code block was corrected to a proper closing fence.

## 2. Front-end Templates

- inspinia 2.9 model (available in the shared files of the QQ group above)
- bootstrap3    front-end framework

> Create a static directory in the project and copy css, font-awesome, fonts, and js from the front-end template into static. (Js plugins you do not need can be removed at your discretion to save space.)

> Add the following to the settings file:

```python
STATICFILES_DIRS = (
    os.path.join(BASE_DIR, 'static'),
)
```

```shell
pip3 install -r  requirements.txt    ## Install all modules; if you add modules, add them here too
```

> Add a base template file under templates. For details, see https://github.com/hequan2017/husky/tree/master/templates/base

- base
  - _css.html     loads css
  - _footer.html    footer
  - _js.html      loads js
  - _nav.html     left navigation bar
  - _navbar-static-top.html   top information bar
  - base.html    base template

## 3. Key Points of the Template Files

- base.html

```html
{% load staticfiles %}  load static files
{% load static %}
{% load bootstrap3 %}
<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>{% block  title %} {% endblock %}</title> title

    {% include  "base/_css.html" %}            default css loaded for the whole site
    {% block header-css %}       css loaded by this page only
    {% endblock %}

</head>

<body>
<div id="wrapper">

    {% include "base/_nav.html" %}   load the navigation bar

    <div id="page-wrapper" class="gray-bg">
        {% include  "base/_navbar-static-top.html" %}    load the top bar

        {% block page-content %}   main content of the page

        {% endblock %}
        {% include  "base/_footer.html" %}   load the footer

    </div>
</div>

</body>

{% include  "base/_js.html" %}

{% block footer-js %}   js loaded by this page only
{% endblock %}

</html>
```

- index.html  example

```html
{% extends "base/base.html" %}   load base.html
{% load static %}
{% block  title %} Home{% endblock %}   title

{% block header-css %}
css needed by this page can be written here
{% endblock %}

{% block page-content %}
    <div class="wrapper wrapper-content">

Welcome to this project!

    </div>

{% endblock %}

{% block footer-js %}
js needed by this page can be written here
{% endblock %}
```
