> **About this post**
>
> A complete example of integrating casbin into the Gin framework for RBAC access control: define the rbac_model.conf model, load policies from the database at startup (instead of using a casbin adapter), and use a Gin middleware to run Enforce checks on sub/obj/act for each request. For dependency injection, facebookgo/inject is reused to wire up the Enforcer and the business objects.
>
> **Technical notes**
>
> The examples in this post are based on an early casbin (v1/v2 era). The `NewEnforcer` and `AddPolicy` APIs remain compatible in the current casbin v2, but `EnforceSafe` is no longer recommended; use `Enforce` directly instead. casbin now lives under the casbin organization, and the full example project path should be `github.com/hequan2017/go-admin`.

### A Simple RBAC Example with gin + casbin in Go

#### Description

> For details, see the author's project: https://github.com/hequan2017/go-admin

Libraries used:

- github.com/casbin/casbin
- github.com/gin-gonic/gin
- github.com/facebookgo/inject

casbin documentation: https://casbin.org/zh-CN/

The example below does not use a casbin adapter. Instead, it initializes at startup and then dynamically loads all permission entries from the corresponding relations stored in the database; a middleware then performs the checks. When there are updates, the permission entries can be modified and updated dynamically.

##### Code

rbac_model.conf:

```ini
[request_definition]
r = sub, obj, act

[policy_definition]
p = sub, obj, act

[role_definition]
g = _, _

[policy_effect]
e = some(where (p.eft == allow))

[matchers]
m = g(r.sub, p.sub) == true \
    && keyMatch2(r.obj, p.obj) == true \
    && regexMatch(r.act, p.act) == true
```

b_auth.go:

```go
package bll

// gin-allin/models is part of my own project, please ignore it
import (
   "gin-allin/models"
   "github.com/casbin/casbin"
)

//models.Auth  is the User table     in practice you can write your own USER table
type Role struct {
   Role      *models.Auth     `inject:""`
   Enforcer  *casbin.Enforcer `inject:""`
}

// LoadPolicy loads the role permission policy,
func (a *Role) LoadPolicy(roleID string) error {
   a.Enforcer.AddPolicy(roleID, "/api/v1/auth_info","GET")
   return nil
}
```

b_common.go and inject.go:

```go
package bll

// Inject the permission table into Common
type Common struct {
   Role   *Role    `inject:""`
}
```

inject.go:

```go
package inject

import (
   "gin-allin/bll"
   "github.com/casbin/casbin"
   "github.com/facebookgo/inject"
   "os"
)

// Object holds the injected objects
type Object struct {
   Common     *bll.Common
   Enforcer   *casbin.Enforcer
}

// Init initializes dependency injection
func Init() *Object {
   g := new(inject.Graph)

   // Inject casbin
   dir, _ := os.Getwd()
   path := dir + "\\src\\gin-allin\\conf\\rbac_model.conf"
   enforcer := casbin.NewEnforcer(path, false)
   _ = g.Provide(&inject.Object{Value: enforcer})

   //  Inject Common, i.e. Role
   Common := new(bll.Common)
   _ = g.Provide(&inject.Object{Value: Common})

   if err := g.Populate(); err != nil {
      panic("初始化依赖注入发生错误：" + err.Error())
   }

   // Return the fully injected object
   return &Object{
      Enforcer:  enforcer,
      Common :Common,
   }
}

package casb

import (
   "gin-allin/inject"
   "github.com/gin-gonic/gin"
   "net/http"
)

// Permission check
func CasbinMiddleware(obj *inject.Object) gin.HandlerFunc {
   return func(c *gin.Context) {

      // Check   whether the permission is true
      if b, err := obj.Enforcer.EnforceSafe("hequan", c.Request.URL.Path, c.Request.Method); err != nil {
         c.JSON(http.StatusUnauthorized, gin.H{
            "code": "权限 判断错误",
            "msg":  "权限 判断错误",
            "data": "权限 判断错误",
         })
         c.Abort()
         return
      } else if !b {

         c.JSON(http.StatusUnauthorized, gin.H{
            "code": "没有权限",
            "msg":  "没有权限",
            "data": "没有权限",
         })
         c.Abort()
         return
      }
      c.Next()
   }
}

package routers

func InitRouter() *gin.Engine {
   // Create the object
   obj := inject.Init()

   err := loadCasbinPolicyData(obj)

   if err != nil {
      panic("加载casbin策略数据发生错误：" + err.Error())
   }

   apiv1.Use(casb.CasbinMiddleware(obj))
}

// Load casbin policy data   loads one permission of hequan
func loadCasbinPolicyData(obj *inject.Object) error {
   err := obj.Common.Role.LoadPolicy("hequan")
   if err != nil {
      fmt.Println(err)
      return err
   }
   return nil
}
```

#### Result

When the user `hequan` accesses `/api/v1/auth_info`, the system checks whether the GET permission exists: if it does, the request passes; otherwise it is rejected.

For testing, you can change the username to something else and restart; the middleware check will then fail and a rejection is returned.
