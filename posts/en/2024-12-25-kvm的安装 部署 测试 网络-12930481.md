> **About this post**
>
> This post records the complete process of deploying KVM from scratch on CentOS 7: checking CPU virtualization support,
> installing the qemu-kvm/libvirt components and starting libvirtd, creating and installing a centos7 virtual machine
> with qemu-img and virt-install, and handling day-to-day management with virsh;
> it demonstrates two cloning approaches (copying the XML, virt-clone) and raw-to-qcow2 format conversion,
> and finally configures the br1 bridge with ifcfg and brctl to give virtual machines bridged networking.

> **Technical notes**
>
> CentOS 7 reached end of maintenance (EOL) on June 30, 2024; migrating to Rocky Linux 9 / AlmaLinux 9 or the domestic openEuler is recommended.
>
> `egrep -o '(vmx|svm)' /proc/cpuinfo`: output of vmx means Intel VT-x, svm means AMD-V; no output means the host does not have virtualization enabled, and it must first be turned on in the BIOS.
>
> virbr0 is libvirt's default NAT network, usually on the 192.168.122.0/24 subnet; the `--network=bridge=virbr0` in the example uses this default network.

## 1. Check CPU virtualization support

```shell
egrep -o '(vmx|svm)' /proc/cpuinfo
```

## 2. Install the KVM components and start the service

```shell
sudo dnf install -y qemu-kvm libvirt libvirt-daemon virt-install virt-manager

sudo systemctl enable --now libvirtd
sudo systemctl start libvirtd

lsmod | grep kvm
```

## 3. Create the disk image and install the virtual machine

```shell
qemu-img create -f raw centos7.raw 10G

virt-install --name centos7 --vcpus 1 --ram 1024 \
  --location=/vm-iso/CentOS-7-x86_64-Minimal-2009.iso \
  --disk path=/vm-centos7/centos7.raw,size=10,format=raw \
  --network=bridge=virbr0 --os-type=linux --os-variant=rhel7 \
  --extra-args='console=ttyS0' --noautoconsole --force
```

## 4. Day-to-day management with virsh

```shell
virsh list --all
virsh dominfo centos7
virsh console centos7

virsh start centos7
virsh shutdown centos7
virsh undefine centos7 --remove-all-storage
```

## 5. Clone a virtual machine (linked clone + copying the XML)

```shell
# Create a new disk image for the centos7-02 virtual machine
qemu-img create -f qcow2 -b centos7.raw centos7-02.qcow2

cd /etc/libvirt/qemu
cp centos7.xml centos7-02.xml
vi centos7-02.xml
```

```xml
  <name>centos7-02</name>
  <uuid>322f0f23-cdb5-4097-afc1-79636dd8fe2f</uuid>
      <source file='/vm-centos7/centos7-02.qcow2'/>
      <mac address='52:54:00:87:c4:b2'/>
```

```shell
virsh define centos7-02.xml   # register it
```

## 6. Clone a virtual machine (second method: virt-clone)

```shell
virt-clone -o centos7 -n vm2 -f /var/lib/libvirt/images/vm2.qcow2
```

## 7. Disk format conversion (raw to qcow2)

```shell
qemu-img convert -f raw -O qcow2 /vm-centos7/centos7.raw /vm-centos7/centos7.qcow2
```

## 8. Create a virtual machine by importing an existing disk

```shell
sudo virt-install \
  --name vm3 \
  --ram 2048 \
  --vcpus 2 \
  --os-variant centos7.0 \
  --disk path=/var/lib/libvirt/images/vm3.qcow2,format=qcow2 \
  --network bridge=br1 \
  --graphics none \
  --console pty,target_type=serial \
  --import
```

## 9. Network bridging

```shell
cp ifcfg-ens160 ifcfg-br1

vim ifcfg-ens160
BRIDGE=br1

vim ifcfg-br1
TYPE=Bridge
PROXY_METHOD=none
BROWSER_ONLY=no
BOOTPROTO=dhcp
DEFROUTE=yes
IPV4_FAILURE_FATAL=no
ONBOOT=yes
NAME=br1
DEVICE=br1

dnf install https://dl.fedoraproject.org/pub/epel/epel-release-latest-8.noarch.rpm
dnf install bridge-utils

brctl show
virsh domiflist centos7

brctl delif virbr0 vnet0
brctl addif br1 vnet0

brctl show
```
