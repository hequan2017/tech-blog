> **About this post**
>
> A quick-reference document for Mock.js (reposted from Lison's Vue practical course), covering intercepting requests with `Mock.mock()`, the 7 generation rules for data templates (string/number/boolean/object/array/function/regexp), the `@` placeholder syntax, `Mock.setup()` timeout configuration, all built-in methods of `Mock.Random` (Basic/Date/Image/Color/Text/Name/Web/Address/Helper/Miscellaneous), and how to extend it with custom placeholders.

> **Technical notes**
>
> The content follows the Mock.js 1.x syntax, which is still the library's latest stable version and can be used as is; however, Mock.js has not been actively maintained for years, and its XHR interception implementation affects fetch requests. For new projects, consider alternatives such as msw (Mock Service Worker).

### A Concise Guide to Mock.js

#### Mock.mock()

- Mock.mock( requestUrl?, requestType?, template|function(options) )
- Mock.mock( template )
- Mock.mock( requestUrl, template )
- Mock.mock( requestUrl, requestType, template )
- Mock.mock( requestUrl, requestType, function(options) )

> requestUrl: The URL to intercept, a string or a regular expression<br>
> requestType: The request type to intercept, get/post/put/delete/options...<br>
> template: The data template<br>
> function(options): The function that generates the response data; options --> { url, type, body }

#### Syntax Specification

##### Data Template Definition

> Each property in a data template consists of three parts: **property name|generation rule: property value**

1. 'name|min-max': value
2. 'name|count': value
3. 'name|min-max.dmin-dmax': value
4. 'name|min-max.dcount': value
5. 'name|count.dmin-dmax': value
6. 'name|count.dcout': value
7. 'name|+step': value

*The property value* may contain @ placeholders.
*The property value* also specifies the initial value and type of the final value.

###### 1. Property Value Is a String

1. 'name|min-max': string

> Generates a string by repeating string, with the repeat count greater than or equal to min and less than or equal to max

1. 'name|count': string

> Generates a string by repeating string, with the repeat count equal to count

###### 2. Property Value Is a Number

1. 'name|+1': number

> The property value is automatically incremented by 1; the initial value is number

1. 'name|min-max': number

> Generates an integer greater than or equal to min and less than or equal to max; the property value number is only used to determine the type

1. 'name|min-max.dmin-dmax': number

> Generates a floating-point number whose integer part is greater than or equal to min and less than or equal to max, with dmin to dmax decimal places retained

###### 3. Property Value Is a Boolean

1. 'name|1': boolean

> Randomly generates a boolean; the probability of true is 1/2, and the probability of false is also 1/2

1. 'name|min-max': value

> Randomly generates a boolean; the probability of value is min / (min + max), and the probability of !value is max / (min + max)

###### 4. Property Value Is an Object

1. 'name|count': object

> Randomly selects count properties from the property value object

1. 'name|min-max': object

> Randomly selects min to max properties from the property value object

###### 5. Property Value Is an Array

1. 'name|1': array

> Randomly selects 1 element from the property value array as the final value

1. 'name|+1': array

> Sequentially selects 1 element from the property value array as the final value

1. 'name|min-max': array

> Generates a new array by repeating the property value array, with the repeat count greater than or equal to min and less than or equal to max

1. 'name|count': array

> Generates a new array by repeating the property value array, with the repeat count equal to count

###### 6. Property Value Is a Function

1. 'name': function

> Executes the function and uses its return value as the final property value; the function's context is the object containing the property 'name'

###### 7. Property Value Is a Regular Expression

1. 'name': regexp

> Generates, in reverse, a string that matches the regular expression regexp. Used to generate strings in custom formats

##### Data Placeholder Definition

1. Use @ to indicate that the string following it is a placeholder
2. A placeholder refers to a method in Mock.Random
3. Custom placeholders are added via Mock.Random.extend()
4. A placeholder can also reference properties in the data template
5. A placeholder gives priority to properties in the data template
6. Placeholders support relative paths and absolute paths

#### Mock.setup()

> Configures the behavior of Ajax requests; currently only timeout is supported as a configuration option

```javascript
  Mock.setup({
    timeout: 500
  })
  Mock.setup({
    timeout: '100-600'
  })
```

#### Mock.Random

```javascript
  const Random = Mock.Random
  Random.email() // => sd.sdf@
  Mock.mock('@email') // => sd.sdf@
  Mock.mock({ email: 'sd.sdf@' }) // => { email: "sd.sdf@" }
```

##### Extension

```javascript
Random.extend({
  fruit () {
    const fruit = ['apple', 'peach', 'lemon']
    return this.pick(fruit)
  }
})
Random.fruit() // => 'peach'
Mock.mock('@fruit')  // => 'lemon'
Mock.mock({
  fruit: '@fruit' // => 'peach'
})
```
