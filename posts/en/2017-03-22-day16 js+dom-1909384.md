## 2. Scope

Scope is the set of accessible **variables, objects, and functions**. A JavaScript variable's lifetime begins when it is declared; local variables are destroyed after the function finishes executing; global variables are destroyed after the page is closed.

1. A function acts as a scope
2. A function's scope is created before the function is called
3. A function's scope has a scope chain, which is also created before the call — look in your own scope first; if it is not there, look one level up, then further outward
4. Local variables inside a function are declared in advance, without being assigned

Closure example (the inner function can still access the outer variable after being returned):

```javascript
function func() {
    var xo = 'hequan';
    function inner() {
        console.log(xo);
    }
    return inner;
}
var ret = func()
ret()
// hequan
```

Hoisted local variable example:

```javascript
function func() {
    console.log(xo);
    var xo = "hequan";
}
func()
// undefined
```

## 3. Object-Oriented

The this constructor style:

```javascript
function foo(n) {
    this.name = n;
    this.sayName = function () {
        console.log(this.name)
    }
}
var obj1 = new foo("hq")
obj1.sayName()
```

The prototype style:

```javascript
function Foo(n) {
    this.name = n;
}
Foo.prototype = {
    'sayName': function () {
        console.log(this.name)
    }
}
obj1 = new Foo('we');
obj1.sayName()
```

## 4. DOM Lookup and Manipulation

Lookup:

- Direct lookup: `var obj = document.getElementById('i1')`
- Indirect lookup: `innerText` for text, `innerHTML` for the full content, `obj.value` to get the value

Style manipulation:

- `className`, `classList.add / .remove`
- `style.color`

Attribute manipulation:

```javascript
obj.setAttribute("attribute", "value")
```

Creating tags and adding them to the HTML:

```javascript
// String approach
insertAdjacentHTML("beforeEnd", obj)

// Object approach
document.createElement('div')
```

Submitting a form:

```javascript
document.getElementById('form').submit()
```

## 6. Events

Events include `onclick`, `onblur`, `onfocus`, and so on. Getting tags:

- `document.getElementById`: get one tag by ID
- `document.getElementsByName`: get a collection of tags by the name attribute
- `document.getElementsByClassName`: get a collection of tags by the class attribute
- `document.getElementsByTagName`: get a collection of tags by tag name

Two ways to bind events:

1. Bind directly: `onclick="xx()"`
2. Get the DOM object first, then bind:

```html
<div id='test'><button type="button">Click Me!</button></div>

<script>
    var mydiv = document.getElementById('test')
    console.log(mydiv)
    mydiv.onclick = function () {
        console.log('asdw');
    }
</script>
```

`this`: the tag that currently triggered the event.

First binding style:

```javascript
onclick="Chang(this)"

function Chang(self){
    // self: the tag currently being clicked
}
```

Second binding style:

```html
<input id='i1' type='button'>

<script>
    document.getElementById('i1').onclick = function(){
        // this refers to the tag currently being clicked
    }
</script>
```
