> **About this post**
>
> A command-line walkthrough of installing the NVIDIA driver on a CentOS 7 GPU server:
> first remove the old kernel, blacklist nouveau, and rebuild the initramfs, then reboot and confirm the blacklist took effect;
> next install kernel-devel matching the running kernel along with the gcc build environment;
> finally install the 550.107.02 driver via the runfile and verify the result with nvidia-smi.

> **Technical notes**
>
> CentOS 7 reached end of life (EOL) on June 30, 2024; migrating to Rocky Linux 9 / AlmaLinux 9 or the domestic openEuler is recommended.
>
> - nouveau is the open-source graphics driver shipped with the kernel and is mutually exclusive with the proprietary NVIDIA driver. It must first be written into a blacklist, the initramfs rebuilt with `dracut --force`, and the machine rebooted before it is fully disabled.
> - The kernel-devel version must match the currently running kernel (check with `uname -r`); otherwise, building the nvidia kernel module will fail.
> - `-no-x-check -no-nouveau-check -no-opengl-files` skip the X server, nouveau, and OpenGL checks respectively, which suits servers without a graphical interface.
> - The CUDA Version shown in the `nvidia-smi` header is the maximum CUDA runtime version supported by the driver; it does not mean a CUDA Toolkit is installed on the host.

## 1. Remove the Old Kernel and Disable nouveau

```shell
# Remove the old ones
sudo rpm -e kernel-5.15.13-1.x86_64
sudo rpm -e kernel-devel-5.15.13-1.x86_64
grub2-mkconfig -o /boot/efi/EFI/centos/grub.cfg
grub2-mkconfig -o /boot/grub2/grub.cfg
sed -i 's/GRUB_CMDLINE_LINUX="/&net.ifnames=0 biosdevname=0 /' /etc/sysconfig/grub
sudo grub2-set-default 0

lsmod | grep nouveau  # Check whether nouveau is loaded
sudo vim /etc/modprobe.d/blacklist-nouveau.conf
# Create and edit this file, adding the following content:
blacklist nouveau
options nouveau modeset=0

sudo dracut --force  # Force the rebuild
reboot  # Reboot the instance to avoid kernel issues
lsmod | grep nouveau  # Verify that nouveau is successfully disabled
```

## 2. Install the Kernel Development Environment

```shell
yum clean all
yum makecache

yum install kernel-devel-3.10.0-1160.71.1.el7* gcc -y
ls /boot | grep vmlinu
rpm -aq | grep kernel-devel  # Verify that the kernel and source versions match; if they match, proceed to the next step.
```

## 3. Install the GPU Driver and Verify

```shell
# If the GPU driver has not been downloaded, download it first
sudo chmod 777 NVIDIA-Linux-x86_64-550.107.02.run  # Grant permissions
sh NVIDIA-Linux-x86_64-550.107.02.run -no-x-check -no-nouveau-check -no-opengl-files
nvidia-smi  # Verify that the installation succeeded
```
