> **About this post**
>
> This post uses a Shell script to batch-process the local network interfaces: it first
> lists the interface names with `ip a` (excluding lo and docker interfaces), then for
> interfaces under `/etc/sysconfig/network-scripts/` that lack an ifcfg- config file it
> automatically generates a minimal DHCP-based configuration
> (DEVICE/BOOTPROTO/ONBOOT/TYPE), and finally checks each interface's status,
> activating any interface still in the DOWN state in the background with `ifup`, and
> uses `wait` to wait for all of them to finish.

> **Technical notes**
>
> ifcfg-* is the legacy initscripts configuration format under
> `/etc/sysconfig/network-scripts/` on RHEL/CentOS systems: the bundled
> network-scripts have been deprecated since RHEL 8, and NetworkManager on RHEL 9
> defaults to the keyfile format, so newer systems need to adapt accordingly with
> `nmcli` or keyfiles. Also note that `ifup` performs a full activation based on the
> config file (including DHCP address acquisition), unlike `ip link set up`, which only
> sets the link state; the script takes column 9 of the `ip link show` output as the
> state, and for some virtual interfaces this value is UNKNOWN, which the script
> directly treats as "already activated".

## 1. The script: auto-generate ifcfg config files and activate the interfaces

The script works through two loops: the first loop fills in the missing
`ifcfg-<interface-name>` config files, and the second loop activates the interfaces
still in the DOWN state in the background with `ifup`.

```shell
#!/bin/bash

# Get all interface names
interface_list=$(ip a | awk '/^[0-9]+: / {gsub(":", ""); print $2}' | grep -v lo | grep -v docker)

network_scripts_dir="/etc/sysconfig/network-scripts/"

for interface in $interface_list; do
  config_file="ifcfg-${interface}"
  config_file_path="${network_scripts_dir}${config_file}"

  # Check whether the config file exists
  if [ ! -f "$config_file_path" ]; then
    echo "生成配置文件: $config_file_path"

    # Create the config file
    touch "$config_file_path"

    # Write the basic configuration to the file
    echo "DEVICE=${interface}" > "$config_file_path"
    echo "BOOTPROTO=dhcp" >> "$config_file_path"
    echo "ONBOOT=yes" >> "$config_file_path"
    echo "TYPE=Ethernet" >> "$config_file_path"
  fi
done

for interface in $interface_list; do
  # Check the interface status (UP or DOWN)
  interface_status=$(ip link show $interface | awk '/<.*>/ {print $9}')

  if [ "$interface_status" == "DOWN" ]; then
    echo "激活网卡：$interface"
    # Bring the interface up with root privileges
    ifup $interface &
  else
    echo "网卡已激活：$interface"
  fi
done

wait
```
