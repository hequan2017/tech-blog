## 1. Introduction to Modules

A module is a collection of code that implements some functionality. Modules come in three kinds:

- Custom modules
- Built-in standard modules (the standard library)
- Open-source modules (site: pypi.org)

The following mock project demonstrates calling modules across directories. The directory structure is shown below (the backend package contains a logic layer and a data layer; config stores the configuration):

![Web project file directory tree](../assets/1886646/03_wKiom1hiSy6xs-UQAAAcrW_IfWM018.png)

Import and call:

```python
from backend.logic import handle  ## this import style requires the directory to be a package, i.e. it must contain an __init__.py

handle.home()
```

## 2. json & pickle Serialization

- json: converts between strings and Python data types; file reading/writing uses `r` / `w`
- pickle: converts between **Python-specific types** and Python data types; file operations use `rb` / `wb`, supports more complex types

Both provide 4 functions: `dumps` / `dump` / `loads` / `load`.

pickle write (for json, just replace `wb` with `w`):

```python
import pickle

f = open("user.txt", "wb")
info = {
    "user": "123",
    "hequan": '123'
}
f.write(pickle.dumps(info))
f.close()
```

Reading:

```python
import pickle

f = open("user.txt", 'rb')
data = pickle.loads(f.read())
print(data)
```

The difference between `dumps/dump` (same for `loads/load`):

```python
pickle.dump(info, f)    ## write
data = pickle.load(f)   ## read
```

## 3. time & datetime & Monthly Calendar

```python
import time
```

Time tuple:

| No. | Field | Value |
| --- | --- | --- |
| 0 | 4-digit year tm_year | 2008 |
| 1 | Month tm_mon | 1 to 12 |
| 2 | Day tm_mday | 1 to 31 |
| 3 | Hour tm_hour | 0 to 23 |
| 4 | Minute tm_min | 0 to 59 |
| 5 | Second tm_sec | 0 to 61 (60 or 61 are leap seconds) |
| 6 | Day of week tm_wday | 0 to 6 (0 is Monday) |
| 7 | Day of year tm_yday | 1 to 366 (Julian day) |
| 8 | Daylight saving time tm_isdst | -1, 0, 1; -1 is the flag deciding whether DST applies |

Get the current time:

```python
import time

localtime = time.localtime(time.time())
print(localtime)
```

Output:

```text

```

Get formatted time and formatted date:

localtime = time.asctime(time.localtime(time.time()))

print(time.strftime("%Y-%m-%d  %H:%M:%S", time.localtime()))

## 4. random Module

- `random.randint(a, b)`: generates an integer within a specified range. Parameter a is the lower bound and parameter b the upper bound; the random number n satisfies a <= n <= b
- `random.randrange([start], stop[, step])`: picks a random number from a set within the specified range, incremented by the specified step. For example, `random.randrange(10, 100, 2)` is equivalent to picking a random number from the sequence [10, 12, 14, 16, ... 96, 98]

## 5. os Module

```python
os.popen("dir").read()  # runs the command, saves the result somewhere temporarily and returns it
```

Quick reference of common interfaces:

```text
os.getcwd()                          returns the current working directory, i.e. the directory path of the running Python script
os.chdir("dirname")                  changes the current working directory; like cd in a shell
os.curdir                            returns the current directory string ('.')
os.pardir                            returns the parent directory string ('..')
os.makedirs('dirname1/dirname2')     creates multi-level recursive directories
os.removedirs('dirname1')            deletes the directory if empty, then recurses to the parent and deletes it if empty too, and so on
os.mkdir('dirname')                  creates a single-level directory; like mkdir dirname in a shell
os.rmdir('dirname')                  deletes a single-level empty directory, error if not empty; like rmdir dirname in a shell
os.listdir('dirname')                lists all files and subdirectories under the given directory, including hidden files, printed as a list
os.remove()                          deletes a file
os.rename("oldname", "newname")      renames a file/directory
os.stat('path/filename')             gets file/directory information
os.sep                               outputs the OS-specific path separator, "\\" on Windows and "/" on Linux
os.linesep                           outputs the line terminator of the current platform, "\r\n" on Windows and "\n" on Linux
os.pathsep                           outputs the string used to separate file paths
os.name                              outputs a string indicating the current platform: Windows -> 'nt'; Linux -> 'posix'
os.system("bash command")            runs a shell command, displaying the output directly
os.environ                           gets system environment variables
os.path.abspath(path)                returns the normalized absolute path of path
os.path.split(path)                  splits path into a (directory, filename) tuple and returns it
os.path.dirname(path)                returns the directory part of path, i.e. the first element of os.path.split(path)
os.path.basename(path)               returns the final filename of path, empty if path ends with / or \; i.e. the second element
os.path.exists(path)                 returns True if path exists, otherwise False
os.path.isabs(path)                  returns True if path is an absolute path
os.path.isfile(path)                 returns True if path is an existing file, otherwise False
os.path.isdir(path)                  returns True if path is an existing directory, otherwise False
os.path.join(path1[, path2[, ...]])  joins multiple paths and returns the result; parameters before the first absolute path are ignored
os.path.getatime(path)               returns the last access time of the file or directory pointed to by path
os.path.getmtime(path)               returns the last modification time of the file or directory pointed to by path
```

## 7. shutil Module

A module for handling files and folders.

**shutil.copyfileobj(fsrc, fdst[, length])**: copies file content into another file; can copy only part of the content. Source code:

```python
def copyfileobj(fsrc, fdst, length=16*1024):
    """copy data from file-like object fsrc to file-like object fdst"""
    while 1:
        buf = fsrc.read(length)
        if not buf:
            break
        fdst.write(buf)
```

Other common functions:

- **shutil.copyfile(src, dst)**: copies files
- **shutil.copymode(src, dst)**: copies permissions only; content, group and owner stay unchanged
- **shutil.copystat(src, dst)**: copies status info, including mode bits, atime, mtime, flags
- **shutil.copy(src, dst)**: copies file and permissions
- **shutil.copy2(src, dst)**: copies file and status info
- **shutil.ignore_patterns(\*patterns)**: used with copytree to exclude files
- **shutil.copytree(src, dst, symlinks=False, ignore=None)**: recursively copies files, e.g. `copytree(source, destination, ignore=ignore_patterns('*.pyc', 'tmp*'))`
- **shutil.rmtree(path[, ignore_errors[, onerror]])**: recursively deletes files
- **shutil.move(src, dst)**: recursively moves files

**shutil.make_archive(base_name, format, ...)**: creates an archive and returns the file path, e.g. zip, tar. Parameters:

- base_name: the filename of the archive, which may also be a path. A bare filename is saved to the current directory; otherwise it is saved to the given path
  - e.g. `www` => saved to the current path
  - e.g. `/Users/wupeiqi/www` => saved to /Users/wupeiqi/
- format: the archive kind: "zip", "tar", "bztar", "gztar"
- root_dir: the folder path to compress (defaults to the current directory)
- owner: the user, defaults to the current user
- group: the group, defaults to the current group
- logger: for logging, usually a logging.Logger object

shutil handles archives by calling the two modules ZipFile and TarFile.

## 8. shelve Module

A simple k,v module that persists in-memory data through files, supports pickle:

```python
import shelve

d = shelve.open('shelve_test')  # open a file


class Test(object):
    def __init__(self, n):
        self.n = n


t = Test(123)
t2 = Test(123334)
name = ["alex", "rain", "test"]

d["test"] = name  # persist the list
d["t1"] = t       # persist the class
d["t2"] = t2
d.close()
```

## 11. configparser Module

Used to generate and modify common configuration files:

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
import configparser

config = configparser.ConfigParser()
config["DEFAULT"] = {'ServerAliveInterval': '45',
                     'Compression': 'yes',
                     'CompressionLevel': '9'}
config['bitbucket.org'] = {}
config['bitbucket.org']['User'] = 'hg'
config['topsecret.server.com'] = {}
topsecret = config['topsecret.server.com']
topsecret['Host Port'] = '50022'   # mutates the parser
topsecret['ForwardX11'] = 'no'  # same here
config['DEFAULT']['ForwardX11'] = 'yes'
with open('example.ini', 'w') as configfile:
    config.write(configfile)
```

The generated example.ini:

```ini
[DEFAULT]
serveraliveinterval = 45
compression = yes
compressionlevel = 9
forwardx11 = yes
[bitbucket.org]
user = hg
[topsecret.server.com]
host port = 50022
forwardx11 = no
```

## 14. logging Module

Provides the standard logging interface, with 5 levels:

```text
debug()  info()  warning()  error()  critical()
```

Screen output:

```python
import logging

logging.warning("user [alex] attempted wrong password more than 3 times")
logging.critical("server is down")

# output
# WARNING:root:user [alex] attempted wrong password more than 3 times
# CRITICAL:root:server is down
```

Writing to a file:

```python
import logging

logging.basicConfig(filename='example.log', level=logging.INFO)
logging.debug('This message should go to the log file')
logging.info('So should this')
logging.warning('And this, too')
```
