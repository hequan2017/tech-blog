> **About this post**
>
> This post documents the complete process of deploying InfluxDB 2.x in Docker:
> first generate the default configuration with influxd print-config,
> then write a docker-compose orchestration file and start the container,
> install the influx CLI and run setup to initialize the user, organization, and bucket,
> and finally demonstrate multi-config management inside the container and common InfluxQL statements in the v1-compatible shell.

> **Technical notes**
>
> CentOS 7 reached end of life (EOL) on June 30, 2024; it is recommended to migrate to Rocky Linux 9 / AlmaLinux 9 or the domestically developed openEuler.
>
> This post uses InfluxDB 2.x: data is organized by org/bucket/token, with the TSM storage engine underneath.
> The official focus has shifted to 3.x (Core/Enterprise), which reached GA in 2025: rewritten in Rust, storage moved to Apache Arrow/Parquet,
> queries are primarily SQL with InfluxQL compatibility provided; Flux is no longer evolving and is not supported in 3.x, while 1.x/2.x have entered maintenance mode (2.7 is the last minor release of 2.x).
> Note: the INFLUXDB_* environment variables in the compose file follow the 1.x image convention, while the 2.x image uses DOCKER_INFLUXDB_INIT_* for automatic initialization;
> in this post, initialization is actually done manually via influx setup.

## 1. Prepare directories and the default config

```shell
mkdir -p /data/influx
cd /data/influx
docker run --rm influxdb:latest influxd print-config > config.yml

vim docker-compose.yaml
```

Write the following content:

```yaml
version: "3"
services:
  influxdb:
    image: influxdb:latest
    container_name: influxdb
    environment:
      - INFLUXDB_DB=db0
      - INFLUXDB_ADMIN_ENABLED=true
      - INFLUXDB_ADMIN_USER=admin
      - INFLUXDB_ADMIN_PASSWORD=123456
    volumes:
      - /data/influx/influxdb2:/var/lib/influxdb2
      - /data/influx/config.yml:/etc/influxdb2/config.yml
      - /data/influx/data:/var/lib/influxdb/data
      - /data/influx/meta:/var/lib/influxdb/meta
      - /data/influx/wal:/var/lib/influxdb/wal
      - /data/influx/backup/bin:/home/backup
      - /data/influx/backup/data:/tmp/backup/data
      - /data/influx/backup/gz:/tmp/backup/gz
      - /etc/localtime:/etc/localtime:ro
    ports:
      - "8086:8086"
    restart: always
```

## 2. Pull the image and start

```shell
docker pull influxdb
docker-compose up -d
```

## 3. Install the influx CLI client

```shell
wget https://dl.influxdata.com/influxdb/releases/influxdb2-client-2.2.0-linux-amd64.tar.gz
tar xvzf influxdb2-client-2.2.0-linux-amd64.tar.gz
sudo cp influxdb2-client-2.2.0-linux-amd64/influx /usr/local/bin/
```

## 4. Initialize InfluxDB

```text

[root@hequan influx]# influx setup
```

Log in at http://localhost:8086

## 5. Multi-config and v1 compatibility operations inside the container

```shell
docker exec -it influxdb /bin/bash
influx config create --config-name test --host-url http://localhost:8086 --org wgs --token 11111111111111 --active
root@1fcc0bd16a40:/# influx v1 shell
```

Common InfluxQL statements:

```sql
create database db1  -- create database db1
drop database db1  -- drop database db1
drop measurement mt1  -- drop measurement mt1
delete from measurement [WHERE <tag_key> <operator>]
drop shard <shard_id_num>  -- delete a shard

> insert myapp,host=127.0.0.1,service=app.service.index qps=1340,rt=1313,cpu=45.23,mem="4145m",load=1.21
> select * from myapp
```
