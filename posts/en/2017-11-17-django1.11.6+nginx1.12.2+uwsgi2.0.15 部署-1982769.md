> **About this post**
>
> This post documents the production deployment stack for the AutoOps automation
> operations platform: Django 1.11.6 + uWSGI 2.0.15 + Nginx 1.12.2. The steps
> cover: compiling Python 3.6.3 from source and replacing the system python
> while keeping the python2.7 interpreter for yum; configuring a China-based
> pip mirror and then installing uwsgi and django; writing uwsgi.ini (workers,
> socket, static directory, timeouts, and logs) along with start/stop/reload
> commands; and finally configuring the uwsgi_pass reverse proxy and the
> /static/ alias in nginx.conf to bring the Django project online.

> **Technical notes**
>
> Python 3.6 reached end of maintenance in December 2021, and Django 1.11 LTS
> went EOL in April 2020; use Python 3.11+/Django 4.2+ LTS for new projects.
> The sohu Python mirror stopped being updated long ago; Huawei Cloud or
> Aliyun mirrors are recommended. A few pieces of content that were eaten by
> the editor or mistyped in the original have been fixed: the empty address in
> pip.conf's `index-url = http:///simple` was completed to the aliyun mirror
> following common 2017 practice; the long dash in `python –V` was changed to
> `-V`; the two ./configure runs should be merged into a single execution
> (both lines are kept as-is — running only the latter would drop
> --enable-shared). Overwriting /usr/bin/python directly with python3 is
> rather risky; on newer systems it is advisable to keep the system python and
> manage it with virtual environments or alternatives.

## 1. Install Python 3.6

```bash
yum -y install xz wget gcc make gdbm-devel openssl-devel sqlite-devel zlib-devel bzip2-devel
wget http://mirrors.sohu.com/python/3.6.3/Python-3.6.3.tar.xz
tar -xf Python-3.6.3.tar.xz
cd Python-3.6.3

./configure --enable-shared --enable-loadable-sqlite-extensions --with-zlib
./configure --enable-optimizations
make && make install
```

> Note: the original ran `./configure` twice in a row; only the parameters of
> the last run take effect. It is advisable to merge the parameters of the two
> lines into a single execution.

Replace the system default python, and point yum back to python2.7:

```bash
mv /usr/bin/python /usr/bin/python2.7
ln -s /usr/local/bin/python3 /usr/bin/python

vim /etc/ld.so.conf
/usr/local/lib
include ld.so.conf.d/*.conf
/sbin/ldconfig

python -V

vim /usr/bin/yum
#!/usr/bin/python2.7
```

## 2. Switch pip to a Mirror and Install uwsgi and django

```bash
vim /root/.pip/pip.conf
[global]
index-url = https://mirrors.aliyun.com/pypi/simple/
trusted-host = mirrors.aliyun.com

pip3     install uwsgi  django
```

## 3. uWSGI Configuration, Start and Stop

Start directly from the command line (for testing):

```bash
uwsgi --http :8001 --chdir /opt/autoops/ -w autoops.wsgi --static-map=/static=static
```

Full configuration file:

```bash
vim      uwsgi.ini
```

```ini
[uwsgi]
# Project directory
chdir=/opt/autoops/
# The project's application
module=autoops.wsgi:application
# Number of worker processes
workers=8
pidfile=/opt/autoops/script/uwsgi.pid
# IP and port to bind
#http=0.0.0.0:8003    ## Can be left disabled when using a socket file; enable it if you only need a test run
# Static files
static-map=/static=/opt/autoops/static
# User and group that run uwsgi
uid=root
gid=root
# Enable the master process
master=true
# Automatically remove the unix socket and pid file when the service stops
vacuum=true
# Serialize accepted content, if possible
thunder-lock=true
# Enable threads
enable-threads=true
# Set the self-kill timeout
harakiri=30
# Set buffering
post-buffering=4096
# Set the log file
daemonize=/opt/autoops/script/uwsgi.log
# Socket file path
socket=/opt/autoops/script/uwsgi.sock
```

Start/stop commands:

```bash
uwsgi --ini uwsgi.ini   # start uwsgi with this config
uwsgi --stop script/uwsgi.pid # stop uwsgi
uwsgi --reload  script/uwsgi.pid  # reload
```

## 4. Nginx Site Configuration

For installing nginx, refer to the post "nginx-1.12.2 Installation,
Configuration Files, Log Rotation, and Startup Script" on the same blog. For
the site part, modify nginx.conf as follows:

```nginx
  root         /opt/autoops;

    location / {
#       uwsgi_pass 127.0.0.1:8003;
        include uwsgi_params;
        uwsgi_connect_timeout 30;
        uwsgi_pass unix:/opt/autoops/script/uwsgi.sock;
    }
    location /static/ {
            alias  /opt/autoops/static/;
            index  index.html index.htm;
    }
```

Once nginx is started, the site is ready for testing.
