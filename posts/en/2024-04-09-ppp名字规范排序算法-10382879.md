> **About this post**
>
> This post implements `CreateId`, a Go function that generates numbers for
> "ppp" resource naming: it reads all `pname` values from the database, filters
> out the names starting with "ppp" and parses their numeric suffixes, sorts
> them, and finds the smallest missing number starting from 0; if there is no
> gap, it continues with the largest number plus one, returning the next
> available number.

> **Technical notes**
>
> The snippet omits imports; in practice it depends on `sort`, `strconv`,
> `strings`, and gorm, and the `Config` struct needs a `Pname` field;
> `sort.Ints` sorts a `[]int` in ascending order in place. Sorting the parsed
> numbers as integers rather than strings avoids the lexicographic pitfall of
> "ppp10 coming before ppp2" — that is the "canonical sorting" in the title;
> the final "all numbers used up" branch is in fact equivalent to simply
> returning `missingNumber`.

---

```go
// Imports needed: sort, strconv, strings, and gorm; the Config struct must have a Pname field
func CreateId(db *gorm.DB) int {
	var configs []Config
	db.Select("pname").Find(&configs)

	var usedNumbers []int
	for _, config := range configs {
		if strings.HasPrefix(config.Pname, "ppp") {
			numberStr := strings.TrimPrefix(config.Pname, "ppp")
			number, err := strconv.Atoi(numberStr)
			if err == nil {
				usedNumbers = append(usedNumbers, number)
			}
		}
	}

	sort.Ints(usedNumbers) // Ensure the numbers are sorted

	// Find the missing number or continue to the next available number
	missingNumber := 0
	for _, number := range usedNumbers {
		if number == missingNumber {
			missingNumber++
		} else {
			break // Found the missing number
		}
	}

	// If all numbers are already used, missingNumber will be the largest number plus one
	if missingNumber == len(usedNumbers) {
		// All numbers are used, continue with the next number
		if len(usedNumbers) > 0 {
			missingNumber = usedNumbers[len(usedNumbers)-1] + 1
		}
	}
	return missingNumber
}
```
