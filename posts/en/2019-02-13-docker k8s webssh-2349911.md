> **About this post**
>
> Use gotty to bring the command-line terminal into the browser: gotty acts as a proxy that runs `docker exec -it <container> /bin/bash`, with the container name passed via URL parameters, enabling web-based entry into docker containers as a webssh; the same applies to Kubernetes (with `kubectl exec`).
>
> **Technical notes**
>
> The gotty project (yudai/gotty) has not been updated for many years; a community-maintained fork exists at sorenisanerd/gotty. To enter K8s containers, it is recommended to use `kubectl exec -it` directly, or to evaluate more modern webssh solutions (e.g., ttyd, or a self-built xterm.js + WebSocket setup).

---

Download the gotty executable: https://github.com/yudai/gotty/releases

Run the command:

```shell
./gotty -w -p 8081 -a 192.168.100.50 --permit-arguments docker exec -it
```

Access it from a browser:

```text
http://192.168.100.50:8081/?arg=mysql&arg=/bin/bash
```

`arg` is an argument; gotty acts as a proxy that executes `docker exec -it mysql /bin/bash`, and you can also pass in all the arguments to be executed. The same applies to K8s.
