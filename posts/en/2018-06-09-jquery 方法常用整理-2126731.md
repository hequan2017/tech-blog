> **About this post**
>
> This post is a quick-reference cheat sheet of commonly used jQuery methods: the two ways to write document-ready and basic selectors;
> effect methods such as hide/show/toggle, fadeIn/fadeOut, and slideDown/slideUp, plus animate-based animations;
> value retrieval with text/html/val, attribute handling with attr/prop, insertion with append/prepend/after/before, and
> removal with remove/empty and other DOM operations; styling with addClass/css and the width/height family of dimension methods;
> tree traversal with parent/children/siblings/find and filtering with first/filter; it closes with $.get/$.post
> AJAX, the $.getJSON/$.noConflict utility methods, and a comparison table of commonly used native DOM interfaces.

> **Technical notes**
>
> The jQuery 1.x / 2.x branches stopped receiving maintenance in 2019; new projects should use jQuery 3.x (4.0 was
> released in 2025);
> This post organizes method names by topic, omitting parameters and callbacks throughout; when actually using them, please consult the official API documentation.

---

## 1. Document Ready and Selectors

```javascript
$(document).ready(function(){
    // Start writing jQuery code...
});

$(function(){
    // Start writing jQuery code...
});

$("p")
$("#id")
$('.class')
$(this)
$('p#id')
```

.prevUntil
