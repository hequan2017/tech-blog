> **About this post**
>
> Server and client configuration for setting up NFS shared storage on CentOS 7: install rpcbind/nfs-utils, write /etc/exports to share /data, start the services with systemctl and hot-reload with exportfs; on the client, inspect with showmount, mount, and add an entry to /etc/fstab; finally, unify the Domain via idmapd.conf to keep file ownership from turning into nobody.

> **Technical notes**
>
> NFS itself is still in common use today, but there are two environment differences: CentOS 7 has reached EOL, and on RHEL 8+/Rocky 8+ the service name is `nfs-server` (rpcbind is still there); `no_root_squash` carries a security risk — in production, prefer `root_squash` combined with fixed uid/gid. Mount timeouts and locking issues in container/K8s scenarios are usually addressed by switching to CSI drivers (e.g., nfs-subdir-external-provisioner).

---

Server and client

```shell
yum -y install rpcbind nfs-utils
```

Server

```shell
vim /etc/exports
/data  192.168.10.0/24(rw,sync,no_root_squash)
* ro # read-only permission
* rw # read-write permission
* sync # synchronous, safer data, slower
* async # asynchronous, faster, more efficient, less secure
```

```shell
systemctl enable nfs-server
systemctl enable rpcbind
systemctl  start nfs-server
systemctl   start rpcbind.service

exportfs

chmod o+w  /data

exportfs -v
/data           192.168.10.0/24(rw,async,wdelay,hide,no_subtree_check,sec=sys,secure,root_squash,no_all_squash)
```

Common options

```shell
* -a: mount or unmount everything
* -r: remount
* -u: unmount a directory
* -v: show shared directories
* Common combination: exportfs -arv
* After changing the configuration file on the server, just run this command without restarting the service and the new configuration takes effect.
Note: Before restarting the NFS service, unmount all mount points first; otherwise a program error will occur, and in severe cases it can bring down the system.
```

Client

```shell
yum -y install  rpcbind nfs-utils
systemctl   start rpcbind.service

showmount -e  192.168.10.100

mount    192.168.10.100:/data /data1

vim /etc/fstab
192.168.10.100:/data    /data  nfs   rw
```

Server and client   # So that after a file is created, it belongs to the creator's user.

```shell
vim /etc/idmapd.conf
5 Domain =

systemctl restart rpcbind.service
```
