> **About this post**
>
> Use Python's croniter library to compute the next execution time from a crontab expression: after installing the dependency, call `get_next()` starting from the current time, and you get a formatted string of the next trigger time. This is commonly used in scheduled-task management systems to show users when a task will run next.
>
> **Technical notes**
>
> croniter is still actively maintained today (it supports Python 3.8+), and its API is essentially the same as in this post. Note that the install command in the original text was mistakenly written as `python 3.6 -m pip`; the correct form is `pip3 install croniter`.

---

```shell
pip3 install croniter
```

```python
import croniter
import datetime

def run_get_next_time(sched):
    now = datetime.datetime.now()
    cron = croniter.croniter(sched, now)
    return [cron.get_next(datetime.datetime).strftime("%Y-%m-%d %H:%M")][0]

print(run_get_next_time("* * * * *"))
```
