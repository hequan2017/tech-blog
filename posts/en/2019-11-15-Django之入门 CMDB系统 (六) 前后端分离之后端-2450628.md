> **About this post**
>
> Part 6 of the "Getting Started with Django: A CMDB System" series, covering the backend side of the
> front-end/back-end separation (MVVC) approach: using djangorestframework to provide APIs that pair
> with the vue + d2Admin front end from Part 5. It first lists the project dependencies and the key
> settings configuration (token authentication, CORS cross-origin access, pagination and filtering,
> disabling CSRF checks), then uses the system app as an example to give a complete set of
> models/serializers/views/urls/admin samples (CRUD for Test, plus user info and logout endpoints),
> and finishes with deployment and startup.

> **Technical notes**
>
> 1. This post was written for Python 3.6 + Django 2.2 + DRF 3.10 (the versions noted in the pandaAdmin repository). Python 3.6 and Django 2.2 LTS reached end of support in December 2021 and April 2022 respectively; the mainstream in 2026 is the Django 4.2/5.x series, and many of the patterns shown here no longer apply.
> 2. MIDDLEWARE_CLASSES was removed as of Django 2.0 (only MIDDLEWARE takes effect), so DisableCSRFCheck is never actually mounted; in MIDDLEWARE, AuthenticationMiddleware appears twice and CsrfViewMiddleware is commented out — these are shortcuts of the demo environment and should not be carried over to production.
> 3. django-rest-swagger was archived and unmaintained in 2019; the CoreAPI-based include_docs_urls has been deprecated by DRF and removed in 3.13 — use drf-yasg or drf-spectacular to generate API documentation today, and DEFAULT_SCHEMA_CLASS should be changed to rest_framework.schemas.openapi.AutoSchema.
> 4. django-cors-headers is still actively maintained, but CORS_ORIGIN_ALLOW_ALL and CORS_ORIGIN_WHITELIST have been renamed to CORS_ALLOW_ALL_ORIGINS and CORS_ALLOWED_ORIGINS — the old names do not work on new versions; django-filter's filter_fields has likewise been renamed to filterset_fields.
> 5. Authentication uses DRF's built-in TokenAuthentication (exchange credentials for a token via the /token endpoint), which current DRF versions still support; for JWT, the common community solution is djangorestframework-simple-jwt. The views.py examples omit imports; add them yourself when using the code (generics, filters, permissions, Token, APIView, HttpResponse, etc.).
> 6. Corrections to the original: the GitHub/QQ group and project addresses in the preface were masked on the source site and have been restored from the author's repositories (hequan2017/panda, pandaAdmin); the missing 'user_id', two empty list comprehensions, and the return value of the Test model's __str__ were all filled in based on the pandaAdmin source code.

- views.py

```python
class TestList(generics.ListCreateAPIView):
    queryset = Test.objects.get_queryset().order_by('id')
    serializer_class = TestSerializer
    filter_backends = (DjangoFilterBackend, filters.SearchFilter, filters.OrderingFilter)
    filter_fields = ('id', 'date','name')
    search_fields = ('id', 'name',)
    permission_classes = (permissions.DjangoModelPermissions,)  # inherits Django's permission system

class TestDetail(generics.RetrieveUpdateDestroyAPIView):
    queryset = Test.objects.get_queryset().order_by('id')
    serializer_class = TestSerializer
    permission_classes = (permissions.DjangoModelPermissions,)

class UserInfo(APIView):
    """
    Get user information
    """
    permission_classes = (permissions.IsAuthenticated,)

    def post(self, request):
        token = (json.loads(request.body))['token']
        obj = Token.objects.get(key=token).user
        result = {
            'name': obj.username,
            'user_id': obj.id,
            'access': list(obj.get_all_permissions()) + ['admin'] if obj.is_superuser else list(
                obj.get_all_permissions()),
            'token': token,
            'avatar': ''
        }
        return HttpResponse(json.dumps(result))

class UserLogout(APIView):
    permission_classes = (permissions.IsAuthenticated,)

    def post(self, request):
        token = (json.loads(request.body))['token']
        obj = Token.objects.get(key=token)
        obj.delete()
        result = {
            "status": True
        }
        return HttpResponse(json.dumps(result))
```

- admin.py

```python
from django.contrib import admin
from system.models import Users, Test
from django.contrib.auth.admin import UserAdmin

class UsersAdmin(UserAdmin):
    fieldsets = (
        (None, {'fields': ('username', 'password')}),
        ('基本信息', {'fields': ('first_name', 'last_name', 'email')}),
        ('权限', {'fields': ('is_active', 'is_staff', 'is_superuser', 'groups', 'user_permissions')}),
        ('登录时间', {'fields': ('last_login', 'date_joined')}),
        ('其他信息', {'fields': (
            'position', 'avatar', 'mobile',)}),
    )

    @classmethod
    def show_group(self, obj):
        return [i.name for i in obj.groups.all()]

    @classmethod
    def show_user_permissions(self, obj):
        return [i.name for i in obj.user_permissions.all()]

    list_display = ('username', 'show_group', 'show_user_permissions')
    list_display_links = ('username',)
    search_fields = ('username',)
    filter_horizontal = ('groups', 'user_permissions')

admin.site.register(Users, UsersAdmin)
admin.site.register(Test)

admin.site.site_header = '管理后台'
admin.site.site_title = admin.site.site_header
```
