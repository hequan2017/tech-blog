> **About this post**
>
> This post shows a Ping function implemented with the go-ping library
> (github.com/go-ping/ping): it sends 2 ICMP probes to the target address
> with a timeout set, and considers the IP alive and returns true as long
> as 1 or more replies are received. It can be embedded in Go programs
> for batch IP reachability checks.

> **Technical notes**
>
> `SetPrivileged(true)` means sending privileged raw ICMP packets (on Linux
> this requires root or the CAP_NET_RAW capability; on Windows there is no
> such requirement); setting it to `false` uses unprivileged UDP ping,
> which under the default Linux configuration usually receives no replies.
> Compared with calling the system ping via `exec.Command`, the library
> approach does not depend on an external command and offers controllable
> timeout and count; if you switch to the system command instead, note that
> the Windows/Linux flags differ (`-n` / `-c`).

---

```go
import "github.com/go-ping/ping"

func Ping(addr string, t time.Duration) bool {
  // ping.New()
  pinger, err := ping.NewPinger(addr)
  if err != nil {
    return false
  }
  // Set the number of pings
  pinger.Count = 2
  pinger.Timeout = time.Duration(t)

  /*
    Set the type of packets the pinger will send.
    false means the pinger will send "unprivileged" UDP pings
    true means the pinger will send "privileged" raw ICMP pings
  */
  pinger.SetPrivileged(true)
  // Run the pinger
  pinger.Run()
  stats := pinger.Statistics()
  if stats.PacketsRecv >= 1 {
    return true
  } else {
    return false
  }
}
```
