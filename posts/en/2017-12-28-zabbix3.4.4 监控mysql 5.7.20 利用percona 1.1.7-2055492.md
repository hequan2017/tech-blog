> **About this post**
>
> This post records the complete steps for monitoring MySQL 5.7.20 with
> percona-monitoring-plugins 1.1.7: installing percona-zabbix-templates
> and php, copying the userparameter configuration, changing the database
> credentials in ss_get_mysql_stats.php, importing a corrected template
> that works with 3.x, and adjusting the absolute paths of php and mysql
> in the wrapper script. It also covers renaming the cache file for
> instances on a non-3306 port and configuring master/slave monitoring
> (running-slave).

> **Technical notes**
>
> - CentOS 7 reached end of maintenance (EOL) on June 30, 2024;
>   migrating to Rocky Linux 9 / AlmaLinux 9 or the Chinese openEuler is
>   recommended.
> - Zabbix 3.4 support ended in October 2019; the Percona monitoring
>   plugin 1.1.7 is the final release and is no longer officially
>   maintained. For new environments, Percona PMM or the MySQL plugin
>   built into zabbix-agent2 is recommended.
> - MySQL 5.7 support ended in October 2023.
> - The template link in the original post was missing the protocol
>   prefix (https:///); it has been corrected to the actual file in the
>   author's GitHub repository
>   https://github.com/hequan2017/zabbix-models.

## 1. Install percona-zabbix-templates-1.1.7-2

```shell
wget https://www.percona.com/downloads/percona-monitoring-plugins/percona-monitoring-plugins-1.1.7/binary/redhat/7/x86_64/percona-zabbix-templates-1.1.7-2.noarch.rpm
rpm -ivh percona-zabbix-templates-1.1.7-2.noarch.rpm
yum install percona-zabbix-templates php php-mysql -y
```

## 2. Copy the configuration file

```shell
rpm -ql percona-zabbix-templates
cp /var/lib/zabbix/percona/templates/userparameter_percona_mysql.conf     /usr/local/zabbix/etc/zabbix_agentd.conf.d/
```

## 3. Modify the database connection file

```shell
vim /var/lib/zabbix/percona/scripts/ss_get_mysql_stats.php
$mysql_user = 'root';
$mysql_pass = '';
$mysql_port = 3306;
$mysql_socket = NULL;
$mysql_flags = 0;
```

## 4. Import the template

Since the original template has problems when used with 3.x, download the template below:

`https://github.com/hequan2017/zabbix-models/blob/master/zabbix_agent_template_percona_mysql_server_ht_2.0.9-sver1.1.7.xml`

## 5. Configure php

Change the php executable path in the wrapper script:

```shell
vim get_mysql_stats_wrapper.sh

CMD="/usr/local/php/bin/php    -q $DIR/ss_get_mysql_stats.php --host $HOST --items gg
```

## 6. Set permissions

```shell
cd /tmp
chown -R zabbix.zabbix localhost-mysql_cacti_stats.txt

/etc/init.d/zabbix_agentd restart
```

## 7. Test

```shell
/var/lib/zabbix/percona/scripts/get_mysql_stats_wrapper.sh gw
17603
```

## 8. Appendix: Adjustments for instances on non-default ports

If mysql does not use the default port 3306, the following script file also needs to be modified:

```shell
touch /tmp/localhost-mysql_cacti_stats.txt:3317
chown -R zabbix.zabbix /tmp/$HOST-mysql_cacti_stats.txt:3317
```

Modify the port in the script:

```shell
vim /var/lib/zabbix/percona/scripts/get_mysql_stats_wrapper.sh
CACHEFILE="/tmp/$HOST-mysql_cacti_stats.txt "
Change to:
CACHEFILE="/tmp/$HOST-mysql_zabbix_stats.txt:3317"
```

```shell
TIMEFLM=`stat -c %Y /tmp/$HOST-mysql_cacti_stats.txt`
Change to:
TIMEFLM=`stat -c %Y /tmp/$HOST-mysql_zabbix_stats.txt:3317`
```

Modify the mysql command path:

```shell
#RES=`HOME=~zabbix mysql -e 'SHOW SLAVE STATUS\G' | egrep '(Slave_IO_Running|Slave_SQL_Running):' | awk -F: '{print $2}' | tr '\n' ','`
Change to:
RES=`/usr/local/mysql/bin/mysql -e 'SHOW SLAVE STATUS\G' | egrep '(Slave_IO_Running|Slave_SQL_Running):' | awk -F: '{print $2}' | tr '\n' ','`
```

## 9. Monitor the slave

Set the login account and password:

```shell
vim /usr/local/mysql/etc/my.cnf
[mysql]
user=zabbixmoniter
password=ys_ipowerlong0418
socket=/usr/local/mysql/mysql.sock
```

Test:

```shell
sh /var/lib/zabbix/percona/scripts/get_mysql_stats_wrapper.sh running-slave
```

An output of `1` means it is working; the corresponding monitoring item is `MySQL running slave`.
