> **About this post**
>
> This is an ops scripting note: use a Go for loop to batch-generate
> configuration lines for the 38 `10GE1/0/x` interfaces of a switch —
> `interface 10GE1/0/N`, `ipv6 enable`, and
> `ipv6 address <hex address> 126`.
> The address is computed as i*4+1, formatted as hexadecimal, and
> stepped through interface by interface.

> **Technical notes**
>
> `i*4 + 1*2 - 1` is just 4i+1: /126 is a common prefix length for IPv6
> point-to-point links (the equivalent of /30 in IPv4). Each /126 block
> has 4 addresses in total, and interface ID 0 is the Subnet-Router
> Anycast address, so the first usable address of each block is taken
> from 4i+1, and a step of 4 lines up with each block exactly. Commands
> like `interface 10GE1/0/x` follow the Huawei VRP command style; the
> generated addresses contain only the low-order hex digits
> (1, 5, 9, d, ...), not the network prefix, which must be filled in
> before the configuration is actually pushed.

---

```go
for i := 0; i < 38; i++ {
    fmt.Printf("interface 10GE1/0/%v\n", i+1)
    fmt.Printf("ipv6 enable\n ")
    a := strconv.Itoa(i*4 + 1*2 - 1)
    distInt64, _ := strconv.ParseInt(a, 10, 64)
    fmt.Printf("ipv6  address  %v 126\n", fmt.Sprintf("%x", distInt64))
    }
```
