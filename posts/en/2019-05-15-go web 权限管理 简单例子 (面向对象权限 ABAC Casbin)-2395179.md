> **About this post**
>
> This post demonstrates how to implement Attribute-Based Access Control (ABAC) with casbin. Unlike RBAC, which makes decisions by role, ABAC compares the attributes of the request subject (the groups the user belongs to) with those of the resource object (App, Type, Method, etc.) directly in the model (abac_model.conf), and grants access once the conditions are met. The example code builds a user, user groups, and a resource object, then iterates over all of the user's groups and calls `Enforce` on each one to check whether access is allowed.

> **Technical notes**
>
> This post is based on the casbin v1 era API. casbin has since evolved to v2 (`github.com/casbin/casbin/v2`), where `NewEnforcer` returns `(e, err)` and the error must be handled. ABAC usage itself has changed little, but note that accessing Go struct attributes in a matcher requires the fields to be exported (starting with an uppercase letter). In addition, the path hardcoded in `casbin.NewEnforcer` as `E:\\` is Windows-style; for cross-platform deployment it should be replaced with a relative path or injected via configuration.

### A Simple Example of Go Web Permission Management (Object-Based Permissions with ABAC / Casbin)

---

#### Description

> ABAC
> Uses github.com/casbin/casbin

---

#### abac_model.conf

```ini
[request_definition]
r = sub, obj, act

[policy_definition]
p = sub, obj,act

[policy_effect]
e = some(where (p.eft == allow))

[matchers]
# Note: the left-hand side expression was lost when the original was collected; from context it should be r.sub.App == r.obj.App
m = r.sub.App == r.obj.App && r.sub.Type == r.obj.Type && r.sub.Method == r.obj.Method
```

#### main.go

```go
package main

import (
	"fmt"
	"github.com/casbin/casbin"
)

type User struct {
	Id       int
	UserName string
	Group    []Group
}

type Group struct {
	Id       int
	Name     string
	App      string // app
	Type     string // type
	Method   string // method
	Priority int    // priority
}

type Obj struct {
	App    string // app
	Type   string // type
	Method string // method
}

func main() {
	e := casbin.NewEnforcer("E:\\go-test\\test\\abac\\abac_model.conf")

	group1 := Group{
		Name:     "group1",
		App:      "asset",
		Type:     "aliyun",
		Method:   "Get",
		Priority: 100,
	}

	group2 := Group{
		Name:     "group2",
		App:      "asset",
		Type:     "aliyun",
		Method:   "Get",
		Priority: 100,
	}

	// user hequan belongs to group1, group2
	user1 := User{
		UserName: "hequan",
		Group:    []Group{group1, group2},
	}

	obj := Obj{
		App:    "asset",
		Type:   "aliyun",
		Method: "Get",
	}

	var perms = false

	// check whether any of the groups of user hequan has permission
	for _, v := range user1.Group {
		if e.Enforce(v, obj, ""){
			perms = true
			break
		}
	}
	if perms {
		fmt.Println("权限正常")
	} else {
		fmt.Println("没有权限")
	}
}
```
