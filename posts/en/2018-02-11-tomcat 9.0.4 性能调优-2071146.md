> **About this post**
>
> When applying Connector optimization parameters found online to Tomcat 9.0.4, the author ran into two startup warnings: the `maxSpareThreads` attribute no longer exists, and the `compressableMimeType` spelling was not recognized. After checking the official documentation, it was confirmed that the former has been removed and that the correct spelling of the latter is `compressibleMimeType`. A working, complete NIO Connector configuration is provided along with a parameter-by-parameter explanation.

> **Technical notes**
>
> Tomcat 9 entered the final phase of maintenance in 2025; new projects are advised to go straight to Tomcat 10.1 (note that starting with 10.x, package names migrated from javax.* to jakarta.*, so legacy applications need adaptation). The NIO connector configuration approach in this post remains generally applicable today; large thread counts such as `maxThreads="1000"` should be determined against real memory and load testing — blindly increasing them does more harm than good.

### tomcat9.0.4

---

I applied some optimization parameters found online, but noticed 2 warnings during startup:

```shell
11-Feb-2018 15:57:23.293 警告 [main] org.apache.catalina.startup.SetAllPropertiesRule.begin [SetAllPropertiesRule]{Server/Service/Connector} Setting property 'maxSpareThreads' to '200' did not find a matching property.
11-Feb-2018 15:57:23.343 警告 [main] org.apache.catalina.startup.SetAllPropertiesRule.begin [SetAllPropertiesRule]{Server/Service/Connector} Setting property 'compressableMimeType' to 'text/html,text/xml,application/javascript,text/css,text/plain' did not find a matching property.
```

After checking the official documentation, confirmed:

- The `maxSpareThreads` parameter no longer exists (it has been removed).
- `compressableMimeType` has been renamed to `compressibleMimeType`.

The final configuration is as follows:

```html
<Connector
port="8080"
protocol="org.apache.coyote.http11.Http11NioProtocol"
enableLookups="false"
maxThreads="1000"
minSpareThreads="100"
acceptCount="900"
disableUploadTimeout="true"
connectionTimeout="20000"
URIEncoding="UTF-8"
redirectPort="8443"
compression="on"
compressionMinSize="1024"
useSendfile="false"
noCompressionUserAgents="gozilla, traviata"
compressibleMimeType="text/html,text/xml,text/plain,text/css,text/javascript,application/javascript "   />
```

Parameter descriptions:

- org.apache.coyote.http11.Http11NioProtocol: switches the working mode to NIO
- maxThreads: the maximum number of threads, 150 by default. Increasing this value avoids too many queued requests, which cause slow responses.
- minSpareThreads: the minimum number of idle threads.
- acceptCount: when requests being processed exceed this value, later requests are placed in a queue to wait.
- disableUploadTimeout: disables the upload timeout.
- connectionTimeout: the connection timeout in milliseconds; 0 means no limit.
- URIEncoding: uses UTF-8 as the URI encoding.
- enableLookups: disables DNS resolution to improve response time.
- compression: enables compression.
- compressionMinSize: the minimum size for compression, in bytes.
- compressibleMimeType: the MIME types to be compressed.

Tested in practice: it runs normally, with no errors.
