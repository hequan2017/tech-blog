> **About this post**
>
> A short ops troubleshooting note: when MySQL clients connect slowly on an
> internal network, it is usually because the server performs a reverse DNS
> lookup on the client IP and the lookup times out. Simply adding the
> `skip-name-resolve` parameter to my.cnf to skip DNS name resolution
> resolves the slow-connection problem.

> **Technical notes**
>
> When MySQL receives a connection request, by default it performs a reverse
> DNS lookup on the client IP in order to match host-based accounts in the
> grant tables. If there is no DNS on the internal network or the reverse
> lookup times out, every new connection stalls at this step, which shows up
> as slow connections. Adding `skip-name-resolve` (equivalent to
> `skip_name_resolve=ON`) to the `[mysqld]` section of my.cnf skips the
> reverse lookup. Note: from then on, the Host column in the grant tables
> can only contain IP addresses or `localhost`; any existing host-name-based
> accounts will stop working, and the grants need to be adjusted accordingly.

---

Add one parameter

```ini
skip-name-resolve
```

This skips DNS name resolution.
