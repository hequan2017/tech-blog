> **About this post**
>
> A Bash script that automates installing the MySQL 5.7.21 binary distribution: it first compiles jemalloc to replace the glibc memory allocator, then writes /etc/my.cnf (with parameters for the InnoDB buffer pool, slow query log, binlog, character set, and more), initializes the data directory, registers a chkconfig service, and sets the root password. The second half demonstrates mysqldump backup options (-A/-B/--single-transaction/--master-data) along with restore and password-changing commands.

> **Technical notes**
>
> MySQL 5.7 reached EOL in October 2023; for new deployments go straight to 8.0/8.4 LTS. A few time-sensitive differences in the script: the default password `123456` is for illustration only and must never be used in production; the `update user set password=...` syntax was replaced by `authentication_string` in 5.7+; `query_cache_size` was removed in MySQL 8.0; for jemalloc integration, newer versions more commonly use LD_PRELOAD or the compile-time -DWITH_JEMALLOC option; and `tcp_tw_recycle` in the kernel parameters was removed in kernel 4.12 and is best deleted.

### Backup

```shell
mysqldump -uroot -p123456 -B  ultrax        --single-transaction  --master-data=2  > ultrax.sql

-A  Full backup
-B  Backup databases (table structure and data)
--single-transaction    Avoids locks; data consistency; ensures that during this session (the dump) you will not see data committed by other sessions.
--master-data=2     Records the replication information as a comment
                       =1      Records the CHANGE MASTER TO statement
```

### Viewing the SQL

```shell
egrep -v "#|\*|--|^$"    ultrax.sql
```

### Restore

```shell
mysql -uroot -p123456        < /root/ultrax.sql
```
