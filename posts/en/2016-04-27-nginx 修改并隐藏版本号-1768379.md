> **About this post**
>
> Two ways to modify and hide the Nginx version number: the first is to edit the
> source code before compiling — the NGINX_VERSION / NGINX_VER / NGINX_VAR macros in
> nginx.h, the Server header string in ngx_http_header_filter_module.c, and the
> error page strings in ngx_http_special_response.c, so that both the version
> number and the product name can be changed; the second is to add server_tokens
> off to the http/server/location blocks of the configuration file to hide the
> version number (the default is on, which displays the full version information).

> **Technical notes**
>
> Nginx configuration differs slightly between major versions; when in doubt,
> follow the official documentation of the current stable release (1.24+/1.26+).
> Note that `server_tokens off` only hides the version number — the response
> header still shows `Server: nginx`. To remove the Server header entirely, use
> the headers-more module (`more_clear_headers Server`) or apply method one:
> edit the source code and recompile.

---

## 1. Check the Current Version Information

```shell
curl -I 192.168.10.11 | grep Server
```

## 2. Method One: Modify the Source Code Before Compiling (Change the Version and Version Number)

`src/core/nginx.h`:

```c
#define nginx_version      1008001
#define NGINX_VERSION      "1.8.1"                  # change to the version you want to display, e.g. 2.2.23
#define NGINX_VER          "nginx/" NGINX_VERSION   # change nginx to the product name you want to display
#define NGINX_VAR          "NGINX"                  # change NGINX to the desired product name (Evan Web Server)
#define NGX_OLDPID_EXT     ".oldbin"
```

`src/http/ngx_http_header_filter_module.c`:

```c
static char ngx_http_server_string[] = "Server: nginx" CRLF;   # change nginx to the desired name
```

`src/http/ngx_http_special_response.c`:

```c
"<hr><center>nginx</center>" CRLF   # product name shown on the error page; this can be changed as well
```

## 3. Method Two: Hide the Version Number

Add `server_tokens off;` to the nginx configuration file. Its scope covers the
http, server, and location blocks; the default value is on, which displays
version information. Setting it to off hides nginx's version information
everywhere.

```nginx
http {
    server_tokens off;
}
```
