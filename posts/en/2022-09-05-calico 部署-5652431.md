> **About this post**
>
> This post demonstrates how to deploy the Calico network plugin on a Kubernetes v1.25.0 cluster built with kubeadm: download the official calico.yaml, change CALICO_IPV4POOL_CIDR so it matches the pod-network-cidr passed to kubeadm, apply it, and verify that pods such as calico-node are all Running. Finally, it also shows how to install the calicoctl command-line tool and query IPPools.
>
> **Technical notes**
>
> Calico v3.24 is already an older release; v3.28+ is recommended today. If you are on a newer Kubernetes (v1.28+), simply download the official manifest for your version — the CIDR can be matched automatically via `--pod-network-cidr`, with no manual edit needed.

---

```shell
Deployment

wget https://docs.projectcalico.org/manifests/calico.yaml --no-check-certificate

vim +4546 calico.yaml
...
- name: CALICO_IPV4POOL_CIDR
  value: "10.244.0.0/16"

kubectl apply -f calico.yaml

mv calicoctl /usr/local/bin/
calicoctl get ippool  --allow-version-mismatch
```
