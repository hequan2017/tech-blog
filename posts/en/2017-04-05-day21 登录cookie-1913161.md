## 2. The URL Routing System

```text
a. /index/                           ->  function or class
b. /index/(\d+)                      ->  function or class
c. /index/(?P<nid>\d+)               ->  function or class
d. /index/(?P<nid>\d+)  name='root'  ->  function or class
   reverse()
   {% url 'root' 1 %}
e. /crm/   include('app01.urls')     ->  route distribution
```

f. Default values:

```python
url(r'^index/', views.index, {'name': 'root'}),

def index(request, name):
    print(name)
    return HttpResponse('OK')
```

g. Namespace:

```python
/admin/  include('app01.urls', namespace='m1')
/crm/    include('app01.urls', namespace='m1')

# app01.urls
/index/  name = 'n1'

reverse('m1:n1')     # typo in the original (reverser); corrected
```

- Decorators. FBV:

```python
def auth(func):
    def inner(request, *args, **kwargs):
        v = request.COOKIES.get('username111')
        if not v:
            return redirect('/login/')
        return func(request, *args, **kwargs)
    return inner
```

## 6. Templates: Master Template and Custom Tags

- Master template ...html: extends, include
- Custom functions

simple_tag:

```python
from django import template
from django.utils.safestring import mark_safe

register = template.Library()

@register.simple_tag
def u():
    return 123

@register.simple_tag
def func(a1, a2, a3, ...):
    return "asdfasd"
```

Steps: a. create a templatetags directory under the app; b. any xxoo.py file;
c. create the template object register; d. register functions as shown above;
e. register the APP in settings; f. at the top of the template, {% load xxoo %};
g. use {% function_name arg1 arg2 %}.

- Drawback: cannot be used as an if condition
- Advantage: any number of arguments

filter:

```python
@register.filter
def func(a1, a2):
    return "asdfasd"
```

Steps are the same as above; usage: `{{ arg1|function_name:"arg2,arg3" }}`,
`{{ arg1|function_name:number }}`.

- Drawback: at most two arguments, and no spaces allowed
- Advantage: can be used as an if condition

Pagination (a custom paginator). XSS:

```python
{{ page_str|safe }}
mark_safe(page_str)
```

Cookie: a file stored in the client's browser, e.g. {"user": 'dachengzi'};
