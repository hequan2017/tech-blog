> **About this post**
>
> This post is a note on setting up a network environment: install the iKuai
> routing system image in a VMware virtual machine to simulate a PPPoE
> dial-up environment. First configure the three network adapters as
> VMnet1, the LAN segment "ppp dial-up", and VMnet8 (NAT) respectively,
> then log in to the iKuai web UI and set up accounts and enable PPPoE
> under "Authentication & Billing → PPPoE Server".
>
> **Technical notes**
>
> The screenshots are based on iKuai 3.7.1 x64: the console home page shows
> the web management address and the lan1/lan2/wan1 NIC bindings; the PPPoE
> server is under "Authentication & Billing → Local Authentication Service",
> with local account authentication; the address pool 10.1.1.2-10.1.1.254
> is bound to lan1, and each LAN allows only 1 address pool (cross-subnet
> pools are allowed). VMware's "LAN segment" is an isolated network reachable
> only by VMs on the same host, which makes it suitable for simulating a
> dial-up link.
