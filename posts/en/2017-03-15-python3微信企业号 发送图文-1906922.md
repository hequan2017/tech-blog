> **About this post**
>
> A complete script for sending image-and-text messages through the WeChat Enterprise Account API with Python 3: it uses requests to fetch the access_token, uploads an image via media/upload to obtain a media_id, then builds text and image message payloads and POSTs each to message/send. The post demonstrates how to fill in parameters such as touser/toparty/agentid.

> **Technical notes**
>
> The "WeChat Enterprise Account" has been upgraded to "WeChat Work"; the API domain and the agentid type have changed, so adjust against the latest documentation. In the code, the variable name `purl1` in `send_text` is inconsistent with the `purl` used afterwards, which would raise a NameError; it has been fixed to a unified variable.

---

This example only applies to the Enterprise Account; I have not tried it with WeChat official accounts, but you can test it yourself since the method is similar. For any issues, consult the official development documentation.

## 1. Configuration Parameters

- `UserID`: Member ID list (recipients of the message; separate multiple IDs with `|`, up to 1000; if set to `@all`, the message is sent to all members who follow this enterprise application).
- `PartyID`: Department ID list, separate multiple IDs with `|`, up to 100; this parameter is ignored when `touser` is `@all`.
- `AppID`: Application ID, an integer, defaults to the "Enterprise Assistant"; you can view it on the application's settings page.

## 2. Complete Code

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
import requests
import json
import urllib.request

ID="xxxxxxxxxxxx"
Secret="xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

UserID = "hequan2011"##Member ID list (message recipients; separate multiple with '|', up to 1000). Special case: set to @all to send to every member following this app
PartyID=17  ##Department ID list, separate multiple with '|', up to 100. Ignored when touser is @all
AppID = 0  ##Application ID, integer, defaults to the Enterprise Assistant. Viewable on the app's settings page

def get_token():  ##Get TOKEN
    gurl = "https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid={}&corpsecret={}".format(ID, Secret)
    r=requests.get(gurl)
    dict_result= (r.json())
    return dict_result['access_token']

def get_media_ID(path):  ##Upload to temporary media, get the image ID
    Gtoken = get_token()
    img_url = "https://qyapi.weixin.qq.com/cgi-bin/media/upload?access_token={}&type=image".format(Gtoken)
    files = {'image': open(path, 'rb')}
    r = requests.post(img_url, files=files)
    re = json.loads(r.text)
    return re['media_id']

def  send_text(text):  ##Send text
    post_data = {}
    msg_content = {}
    msg_content['content'] = text  ## Message content, at most 2048 bytes
    post_data['touser'] = UserID
    post_data['toparty'] = PartyID
    post_data['msgtype'] = 'text'
    post_data['agentid'] = AppID
    post_data['text'] = msg_content
    post_data['safe'] = '0'  #Whether the message is confidential: 0 no, 1 yes, default 0
    Gtoken = get_token()
    purl1="https://qyapi.weixin.qq.com/cgi-bin/message/send?access_token={}".format(Gtoken)
    json_post_data = json.dumps(post_data,False,False)
    request_post = urllib.request.urlopen(purl1,json_post_data.encode(encoding='UTF8'))
    return request_post

def  send_tu(path):  ##Send image
    img_id = get_media_ID(path)
    post_data1 = {}
    msg_content1 = {}
    msg_content1['media_id'] = img_id
    post_data1['touser'] = UserID
    post_data1['toparty'] = PartyID
    post_data1['msgtype'] = 'image'
    post_data1['agentid'] = AppID
    post_data1['image'] = msg_content1
    post_data1['safe'] = '0'
    Gtoken = get_token()
    purl2="https://qyapi.weixin.qq.com/cgi-bin/message/send?access_token={}".format(Gtoken)
    json_post_data1 = json.dumps(post_data1,False,False)
    request_post = urllib.request.urlopen(purl2,json_post_data1.encode(encoding='UTF8'))
    return request_post

send_tu("1.png")  ##Image path
send_text("123-何全")  ##Text content
```
