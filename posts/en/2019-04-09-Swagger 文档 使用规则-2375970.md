> **About this post**
>
> A reposted compilation of the declarative comments format documentation from teambition/swaggo: it explains how to generate Swagger API documentation from comment annotations in a Go project, covering the global annotations in swagger.go (@Title/@Host/@BasePath, etc.), Controller annotations, Handler annotations (@Param/@Success/@Failure/@Router), and the usage of the swaggo struct tag.
>
> **Technical notes**
>
> teambition/swaggo has not been maintained for many years; the mainstream choice in the Go community is now swaggo/swag (where `swag init` generates the docs). The annotation syntax is similar but not fully compatible (for example, the @Param format and the @Router style differ). The original wiki link may no longer be valid.

---

1. The swagger.go file

Use `_` imports to bring in all packages that contain documentation annotations.

```go
package main

import (
    _ "github.com/teambition/swaggo/example/pkg/api"
)

// @Version 1.0.0
// @Title Swagger Example API
// @Description Swagger Example API
// @Schemes http,wss
// @Host 127.0.0.1:3000
// @BasePath /api
// @Name teambition
// @Contact swagger@teambition.com
// @URL http://teambition.com
// @TermsOfServiceUrl http://teambition.com/
// @License Apache
// @LicenseUrl http://teambition.com/
// @Consumes json,xml
// @Produces json,xml
```

@Version: the API version number.

@Title: the service name.

@Description: the service description.

@Schemes: the service protocols (http, websockes).

@Host: the available server address, used for testing.

@BasePath: the prefix of the API path.

@Name: the author's name.

@Contact: the author's contact information.

@URL: the author's personal page.

@TermsOfServiceUrl: the URL of the terms of service.

@License: the open source license.

@LicenseUrl: the URL of the license.

@Consumes: the media types the method accepts; separate multiple values with commas, including (json,xml,plain,form,formData,stream).

@Produces: the media types the method returns, including (json,xml,plain,html,form,formData,stream).

### 2. Controller annotations

Reference: https://github.com/teambition/swaggo/wiki/Declarative-Comments-Format (the link may no longer be valid)

```go
// @Private reason
// @Name Controller
// @Description test apis
type Controller struct {
}
```

@Private: if present, all API documentation under this Controller is not exposed publicly.

- reason: the private note, optional.

@Name: the resource name.

@Description: the resource description.

### 3. Handler annotations

```go
// @Private reason
// @Title Hello
// @Summary say hello
// @Description this is a method to say hello
// @Deprecated true
// @Consumes json
// @Produces json
// @Param some_id path int true "Some ID"
// @Param offset query int true "Offset"
// @Param limit query int true "Limit"
// @Success 200 StructureWithEmbededPointer "Success!"
// @Failure 400 APIError "We need ID!!"
// @Failure 404 APIError "Can not find ID"
// @Router GET /say/hello/{some_id}
func (c *Controller) Hello(rw http.ResponseWriter, req *http.Request) {
}
```

@Private: if present, the API documentation is not exposed publicly.

@Title: the method name.

@Summary: a brief summary of the method.

@Description: a detailed description of the method.

@Deprecated: the API is no longer in use.

@Consumes: the media types the method accepts; separate multiple values with commas, including (json,xml,plain,form,formData,stream).

@Produces: the media types the method returns, including (json,xml,plain,html,form,formData,stream).

@Param: the parameter list, separated by spaces.

```text
// @Param some_id path int true "Some ID" 6
```

- some_id: the parameter name.
- path: the parameter type, including (path: path parameter, query: request parameter, header: request header, form: form, body: request body).
- int: the data type; supports native Golang types (int,string,bool...) and custom types (your_package.YourType).
- true: whether the parameter is required, optional; use - as a placeholder.
- "Some ID": a brief description of the parameter, optional; use - as a placeholder.
- 6: the default value, optional.

@Success: the success response example, separated by spaces.

```text
// @Success 200 StructureWithEmbededPointer "Success!"
```

- 200: the HTTP status code.
- StructureWithEmbededPointer: the response data type; supports native Golang types ([]int,int,string,bool...) and custom types (your_package.YourType).
- "Success!": the result description, required.

@Failure: the failure response example, separated by spaces.

@Router: the route definition, separated by spaces.

```text
// @Router GET /say/hello/{some_id}
```

- GET: the request method; supports (GET,POST,PUT,PATCH,DELETE,HEAD,OPTIONS).
- /say/hello/{some_id}: the route path; {some_id} is defined in **@Param**.

### 4. Go struct tags

```go
type SimpleStructure struct {
    Id float32 `json:"id" swaggo:"true,my id,19"`
    Name string `json:"name" swaggo:"true,,xus"`
    Age int `json:"age" swaggo:"true,the user age,18"`
    CTime time.Time `json:"ctime" swaggo:"true,create time"`
    Sub subpackage.SimpleStructure `json:"sub" swaggo:"true"`
    I TypeInterface `json:"i" swaggo:"true"`
}
```

swaggo:"true,dfsdfdsf,19": the swaggo tag related to the Swagger documentation, separated by commas.

- true: whether it is required, optional; when a value is omitted, the comma separator is kept.
- my id: the documentation description, optional; when a value is omitted, the comma separator is kept.
- 19: the default value, optional; when a value is omitted, the comma separator is kept.
