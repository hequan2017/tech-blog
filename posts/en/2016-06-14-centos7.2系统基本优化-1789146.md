> **About this post**
>
> This post records 16 basic optimizations to apply after installing CentOS 7.2 (kernel 3.10.0-327.18.2):
> renaming the NIC to eth0 (editing grub to disable consistent naming), updating the system, making
> rc.local executable, creating a user and elevating privileges via wheel/sudo, disabling SELinux,
> replacing firewalld with iptables, setting the hostname and locale, configuring the 163/EPEL/rpmforge
> repositories and common dependency packages, hardening sshd, raising file descriptor and nproc limits,
> tuning sysctl kernel parameters, chrony time synchronization, plus the Chinese man pages and a
> personalized vim configuration — each item with complete commands and output.

> **Technical notes**
>
> CentOS 7.2 reached EOL on June 30, 2024 (an earlier note mistakenly said CentOS 6); production
> environments should migrate to Rocky Linux 9 / AlmaLinux 9 / openEuler.
> The kernel parameter `net.ipv4.tcp_tw_recycle` has been removed since Linux 4.12, and enabling it
> behind NAT causes broken connections — do not configure it on newer kernels; keep `tcp_timestamps`
> at its default.
> Third-party repositories such as the 163 mirror and rpmforge (Repoforge) are defunct or unmaintained;
> the related sections are for historical reference only. On CentOS 8+, iptables uses the nftables
> backend, and firewalld is the default firewall solution.

## 1. Rename the NIC to eth0

Edit the NIC configuration:

```shell
cd /etc/sysconfig/network-scripts/
vim ifcfg-eno16777729
```

```ini
TYPE=Ethernet
BOOTPROTO=static
IPADDR=192.168.1.201
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
DEFROUTE=yes
PEERDNS=yes
PEERROUTES=yes
IPV4_FAILURE_FATAL=no
NAME=eth0
UUID=efd17b9a-a5ab-4c94-be62-d2c32eb48a7e
DEVICE=eth0
ONBOOT=yes
DNS1=202.106.0.20
```

Rename it and disable consistent device naming:

```shell
mv ifcfg-eno16777729 ifcfg-eth0
vi /etc/sysconfig/grub
```

```ini
GRUB_TIMEOUT=5
GRUB_DISTRIBUTOR="$(sed 's, release .*$,,g' /etc/system-release)"
GRUB_DEFAULT=saved
GRUB_DISABLE_SUBMENU=true
GRUB_TERMINAL_OUTPUT="console"
GRUB_CMDLINE_LINUX="net.ifnames=0 biosdevname=0 rhgb quiet"   # add net.ifnames=0 biosdevname=0
GRUB_DISABLE_RECOVERY="true"
```

Generate the boot menu, then reboot and verify:

```shell
grub2-mkconfig -o /boot/grub2/grub.cfg      # generate the boot menu
```



Extension: give user hequan sudo for every operation except shutdown:

```shell
[root@www ~]# visudo
```

```sudoers
Cmnd_Alias SHUTDOWN = /sbin/halt, /sbin/shutdown, /sbin/poweroff, /sbin/reboot, /sbin/init
hequan         ALL=(ALL)       ALL,!SHUTDOWN
%wheel         ALL=(ALL)       ALL,!SHUTDOWN    # adjust wheel group privileges, forbid shutdown
Defaults logfile=/var/log/sudo.log
```

## 5. Disable SELinux

```shell
[root@bogon ~]# grep -i ^selinux /etc/selinux/config
SELINUX=enforcing
SELINUXTYPE=targeted
[root@bogon ~]# sed -i '/^SELINUX/s/enforcing/disabled/g' /etc/selinux/config
[root@bogon ~]# grep -i ^selinux /etc/selinux/config
SELINUX=disabled
SELINUXTYPE=targeted
[root@bogon ~]# getenforce
Enforcing
[root@bogon ~]# reboot
```

## 10. yum repositories and common dependency packages

Install common dependencies:

```shell
yum install gcc cmake bzip2-devel curl-devel db4-devel libjpeg-devel libpng-devel freetype-devel libXpm-devel gmp-devel libc-client-devel openldap-devel unixODBC-devel postgresql-devel sqlite-devel aspell-devel net-snmp-devel libxslt-devel libxml2-devel pcre-devel mysql-devel pspell-devel libmemcached libmemcached-devel zlib-devel vim wget lrzsz tree
```

Install the 163 repo:

```shell
mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.backup
cd /etc/yum.repos.d/
wget http://mirrors.163.com/.help/CentOS7-Base-163.repo
yum clean all
yum makecache
```

Other repositories (priority plugin, EPEL, rpmforge):

```shell
yum -y install yum-plugin-priorities    ## install the priority plugin
sed -i -e "s/\]$/\]\npriority=1/g" /etc/yum.repos.d/CentOS-Base.repo   ## set the base yum repo priority to 1
yum -y install epel-release             ## install the EPEL repo
sed -i -e "s/\]$/\]\npriority=5/g" /etc/yum.repos.d/epel.repo          ## set the priority to 5
sed -i -e "s/enabled=1/enabled=0/g" /etc/yum.repos.d/epel.repo        ## disable the EPEL repo
yum -y install http://apt.sw.be/redhat/el7/en/x86_64/rpmforge/RPMS/rpmforge-release-0.5.3-1.el7.rf.x86_64.rpm  ## install the rpmforge repo
sed -i -e "s/\]$/\]\npriority=10/g" /etc/yum.repos.d/rpmforge.repo    ## set the priority to 10
sed -i -e "s/enabled = 1/enabled = 0/g" /etc/yum.repos.d/rpmforge.repo ## disable the yum repo
```

Usage:

```shell
yum --enablerepo=rpmforge install [Package]
```

## 11. Configure sshd

```shell
sed -i -e '49s/^#//g' /etc/ssh/sshd_config       ## enable the line 49 setting
sed -i -e '49s/yes/no/g' /etc/ssh/sshd_config    ## forbid root login via ssh
sed -i -e '129s/#/ /g' /etc/ssh/sshd_config      ## uncomment the UseDNS setting
sed -i -e '129s/yes$/no/g' /etc/ssh/sshd_config  ## disable UseDNS
sed -i '/^GSS/s/yes/no/g' /etc/ssh/sshd_config   ## disable GSSAPI authentication to speed up login

systemctl restart sshd                           ## restart the service
systemctl enable sshd                            ## enable it at boot
systemctl status sshd                            ## check the status
```

## 12. Raise the open files limit

```shell
ulimit -n
ulimit -a
vi /etc/security/limits.conf
```

Append at the end:

```text
* soft nofile 1024000
* hard nofile 1024000
hive   - nofile 1024000
hive   - nproc  1024000
```

Per-user process limits:

```shell
[root@hequan ~]# sed -i 's#4096#65535#g' /etc/security/limits.d/20-nproc.conf   # raise the limit for ordinary users; can also be set to unlimited
[root@hequan ~]# egrep -v "^$|^#" /etc/security/limits.d/20-nproc.conf
*          soft    nproc     65535
root       soft    nproc     unlimited
```

```shell
reboot
```

## 13. Kernel tuning

```shell
cat /etc/sysctl.conf
```

```ini
# CTCDN system tuning parameters
# disable IPv6
net.ipv6.conf.all.disable_ipv6 = 1
net.ipv6.conf.default.disable_ipv6 = 1
# how often stale neighbor entries are checked
net.ipv4.neigh.default.gc_stale_time=120
# use arp_announce / arp_ignore to solve ARP mapping problems
net.ipv4.conf.default.arp_announce = 2
net.ipv4.conf.all.arp_announce=2
net.ipv4.conf.lo.arp_announce=2
# avoid amplification attacks
net.ipv4.icmp_echo_ignore_broadcasts = 1
# enable protection against bogus ICMP error messages
net.ipv4.icmp_ignore_bogus_error_responses = 1
# disable routing forwarding
net.ipv4.ip_forward = 0
net.ipv4.conf.all.send_redirects = 0
net.ipv4.conf.default.send_redirects = 0
# enable reverse path filtering
net.ipv4.conf.all.rp_filter = 1
net.ipv4.conf.default.rp_filter = 1
# handle packets without source routing
net.ipv4.conf.all.accept_source_route = 0
net.ipv4.conf.default.accept_source_route = 0
# disable the SysRq feature
kernel.sysrq = 0
# append pid to core dump file names
kernel.core_uses_pid = 1
# enable SYN flood protection
net.ipv4.tcp_syncookies = 1
# adjust the message queue length
kernel.msgmnb = 65536
kernel.msgmax = 65536
# set the max shared memory segment size in bytes
kernel.shmmax = 68719476736
kernel.shmall = 4294967296
# number of timewait sockets, default 180000
net.ipv4.tcp_max_tw_buckets = 6000
net.ipv4.tcp_sack = 1
net.ipv4.tcp_window_scaling = 1
net.ipv4.tcp_rmem = 4096        87380   4194304
net.ipv4.tcp_wmem = 4096        16384   4194304
net.core.wmem_default = 8388608
net.core.rmem_default = 8388608
net.core.rmem_max = 16777216
net.core.wmem_max = 16777216
# max packets allowed into the queue when an interface receives packets faster than the kernel can process them
net.core.netdev_max_backlog = 262144
# this limit is only to guard against simple DoS attacks
net.ipv4.tcp_max_orphans = 3276800
# max connection requests that have not received an ACK from the client
net.ipv4.tcp_max_syn_backlog = 262144
net.ipv4.tcp_timestamps = 0
# number of SYNACK packets the kernel sends before giving up a connection
net.ipv4.tcp_synack_retries = 1
# number of SYN packets the kernel sends before giving up a connection
net.ipv4.tcp_syn_retries = 1
# enable fast recycling of timewait sockets
net.ipv4.tcp_tw_recycle = 1
# enable reuse: allow TIME-WAIT sockets to be reused for new TCP connections
net.ipv4.tcp_tw_reuse = 1
net.ipv4.tcp_mem = 94500000 915000000 927000000
net.ipv4.tcp_fin_timeout = 1
# how often TCP sends keepalive messages when keepalive is enabled; default is 2 hours
net.ipv4.tcp_keepalive_time = 1800
net.ipv4.tcp_keepalive_probes = 3
net.ipv4.tcp_keepalive_intvl = 15
# port range the system is allowed to open
net.ipv4.ip_local_port_range = 1024    65000
# resize the firewall table, default 65536
net.netfilter.nf_conntrack_max=655350
net.netfilter.nf_conntrack_tcp_timeout_established=1200
# make sure nobody can modify the routing table
net.ipv4.conf.all.accept_redirects = 0
net.ipv4.conf.default.accept_redirects = 0
net.ipv4.conf.all.secure_redirects = 0
net.ipv4.conf.default.secure_redirects = 0
```

> Note: the sysctl parameters in this section come from the "Lanzhi" blog (http://7826443.blog.51cto.com/7816443/1775248).

```shell
sysctl -p    # apply the settings
```

## 14. Time settings

```shell
ntpdate
hwclock -w             # sync the time to the hardware clock first
```

Using chrony:

```shell
yum install chrony
vi /etc/chrony.conf
```

```ini
server 0.centos.pool.ntp.org
server 3.europe.pool.ntp.org
```

```shell
systemctl enable chronyd.service
systemctl start chronyd.service

timedatectl set-timezone Asia/Shanghai
timedatectl set-time "2015-01-21 11:50:00"    # set the date and time
timedatectl                                   # show the time status

chronyc sources -v       # show the time synchronization sources
chronyc sourcestats -v
```

timedatectl set-time can modify just the date or just the time on its own.
