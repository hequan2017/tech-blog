> **About this post**
>
> A script that implements WeChat Enterprise Account message push with Shell + curl: it obtains an access_token via the gettoken API, uploads an image through media/upload to get a media_id, then calls message/send to deliver text and image messages to designated members — well suited for hooking into crontab as a scheduled alerting job.

> **Technical notes**
>
> The API approach is still generally applicable today, but the "WeChat Enterprise Account" has since been upgraded to "WeChat Work": the API domain, the meaning of agentid, and some field types have all changed, so consult the latest WeChat Work documentation before reusing the script as is; the `p_w_picpath` variable name in the script is contamination introduced during content scraping and should actually be the image file path.

---

```bash
#!/bin/bash
#Get the access token
function getToken(){ #Arguments: $1 is the corpid, $2 is the corpsecret
    curl -s "https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid=$1&corpsecret=$2" | awk -F '"' '{print $4}'
}

#Get the media_id
function getMediaId(){ #Arguments: $1 is the access token; $2 is the image file
    curl -s -F media=@$2 "https://qyapi.weixin.qq.com/cgi-bin/media/upload?access_token=$1&type=p_w_picpath" | awk -F '"' '{print $8}'
}

#Send a text message
function sendText(){ #Arguments: $1 is the access token, $2 is the message content, $3 specifies the account to receive the message
    curl -d '{"touser": "'$3'", "msgtype": "text", "agentid": 0, "text": {"content": "'$2'"}, "safe":"0"}'  "https://qyapi.weixin.qq.com/cgi-bin/message/send?access_token=$1"
}

#Send an image message
function sendImage(){ #Arguments: $1 is the access token; $2 is the media_id, $3 specifies the account to receive the message
    postdata='{"touser": "'$3'", "msgtype": "p_w_picpath", "agentid": 0, "p_w_picpath": {"media_id": "'$2'"}, "safe":"0"}'
    curl -d "$postdata"  "https://qyapi.weixin.qq.com/cgi-bin/message/send?access_token=$1"
}
corpid='xxxxxxxxxx' #Replace with the value noted down earlier
corpsecret='xxxxxxxxxxxxxxxxxxxxxxxxxxxxx'  #Replace with the value noted down earlier
image='test.png'   #Path of the image file to send
text='This is the message content'
receiver='mer_aqu' #This is the receiver's id, per the enterprise account backend settings (ID); it can be a phone number, a WeChat id, or something else. Separate multiple recipients with "|".
token=`getToken $corpid $corpsecret`
sendText $token $text $receiver
media_id=`getMediaId $token $image`
sendImage $token $media_id $receiver
```
