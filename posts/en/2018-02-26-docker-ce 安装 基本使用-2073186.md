> **About this post**
>
> Beginner's notes on installing Docker CE on CentOS 7 from the Aliyun mirror repository, covering how to install a specific version, configuring an Aliyun registry mirror in daemon.json, searching/pulling/exporting/importing images, and basic container commands such as running, starting/stopping, removing, viewing logs, and exec-ing into a container. It ends with a demo of installing openssh-server inside a container and committing it into an SSH-enabled image.

> **Technical notes**
>
> CentOS 7 reached end of life (EOL) on June 30, 2024; production environments are advised to migrate to Rocky Linux / AlmaLinux / Ubuntu LTS. The `--link` flag in this post has been officially deprecated; use user-defined networks (docker network) for container interconnection instead. Running sshd inside a container was an early hands-on exercise; use `docker exec` to enter containers in real scenarios. The Docker CE installation steps and registry mirror configuration remain applicable today.

### Installation

```shell
# step 1: Install the required system tools
sudo yum install -y yum-utils device-mapper-persistent-data lvm2
# Step 2: Add the repository information
sudo yum-config-manager --add-repo http://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo
# Step 3: Update and install Docker-CE
sudo yum makecache fast
sudo yum -y install docker-ce

# Note:
# The official repository enables the latest version by default. You can edit the repo file to obtain other package versions. For example, the test repository is not enabled by default; you can enable it as follows. Other test versions can be enabled the same way.
# vim /etc/yum.repos.d/docker-ce.repo
#   Change enabled=0 to enabled=1 under [docker-ce-test]
#
# Install a specific version of Docker-CE:
# Step 1: Find the Docker-CE versions:
# yum list docker-ce.x86_64 --showduplicates | sort -r
#   Loading mirror speeds from cached hostfile
#   Loaded plugins: branch, fastestmirror, langpacks
#   docker-ce.x86_64            17.03.1.ce-1.el7.centos            docker-ce-stable
#   docker-ce.x86_64            17.03.1.ce-1.el7.centos            @docker-ce-stable
#   docker-ce.x86_64            17.03.0.ce-1.el7.centos            docker-ce-stable
#   Available Packages
# Step 2: Install a specific version of Docker-CE: (VERSION, e.g. 17.03.0.ce.1-1.el7.centos above)
# sudo yum -y install docker-ce-[VERSION]

docker version
```

### Start

```shell
systemctl enable docker.service
systemctl start docker.service
```

### Images

```shell
##Search for images
docker search centos7

##Mirror accelerator URL - Aliyun    Select the accelerator, then run the commands
https://cr.console.aliyun.com/?spm=5176.1971733.0.2.f41b5aaambME9y#/accelerator

sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
"registry-mirrors": ["https://"]
}
EOF
sudo systemctl daemon-reload
sudo systemctl restart docker
```

```shell
##Pull an image
docker pull centos

##Run a container
docker run -it centos /bin/bash

##List images
docker images

##Remove an image
docker rmi   imageID

##Export an image
docker  save centos > /opt/centos.tar.gz

##Import an image
docker load  <  /opt/centos.tar.gz
```

```shell
##Run 1  Start a container, run echo, then stop            Add -d  to run it as a daemon
docker  run  centos  /bin/echo "123"

##Run 2  Start a terminal for interaction        --name name     -i keep stdin open   -t allocate a pseudo-terminal
##To keep the container running after you exit, use CTRL+P+Q
docker run  --name  he -it centos /bin/bash

##Standard sequence
Check whether the specified image exists locally; if not, download it from the public registry
Create and start a container from the image
Allocate a filesystem, with a read-write layer mounted on top of the read-only image layers
Bridge a virtual interface from the host's configured bridge interface into the container
Assign an IP address to the container from the address pool
Run the application specified by the user
The container is terminated once execution finishes
docker ps -a

##Start a stopped container
docker start  CONTAINER ID
docker stop  CONTAINER ID

##Remove a container   -f removes a running one
docker rm  CONTAINER ID

##Logs
docker logs ${container_id}

##Options
docker  -p ip:port:port    -e environment variables  -v host dir:container dir:rw/ro     --volumes-from container name  mount that container's data volumes
        --link  container name:link alias

##Log in
docker exec -it   web    /bin/bash
```

### An image with SSH support

```shell
docker run  -itd centos  /bin/bash
docker attach dedabba9293e
yum install openssh-server net-tools  vim  -y
ssh-keygen -t rsa -b 2048 -f /etc/ssh/ssh_host_rsa_key
mkdir  -p  /var/run/sshd
/usr/sbin/sshd -D &

sed -ri  's/session    required     pam_loginuid.so/#session    required     pam_loginuid.so/g'    /etc/pam.d/sshd

cat  >> /opt/run.sh  <<EOF
#!/bin/bash
/usr/sbin/sshd -D   &
EOF

chmod +x /opt/run.sh

passwd

docker commit   dedabba9293e  sshd

docker run  --name  ssh1  -p 10022:22  -itd  sshd  /opt/run.sh
```
