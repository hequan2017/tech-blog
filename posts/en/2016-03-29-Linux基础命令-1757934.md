> **About this post**
>
> This post is a quick-reference note on Linux commands for beginners. It groups
> the commands most commonly used in day-to-day ops work by purpose: file and
> directory operations (mkdir / touch / cp / mv / rm), text viewing and processing
> (head / tail / grep / sed / awk), searching and batch processing (find / xargs),
> aliases and help (alias / man), users and permissions (passwd / su / sudo / visudo),
> environment variables, checking network status (netstat / lsof), and shutting down,
> among others. It is suitable for beginners to follow along and practice.

> **Technical notes**
>
> These basic commands have long been stable and available on all major
> distributions as of 2026, with just a few reminders: `netstat` belongs to the
> net-tools suite, unmaintained for years; newer distributions are advised to
> switch to iproute2's `ss` instead (e.g. `ss -lntup`); `echo password | passwd --stdin`
> only works on RHEL/CentOS systems; use `chpasswd` on Debian/Ubuntu; on systemd
> systems, `init 0` / `halt` are compatibility wrappers for `systemctl poweroff` /
> `systemctl reboot`.

## 1. File and Directory Operations

```shell
mkdir /data                 # create a directory
mkdir -p /xx/xxx            # create nested directories recursively (no error if parents are missing)
ls -ld /data                # show the directory's own attributes (not its contents)
cd /                        # change directory
touch hequan.txt            # create an empty file (or update an existing file's timestamp)
vi hequan.txt               # edit a file (same for vim)
cat hequan.txt              # view file contents
echo "hequan" >> hequan.txt # append a line
cat >> xx << EOF            # append multiple lines interactively via here-doc; end with EOF
cp -a hequan.txt /tmp       # copy while preserving permissions/owner/timestamps
mv /data /root              # move or rename
rm -f xx                    # force-delete a file (no prompt)
rmdir /data                 # remove an empty directory
rm -rf /data                # recursive force-delete (dangerous, use with care!)
tree xx                     # show a directory tree (requires yum install tree)
```

## 2. Text Viewing and Processing

```shell
head -2 xxx                 # show the first 2 lines
tail -2 xxx                 # show the last 2 lines
head -30 xxx | tail -10     # extract lines 21-30
grep -v keyword xxx         # invert match (hide matching lines)
grep -E "consecutive string" xxx  # use extended regex
grep -i keyword xxx         # case-insensitive match
sed -n '/he/p' xxx          # print lines containing he
sed '/hequan/d' xxx         # delete lines containing hequan (output only, file unchanged)
sed -n '20,30p' xxx         # print lines 20-30
sed -i 's#hequan#quanhe#g' he         # replace throughout the file and write in place
awk '/[^hequan]/' xxx                 # filter lines with a regex
awk '{if(NR>19&&NR<31) print $0}' xxx # print lines 20-30
awk -F ":" '{print $1}' /etc/passwd   # split on colon, print field 1 (all usernames)
tac xxx                     # print the file in reverse (cat reversed)
seq 100                     # generate the sequence 1-100
seq -s " " 5                # generate "1 2 3 4 5" (-s sets the separator)
diff a b                    # compare two files
vimdiff a b                 # compare visually with vim
```

## 3. Searching and Batch Processing

```shell
find / -type f -name "cat" -exec ls -l {} \;   # find files and run ls -l on each result
find / -type f -mtime +5                        # find files modified more than 5 days ago
find / -type f -name he | xargs cat             # find, then view contents in batch
find / -type f -name he | xargs sed -i 's#hequan#quanhe#g'   # find, then replace contents in batch
echo {a..z}                                     # brace expansion prints a-z
echo {1..6}                                     # brace expansion prints 1-6
```

## 4. Help and Aliases

```shell
man mkdir                   # view the full manual of a command
mkdir --help                # view brief help
which cp                    # show the actual path of a command
alias 1=xx                  # set a temporary alias
unalias 1                   # remove an alias
cat ~/.bashrc               # permanent aliases usually live in this file
\cp /tmp/xx /xxx            # a leading backslash bypasses the alias and runs the original command
```

## 5. Users and Permissions

```shell
echo 123456 | passwd --stdin hequan   # change password non-interactively (RHEL/CentOS only)
history                               # view command history
history -c                            # clear the current session's history
whoami                                # show the current username
su - root                             # switch to root (- loads its environment variables)
sudo su -                             # elevate a normal user to root
visudo                                # safely edit the sudo authorization file
```

Example `visudo` authorization:

```shell
hequan  ALL=(ALL)       /usr/sbin/useradd    # allow hequan to run only useradd
hequan  ALL=(ALL)       NOPASSWD:ALL         # run all commands without a password (use with care)
```

Once authorized, you can run:

```shell
sudo useradd xx   # add a user with root privileges
```

> Note: `passwd --stdin` does not exist on Debian/Ubuntu; the equivalent is
> `echo 'hequan:123456' | chpasswd`.

## 6. Environment Variables

```shell
vi /etc/profile                            # global environment variable config file
echo 'PATH=/hequan:$PATH' >> /etc/profile  # append a custom PATH
source /etc/profile                        # apply the change immediately (no re-login needed)
```

## 7. Network Status

```shell
netstat -an                # view all connections and listeners
netstat -lntup             # view listening ports and their processes
netstat -lntup | grep ssh  # filter ssh-related ports
lsof -i:22                 # see which process occupies port 22
```

> Note: net-tools is no longer maintained; on newer systems, use `ss -lntup` instead of
> netstat, with faster output and consistent information.

## 8. Shutdown and Reboot

```shell
halt              # halt (equals systemctl halt on systemd systems)
init 0            # power off (runlevel 0)
reboot            # reboot
shutdown -r now   # reboot immediately
shutdown -h now   # power off immediately
```
