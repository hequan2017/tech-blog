> **About this post**
>
> Following the compile options from typecodes, this post installs PHP 7.1.1 from source on CentOS: from installing dependencies and the configure options (enabling FPM, OPcache, mysqli/pdo_mysql, gd, mbstring, etc.) to copying php.ini, php-fpm.conf and www.conf, turning off expose_php/display_errors, enabling the error log and slow log, setting up the session directory, registering php-fpm as a system service, and verifying startup. A phpinfo() test snippet is included at the end.

> **Technical notes**
>
> PHP 7.1 reached end of security support in December 2019; for production, PHP 8.1+ is recommended (via the Remi repository or distribution sources). The `--with-mysql` option was removed in PHP 7 (only mysqli/pdo_mysql remain), and `--with-mcrypt` was removed as of PHP 7.2; remove these two parameters if reproducing the steps on a modern system.

---

The following is a walkthrough done with reference to https://typecodes.com/, and the connection test with the nginx set up earlier went without problems. When connecting to MySQL, pay attention to the `--with-mysql-sock=/var/run/mysql/mysql.sock` parameter — it must be the same as the setting inside MySQL.

```bash
yum -y install libxml2 libxml2-devel openssl openssl-devel curl-devel libjpeg-devel libpng-devel freetype-devel libmcrypt-devel
groupadd -r php && useradd -r -g php -s /bin/false -d /usr/local/php7 -M php

cd /usr/local/src
wget http://au1.php.net/distributions/php-7.1.1.tar.gz
```

```bash
tar zxvf php-7.1.1.tar.gz
cd php-7.1.1
./configure \
--prefix=/usr/local/php7 \
--exec-prefix=/usr/local/php7 \
--bindir=/usr/local/php7/bin \
--sbindir=/usr/local/php7/sbin \
--includedir=/usr/local/php7/include \
--libdir=/usr/local/php7/lib/php \
--mandir=/usr/local/php7/php/man \
--with-config-file-path=/usr/local/php7/etc \
--with-mysql-sock=/var/run/mysql/mysql.sock \
--with-mcrypt=/usr/include \
--with-mhash \
--with-openssl \
--with-mysql=shared,mysqlnd \
--with-mysqli=shared,mysqlnd \
--with-pdo-mysql=shared,mysqlnd \
--with-gd \
--with-iconv \
--with-zlib \
--enable-zip \
--enable-inline-optimization \
--disable-debug \
--disable-rpath \
--enable-shared \
--enable-xml \
--enable-bcmath \
--enable-shmop \
--enable-sysvsem \
--enable-mbregex \
--enable-mbstring \
--enable-ftp \
--enable-gd-native-ttf \
--enable-pcntl \
--enable-sockets \
--with-xmlrpc \
--enable-soap \
--without-pear \
--with-gettext \
--enable-session \
--with-curl \
--with-jpeg-dir \
--with-freetype-dir \
--enable-opcache \
--enable-fpm \
--enable-fastcgi \
--with-fpm-user=nginx \
--with-fpm-group=nginx \
--without-gdbm \
--disable-fileinfo
make && make install
make test    ## not required
ll /usr/local/php7/lib/php/extensions/no-debug-non-zts-20160303/
```

Use the configuration files generated by the build as-is, without any optimization:

```bash
cp php.ini-production /usr/local/php7/etc/php.ini
cp sapi/fpm/init.d.php-fpm /etc/init.d/php-fpm
cp /usr/local/php7/etc/php-fpm.conf.default /usr/local/php7/etc/php-fpm.conf
cp /usr/local/php7/etc/php-fpm.d/www.conf.default /usr/local/php7/etc/php-fpm.d/www.conf
```

Edit the configuration file `vim /usr/local/php7/etc/php.ini`:

```ini
###### Prevent PHP version info from being exposed in HTTP headers
expose_php = Off
###### Avoid exposing error messages from PHP calling MySQL
display_errors = Off

###### Enable the PHP error log after turning off display_errors (the path is configured in php-fpm.conf)
log_errors = On

###### Set the PHP extension library path
extension_dir = "/usr/local/php7/lib/php/extensions/no-debug-non-zts-20160303/"

###### Set the opcache and MySQL dynamic libraries for PHP
zend_extension=opcache.so
extension=mysqli.so
extension=pdo_mysql.so

###### Set the PHP timezone
date.timezone = PRC

###### Enable opcache
[opcache]
opcache.enable=1
###### Set the directories PHP scripts are allowed to access (configure according to your actual needs)
open_basedir = /etc/nginx/html;
```

`vim /usr/local/php7/etc/php-fpm.conf`:

```ini
###### Set the error log path
error_log = /var/log/php-fpm/error.log
###### Include the configuration from the www.conf file
include=/usr/local/php7/etc/php-fpm.d/*.conf
```

`vim /usr/local/php7/etc/php-fpm.d/www.conf`:

```ini
###### Set the user and group
user = nginx
group = nginx
###### Set the PHP listen directive according to fastcgi_pass unix:/var/run/php-fpm/php-fpm.sock; in nginx.conf
; listen = 127.0.0.1:9000  ##### not recommended (depends on your own setup)
listen = /var/run/php-fpm/php-fpm.sock
###### Enable the slow log
slowlog = /var/log/php-fpm/$pool-slow.log
request_slowlog_timeout = 10s
###### Set the PHP session directory (both owner and group are nginx)
php_value[session.save_handler] = files
php_value[session.save_path] = /var/lib/php/session
```

Set up the environment variables, create the directories, register the service, and start it:

```bash
echo -e '\nexport PATH=/usr/local/php7/bin:/usr/local/php7/sbin:$PATH\n' >> /etc/profile && source /etc/profile

mkdir -p /var/log/php-fpm/ && mkdir -p /var/run/php-fpm && cd /var/run/ && chown -R nginx:nginx php-fpm
mkdir -p /var/lib/php/session

chown -R nginx:nginx /var/lib/php
chmod +x /etc/init.d/php-fpm
chkconfig --add php-fpm
chkconfig php-fpm on
php-fpm -t
service php-fpm start
```
