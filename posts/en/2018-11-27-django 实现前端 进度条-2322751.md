> **About this post**
>
> This post demonstrates how to implement a real-time refreshing front-end progress bar over WebSocket with Django Channels 2.1.5 + Redis channel layer: the backend AsyncWebsocketConsumer creates a group named after the username, and after receiving the task id list sent from the front end, it queries the progress_bar field in the database and pushes the result back to the front end via group_send; the front end sends once per second on a timer and updates the progress percentage of the corresponding table row in onmessage. The post includes the complete settings/asgi/consumers/routing configurations and the front-end WebSocket code.

> **Technical notes**
>
> The channels==2.1.5 and channels-redis==2.3.1 versions used here are quite old. In Channels 3.x/4.x, get_default_application has been removed (instantiate ProtocolTypeRouter directly in asgi.py), and for the routing it is recommended to wrap consumer.as_asgi() with re_path instead. Also, parsing front-end data with eval(text_data) is a serious security risk; in real use, replace it with json.loads.

consumers.py:

```python
from asgiref.sync import async_to_sync
from channels.generic.websocket import WebsocketConsumer, AsyncWebsocketConsumer
from channels.layers import get_channel_layer
import time
channel_layer = get_channel_layer()
from apply.models import UpCodeInfo
import json

class ExecConsumer(AsyncWebsocketConsumer):
    async def connect(self):
        print('ws连接')
        # Create a channels group named after the username, and write it to redis via channel_layer
        await self.channel_layer.group_add(self.scope['user'].username, self.channel_name)

        # Hand over to the receive method for processing
        await self.accept()

    async def receive(self, text_data):
        if len(text_data) == 1:
            id_list = [text_data]
        else:
            id_list = eval(text_data)
        data = {}

        for i in id_list:
            data[i] = UpCodeInfo.objects.get(id=int(i)).progress_bar
        await self.channel_layer.group_send(
            self.scope['user'].username,
            {
                "type": "user.message",
                "text": json.dumps(data),
            },
        )

    async def user_message(self, event):
        # Consume
        await self.send(text_data=event["text"])

    async def disconnect(self, close_code):
        print("关闭ws", close_code)
        await self.channel_layer.group_discard(self.scope['user'].username, self.channel_name)
```

routing.py:

```python
from channels.auth import AuthMiddlewareStack
from channels.routing import URLRouter, ProtocolTypeRouter
from django.urls import path

from .consumers import ExecConsumer

application = ProtocolTypeRouter({
    "websocket": AuthMiddlewareStack(
        URLRouter([
            path(r"progress/", ExecConsumer),
        ])
    )
})
```
