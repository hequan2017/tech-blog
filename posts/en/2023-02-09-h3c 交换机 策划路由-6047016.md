> **About this post**
>
> This post is a configuration note on H3C switch policy-based routing (PBR):
> applying a policy named aaa on Vlan-interface2, using advanced ACL 3000 to
> match traffic from a specified source subnet, and forcing matched traffic's
> next hop to 192.168.1.1, so that traffic is forwarded according to policy.
>
> **Technical notes**
>
> The commands above are in H3C Comware style: `ip address ... sub` denotes a
> secondary address (Cisco uses `secondary`); ACL 3000 is an advanced ACL;
> policy-based routing is invoked on the interface with `ip policy-based-route`,
> and traffic matching `if-match acl` is forwarded according to `apply next-hop`
> (the Cisco equivalent is `route-map` + `ip policy route-map`).

---

```shell
interface Vlan-interface2
ip address x.x.x.x 255.255.255.0
ip address 192.168.1.2 255.255.255.252 sub
ip policy-based-route aaa
#

acl number 3000
rule 0 permit ip source x.x.x.x 0.0.0.255
#

policy-based-route aaa permit node 2
if-match acl 3000
apply next-hop 192.168.1.1
#
```
