> **About this post**
>
> This article configures a multi-NIC CentOS 7 server as a "network relay": the
> external interface enp1s0 performs MASQUERADE so that traffic can be forwarded
> to the Internet, while the three internal interfaces enp2s0, eno1, and enp4s0
> serve the 192.168.2/3/4 subnets respectively, with addresses handed out
> automatically by dhcpd. The article first walks through the manual step-by-step
> configuration, then provides a one-shot automation script.

> **Technical notes**
>
> - CentOS 7 reached end of life (EOL) on June 30, 2024; migrating to Rocky
>   Linux 9 / AlmaLinux 9, or China's openEuler, is recommended.
> - CentOS 7 enables firewalld by default, which interferes with the bare
>   iptables rules used in this article. Run `systemctl disable --now firewalld`
>   before applying them.
> - Forwarding depends on the kernel parameter `net.ipv4.ip_forward=1`. Since
>   RHEL 8/9, the firewalld backend has switched to nftables, and both
>   `iptables-services` persistence and the `network` scripts are gradually
>   being replaced by NetworkManager/nmcli; rework those parts when migrating.
> - The 8.8.8.8 / 8.8.4.4 addresses in the configuration are Google public DNS;
>   replace them as needed with something closer to your environment, such as
>   223.5.5.5.

## 1. Preparation: Identify the Internal and External NICs

Make sure your computer is connected to the Internet. Based on the information
provided, your computer is already connected to the Internet through the
`enp1s0` interface, with the IP address 192.168.1.226.

Choose an unused network interface to connect other devices. You can pick any
of `enp2s0`, `eno1`, or `enp4s0`, since all of them show a status of DOWN.

## 2. Install iptables and Enable Kernel Forwarding

Install the iptables tools in a terminal (if not already installed):

```shell
sudo yum install iptables
```

Enable IPv4 forwarding. Run the following command to enable it for the current
session:

```shell
sudo sysctl -w net.ipv4.ip_forward=1
```

To make it persist across reboots, edit the `/etc/sysctl.conf` file and
uncomment the following line (if present), or add it (if missing):

```text
net.ipv4.ip_forward = 1
```

## 3. Configure and Save the iptables Forwarding Rules

Configure iptables rules to forward packets. Assuming you chose `enp2s0` as
the LAN interface, run the following commands:

```shell
sudo iptables -t nat -A POSTROUTING -o enp1s0 -j MASQUERADE
sudo iptables -A FORWARD -i enp1s0 -o enp2s0 -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A FORWARD -i enp2s0 -o enp1s0 -j ACCEPT
```

Save the iptables rules so that they survive a reboot:

```shell
sudo yum install iptables-services
sudo systemctl enable iptables
sudo iptables-save > /etc/sysconfig/iptables
```

## 4. Install and Configure the DHCP Server

First, install the DHCP server software:

```shell
sudo yum install dhcp
```

Back up the original DHCP configuration file, then create a new one:

```shell
sudo cp /etc/dhcp/dhcpd.conf /etc/dhcp/dhcpd.conf.bak
sudo vim /etc/dhcp/dhcpd.conf
```

In the new configuration file, add the following:

```text
subnet 192.168.2.0 netmask 255.255.255.0 {
    range 192.168.2.10 192.168.2.250;
    option domain-name-servers 8.8.8.8, 8.8.4.4;
    option routers 192.168.2.1;
    option broadcast-address 192.168.2.255;
    default-lease-time 600;
    max-lease-time 7200;
}
```

## 5. Static IPs for the Internal NICs and Starting the Services

Assign a static IP address to the LAN interface (assume `enp2s0`). Edit the
`/etc/sysconfig/network-scripts/ifcfg-enp2s0` file and add the following:

```ini
DEVICE=enp2s0
TYPE=Ethernet
ONBOOT=yes
NM_CONTROLLED=no
BOOTPROTO=static
IPADDR=192.168.2.1
NETMASK=255.255.255.0
```

Here, we set the IP address of the `enp2s0` interface to 192.168.2.1.

Restart the network service to apply the changes:

```shell
sudo systemctl restart network
```

Start and enable the DHCP server service:

```shell
sudo systemctl start dhcpd
sudo systemctl enable dhcpd
```

Now, when other devices connect to the LAN interface you chose (`enp2s0` in
this example), they should be able to obtain an IP address automatically from
the DHCP server and access the Internet through your computer.

## 6. One-Shot Automation Script

The following script bundles the steps above, covering all three internal NICs
`enp2s0`, `eno1`, and `enp4s0` (corresponding to the 192.168.2/3/4 subnets) in
one pass, and also opens port 8909:

```shell
#!/bin/bash

# Install the required packages
sudo yum install iptables dhcp iptables-services -y

# Enable IPv4 forwarding
sudo sysctl -w net.ipv4.ip_forward=1
echo "net.ipv4.ip_forward = 1" | sudo tee -a /etc/sysctl.conf

# Configure the iptables rules
sudo iptables -t nat -A POSTROUTING -o enp1s0 -j MASQUERADE
sudo iptables -A FORWARD -i enp1s0 -o enp2s0 -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A FORWARD -i enp1s0 -o eno1 -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A FORWARD -i enp1s0 -o enp4s0 -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A FORWARD -i enp2s0 -o enp1s0 -j ACCEPT
sudo iptables -A FORWARD -i eno1 -o enp1s0 -j ACCEPT
sudo iptables -A FORWARD -i enp4s0 -o enp1s0 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 8909 -j ACCEPT

# Save the iptables rules
sudo systemctl enable iptables
sudo iptables-save > /etc/sysconfig/iptables

# Configure the network interfaces
cat > /tmp/enp2s0_config << EOF
DEVICE=enp2s0
TYPE=Ethernet
ONBOOT=yes
NM_CONTROLLED=no
BOOTPROTO=static
IPADDR=192.168.2.1
NETMASK=255.255.255.0
EOF

cat > /tmp/eno1_config << EOF
DEVICE=eno1
TYPE=Ethernet
ONBOOT=yes
NM_CONTROLLED=no
BOOTPROTO=static
IPADDR=192.168.3.1
NETMASK=255.255.255.0
EOF

cat > /tmp/enp4s0_config << EOF
DEVICE=enp4s0
TYPE=Ethernet
ONBOOT=yes
NM_CONTROLLED=no
BOOTPROTO=static
IPADDR=192.168.4.1
NETMASK=255.255.255.0
EOF

sudo mv /tmp/enp2s0_config /etc/sysconfig/network-scripts/ifcfg-enp2s0
sudo mv /tmp/eno1_config /etc/sysconfig/network-scripts/ifcfg-eno1
sudo mv /tmp/enp4s0_config /etc/sysconfig/network-scripts/ifcfg-enp4s0

# Configure the DHCP server
sudo cp /etc/dhcp/dhcpd.conf /etc/dhcp/dhcpd.conf.bak
cat > /tmp/dhcpd.conf << EOF
subnet 192.168.2.0 netmask 255.255.255.0 {
    range 192.168.2.10 192.168.2.250;
    option domain-name-servers 8.8.8.8, 8.8.4.4;
    option routers 192.168.2.1;
    option broadcast-address 192.168.2.255;
    default-lease-time 600;
    max-lease-time 7200;
}

subnet 192.168.3.0 netmask 255.255.255.0 {
    range 192.168.3.10 192.168.3.250;
    option domain-name-servers 8.8.8.8, 8.8.4.4;
    option routers 192.168.3.1;
    option broadcast-address 192.168.3.255;
    default-lease-time 600;
    max-lease-time 7200;
}

subnet 192.168.4.0 netmask 255.255.255.0 {
    range 192.168.4.10 192.168.4.250;
    option domain-name-servers 8.8.8.8, 8.8.4.4;
    option routers 192.168.4.1;
    option broadcast-address 192.168.4.255;
    default-lease-time 600;
    max-lease-time 7200;
}
EOF

sudo mv /tmp/dhcpd.conf /etc/dhcp/dhcpd.conf

sudo systemctl restart network

sudo systemctl start dhcpd
sudo systemctl enable dhcpd
```
