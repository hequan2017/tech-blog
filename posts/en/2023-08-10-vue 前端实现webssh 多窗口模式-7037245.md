> **About this post**
>
> This post presents the core code for implementing a multi-window webssh mode
> in a Vue frontend: each time a server is connected, a new xterm.js terminal
> instance is created, with AttachAddon binding the WebSocket for sending and
> receiving data and FitAddon adapting the size; connection records (server,
> terminal, socket) are stored in an array and switched via tabs, and the
> terminal containers are saved keyed by server, then mounted into the
> xtermContainer element when displayed.

> **Technical notes**
>
> Terminal/AttachAddon/FitAddon in this post are official xterm.js packages;
> since xterm.js 5.x they have been renamed to @xterm/xterm,
> @xterm/addon-attach, and @xterm/addon-fit. The example puts the SSH password
> in plaintext in the WebSocket URL query string; in production, prefer a
> one-time token and enable wss instead. The code uses the Vue Options API;
> Vue 2 reached end of life (EOL) on 2023-12-31.

## 1. Core Code for the Multi-window Mode

When clicking to connect to a server, create a new terminal instance and WebSocket connection, and mount the terminal container onto the page:

```vue
<template>
  <!-- Other template code omitted -->

  <div class="main-content">
    <!-- ... -->

    <div ref="xtermContainer" style="width: calc(100% - 40px); height: 600px; padding: 20px"></div>
  </div>

  <!-- ... -->
</template>

<script>
// ... other import statements ...

export default {
  // ... other options ...

  data() {
    return {
      // ... other data ...

      // Map each connected server's terminal container to the server's key
      terminalContainers: {}
    }
  },

  methods: {
    // ... other methods ...

    connectToServer() {
      const socketURI =
        `ws://127.0.0.1:8000/api/admin/user/ssh/webssh?ip=${this.selectedServer.private_ip}&port=${this.selectedServer.ssh_port}&username=${this.selectedServer.username}&password=${this.selectedServer.password}&authmodel=${this.selectedConnectionType}`;

      // Create a new terminal instance and WebSocket connection
      const term = new Terminal();
      const socket = new WebSocket(socketURI);
      const attachAddon = new AttachAddon(socket);
      const fitAddon = new FitAddon();
      term.loadAddon(attachAddon);
      term.loadAddon(fitAddon);

      // Create a new DOM element to host the terminal
      const terminalContainer = document.createElement('div');
      term.open(terminalContainer);
      fitAddon.fit();
      term.focus();

      // Save the connected server and its terminal instance into the array
      const connectedServer = {
        server: this.selectedServer,
        term: term,
        socket: socket
      };
      this.connectedServers.push(connectedServer);
      this.activeTab = connectedServer;

      // Associate the terminal container with the server's key
      this.terminalContainers[this.selectedServer.private_ip] = terminalContainer;

      // Clear the previous terminal container
      this.$refs.xtermContainer.innerHTML = '';
      // Append the current server's terminal container to the page
      this.$refs.xtermContainer.appendChild(terminalContainer);

      // Close the connection options dialog
      this.connectionOptionsDialog = false;
    },

    // ... other methods ...
  }
}
</script>
```
