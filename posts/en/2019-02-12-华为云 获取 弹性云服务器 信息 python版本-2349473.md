> **About this post**
>
> Uses the Python version of the Huawei Cloud SDK (huaweicloud-sdk-python, based on the OpenStack SDK) to connect to the IAM authentication endpoint and list Elastic Cloud Server (ECS) information. The post explains the meaning of parameters required by `Connection`, such as `username`, `projectId`, and `userDomainId`, along with a `list_servers` example.
>
> **Technical notes**
>
> The original huaweicloud-sdk-python (OpenStack style) has been marked as a legacy version by the official team; new projects are advised to use the official `huaweicloudsdk-python` (`from huaweicloudsdkecs.v2 import ...`), whose API structure is completely different from the one shown here.

---

### Getting Elastic Cloud Server (ECS) Information on Huawei Cloud

#### Install the SDK

SDK repository: https://github.com/huaweicloud/huaweicloud-sdk-python

```shell
cd huaweicloud-sdk-python
pip install -r requirements.txt
python3 setup.py install
```

#### Code

```python
from openstack import connection

# create connection
username = "hequan"
password = "hequan"
projectId = "xxxxxxxxxxxxxxxxxxxxxxxxx"  # tenant ID
userDomainId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"  # user account ID
auth_url = "https://iam.cn-north-1.myhuaweicloud.com"  # endpoint url https://ecs.cn-north-1.myhuaweicloud.com
conn = connection.Connection(auth_url=auth_url,
                             user_domain_id=userDomainId,
                             project_id=projectId,
                             username=username,
                             password=password)

# get list of server
def list_servers():
    servers = conn.compute.servers(limit=1)
    for server in servers:
        print(server)

if __name__ == "__main__":
    list_servers()
```
