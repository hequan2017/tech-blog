> **About this post**
>
> A minimal example of rendering a piece of text into an image with Python 3 and
> Pillow (a fork of PIL): install pillow, place the Microsoft YaHei font
> msyh.ttf under the fonts directory, then use Image.new to create a white
> canvas, ImageFont.truetype to load the font, and ImageDraw.Draw to draw a
> string containing variables onto it, and finally preview it with im.show()
> and save it as t.png.

> **Technical notes**
>
> Pillow remains the standard imaging library for Python and is still actively
> maintained. Note: Microsoft YaHei (msyh.ttf) is a commercial font; copying it
> onto a Linux server yourself carries copyright risk — consider open-source
> fonts such as Source Han Sans or WenQuanYi instead. In this example, the first
> argument to `ImageFont.truetype` is a path relative to the current working
> directory; switch to an absolute path if you run the script from another
> directory.

---

## 1. Installation and Font Preparation

Under python3, PIL is called pillow:

```bash
python -m pip install pillow
```

Create a directory named fonts and put the Microsoft YaHei font in it, i.e. `fonts/msyh.ttf`.

## 2. Code Example

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
import os
from PIL import Image, ImageFont, ImageDraw

l = [1, 23, 4]
text = u"这是一段测试文本，test 123。{}\n ".format(l[1])
im = Image.new("RGB", (300, 50), (255, 255, 255))
dr = ImageDraw.Draw(im)
font = ImageFont.truetype(os.path.join("fonts", "msyh.ttf"), 14)
dr.text((10, 5), text, font=font, fill="#000000")
im.show()
im.save("t.png")
```
