## 1. Introduction and Object Conversion

jQuery is a library for DOM/BOM/JavaScript (module <=> library); official site https://jquery.com .

Versions: 1.x (1.12), 2.x, 3.x.

Conversion between jQuery objects and DOM objects:

- `jqueryObj[0]` => DOM object
- `DOM object` => `$(DOM object)`

## 2. Finding Elements

DOM offers about 10 ways to find elements; jQuery uses selectors to find one tag or a group of tags directly:

```javascript
$('#id')        // 1. id
$(".c1")        // 2. class
$('a')          // 3. tag
$('a,.c2,#i10') // 4. combined
$('#i10 a')     // 5. hierarchy: descendants at any depth
$('#i10>a')     // 5. hierarchy: direct children
:first          // 6. basic
:last
:eq()
$('[alex]')          // 7. attribute: all tags that have the alex attribute
$('[alex="123"]')    // tags whose alex attribute equals 123
$("input[type='text']")  // equivalent to $(':text')
```

HTML structure example for the hierarchy selectors:

```html
<div id='i10' class='c1'>
    <a>f</a>
    <a>f</a>
</div>
<div class='c1'>
    <a>f</a>
</div>
```

input example for the attribute filtering:

```html
<input type='text'/>
<input type='text'/>
<input type='file'/>
<input type='password'/>
```

## 4. Filtering

```javascript
$('#i1').next()            // the next one
$('#i1').nextAll()         // all the ones below
$('#i1').nextUntil('#ii1') // until ii1 is found
$('#i1').prev()            // the previous one
$('#i1').prevAll()         // all the ones above
$('#i1').prevUntil('#ii1')
$('#i1').parent()          // parent tag
$('#i1').parents()         // ancestor tags
$('#i1').parentsUntil()    // where to stop
$('#i1').children()        // children
$('#i1').siblings()        // siblings
$('#i1').find()            // search among all descendants
```

HTML structure example for the filtering methods:

```html
<div>
    <a>asdf</a>
    <a>asdf</a>
    <a id='i1'>asdf</a>
    <a>asdf</a>
    <a id='ii1'>asdf</a>
    <a>asdf</a>
</div>
```

Others: `$('li:eq(1)')` is equivalent to `$('li').eq(1)`; `first()`, `last()`,
`hasClass(class)`; PS: `index` gets the index position.

## 5. Text, Style, and Attribute Operations

Text operations:

```javascript
$(..).text()               // get the text content
$(..).text("<a>1</a>")     // set the text content
$(..).html()
$(..).html("<a>1</a>")
$(..).val()                // set the value of input
$(..).val(..)
```

Style operations:

```javascript
addClass
removeClass
toggleClass    // toggle

$('#i1').click(function(){
    $('.c1').toggleClass('hide');
})
```

Attribute operations — `attr` is dedicated to custom attributes:

```javascript
$(..).attr('n')       // get the value
$(..).attr('n','v')   // the first argument is the attribute name, the second is the updated value
$(..).removeAttr('n') // remove
```

`prop` is dedicated to checkbox and radio:

```html
<input type='checkbox' id='i1'  />
```

```javascript
$(..).prop('checked')
$(..).prop('checked', true)
```

## 8. Events

DOM has three binding approaches; the jQuery way:

```javascript
$('.c1').click()
$('.c1').bind('click', function(){ })
$('.c1').unbind('click', function(){ })

// ******************* special
$('.c').delegate('a', 'click', function(){ })     // delegation
$('.c').undelegate('a', 'click', function(){ })

$('.c1').on('click', function(){ })
$('.c1').off('click', function(){ })
```

To stop an event from happening: `return false`.

Executed automatically once the page structure has finished loading:

```javascript
$(function(){
    $(...)
})
```

jQuery extensions:

- `$.extend`: defines `$.method`
- `$.fn.extend`: defines `$(..).method`

```javascript
(function(){
    var status = 1;
    // encapsulate the variable
})(jQuery)
```

### 4. Menu Switching

Match the target panel by attribute:

```javascript
$('.menu-item').click(function(){
    $(this).addClass('active').siblings().removeClass('active');
    var target = $(this).attr('a');
    $('.content').children("[b='"+ target+"']").removeClass('hide').siblings().addClass('hide');
});
```

Match the target panel by index:

```javascript
$('.menu-item').click(function(){
    $(this).addClass('active').siblings().removeClass('active');
    $('.content').children().eq($(this).index()).removeClass('hide').siblings().addClass('hide');
});
```

### 5. Login Validation

```javascript
$(function(){
    // executed after all page elements are fully loaded
    $(':submit').click(function () {
        $('.error').remove();
        var flag = true;
        $('#f1').find('input[type="text"],input[type="password"]').each(function () {
            var v = $(this).val();
            var n = $(this).attr('tex');
            if(v.length <= 0){
                flag = false;
                var tag = document.createElement('span');
                tag.className = "error";
                tag.innerHTML = n + " is required";
                $(this).after(tag);
                // return false;
            }
        });
        return flag;
    });
});
```
