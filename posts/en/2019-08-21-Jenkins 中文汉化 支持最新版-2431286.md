> **About this post**
>
> This is a short note in the Kubernetes cloud-native practice series, describing how to
> localize the Jenkins UI into Simplified Chinese: install the Localization: Chinese
> (Simplified) plugin from the plugin manager, then in the **Locale** section of the
> "System settings" page set Default Language to zh_CN and check the option to ignore
> browser preferences and force this language for all users. After saving, the UI switches
> to Simplified Chinese; a screenshot of the configuration location is included at the end.

> **Technical notes**
>
> - As of 2026, the Localization: Chinese (Simplified) plugin (plugin ID:
>   localization-zh-cn) is still actively maintained in the Jenkins plugin center and
>   remains the mainstream solution for Simplified Chinese localization; on newer Jenkins
>   versions the UI is usually localized right after installing the plugin, and manually
>   configuring the Locale as described in this post is generally no longer necessary.
> - Jenkins versions evolve quickly: since 2.357 Java 8 is no longer supported, and since
>   2.477 Java 17/21 is required. All of the 2019 versions mentioned here are no longer
>   maintained; it is recommended to use the latest LTS together with up-to-date plugins.

---

## 1. Install the localization plugin

Install the **Localization: Chinese (Simplified)** plugin.

## 2. Set the default language and save

In the **Locale** section of the "System settings" page, set Default Language to `zh_CN`
and check *Ignore browser preference and force this language to all users*
(ignore the browser's language preference and force this language for all users).
Finally, click "Save / Apply" in the lower-left corner for the change to take effect:
