> **About this post**
>
> This post records three key points of integrating vue-element-admin login with a backend:
> in utils/request.js, attach Authorization: Token to the request header and intercept
> non-200 responses uniformly; in vue.config.js, point the development proxy target to the
> local backend at 127.0.0.1:8000; and in the api layer, wrap the two endpoints /auth for
> login and /api/v1/userInfo.

> **Technical notes**
>
> vue-element-admin is based on Vue 2 + Element UI, and Vue 2 reached end of life (EOL)
> on 2023-12-31; the template has not been updated for years either, so new projects are
> advised to use an admin template from the Vue 3 ecosystem. The development proxy
> corresponds to server.proxy in Vite projects, which works the same way as devServer.proxy
> in vue-cli. The `Token ` prefix in the request header is the auth format of Django REST
> framework's TokenAuthentication; JWT is more common today, and for local login debugging
> the frontend now typically uses mock solutions such as MSW or vite-plugin-mock.

---

## 1. utils/request.js

In the request interceptor, attach the Token to the request header; in the response handling, intercept any case where the code is not 200:

```javascript
config.headers['Authorization'] = 'Token ' + getToken()

if (res.code !== 200) {
```

## 2. vue.config.js

Point the development proxy to the local backend:

```javascript
target: 'http://127.0.0.1:8000'
```

## 3. api

Wrap the two endpoints for login and fetching user info:

```javascript
import request from '@/utils/request'

export function login(data) {
  return request({
    url: '/auth',
    method: 'post',
    data
  })
}

export function getInfo(token) {
  return request({
    url: '/api/v1/userInfo',
    method: 'get',
    params: { token }
  })
}
```
