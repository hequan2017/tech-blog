> **About this post**
>
> The first installment of my TypeScript study notes: setting up a TS development environment based on webpack 4 + ts-loader from scratch, covering the VS Code theme, npm init, global installation of typescript/tslint/ts-loader/cross-env, the directory structure (build/src/typings), and the complete configuration of the package.json scripts and webpack.config.js.
>
> **Technical notes**
>
> This post is based on webpack 4 and TypeScript 3.x. Since then, webpack has moved on to 5.x, the `clean-webpack-plugin` usage has changed from `new CleanWebpackPlugin()` to the named export `{ CleanWebpackPlugin }`, and tslint has been deprecated (ESLint is the officially recommended replacement). For new projects, consider faster options such as Vite or esbuild.

---

### Setting Up a Basic TypeScript Environment

#### Tools

VS Code

#### Steps

Install the One Dark Pro theme via a VS Code extension.

Initialize the project:

```shell
npm init
```

package.json:

```json
{
  "name": "client-side",
  "version": "1.0.0",
  "description": "source code of ts-learning",
  "main": "./src/index.ts",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "keywords": [
    "typescript",
    "source_code",
    "hequan"
  ],
  "author": "hequan <hequan2011@sina.com>",
  "license": "MIT"
}
```

Directory structure:

```text
build
    webpack.config.js
package.json
src
    api
    assets
            font
            img
    config
    tools
    utils
typings
```

Install dependencies and initialize the TS configuration:

```shell
npm install -g typescript tslint ts-loader cross-env
tsc --init

npm install webpack webpack-cli webpack-dev-server clean-webpack-plugin html-webpack-plugin -D
npm install typescript -S
```

Final package.json:

```json
{
  "name": "client-side",
  "version": "1.0.0",
  "description": "source code of ts-learning",
  "main": "./src/index.ts",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1",
    "start": "cross-env NODE_ENV=development webpack-dev-server --config ./build/webpack.config.js",
    "build": "cross-env NODE_ENV=production webpack --config ./build/webpack.config.js"
  },
  "keywords": [
    "typescript"
  ],
  "author": "hequan<hequan2011@sina.com>",
  "license": "MIT",
  "devDependencies": {
    "clean-webpack-plugin": "^2.0.0",
    "cross-env": "^5.2.0",
    "html-webpack-plugin": "^3.2.0",
    "ts-loader": "^5.3.3",
    "webpack": "^4.29.6",
    "webpack-cli": "^3.2.3",
    "webpack-dev-server": "^3.2.1"
  },
  "dependencies": {
    "typescript": "^3.3.3333"
  }
}
```

build/webpack.config.js:

```javascript
const HtmlWebpackPlugin = require('html-webpack-plugin')
const CleanWebpackPlugin = require('clean-webpack-plugin')

module.exports = {
    entry: "./src/index.ts",
    output: {
        filename: "main.js"
    },
    resolve: {
        extensions: ['.ts', '.tsx', '.js']
    },
    module: {
        rules: [{
            test: /\.tsx?$/,
            use: 'ts-loader',
            exclude: /node_modules/
        }]
    },
    devtool: process.env.NODE_ENV === 'production' ? false : 'inline-source-map',
    devServer: {
        contentBase: './dist',
        stats: 'errors-only',
        compress: false,
        host: 'localhost',
        port: 8089
    },
    plugins: [
        new CleanWebpackPlugin({
            cleanOnceBeforeBuildPatterns: ['./dist']
        }),
        new HtmlWebpackPlugin({
            template: './src/template/index.html'
        })
    ]
}
```
