> **About this post**
>
> This post presents a PPP dial-up line management script: it first pings 223.5.5.5 to probe whether the network is up; if it is, the default gateway is left untouched. When the network is down, it first switches the default route to the management port recorded in /root/iface.txt. If the management port is unavailable (the file is empty, or the network is still unreachable after the switch), it then iterates over each ppp dial-up interface, tries them one by one, and uses ip route replace default to switch the default gateway to a working line.

> **Technical notes**
>
> `ip route replace` can only replace an existing default route and fails if there is no default route at the moment. A later, optimized release changed the logic to first check whether a default route exists, and only then decide between replace and add. 223.5.5.5 is Alibaba Public DNS, used in this post as the connectivity probe address.

## 1. Full Script

```shell
#!/bin/bash

PppCheck() {
    ppp_interfaces=$(ip r | grep -o "\<ppp[0-9]\+\>" | awk -F'ppp' '{print $2}' | sort -n |uniq | awk 'BEGIN{ORS=" "}{print "ppp"$NF}')
    for iface in $ppp_interfaces; do
        if ping -I $iface -W 5 -c 2  223.5.5.5 >/dev/null 2>&1; then
            dial_ip=$(ip route show dev $iface  | awk '{print $1}')
            echo "Setting default gateway to $dial_ip (via $iface)"
            ip route replace default via $dial_ip dev $iface
            if ping -W 5 -c 2  223.5.5.5 >/dev/null 2>&1; then
                echo "网络正常 is ok,修改默认网关成功"
                return 0
            fi
        fi
    done
    echo "网络不通 is not ok,修改默认网关失败"
    return 1
}

if ping -W 5 -c 2  223.5.5.5 >/dev/null 2>&1; then
    echo "网络正常 is ok,不修改默认网关"
else
    echo "网络不通 is not ok,修改默认网关"
    mgmt_iface="$(cat /root/iface.txt 2>/dev/null)"
    if [ -n "$mgmt_iface" ]; then
        if ip link show "$mgmt_iface" | grep -q "state UP"; then
            mgmt_ip=$(ip route show dev "$mgmt_iface" | awk '/^default/{print $3}')
            echo "Setting default gateway to $mgmt_ip (via $mgmt_iface)"
            ip route replace default via "$mgmt_ip" dev "$mgmt_iface"
            if ping -W 5 -c 2  223.5.5.5 >/dev/null 2>&1; then
                echo "网络正常 is ok,修改默认网关成功"
            else
                PppCheck
            fi
        else
            echo "$mgmt_iface 接口未开启"
        fi
    else
        echo "/root/iface.txt文件为空"
        PppCheck
    fi
fi
```
