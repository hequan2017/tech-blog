> **About this post**
>
> An operations practice note explaining three steps for customizing CentOS: unpack
> squashfs.img with unsquashfs and modify the rootfs.img inside, then pack it back
> with mksquashfs; build a custom RPM package containing /usr/local/hequan with
> rpmbuild; finally, add a package group to comps.xml and rebuild the repodata with
> createrepo to obtain a customized installation source.
>
> **Technical notes**
>
> - Timeliness: CentOS 8 reached EOL at the end of 2021, and CentOS Linux 7 was
>   discontinued on 2024-06-30; today, similar customization can be based on Rocky
>   Linux, AlmaLinux, or CentOS Stream.
> - Tool status: the commands in this post are still useful for reference, but in
>   EL8+ yum has been superseded by dnf, createrepo has largely been replaced by
>   createrepo_c, and mkisofs is usually provided by genisoimage or xorriso.

## 1. Modifying rootfs.img

```shell
1. Install the tools
[root@localhost ~]# yum install -y squashfs-tools

2. Use the unsquashfs command to unpack squashfs.img directly
[root@localhost ~]# unsquashfs squashfs.img

3. Mount the file system
[root@localhost ~]# cd squashfs-root/LiveOS/
[root@localhost LiveOS]# mount rootfs.img /mnt/rootfs/
[root@localhost LiveOS]# ls /mnt/rootfs/
bin  boot  dev  etc  firmware  lib  lib64  lost+found  mnt  modules  proc  root  run  sbin  sys  tmp  usr  var

4. Modify the files under the /mnt/rootfs directory as needed

5. Pack it again after the modifications
[root@localhost ~]# mksquashfs squashfs-root/ squashfs.img -comp xz -Xbcj x86 -e boot
```

## 2. Creating an RPM package

```shell
rpmdev-setuptree
mkdir -p BUILDROOT/hequan-1.0-1.1.x86_64

[root@test SPECS]# cat temp.spec
Name: hequan
Version: 1.0
Release: 1.1
Summary: This is a hedata package

Group: he
License: Special Proprietary
BuildArch: x86_64
# BuildArch: noarch

%description
%prep
%build
%pre
%post
%preun
%postun
%files
/usr/local/hequan/
%changelog

mkdir -p /root/rpmbuild/BUILDROOT/hequan-1.0-1.1.x86_64

cp -r --parents /usr/local/hequan/*  BUILDROOT/hequan-1.0-1.1.x86_64/
cd SPECS/
rpmbuild -bb temp.spec
```

## 3. Modifying createrepo

```shell
yum -y install createrepo mkisofs isomd5sum rsync

mkdir /ISO

/usr/bin/rsync -a  /media/ /ISO/

Upload the packages to Packages

cp /media/repodata/*-comps.xml  /ISO/repodata/comps.xml

vim comps.xml
```

Add the following to comps.xml:

```xml
<group>
<id>he</id>
<name>he</name>
<default>true</default>
<uservisible>true</uservisible>
<packagelist>
  <packagereq type="default">hequan</packagereq>
</packagelist>
</group>

<grouplist>
      <groupid>core</groupid>
      <groupid>core</groupid>
      <groupid>he</groupid>
</grouplist>
```

Finally, regenerate the repository metadata:

```shell
cd iso/
createrepo -g repodata/comps.xml ./
```
