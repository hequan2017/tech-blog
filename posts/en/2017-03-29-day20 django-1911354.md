> **About this post**
>
> These are notes from day 20 of a Django course: a point-by-point review with classmates of the request lifecycle, routing, FBV/CBV, the template language (traversing keys/values/items), and ORM CRUD (values/values_list/first, foreign-key cross-table queries). It then walks through a foreign-key table example, Ajax submission ($.ajax returning JSON, plus the convention that the server always returns a dict), two ways to build many-to-many tables (a custom relation table vs. one auto-created by ManyToManyField) with the add/remove/clear/set operations, and closes with the complete jQuery front-end code for a modal dialog that adds and edits hosts.

> **Technical notes**
>
> This post is based on Django 1.10 (2017): `models.IntergerFiled()` was a typo in the original and has been corrected to `IntegerField()`; misspellings such as "reqeust" and "clink", as well as a mistyped "view function", have been fixed too; template variables {{ }} swallowed by the editor have been restored; in the query comparison, the second v2, which was chained to values_list, has been corrected to v3. Django 2.0+ switches routing to path()/re_path(); comparison operators such as `{% if age > 16 %}` have been available since Django 1.2.

```python

/detail/  name='a1'      ->  include("app01.urls")
```

## 7. Ajax Submission (Zhang Yang)

Key points: position: fixed, absolute, relative.

```html
<a id="ajax_submit">Submit</a>
```

```javascript
$('#ajax_submit').click(function(){      // typo in the original (clink); corrected
    $.ajax({
        url: '/host',
        type: "POST",
        data: {'k1': 123, 'k2': "root"},   // e.g. 'hostname': $('#host').val()
        success: function(data){
            // data is the string returned by the server: data = {'status': false, 'data': null, "error": ...}
            var obj = JSON.parse(data);
            if(obj.status){
                location.reload();
            } else {
                $('error_msg').text(obj.error);
            }
        }
    })
})
```

Server side:

```python
def test_ajax(request):
    ret = {'status': True, 'error': None, 'data': None}
    try:
        h = request.POST.get('hostname')
        i = request.POST.get('ip')
        p = request.POST.get('port')
        b = request.POST.get('b_id')
        if h and len(h) > 5:
            models.Host.objects.create(hostname=h, ip=i, port=p, b_id=b)
        else:
            ret['status'] = False
            ret['error'] = "too short"
    except Exception as e:
        ret['status'] = False
        ret['error'] = 'request error'
    return HttpResponse(json.dumps(ret))
```

Suggestion: always have the server side return a dict — `return HttpResponse(json.dumps(dict))`.

## 8. Many-to-Many

Creating a many-to-many relation:

Approach 1: a custom relation table

```python
class Host(models.Model):
    nid = models.AutoField(primary_key=True)
    hostname = models.CharField(max_length=32, db_index=True)
    ip = models.GenericIPAddressField(protocol="ipv4", db_index=True)
    port = models.IntegerField()
    b = models.ForeignKey(to="Business", to_field='id')
    # 10

class Application(models.Model):
    name = models.CharField(max_length=32)
    # 2

class HostToApp(models.Model):
    hobj = models.ForeignKey(to='Host', to_field='nid')
    aobj = models.ForeignKey(to='Application', to_field='id')

# HostToApp.objects.create(hobj_id=1, aobj_id=2)
```

Approach 2: the relation table is created automatically

```python
class Host(models.Model):
    nid = models.AutoField(primary_key=True)
    hostname = models.CharField(max_length=32, db_index=True)
    ip = models.GenericIPAddressField(protocol="ipv4", db_index=True)
    port = models.IntegerField()
    b = models.ForeignKey(to="Business", to_field='id')
    # 10

class Application(models.Model):
    name = models.CharField(max_length=32)
    r = models.ManyToManyField("Host")
```

You cannot operate on the third table directly:

```python
obj = Application.objects.get(id=1)
obj.name

# Operations on the third table
obj.r.add(1)                # 1 === 1
obj.r.add(2)
obj.r.add(2, 3, 4)
obj.r.add(*[1, 2, 3, 4])
obj.r.remove(1)
obj.r.remove(2, 4)
obj.r.remove(*[1, 2, 3])
obj.r.clear()
obj.r.set([3, 5, 7])

# A QuerySet "list" of all related host objects
obj.r.all()
```
