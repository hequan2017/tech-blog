> **About this post**
>
> A set of ready-to-use baseline iptables rules for servers: flush the chains first, then allow SSH (22), HTTP (80), outbound yum/DNS (53), ICMP and the lo loopback as needed, REJECT everything else, and finally set the default INPUT/FORWARD/OUTPUT policies to DROP. Works well as a minimally open firewall template.

> **Technical notes**
>
> The iptables commands still work today, but RHEL 8+/Debian 10+ have switched to the nftables backend by default (iptables is merely a compatibility layer). If you plan to maintain this long term, consider learning nftables directly or using firewalld. CentOS 6/7 have also reached end of life; please migrate to newer distributions such as Rocky Linux/AlmaLinux.

---

```bash
# Basic iptables configuration for a server

# 1. Delete existing rules
iptables -F

# 2. Allow remote hosts to make SSH connections
iptables -A INPUT -i eth0 -p tcp --dport 22 -m state --state NEW,ESTABLISHED -j ACCEPT
iptables -A OUTPUT -o eth0 -p tcp --sport 22 -m state --state ESTABLISHED -j ACCEPT

# 3. Allow the local host to make SSH connections
iptables -A OUTPUT -o eth0 -p tcp --dport 22 -m state --state NEW,ESTABLISHED -j ACCEPT
iptables -A INPUT -i eth0 -p tcp --sport 22 -m state --state ESTABLISHED -j ACCEPT

# 4. Allow HTTP requests
iptables -A INPUT -i eth0 -p tcp --dport 80 -m state --state NEW,ESTABLISHED -j ACCEPT
iptables -A OUTPUT -o eth0 -p tcp --sport 80 -m state --state ESTABLISHED -j ACCEPT

# 5. Allow yum
# Only replies to packets this machine sent out may get in; ESTABLISHED: an established connection state. RELATED: the packet is related to a connection initiated by this machine.
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
iptables -A OUTPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
iptables -A OUTPUT -p tcp -m tcp -m state --state NEW --dport 80 -j ACCEPT

# 6. Allow DNS
iptables -A INPUT -p udp -m udp --sport 53 -j ACCEPT
iptables -A OUTPUT -p udp -m udp --dport 53 -j ACCEPT

# 7. System defaults: allow ICMP and local lo access
iptables  -A INPUT -p icmp -j ACCEPT
iptables  -A INPUT -i lo -j ACCEPT
# In the INPUT and FORWARD chains, reject all other packets that match none of the rules above, and send a host-prohibited message back to the rejected host.
iptables  -A INPUT -j REJECT --reject-with icmp-host-prohibited
iptables  -A FORWARD -j REJECT --reject-with icmp-host-prohibited

# 8. Configure default chain policies (do this last)
iptables -P INPUT DROP
iptables -P FORWARD DROP
iptables -P OUTPUT DROP
```
