> **About this post**
>
> Treat DingTalk Approval as a lightweight workflow engine and call the DingTalk Open Platform API from Python: first get the access_token, then list approval templates by user to obtain the `process_code`, and finally initiate a "Command Execution" approval ticket and query its status. Suitable for ops platforms that delegate their approval flow to DingTalk.

> **Technical notes**
>
> The examples are based on DingTalk's legacy `oapi.dingtalk.com` API (2020). DingTalk has since released the new `api.dingtalk.com` and a new approval API, and the legacy API is being phased out — always refer to the latest DingTalk Open Platform documentation before integrating. Replace `app_key`/`app_secret` with your actual application credentials.

---

### Ops Platform: Calling the DingTalk Workflow API with Python/Go

> I looked through many open-source workflow engines for Python or Go, but couldn't find a suitable, usable one. In the end I decided to use DingTalk Approval as the workflow engine, with the ops platform calling it through the API. This basically meets practical needs. The drawback is that the company or department has to run its approvals through DingTalk.

> The example below is the Python version. For Go, just adapt the calls yourself.

#### Code

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-

import json
import requests

# API endpoint - you need to create a mini app, authorize it, and set the server IPs allowed to send requests
# https://open-dev.dingtalk.com/#/corpeapp

def ding_book_token():
    """
    token
    :return:
    """
    app_key = "xxxxxxxxxxx"
    app_secret = "xxxxxxxxxxxxxxxxxxxxxxxxx"
    token = requests.get(f'https://oapi.dingtalk.com/gettoken?appkey={app_key}&appsecret={app_secret}')
    return token.json()["access_token"]

# Get the process_code of all approval tickets
url = f'https://oapi.dingtalk.com/topapi/process/listbyuserid?access_token={ding_book_token()}'
headers = {"Content-Type": "application/json"}
req = requests.post(url, headers=headers, data=json.dumps({
    "offset": 10,
    "size": "100"
}))

# The form is set up in advance
process_code = ""
for i in req.json()["result"]["process_list"]:
    if i["name"] == "命令执行":
        process_code = i["process_code"]

# Returns the ticket info we want    'name': '命令执行', 'process_code': 'PROC-123B9BAC-7170-40C9-A88A-7F18DFD54E4F',

# Initiate a workflow ticket
data = {
    "form_component_values": [
        {
            "name": "执行命令",
            "value": "hostname",
        },
        {
            "name": "主机",
            "value": "192.168.100.50",
        },
    ],
    "dept_id": "1",  # Department ID
    "process_code": process_code,
    "originator_user_id": "manager2704"  # User
}

url = f'https://oapi.dingtalk.com/topapi/processinstance/create?access_token={ding_book_token()}'
headers = {"Content-Type": "application/json"}
req = requests.post(url, headers=headers, data=json.dumps(data))

print(req.json()["process_instance_id"])

# {
# 	"errcode":0,
# 	"process_instance_id":"9ab7fa57-96fd-40a0-b6c3-6e73f21f2f51",
# 	"request_id":"1461t2b34oifh"
# }

# Get the current status of the ticket

data1 = {
    "process_instance_id": req.json()["process_instance_id"]
}

url = f'https://oapi.dingtalk.com/topapi/processinstance/get?access_token={ding_book_token()}'
headers = {"Content-Type": "application/json"}
req = requests.post(url, headers=headers, data=json.dumps(data1))

print(req.json())
```
