> **About this post**
>
> This post documents the process of installing Python 3.6 and pip via yum on CentOS 7 using the EPEL + IUS repositories: first install the sqlite development libraries and the ius-release repository, then use yum to install python36 and python36u-pip and upgrade pip;
> then point the /usr/bin/python symlink to python3.6 while changing the shebangs of /usr/bin/yum and
> urlgrabber-ext-down back to python2, so that yum keeps working; finally, configure the Alibaba Cloud
> PyPI mirror and verify the result with python -V.

> **Technical notes**
>
> The IUS repository project has been archived and is no longer maintained (historical packages can still be fetched from repo.ius.io); on CentOS/Rocky you can now simply run `dnf install python3 python3-pip`;
> Python 2 reached end of official support on 2020-01-01, and Python 3.6 reached EOL in December 2021; for new environments, Python 3.8+ is recommended;
> The installation URL for ius-release.rpm in the original post was swallowed by the editor; it has been restored to the CentOS 7 package address at repo.ius.io.

## 1. Installing Dependencies and the IUS Repository

```shell
yum install epel-release -y

yum -y install sqlite  sqlite-devel

sudo yum -y install https://repo.ius.io/ius-release-el7.rpm
```

## 2. Installing python36 and pip

```shell
yum install python36  python36u-pip  -y
python3.6  -m  pip install --upgrade pip
```

## 3. Switching the Default python and Fixing yum

> ⚠️ After pointing the system python to 3.6, system scripts such as yum still depend on python2; you must change their interpreters back to python2 at the same time, otherwise yum will fail outright with syntax errors.

```shell
mv   /usr/bin/python  /tmp/
ln -s /usr/bin/python3.6    /usr/bin/python

sed  -i    's/\#\!\/usr\/bin\/python/\#\!\/usr\/bin\/python2/'   /usr/bin/yum
sed  -i    's/\#\! \/usr\/bin\/python/\#\! \/usr\/bin\/python2/'   /usr/libexec/urlgrabber-ext-down
```

## 4. Configuring the Alibaba Cloud Mirror for pip

```shell
mkdir -p  /root/.pip/

cat >  /root/.pip/pip.conf   <<EOF
[global]
trusted-host=mirrors.aliyun.com
index-url=http://mirrors.aliyun.com/pypi/simple/
EOF
```

## 5. Verification

```shell
python -V
```
