> **About this post**
>
> This post shows how to disable Windows Defender via the registry: open
> cmd as administrator and run reg add to write
> DisableAntiSpyware=1 (REG_DWORD) to
> HKLM\SOFTWARE\Policies\Microsoft\Windows Defender, which turns off
> Windows Defender's protection.

> **Technical notes**
>
> This method works on older Windows 10 builds; on newer Windows 10/11,
> Defender's Tamper Protection may block or roll back this key. It is
> recommended to turn off real-time protection via "Windows Security →
> Virus & threat protection → Manage settings", or use Group Policy
> (gpedit.msc → Computer Configuration → Administrative Templates →
> Windows Components → Microsoft Defender Antivirus). Defender is also
> disabled automatically when third-party antivirus software takes over.

---

## 1. How to Disable It

Run cmd as administrator and execute:

```bat
reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows Defender" /v "DisableAntiSpyware" /d 1 /t REG_DWORD /f
```
