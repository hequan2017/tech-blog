> **About this post**
>
> This post is a small script (Python 2) that fetches the latest block heights of six major coins: for BTC and BCH it calls the btc.com JSON API and reads `data.height` directly; USDT (whose Omni protocol is built on top of the Bitcoin chain) simply reuses the BTC height; LTC, ETC, and ETH are scraped from their respective block explorer pages, with the height text parsed out via lxml xpath, and everything is printed at the end.

> **Technical notes**
>
> - The code uses Python 2 syntax (the `print` statement); under Python 3 it must be changed to `print(btc, bch, ltc, usdt)`.
> - Some URLs in the original post were truncated: the BTC/BCH endpoints have been restored from the original 51CTO article as `chain.api.btc.com` / `bch-chain.api.btc.com`, but the btc.com API has since been discontinued and both endpoints are unavailable; the ETH scraping URL was already missing in the original (`https:///`) and cannot be restored.
> - The xpath-based web scraping approach stopped working long ago after the sites were redesigned; public APIs such as Etherscan (`api.etherscan.io`) or BlockCypher are recommended instead.

## 1. Script for Fetching Block Heights

```python
#!/usr/bin/python
# -*- coding: utf-8 -*-
import requests
from lxml import etree
import json

b_re = requests.get('https://chain.api.btc.com/v3/block/latest')
btc=b_re.json()['data']['height']

bch_re = requests.get('https://bch-chain.api.btc.com/v3/block/latest')
bch=bch_re.json()['data']['height']

ltc_re = requests.get('http://explorer.litecoin.net/')
selector1 = etree.HTML(ltc_re.text)
ltc = selector1.xpath('//td/a/text()')[1]

usdt = btc

etc_re = requests.get('http://gastracker.io/')
selector2 = etree.HTML(etc_re.text)
etc = selector2.xpath('//dl/dd/span/text()')[6]

eth_re = requests.get('https:///')   # URL truncated in the original post, cannot be restored
selector3 = etree.HTML(eth_re.text)
eth = selector3.xpath('//h4[@style="color: #FFFFFF"]//text()')[0]

print btc,bch,ltc,usdt
print eth,etc
```
