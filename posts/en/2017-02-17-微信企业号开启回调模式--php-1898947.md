> **About this post**
>
> Steps to quickly verify callback mode for the WeChat Enterprise Account with PHP: enable callback mode in the admin console and generate the Token and EncodingAESKey, upload the official PHP SDK to the website directory, modify the three constants encodingAesKey/token/corpId in Sample.php, and complete the URL validity verification.

> **Technical notes**
>
> "WeChat Enterprise Account" has been upgraded to "WeChat Work"; the callback configuration entry and API parameters have changed, but the encryption/decryption flow (WXBizMsgCrypt) follows the same idea. The official PHP callback SDK requires PHP 5.3+, and you must make sure the mcrypt extension (before PHP 7.1) or the openssl extension (PHP 7.2+) is enabled.

---
