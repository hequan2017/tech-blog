> **About this post**
>
> This post demonstrates the complete workflow of implementing pagination in Django based on django-pure-pagination 0.3.0: installation and configuration (INSTALLED_APPS and PAGINATION_SETTINGS), paginating a queryset with Paginator in a view, and rendering a pagination navigation bar with "First / Previous / page numbers / Next / Last" links in a template, using the querystring attribute provided by pure_pagination to preserve the original GET query parameters.

> **Technical notes**
>
> django-pure-pagination 0.3.0 was released in 2015 and the project has not been updated for many years; it is incompatible with recent Django (4.x/5.x) and Python 3.10+. For new projects, use Django's built-in django.core.paginator.Paginator directly, or, when using DRF, use PageNumberPagination from rest_framework.pagination.

---

### Django Pagination Example

#### Installation

```shell
python -m pip install django-pure-pagination==0.3.0
```

#### Settings

```python
INSTALLED_APPS = [
    'pure_pagination',
]

PAGINATION_SETTINGS = {
    'PAGE_RANGE_DISPLAYED': 3,
    'MARGIN_PAGES_DISPLAYED': 2,
    'SHOW_FIRST_PAGE_WHEN_INVALID': True,
}

DISPLAY_PER_PAGE = 15
```

#### Usage

```python
from pure_pagination import PageNotAnInteger
from pure_pagination import Paginator
```

```python
try:
            page = self.request.GET.get('page', 1)
        except PageNotAnInteger as e:
            page = 1
        p = Paginator(self.queryset, getattr(settings, 'DISPLAY_PER_PAGE'), request=self.request)
        asset_list = p.page(page)

        context = {
            "ecs_list": asset_list,
			     }
```

```html
<div style="text-align:center;">
			<nav class="pagination">

					<li><a rel="nofollow" href="{% url "asset:ecs_list" %}?page=1">Home </a></li>

					{% if ecs_list.has_previous %}
							<li class="long"><a
											href="?{{ ecs_list.previous_page_number.querystring }}">Previous</a>
							</li>
					{% endif %}

					{% for page in ecs_list.pages %}
							{% if page %}
									{% ifequal page ecs_list.number %}
											<li class="active"><a rel="nofollow" href="?{{ page.querystring }}">{{ page }}</a>
											</li>
									{% else %}
											<li><a rel="nofollow" href="?{{ page.querystring }}" class="page">{{ page }}</a>
											</li>
									{% endifequal %}
							{% else %}
									<li class="none"><a rel="nofollow" href="">...</a></li>
							{% endif %}
					{% endfor %}
					{% if ecs_list.has_next %}
							<li class="long"><a
											href="?{{ ecs_list.next_page_number.querystring }}">Next</a>
							</li>
					{% endif %}
					<li>
							<a rel="nofollow" href="{% url "asset:ecs_list" %}?page={{ ecs_list.paginator.num_pages }}">Last </a>
					</li>
					<li><span
									style="color: #0a0a0a">Total:  {{ ecs_list.paginator.num_pages }} pages</span>
					</li>
					<li><span
									style="color: #0a0a0a">  ECS count: {{ ecs_count }}</span>
					</li>
			</nav>
	</div>
```
