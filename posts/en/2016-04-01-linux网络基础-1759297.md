> **About this post**
>
> This article is a quick-reference note on Linux networking basics, covering hostname configuration, local hosts file resolution, disabling ping, DNS configuration, viewing and adding routes, and the basic usage of common network diagnostic commands such as dig, nslookup, traceroute, telnet, nmap, and tcpdump. It also uses tcpdump to capture ICMP packets as an example to show the request/reply process of ping.

> **Technical notes**
>
> This article reflects the CentOS 6 era approach to network configuration (/etc/sysconfig/network, the route command). On mainstream distributions in 2026 (CentOS 7+/Rocky/Alma/Ubuntu 22.04+): use `hostnamectl set-hostname` for hostnames; `route`/`ifconfig` have been replaced by `ip route`/`ip addr`; `netstat` has been replaced by `ss`; and NetworkManager (`nmcli`/`nmtui`) is the standard management tool. tcpdump, dig (now part of bind-utils), and traceroute remain in common use.

## 1. Hostname Configuration

Check the current hostname:

```shell
hostname   # show the current hostname
```

Set the hostname permanently (CentOS 6 and earlier):

```shell
vi /etc/sysconfig/network
# edit HOSTNAME=your.hostname
```

> Note: On CentOS 7 and later, use `hostnamectl set-hostname your.hostname` instead; the config file is `/etc/hostname` (the original approach is the legacy way).

Local static resolution:

```shell
vi /etc/hosts
# format: IP address  hostname  alias
```

## 2. Disabling/Allowing ping

Control whether ICMP echo requests are answered via a kernel parameter:

```shell
vi /etc/sysctl.conf
```

```ini
# 1 ignores all ICMP echo (ping disabled); 0 answers
net.ipv4.icmp_echo_ignore_all = 0
```

```shell
sysctl -p   # apply the change immediately
```

## 3. DNS Configuration

```shell
cat /etc/resolv.conf   # show the DNS server configuration
# nameserver 8.8.8.8
```

## 4. Viewing and Adding Routes

```shell
route -n   # show the routing table (-n shows numeric addresses, no DNS lookup)

route add default gw <gateway-ip>   # add the default gateway (the original "defult" is a typo for default)
```

> Note: Modern distributions recommend `ip route show` and `ip route add default via <gateway-ip>`.

## 5. Common Network Diagnostic Commands

```shell
dig www.baidu.com        # query DNS records
nslookup www.baidu.com   # interactive DNS lookup
traceroute www.baidu.com # trace route hops to the target

telnet <target-ip> 80    # test TCP port connectivity (the original "telnet ----- 80" means this)
nmap <target-ip>         # port scan (the original "nmp" is a typo for nmap)
```

## 6. tcpdump Capture Example

Capture ICMP packets on eth0:

```shell
tcpdump -n icmp -i eth0   # -n skips name resolution; capture icmp only
```

Output of a single ping (one request + one reply):

```text
19:13:33.470103 IP 192.168.10.5 > 192.168.10.10: ICMP echo request, id 1, seq 1, length 40
19:13:33.470258 IP 192.168.10.10 > 192.168.10.5: ICMP echo reply, id 1, seq 1, length 40
```

The first line is the echo request sent by the local machine and the second is the echo reply returned by the peer, indicating normal network-layer connectivity.
