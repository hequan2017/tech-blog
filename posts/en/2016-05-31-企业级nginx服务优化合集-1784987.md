> **About this post**
>
> This post is a four-in-one collection of production optimizations for
> Nginx/Apache: (1) hiding the version number (server_tokens and source code
> changes), the runtime user, worker processes and CPU affinity, webbench
> stress testing, the epoll event model and connection limits, the
> server_names hash, sendfile, timeouts, upload limits, and fastcgi caching;
> (2) gzip, mime.types, expires, robots.txt, blocking crawler user agents,
> log rotation, minimal permissions, IP restrictions, error pages, and tmpfs;
> (3) Apache prefork/worker MPM parameters and two anti-hotlinking setups;
> (4) Discuz pseudo-static rewrite rules, php.ini security settings, and
> php-fpm process pool configuration.

> **Technical notes**
>
> The examples are based on CentOS 6 with Nginx 1.6/1.8, Apache 2.2, and
> PHP 5.x. CentOS 6 reached EOL in 2020, and nginx 1.8 and Apache 2.2 have
> long been unmaintained; use a maintained newer version in production.
> safe_mode, register_globals, and magic_quotes_gpc in php.ini were removed
> as of PHP 5.4; newer versions neither need nor support them. php-fpm ships
> with the PHP core since PHP 5.3.3, so building with `--enable-fastcgi` is
> no longer needed.
> The webbench source site blog.s135.com is no longer available; use ab / wrk
> for stress testing instead. On nginx 1.9.10+, worker_cpu_affinity supports
> auto binding.

## 1. Optimization (1): Version, Process, and Connection Tuning

### Changing the Version Information

```shell
curl -I 192.168.10.11
```

```text
Server: nginx/1.6.3
```

Method 1: modify the version and version number (edit before compiling nginx).

src/core/nginx.h:

```c
#define nginx_version      1008001
#define NGINX_VERSION      "1.8.1"                # change to the version you want to display, e.g. 2.2.23
#define NGINX_VER          "nginx/" NGINX_VERSION # change nginx to the software name you want to display
#define NGINX_VAR          "NGINX"                # change nginx to the software name you want to display (e.g. Evan Web Server)
#define NGX_OLDPID_EXT     ".oldbin"
```

src/http/ngx_http_header_filter_module.c:

```c
static char ngx_http_server_string[] = "Server: nginx" CRLF;   # change nginx to the version you want
```

src/http/ngx_http_special_response.c:

```c
"<hr><center>nginx</center>" CRLF    # change nginx to the version information you want
```

Method 2: hide the version number by adding `server_tokens off;` to the nginx
configuration file. The scope of server_tokens is the http, server, and
location blocks; the default is on (version information shown). Setting it to
off hides the nginx version information everywhere:

```nginx
http {
    server_tokens off;
}
```

```shell
/application/nginx/sbin/nginx -s reload
```

Effect: `nginx/1.6.3` becomes `nginx` (the 404 Not Found page no longer shows
the version number).

### Configuring worker_cpu_affinity

Pin each worker process to its own CPU core:


### Event Processing Model Optimization

Use the epoll model on Linux:

```nginx
events {                          # set the nginx working mode and the connection limit
    use epoll;
    worker_connections  20480;    # max connections per process, default 1024
}
```

Maximum connections: Max_client = worker_processes × worker_connections.

The per-process connection limit is also capped by the system's maximum number
of open files. Run `ulimit -HSn 65535`, or set worker_rlimit_nofile below
(main context) for it to take effect:

```nginx
worker_rlimit_nofile  65535;    # max open files per process
```

### Tuning the Server Names Hash Table Size

```nginx
http {
    server_names_hash_bucket_size  64;
    server_names_hash_max_size  512;    # default 512, usually 4-5 times the CPU L1 cache
}
```

(Example: wildcard resolution such as http://hequan.blog.51cto.com/.)

## 2. Optimization (2): Compression, Caching, Logs, and Security

### Configuring nginx gzip Compression

```nginx
gzip  on;
gzip_min_length   1k;        # only compresses when larger than 1K
gzip_buffers      4 32k;     # compression buffer size
gzip_http_version 1.1;
gzip_comp_level   9;         # compression ratio 1-9
gzip_types  text/css text/xml application/javascript;    # types to compress; they differ across versions
gzip_vary  on;               # vary header support
```

Test: `unzip test_deflate.zip`; in Firefox you can install the YSlow add-on to
view the compression/caching results.

### include mime.types

```shell
cat conf/mime.types    # types differ across versions
```

```nginx
types {
    text/html                html htm shtml;
    text/css                 css;
    text/xml                 xml;
    image/gif                gif;

    application/javascript   js;
    application/atom+xml     atom;
    application/rss+xml      rss;
```

The apache equivalent is mod_deflate (`--enable-deflate` at compile time).

### nginx expire Caching

How long files are cached locally on the client; put this inside a server
block:

```nginx
location ~ .*\.(gif|jpg|jpeg|png|bmp|swf)$ {
    expires  3650d;
}

location ~ .*\.(js|css)?$ {
    expires  30d;
}
```

Example: cache robots.txt for 7 days and record 404s:

```nginx
location ~(robots.txt) {
    log_not_found  off;
    expires    7d;
    break;
}
```

The apache equivalent is mod_expires:

```shell
./configure --enable-expires
cd /httpd-2.2.22/modules/metadata/                    # switch to the apache source directory
/application/apache/bin/apxs -c -i -a mod_expires.c   # compile into apache as a DSO
ll /application/apache2.2.22/modules/mod_expires.so   # verify
```

### robots.txt and Blocking Crawler User Agents

Referring to http://www.51cto.com/robots.txt, write a file like this:

```text
User-agent: *
Crawl-delay: 500
Disallow: /wuyou/
Disallow: /php/
Disallow: /wuyou_admin/
Disallow: /actions/
```

Modify nginx.conf to block web crawler user agents and return 403:

```nginx
server {
    listen 80;
    server_name 127.0.0.1;
    # add the content below to block crawlers
    if ($http_user_agent ~* "qihoobot|Baiduspider|Googlebot|Googlebot-Mobile|Googlebot-Image|Mediapartners-Google|Adsbot-Google|Feedfetcher-Google|Yahoo! Slurp|Yahoo! Slurp China|YoudaoBot|Sosospider|Sogou spider|Sogou web spider|MSNBot|ia_archiver|Tomato Bot") {
        return 403;    # you could also change the above to browsers to block browser access
    }
}
```

## 3. Optimization (3): Apache MPM and Anti-Hotlinking

### apache worker/prefork

```shell
/application/apache/bin/apachectl -l | sed -n '/worker\|prefork/p'
worker.c
Server MPM:     Worker
```

```shell
./configure --with-mpm=worker    # specify at compile time; the default is prefork
```

### prefork (Default)

It uses multiple child processes, each with a single thread; efficient,
stable, and secure, but it consumes more resources than worker.

```apache
# vim /application/apache/conf/extra/httpd-mpm.conf
<IfModule mpm_prefork_module>
StartServers          10            # number of server processes started at startup
MinSpareServers       10            # minimum number of idle servers
MaxSpareServers       15            # maximum number of idle servers
ServerLimit         2000
MaxClients           1000           # maximum processes/concurrency
MaxRequestsPerChild   5000          # max requests a child process handles, 0 = unlimited
</IfModule>
```

Check concurrent connections:

```shell
ps -ef | grep http | grep -v grep | wc -l
6
```

### worker (Combination of Threads and Processes)

```apache
# vim /application/apache/conf/extra/httpd-mpm.conf
<IfModule mpm_worker_module>
StartServers            2
MaxClients           2000      # number of concurrent client connections
ServerLimit            25      # total number of processes
MinSpareThreads        50
MaxSpareThreads       200
ThreadLimit           200
ThreadsPerChild       100      # steady-state number of worker threads per server process
MaxRequestsPerChild     0      # total requests a single child process may handle, default 0 = unlimited
</IfModule>
```

Constraints:

```text
MaxClients <= ServerLimit * ThreadsPerChild
MaxClients % ThreadsPerChild = 0
```

## 4. Optimization (4): Pseudo-Static URLs + php.ini

### Apache Pseudo-Static URLs

Open the apache configuration file httpd.conf:

1. Remove the leading # from `#LoadModule rewrite_module modules/mod_rewrite.so`.
2. Find the section below and change AllowOverride None to AllowOverride All:

```apache
#
# AllowOverride controls what directives may be placed in .htaccess files.
# It can be "All", "None", or any combination of the keywords:
# Options FileInfo AuthConfig Limit
#
AllowOverride All
```

### Discuz Pseudo-Static Configuration File (Apache Web Server, Dedicated Host Users)

```apache
<IfModule mod_rewrite.c>
        RewriteEngine On
        RewriteCond %{QUERY_STRING} ^(.*)$
        RewriteRule ^(.*)/topic-(.+)\.html$ $1/portal.php?mod=topic&topic=$2&%1
        RewriteCond %{QUERY_STRING} ^(.*)$
        RewriteRule ^(.*)/article-([0-9]+)-([0-9]+)\.html$ $1/portal.php?mod=view&aid=$2&page=$3&%1
        RewriteCond %{QUERY_STRING} ^(.*)$
        RewriteRule ^(.*)/forum-(\w+)-([0-9]+)\.html$ $1/forum.php?mod=forumdisplay&fid=$2&page=$3&%1
        RewriteCond %{QUERY_STRING} ^(.*)$
        RewriteRule ^(.*)/thread-([0-9]+)-([0-9]+)-([0-9]+)\.html$ $1/forum.php?mod=viewthread&tid=$2&extra=page\%3D$4&page=$3&%1
        RewriteCond %{QUERY_STRING} ^(.*)$
        RewriteRule ^(.*)/group-([0-9]+)-([0-9]+)\.html$ $1/forum.php?mod=group&fid=$2&page=$3&%1
        RewriteCond %{QUERY_STRING} ^(.*)$
        RewriteRule ^(.*)/space-(username|uid)-(.+)\.html$ $1/home.php?mod=space&$2=$3&%1
        RewriteCond %{QUERY_STRING} ^(.*)$
        RewriteRule ^(.*)/blog-([0-9]+)-([0-9]+)\.html$ $1/home.php?mod=space&uid=$2&do=blog&id=$3&%1
        RewriteCond %{QUERY_STRING} ^(.*)$
        RewriteRule ^(.*)/(fid|tid)-([0-9]+)\.html$ $1/index.php?action=$2&value=$3&%1
        RewriteCond %{QUERY_STRING} ^(.*)$
        RewriteRule ^(.*)/([a-z]+[a-z0-9_]*)-([a-z0-9_\-]+)\.html$ $1/plugin.php?id=$2:$3&%1
</IfModule>
```

### rewrite Regex Syntax Notes

Regular expression matching, where:

- `~` is a case-sensitive match
- `~*` is a case-insensitive match
- `!~` and `!~*` are a case-sensitive non-match and a case-insensitive non-match respectively

File and directory matching, where:

- `-f` and `!-f` test whether a file exists
- `-d` and `!-d` test whether a directory exists
- `-e` and `!-e` test whether a file or directory exists
- `-x` and `!-x` test whether a file is executable

Flag markers:

- `last` is equivalent to the [L] flag in Apache; it means the rewrite is complete
- `break` stops matching; later rules are not matched
- `redirect` returns a 302 temporary redirect; the address bar shows the redirected address
- `permanent` returns a 301 permanent redirect; the address bar shows the redirected address

### Discuz Pseudo-Static Configuration File (nginx Web Server)

```nginx
rewrite ^([^\.]*)/topic-(.+)\.html$ $1/portal.php?mod=topic&topic=$2 last;
rewrite ^([^\.]*)/article-([0-9]+)-([0-9]+)\.html$ $1/portal.php?mod=view&aid=$2&page=$3 last;
rewrite ^([^\.]*)/forum-(\w+)-([0-9]+)\.html$ $1/forum.php?mod=forumdisplay&fid=$2&page=$3 last;
rewrite ^([^\.]*)/thread-([0-9]+)-([0-9]+)-([0-9]+)\.html$ $1/forum.php?mod=viewthread&tid=$2&extra=page%3D$4&page=$3 last;
rewrite ^([^\.]*)/group-([0-9]+)-([0-9]+)\.html$ $1/forum.php?mod=group&fid=$2&page=$3 last;
rewrite ^([^\.]*)/space-(username|uid)-(.+)\.html$ $1/home.php?mod=space&$2=$3 last;
rewrite ^([^\.]*)/blog-([0-9]+)-([0-9]+)\.html$ $1/home.php?mod=space&uid=$2&do=blog&id=$3 last;
rewrite ^([^\.]*)/(fid|tid)-([0-9]+)\.html$ $1/index.php?action=$2&value=$3 last;
rewrite ^([^\.]*)/([a-z]+[a-z0-9_]*)-([a-z0-9_\-]+)\.html$ $1/plugin.php?id=$2:$3 last;
if (!-e $request_filename) {
    return 404;
}
```
