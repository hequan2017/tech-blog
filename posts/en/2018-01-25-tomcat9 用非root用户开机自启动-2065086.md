> **About this post**
>
> One of two ways to make Tomcat start automatically at boot as the non-root tomcat user: compile jsvc from commons-daemon, reuse bin/daemon.sh as the /etc/init.d/tomcat startup script, register it with chkconfig for boot startup, and tune JVM heap memory and CMS GC parameters via JAVA_OPTS in the script.

> **Technical notes**
>
> This approach applies to SysV init on CentOS 6/7. On RHEL 8+/Rocky 8+, chkconfig/init.d is no longer mainstream; a systemd unit (`User=tomcat` + `ExecStart=/usr/local/tomcat/bin/startup.sh`) is recommended instead. PermSize/MaxPermSize was superseded by MetaspaceSize (since JDK 8), CMS GC was removed starting with JDK 14, and G1 or ZGC is recommended on modern versions.

---

### Start at Boot with the tomcat User

#### Create the user

```shell
groupadd tomcat
useradd -g tomcat   tomcat   -s /sbin/nologin
chown tomcat.tomcat -R /usr/local/tomcat/*
```

#### Compile jsvc

```shell
cd /usr/local/tomcat/bin/
tar xf commons-daemon-native.tar.gz
cd commons-daemon-1.1.0-native-src/unix/
./configure --with-java=$JAVA_HOME
make

cp jsvc /usr/local/tomcat/bin/
cp /usr/local/tomcat/bin/daemon.sh    /etc/init.d/tomcat
```

#### Modify the startup file for memory tuning

```shell
vim /etc/init.d/tomcat
#!/bin/sh
# chkconfig: 2345 81 91
# description: Start and Stop  tomcat

JAVA_HOME=/usr/local/jdk8.0
JAVA_BIN=/usr/local/jdk8.0/bin
CLASSPATH=$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar
CATALINA_BASE=/usr/local/tomcat
CATALINA_HOME=/usr/local/tomcat

JAVA_OPTS="-server
-Xms1024m
-Xmx1536m
-XX:PermSize=256m
-XX:MaxPermSize=512m
-XX:+UseConcMarkSweepGC
-XX:+UseCMSCompactAtFullCollection
-XX:CMSFullGCsBeforeCompaction=0
-XX:-PrintGC
-XX:-PrintGCDetails
-XX:-PrintGCTimeStamps
-Xloggc:../logs/gc.log "

## -Xmx1536m     Maximum heap size allowed; generally keep it under 80% of physical memory

/etc/init.d/tomcat start

chkconfig tomcat on
```
