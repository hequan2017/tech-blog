> **About this post**
>
> This post describes the fastest way to install GeoIP: download and extract the
> GeoIP/GeoLiteCity/GeoIPASNum data packages, install GeoIP, GeoIP-devel, and
> perl-Geo-IP via yum from the EPEL repository, and explain which data file
> corresponds to country, city, and organization information respectively.

> **Technical notes**
>
> The wget links in this post are no longer valid, and MaxMind stopped
> distributing the legacy GeoLite data in 2019; CentOS 6 reached EOL in 2020
> and the EPEL 6 repository is no longer maintained, so it is recommended to
> switch to the GeoLite2 databases and the geoipupdate tool.

---

## 1. Download the data packages

```shell
mkdir /GeoIP
cd /GeoIP

wget http://geolite.maxmind.com/download/geoip/database/GeoLiteCountry/GeoIP.dat.gz
wget http://geolite.maxmind.com/download/geoip/database/GeoLiteCity.dat.gz
wget http://geolite.maxmind.com/download/geoip/database/asnum/GeoIPASNum.dat.gz

gunzip GeoIP.dat.gz
gunzip GeoIPASNum.dat.gz
gunzip GeoLiteCity.dat.gz
```

GeoIP is the country data, GeoLiteCity is the city data, and GeoIPASNum is the organization data.

## 2. Install the EPEL repository and GeoIP

```shell
rpm -ivh https://dl.fedoraproject.org/pub/epel/6/x86_64/epel-release-6-8.noarch.rpm
```

```shell
# vim /etc/yum.repos.d/epel.repo     ## comment out the mirrorlist url (the https one), then uncomment baseurl

yum -y install GeoIP GeoIP-devel perl-Geo-IP
```
