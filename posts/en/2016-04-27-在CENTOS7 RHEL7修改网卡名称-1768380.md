> **About this post**
>
> This post records the complete steps to change the consistent network interface names (eno/ens) back to the
> traditional eth0 on CentOS 7 / RHEL 7: edit /etc/default/grub to append net.ifnames=0 biosdevname=0 and
> regenerate the configuration with grub2-mkconfig, rename ifcfg-enoxxxxxx to ifcfg-eth0, write a udev rule
> that binds the MAC address to eth0, and reboot for the change to take effect. The end of the post also
> covers common system initialization commands such as switching to the Alibaba Cloud yum repository,
> managing services with systemctl, and disabling firewalld.

> **Technical notes**
>
> CentOS 7 reached end of life (EOL) on June 30, 2024; consider migrating to Rocky Linux 9 / AlmaLinux 9 or
> the Chinese openEuler distribution. Note: `net.ifnames=0 biosdevname=0` only makes the kernel fall back to
> traditional naming; RHEL 8/9 and their derivative distributions still default to consistent naming, so new
> environments are advised to adopt names such as ens33 instead of reverting to eth0. From RHEL 9 on,
> NetworkManager keyfiles (/etc/NetworkManager/system-connections/) are recommended for network interface
> configuration.

## 1. Disable the Predictable Naming Rules

Edit the grub configuration and add `net.ifnames=0 biosdevname=0` to `GRUB_CMDLINE_LINUX`:

```ini
# vim /etc/default/grub
GRUB_TIMEOUT=5
GRUB_DEFAULT=saved
GRUB_DISABLE_SUBMENU=true
GRUB_TERMINAL_OUTPUT="console"
GRUB_CMDLINE_LINUX="rd.lvm.lv=centos/root rd.lvm.lv=centos/swap net.ifnames=0 biosdevname=0 rhgb quiet"
GRUB_DISABLE_RECOVERY="true"
```

Regenerate the grub configuration:

```shell
grub2-mkconfig -o /boot/grub2/grub.cfg
```

The output is as follows:

```text
Generating grub configuration file ...
Found linux image: /boot/vmlinuz-3.10.0-229.el7.x86_64
Found initrd image: /boot/initramfs-3.10.0-229.el7.x86_64.img
Found linux image: /boot/vmlinuz-0-rescue-a8ecfd39a4014521ae54ccef4ada1c67
Found initrd image: /boot/initramfs-0-rescue-a8ecfd39a4014521ae54ccef4ada1c67.img
done
```

## 2. Modify the Network Interface Configuration File

```shell
cd /etc/sysconfig/network-scripts/
mv ifcfg-enoxxxxxx ifcfg-eth0
```

## 3. Modify the Device Name Mapping

```shell
# vim /etc/udev/rules.d/70-persistent-ipoib.rules
```

```text
SUBSYSTEM=="net", ACTION=="add", DRIVERS=="?*", ATTR{address}=="00:0c:29:e0:17:54", ATTR{type}=="1", KERNEL=="eth*", NAME="eth0"
```

## 5. Appendix: Switching to the Alibaba Cloud yum Repository

```shell
mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.backup
wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.aliyun.com/repo/Centos-7.repo
yum clean all
yum makecache
```

## 6. Appendix: systemctl and Basic Tools

```shell
systemctl action service-name.service   # general syntax for service management
yum -y install net-tools                # after installation, ifconfig and other legacy commands become available
```

## 7. Appendix: firewall and iptables

CentOS 7.0 uses firewall as the default firewall; here we switch to the iptables firewall instead.

```shell
systemctl start firewalld.service    # start firewalld
systemctl stop firewalld.service     # stop firewalld
systemctl disable firewalld.service  # disable firewalld from starting at boot
```
