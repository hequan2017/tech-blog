> **About this post**
>
> This post is a collection of notes on Linux disk management, covering common operations such as viewing memory (free), viewing disks and partitions (fdisk -l), interactive partitioning with fdisk (primary/extended/logical partitions), using partprobe to have the kernel re-read the partition table, partitioning disks larger than 2TB with parted + GPT, formatting with mkfs, mounting with mount/umount, backing up the MBR with dd, and tuning ext filesystem parameters with tune2fs/dumpe2fs.

> **Technical notes**
>
> The commands in this post remain largely applicable in 2026, but note: fdisk has natively supported GPT since util-linux 2.23, so the claim that "disks over 2T must use parted" is outdated; GPT is recommended for new disks (MBR caps a single partition at 2TB); ext4 is still mainstream, but XFS is the default filesystem on RHEL/Rocky/Alma; `partprobe` can be replaced with `udevadm settle` or `blockdev --rereadpt`. CentOS 7 reached EOL on 2024-06-30.

## 1. Memory and Disk Overview

```shell
free -m    # show memory/swap usage in MB
fdisk -l   # list all disks and their partitions
```

## 2. Partitioning with fdisk (MBR, ≤2TB)

Partition type concepts: primary partitions (up to 4), an extended partition (takes one primary slot), and logical partitions (created inside an extended partition, numbered starting from 5).

To enter interactive partitioning:

```shell
fdisk /dev/sdb
```

The fdisk built-in command menu:

```text
Command action
   a   toggle a bootable flag        # set the bootable flag
   b   edit bsd disklabel
   c   toggle the dos compatibility flag
   d   delete a partition            # delete a partition
   l   list known partition types    # list known partition type IDs
   m   print this menu               # print help
   n   add a new partition           # add a new partition
   o   create a new empty DOS partition table
   p   print the partition table     # print the partition table
   q   quit without saving changes   # quit without saving
   s   create a new empty Sun disklabel
   t   change a partition's system id  # change the partition type ID
   u   change display/entry units
   v   verify the partition table
   w   write table to disk and exit  # save and exit
   x   extra functionality (experts only)
```

Example of creating a new partition (a 500MB primary + an extended partition):

```text
Command (m for help): n
Command action
   e   extended
   p   primary partition (1-4)
p
Partition number (1-4): 1
Last cylinder, +cylinders or +size{K,M,G} (1-130, default 130): +500M
```

Partitioning result:

```text
Device Boot      Start         End      Blocks   Id  System
/dev/sdb1              1          20      160618+  83  Linux
/dev/sdb2             21         130      883575    5  Extended
```

Use the `t` command to change the partition type to LVM (ID 8e); `l` lists all the type IDs:

```text
/dev/sdb1              1          20      160618+  8e  Linux LVM
```

After partitioning, tell the kernel to re-read the partition table (avoids a reboot):

```shell
partprobe /dev/sdb   # tell the kernel the partition table has changed
```

## 3. Partitioning with parted (GPT, supports >2TB)

parted is the GNU disk partitioning tool, traditionally used for disks larger than 2TB (requires a GPT partition table):

```shell
parted /dev/sdb
```

The interactive session:

```text
GNU Parted 2.1
使用 /dev/sdb
Welcome to GNU Parted! Type 'help' to view a list of commands.

(parted) rm                # delete an existing partition
分区编号？ 1

(parted) mklabel gpt       # create a GPT partition table (destroys all data on the disk!)
警告: The existing disk label on /dev/sdb will be destroyed and all data
on this disk will be lost. Do you want to continue?
是/Yes/否/No? yes

(parted) p                 # print the partition table
Model: VMware, VMware Virtual S (scsi)
Disk /dev/sdb: 1074MB
Sector size (logical/physical): 512B/512B
Partition Table: gpt

(parted) mkpart primary 0 500    # create a partition from 0 to 500MB
警告: The resulting partition is not properly aligned for best performance.
忽略/Ignore/放弃/Cancel? Ignore

(parted) mkpart logical 501 1024
(parted) p
Number  Start   End     Size   File system  Name     标志
 1      17.4kB  500MB   500MB               primary
 2      501MB   1024MB  523MB               logical
```

> Note: A GPT partition table has no primary/extended/logical partition distinction; `primary`/`logical` in parted are just partition name labels here (the original example follows MBR naming habits).

You can also do this non-interactively, one command per step:

```shell
parted /dev/sdb mklabel gpt                 # create a GPT partition table
parted /dev/sdb mkpart primary 0 500        # create a partition
parted /dev/sdb mkpart logical 501 1024
parted /dev/sdb p                           # show the partition table
```

## 4. Formatting and Mounting

```shell
mkfs.ext4 /dev/sdb1        # format as ext4
mount /dev/sdb1 /mnt       # mount to /mnt
df -hT                     # check mounts (-T shows the filesystem type)
```

Full mount syntax and forced unmounting:

```shell
mount -t <filesystem-type> -o <mount-options> <device> <mount-point>
mount -a                   # mount everything listed in /etc/fstab
umount -lf /mnt            # force unmount (lazy + force)
```

## 5. Tuning Filesystem Parameters with tune2fs

By default, an ext filesystem gets an automatic fsck check every 22 mounts or 180 days, whichever comes first:

```text
This filesystem will be automatically checked every 22 mounts or
180 days, whichever comes first.  Use tune2fs -c or -i to override.
```

Disable the mount-count check:

```shell
tune2fs -c -1 /dev/sdb1    # -c -1 disables the mount-count check
# tune2fs 1.41.12 (17-May-2010)
# Setting maximal mount count to -1
```

## 6. Backing Up the MBR with dd

```shell
dd if=/dev/sda of=mbr.bin bs=512 count=1   # back up the MBR of sda (first 512 bytes)
```

## 7. Checking Disk Usage

```shell
du -sh /etc        # total size of a directory, h = human-readable
du -sh /etc/*      # size of each entry under /etc
# 27M     /etc
```

## 8. Other Related Tools

- `tune2fs`: adjusts tunable parameters of ext2/ext3/ext4 filesystems.
- `dumpe2fs`: dumps detailed information of ext2/ext3/ext4 filesystems (superblock, block groups, etc.).
