> **About this post**
>
> A small ops script for taking stock of disk types on CentOS: extract the
> macs and bw configuration values from /etc/pcdn/pcdn.conf; locate the
> system disk device name with lsblk/pvs (LVM-compatible); check whether
> /pcdn_data/pcdn_index_data resides on sda and read its capacity; count
> the remaining disk blocks, and use the rota flag from lsblk to
> distinguish SSDs (0) from HDDs (1).

> **Technical notes**
>
> `lsblk -ar` lists all block devices in raw format, where the last two
> columns are TYPE and MOUNTPOINT, so `$(NF-1)` picks up the device type,
> and `grep -w "/"` matches exactly the line containing the root partition;
> under LVM the root device looks like centos-root, so split out the VG name
> by `-` and look up the physical disk with `pvs`.
> The `rota` column comes from the kernel's `/sys/block/<device>/queue/rotational`;
> 0 means SSD and 1 means HDD. You can also check it directly with
> `cat /sys/block/sda/queue/rotational`. For virtual machine disks (e.g. virtio)
> or some cloud disks this value may be inaccurate, so treat the result as
> reference only. Note that `fdisk -l | grep sd | grep -v sda` also counts
> partitions of sdb (e.g. sdb1); what it actually counts is "the number of
> non-sda sd* device lines" rather than the pure disk count.

## 1. Reading the PCDN configuration values (macs / bw)

```shell
# Get the macs value
cat /etc/pcdn/pcdn.conf | grep macs   | head -n 1 | awk -F" " '{print $2}'

# Get the bw value
cat /etc/pcdn/pcdn.conf | grep  bw  | head -n 1 | awk -F" " '{print $2}'
```

## 2. Locating the system disk device name

First use `lsblk -ar` to find the line whose mount point is `/`, and take the second-to-last column (TYPE) and the first column (device name); if it is LVM, split out the VG name by `-`, look up the physical disk with `pvs`, and strip the partition number; otherwise just strip the partition number from the device name. If nothing is found, print 0 and exit.

```shell
root_type=`lsblk -ar 2>>/dev/null | grep -w "/" | awk '{print $(NF-1)}'`
root_name=`lsblk -ar 2>>/dev/null | grep -w "/" | awk '{print $1}'`
root_disk=""
if [ x"$root_type" == x"lvm" ];then
  root_vg_name=`echo $root_name | awk -F- '{print $1}'`
  root_disk=`pvs 2>>/dev/null | grep $root_vg_name | awk '{print $1}' | sed 's/[0-9]//;s/\/dev\///'`
else
  root_disk=`lsblk -ar 2>>/dev/null | grep -w "/" | awk '{print $1}' | sed 's/[0-9]//'`
fi

if [ -z "$root_disk" ];then
  echo "0"
  exit 1
else
  echo "$root_disk"
fi
```

## 3. Data disk location and capacity

Check whether `/pcdn_data/pcdn_index_data` resides on sda, and read its capacity.

```shell
df -hT | grep  /pcdn_data/pcdn_index_data   | grep sda | wc -l
# 1 supported / 0 not supported

df -hT | grep  /pcdn_data/pcdn_index_data   | awk -F" "  '{print  $5}'  | awk -F"G" '{print $1}'
# The supported capacity
```

## 4. Disk block count and SSD/HDD detection

```shell
# System disk block count
fdisk -l | grep sd | grep -v sda | wc -l

# 0 means SSD, 1 means HDD
lsblk  -d -o name,rota | grep sda  | awk -F" "  '{print $2}'
```
