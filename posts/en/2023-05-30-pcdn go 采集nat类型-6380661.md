> **About this post**
>
> This post presents a small Go program: it sends a probe to a STUN server
> (default port 3478) and collects the NAT type and public IP of the local
> machine's egress — a basic collection capability for PCDN scenarios.
> The code is only a dozen lines, relying on the Query interface wrapped
> by `github.com/ppma/nat-type`.

> **Technical notes**
>
> STUN works by having the local machine send UDP requests to a public
> server and inferring the egress NAT behavior from the mapped address
> returned. Under the classic classification of RFC 3489, NAT falls into
> four types — full cone, IP-restricted cone, port-restricted cone, and
> symmetric — with the later ones being less favorable to P2P hole punching.
> `stun.qq.com` is a public STUN server provided by Tencent, and 3478 is
> the default STUN port.

---

```go
package main

import (
	"fmt"
	stun "github.com/ppma/nat-type"
)

const (
	STUN_SERVER = "stun.qq.com"
	STUN_PORT   = 3478
)

func main() {
	localAddr := fmt.Sprintf("%s:%d", "192.168.8.109", 8569)
	stunAddr := fmt.Sprintf("%s:%d", STUN_SERVER, STUN_PORT)
	result, err := stun.Query(stunAddr, localAddr)
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println("Nat type: ", result.GetNatType())

	fmt.Println("Public IP: ", result.GetIpAddr())
}
```
