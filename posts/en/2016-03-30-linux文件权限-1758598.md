> **About this post**
>
> This post documents common operations on Linux file permissions: the mapping
> between rwx and the numbers 4/2/1, the numeric and symbolic modes of chmod
> (including -R for recursion), and chown for changing owner and group; how
> umask determines the default permissions of 666 for files and 777 for
> directories, plus the decision logic in /etc/profile; the focus is on the
> three special permissions setuid/setgid/sticky bit — their uses, numeric
> representation (4000/2000/1000), and how to locate them with find -perm;
> it closes with chattr file attribute locking, setfacl/getfacl access
> control lists, and using cut to extract columns.

> **Technical notes**
>
> Commands and output are based on CentOS 6; the permission mechanism still
> applies today. Two reminders: adding suid to /etc/passwd here is only to
> demonstrate the capital S shown when the execute bit is absent — never add
> special permissions to data files in production; setgid on a directory
> (2770) means something different than on a file: it makes files inherit
> the directory's group automatically for in-group sharing.

## 1. Basic Permissions and chmod / chown

r, w, and x correspond to the numbers 4, 2, and 1 respectively:

```shell
[root@localhost ~]# chmod 575 a.txt
[root@localhost ~]# ls -l a.txt
-r-xrwxr-x 1 root root 0 3月  27 19:09 a.txt
```

Recursion and symbolic mode:

```shell
# chmod -R 777 xx/                  # change permissions recursively
# chmod u=rwx,g=rwx,o=rwx xx        # a=rwx means all users; + and - also work
# chmod a-w xx
# chown root:root xx
```

cut extracts by column (-d for the delimiter, -f to select columns by number, -c/-b by character):

```shell
# who | cut -b 10-14
tty1
pts/0
# who | cut -b 3-
# who | cut -c 3-5
# cat /etc/passwd | head -n 5 | cut -d : -f 1
root
bin
daemon
adm
lp
```

Creating a user with a specified group (the same applies to chgrp):

```shell
# useradd yy -g he
$ ll
-rw-r--r-- 1 xx he 15 3月  27 20:20 a
```

## 2. umask Default Permissions

Whether a file can be deleted is controlled by the permissions of its parent directory, and has nothing to do with the file's own permissions.

```shell
# umask
0022
```

- Files: 666-022
- Directories: 777-022

A regular user's umask is not necessarily 002, unless the following condition is met:

```shell
# vi /etc/profile
if [ $UID -gt 199 ] && [ "`id -gn`" = "`id -un`" ]; then
    umask 002
else
    umask 022
fi
```

```shell
# vi /etc/login.defs
UMASK           077     # for home directories
```

## 3. Special Permissions: setuid / setgid / Sticky Bit

- setuid: lets a regular user run with root's role (the typical example is passwd)
- setgid: files inside a directory automatically inherit the directory's group
- Sticky bit (sbit): in a shared directory, only the owner and root can delete files; nobody else can touch other people's things

Adding suid to a file without the execute bit shows a capital S:

```shell
# chmod u+s /etc/passwd
-rwSr--r--
```

Finding setuid programs on the system:

```shell
# find /usr/bin -type f -perm 4755 | xargs ls -l
-rwsr-xr-x. 1 root root 54240 1月  30 2012 /usr/bin/at
-rwsr-xr-x. 1 root root 66352 12月  8 2011 /usr/bin/chage
-rwsr-xr-x. 1 root root 51784 11月 23 2013 /usr/bin/crontab
-rwsr-xr-x. 1 root root 71480 12月  8 2011 /usr/bin/gpasswd
-rwsr-xr-x. 1 root root 36144 12月  8 2011 /usr/bin/newgrp
-rwsr-xr-x. 1 root root 30768 2月  22 2012 /usr/bin/passwd
-rwsr-xr-x  1 root root 27576 9月  20 2013 /usr/bin/pkexec
```

setgid for a group-shared directory:

```shell
# chown .xx /home/admins/
# chmod 770 /home/admins/
# chmod 2770 /home/admins/      # files below automatically inherit the directory's group
# ls -ld /home/admins/
drwxrws--- 2 root xx 4096 3月  27 22:07 /home/admins/
# ls -l /home/admins/xxxxx
-rw--w--w- 1 root xx 0 3月  27 22:09 /home/admins/xxxxx
```

Numeric representation: setuid 4000 + setgid 2000 = 6755:

```text
-rwsr-xr-x                -rwxr-sr-x
```

```shell
# chmod 4755 a                  # result: -rwsr-xr-x
# chmod u+s a                   # chmod g+s a
```

When the permission overlaps with x, it shows as a lowercase s.

The sticky bit is 1000; /tmp is the typical example:

```shell
# ls -ld /tmp/
drwxrwxrwt. 3 root root 4096 3月  27 21:46 /tmp/
# chmod 7755 test
```
