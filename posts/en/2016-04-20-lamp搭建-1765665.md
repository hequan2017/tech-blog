> **About this post**
>
> The complete process of a manual, source-built LAMP installation: MySQL
> 5.1.72 compiled from source (ncurses dependency, configure options,
> mysql_install_db initialization, registering the mysqld service with
> boot-time autostart, setting/changing the root password, cleaning up
> extra accounts); PHP 5.3.27 compiled and installed (yum dependencies,
> libiconv, building the PHP module into Apache via apxs2, copying
> php.ini); key httpd.conf changes (ServerName/AddType/User/DirectoryIndex);
> finally, the whole environment is verified with phpinfo and a database
> connection test page.

> **Technical notes**
>
> CentOS 7 reached end of maintenance (EOL) on June 30, 2024; migrating to
> Rocky Linux 9 / AlmaLinux 9 or the Chinese openEuler is recommended.
>
> MySQL 5.1 (EOL in late 2013) and PHP 5.3 (EOL in 2014) in this post have
> long been out of security maintenance, carry many known vulnerabilities,
> and must no longer be used in production. The `mysql_connect()` and other
> `mysql_*` functions shown in the examples were removed as of PHP 7; the
> connection test code should be rewritten with `mysqli` or PDO.

## 1. MySQL 5.1.72 Source Compilation and Installation

Install the build dependencies and create the runtime user:

```shell
yum install -y ncurses-devel
groupadd mysql
useradd mysql -g mysql -M -s /sbin/nologin
tar zxvf mysql-5.1.72.tar.gz
cd mysql-5.1.72
```

The configure options are numerous; the author first wrote the options
below into `x.log`, then ran `cat x.log | bash` to execute them in one go:

```shell
./configure \
--prefix=/application/mysql5.1.72 \
--with-unix-socket-path=/application/mysql5.1.72/tmp/mysql.sock \
--localstatedir=/application/mysql5.1.72/data \
--enable-assembler \
--enable-thread-safe-client \
--with-mysqld-user=mysql \
--with-big-tables \
--without-debug \
--with-pthread \
--with-extra-charsets=complex \
--with-readline \
--with-ssl \
--with-embedded-server \
--enable-local-infile \
--with-plugins=partition,innobase \
--with-mysqld-ldflags=-all-static \
--with-client-ldflags=-all-static
```

```shell
cat x.log | bash
make && make install        # or use make -j 4 for a parallel multi-core build
ln -s /application/mysql5.1.72/ /application/mysql
```

## 2. Configuration File and Initialization

The configuration file templates are in the source directory
`mysql-5.1.72/support-files/`:

```shell
cp my-small.cnf /etc/my.cnf
mkdir -p /application/mysql/data
chown -R mysql.mysql /application/mysql/
/application/mysql/bin/mysql_install_db \
    --basedir=/application/mysql \
    --datadir=/application/mysql/data/ \
    --user=mysql                          # initialization
```

Register the service and enable it at boot:

```shell
cp /lamp/mysql-5.1.72/support-files/mysql.server /etc/init.d/mysqld   # startup script
chmod +x /etc/init.d/mysqld
chkconfig --add mysqld
chkconfig mysqld on
/etc/init.d/mysqld start
# Alternatively, start the service in the background with mysqld_safe:
/application/mysql/bin/mysqld_safe &
```

Add the client to PATH:

```shell
vim /etc/profile            # edit PATH
PATH=/application/mysql/bin:$PATH
. /etc/profile              # make it take effect
```

## 3. Login, Setting the Password, and Account Cleanup

```shell
/application/mysql/bin/mysql    # log in to MySQL
```

```sql
mysql> show databases;
+--------------------+
| Database           |
+--------------------+
| information_schema |
| mysql              |
| test               |
+--------------------+
3 rows in set (0.00 sec)
```

Set and change the root password:

```shell
/application/mysql/bin/mysqladmin -u root password '123456'
mysql -u root -p
/application/mysql/bin/mysqladmin -u root -p123456 password 123123
```

Clean up the extra accounts and refresh privileges:

```sql
select user,host from mysql.user;
drop user "root"@kaoshi.com;
flush privileges;    -- refresh privileges
```

## 4. PHP 5.3.27 Compilation and Installation

Install the dependency libraries:

```shell
yum install zlib libxml libjpeg freetype libpng gd curl libiconv \
    zlib-devel libxml2-devel libjpeg-devel freetype-devel libpng-devel \
    gd-devel curl-devel -y
yum install -y libxslt libxslt-devel libxml2 libxml2-devel
```

Compile libiconv first:

```shell
tar zxf libiconv-1.14.tar.gz
cd libiconv-1.14
./configure --prefix=/usr/local/libiconv
make
make install
cd ../
```

Compile PHP; the key is `--with-apxs2`, which builds the PHP module into
Apache:

```shell
./configure \
--prefix=/application/php5.3.27 \
--with-apxs2=/application/apache/bin/apxs \
--with-mysql=/application/mysql \
--with-xmlrpc \
--with-openssl \
--with-zlib \
--with-freetype-dir \
--with-gd \
--with-jpeg-dir \
--with-png-dir \
--with-iconv=/usr/local/libiconv \
--enable-short-tags \
--enable-sockets \
--enable-zend-multibyte \
--enable-soap \
--enable-mbstring \
--enable-static \
--enable-gd-native-ttf \
--with-curl \
--with-xsl \
--enable-ftp \
--with-libxml-dir
```

Seeing `Thank you for using PHP.` means configure succeeded:

```shell
make && make install
ln -s /application/php5.3.27/ /application/php
```

Confirm that Apache has loaded the PHP module:

```shell
ll /application/apache/modules/
-rw-r--r-- 1 root root     9115 4月  19 12:33 httpd.exp
-rwxr-xr-x 1 root root 29540885 4月  20 08:53 libphp5.so

grep libphp5 /application/apache/conf/httpd.conf
LoadModule php5_module        modules/libphp5.so
```

Choose and copy php.ini:

```shell
ls php.ini-*        # php.ini-development  php.ini-production
diff `ls php.ini-*` # compare
cp php.ini-production /application/php/lib/php.ini    # configuration file
```

## 5. Modifying httpd.conf to Integrate PHP

Edit `/application/apache/conf/httpd.conf`; the following changes are
involved (line numbers refer to the original file):

```apache
ServerName 127.0.0.1:80                              # line 100
AddType application/x-httpd-php .php .phtml          # line 311
AddType application/x-httpd-php-source .phps
User www                                             # line 65
Group www
<IfModule dir_module>
    DirectoryIndex index.php index.html              # line 168
</IfModule>
```

Create the www runtime user and restart Apache:

```shell
groupadd www
useradd -s /sbin/nologin -M -g www www
/application/apache/bin/apachectl restart
```

## 6. Test Pages

`hequan.php` verifies that PHP is being parsed:

```php
<?php
phpinfo();
?>
```

`index.php` verifies the database connection:

```php
<?php
//$link_id=mysql_connect('hostname','user','password');
$link_id=mysql_connect('localhost','root','oldboy123') or mysql_error();
if($link_id){
    echo "mysql successful by oldboy !";
}else{
    echo mysql_error();
}
?>
```
