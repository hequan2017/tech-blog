> **About this post**
>
> This post records the complete process of installing the Chinese man manual (manpages-zh 1.5.2) from source on Linux:
> downloading the archive with wget, extracting it with tar, configuring with ./configure --disable-zhtw,
> building and installing with make / make install, then appending
> `alias hman='man -M /usr/local/share/man/zh_CN'` to /etc/profile and running source to make it take effect. After that,
> the hman command shows Chinese man pages. The end of the post includes a full command sequence you can copy and run directly.

> **Technical notes**
>
> - The `pkgs.fedoraproject.org` download URL in this post is no longer valid; the project has moved to GitHub
>   (man-pages-zh/manpages-zh). Get the new source package from the Releases page.
> - Building from source is no longer necessary: on Debian/Ubuntu use `apt install manpages-zh`,
>   on RHEL/CentOS use `yum install man-pages-zh-CN`, then configure an alias or use
>   `man -L zh_CN.UTF-8`.

Reading the English ones is honestly a bit dizzying, so I found a Chinese man manual online and have organized it below.

## 1. Step-by-Step Installation

Download the file (you can also download it on Windows and transfer it to Linux with rz):

```bash
wget http://pkgs.fedoraproject.org/repo/pkgs/man-pages-zh-CN/manpages-zh-1.5.2.tar.bz2/cab232c7bb49b214c2f7ee44f7f35900/manpages-zh-1.5.2.tar.bz2
```

Extract the archive:

```bash
tar xvf manpages-zh-1.5.2.tar.bz2
cd manpages-zh-1.5.2
```

Build and install:

```bash
./configure --disable-zhtw
make
make install
```

## 2. Define the Alias and Make It Take Effect

Append an hman alias to /etc/profile, pointing to the Chinese manual directory:

```bash
echo "alias hman='man -M /usr/local/share/man/zh_CN'" >> /etc/profile
```

Make the system variables take effect:

```bash
source /etc/profile
```

Usage: `hman cp`
