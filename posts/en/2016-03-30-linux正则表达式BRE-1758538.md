> **About this post**
>
> This post organizes the symbols of Linux basic regular expressions (BRE) and
> extended regular expressions (ERE): the meanings of ^ $ . \ * [], [^], and
> \{n,m\}, plus the ERE operators + ? | (); it runs several hands-on examples
> with grep/sed/awk: extracting the IP and MAC addresses from ifconfig output,
> extracting permission bits from stat, and the sed backreference \1 syntax;
> it also collects quick references on echo -e, date formatting, tar backups
> named by date, deleting logs older than 7 days with find, the PATH
> environment variable, and locating commands with which/whereis/locate.

> **Technical notes**
>
> The commands and output are based on net-tools on CentOS 6: ifconfig is no
> longer installed by default on CentOS 7+, so use `ip addr` or `hostname -I`
> to get the IP; the BRE `\{n,m\}` is written as `{n,m}` under grep -E/ERE,
> while the usage of the sed backreference `\1` is unchanged to this day.

## 1. Introduction to Regular Expressions

A regular expression is a set of rules and methods for processing strings, working on text line by line; with the help of special symbols, specific strings can be filtered or replaced quickly.

Common tools: grep, sed, awk.

## 2. Basic Regular Expressions (BRE)

| Symbol | Meaning |
| --- | --- |
| `^word` | Starts with word |
| `word$` | Ends with word |
| `.` | Any single character |
| `\` | Escape character; cancels the special meaning of the original character |
| `*` | Repeats the preceding character 0 or more times |
| `.*` | Any number of any characters |
| `[character set]` | A character set; matches any one character in the set |
| `[^word]` | Matches any character not listed after the ^ |

Examples:

```shell
# grep "^I" hequan
# grep -i "^i" hequan            # case-insensitive
# grep -i ".$" hequan
# grep "li.e" hequan
# grep -n "\." hequan
# grep "490*448" hequan
49000000000000048,49448
# grep "49.*448" hequan
# grep ".*" hequan               # match all lines
# grep "^.*" hequan
# grep "h[ex]quan" hequan        # find hequan or hxquan
# grep "[^not boog]" hequan --color=auto
# grep -E "[^0-9|,]" hequan --color=auto
```

Contents of the test file hequan:

```text
I  am   hequan  linux   teacher.
I   like  chinese   chess, table  tennis.
111111111111111
49000000000000048,49448
```

Repetition counts `\{n,m\}` (repeat the preceding character n to m times):

```shell
# grep "490\{2,3\}" hequan          # repeat n to m times
# grep "490\{1,\}" hequan           # at least n times
# grep "490\{4\}" hequan --color=auto   # exactly n times
```

## 3. Extended Regular Expressions (ERE)

| Symbol | Meaning |
| --- | --- |
| `+` | Repeats the preceding character one or more times |
| `?` | Repeats the preceding character 0 or 1 time |
| `\|` | Matches multiple strings with OR |
| `()` | Finds "grouped" strings |

```shell
# egrep "490+" hequan
# grep -E "h(ex|equa)n" hequan
```

To locate the relevant section in the man pages: run `man grep` and type `/REGULAR` to search.

## 4. Extracting the IP and MAC with grep/sed/awk

```shell
# ifconfig eth0 | grep "inet addr" | cut -d ":" -f2 | cut -d " " -f1
192.168.10.10
# ifconfig eth0 | grep "inet addr" | awk -F ":" '{print $2}' | awk '{print $1}'
# ifconfig eth0 | grep "inet addr" | awk -F "[: ]" '{print $13}'
192.168.10.10
# ifconfig eth0 | grep "inet addr" | awk -F "[: ]+" '{print $4}'
# echo ---1:----2 | awk -F '[-:]+' '{print $3}'
2
# ifconfig eth0 | sed -n '2p'
```

awk field variables: `$1` is the first field, `$NF` the last field, `$0` the whole line; NF is the field count, NR the line number.

Extracting with sed substitution:

```shell
# ifconfig eth0 | sed -n '/inet addr/p'
# ifconfig eth0 | sed -n '/inet addr/p' | sed 's#^.*addr:##g'
# ifconfig eth0 | sed -n '/inet addr/p' | sed 's#^.*addr:##g' | sed 's#  Bc.*$##g'
# ifconfig eth0 | grep "HWaddr" | awk -F "[ ]+" '{print $5}'
00:0C:29:E1:35:13
```

`.*` combined with the backreference `\1`:

```shell
# ifconfig eth0 | sed -n 's#^.*addr:\(.*\)  Bcast.*$#\1#gp'
192.168.10.10
# ifconfig eth0 | sed -n 's#^.*HWaddr \(.*\)#\1#gp'
00:0C:29:E1:35:13
# sed 's#\(dd\) \(xx\)#\1#g' a.txt
dd
# ifconfig eth0 | sed -n 's#^.*dr:\(.*\)  Bcast:\(.*\)  Ma.*$#\1 \2#gp'
192.168.10.10 192.168.10.255
# ifconfig eth0 | sed -n 's#^.*HWaddr \(.*\)#\1#gp'
00:0C:29:E1:35:13
```

## 5. Extracting Permission Bits from stat

```shell
# stat /xx | sed -n 4p | awk -F "[/(]" '{print $2}'
0644
# stat /xx | head -4 | tail -1 | awk -F "[/(]" '{print $2}'
0644
# stat /xx | sed -n 's#^.*ess: (0\(.*\)/-.*$#\1#gp'
644
# stat /xx | sed -n 's#^.*(\(.*\)/-.*$#\1#gp'
0644
# stat /xx | sed -n '4p' | awk -F "[(/]" '{print $2}'
0644
```

Getting it directly with `stat -c`:

```shell
# stat -c %a /xx
644
# stat -c %A /xx
-rw-r--r--
# stat -c %B /xx
512
# stat -c %b /xx
0
```

Converting rwx- to 4210 and joining the sums (the parts are juxtaposed as string concatenation, yielding 644):

```shell
# ll /xx | cut -c 2-10 | tr rwx- 4210 | awk -F "" '{print $1+$2+$3 $4+$5+$6 $7+$8+$9}'
644
```

## 6. echo and date

```shell
# echo -n hequan;echo hequan          # no newline
hequanhequan
# echo -e "hequan\thequan"            # \t inserts a tab
hequan  hequan
# echo -e "hequan\nhequan"
hequan
hequan
# LANG=en
# date '+%y-%m-%d'
16-03-30
# date '+%Y-%m-%d'
2016-03-30
# date +%w
3
# date +%u
3
# echo `date +%F\ %T`
2016-03-30 17:06:52
# date +%F --date='3 day ago'
2016-03-24
```

## 7. tar Backups and Cleaning Old Logs with find

```shell
# tar zcvf /tmp/qwe2.tar.gz ./etc/
# tar zcvf /tmp/qwe-$(date +%F-%T).tar.gz ./etc/
# tar zcvf /tmp/qwe-$(date +%w).tar.gz ./etc/
# find /log -type f -name "*.log" -mtime +7 | xargs rm -f
# /usr/sbin/ntpdate
```

## 8. The PATH Environment Variable and Locating Commands

```shell
# echo $PATH
/usr/local/sbin:/usr/local/bin:/sbin:/bin:/usr/sbin:/usr/bin:/root/bin
# which ifconfig
/sbin/ifconfig
# export PATH=$PATH:$HOME/bin:/sbin
# echo $PATH
/usr/local/sbin:/usr/local/bin:/sbin:/bin:/usr/sbin:/usr/bin:/root/bin:/root/bin:/sbin
# vi /etc/profile
```

Several ways to locate commands: which, whereis, find, locate:

```shell
# locate -n 1 cp
# find / -name "cp"
```

Network configuration files:

```shell
# vi /etc/resolv.conf                            # DNS
# vi /etc/sysconfig/network-scripts/ifcfg-eth0   # NIC
# chmod 644 hequan
```
