> **About this post**
>
> This post uses the python-jenkins library to demonstrate driving Jenkins from a script: after connecting to the server, it first fetches the next build number of the test job and triggers a build with parameters (version, env); it then polls the number of the most recently completed build to determine whether the build has finished, continuously printing the build console output along the way; finally, it reads the build duration and compares the numbers of the most recently completed build and the most recent successful build, printing either "Build succeeded" or "Build failed".

> **Technical notes**
>
> python-jenkins can still be installed and used today, but the community has seen few updates in recent years, mostly limited to compatibility fixes. The practice of "disabling CSRF protection" in the original comments is outdated: modern Jenkins enables crumb validation by default, and python-jenkins, built on requests.Session, carries the crumb automatically, so there is no need to disable protection; authentication should also switch to an API Token instead of a plaintext username and password. Jenkins itself is still 2.x, but its runtime requirement has been raised to Java 17 or above. The "trigger — poll — fetch results" scripting approach remains applicable today.

## 1. Packaging and Building Code with Python and Jenkins

First install the dependency, then connect to Jenkins, trigger a build with parameters, poll until it finishes, and evaluate the result:

```python
# pip install python-jenkins

import jenkins
import pprint
import time

# Under Jenkins' "Configure Global Security", uncheck "Prevent Cross Site Request Forgery exploits"
server = jenkins.Jenkins('http://192.168.100.151:8081', username='admin', password='admin')

# ID of the next build
jenkins_next_build_number = server.get_job_info("test")['nextBuildNumber']

# Start a build  build_job(self, name, parameters=None, token=None)   parameters accepts extra arguments
server.build_job("test", parameters={'version': '1.0.2', "env": "test"})

time.sleep(10)

while True:
    time.sleep(1)
    if server.get_job_info("test")['lastCompletedBuild']['number'] == jenkins_next_build_number:
        print("-------------------构建完成-----------------------")
        break

    result = server.get_build_console_output("test", jenkins_next_build_number)
    print(result)

info = server.get_build_info("test", jenkins_next_build_number)
print(f"构建时间 {int(info['duration']) / 1000}秒")

if server.get_job_info("test")['lastCompletedBuild']['number'] == \
        server.get_job_info("test")['lastSuccessfulBuild']['number']:
    print("构建成功")
else:
    print("构建失败")
```
