## 1. Socket Introduction

A **socket** describes an IP address and port; it is a handle to a communication link, and applications usually send requests to the network, or answer network requests, through sockets.

The socket module performs **open, read/write, close** operations on server-side and client-side sockets.

## 2. A Simple Socket Interaction Example

### Server: receiving one message

```python
import socket  # standard library

ip_port = ('127.0.0.1', 9998)  ## declaration
sk = socket.socket()  ## create a handle
sk.bind(ip_port)
sk.listen(5)  ## listen
while True:
    print('server waiting...')
    conn, addr = sk.accept()  ## creates an instance from the client's IP and port, serving only this client
    ## the generated instance and address
    client_data = conn.recv(1024)  ## 1024 bytes
    print(str(client_data, 'utf8'))
    conn.sendall(bytes('不要回答,不要回答,不要回答', 'utf8'))
    conn.close()
```

### Client: sending one message

```python
import socket

ip_port = ('127.0.0.1', 9998)
sk = socket.socket()
sk.connect(ip_port)
sk.sendall(bytes('请求占领地球', 'utf8'))
server_reply = sk.recv(1024)
print(str(server_reply, 'utf8'))
sk.close()
```

## 3. Simulating ssh Command Execution

Key point: send the length of the result first, wait for the client's ack, then send the content — this solves the sticky-packet / cannot-send-it-all-in-one-go problem.

Server side:

```python
import socket
import os
import subprocess

server = socket.socket()  # get a socket instance
server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)

server.bind(("localhost", 9999))  # bind ip port
server.listen()  # start listening
while True:  # outer loop
    print("等待客户端的连接...")
    conn, addr = server.accept()  # accept and establish the connection with the client; the program blocks here until a client connects
    print("新连接:", addr)
    while True:
        data = conn.recv(1024)
        if not data:
            print("客户端断开了...")
            break  # breaking here goes back to the outer loop again
        print("收到命令:", data)
        # res = os.popen(data.decode()).read()  # in py3 sockets only send bytes, while os.popen only accepts str, so decode first
        res = subprocess.Popen(data, shell=True, stdout=subprocess.PIPE).stdout.read()  # same effect as the line above
        if len(res) == 0:
            res = "cmd exec success,has not output!".encode("utf-8")
        conn.send(str(len(res)).encode("utf-8"))  # before sending the data, tell the client how much data is coming
        print("等待客户ack应答...")
        client_final_ack = conn.recv(1024)  # wait for the client to respond
        print("客户应答:", client_final_ack.decode())
        print(type(res))
        conn.sendall(res)  # the sending side also has a max data-size limit, so sendall is used here — like calling conn.send in a loop until all data is sent
server.close()
```

Client side:

```python
import socket
import sys

client = socket.socket()

client.connect(("localhost", 9999))
while True:
    msg = input(">>:").strip()
    if len(msg) == 0:
        continue
    client.send(msg.encode("utf-8"))

    res_return_size = client.recv(1024)  # receive the size of this command's execution result
    print("getting cmd result , ", res_return_size)
    total_rece_size = int(res_return_size)
    print("total size:", res_return_size)
    client.send("准备好接收了,发吧loser".encode("utf-8"))
    received_size = 0  # data received so far
    cmd_res = b''
    f = open("test_copy.html", "wb")  # save the received result, to check later whether the data is correct
    while received_size != total_rece_size:  # means not finished receiving yet
        data = client.recv(1024)
        received_size += len(data)  # why not just add 1024, why check len? Note: the data actually received may be less than 1024
        cmd_res += data
    else:
        print("数据收完了", received_size)
        # print(cmd_res.decode())
        f.write(cmd_res)  # save the received result, to check later whether the data is correct
    # print(data.decode())  # the command's execution result
client.close()
```

## 4. Basic Socket Syntax

### Socket Families (address families)

```text
socket.AF_UNIX     Unix local inter-process communication
socket.AF_INET     IPv4 (most commonly used)
socket.AF_INET6    IPv6
```

### Socket Types

```text
socket.SOCK_STREAM    TCP
socket.SOCK_DGRAM     UDP
socket.SOCK_RAW       raw sockets
socket.SOCK_RDM       reliable UDP
```

### socket module functions

- `socket.socket(family=AF_INET, type=SOCK_STREAM, proto=0, fileno=None)`
- `socket.socketpair([family[, type[, proto]]])`
- `socket.create_connection(address[, timeout[, source_address]])`
- `socket.getaddrinfo(host, port, family=0, type=0, proto=0, flags=0)`: gets the address of the peer host to connect to

### Socket object methods

- **sk.bind(address)**: binds the socket to an address. The format of address depends on the address family; under AF_INET the address is given as a tuple (host, port)
- **sk.listen(backlog)**: starts listening for incoming connections. backlog specifies the maximum number of connections that may be queued before connections are refused
- **sk.setblocking(bool)**: whether to block (True by default). If set to False, accept and recv raise an error as soon as there is no data
- **sk.accept()**: accepts a connection and returns (conn, address), where conn is a new socket object that can be used to receive and send data, and address is the connecting client's address. Accepts TCP client connections (blocking), waiting for a connection to arrive
- **sk.connect(address)**: connects to the socket at address. address is usually a tuple (hostname, port); if the connection fails, a socket.error is raised
- **sk.connect_ex(address)**: same as above, but returns a value: 0 on success, or an error code on failure, e.g. 10061
- **sk.close()**: closes the socket
- **sk.recv(bufsize[, flag])**: receives data from the socket. The data is returned as bytes; bufsize specifies the **maximum** number of bytes to receive (e.g. 1024, 8192); flag provides extra information about the message and can usually be ignored
- **sk.recvfrom(bufsize[, flag])**: similar to recv(), but the return value is (data, address), where data is the string containing the received data and address is the address of the socket that sent it
- **sk.send(string[, flag])**: sends the data in string to the connected socket. The return value is the number of bytes sent, which may be smaller than the byte size of string — i.e. the specified content may not all get sent
- **sk.sendall(string[, flag])**: sends the data in string to the connected socket, but tries to send all of it before returning. Returns None on success and raises an exception on failure. Internally it calls send repeatedly to send all the content
- **sk.sendto(string[, flag], address)**: sends data to a socket; address is a tuple (ipaddr, port) specifying the remote address, and the return value is the number of bytes sent. This function is mainly used with the UDP protocol
- **sk.settimeout(timeout)**: sets a timeout for socket operations; timeout is a float in seconds, and a value of None means no timeout. The timeout should generally be set right after the socket is created, because it may be used for connect operations (e.g. a client connection waiting at most 5s)
- **sk.getpeername()**: returns the remote address of the connected socket; the return value is usually a tuple (ipaddr, port)
- **sk.getsockname()**: returns the socket's own address, usually a tuple (ipaddr, port)
- **sk.fileno()**: the socket's file descriptor

## 5. SocketServer Multithreading

Inheritance structure:

```text
+------------+
| BaseServer |
+------------+
      |
      v
+-----------+        +------------------+
| TCPServer |------->| UnixStreamServer |
+-----------+        +------------------+
      |
      v
+-----------+        +--------------------+
| UDPServer |------->| UnixDatagramServer |
+-----------+        +--------------------+
```

Available server types:

- `class socketserver.ForkingTCPServer`
- `class socketserver.ForkingUDPServer`
- `class socketserver.ThreadingTCPServer`
- `class socketserver.ThreadingUDPServer`

**Example**

Server side (ThreadingTCPServer + BaseRequestHandler):

```python
import socketserver


class MyTCPHandler(socketserver.BaseRequestHandler):
    """
    The request handler class for our server.
    It is instantiated once per connection to the server, and must
    override the handle() method to implement communication to the
    client.
    """
    def handle(self):
        # self.request is the TCP socket connected to the client
        self.data = self.request.recv(1024).strip()
        print("{} wrote:".format(self.client_address[0]))
        print(self.data)
        # just send back the same data, but upper-cased
        self.request.sendall(self.data.upper())


if __name__ == "__main__":
    HOST, PORT = "localhost", 9999
    # Create the server, binding to localhost on port 9999
    server = socketserver.ThreadingTCPServer((HOST, PORT), MyTCPHandler)
    # Activate the server; this will keep running until you
    # interrupt the program with Ctrl-C
    server.serve_forever()
```

Client side:

```python
import socket
import sys

HOST, PORT = "localhost", 9999
data = " ".join(sys.argv[1:])
# Create a socket (SOCK_STREAM means a TCP socket)
sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
try:
    # Connect to server and send data
    sock.connect((HOST, PORT))
    sock.sendall(bytes(data + "\n", "utf-8"))
    # Receive data from the server and shut down
    received = str(sock.recv(1024), "utf-8")
finally:
    sock.close()

print("Sent:     {}".format(data))
print("Received: {}".format(received))
```

## 6. Exception Handling

- **isinstance(obj, cls)**: checks whether an object is an instance of class cls
- **issubclass(sub, super)**: checks whether class sub is a derived class (subclass) of class super

### Exception basics

```python
while True:
    num1 = input('num1:')
    num2 = input('num2:')
    try:
        num1 = int(num1)
        num2 = int(num2)
        result = num1 + num2
    except Exception as e:  ## the universal exception; catches all exceptions
        print('出现异常，信息如下：')
        print(e)
    pass
```

### Common errors

```text
AttributeError      trying to access an attribute an object does not have, e.g. foo.x, but foo has no attribute x
IOError             input/output exception; basically means a file cannot be opened
ImportError         a module or package cannot be imported; basically a path problem or a wrong name
IndentationError    a syntax error (its subclass); the code is not properly aligned
IndexError          a subscript is out of the sequence's range, e.g. x has only three elements but x[5] is accessed
KeyError            trying to access a key that does not exist in a dictionary
KeyboardInterrupt   Ctrl+C was pressed
NameError           using a variable that has not been assigned to an object yet
SyntaxError         illegal Python code; the code cannot compile (personally I think this is a syntax error, i.e. written wrong)
TypeError           the type of the object passed in does not match what is required
UnboundLocalError   trying to access a local variable that has not been set yet, usually because a global variable
                    with the same name exists, making you think you are accessing it
ValueError          passing a value the caller does not expect, even though the value's type is correct
```

### Custom exceptions

```python
class WupeiqiException(Exception):

try:
    raise WupeiqiException('我的异常')
```

### Other exception structure

```python
try:
    # main code block
    pass
except KeyError as e:
    # executed when an exception occurs
    pass
else:
    # executed after the main code block finishes
    pass
finally:
    # executed no matter whether an exception occurred
    pass
```
