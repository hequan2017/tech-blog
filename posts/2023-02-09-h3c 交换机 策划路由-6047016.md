> **内容介绍**
>
> 本文是 H3C 交换机策略路由（PBR）配置笔记：在 Vlan-interface2 上
> 应用名为 aaa 的策略，通过高级 ACL 3000 匹配指定源网段的流量，
> 命中后将其下一跳强制指向 192.168.1.1，实现按策略分流转发。
>
> **技术备注**
>
> 以上为 H3C Comware 风格命令：`ip address ... sub` 表示从地址
> （Cisco 用 `secondary`）；ACL 3000 为高级 ACL；策略路由在接口下以
> `ip policy-based-route` 调用，命中 `if-match acl` 的流量按
> `apply next-hop` 转发（Cisco 对应 `route-map` + `ip policy route-map`）。

---

```shell
interface Vlan-interface2
ip address x.x.x.x 255.255.255.0
ip address 192.168.1.2 255.255.255.252 sub
ip policy-based-route aaa
#

acl number 3000
rule 0 permit ip source x.x.x.x 0.0.0.255
#

policy-based-route aaa permit node 2
if-match acl 3000
apply next-hop 192.168.1.1
#
```
