> **内容介绍**
>
> 本文记录在 CentOS 7 / RHEL 7 下把一致性网卡名（eno/ens）改回传统 eth0 的完整步骤：
> 编辑 /etc/default/grub 追加 net.ifnames=0 biosdevname=0 并用 grub2-mkconfig 重新
> 生成配置、把 ifcfg-enoxxxxxx 改名为 ifcfg-eth0、编写 udev 规则把 MAC 绑定到 eth0
> 后重启生效；文末另附阿里云 yum 源替换、systemctl 服务管理、firewalld 停用等
> 系统初始化常用命令。

> **技术备注**
>
> CentOS 7 已于 2024 年 6 月 30 日停止维护(EOL),建议迁移至 Rocky Linux 9 / AlmaLinux 9 或国产 openEuler。
> 补充:`net.ifnames=0 biosdevname=0` 只是让内核回归传统命名,RHEL 8/9 及替代发行版
> 仍默认一致性命名,新环境建议直接适配 ens33 等名称而非改回 eth0;RHEL 9 起网卡配置
> 推荐 NetworkManager keyfile(/etc/NetworkManager/system-connections/)。

---

## 1. 禁用可预测命名规则

编辑 grub 配置,在 `GRUB_CMDLINE_LINUX` 中添加 `net.ifnames=0 biosdevname=0`:

```ini
# vim /etc/default/grub
GRUB_TIMEOUT=5
GRUB_DEFAULT=saved
GRUB_DISABLE_SUBMENU=true
GRUB_TERMINAL_OUTPUT="console"
GRUB_CMDLINE_LINUX="rd.lvm.lv=centos/root rd.lvm.lv=centos/swap net.ifnames=0 biosdevname=0 rhgb quiet"
GRUB_DISABLE_RECOVERY="true"
```

重新生成 grub 配置:

```shell
grub2-mkconfig -o /boot/grub2/grub.cfg
```

输出如下:

```text
Generating grub configuration file ...
Found linux image: /boot/vmlinuz-3.10.0-229.el7.x86_64
Found initrd image: /boot/initramfs-3.10.0-229.el7.x86_64.img
Found linux image: /boot/vmlinuz-0-rescue-a8ecfd39a4014521ae54ccef4ada1c67
Found initrd image: /boot/initramfs-0-rescue-a8ecfd39a4014521ae54ccef4ada1c67.img
done
```

## 2. 修改网卡配置文件

```shell
cd /etc/sysconfig/network-scripts/
mv ifcfg-enoxxxxxx ifcfg-eth0
```

## 3. 修改设备对应名称

```shell
# vim /etc/udev/rules.d/70-persistent-ipoib.rules
```

```text
SUBSYSTEM=="net", ACTION=="add", DRIVERS=="?*", ATTR{address}=="00:0c:29:e0:17:54", ATTR{type}=="1", KERNEL=="eth*", NAME="eth0"
```

## 4. 重启系统即可

## 5. 附:更换阿里云 yum 源

```shell
mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.backup
wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.aliyun.com/repo/Centos-7.repo
yum clean all
yum makecache
```

## 6. 附:systemctl 与基础工具

```shell
systemctl 动作 服务名.service   # 服务管理通用格式
yum -y install net-tools        # 安装后可用 ifconfig 等传统命令
```

## 7. 附:firewall 与 iptables

CentOS 7.0 默认使用的是 firewall 作为防火墙,这里改为 iptables 防火墙。

```shell
systemctl start firewalld.service    # 启动 firewall
systemctl stop firewalld.service     # 停止 firewall
systemctl disable firewalld.service  # 禁止 firewall 开机启动
```
