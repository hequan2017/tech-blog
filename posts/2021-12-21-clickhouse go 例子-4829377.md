> **内容介绍**
>
> 用 Go 查询 ClickHouse 的最小示例：基于 `mailru/dbr` 查询构造器，配合 HTTP 驱动 `mailru/go-clickhouse` 打开连接（`http://name:password@host:8123/db`），通过 `Select(...).From(...).Where(...)` 构造查询并 `Load` 到结构体切片，最后循环打印结果。

> **技术备注**
>
> 示例使用的 `mailru/go-clickhouse`（HTTP 驱动）仓库已归档不再维护，目前官方推荐的 Go 客户端是 `github.com/ClickHouse/clickhouse-go`（v2），同时支持 Native(TCP) 与 HTTP 协议，新项目建议直接迁移。原文 import 路径被截断，实际应为 `github.com/mailru/dbr` 与 `github.com/mailru/go-clickhouse`，已在文中修正；原代码最后一处 `log.Printf` 语句在抓取时损坏（缺闭合引号与参数），也已补全。

---

```go
package main

import (
  "fmt"
  "log"

  "github.com/mailru/dbr"
  _ "github.com/mailru/go-clickhouse"
)

func main() {
  connect, err := dbr.Open("clickhouse", "http://name:password@192.168.1.2:8123/test", nil)
  if err != nil {
    log.Fatal(err)
  }
  type items struct {
    Test string `json:"test" db:"test"`
  }
  var it []items
  sess := connect.NewSession(nil)

  _, err = sess.Select("test").From("test").Where("test = ?", "test").Load(&it)
  if err != nil {
    fmt.Println(err)
    return
  }

  for _, item := range it {
    log.Printf("test: %s", item.Test)
  }
}
```
