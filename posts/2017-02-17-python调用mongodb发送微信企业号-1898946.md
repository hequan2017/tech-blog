> **内容介绍**
>
> 一个 Python 2 小工具：先从 MongoDB 集合中取出第一条记录的两个字段拼成文本消息，再调用微信企业号接口（gettoken + message/send）推送给指定成员。封装了一个 `Weixin` 类，包含获取 access_token 和发送文本消息两个方法。

> **技术备注**
>
> 代码是 Python 2 语法（`print` 语句、`except Exception, e`、`sys.setdefaultencoding`），Python 2 已于 2020 年 1 月停止维护，迁移到 Python 3 需改为 `print()` 函数和 `except ... as` 语法。另外"微信企业号"已升级为"企业微信"，接口域名与部分参数（如 agentid 类型）有变化，请对照企业微信最新文档调整。
