> **内容介绍**
>
> 本文在 CentOS 6.5 上部署 NFS：安装 rpcbind 与 nfs-utils、先启 rpcbind
> 再启 nfs 并用 rpcinfo 检查端口注册；配置 /etc/exports 把 /data 共享给
> 192.168.10.0/24，用 exportfs 平滑重载、showmount 查看、客户端
> mount -t nfs 挂载；分析 nfsnobody（UID 65534）、root_squash/
> all_squash、anonuid/anongid 等参数与统一 UID 的做法；末尾比较 fstab
> 与 rc.local 两种开机自动挂载方式，并附救援模式只读重挂载命令。

> **技术备注**
>
> CentOS 6 已于 2020 年 11 月停止维护（EOL），生产环境建议迁移至
> Rocky Linux / AlmaLinux / Ubuntu LTS。补充：CentOS 7+ 服务管理改用
> `systemctl start nfs-server`；NFSv4 只需 2049 端口，对 rpcbind 的
> 依赖与本文的 v3/v4 混合场景不同，showmount/exportfs 用法不变。

## 1. 环境与软件安装

```shell
# cat /etc/centos-release
CentOS release 6.5 (Final)
# uname -r
2.6.32-431.el6.x86_64
# uname -m
x86_64
# ls /lib/modules/2.6.32-431.el6.x86_64/kernel/fs/
```

Network File System：内核自带文件系统模块支持（上面 fs 目录里还能看到
xfs 等模块）。

安装（nfs-utils 提供 rc.nfsd、rpc.mountd，rpcbind 负责端口注册）：

```shell
# rpm -qa rpcbind nfs-utils
# yum groupinstall "NFS file server" -y
# yum -y install rpcbind nfs-utils
```

先启动 rpcbind，再启动 nfs：


## 3. 配置共享并挂载

```shell
# vi /etc/exports
# nfs shared data by hequan at 20160403
/data      192.168.10.0/24(rw,sync)
```

平滑重载与查看：

```shell
# /etc/init.d/nfs reload          # 平滑重启，等价 /usr/sbin/exportfs -r
# showmount -e localhost
Export list for localhost:
/data 192.168.10.0/24
```

客户端挂载，并给共享目录加本地写权限：

```shell
# mount -t nfs 192.168.10.10:/data /mnt     # 挂载
# chmod o+w /data                          # 共享目录的本地权限
-rw-r--r-- 1 nfsnobody nfsnobody 0 Mar 27 22:31 xx
```

命令速查（可用 man 进程名查详情）：

- /etc/exports：NFS 配置文件
- /usr/sbin/exportfs：NFS 管理命令，`-rv` 加载配置生效，等价优雅重启，
  直接共享目录
- /usr/sbin/showmount：查看 NFS 配置及挂载结果
- /var/lib/nfs/etab：完整默认参数
- mount：查看挂载信息

```shell
# mount
192.168.10.10:/data on /mnt type nfs (rw,vers=4,addr=192.168.10.10,clientaddr=192.168.10.11)
```

## 5. exports 常用参数

格式：绝对路径 + 客户端（参数）。共享三要素：绝对路径、共享目录的本地
权限（nfsnobody）、客户端网段 192.168.10.0/24。

- rw / ro：读写 / 只读
- sync 同步 / async 异步：异步快（先写到内存），但不可靠，是性能与
  可靠性的取舍
- root_squash：把 root 映射成匿名用户
- all_squash：把所有客户端用户都压缩成匿名用户（65534），确保所有
  服务器对 NFS 共享目录具备相同的权限
- anonuid / anongid：匿名用户映射目标，所有客户端和服务端都需要有
  相同的 UID 和 GID（nfsnobody 的 UID）

统一 UID 示例——两端都建立相同 UID 的用户：

```shell
# useradd hequan -u 555
```

```shell
# vim /etc/exports
/data    192.168.10.0/24(rw,sync,all_squash,anonuid=555,anongid=555)
# mount 192.168.10.10:/data /mnt
```

## 7. 开机自动挂载

将挂载信息写入 fstab：

```shell
# vi /etc/fstab
192.168.10.10:/data /mnt/ nfs defaults 0 0
```

保存退出后：

```shell
# mount -a
```

或写入 rc.local：

```shell
# vi /etc/rc.local
/etc/init.d/rpcbind start
/bin/mount -t nfs 192.168.10.10:/data /mnt
```

开机流程：开机自检加载 BIOS → 读取 MBR → BOOT Loader → 加载 kernel
内核 → init 进程 → init 进程执行 rc.sysinit → 启动内核模块 → 执行
不同运行级别的脚本程序。

不建议在 fstab 里加载网络 NFS 文件（网络未就绪会卡住启动），自动挂载
见下一篇 autofs。

## 8. 救援模式

维护模式或者救援模式下文件系统只读：

```shell
# mount -o rw,remount /       # 重新挂载成可写
```
