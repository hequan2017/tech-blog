> **内容介绍**
>
> 在 Linux（CentOS）上用 yum 安装 Go 并配置开发环境的笔记：设置 GOPATH、开启 GO111MODULE、配置国内代理 GOPROXY，以及通过 git clone 镜像方式补齐 golang.org/x 下的 sys/net/text/tools/crypto 等常用依赖包。
>
> **技术备注**
>
> 内容已明显过时：Go 1.16 起模块默认开启，`GO111MODULE=on` 无需再设；goproxy.io 可用但更推荐 `https://goproxy.cn,direct`；有了 Go Modules 后不再需要手动 clone golang.org/x 各仓库到 GOPATH，`go mod tidy` 会自动拉取。yum 源的 go 版本通常很旧，建议从 go.dev 下载官方二进制安装。

---

安装 Go 并配置环境变量：

```shell
yum install go -y

mkdir -p /data/go
echo export GO111MODULE=on >> /etc/profile
echo export GOPATH=/data/go >> /etc/profile
echo export GOPROXY=https://goproxy.io >> /etc/profile
source /etc/profile
```

补齐 golang.org/x 常用包（Go Modules 时代已不需要）：

```shell
git clone https://github.com/golang/sys.git $GOPATH/src/github.com/golang/sys
git clone https://github.com/golang/net.git $GOPATH/src/github.com/golang/net
git clone https://github.com/golang/text.git $GOPATH/src/github.com/golang/text
git clone https://github.com/golang/lint.git $GOPATH/src/github.com/golang/lint
git clone https://github.com/golang/tools.git $GOPATH/src/github.com/golang/tools
git clone https://github.com/golang/crypto.git $GOPATH/src/github.com/golang/crypto
git clone https://github.com/golang/sync.git $GOPATH/src/github.com/golang/sync
git clone https://github.com/golang/time.git $GOPATH/src/github.com/golang/time
git clone https://github.com/golang/image.git $GOPATH/src/github.com/golang/image

mkdir -p $GOPATH/src/golang.org
ln -s $GOPATH/src/github.com/golang/ $GOPATH/src/golang.org/x
```
