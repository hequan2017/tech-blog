> **内容介绍**
>
> CentOS 7 下搭建 NFS 共享存储的服务端与客户端配置：安装 rpcbind/nfs-utils、写 /etc/exports 共享 /data、systemctl 启服务并用 exportfs 热加载；客户端 showmount 查看、mount 挂载并写入 /etc/fstab；最后通过 idmapd.conf 统一 Domain 避免文件属主变成 nobody。

> **技术备注**
>
> NFS 本身至今通用，但有两个环境差异：CentOS 7 已 EOL，RHEL 8+/Rocky 8+ 上服务名改为 `nfs-server`（rpcbind 仍保留）；`no_root_squash` 有安全风险，生产建议改为 `root_squash` 并配合固定 uid/gid。挂载超时、锁问题在容器/K8s 场景一般改用 CSI 驱动（如 nfs-subdir-external-provisioner）。

---

服务器客户端

```shell
yum -y install rpcbind nfs-utils
```

服务器

```shell
vim /etc/exports
/data  192.168.10.0/24(rw,sync,no_root_squash)
* ro # 只读权限
* rw # 读写权限
* sync # 同步，数据更安全，速度慢
* async #异步，速度快，效率高，安全性低
```

```shell
systemctl enable nfs-server
systemctl enable rpcbind
systemctl  start nfs-server
systemctl   start rpcbind.service

exportfs

chmod o+w  /data

exportfs -v
/data           192.168.10.0/24(rw,async,wdelay,hide,no_subtree_check,sec=sys,secure,root_squash,no_all_squash)
```

常用选项

```shell
* -a：全部卸载或全部挂载
* -r：重新挂载
* -u：卸载某个目录
* -v：显示共享目录
* 常用组合：exportfs -arv
* 服务端更改配置文件后，不重启服务，直接执行该命令就可以使更改后的配置文件生效。
注意： 在重启nfs服务之前需要先将所有挂载点卸载，否则将发生程序错误，严重者会拖垮系统
```

客户端

```shell
yum -y install  rpcbind nfs-utils
systemctl   start rpcbind.service

showmount -e  192.168.10.100

mount    192.168.10.100:/data /data1

vim /etc/fstab
192.168.10.100:/data    /data  nfs   rw
```

服务器客户端   # 使创建者 创建完之后，为创建者的用户。

```shell
vim /etc/idmapd.conf
5 Domain =

systemctl restart rpcbind.service
```
