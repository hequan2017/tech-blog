> **内容介绍**
>
> 本文记录一个可嵌入 Jenkins 构建流程的钉钉审批脚本：构建时先向钉钉群
> 机器人发送 actionCard 消息（带“同意/拒绝”两个按钮），再轮询本地 go
> 服务读取点击结果，审批通过则继续执行后续构建，审批失败则不执行；
> 文末附接收回调并返回审批结果的 go/gin 服务示例。

> **技术备注**
>
> 按钮的 actionURL 与轮询地址都指向 localhost:8080，go 服务需与脚本同机
> 部署：钉钉自定义机器人只把消息展示到群里，点击按钮仅跳转该 URL，不会
> 自动回传审批结果；且脚本在“拒绝”时只 echo 后正常退出（无非零退出码），
> 接入 Jenkins 时需自行依据结果决定构建成败。钉钉后来强制自定义机器人
> 配置安全设置（自定义关键词/加签/IP 白名单），webhook 需相应适配。
> 这类构建前人工卡点，Jenkins pipeline 现在更常用 `input` 步骤实现。

## 1. 钉钉审批脚本（可接入 Jenkins）

获取钉钉审批脚本，可以接入到 jenkins 中：在 jenkins 构建过程中，先使用此
脚本，其中 actionURL 可以用 golang 起个端口服务，解析 url 参数，最后判断
脚本审批失败，则不触发后续构建，审批成功，则触发后续构建。

```shell
#!/bin/bash
if [ $# != 2 ];then
    echo "参数不对";
    exit 1
fi

title=$1
text=$2
# 钉钉机器人Webhook地址
webhook_url="https://oapi.dingtalk.com/robot/send?access_token=钉钉token"

# 请求体
data='{
    "msgtype": "actionCard",
    "actionCard": {
        "title": "20'"$title"'",
        "text":  "'"$text"'",
        "hideAvatar": "0",
        "btnOrientation": "0",
        "btns": [
            {
                "title": "同意",
                "actionURL": "http://localhost:8080/request?action=agree&text='"$text"'"
            },
            {
                "title": "拒绝",
                "actionURL": "http://localhost:8080/request?action=reject&text='"$text"'"
            }
        ]
    }
}'

# 发送消息
curl -sS ${webhook_url} \
    -H 'Content-Type: application/json' \
    -d "${data}" > /dev/null

# 模拟轮询读取审批结果，最多轮询 1000 次
for i in {1..1000}; do
    approve_url="http://localhost:8080/recent"
    result=$(curl -s $approve_url)
    if [ "$result" == "agree" ]; then
        echo "审批已通过"
        break
    elif [ "$result" == "reject" ]; then
        echo "审批已拒绝"
        break
    fi

    sleep 5
done

if [ $i -eq 1000 ]; then
    echo "轮询超时，请检查审批进度。"
fi
```

> 注：`title` 字段里的 `20` 前缀为原文原样。

## 2. go 示例：解析审批回调

> 注：原文将 go 示例以 `#` 注释形式内嵌在同一代码块中，此处还原为独立的
> go 代码块，并补全被吃掉的 `github.com` 导入前缀。

```go
package main

import (
	"net/http"
	"strconv"

	"github.com/gin-gonic/gin"
)

func main() {
	r := gin.Default()

	var recent string

	r.GET("/request", func(c *gin.Context) {
		action := c.Query("action")
		text := c.Query("text")

		recent = "action=" + action + "&text=" + text

		c.JSON(http.StatusOK, gin.H{
			"action": action,
			"text":   text,
		})
	})

	r.GET("/recent", func(c *gin.Context) {
		// 转义字符串中的特殊字符
		quoted := strconv.QuoteToASCII(recent)

		var content string
		if recent == "" {
			content = "No recent visit"
		} else {
			content = quoted[1 : len(quoted)-1] // 去掉转义后字符串外围的引号
		}

		// 修改响应头使其返回纯文本
		c.Header("Content-Type", "text/plain; charset=utf-8")
		c.String(http.StatusOK, content)
	})

	r.Run()
}
```
