> **内容介绍**
>
> 在 Gin 框架中接入 casbin 实现 RBAC 权限控制的完整示例：定义 rbac_model.conf 模型，启动时从数据库加载策略（而非使用 casbin adapter），再通过 Gin 中间件对每个请求的 sub/obj/act 做 Enforce 判断。依赖注入部分沿用 facebookgo/inject 组装 Enforcer 与业务对象。
>
> **技术备注**
>
> 文中示例基于早期 casbin（v1/v2 时代），当前 casbin v2 的 `NewEnforcer`、`AddPolicy` API 仍兼容，但 `EnforceSafe` 已不推荐，建议直接使用 `Enforce`。casbin 现已归属 casbin 组织，完整示例项目路径应为 `github.com/hequan2017/go-admin`。

### go  gin+casbin RBAC 简单例子

#### 说明

> 详情可以查看作者的项目：https://github.com/hequan2017/go-admin

利用的库：

- github.com/casbin/casbin
- github.com/gin-gonic/gin
- github.com/facebookgo/inject

casbin 文档：https://casbin.org/zh-CN/

下面例子未使用 casbin 的 adapter，而是在启动时先初始化，然后通过数据库里的对应关系动态加载所有权限条目；再通过中间件去判断，如果有更新，可以动态修改更新权限条目。

##### 代码

rbac_model.conf：

```ini
[request_definition]
r = sub, obj, act

[policy_definition]
p = sub, obj, act

[role_definition]
g = _, _

[policy_effect]
e = some(where (p.eft == allow))

[matchers]
m = g(r.sub, p.sub) == true \
    && keyMatch2(r.obj, p.obj) == true \
    && regexMatch(r.act, p.act) == true
```

b_auth.go：

```go
package bll

// gin-allin/models 为自己的项目 请忽略
import (
   "gin-allin/models"
   "github.com/casbin/casbin"
)

//models.Auth  为 User表     实际可以写成自己的USER 表
type Role struct {
   Role      *models.Auth     `inject:""`
   Enforcer  *casbin.Enforcer `inject:""`
}

// LoadPolicy 加载角色权限策略,
func (a *Role) LoadPolicy(roleID string) error {
   a.Enforcer.AddPolicy(roleID, "/api/v1/auth_info","GET")
   return nil
}
```

b_common.go 与 inject.go：

```go
package bll

// 把权限表注入到 Common
type Common struct {
   Role   *Role    `inject:""`
}
```

inject.go：

```go
package inject

import (
   "gin-allin/bll"
   "github.com/casbin/casbin"
   "github.com/facebookgo/inject"
   "os"
)

// Object 注入对象
type Object struct {
   Common     *bll.Common
   Enforcer   *casbin.Enforcer
}

// Init 初始化依赖注入
func Init() *Object {
   g := new(inject.Graph)

   // 注入casbin
   dir, _ := os.Getwd()
   path := dir + "\\src\\gin-allin\\conf\\rbac_model.conf"
   enforcer := casbin.NewEnforcer(path, false)
   _ = g.Provide(&inject.Object{Value: enforcer})

   //  注入Common  也就是 Role
   Common := new(bll.Common)
   _ = g.Provide(&inject.Object{Value: Common})

   if err := g.Populate(); err != nil {
      panic("初始化依赖注入发生错误：" + err.Error())
   }

   // 返回 注入完的对象
   return &Object{
      Enforcer:  enforcer,
      Common :Common,
   }
}

package casb

import (
   "gin-allin/inject"
   "github.com/gin-gonic/gin"
   "net/http"
)

// 权限判断
func CasbinMiddleware(obj *inject.Object) gin.HandlerFunc {
   return func(c *gin.Context) {

      // 判断   权限 是否为 true
      if b, err := obj.Enforcer.EnforceSafe("hequan", c.Request.URL.Path, c.Request.Method); err != nil {
         c.JSON(http.StatusUnauthorized, gin.H{
            "code": "权限 判断错误",
            "msg":  "权限 判断错误",
            "data": "权限 判断错误",
         })
         c.Abort()
         return
      } else if !b {

         c.JSON(http.StatusUnauthorized, gin.H{
            "code": "没有权限",
            "msg":  "没有权限",
            "data": "没有权限",
         })
         c.Abort()
         return
      }
      c.Next()
   }
}

package routers

func InitRouter() *gin.Engine {
   // 生成对象
   obj := inject.Init()

   err := loadCasbinPolicyData(obj)

   if err != nil {
      panic("加载casbin策略数据发生错误：" + err.Error())
   }

   apiv1.Use(casb.CasbinMiddleware(obj))
}

// 加载casbin策略数据   加载 hequan  的一个权限
func loadCasbinPolicyData(obj *inject.Object) error {
   err := obj.Common.Role.LoadPolicy("hequan")
   if err != nil {
      fmt.Println(err)
      return err
   }
   return nil
}
```

#### 结果

当用户 `hequan` 访问 `/api/v1/auth_info` 时，会去判断是否有 GET 权限，有就通过，没有就拒绝。

测试时可以把用户名改成其他的再重新启动，此时中间件判断不通过，就会返回拒绝。
