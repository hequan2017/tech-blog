> **内容介绍**
>
> 本文是 PHP 缓存加速优化系列第一篇(上):先给出 LAMP(Apache 2.2.27 + MySQL 5.1.72 +
> PHP 5.3.27)与 LNMP(nginx 1.6.3 + MySQL 5.5.32 + PHP 5.5.32)的实验环境,以及查看
> 各组件编译参数的命令(apachectl -V、config.nice、mysqlbug、php -i、nginx -V);随后
> 演示用 phpize 编译安装 eaccelerator 与 xcache 两款 PHP opcode 缓存加速模块(二者

>

## 1. 环境说明与版本查看

php web 引擎缓存加速优化,基础 web 环境准备。

### LAMP

环境:CentOS 6.5_64 + Apache/2.2.27 (Unix) + MySQL 5.1.72 + PHP 5.3.27。

```shell
/application/apache/bin/apachectl -V
```

```text
Server version: Apache/2.2.27 (Unix)
```

```shell
cat /application/apache/build/config.nice       # 查看 Apache 编译参数
grep CONFIGURE /application/mysql/bin/mysqlbug  # 查看 MySQL 编译参数
/application/php/bin/php -i | grep configure    # 查看 PHP 编译参数
```

### LNMP

环境:CentOS 6.5_64 + nginx/1.6.3 + MySQL 5.5.32 + PHP 5.5.32。

```shell
# /application/nginx/sbin/nginx -V
```

```text
nginx version: nginx/1.6.3
```

## 2. 安装 eaccelerator 缓存加速模块

eaccelerator-0.9.6,缓存优化加速:

```shell
tar jxf eaccelerator-0.9.6.tar.bz2
cd eaccelerator-0.9.6

/application/php/bin/phpize     # 建立 php 的外挂模块

./configure --enable-eaccelerator=shared \
    --with-php-config=/application/php/bin/php-config

make && make install

ls /application/php5.3.27/lib/php/extensions/no-debug-zts-20090626/
```

## 3. 安装 xcache 缓存加速模块

xcache-1.3.2,PHP opcode 缓存器,效果更好,和 eaccelerator 二选一:

```shell
tar jxf xcache-1.3.2.tar.bz2
cd xcache-1.3.2

/application/php/bin/phpize

./configure --enable-xcache \
    --with-php-config=/application/php/bin/php-config

make && make install

ls /application/php5.3.27/lib/php/extensions/no-debug-non-zts-20090626/
```

## 4. 两个扩展目录的区别

```shell
ls /application/php5.3.27/lib/php/extensions/no-debug-zts-20090626/         # ===== apache
ls /application/php5.3.27/lib/php/extensions/no-debug-non-zts-20090626/     # ===== nginx
```

## 5. 缓存加速器种类

常见 PHP 缓存加速器按效果排序:**xcache > eaccelerator**,此外还有 Zend、apc。
