> **内容介绍**
>
> 在 CentOS 7 GPU 服务器上安装 NVIDIA 驱动的命令操作记录：
> 先卸载旧内核、禁用 nouveau 并重建 initramfs，重启后确认禁用生效；
> 再安装与运行内核一致的 kernel-devel 及 gcc 编译环境；
> 最后以 runfile 方式安装 550.107.02 驱动，用 nvidia-smi 验证结果。

> **技术备注**
>
> CentOS 7 已于 2024 年 6 月 30 日停止维护(EOL),建议迁移至 Rocky Linux 9 / AlmaLinux 9 或国产 openEuler。
>
> - nouveau 是内核自带的开源显卡驱动,与 NVIDIA 闭源驱动互斥,须先写入 blacklist、`dracut --force` 重建 initramfs 并重启,才能彻底禁用。
> - kernel-devel 版本须与当前运行内核一致(可用 `uname -r` 核对),否则编译 nvidia 内核模块会失败。
> - `-no-x-check -no-nouveau-check -no-opengl-files` 分别用于跳过 X 服务、nouveau 与 OpenGL 检查,适合无图形界面的服务器。
> - `nvidia-smi` 表头的 CUDA Version 是该驱动支持的最高 CUDA 运行时版本,不代表宿主机已安装 CUDA Toolkit。

## 1. 卸载旧内核并禁用 nouveau

```shell
# 卸载旧的
sudo rpm -e kernel-5.15.13-1.x86_64
sudo rpm -e kernel-devel-5.15.13-1.x86_64
grub2-mkconfig -o /boot/efi/EFI/centos/grub.cfg
grub2-mkconfig -o /boot/grub2/grub.cfg
sed -i 's/GRUB_CMDLINE_LINUX="/&net.ifnames=0 biosdevname=0 /' /etc/sysconfig/grub
sudo grub2-set-default 0

lsmod | grep nouveau  # 查看是否安装了 nouveau
sudo vim /etc/modprobe.d/blacklist-nouveau.conf
# 创建并编辑该文档，并在文档内添加以下内容：
blacklist nouveau
options nouveau modeset=0

sudo dracut --force  # 强制写入
reboot  # 为避免内核异常，请重启实例
lsmod | grep nouveau  # 验证是否成功禁用
```

## 2. 安装内核开发环境

```shell
yum clean all
yum makecache

yum install kernel-devel-3.10.0-1160.71.1.el7* gcc -y
ls /boot | grep vmlinu
rpm -aq | grep kernel-devel  # 验证内核版本和源码版本是否一致，一致请执行下一步。
```

## 3. 安装 GPU 驱动并验证

```shell
# 若未下载 GPU 驱动，请先完成下载
sudo chmod 777 NVIDIA-Linux-x86_64-550.107.02.run  # 赋权
sh NVIDIA-Linux-x86_64-550.107.02.run -no-x-check -no-nouveau-check -no-opengl-files
nvidia-smi  # 验证安装是否成功
```
