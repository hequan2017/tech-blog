> **内容介绍**
>
> 记录 Nacos 1.4.1 之前版本在开启 `nacos.core.auth.enabled=true` 后仍可通过伪造 User-Agent 绕过鉴权的问题，给出 1.4.1 的修复配置：关闭 `userAgentAuthWhite` 并设置服务端身份标识 `server.identity.key/value`，最后补充 Go SDK 在开启鉴权后需要携带用户名密码的示例。

> **技术备注**
>
> 该漏洞对应 Nacos CVE-2021-29442，官方在 1.4.1 中修复；当前生产环境建议直接升级到 2.x 最新稳定版并开启鉴权。`nacos-sdk-go` 的 import 路径原文被截断，实际应为 `github.com/nacos-group/nacos-sdk-go/...`。

### Nacos 1.4.1 之前存在鉴权漏洞，建议修复到最新版

```shell
nacos .core.auth.enabled=true

开启鉴权得情况下，添加请求参数，可以获取到信息
```

![postman 测试 nacos 未授权访问,伪造请求头绕过鉴权](assets/2602035/01_853a7df2365959872502b32175ffc262.png)

### 1.4.1

```shell
nacos .core.auth.enabled=true

### Since 1.4.1, Turn on/off white auth for user-agent: nacos-server, only for upgrade from old version.
nacos.core.auth.enable.userAgentAuthWhite=false

### Since 1.4.1, worked when nacos.core.auth.enabled=true and nacos.core.auth.enable.userAgentAuthWhite=false.
### The two properties is the white list for auth and used by identity the request from other server.
nacos.core.auth.server.identity.key=aaa
nacos.core.auth.server.identity.value=bbb

请求url得时候 带上

key :         value
```

### sdk-go

> 需要添加 用户密码，才能获取到信息

```go
package main

import (
	"fmt"

	"github.com/nacos-group/nacos-sdk-go/clients"
	"github.com/nacos-group/nacos-sdk-go/common/constant"
	"github.com/nacos-group/nacos-sdk-go/vo"
)

func main()  {

	clientConfig := constant.ClientConfig{

		TimeoutMs:           5000,
		NotLoadCacheAtStart: true,
		RotateTime:          "1h",
		MaxAge:              3,
		LogLevel:            "debug",
		Username:			"nacos",
		Password:			"nacos",
	}

	// 至少一个ServerConfig
	serverConfigs := []constant.ServerConfig{
		{
			IpAddr:      "192.168.100.100",
			ContextPath: "/nacos",
			Port:        8848,
			Scheme:      "http",
		},
	}
	// 创建动态配置客户端的另一种方式 (推荐)
	configClient, _ := clients.NewConfigClient(
		vo.NacosClientParam{
			ClientConfig:  &clientConfig,
			ServerConfigs: serverConfigs,
		},
	)
	content, _ := configClient.GetConfig(vo.ConfigParam{
		DataId: "1",
		Group:  "DEFAULT_GROUP"})

	fmt.Println(content)

}
```
