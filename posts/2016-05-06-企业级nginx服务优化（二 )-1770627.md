> **内容介绍**
>
> 本文是系列第二篇:讲 nginx 的 gzip 压缩(gzip_min_length、gzip_buffers、
> gzip_comp_level、gzip_types、gzip_vary 等参数含义)与 expires 客户端缓存(图片

## 1. 配置 nginx gzip 压缩功能

```nginx
gzip on;
gzip_min_length 1k;        # 大于 1K 才压缩
gzip_buffers 4 32k;        # 压缩缓存区大小
gzip_http_version 1.1;
gzip_comp_level 9;         # 压缩比率 1-9
gzip_types text/css text/xml application/javascript;   # 压缩类型,不同版本类型不一样
gzip_vary on;              # vary header 支持
```

## 5. nginx expires 缓存功能

指定资源在客户端本地保存多久,写在 server 标签里:

```nginx
location ~ .*\.(gif|jpg|jpeg|png|bmp|swf)$ {
    expires 3650d;
}

location ~ .*\.(js|css)?$ {
    expires 30d;
}
```

实例——robots.txt 缓存 7 天并记录 404:

```nginx
location ~(robots.txt) {
    log_not_found off;
    expires 7d;
    break;
}
```

## 6. Apache mod_expires 以 DSO 方式编译

```shell
./configure --enable-expires

cd /httpd-2.2.22/modules/metadata/    # 切到 apache 软件目录

/application/apache/bin/apxs -c -i -a mod_expires.c   # 以 DSO 的方式编译进 apache

ll /application/apache2.2.22/modules/mod_expires.so   # 检查
```

## 7. robots.txt 与禁止爬虫 UA

写一个这样的文件(<http://www.51cto.com/robots.txt>):

```text
User-agent: *
Crawl-delay: 500
Disallow: /wuyou/
Disallow: /php/
Disallow: /wuyou_admin/
Disallow: /actions/
```

修改 nginx.conf,禁止网络爬虫的 UA,返回 403:

```nginx
server {
    listen 80;
    server_name 127.0.0.1;

    # 添加如下内容即可防止爬虫
    if ($http_user_agent ~* "qihoobot|Baiduspider|Googlebot|Googlebot-Mobile|Googlebot-Image|Mediapartners-Google|Adsbot-Google|Feedfetcher-Google|Yahoo! Slurp|Yahoo! Slurp China|YoudaoBot|Sosospider|Sogou spider|Sogou web spider|MSNBot|ia_archiver|Tomato Bot")
    {
        return 403;    # 也可以把上面改成浏览器,禁止浏览器访问
    }
}
```

## 8. nginx 日志切割

```shell
# cut_nginx_log.sh
cd /application/nginx/logs && \
/bin/mv www_access.log www_access_$(date +%F -d -1day).log
/application/nginx/sbin/nginx -s reload
```

```shell
crontab -e
00 00 * * * /bin/sh /server/scripts/cut_nginx_log.sh >/dev/null 2>&1
```

syslog 日志分析配合使用。

## 9. 不记录不需要的访问日志

```nginx
location ~ .*\.(js|jpg|JPG|jpeg|JPEG|css|bmp|gif|GIF)$ {
    access_log off;
}
```

```text

```

## 10. 最小化 Apache 目录及文件权限

- 所有站点目录的用户和组都应为 root
- 所有目录权限是 755
- 所有文件权限是 644
- 网站服务的用户不能用 root

## 11. 限制 IP 访问

```nginx

    deny all;
}
```

## 13. tmpfs 内存文件系统
