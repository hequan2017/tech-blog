> **内容介绍**
>
> 把 Tomcat 9 的连接器从默认 NIO 切换到 APR（Apache Portable Runtime）模式的操作笔记：先编译 apr / apr-iconv / apr-util，再编译 tomcat 自带的 tomcat-native，最后把 server.xml 的 Connector protocol 改为 `org.apache.coyote.http11.Http11AprProtocol`，并给出线程数、压缩等参数配置示例。

> **技术备注**
>
> APR 是 Tomcat 8.5 之前的“高性能首选”，但从 Tomcat 8.5 起 NIO/NIO2 已足够优秀，官方甚至移除了 BIO，APR 只在极少数场景才需要单独编译。文中 wget 的镜像地址（apache 镜像站）已失效，请改用 https://archive.apache.org 或官方 dlcdn。配置里的 `maxThreads/acceptCount` 等参数在 Tomcat 9/10 仍沿用，注意 Tomcat 10 的 Servlet 包名从 `javax.servlet` 迁移到 `jakarta.servlet`。

---

Tomcat支持三种接收请求的处理方式：BIO、NIO、APR 。

```shell
1. BIO由于每个请求都要创建一个线程来处理，线程开销比较大，不能再高并发的场景，性能也是最低的。
2. NIO是一个基于缓冲区、并能提供非阻塞I/O操作的Java API，比传统的bio更好的并发性能。
3. APR（Apache Portable Run-time libraries）简单理解，就是从操作系统级别解决异步IO问题，大幅度的提高服务器的处理和响应性能， 也是Tomcat运行高并发应用的首选模式。
```

所需软件

```shell
* apr
* apr-iconv
* apr-util
* tomcat-native
```

---

### 安装软件

```shell
yum install -y apr-devel openssl-devel gcc make expat-devel libtool
```

```shell
cd /usr/local/src
wget  https://archive.apache.org/dist/apr/apr-1.6.3.tar.gz

tar xf apr-1.6.3.tar.gz
cd apr-1.6.3/
./configure --prefix=/usr/local/apr
make && make install

cd /usr/local/src
wget https://archive.apache.org/dist/apr/apr-iconv-1.2.2.tar.gz
tar xf apr-iconv-1.2.2.tar.gz
cd apr-iconv-1.2.2/
./configure   --with-apr=/usr/local/apr  --prefix=/usr/local/apr-iconv
make && make install

cd /usr/local/src
wget  https://archive.apache.org/dist/apr/apr-util-1.6.1.tar.gz
tar xf apr-util-1.6.1.tar.gz
cd apr-util-1.6.1/
./configure --prefix=/usr/local/apr-util  --with-apr=/usr/local/apr   --with-apr-iconv=/usr/local/apr-iconv/bin/apriconv
make && make install

cd /usr/local/tomcat/bin/
tar xf tomcat-native.tar.gz
cd  /usr/local/tomcat/bin/tomcat-native-1.2.16-src/native

./configure --with-apr=/usr/local/apr  --with-java-home=/usr/local/jdk8.0
make && make install

echo 'export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/usr/local/apr/lib
export LD_RUN_PATH=$LD_RUN_PATH:/usr/local/apr/lib' >> /etc/profile

source /etc/profile
```

### 修改配置

```html
vim /usr/local/tomcat/conf/server.xml

<Connector      port="80"        protocol="org.apache.coyote.http11.Http11AprProtocol"
                maxThreads="1000"
                minSpareThreads="100"
                acceptCount="900"
                disableUploadTimeout="true"
                connectionTimeout="20000"
                URIEncoding="UTF-8"
                enableLookups="false"
                redirectPort="8443"
                compression="on"
                compressionMinSize="1024"
               />


<!-- Define an AJP 1.3 Connector on port 8009 -->  ##注释掉下面那行，如果不用apache
<!-- <Connector port="8009" protocol="AJP/1.3" redirectPort="8443" />  -->
```
