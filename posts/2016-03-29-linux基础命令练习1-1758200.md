## 1. 只列出目录的 N 种写法

```shell
ls -l | grep "^d"              # 按首字符过滤
ls -Fl | grep "/$"             # -F 给目录加 / 后缀再过滤
ls -l | sed -n '/^d/p'
ls -l | awk '/^d/'
ls -lF | sed -n '/\/$/p'
find . -type d ! -name "."
find . -type d ! -name "." -prune
tree -Ld 1                     # 只显示目录,深度 1
```

> 经验：当一个命令的输出含有我们想要的内容时，先想想这个命令本身
> 是否有参数可以直接显示（如 `tree -L` / `ls -F`），而不是一味过滤。

## 2. 过滤注释与空行

```shell
cat /etc/ssh/sshd_config | grep -v ^#          # 去掉注释行
grep -Ev "^#|^$" /etc/ssh/sshd_config          # 同时去掉注释和空行(-E 使 | 表示"或")
grep -v -e "^#" -e "^$" /etc/ssh/sshd_config   # 不用 -E 时的等价写法
grep -Ev "^#|^$" /etc/inittab
```

正则要点：

- `[^xx]` 匹配**不包括** xx 的字符
- `^$` 匹配空行
- `\` 转义特殊字符

## 3. 常用查看与翻页

```shell
cat -n file            # 显示行号
more / less file       # 翻页查看; vim 里 :set nu 显示行号, :set nonu 取消
ll -lrt /etc/          # 按修改时间倒序排列(最近修改的排最后)
grep hequan --color=auto 1.txt   # 匹配内容高亮
cd -                   # 回到上一次所在目录
```

## 4. 打包与压缩

```shell
tar zcvf /tmp/etc.tar.gz /etc/                    # 打包压缩
tar tf etc.tar.gz                                 # 查看包内容
tar vxf hequan.tar.gz -C /tmp/                    # 解包到指定目录
tar zcfv hequan.tar.gz --exclude=/etc/ssh /etc/   # 排除某目录
tar zcvfX hequan.tar.gz a.txt /etc/               # 按 a.txt 清单打包
tar jcvf xx.tar.bz2 /etc/                         # bzip2 压缩
tar jxvf xx.tar.bz2                               # bzip2 解压
# -N 日期 可做增量打包
```

## 5. 文本处理组合

```shell
awk '{print $3 " " $6}' hequan.txt               # 取第 3、6 列
cut -c 6-12,21- hequan.txt                        # 按字符区间切割
sed 's#,##g' hequan.txt | awk '{print $3" "$6}'   # 先把 , 换空格再取列
cut -d ":" -f1 /etc/passwd                        # 按 : 取第 1 列
# cut: -d 指定分隔符, -f 选列, -c 按字符切割
```

## 6. 统计行数

```shell
wc -l hequan.txt
cat -n /etc/services | tail -1                    # 取最大行号(原文 tail -l 为笔误)
sed -n '$=' /etc/services
awk '{print NR}' /etc/services | tail -1
```

## 7. 进程查看

```shell
ps -ef
ps -ef | grep sshd
ps -ef | grep sshd | wc -l
ps -ef | grep -v grep | grep sshd     # 排除 grep 自身
```

## 8. 其他零散命令

```shell
runlevel                                # 查看运行级别
ls /etc/rc.d/rc3.d/ | grep sshd         # 查看 sshd 启动脚本
vi /etc/sysconfig/i18n                  # 配置语言(CentOS 6)
source /etc/profile                     # 使别名/变量立即生效
echo / source / export                  # 变量相关命令
ln 源文件 目标文件                       # 创建硬链接
ln -s 源文件 目标文件                    # 创建软链接(原文表述有误)
find ./ -type f -name "*.log" -mtime +7 | xargs rm -f   # 清理 7 天前日志
for n in `seq 100`; do sleep 1; echo $n >> /var/log/messages; done   # 模拟写日志
```
