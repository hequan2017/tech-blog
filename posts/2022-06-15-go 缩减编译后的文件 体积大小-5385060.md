> **内容介绍**
>
> 本文记录缩减 Go 编译后二进制体积的做法：go build 时用
> -ldflags "-s -w" 去掉符号与调试信息，再用 upx 对可执行文件
> 再次压缩，最后 tar 打包归档。

> **技术备注**
>
> `-s` 去掉符号表、`-w` 去掉 DWARF 调试信息，均为 Go 链接器参数，
> 可单独或叠加使用；裁剪后无法再用 gdb/delve 做源码级调试。
> upx 压缩率高，可进一步大幅减小体积，但加壳后的程序容易被杀毒
> 软件误报，且运行时需先解压，有轻微启动开销。

---

go build 编译程序时可以通过 -ldflags 来指定编译参数，`-s` 的作用是
去掉符号信息，`-w` 的作用是去掉调试信息。

```shell
go build -ldflags "-s -w" main.go
```

再次压缩：

```shell
upx main
```

最后进行压缩：

```shell
tar zcvf main.tar.gz main
```
