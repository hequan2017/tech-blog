```
go build 编译程序时可以通过 -ldflags 来指定编译参数。

-s 的作用是去掉符号信息。 -w    作用是去掉调试信息。

go build  -ldflags "-s -w"   main.go
```

```
upx   main
##再次压缩 

最后进行压缩

tar zcvf   main.tar.gz  main
```
