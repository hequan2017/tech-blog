> **内容介绍**
>
> 本文讲 Linux 定时任务：先区分程序与进程（前台/后台、守护进程，ps -ef
> 与 netstat -lntup 查看）；用 while+sleep 脚本实现 crond 做不到的秒级
> 任务；梳理系统自带的 /etc/cron.* 目录、logrotate、at 与 anacron 的分工；
> 详解 crontab 分/时/日/月/周字段、-u/-l/-e/-r 参数与 /etc/crontab 格式；
> 最后归纳生产书写规范——输出重定向 /dev/null 2>&1、% 需转义、任务脚本化、
> 指定用户执行、先测试再上线，以及 sendmail 邮件积压问题。

> **技术备注**
>
> 文中环境为 CentOS 6。CentOS 7+ 中服务管理改用 systemctl（如
> `systemctl enable --now crond`），chkconfig 仅剩兼容；crontab 里 %
> 会被解释为换行，date 格式串中的 % 必须写成 \%，这一点至今容易踩坑。

## 1. 程序与进程

程序是静态的代码，进程是现在系统正在执行的程序，每个进程有唯一的数字
进程 ID，分前台与后台：

```shell
# ps -ef | grep sshd
```

系统网络服务在后台常驻（守护进程）：

```shell
# netstat -lntup | grep sshd          # 守护进程与端口
```

## 2. 秒级定时任务

crond 只能精确到分钟，秒级任务用 while + sleep 实现：

```bash
#!/bin/bash
while true
do
    echo hequan >> /tmp/a.log
    sleep 1
done
```

```shell
# sh xx. &
[1] 1844
# ps -ef | grep xx.
# kill 1844
```

## 3. 系统自身的定时任务

```shell
# chkconfig --list | grep 3:on
# ll /var/log/messages
# cat /etc/logrotate.conf
# ll /etc/ | grep cron --color=auto
-rw-------.  1 root root    541 11月 23 2013 anacrontab
drwxr-xr-x.  2 root root   4096 3月  27 18:47 cron.d
drwxr-xr-x.  2 root root   4096 3月  27 18:48 cron.daily
-rw-------.  1 root root      0 11月 23 2013 cron.deny
drwxr-xr-x.  2 root root   4096 3月  27 18:47 cron.hourly
drwxr-xr-x.  2 root root   4096 3月  27 18:48 cron.monthly
-rw-r--r--.  1 root root     457 9月  27 2011 crontab
drwxr-xr-x.  2 root root   4096 9月  27 2011 cron.weekly
```

三种定时机制：

1. at：执行一次（`chkconfig --list atd`）
2. anacron：适合非 7*24 开机的服务器
3. crond：每分钟检查是否有需要执行的任务

crond 是后台守护进程，crontab 是用来设置定时任务规则的命令：

- -u 指定用户
- -l 查看
- -e 编辑
- -r 删除
- -i 确认

用户执行的定时任务存放在 /var/spool/cron/ 下：

```shell
# crontab -e
# cat /var/spool/cron/root
# cat /etc/cron.deny
# crontab -l
/usr/sbin/ntpdate     >>/dev/null 2>&1
```

## 4. crontab 字段与 /etc/crontab

```ini
SHELL=/bin/bash
PATH=/sbin:/bin:/usr/sbin:/usr/bin
MAILTO=root
HOME=/

# For details see man 4 crontabs
# Example of job definition:
# .---------------- minute (0 - 59)
# |  .------------- hour (0 - 23)
# |  |  .---------- day of month (1 - 31)
# |  |  |  .------- month (1 - 12) OR jan,feb,mar,apr ...
# |  |  |  |  .---- day of week (0 - 6) (Sunday=0 or 7) OR sun,mon,tue,wed,thu,fri,sat
# |  |  |  |  |
# *  *  *  *  * user-name command to be executed
```

分 时 日 月 周 命令（0 是周日）。周和日尽量不要同时用。

常用示例：

```text
00 23 * * *                        # 每天 23:00
00 17-19 * * *                     # 每天 17、18、19 点整执行
*/10 * * * *                       # 每 10 分钟
10 1 * * 6,0                       # 每周六、周日 01:10
00 */1 * * *                       # 每小时
00 9,14 * * *   /bin/sh /root/x > /dev/null 2>&1
* * * * *       echo hequan >> /root/hequan.txt
*/1 * * * *     /bin/echo "+" >> /hequan.log
```

date 取值验证：

```shell
# date +%T
14:15:15
# date +%F
2016-03-31
# date +%F%T
2016-03-3115:40:05
# date +%Y%m%d
20160331
```

## 5. 生产环境书写规范

- 专业、规范
- `/dev/null 2>&1` 等价于 `1>/dev/null 2>/dev/null`，把标准输出和标准
  错误都定向到空，避免产生垃圾输出
- 命令行操作成功是定时任务可以成功的大前提
- 命令放定时任务时，时间里的 % 需要转义（crontab 中 % 有特殊含义）
- 定时任务用脚本文件，不要直接写长命令
- 在指定用户的身份下执行相关的定时任务
- 任务程序不要随意打印输出信息
- 脚本要写注释（如 `#/bin/sh` 与描述），路径要规范，如 /server/scripts
- 先在测试环境下测试，然后正式环境规范部署，防止出错
- 定时任务执行时会给系统发邮件（sendmail），临时存放在
  /var/spool/clientmqueue/；CentOS 6 没装 sendmail 时更要注意屏蔽输出

```shell
# rpm -qa | grep sendmail
```

脚本示例：

```bash
# cat /server/scripts/tar_html.sh
cd /var/www
tar zcvf /tmp/html_$(date +%F).tar.gz ./html/
```

```text
00 */2 * * *  /bin/sh /server/scripts/tar.sh >/dev/null 2>&1
* 00 * * *   /bin/sh /server/scripts/tar_html.sh >/dev/null 2>&1
```

```shell
# tar zcvf /tmp/services_$(date +%F-%H) ./services
# cat /var/log/cron      # 定时任务日志
# df -lk
```

## 6. 复习速查

相关文件与知识点：

- /etc/sysctl.conf：内核优化
- /etc/hosts：本地解析
- /var/log/secure：登录安全
- 正则表达式：`.` 任意一个字符、`*` 重复前面的字符 N 次、
  `{n,m}` 重复 n-m 次、`[^t]` 非 t
- `chmod -R 755 xx`、`chown -R root:xx xx`
- umask 遮罩权限：666-022、777-022
- `groupadd -g 801 sa`
