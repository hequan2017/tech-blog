> **内容介绍**
>
> 介绍 Go 中用 facebookgo/inject 库实现依赖注入的思路：通过 struct tag `inject:""` 标记依赖字段，借助 `inject.Graph` 注册对象并自动完成赋值，避免手动逐层组装组件。文中给出 DBEngine → UserDB → UserService → App 四层依赖链的完整例子。

> **技术备注**
>
> facebookgo/inject 所属的 facebookgo 系列仓库已归档停止维护（约 2020 年起），新项目不建议引入。现代 Go 的替代方案：编译期生成代码的 google/wire、运行时容器式的 uber/fx，或最直接的手写构造函数逐层组装。基于反射与 struct tag 的注入错误只能在运行时暴露，依赖规模变大后不易排查。

### go 依赖注入

#### 说明

> 软件构建的核心就是管理复杂度。 —— 《Code Complete》

依赖注入的目的是解耦组件之间的依赖关系，避免手动配置每个组件的依赖关系。

#### 库

利用库 `github.com/facebookgo/inject`

#### 例子

```go
package main

import (
	"fmt"

	"github.com/facebookgo/inject"
)

type DBEngine struct {
	Name string
}

type UserDB struct {
	Db *DBEngine `inject:""`
}

type UserService struct {
	Db *UserDB `inject:""`
}

type App struct {
	Name string
	User *UserService `inject:""`
}

func (a *App) Create() string {
	return "create app, in db name:" + a.User.Db.Db.Name + " app name :" + a.Name
}

type Object struct {
	App *App
}

func Init() *Object {
	db := DBEngine{Name: "db1"}
	var g inject.Graph
	app := App{Name: "go-app"}

	_ = g.Provide(
		&inject.Object{Value: &app},
		&inject.Object{Value: &db},
	)
	_ = g.Populate()
	return &Object{
		App: &app,
	}

}

func main() {
	obj := Init()
	fmt.Println(obj.App.Create())
}
```

#### 打印结果

```text
create app, in db name:db1 app name :go-app
```
