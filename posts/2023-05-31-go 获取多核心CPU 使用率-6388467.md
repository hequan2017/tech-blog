> **内容介绍**
>
> 本文演示用 Go 的 gopsutil 库采集多核心 CPU 使用率。
> 程序先用 cpu.Counts 拿到逻辑 CPU 数，再在无限循环中调用
> cpu.Percent 按核心采样，逐个打印每颗核心的使用率。
>
> **技术备注**
>
> - gopsutil 是跨平台的系统信息采集库，Linux 下 CPU 数据来自 /proc/stat。
> - `cpu.Counts(true)` 返回逻辑 CPU 数，与 `cpu.Percent(interval, true)` 返回的切片一一对应；若要物理核心数应改用 `Counts(false)`。
> - `cpu.Percent` 传入正的 interval 会阻塞该时长完成一次采样，加上循环里的 `time.Sleep`，实际每轮约 2×interval；改用 `cpu.Percent(0, true)` 则非阻塞，返回自上次调用以来的均值。
> - 新版 gopsutil v3 的导入路径为 `github.com/shirou/gopsutil/v3/cpu`。

---

```go
package main

import (
	"fmt"
	"log"
	"time"

	"github.com/shirou/gopsutil/cpu"
)

func main() {
	// 获取CPU核心数
	cpuCount, err := cpu.Counts(true)
	if err != nil {
		log.Fatal("Failed to get CPU core count:", err)
	}

	// 设置采集的间隔时间
	interval := time.Second

	for {
		// 采集每个核心的CPU使用率
		cpuPercent, err := cpu.Percent(interval, true)
		if err != nil {
			log.Println("Failed to get CPU usage:", err)
			continue
		}

		// 显示每个核心的使用率
		for i := 0; i < cpuCount; i++ {
			fmt.Printf("CPU Core %d Usage: %.2f%%\n", i, cpuPercent[i])
		}

		fmt.Println("------------------")

		// 等待一段时间
		time.Sleep(interval)
	}
}
```
