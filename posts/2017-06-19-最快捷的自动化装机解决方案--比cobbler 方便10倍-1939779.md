> **技术备注**
>
> 原文命令 `ipmitool pass power reset` 中 `pass` 为笔误,已修正为标准写法

给大家推荐一个自动化装机的解决方案，非常简单。

使用的为云霁科技的 CloudBoot 云启装机平台。实测使用过，安装简单，使用方便，在这里安利一下。以下是装机平台的图，详情可去官网查看。

## 1. 安装原理

安装包已经打包好了，直接 rpm 安装，简单设置即可，原理也是 PXE 装机。

被安装的服务器需要安装 ipmitool，然后设置下一次 PXE 启动，就能 DHCP 找到主机开始安装：

```bash
yum install OpenIPMI ipmitool
/etc/init.d/ipmi start
lsmod | grep ipmi_devintf || insmod /lib/modules/`uname -r`/kernel/drivers/char/ipmi/ipmi_devintf.ko
/etc/init.d/ipmi restart

ipmitool chassis bootdev pxe
ipmitool chassis power reset
```

## 2. 产品特色

1. 服务器上架加电后，无需人工干预，实现从硬件配置、操作系统安装、主机名 IP 配置等完全闭环的自动化。
2. 支持主流 X86 服务器的硬件配置功能（包括 RAID/OOB/BIOS 等），联合国内硬件厂商整合，支持主流的服务器品牌。
3. 基于标准的 IPMI 接口通过带外对服务器进行控制安装。
4. 支持企业级操作系统的自动化安装配置，包括 RedHat/CentOS/Windows/Ubuntu/SUSE/VMware/XenServer/OpenStack 等；自带简易的 CMDB，可用于资产管理。
5. 基于 x86 服务器构建了一套轻量级的 KVM 虚拟机管理系统，同时也能很好地支持 VMware、VirtualBox、KVM、Xen 等虚拟化平台部署操作系统。
6. 支持一键安装部署，一分钟时间搞定一周的工作。
7. 支持在线或者离线升级，也灵活地允许用户自定义配置。
8. 完全免费开源，支持二次开发。
