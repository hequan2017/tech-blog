## 2. 路由系统 URL

```text
a. /index/                           ->  函数或类
b. /index/(\d+)                      ->  函数或类
c. /index/(?P<nid>\d+)               ->  函数或类
d. /index/(?P<nid>\d+)  name='root'  ->  函数或类
   reverse()
   {% url 'root' 1 %}
e. /crm/   include('app01.urls')     ->  路由分发
```


## 6. 模板:母版与自定义标签

- 母版 ...html:extends、include
- 自定义函数

simple_tag:

```python
from django import template
from django.utils.safestring import mark_safe

register = template.Library()

@register.simple_tag
def u():
    return 123

@register.simple_tag
def func(a1, a2, a3, ...):
    return "asdfasd"
```

步骤:a. app 下创建 templatetags 目录;b. 任意 xxoo.py 文件;c. 创建 template
对象 register;d. 如上注册函数;e. settings 中注册 APP;f. 顶部 {% load xxoo %};
g. 使用 {% 函数名 arg1 arg2 %}。

- 缺点:不能作为 if 条件
- 优点:参数任意

filter:

```python
@register.filter
def func(a1, a2):
    return "asdfasd"
```

步骤同上,使用 `{{ 参数1|函数名:"参数二,参数三" }}`、`{{ 参数1|函数名:数字 }}`。

- 缺点:最多两个参数,不能加空格
- 优点:能作为 if 条件

分页(自定义的分页)。XSS:

```python
{{ page_str|safe }}
mark_safe(page_str)
```
