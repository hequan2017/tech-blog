> **内容介绍**
>
> 解决源码编译安装 Python 3.7 后运行报错 `error while loading shared libraries: libpython3.7m.so.1.0: cannot open shared object file` 的问题：动态链接器找不到编译出来的共享库，把库文件拷到系统库目录即可。

> **技术备注**
>
> 除文中直接拷贝 `.so` 到 `/usr/lib64` 的做法外，更规范的方式是编译时加 `--enable-shared --prefix=/usr/local`，安装后执行 `echo /usr/local/lib >> /etc/ld.so.conf.d/python3.conf && ldconfig` 刷新缓存。Python 3.7 已于 2023 年 6 月停止安全更新，新环境请使用 3.10+。

---

```text
python3.7: error while loading shared libraries: libpython3.7m.so.1.0: cannot open shared object file: No such file or directory
```

解决办法:

进入源码包目录，把编译出来的共享库文件拷贝到系统库目录：

```shell
[root@stack Python-3.7.0]# cp libpython3.7m.so.1.0 /usr/lib64/
```

（原文中被脱敏的库文件名应为 `libpython3.7m.so.1.0`；拷贝后如仍报错可执行 `ldconfig` 刷新链接缓存。）
