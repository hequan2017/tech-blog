> **内容介绍**
>
> 本文是 rsync daemon 模式的进阶实战笔记:服务的启动、进程查看与写入
> /etc/rc.local 实现开机自启;客户端用 --exclude={1,2}、--exclude-from 排除多个
> 文件,服务端在 /etc/rsyncd.conf 中用 exclude 参数排除后重启服务;重点演示
> --delete 无差异同步的危险性与两个方向——推送时"本地有什么,服务器有什么",
> 代码发布/下载时"远端有啥本地有啥,远端没有的本地也删除";最后给出 timeout
> 超时参数与 /var/log/rsyncd.log 日志这两个排错线索。

> **技术备注**
>
> 文中环境为 CentOS 6（rsync 3.0.6）,已于 2020 年 11 月停止维护（EOL）;该系统
> 上服务自启依赖 /etc/rc.local,新发行版应改用 systemd unit。--delete 属破坏性
> 参数,建议先加 -n（--dry-run）预演确认;改服务端配置后需 pkill rsync 再
> rsync --daemon 重启,新系统中对应 systemctl restart rsyncd。

## 1. 服务启动与开机自启

```shell
rsync --daemon
ps -ef | grep rsync
echo "/usr/bin/rsync --daemon" >> /etc/rc.local
```

## 2. 排除同步

客户端排除（排除多个文件）:

```shell
rsync -avz /data/ --exclude={1,2} \
    rsync_backup@192.168.10.10::hequan --password-file=/etc/rsync.password
```

从文件读取排除列表:

```text
--exclude-from=排除的文件
```

服务端排除（/etc/rsyncd.conf 中配置）:

```shell
vi /etc/rsyncd.conf
```

```ini
exclude = 1 2 3
```

修改配置后重启服务:

```shell
pkill rsync
rsync --daemon
```

## 3. 无差异同步 --delete（危险）

无差异同步,超级危险,做备份时尤其要小心:

推送方向——本地有什么,服务器有什么（会清空服务器端多余文件,注意）:

```shell
rsync -avz /data/ rsync_backup@192.168.10.10::hequan \
    --password-file=/etc/rsync.password --delete
```

代码发布、下载方向——远端有啥,本地有啥,远端没有的本地也删除:

```shell
rsync -avz rsync_backup@192.168.10.10::hequan /data/ \
    --password-file=/etc/rsync.password --delete
```

## 4. 超时与日志

- `timeout = 400`:rsyncd.conf 中的超时配置,防止客户端异常导致服务端无限等待
- `/var/log/rsyncd.log`:rsync 服务日志,出问题先看这里
