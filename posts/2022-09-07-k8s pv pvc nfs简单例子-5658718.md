> **内容介绍**
>
> 本文讲解 Kubernetes 中使用 NFS 作为持久化存储的完整流程：在存储节点安装 nfs-utils 并配置 /etc/exports，各节点通过 showmount 验证后挂载共享目录，最后给出 PV、PVC 与 Pod 的 YAML 示例，演示静态供给方式。
>
> **技术备注**
>
> 文中 PV 使用 `hostPath` 类型，仅适合单节点测试；生产环境应改用 `nfs` 卷类型或配合 nfs-subdir-external-provisioner 实现动态供给。`Recycle` 回收策略在 Kubernetes 1.20+ 已被弃用，建议改用 `Retain` 或 `Delete`。

---

yum install -y nfs-utils  rpcbind

存储节点：
vim /etc/exports
/data1 192.168.100.0/24(rw,async,no_root_squash,no_all_squash)
mkdir -p /data1

systemctl start rpcbind
systemctl enable rpcbind

exportfs  -arv

所有节点
showmount -e 192.168.209.128

systemctl start nfs-server.service
systemctl enable nfs-server.service

mount -t nfs 192.168.209.128:/data1 /data1

```shell
pvc _test.yaml

apiVersion: v1
kind: PersistentVolume
metadata:
  name: task-pv-volume
  labels:
    type: local
spec:
  storageClassName: manual
  capacity:
    storage: 10Gi
  accessModes:
    - ReadWriteOnce
  persistentVolumeReclaimPolicy: Recycle
  hostPath:
    path: "/data1"

---

apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: task-pv-claim
spec:
  storageClassName: manual
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 3Gi

---

apiVersion: v1
kind: Pod
metadata:
  name: task-pv-pod
spec:
  volumes:
    - name: task-pv-storage
      persistentVolumeClaim:
        claimName: task-pv-claim
  containers:
    - name: task-pv-container
      image: nginx
      ports:
        - containerPort: 80
          name: "http-server"
      volumeMounts:
        - mountPath: "/usr/share/nginx/html"
          name: task-pv-storage
```
