> **内容介绍**
>
> 本文演示 Go 向 InfluxDB 2.x 批量写入数据的两种方式：
> 一是用 net/http 直接 POST 行协议数据到 `/api/v2/write` 接口；
> 二是用官方 `influxdb-client-go/v2` 客户端的 WriteAPIBlocking 批量写 Point。

> **技术备注**
>
> 片段一手工拼接行协议（一行一条 Point），故 Content-Type 为 text/plain；
> `precision=s` 表示秒级时间戳。1.x 时代的 BatchPoints 在 2.x 客户端中已由
> `write.Point` 搭配 `WriteAPIBlocking` 取代；片段一的 resp 实为请求对象
> （*http.Request），变量命名沿用原文。

---

## 1. 原生 HTTP 调用 /api/v2/write 接口

```go
import (
	"bytes"
	"net/http"
	"strings"
	"time"
)

a := []string{}

a1 := strings.Join(a, "\n")
reader := bytes.NewBuffer([]byte(a1))
cHttp := &http.Client{Timeout: 10 * time.Second}
resp, _ := http.NewRequest("POST", "http://localhost:8086/api/v2/write?org=org&bucket=test&precision=s", reader)
resp.Header.Add("Authorization", "Token 12345")
resp.Header.Set("Content-Type", "text/plain; charset=utf-8")
resp.Header.Set("Accept", "application/json")
_, _ = cHttp.Do(resp)
```

## 2. influxdb-client-go/v2 客户端批量写入

```go
import (
	"context"
	"fmt"
	"time"

	influxdb2 "github.com/influxdata/influxdb-client-go/v2"
	"github.com/influxdata/influxdb-client-go/v2/api/write"
)

influxdbClient := influxdb2.NewClient("http://", "")
influxdbClient.Options().SetPrecision(time.Second)
writeAPI := influxdbClient.WriteAPIBlocking("org", "test")

data := make(map[string]float64)
data["1"] = 71.00
data["2"] = 72.00
data["3"] = 73.00
data["4"] = 74.00

var pList []*write.Point
for k, v := range data {
	p := influxdb2.NewPoint("cpu",
		map[string]string{"id": "123", "cpu": k},
		map[string]interface{}{"s": v},
		time.Now())
	pList = append(pList, p)
}
fmt.Println(pList)
_ = writeAPI.WritePoint(context.Background(), pList...)
_ = writeAPI.Flush(context.Background())
influxdbClient.Close()
```
