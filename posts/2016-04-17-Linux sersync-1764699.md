## 1. sersync 简介与选型对比

1. sersync 是基于 Inotify 开发的,类似于 Inotify-tools 的工具
2. sersync 可以记录下被监听目录中发生变化的（包括增加、删除、修改）具体某一个文件或某一个目录的名字,然后使用 rsync 同步的时候,只同步发生变化的这个文件或者这个目录。

Rsync+Inotify-tools 与 Rsync+sersync 这两种架构有什么区别?

### Rsync+Inotify-tools

1. Inotify-tools 只能记录下被监听的目录发生了变化（包括增加、删除、修改）,并没有把具体是哪个文件或者哪个目录发生了变化记录下来;
2. rsync 在同步的时候,并不知道具体是哪个文件或者哪个目录发生了变化,每次都是对整个目录进行同步,当数据量很大时,整个目录同步非常耗时（rsync 要对整个目录遍历查找对比文件）,因此,效率很低。

### Rsync+sersync

1. sersync 可以记录下被监听目录中发生变化的（包括增加、删除、修改）具体某一个文件或某一个目录的名字;
2. rsync 在同步的时候,只同步发生变化的这个文件或者这个目录（每次发生变化的数据相对整个同步目录数据来说是很小的,rsync 在遍历查找比对文件时,速度很快）,因此,效率很高。

小结:当同步的目录数据量不大时,建议使用 Rsync+Inotify-tools;当数据量很大（几百 G 甚至 1T 以上）、文件很多时,建议使用 Rsync+sersync。

## 2. 安装与配置

```shell
tar zxvf sersync2.5.4_64bit_binary_stable_final.tar
mv GNU-Linux-x86 /usr/local/sersync     # 原文误写为 "GUN-linux x86"
cd /usr/local/sersync                   # 进入 sersync 安装目录
cp confxml.xml confxml.xml-bak          # 备份原文件
vi confxml.xml                          # 编辑,修改下面的配置
```

需要修改的几处配置:

```xml
<localpath watch="本地目录">
    <remote ip="目的IP" name="模块名字"/>
</localpath>

<commonParams params="-artuz"/>

<auth start="true" users="用户名" passwordfile="密码文件"/>

<crontab start="true" schedule="600"/>
```

说明:crontab 设置为 true 时,每隔 600 分钟（schedule,单位为分钟）执行一次全盘同步。

## 3. 设置开机自动执行

```shell
vi /etc/rc.d/rc.local
```

在最后添加一行（:wq! 保存退出）:

```shell
/usr/local/sersync/sersync2 -d -r -o /usr/local/sersync/confxml.xml
```

## 4. 手动同步与守护脚本

手动同步:

```shell
cd /usr/local/sersync
./sersync2 -r
```

进程守护检测脚本（原文未给出脚本文件名,以下以 /home/sh/sersync.sh 为例）:

```shell
vi /home/sh/sersync.sh
```

```shell
#!/bin/sh
sersync="/usr/local/sersync/sersync2"
confxml="/usr/local/sersync/confxml.xml"
status=$(ps aux | grep 'sersync2' | grep -v 'grep' | wc -l)
if [ $status -eq 0 ];
then
    $sersync -d -r -o $confxml &
else
    exit 0;
fi
```

保存脚本后加执行权限,并加入 crontab 每 5 分钟检测一次:

```shell
chmod +x /home/sh/sersync.sh
vi /etc/crontab     # 编辑,在最后添加下面一行
```

```shell
*/5 * * * * root /home/sh/sersync.sh > /dev/null 2>&1   # 每隔5分钟执行一次脚本
```

```shell
service crond reload   # 重新加载服务
```

## 5. 常用启动参数

在主服务器上开启 sersync 守护进程,使 sersync 在后台运行,开启实时同步:

```shell
./sersync2 -d
```

在开启实时监控之前,对主服务器目录与远程目标机目录进行一次整体同步:

```shell
./sersync2 -r
```

指定配置文件:

```shell
./sersync2 -o XXXX.xml
```
