> **内容介绍**
>
> 本文记录自动化运维平台 AutoOps 的线上部署组合:Django 1.11.6 + uWSGI
> 2.0.15 + Nginx 1.12.2。步骤包括:源码编译安装 Python 3.6.3 并替换系统
> python、为 yum 保留 python2.7 解释器;配置 pip 国内源后安装 uwsgi 与
> django;编写 uwsgi.ini(workers、socket、静态目录、超时与日志)并给出
> 启动/停止/重载命令;最后在 nginx.conf 中配置 uwsgi_pass 反代与 /static/
> 别名,完成 Django 项目的上线。

> **技术备注**
>
> Python 3.6 已于 2021 年 12 月停止维护,Django 1.11 LTS 亦于 2020 年 4 月
> EOL,新项目请用 Python 3.11+/Django 4.2+ LTS。sohu 的 Python 镜像早已
> 停更,建议改用华为云/阿里云镜像。原文有几处被编辑器吃掉/写错的内容已修复:
> pip.conf 的 `index-url = http:///simple` 地址为空,按 2017 年惯用写法补全为
> aliyun 镜像;`python –V` 中的长破折号改为 `-V`;两次 ./configure 建议合并
> 为一次执行(原样保留两条,只跑后一条会丢掉 --enable-shared)。直接用
> python3 覆盖 /usr/bin/python 的做法风险较高,新系统建议保留系统 python、
> 用虚拟环境或 alternatives 管理。

## 1. 安装 Python 3.6

```bash
yum -y install xz wget gcc make gdbm-devel openssl-devel sqlite-devel zlib-devel bzip2-devel
wget http://mirrors.sohu.com/python/3.6.3/Python-3.6.3.tar.xz
tar -xf Python-3.6.3.tar.xz
cd Python-3.6.3

./configure --enable-shared --enable-loadable-sqlite-extensions --with-zlib
./configure --enable-optimizations
make && make install
```

> 注:原文连续执行了两次 `./configure`,只有最后一次的参数会生效,建议把
> 两行的参数合并到一次执行中。

替换系统默认 python,并为 yum 指回 python2.7:

```bash
mv /usr/bin/python /usr/bin/python2.7
ln -s /usr/local/bin/python3 /usr/bin/python

vim /etc/ld.so.conf
/usr/local/lib
include ld.so.conf.d/*.conf
/sbin/ldconfig

python -V

vim /usr/bin/yum
#!/usr/bin/python2.7
```

## 2. pip 换源并安装 uwsgi、django

```bash
vim /root/.pip/pip.conf
[global]
index-url = https://mirrors.aliyun.com/pypi/simple/
trusted-host = mirrors.aliyun.com

pip3     install uwsgi  django
```

## 3. uWSGI 配置与启停

命令行直接启动(测试用):

```bash
uwsgi --http :8001 --chdir /opt/autoops/ -w autoops.wsgi --static-map=/static=static
```

完整配置文件:

```bash
vim      uwsgi.ini
```

```ini
[uwsgi]
# 项目目录
chdir=/opt/autoops/
# 指定项目的application
module=autoops.wsgi:application
# 进程个数
workers=8
pidfile=/opt/autoops/script/uwsgi.pid
# 指定IP端口
#http=0.0.0.0:8003    ##可以不启用，利用socket文件，如果只是测试，需要启用
# 指定静态文件
static-map=/static=/opt/autoops/static
# 启动uwsgi的用户名和用户组
uid=root
gid=root
# 启用主进程
master=true
# 自动移除unix Socket和pid文件当服务停止的时候
vacuum=true
# 序列化接受的内容，如果可能的话
thunder-lock=true
# 启用线程
enable-threads=true
# 设置自中断时间
harakiri=30
# 设置缓冲
post-buffering=4096
# 设置日志目录
daemonize=/opt/autoops/script/uwsgi.log
# 指定sock的文件路径
socket=/opt/autoops/script/uwsgi.sock
```

启停命令:

```bash
uwsgi --ini uwsgi.ini   # 启动uwsgi配置
uwsgi --stop script/uwsgi.pid # 关闭uwsgi
uwsgi --reload  script/uwsgi.pid  #重新加载
```

## 4. Nginx 站点配置

nginx 的安装可参看同博客《nginx-1.12.2 安装 配置文件 日志切割 启动文件》
一文,站点部分修改 nginx.conf 如下:

```nginx
  root         /opt/autoops;

    location / {
#       uwsgi_pass 127.0.0.1:8003;
        include uwsgi_params;
        uwsgi_connect_timeout 30;
        uwsgi_pass unix:/opt/autoops/script/uwsgi.sock;
    }
    location /static/ {
            alias  /opt/autoops/static/;
            index  index.html index.htm;
    }
```

启动后即可访问测试。
