## 1. 集群与 LVS 基本概念

集群：一组计算机利用网络组成一个系统，每个节点都是运行其自己进程的一个独立服务器。

解决高并发、高吞吐，具备透明性、高性能、高可用性、可伸缩性、可管理性、可编程性。

- 负载均衡集群：lvs、nginx、haproxy
- 高可用集群：keepalived

Linux Virtual Server（LVS）：

- 调度实现：IPVS（内核模块）
- 管理工具：ipvsadm
- keepalived 实现管理及高可用

四个关键地址：

1. CIP（Client computer's IP address）：公网 IP，客户端使用的 IP。
2. VIP（Virtual IP address）：Director 用来向客户端提供服务的 IP 地址。
3. RIP（Real IP address）：集群节点（后台真正提供服务的服务器）所使用的 IP 地址。
4. DIP（Director's IP address）：Director 用来和 D/RIP 进行联系的地址。

报文流向 CIP ←→ DIP ←→ RIP，VIP 由 Director 对外承载：

## 2. LVS 工作模式与 DR 原理

模式：NAT、TUN、**DR**、FULLNAT。

DR 直接路由模式：

通过改写请求报文的目标 MAC 地址，将请求发给真实服务器，真实服务器将响应后的处理结果直接返回客户端。

LVS 调度器根据各个服务器的负载情况，**动态地选择一台服务器**，不修改也不封装 IP 报文，而是将**数据帧的 MAC 地址**改为选出**服务器的 MAC 地址**，再将修改后的数据帧在与服务器组的局域网上发送。因为数据帧的 MAC 地址是选出的服务器，所以服务器肯定可以收到这个数据帧，从中可以获得该 IP 报文。

当服务器发现报文的目标地址 VIP 是在本地的网络设备上，服务器处理这个报文，然后根据路由表将响应报文**直接返回给客户**。

要求 Director Server 与 Real Server 都有一块网卡连在同一物理网段上。

## 3. LVS 调度算法（共 8~10 种）

1. **rr** 轮询调度
2. **wrr** 加权轮询调度 / **wlc** 加权最小链接数调度
3. dh 目的地址哈希调度
4. sh 源地址哈希调度

## 4. Director 端：安装与配置

安装依赖并编译 ipvsadm：

```shell
yum -y install kernel-devel libnl* popt* gcc
ln -s /usr/src/kernels/2.6.32-642.1.1.el6.x86_64/ /usr/src/linux
tar zxvf ipvsadm-1.26.tar.gz
cd ipvsadm-1.26
make && make install
```

加载内核模块并确认：

```shell
modprobe ip_vs
lsmod | grep ip_vs
```

```text
ip_vs                 126897  0
libcrc32c               1246  1 ip_vs
ipv6                  336282  265 ip_vs
```

查看版本：

```shell
/sbin/ipvsadm
```

```text
IP Virtual Server version 1.2.1 (size=4096)
Prot LocalAddress:Port Scheduler Flags
  -> RemoteAddress:Port           Forward Weight ActiveConn InActConn
```

在 Director 上配置 VIP 并添加主机路由：

```shell
ifconfig eth0:0 192.168.10.40
route add -host 192.168.10.1 dev eth0
route -n
```

```text
Destination     Gateway         Genmask         Flags Metric Ref    Use Iface
192.168.10.1    0.0.0.0         255.255.255.255 UH    0      0        0 eth0
```

添加虚拟服务与真实服务器：

```shell
ipvsadm -C
ipvsadm --set 30 5 60
ipvsadm -A -t 192.168.10.40:80 -s rr -p 20                 # -D 删除
ipvsadm -a -t 192.168.10.40:80 -r 192.168.10.11 -g -w 1    # -d 删除
ipvsadm -a -t 192.168.10.40:80 -r 192.168.10.10 -g -w 1
```

查看规则：

```shell
ipvsadm -L -n
```

```text
IP Virtual Server version 1.2.1 (size=4096)
Prot LocalAddress:Port Scheduler Flags
  -> RemoteAddress:Port           Forward Weight ActiveConn InActConn
TCP  192.168.10.40:80 rr persistent 20
  -> 192.168.10.10:80             Route   1      0          0
  -> 192.168.10.11:80             Route   1      0          0
```

## 5. Real Server 端：绑定 VIP 与抑制 ARP

RS 端绑定 VIP 到 lo:0：

```shell
ifconfig lo:0 192.168.10.40/32 up
route add -host 192.168.10.40 dev lo
```

抑制 ARP：

```shell
echo "1" > /proc/sys/net/ipv4/conf/lo/arp_ignore
echo "2" > /proc/sys/net/ipv4/conf/lo/arp_announce
echo "1" > /proc/sys/net/ipv4/conf/all/arp_ignore
echo "2" > /proc/sys/net/ipv4/conf/all/arp_announce
```
