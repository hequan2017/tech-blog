> **内容介绍**
>
> 本文介绍 rsync 的三种工作方式——本地复制、远程 shell（ssh 通道）与守护进程
> （daemon/socket）模式,并逐条讲解 -avz、-a=-rtopgDl、-e、--delete、
> --password-file 等常用参数。核心是 daemon 模式的服务端部署:编辑
> /etc/rsyncd.conf、创建 rsync 运行用户、写入虚拟用户密码文件
> （rsync_backup:hequan,权限 600）、以 rsync --daemon 启动并确认 873 端口监听,
> 最后在客户端配置密码文件完成推（push）拉（pull）同步。

> **技术备注**
>
> 文中环境为 CentOS 6 自带的 rsync 3.0.6（protocol 30）,该系统已于 2020 年 11
> 月停止维护（EOL）。新发行版上 daemon 方式建议改由 systemd 管理（unit 文件或
> systemctl start rsyncd）;rsyncd.conf 中布尔值写 false 与 no 等价;密码文件权限
> 必须为 600,否则认证会失败。

## 1. rsync 简介

rsync 是开源、快速、多功能的同步工具,支持全量及增量备份,可以在本地、远程间
传输数据,也能以守护进程（socket）的方式传输数据。

命令格式:`rsync 参数 源 目的`（source 源 / dest 目的）。

三种工作方式（SYNOPSIS）:

```text
Local:  rsync [OPTION...] SRC... [DEST]

Access via remote shell:
Pull: rsync [OPTION...] [USER@]HOST:SRC... [DEST]
Push: rsync [OPTION...] SRC... [USER@]HOST:DEST

Access via rsync daemon:
Pull: rsync [OPTION...] [USER@]HOST::SRC... [DEST]
      rsync [OPTION...] rsync://[USER@]HOST[:PORT]/SRC... [DEST]
Push: rsync [OPTION...] SRC... [USER@]HOST::DEST
      rsync [OPTION...] SRC... rsync://[USER@]HOST[:PORT]/DEST
```

## 2. 本地与远程（shell）同步示例

```shell
# 直接本地同步,相当于 cp
rsync -avz /etc/hosts /tmp/

# 删除文件:让空目录 /null/ 和 /hequan/ 下保持一样
rsync -r --delete /null/ /hequan/

# 推送 push(-e 指定通道)
rsync -avz -e 'ssh' /etc/hosts hequan@192.168.10.11:~

# 拉取 pull
rsync -avz -e 'ssh' hequan@192.168.10.11:~/hosts /home/hequan/
```

## 3. 常用参数

- `-v` 详细输出
- `-z` 压缩传输
- `-a` 归档模式,等于 `-rtopgDl`:递归、保持文件时间、属主、权限、属组信息、设备文件信息、软连接
- `-e` 使用信道协议

daemon 模式下还常用 `--delete`（无差异同步）与 `--password-file`（密码文件）。

## 4. daemon 模式（服务端）

检查版本并安装:

```shell
rsync --version
# rsync  version 3.0.6  protocol version 30
yum install rsync -y
```

编辑配置文件:

```shell
vim /etc/rsyncd.conf
```

```ini
##rsyncd.conf start##
uid = rsync
gid = rsync
use chroot = no
max connections = 200
timeout = 300
pid file = /var/run/rsyncd.pid
lock file = /var/run/rsync.lock
log file = /var/log/rsyncd.log

[hequan]
path = /hequan/
ignore errors
read only = false
list = false
hosts allow = 192.168.10.0/24
hosts deny = 0.0.0.0/32
auth users = rsync_backup
secrets file = /etc/rsync.password
#rsync_config_______________end
```

以守护进程方式启动,并确认 873 端口已监听:

```shell
rsync --daemon
netstat -lntup | grep 873
```

```text
tcp        0      0 0.0.0.0:873                 0.0.0.0:*                   LISTEN      1768/rsync
```

查看日志:

```shell
cat /var/log/rsyncd.log
```

```text
2016/03/29 22:53:45 [1768] rsyncd version 3.0.6 starting, listening on port 873
```

创建用户、授权、写入用户名密码:

```shell
useradd rsync -s /sbin/nologin
chown -R rsync.rsync /hequan/
echo "rsync_backup:hequan" > /etc/rsync.password   # 内容为 用户名:密码
chmod 600 /etc/rsync.password                      # 降低权限
```

确认密码文件内容:

```shell
cat /etc/rsync.password
# rsync_backup:hequan
```

## 5. 客户端配置与推拉同步

客户端密码文件只写密码:

```shell
echo "hequan" > /etc/rsync.password
chmod 600 /etc/rsync.password
```

拉取（`hequan` 是模块名）:

```shell
rsync -avz rsync_backup@192.168.10.10::hequan /data/
```

```text
Password:
receiving incremental file list
./
test1
```

免交互拉取与推送（`--password-file` 指定密码文件）:

```shell
rsync -avz rsync_backup@192.168.10.10::hequan --password-file=/etc/rsync.password /data/
rsync -avz /data/ rsync_backup@192.168.10.10::hequan --password-file=/etc/rsync.password
```

## 6. 部署要点回顾

服务端（/etc/rsyncd.conf）:用户、目录、模块、虚拟用户及密码文件。

- 共享目录 /hequan,创建 rsync 用户并授权
- 创建密码文件:复制配置文件里的路径,然后添加密码内容,格式为"虚拟用户名:密码"
- 密码文件的权限设为 600
- 用 `rsync --daemon` 启动

客户端:

- 密码文件和服务端没有关系,里面只写密码,权限同样 600
- 用 `--password-file=/etc/rsync.password` 指定密码
- 同步方向:推、拉
