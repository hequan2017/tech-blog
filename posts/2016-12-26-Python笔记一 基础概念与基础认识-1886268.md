## 1. 简介

Python 的创始人为吉多·范罗苏姆（Guido van Rossum）。在（2016 年）10 月份 TIOBE 排行榜上，Python 为第五，占有率为 3.775%（注：此为历史数据，2026 年 Python 已稳居第一）。

Python 是一门**动态解释型的强类型定义**语言。

执行 `.py` 文件时由 Python 解释器逐行编译→解释，再运行。

`PyCodeObject` 是编译结果，运行完成后保存到 `.pyc` 中，以便下次直接运行 pyc 文件。

- **动态类型**：运行期间才做数据类型检查的语言。
- **强类型定义语言**：一旦一个变量被指定了某个数据类型，不经过强制转换，永远都是这个类型。

**优点**：优雅、明确、简单；开发效率高；高级语言；可移植性、可扩展性、可嵌入性。

**缺点**：速度慢；代码不能加密；线程不能利用多 CPU（受 GIL 限制，原文"不能理由"为笔误）。

Python 解释器：**CPython** 是使用最广的解释器。Windows 可使用 PyCharm 编写 Python 程序（2026 年也可用 VS Code）。

接下来的内容都基于 **Python 3**。

## 2. 基础认识

### 2.1 第一个程序

```python
print("Hello World!")
# 输出: Hello World!
```

执行方式：

```shell
python hello.py        # 命令行指定解释器执行
```

```python
#!/usr/bin/env python   # 在脚本头部指定解释器（Unix 下可直接 ./hello.py 执行）
#_*_ coding:utf-8 _*_   # 声明源码编码（Python 3 默认 UTF-8，此行可省略）
```

### 2.2 变量

```python
name = 'he quan'
```

命名规则：

- 变量名只能是字母、数字或下划线的任意组合
- 变量名的第一个字符不能是数字
- Python 关键字不能声明为变量名（原文"生命"为笔误）：

```python
>>> import keyword
>>> keyword.kwlist
['and', 'as', 'assert', 'break', 'class', 'continue', 'def', 'del',
 'elif', 'else', 'except', 'finally', 'for', 'from', 'global', 'if',
 'import', 'in', 'is', 'lambda', 'not', 'or', 'pass', 'raise',
 'return', 'try', 'while', 'with', 'yield']
# 注：Python 3.9+ 的 kwlist 中已没有 'exec' 和 'print'（它们是内置函数）
```

命名约定：

- **常量**：对于不会发生改变的全局变量，使用大写加下划线，如 `USER_CONSTANT`
- **私有变量**：只在内部使用时，用小写加一个前导下划线，如 `_private_value`
- **内置变量**：小写，双前导和双后置下划线，如 `__class__`

### 2.6 交互解释器 tab 补全配置

以下为 Python 交互式启动文件（`PYTHONSTARTUP`）示例，实现 tab 补全和历史记录：

```python
#!/usr/bin/env python
# python startup file
import sys
import readline
import rlcompleter
import atexit
import os

# tab completion
readline.parse_and_bind('tab: complete')

# history file
histfile = os.path.join(os.environ['HOME'], '.pythonhistory')
try:
    readline.read_history_file(histfile)
except IOError:
    pass

atexit.register(readline.write_history_file, histfile)
del os, histfile, readline, rlcompleter
```

## 3. 类型

Python 3 有六个标准的数据类型：Number（数字）、String（字符串）、List（列表）、Tuple（元组，原文"元祖"为笔误）、Set（集合）、Dictionary（字典）。

### 3.1 Number（数字）

Python 3 支持 `int`、`float`、`complex`（复数）。

在 Python 3 里只有一种整数类型 `int`，表示为长整型，没有 Python 2 中的 `Long`。

`bool` 分为：`True`、`False`。

### 3.2 String（字符串）

Python 中的字符串用单引号（`'`）或双引号（`"`）括起来，同时使用反斜杠（`\`）转义特殊字符（原文"饭斜杠"为笔误）。

编码转换关系（原文图示）：

```text
记事本（Unicode 编码）
   ↓        ↑
UTF-8 ←→ Unicode
   ↓        ↑
文件 abc.txt（原文 "abc.tx" 漏了 t，为笔误）
```

格式化字符串：`%d` 数字、`%f` 浮点、`%s` 字符、`%x` 十六进制（2026 年推荐 f-string）。

### 3.3 List（列表）

列表可以完成大多数集合类的数据结构实现。列表中元素的类型可以不相同，支持数字、字符串甚至列表（嵌套）。

```python
list = ['he', 213]
```

**切片语法：`变量[头下标:尾下标]`**，索引从 0 开始，-1 为末尾开始位置。`+` 是连接运算符，`*` 是重复操作。

```python
list.append(x)      # 追加
list.insert(1, x)   # 插入
list.pop(1)         # 移除
list[1] = x         # 变更
```

### 3.4 Tuple（元组）

元组（tuple）与列表类似，不同之处在于元组的元素不能修改（原文"不用支出/类线/子啊"均为笔误）。元组写在小括号 `()` 里，元素之间用逗号隔开。

```python
tuple = ('he', 12345)

tup1 = ()      # 空元组
tup2 = (20,)   # 单元素元组，需要在元素后添加逗号
```

### 3.5 Set（集合）

集合（set）是一个无序不重复元素的序列（原文"无需"为笔误）。基本功能是成员关系测试和删除重复元素。

```python
s = {1, 2, 3}   # 或用 set() 创建
s.add(4)        # 添加
s.remove(2)     # 删除
```

### 3.6 Dictionary（字典）

字典是 Python 中非常有用的内置映射类型。列表是有序的对象集合，字典在 Python 3.6 及更早版本中是无序集合（3.7+ 保持插入顺序）。字典中的元素通过键存取，而不是通过偏移存取。

```python
dictionary = {'name': 'hequan', 'age': 1, 'site': 'www.hequan.lol'}
```

- 键（key）必须使用不可变类型；同一字典中键必须唯一
- dict 和 set 都要求 key 不可变
- 元组 `(1, 2, 3)` 里的元素都不可变；`(1, [2, 3])` 里的列表 `[2, 3]` 的值是可变的

### 3.7 运算符

1. 算术：`+  -  *  /  %  **  //`
2. 比较：`==  !=  >  <  >=  <=`
3. 赋值：`=  +=  -=  *=  /=  %=  **=  //=`（原文 `/+` 为笔误），例：`c += a` 等价于 `c = c + a`

位运算（把数字看作二进制计算）：

- `&` 按位与：两个相应位都为 1，则该位结果为 1，否则为 0
- `|` 按位或：对应二进制位有一个为 1 时，结果为 1
- `^` 按位异或：两对应二进位相异时，结果为 1
- `~` 按位取反：每个二进制位取反
- `<<` 左移：全部左移若干位，高位丢弃，低位补 0
- `>>` 右移：全部右移若干位

逻辑：`and`、`or`、`not`。成员（适用于字符串、列表或元组）：

- `in`：找到值返回 True，否则 False
- `not in`：未找到值返回 True，否则 False（原文漏掉 `in`，已补正）

身份（比较两个对象的存储单元）：

- `is`：判断两个标识符是否引用自同一对象
- `is not`：判断是否引用自不同对象

优先级（原文符号有乱码，按官方优先级修正，由高到低）：

```text
** → ~ + -（一元） → * / % // → + - → >> << → & → ^ | →
<= < > >= → == != → = %= /= //= -= += *= **= → is/is not →
in/not in → not → and → or
```

## 4. 基础操作速查

- `strip`：移除两端空白
- `split`：分割，`str.split(sep, maxsplit)`
- `len(obj)`：长度
- `obj[1]`：索引
- `obj[1:]`、`obj[1:10]`：切片

```python
ll = [1, 2, 3, 4, 5]
# 列表常用：index / append / del / remove / pop / len
# 循环：for / while，控制：break（结束循环）、continue（跳过单次）、
#       pass（占位）、return（返回）、exit（退出）
```

元组的元素不可以修改，但元组里可变元素的内部可以被修改：

```python
t1 = (1, 2, {'h1': 123})
t1[2]['h1'] = 'h2'   # 修改元组中字典的值，合法
print(t1)            # (1, 2, {'h1': 'h2'})
```

字典视图：

```python
D.keys()    # 键
D.values()  # 值
D.items()   # 键值对
```

文件打开模式：`r`（只读）、`r+`（读写）、`w`（写，清空）、`a`（追加）、`b`（二进制，可与上述组合）。
