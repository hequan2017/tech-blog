> **内容介绍**
>
> 本文演示 Kubernetes v1.25 集群中节点被删除后重新加入的方法：在 master 节点通过 `kubeadm token create` 生成新 token，并计算 CA 证书哈希，然后在目标 node 上执行 `kubeadm join` 携带新 token 与 hash 完成注册。
>
> **技术备注**
>
> token 默认 24 小时过期；若忘记保留 token，可在 master 上重新创建。生产环境建议使用 `kubeadm join --discovery-token-unsafe-skip-ca-verification` 之外的正式 hash 校验，避免中间人攻击。

---

#### master节点

```shell
kubeadm token create
kubeadm token list
openssl x509 -pubkey -in /etc/kubernetes/pki/ca.crt | openssl rsa -pubin -outform der 2>/dev/null | openssl dgst -sha256 -hex | sed 's/^.* //'
```

#### node节点

```shell
kubeadm join 192.168.209.128:6443 --token ydt239.zdza2unu6nj2wdou \
    --discovery-token-ca-cert-hash sha256:18d09ae702b558269aa4f0fe901b0cac1a9b78e0dd9d9e5c1b3f3899632a2cd7
```
