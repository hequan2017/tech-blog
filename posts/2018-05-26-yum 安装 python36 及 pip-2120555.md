> **内容介绍**
>
> 本文记录 CentOS 7 通过 EPEL + IUS 源用 yum 安装 Python 3.6 与 pip 的过程：先装
> sqlite 开发库和 ius-release 源，再 yum 安装 python36、python36u-pip 并升级 pip；
> 然后把 /usr/bin/python 软链指向 python3.6，同时把 /usr/bin/yum 与
> urlgrabber-ext-down 的 shebang 改回 python2，保证 yum 正常可用；最后配置阿里云
> PyPI 镜像并用 python -V 验证。

> **技术备注**
>
> IUS 源项目已归档停止维护（历史包仍可从 repo.ius.io 获取），现在 CentOS/Rocky
> 可直接 `dnf install python3 python3-pip`；
> Python 2 已于 2020-01-01 停止官方支持，Python 3.6 亦于 2021-12 到达 EOL，新环境
> 建议 Python 3.8+；
> 原文 ius-release.rpm 的安装地址被编辑器吃掉，已补全为 repo.ius.io 的 CentOS 7 包地址。

---

## 1. 安装依赖与 IUS 源

```shell
yum install epel-release -y

yum -y install sqlite  sqlite-devel

sudo yum -y install https://repo.ius.io/ius-release-el7.rpm
```

## 2. 安装 python36 与 pip

```shell
yum install python36  python36u-pip  -y
python3.6  -m  pip install --upgrade pip
```

## 3. 切换默认 python 并修复 yum

> ⚠️ 把系统 python 指向 3.6 后，yum 等系统脚本仍依赖 python2，必须同步把它们的
> 解释器改回 python2，否则 yum 会直接报语法错误。

```shell
mv   /usr/bin/python  /tmp/
ln -s /usr/bin/python3.6    /usr/bin/python

sed  -i    's/\#\!\/usr\/bin\/python/\#\!\/usr\/bin\/python2/'   /usr/bin/yum
sed  -i    's/\#\! \/usr\/bin\/python/\#\! \/usr\/bin\/python2/'   /usr/libexec/urlgrabber-ext-down
```

## 4. 配置 pip 阿里云镜像

```shell
mkdir -p  /root/.pip/

cat >  /root/.pip/pip.conf   <<EOF
[global]
trusted-host=mirrors.aliyun.com
index-url=http://mirrors.aliyun.com/pypi/simple/
EOF
```

## 5. 验证

```shell
python -V
```
