> **内容介绍**
>
> 用 Python 标准库 `datetime` 计算当前周周一和周日的日期：通过 `weekday()` 判断当天是星期几，再用 `timedelta` 逐日前移或后移直到落在周一和周天上。适合做周报统计、按周查询数据等场景的时间边界计算。

> **技术备注**
>
> 文中的逐日循环可用一行算式等价替代：`monday = today - timedelta(days=today.weekday())`、`sunday = monday + timedelta(days=6)`，无需循环。周日口径按"周一为一周之始"计算，与 `date.isocalendar()` 的 ISO 周定义一致；若业务以周日为一周开始，需自行偏移一天。

---

```python
import datetime

def get_current_week():
    monday, sunday = datetime.date.today(), datetime.date.today()
    one_day = datetime.timedelta(days=1)
    while monday.weekday() != 0:
        monday -= one_day
    while sunday.weekday() != 6:
        sunday += one_day

    return monday, sunday

print(get_current_week())
```
