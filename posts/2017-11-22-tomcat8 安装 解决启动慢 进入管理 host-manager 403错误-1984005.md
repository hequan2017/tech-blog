> **内容介绍**
>
> 本文记录 Tomcat 8.5.23 在 CentOS 上的安装与常见坑:先安装 JDK 8 并配置
> JAVA_HOME 等环境变量,再部署 Tomcat 并做软链接、写 setenv.sh;针对启动
> 慢的问题,给出 catalina.sh 加 urandom 参数与修改 java.security 两处方案;
> 接着通过 manager.xml 与 tomcat-users.xml 配置允许所有 IP 登录 Manager
> 管理页面,解决 host-manager 403;最后演示把端口改为 80、指定默认站点
> 路径与欢迎页的方法。

> **技术备注**
>

> 根因是熵源不足(securerandomsource 阻塞),除文中改 urandom 外,也可安装
> haveged 或 rng-tools 解决。原文被编辑器吃掉的内容已补全:`echo ... >>` 一行
> 补上重定向目标 setenv.sh;"在中加入这么一行"补为 bin/catalina.sh;另将
> 网页复制带入的不换行空格(NBSP)归一为普通空格。

## 1. 安装 JDK 8

到 Oracle 页面接受协议后下载 jdk8(wget 那个地址是下载页,需浏览器操作):

```bash
cd /usr/local/src
wget http://www.oracle.com/technetwork/java/javase/downloads/jdk8-downloads-2133151.html
##需要进去，点介绍协议，下载jdk8

tar zxvf jdk-8u144-linux-x64.tar.gz
mv jdk1.8.0_144/   /usr/local/jdk8.0

vim /etc/profile
JAVA_HOME=/usr/local/jdk8.0
JAVA_BIN=/usr/local/jdk8.0/bin
PATH=$PATH:$JAVA_BIN
CLASSPATH=$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar
export JAVA_HOME JAVA_BIN PATH CLASSPATH
export CATALINA_BASE=/usr/local/tomcat
export CATALINA_HOME=/usr/local/tomcat

source /etc/profile
```

## 2. 安装 Tomcat 8.5

```bash
cd /usr/local/src/
wget https://mirrors.tuna.tsinghua.edu.cn/apache/tomcat/tomcat-8/v8.5.23/bin/apache-tomcat-8.5.23.tar.gz
tar zxvf apache-tomcat-8.5.23.tar.gz
mv apache-tomcat-8.5.23  /usr/local/tomcat8.5

ln -s /usr/local/tomcat8.5/ /usr/local/tomcat
cd /usr/local/tomcat/bin/
echo "CATALINA_HOME=/usr/local/tomcat8.5/"  >> setenv.sh
chmod +x   *.sh
./startup.sh
```

## 3. 解决启动慢

方案一:在 `bin/catalina.sh` 中加入这么一行:

```bash
JAVA_OPTS="-Djava.security.egd=file:/dev/./urandom"
```

方案二:打开 `$JAVA_PATH/jre/lib/security/java.security` 这个文件,找到下面的内容:

```properties
securerandom.source=file:/dev/urandom
```

替换成:

```properties
securerandom.source=file:/dev/./urandom
```

## 4. 进入 Manager 管理页面

`conf/Catalina/localhost/` 下创建 manager.xml,填入如下内容(允许所有 IP 访问):

```xml
<Context privileged="true" antiResourceLocking="false"
         docBase="${catalina.home}/webapps/manager">
    <Valve className="org.apache.catalina.valves.RemoteAddrValve" allow="^.*$" />
</Context>
```

添加用户:`conf/tomcat-users.xml` 中的 `<tomcat-users></tomcat-users>` 标签内添加如下代码:

```xml
<role rolename="manager-gui"/>
<role rolename="manager-script"/>
<role rolename="manager-jmx"/>
<role rolename="manager-status"/>
<role rolename="admin-gui"/>
<role rolename="admin-script"/>

<user username="admin" password="admin" roles="manager-gui,manager-script,manager-jmx,manager-status,admin-gui,admin-script"/>
<user username="deploy" password="deploy" roles="manager-script"/>
```

## 5. host-manager 403 错误

host-manager 还是 403,解决办法同样是允许所有 IP 访问:

```xml
vim /usr/local/tomcat/webapps/host-manager/META-INF/context.xml
<Context antiResourceLocking="false" privileged="true" >
     <Valve className="org.apache.catalina.valves.RemoteAddrValve"
     allow="^.*$" /> #修改这里
</Context>
```

## 6. 修改端口与默认站点

修改端口为 80:

```xml
vim conf/server.xml
<Connector port="80" protocol="HTTP/1.1"
               connectionTimeout="20000"
               redirectPort="8443" />
```

修改默认网页路径(`docBase` 就是你要访问的路径):

```xml
vim conf/server.xml
<Host name="localhost"  appBase="webapps"
            unpackWARs="true" autoDeploy="true">

<Context path="" docBase="/usr/local/tomcat/webapps/shyt/" debug="0"/>   ###加入此行

</Host>
```

修改默认首页文件:

```xml
vim conf/web.xml
<welcome-file-list>
    <welcome-file>index.html</welcome-file>
    <welcome-file>index.htm</welcome-file>
    <welcome-file>index.jsp</welcome-file>
</welcome-file-list>
```
