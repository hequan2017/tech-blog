> **内容介绍**
>
> 本文演示让 Django 支持用户名或邮箱均可登录:自定义认证后端
> CustomBackend 继承 ModelBackend,重写 authenticate(),用
> Q(username=username) | Q(email=username) 联合查询用户,check_password
> 校验通过即返回用户对象;再在 settings.py 的
> AUTHENTICATION_BACKENDS 中指定该后端即可生效。

> **技术备注**
>
> `authenticate()` 带 request 参数需 Django 1.11 及以上;此写法在
> Django 2.x ~ 5.x 仍然适用。两点注意:except 里把异常整个吞掉并返回
> None 会掩盖问题,建议至少打日志;当某个用户名恰好等于另一用户的邮箱
> 时 Q 联合查询可能命中多行,get() 抛 MultipleObjectsReturned,同样会
> 走 except 返回 None(登录失败)。

---

## 1. views.py:自定义认证后端

```python
from django.contrib.auth.backends import ModelBackend
from django.db.models import Q
from django.contrib.auth.models import AbstractUser, Group, User

class CustomBackend(ModelBackend):
    """邮箱也能登录"""
    def authenticate(self, request, username=None, password=None, **kwargs):
        try:
            user = User.objects.get(Q(username=username) | Q(email=username))
            if user.check_password(password):
                return user
        except Exception as e:
            return None
```

## 2. settings.py:启用该后端

```python
AUTHENTICATION_BACKENDS = ('system.views.CustomBackend',)
```

配置后,登录表单里填用户名或绑定的邮箱都能通过验证。
