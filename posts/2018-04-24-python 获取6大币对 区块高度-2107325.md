> **内容介绍**
>
> 本文是一个抓取六大币种最新区块高度的小脚本（Python 2）：BTC、BCH
> 调用 btc.com 的 JSON 接口直接取 data.height；USDT（Omni 协议构建于
> 比特币链上）直接复用 BTC 高度；LTC、ETC、ETH 则抓取各自区块浏览器
> 页面，用 lxml xpath 解析出高度文本，最后统一 print 输出。

> **技术备注**
>
> - 代码为 Python 2 语法（print 语句），Python 3 下需改为
>   `print(btc, bch, ltc, usdt)`。
> - 原文部分 URL 被截断：BTC/BCH 接口已按 51CTO 原文恢复为
>   `chain.api.btc.com` / `bch-chain.api.btc.com`，但 btc.com 的 API
>   如今已停止服务，两个接口均不可用；ETH 的抓取地址原文即缺失
>   （`https:///`），无法恢复。
> - 网页 xpath 爬取方式随站点改版早已失效，现建议改用公开 API，如
>   Etherscan（`api.etherscan.io`）、BlockCypher 等。

## 1. 获取区块高度脚本

```python
#!/usr/bin/python
# -*- coding: utf-8 -*-
import requests
from lxml import etree
import json

b_re = requests.get('https://chain.api.btc.com/v3/block/latest')
btc=b_re.json()['data']['height']

bch_re = requests.get('https://bch-chain.api.btc.com/v3/block/latest')
bch=bch_re.json()['data']['height']

ltc_re = requests.get('http://explorer.litecoin.net/')
selector1 = etree.HTML(ltc_re.text)
ltc = selector1.xpath('//td/a/text()')[1]

usdt = btc

etc_re = requests.get('http://gastracker.io/')
selector2 = etree.HTML(etc_re.text)
etc = selector2.xpath('//dl/dd/span/text()')[6]

eth_re = requests.get('https:///')   # 原文此处抓取地址已被截断,无法恢复
selector3 = etree.HTML(eth_re.text)
eth = selector3.xpath('//h4[@style="color: #FFFFFF"]//text()')[0]

print btc,bch,ltc,usdt
print eth,etc
```
