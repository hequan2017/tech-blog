> **内容介绍**
>
> 本文是一则极简的 Zabbix 部署速记：克隆官方 zabbix-docker
> 仓库并切换到 6.0 分支，将 v3 Alpine + MySQL 编排文件软链为
> docker-compose.yaml，再用 docker-compose 一键拉起整套监控服务。

> **技术备注**
>
> Zabbix 6.0 为 LTS 版本，现已进入有限支持期（官方支持至 2027 年 2 月）；
> 截至 2026 年最新 LTS 为 7.0（支持至 2029 年中），8.0 LTS 尚未发布。
> 带 `_latest` 后缀的编排文件使用 `alpine-6.0-latest` 这类滚动 tag，会自动
> 跟随 6.0 分支内的小版本更新，需要锁定版本时可将镜像 tag 固定到具体小版本
> （形如 `alpine-6.0.x`）。独立版 `docker-compose`（V1）已于 2023 年 6 月
> 停止维护，新环境建议改用 `docker compose`（V2 插件）。Alpine 基础镜像
> 默认不含 tzdata，官方 `TZ` 变量主要作用于 Web 界面时区，若需容器本机
> 时区为北京时间，可改用 Ubuntu 基础镜像的编排文件或自行安装 tzdata。

---

```shell
# 下载 docker-compose 文件
git clone https://github.com/zabbix/zabbix-docker.git

# 启动服务
cd zabbix-docker
git checkout 6.0  # 切换到 6.0 版本，进行 6.0 版本安装
ln -s docker-compose_v3_alpine_mysql_latest.yaml docker-compose.yaml  # 创建软链接
docker-compose up -d
```
