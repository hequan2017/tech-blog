> **内容介绍**
>
> 本文用 GoFrame（gf）的 `crypto/gaes` 包演示 AES 加密解密：以 16 字节
> 密钥把字符串 "hequan" 加密成 hex 字符串，再用同一密钥解密还原明文，
> 适合作为 Go 后端密码 / Token 加解密的快速示例。

> **技术备注**
>
> 示例基于 GoFrame v2 的 `crypto/gaes`（AES-GCM 模式），密钥须为
> 16/24/32 字节，这里用 16 字节即 AES-128；密文经 hex 编码便于存储
> 与展示，解密前需先 hex 解码。注意示例密钥硬编码在源码里，仅作演示，
> 实际项目应从配置或密钥管理服务读取，切勿把真实密钥提交进代码。

---

```go
package main

import (
	"encoding/hex"
	"fmt"

	"github.com/gogf/gf/v2/crypto/gaes"
)

func main() {
	key := []byte("B4OcDhdFwIyDdjFz") // 16 字节（AES-128）
	res, _ := gaes.Encrypt([]byte("hequan"), key)
	res2 := hex.EncodeToString(res)
	fmt.Println(res2) // 650d7f2e5aff02da85ff4af9ae36b052

	res3, _ := hex.DecodeString(res2)
	res4, _ := gaes.Decrypt(res3, key)
	fmt.Println(string(res4)) // hequan
}
```
