> **内容介绍**
>
> 本文记录在 CentOS 7.9 上以 kubeadm 部署 Kubernetes v1.30.2 双节点集群
> （1 master + 1 node）的完整流程：主机名/hosts、软件包、防火墙、时区等
> 系统初始化，内核参数调优、journald 日志持久化与 ipvs 前置条件；随后
> 安装 Docker 与 containerd（镜像加速、systemd cgroup、pause 镜像地址），
> 用阿里云 kubernetes-new 源安装 kubeadm/kubelet/kubectl；最后 kubeadm init
> 初始化 master、生成令牌加入 node，部署 flannel 并验证集群状态。

> **技术备注**
>
> CentOS 7 已于 2024 年 6 月 30 日停止维护（EOL），建议迁移至 Rocky Linux 9 /
> AlmaLinux 9 或国产 openEuler。Kubernetes v1.30 发布于 2024 年 4 月，官方
> 支持期至 2025 年 6 月底。kubeadm 自 v1.24 起移除 dockershim，本文同时安装
> 了 containerd 与 Docker，实际对接的是 containerd（config.toml 中的
> `SystemdCgroup`、`sandbox_image` 即为其配置），若要以 Docker 作为运行时
> 需额外安装 cri-dockerd；kubeadm 默认镜像源 registry.k8s.io 国内访问受限，
> 本文统一改用阿里云镜像仓库与 kubernetes-new yum 源。

## 1. 准备工作

系统版本为 CentOS Linux release 7.9，两台机器分别设置主机名：

```shell
hostnamectl set-hostname k8s-master
hostnamectl set-hostname k8s-node1
```

写入 /etc/hosts：

```text
192.168.117.224 k8s-master
192.168.117.225 k8s-node1
```

安装基础软件包，关闭防火墙，统一时区：

```shell
yum -y install wget jq psmisc vim net-tools nfs-utils telnet yum-utils device-mapper-persistent-data lvm2 git network-scripts tar curl -y
systemctl stop firewalld && systemctl disable firewalld
systemctl stop iptables && systemctl disable iptables

timedatectl set-timezone Asia/Shanghai
timedatectl set-local-rtc 0
systemctl restart rsyslog
systemctl restart crond
```

## 2. 内核参数与系统配置

写入 sysctl 配置并生效：

```shell
cat > kubernetes.conf<<EOF
#开启网桥模式【重要】
net.bridge.bridge-nf-call-iptables=1
#开启网桥模式【重要】
net.bridge.bridge-nf-call-ip6tables=1
net.ipv4.ip_forward=1
net.ipv4.tcp_tw_recycle=0
#禁止使用swap空间，只有当系统OOM时才允许使用它
vm.swappiness=0
#不检查物理内存是否够用
vm.overcommit_memory=1
#开启OOM
vm.panic_on_oom=0
fs.inotify.max_user_instances=8192
fs.inotify.max_user_watches=1048576
fs.file-max=52706963
fs.nr_open=52706963
#关闭ipv6【重要】
net.ipv6.conf.all.disable_ipv6=1
net.netfilter.nf_conntrack_max=2310720
EOF

cp kubernetes.conf /etc/sysctl.d/kubernetes.conf
modprobe ip_conntrack
sysctl -p /etc/sysctl.d/kubernetes.conf
```

journald 日志持久化：

```shell
mkdir /etc/systemd/journal.conf.d
cat >/etc/systemd/journal.conf.d/99-prophet.conf <<EOF
[Journal]
#持久化保存到磁盘
Storage=persistent
#压缩历史日志
Compress=yes
SyncIntervalSec=5m
RateLimitInterval=30s
RateLimitBurst=1000
#最大占用空间10G
SystemMaxUse=10G
#单日志文件最大200M
SystemMaxFileSize=200M
#日志保存时间2周
MaxRetentionSec=2week
#不将日志转发到syslog
ForwardToSyslog=no
EOF

systemctl restart systemd-journald
```

kube-proxy 开启 ipvs 的前置条件：

```shell
yum install -y ipset ipvsadm
for i in $(ls /usr/lib/modules/$(uname -r)/kernel/net/netfilter/ipvs|grep -o "^[^.]*");do echo $i; /sbin/modinfo -F filename $i >/dev/null 2>&1 && /sbin/modprobe $i;done
```

## 3. 安装 Docker 与 containerd

```shell
yum install -y yum-utils device-mapper-persistent-data lvm2
yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo
yum install -y docker-ce docker-ce-cli containerd.io
```

containerd 配置：

```shell
cat << EOF > /etc/modules-load.d/containerd.conf
overlay
br_netfilter
EOF

modprobe overlay
modprobe br_netfilter

mkdir -p /etc/containerd
containerd config default > /etc/containerd/config.toml
```

编辑 /etc/containerd/config.toml，修改两处（行首数字为默认配置中的行号）：

```text
127 SystemdCgroup = true
63 sandbox_image = "registry.aliyuncs.com/google_containers/pause:3.9"
```

```shell
systemctl restart containerd
systemctl enable containerd
```

/etc/docker/daemon.json 的内容（各行注释为原文说明）：

```text
{
  #Docker的镜像加速器配置。加速地址可以登录阿里云官网获取
  "registry-mirrors": ["https://"],
  #指定了Docker容器使用的cgroup驱动程序并交由systemd管理
  "exec-opts": ["native.cgroupdriver=systemd"],
  #这个配置项指定了Docker容器日志的驱动程序
  "log-driver": "json-file",
  #指定了单个容器日志文件的最大大小为100m
  "log-opts": {
    "max-size": "100m"
  }
}
```

```shell
systemctl daemon-reload
systemctl restart docker.service
systemctl enable docker.service
```

## 4. 安装 kubeadm / kubelet / kubectl

配置阿里云 kubernetes 源：

```shell
sudo cat <<EOF | tee /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://mirrors.aliyun.com/kubernetes-new/core/stable/v1.30/rpm/
enabled=1
gpgcheck=0
gpgkey=https://mirrors.aliyun.com/kubernetes-new/core/stable/v1.30/rpm/repodata/repomd.xml.key
EOF
yum clean all
yum makecache
```

安装并启用 kubelet：

```shell
yum install kubectl kubeadm kubelet -y

cat > /etc/sysconfig/kubelet <<EOF
KUBELET_EXTRA_ARGS="--cgroup-driver=systemd"
EOF
systemctl enable kubelet.service
```

## 5. 部署 master

先查看所需镜像列表，再初始化集群：

```shell
kubeadm config images list

kubeadm init \
--apiserver-advertise-address=192.168.117.224 \
--image-repository registry.aliyuncs.com/google_containers \
--kubernetes-version v1.30.2 \
--service-cidr=10.1.0.0/16 \
--pod-network-cidr=10.244.0.0/16 --v=6
```

初始化失败可以执行：

```shell
kubeadm reset -f
journalctl -u kubelet
```

配置 kubectl 凭据：

```shell
mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config
export KUBECONFIG=/etc/kubernetes/admin.conf

echo "export KUBECONFIG=/etc/kubernetes/admin.conf" >> ~/.bashrc
```

## 6. 添加 node 节点

查看令牌与 CA 证书哈希，生成新令牌用于 node 加入：

```shell
kubeadm token list

#查看密码
openssl x509 -pubkey -in /etc/kubernetes/pki/ca.crt | openssl rsa -pubin -outform der 2>/dev/null | openssl dgst -sha256 -hex | sed 's/^.* //'

#生成新令牌，加入node
kubeadm token create --print-join-command
```

## 7. 部署 flannel 网络插件并验证

```shell
kubectl apply -f https://raw.githubusercontent.com/coreos/flannel/master/Documentation/kube-flannel.yml

kubectl get nodes
kubectl get pods -n kube-system

sudo systemctl restart kubelet
```
