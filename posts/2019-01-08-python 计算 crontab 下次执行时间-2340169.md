> **内容介绍**
>
> 使用 Python 的 croniter 库根据 crontab 表达式计算下一次执行时间：安装依赖后以当前时间为起点调用 `get_next()`，即可得到格式化后的下次触发时间字符串。常用于定时任务管理类系统向用户展示任务下次运行时间。
>
> **技术备注**
>
> croniter 至今仍活跃维护（已支持 Python 3.8+），API 与文中基本一致。注意安装命令原文误写成 `python 3.6 -m pip`，正确写法应为 `pip3 install croniter`。

---

```shell
pip3 install croniter
```

```python
import croniter
import datetime

def run_get_next_time(sched):
    now = datetime.datetime.now()
    cron = croniter.croniter(sched, now)
    return [cron.get_next(datetime.datetime).strftime("%Y-%m-%d %H:%M")][0]

print(run_get_next_time("* * * * *"))
```
