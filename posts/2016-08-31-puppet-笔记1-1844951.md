> **内容介绍**
>
> Puppet 入门实操笔记：在两台机器上搭建 master/agent 架构，完成证书签发建立信任（agent 发起请求、master 端 `puppet cert --sign` 签发），然后编写 site.pp 与 node.pp 清单，演示用 package 资源装软件、用 file 资源在 agent 上创建文件并设置权限。

> **技术备注**
>
> 本文是 Puppet 3.x 时代的写法：`puppet master` 直接起服务、`import` 语句、`puppet cert` 子命令在 Puppet 4+ 均已废弃，现代版本使用 puppetserver（JVM 服务）、`puppetserver ca` 管理证书，清单入口为 `/etc/puppetlabs/code/environments/production/manifests`。如今配置管理领域 Ansible 更为主流。

---

master 与 agent 之间通过证书加密建立信任。

## 一、环境准备与安装

两台机器的 hosts 解析：

```text
192.168.2.130   puppet.hequan.lol   puppet
192.168.2.131   station.hequan.lol  station
```

```bash
# master 端
yum install puppet.noarch puppet-server.noarch
# agent 端
yum install puppet.noarch
```

## 二、配置并启动 master

```bash
[root@puppet puppet]# ls
auth.conf  fileserver.conf  manifests  modules  puppet.conf
[root@puppet puppet]# vim puppet.conf
```

```ini
[master]
    certname=puppet.hequan.lol
```

```bash
[root@puppet puppet]# puppet master
[root@puppet puppet]# netstat -lntup | grep 8140
tcp        0      0 0.0.0.0:8140            0.0.0.0:*               LISTEN      2580/ruby
```

## 三、agent 发起证书请求

```bash
[root@station ~]# puppet agent --server=puppet.hequan.lol --no-daemonize --verbose --onetime   ## 默认去找puppet
```

master 端查看请求并签发：

```bash
[root@puppet puppet]# ll /var/lib/puppet/ssl/ca/requests/

[root@puppet puppet]# puppet cert --list
```

## 四、编写清单

`/etc/puppet/manifests` 是管理服务器清单目录，里面需要 xxx.pp 文件：

```bash
[root@puppet manifests]# ll
-rw-r--r-- 1 root root 159 8月  31 20:58 node.pp
-rw-r--r-- 1 root root  53 8月  31 20:48 site.pp

[root@puppet manifests]# cat site.pp
```

```puppet
$puppetserver="puppet.hequan.lol"
import 'node.pp'
```

```bash
[root@puppet manifests]# cat node.pp
```

```puppet
node 'station.hequan.lol' {
    #定义资源的方式：
    #资源类型{'资源名'：属性1=>'值1'}
    package{"system-config-date":ensure=>'present'}
}
```

也可以定义 nginx 软件包与文件资源：

```puppet
package {'nginx':
    ensure => present,
}

file {"/root/aa1.txt":
    ensure => "present",
    mode   => "0000"
}
```

agent 端执行后验证：

```bash
[root@station puppet]# ll /root
总用量 4
---------- 1 root root 0 8月  31 21:26 aa1.txt
```
