> **内容介绍**
>
> 用 Docker Compose 部署 Redash 10.0.0-beta：编排 server、scheduler、scheduled_worker、adhoc_worker、Redis、PostgreSQL 与 Nginx 七个服务，通过环境文件配置数据库、Redis、Cookie 密钥与邮件参数，最后初始化数据库并启动。

> **技术备注**
>
> 示例基于 Redash 10.0.0-beta 与 Docker Compose v1 语法编写；Redash 10.0.0 正式版及后续版本已发布，且 Docker Compose v2 推荐使用 `docker compose`（无连字符）。原文 `docker -compose` 为笔误，正确命令为 `docker-compose` 或 `docker compose`。PostgreSQL 9.6 与 Redis 5.0 均已 EOL，生产环境建议升级。

### 安装文件

```yaml
version: "3.4"
x-redash-service: &redash-service
  image: redash/redash:10.0.0-beta.b49597
  depends_on:
    - postgres
    - redis
  env_file: /opt/redash/env
  restart: always
services:
  server:
    <<: *redash-service
    command: server
    ports:
      - "5000:5000"
    environment:
      REDASH_WEB_WORKERS: 4
  scheduler:
    <<: *redash-service
    command: scheduler
    environment:
      QUEUES: "celery"
      WORKERS_COUNT: 1
  scheduled_worker:
    <<: *redash-service
    command: worker
    environment:
      QUEUES: "scheduled_queries,schemas"
      WORKERS_COUNT: 1
  adhoc_worker:
    <<: *redash-service
    command: worker
    environment:
      QUEUES: "queries"
      WORKERS_COUNT: 2
  redis:
    image: redis:5.0-alpine
    restart: always
  postgres:
    image: postgres:9.6-alpine
    env_file: /opt/redash/env
    volumes:
      - /opt/redash/postgres-data:/var/lib/postgresql/data
    restart: always
  nginx:
    image: redash/nginx:latest
    ports:
      - "80:80"
    depends_on:
      - server
    links:
      - server:redash
    restart: always
```

### 启动

```shell
docker-compose up -d

docker-compose -f docker-compose.yml run --rm server create_db
```
