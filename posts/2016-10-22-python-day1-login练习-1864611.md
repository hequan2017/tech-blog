> **内容介绍**
>
> 本文是 Python 入门第一天的练习：实现一个命令行用户登录程序。程序读取 `account.txt` 账号文件校验用户名密码，密码用 `getpass` 隐藏输入；同一用户密码连续输错 3 次会被写入 `account_lock.txt` 锁定文件，之后该用户再登录时直接拒绝。代码综合运用了文件读写、`while` 循环、`for...else` / `while...else` 结构和 `sys.exit` 退出。

> **技术备注**
>
> 代码基于 Python 3（`input`、`print()` 语法），在 Python 3.12/3.13（2026 年主流版本）仍可运行。注意两点：`os.system('cls')` 仅适用于 Windows，Linux/macOS 应为 `clear`；明文保存密码仅为教学示例，实际项目必须用 `hashlib`/`bcrypt` 做哈希存储。原文代码块语言标记被爬虫截断成 `bas` + `h`，已修正为 `python`。

## 1. 程序功能

![python-day1-login练习_用户登录](assets/1864611/01_wKiom1gLTNaQZ8QvAAD4SS6Cq3s810.png)

登录程序的执行逻辑：

1. 用户最多有 3 次输入用户名的机会。
2. 输入用户名后先检查 `account_lock.txt`，若该用户已被锁定则直接退出。
3. 在 `account.txt` 中匹配用户名，匹配成功则进入密码验证（同样有 3 次机会）。
4. 密码 3 次错误后把该用户名追加到锁定文件并退出；用户名 3 次不匹配则直接退出。

## 2. 数据文件格式

`account.txt`：每行一个账号，用户名和密码以空格分隔：

```text
alice 123456
bob  abcdef
```

`account_lock.txt`：每行一个被锁定的用户名（程序自动写入）。

## 3. 完整代码

```python
#!/usr/bin/python
#_*_ coding:utf-8 _*_
import sys, os, getpass

os.system('cls')   # 清屏（仅 Windows；Linux/macOS 应改为 'clear'）

i = 0
while i < 3:                                                     # 只要用户登录异常不超过3次就不断循环
    name = input("请输入用户名：")
    lock_file = open('account_lock.txt', 'r+')                   # 当用户输入用户名后，打开 LOCK 文件以检查此用户是否已被锁定
    lock_list = lock_file.readlines()
    for lock_line in lock_list:                                  # 循环 LOCK 文件
        lock_line = lock_line.strip('\n')                        # 去掉换行符
        if name == lock_line:                                    # 如果已锁定就直接退出
            sys.exit('用户 %s 已经被锁定，退出' % name)
    user_file = open('account.txt', 'r')                         # 打开帐号文件
    user_list = user_file.readlines()
    for user_line in user_list:                                  # 对帐号文件进行遍历
        (user, password) = user_line.strip('\n').split()         # 分别获取帐号和密码信息
        if name == user:                                         # 用户名正常匹配
            j = 0
            while j < 3:                                         # 只要密码异常不超过3次就不断循环
                passwd = getpass.getpass('请输入密码：')          # 输入隐藏密码（不回显）
                if passwd == password:                           # 密码正确，提示欢迎登录
                    print('欢迎登录管理平台，用户%s' % name)
                    sys.exit(0)                                  # 正常退出
                else:
                    if j != 2:                                   # j=2 时是最后一次机会，不用再提示剩余 0 次
                        print('用户 %s 密码错误，请重新输入，还有 %d 次机会' % (name, 2 - j))
                j += 1                                           # 密码输入错误后，循环计数加 1
            else:
                lock_file.write(name + '\n')                     # 密码三次错误后，将该用户追加到 LOCK 文件
                sys.exit('用户 %s 达到最大登录次数，将被锁定并退出' % name)
        else:
            pass                                                 # 用户名不匹配时，跳过并继续循环
    else:
        if i != 2:                                               # i=2 时是最后一次机会，不用再提示剩余 0 次
            print('用户 %s 不存在，请重新输入，还有 %d 次机会' % (name, 2 - i))
    i += 1                                                       # 用户名输入错误时，循环计数加 1
else:
    sys.exit('用户 %s 不存在，退出' % name)                      # 用户名三次错误后，异常退出

lock_file.close()                                                # 关闭 LOCK 文件
user_file.close()                                                # 关闭帐号文件
```

## 4. 要点说明

- `while ... else` / `for ... else`：`else` 在循环**没有被 `break` 打断、正常耗尽**时执行，本文用它实现"三次机会用完"的兜底分支。
- `getpass.getpass()`：读取密码时终端不回显，比 `input()` 更适合口令输入。
- 文件句柄在 `sys.exit()` 前未显式 `close()`，依赖进程退出时释放；更稳妥的写法是使用 `with open(...) as f:` 上下文管理器。
