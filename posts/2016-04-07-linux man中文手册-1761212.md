> **内容介绍**
>
> 本文记录在 Linux 上源码安装 man 中文手册（manpages-zh 1.5.2）的完整过程：
> 从软件源 wget 下载压缩包、tar 解压、./configure --disable-zhtw 配置、
> make / make install 编译安装，再向 /etc/profile 写入
> `alias hman='man -M /usr/local/share/man/zh_CN'` 并 source 生效，之后即可
> 用 hman 命令查看中文 man 手册，文末附可直接复制执行的完整命令串。

> **技术备注**
>
> - 文中 `pkgs.fedoraproject.org` 下载地址已失效，项目现已迁至 GitHub
>   （man-pages-zh/manpages-zh），请从 Releases 页获取新版源码包。
> - 如今无需源码编译：Debian/Ubuntu 用 `apt install manpages-zh`，
>   RHEL/CentOS 用 `yum install man-pages-zh-CN`，再配置别名或
>   `man -L zh_CN.UTF-8` 即可。

看英文实在是有点晕，在网上找了一个关于 man 中文手册的，现在整理到下面。

## 1. 分步安装

下载文件（用 Windows 下载后 rz 传到 Linux 上也行）：

```bash
wget http://pkgs.fedoraproject.org/repo/pkgs/man-pages-zh-CN/manpages-zh-1.5.2.tar.bz2/cab232c7bb49b214c2f7ee44f7f35900/manpages-zh-1.5.2.tar.bz2
```

解压缩：

```bash
tar xvf manpages-zh-1.5.2.tar.bz2
cd manpages-zh-1.5.2
```

编译安装：

```bash
./configure --disable-zhtw
make
make install
```

## 2. 定义别名并生效

向 /etc/profile 追加一个 hman 别名，指向中文手册目录：

```bash
echo "alias hman='man -M /usr/local/share/man/zh_CN'" >> /etc/profile
```

系统变量生效：

```bash
source /etc/profile
```

使用：`hman cp`

## 3. 完整命令（可直接复制）

直接复制下面的命令就可以了，亲测可用：

```bash
wget http://pkgs.fedoraproject.org/repo/pkgs/man-pages-zh-CN/manpages-zh-1.5.2.tar.bz2/cab232c7bb49b214c2f7ee44f7f35900/manpages-zh-1.5.2.tar.bz2 &> /dev/null
tar xvf manpages-zh-1.5.2.tar.bz2
cd manpages-zh-1.5.2
./configure --disable-zhtw
make
make install
echo "alias hman='man -M /usr/local/share/man/zh_CN'" >> /etc/profile
source /etc/profile
```
