> **内容介绍**
>
> 本文介绍 metrics-server 在 Kubernetes v1.25 集群中的快速部署：下载官方 components.yaml，替换镜像地址为国内可访问源，添加 `--kubelet-insecure-tls` 跳过 kubelet 证书校验，最后通过 `kubectl top node` 验证 CPU/内存指标采集正常。
>
> **技术备注**
>
> `--kubelet-insecure-tls` 仅适合测试环境；生产环境应配置 kubelet 证书签名或使用 `--kubelet-preferred-address-types` 指定 InternalIP。metrics-server 镜像建议替换为阿里云镜像仓库，避免 GitHub 访问受限。

---

```shell
监控  metrics-server

wget  https:///kubernetes-sigs/metrics-server/releases/latest/download/components.yaml

sed -i "s#/metrics-server#/chenby#g" components.yaml

vim +140 components.yaml

- --kubelet-insecure-tls

kubectl apply -f components.yaml

[root@k8s-master ~]# kubectl top node k8s-node1
NAME        CPU(cores)   CPU%   MEMORY(bytes)   MEMORY%
k8s-node1   113m         2%     1035Mi          61%
```
