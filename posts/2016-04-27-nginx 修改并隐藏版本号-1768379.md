> **内容介绍**
>
> 修改并隐藏 Nginx 版本号的两种办法:一是编译前改源码——nginx.h 中的
> NGINX_VERSION / NGINX_VER / NGINX_VAR 宏,以及
> ngx_http_header_filter_module.c 的 Server 头字符串、
> ngx_http_special_response.c 的错误页字符串,可把版本号和软件名一并改掉;
> 二是在配置文件 http/server/location 块加 server_tokens off,隐藏版本号
> (默认值为 on,会显示完整版本信息)。

> **技术备注**
>
> Nginx 配置在不同大版本间略有差异,建议以当前稳定版(1.24+/1.26+)官方文档
> 为准。注意 `server_tokens off` 只隐藏版本号,响应头仍保留 `Server: nginx`
> 字样;若要彻底去掉 Server 头,需借助 headers-more 模块
> (`more_clear_headers Server`)或采用方法一改源码重编译。

---

## 1. 查看当前版本信息

```shell
curl -I 192.168.10.11 | grep Server
```

## 2. 方法一:编译前修改源码(修改版本及版本号)

`src/core/nginx.h`:

```c
#define nginx_version      1008001
#define NGINX_VERSION      "1.8.1"                  # 修改想要显示的版本,如 2.2.23
#define NGINX_VER          "nginx/" NGINX_VERSION   # 将 nginx 改成想要显示的软件名称
#define NGINX_VAR          "NGINX"                  # 将 NGINX 改成想要的软件名称(Evan Web Server)
#define NGX_OLDPID_EXT     ".oldbin"
```

`src/http/ngx_http_header_filter_module.c`:

```c
static char ngx_http_server_string[] = "Server: nginx" CRLF;   # 将 nginx 改为想要的名称
```

`src/http/ngx_http_special_response.c`:

```c
"<hr><center>nginx</center>" CRLF   # 错误页中显示的软件名,同样可改
```

## 3. 方法二:隐藏版本号

在 nginx 配置文件里增加 `server_tokens off;`。其作用域是 http、server、
location 语句块;默认值是 on,表示显示版本信息,设置为 off 就可以在所有地方
隐藏 nginx 的版本信息。

```nginx
http {
    server_tokens off;
}
```
