> **内容介绍**
>
> 本文是一篇 Vue 3 前端实践笔记：基于 element 的 el-autocomplete
> 组件实现自动补全输入框，并适配多个输入框（v-for 遍历）的场景。
> 给出了组件模板写法，以及 querySearch 候选查询、createFilter
> 过滤、handleSelect 选中回调的组合式 API 实现。

> **技术备注**
>
> - 本文代码为 Vue 3 组合式 API 写法，组件对应的是 Element Plus；
>   面向 Vue 2 的 element-ui 已随 Vue 2 于 2023 年 12 月 31 日
>   停止官方维护，新项目建议直接使用 Element Plus。
> - 原文 `:value-key="测试"` 会把「测试」当作 JS 变量求值，
>   已修正为静态属性 `value-key="测试"`，与候选对象中的
>   "测试" 字段名对应。

## 1. 基于 element

### 组件模板

```html
<el-autocomplete
    class="inline-input"
    v-model="item.content"
    :key="index"
    :fetch-suggestions="querySearch"
    placeholder="请输入内容"
    @select="handleSelect"
    style="width: 769px"
    value-key="测试"
>
```
