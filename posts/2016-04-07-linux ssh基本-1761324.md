## 1. 协议与软件组成

SSH（Secure Shell Protocol）用于远程连接，默认端口 22，协议版本 ssh2，
主要包含 ssh 远程连接和 SFTP 服务。

服务端为 OpenSSH：

```shell
# rpm -qa openssh openssl
openssh-5.3p1-94.el6.x86_64
openssl-1.0.1e-15.el6.x86_64      # 负责加密
```

查看进程：

```shell
# ps -ef | grep sshd
root       1243      1  0 19:06 ?        00:00:00 /usr/sbin/sshd
```

## 2. 密钥机制（v1 与 v2 的区别）

支持 RSA、DSA 密钥，分为公钥（Public key）和私钥（Private key）。

查看配置文件：

```shell
# less /etc/ssh/sshd_config          # 配置文件
# grep ServerKey /etc/ssh/sshd_config    # 临时公钥
#ServerKeyBits 1024
```

首次连接（会接受服务端的公钥）：

```shell
# ssh root@192.168.10.10
The authenticity of host '192.168.10.10 (192.168.10.10)' can't be established.
RSA key fingerprint is c6:94:5f:af:17:75:7f:dd:bc:2a:54:83:f3:5a:d2:dc.
Are you sure you want to continue connecting (yes/no)?
```

客户端会记录密钥信息（配置见 `/etc/ssh/ssh_config`）：

```shell
# ll ~/.ssh/known_hosts
-rw-r--r-- 1 root root 395 4月   3 19:37 /root/.ssh/known_hosts
```

**SSH 1.x 版本**：ServerKey + Private Key = Key pair，生成此密钥对后，
通过它交换数据。

> ⚠️ 危险：此后交换数据不再检查 key pair，存在被篡改的风险。

**Version 2** 多加了一个确认联机正确性的 Diffie-Hellman 机制，
检查数据的来源是否正确。

认证方式两种：**基于口令**、**基于密钥**。

## 3. 查看端口与服务

```shell
# netstat -lntup | grep 22
tcp        0      0 0.0.0.0:22                  0.0.0.0:*                   LISTEN      1162/sshd
tcp        0      0 :::22                       :::*                        LISTEN      1162/sshd
```

```shell
# lsof -i :22
COMMAND  PID USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
sshd    1162 root    3u  IPv4  10478      0t0  TCP *:ssh (LISTEN)
sshd    1162 root    4u  IPv6  10480      0t0  TCP *:ssh (LISTEN)
sshd    1437 root    3r  IPv4  11491      0t0  TCP 192.168.10.11:ssh->bogon:62818 (ESTABLISHED)
```

扫描端口：

```shell
# nmap 192.168.10.10 -p1-65535
```

## 4. 基本命令

ssh 远程连接：

```shell
# ssh root@192.168.10.10
# ssh root@192.168.10.10 ifconfig
```

scp 复制文件：

```shell
# scp xx root@192.168.10.10:/tmp       # cp 文件 xx 到远端 /tmp
# scp root@192.168.10.10:/tmp/xx .     # 相反，从远端拉回当前目录
```

SFTP：

```shell
# sftp root@192.168.10.10
sftp> put /root/xx /tmp     # 上传，加客户端本地路径
sftp> get /root/xx /tmp     # 下载到本地的当前目录
```
