> **内容介绍**
>
> OpenStack 学习笔记第一篇：先简要区分 SaaS/PaaS/IaaS/XaaS 概念，然后以 CentOS 7.2 为环境，用 RDO 项目的 packstack 工具安装 OpenStack Liberty 版本。内容包括两种安装方式（allinone 一键安装与应答文件安装）、如何批量修改应答文件中的密码、安装完成后如何用 keystonerc_admin 登录 Dashboard，以及如何通过修改应答文件添加第二个计算节点（192.168.1.202）。

> **技术备注**
>
> OpenStack Liberty（2015 年发布）和 Mitaka 早已 EOL，2026 年社区维护的版本已进入 2024/2025 命名体系（如 Caracal、Dalmatian）。packstack 目前仅用于单机实验，生产部署建议用 Kolla-Ansible。CentOS 7 已于 2024 年 6 月 EOL，应迁移到 Rocky Linux 9 / openEuler 22.03 等。此外文中的 keystone v2.0 API（OS_AUTH_URL 带 /v2.0）早已废弃，现在统一使用 v3。

## 1. 云计算服务模式与 OpenStack 版本

- SaaS：软件即服务
- PaaS：平台即服务（原文写作 "PasS"，为笔误）
- IaaS：基础设施即服务
- XaaS：一切皆服务

写本文时的 OpenStack 版本情况：

- Liberty 版本（代号含义：自由）
- Mitaka 版本（当时最新版，代号来自日本三鹰市）

RDO 是红帽主导的开源项目，把 OpenStack 打包成 RPM 发布，配套 **packstack** 工具完成安装。packstack 有两种用法：

- **allinone**：所有组件全部装在一台机器上，不好定制，只适合测试环境。注意：allinone 安装时会从互联网下载一个 cirros 测试镜像。
- **应答文件（answer file）**：可定制各组件装在哪台机器、用什么密码，适合多节点部署。

实验环境：

```shell
[root@h1 ~]# cat /etc/redhat-release
CentOS Linux release 7.2.1511 (Core)
```

网络规划：

- 控制节点：192.168.1.201（h1）
- 计算节点：192.168.1.202（h2）（原文写作"结算节点"，为笔误，应为"计算节点"）

## 2. 安装前准备：关闭 NetworkManager、配置 yum 源

```shell
# 停止并禁用 NetworkManager（OpenStack 网络服务与之冲突）
[root@h1 ~]# systemctl is-active NetworkManager
active
[root@h1 ~]# systemctl stop NetworkManager
[root@h1 ~]# systemctl disable NetworkManager
```

软件包可从镜像站下载：http://mirrors.163.com/centos/7.2.1511/cloud/x86_64/ ，按需要的 OpenStack 版本选择（此次安装的是 Liberty）。然后配置本地 yum 源：

```ini
# /etc/yum.repos.d/openstack.repo
[openstack]
name=openstack
baseurl=file:///root/openstack   # 指向存放下载软件的目录
enabled=1
gpgcheck=0
```

```shell
yum clean all
```

## 3. 安装 packstack

```shell
# 确认源里能查到 packstack 包
[root@h1 openstack]# yum list openstack-packstack
可安装的软件包
openstack-packstack.noarch   1:7.0.0-0.10.dev1682.g42b3426.el7   openstack

[root@h1 openstack]# yum install openstack-packstack
```

## 4. 方式一：allinone 一键安装

```shell
# 查看 demo 选项
[root@h1 openstack]# packstack --help | grep demo
  Provisioning demo config:
    --provision-demo=PROVISION_DEMO
                        Specify 'y' to provision for demo usage and testing.

# 全部组件安装到本机，不配置 demo 租户网络
[root@h1 openstack]# packstack --allinone --provision-demo=n
```

## 5. 方式二：应答文件安装

```shell
[root@h1 ~]# packstack --help | grep ans
  --gen-answer-file=GEN_ANSWER_FILE
                        Generate a template of an answer file.
  --answer-file=ANSWER_FILE

# 生成应答文件模板
[root@h1 ~]# packstack --gen-answer-file=he.txt

# 关掉不需要的组件（应答文件中的行号位置）
#  67  CONFIG_NAGIOS_INSTALL=n
# 1116  CONFIG_PROVISION_DEMO=n

[root@h1 ~]# grep _PW he.txt    # 查看所有密码配置项

# 把所有 *_PW=xxx 形式的密码统一改成 hequan（-i.bak 保留备份 he.txt.bak）
[root@h1 ~]# sed -i.bak -r 's/(.+_PW)=.+/\1=hequan/' he.txt

# 按应答文件开始安装
[root@h1 ~]# packstack --answer-file=he.txt
```

## 6. 登录验证

命令行工具使用前先 source 认证文件：

```shell
[root@h1 ~]# cat keystonerc_admin
unset OS_SERVICE_TOKEN
export OS_USERNAME=admin
export OS_PASSWORD=hequan
export OS_AUTH_URL=http://192.168.1.201:5000/v2.0   # keystone v2.0 API（已废弃，现为 v3）
export PS1='[[34m\u@\h \W(keystone_admin)[0m]\$ '
export OS_TENANT_NAME=admin
export OS_REGION_NAME=RegionOne
```

浏览器访问 `http://192.168.1.201/dashboard`，右上角用 admin / hequan 登录，可以设置语言和时区。

## 7. 添加计算节点

在计算节点 h2（192.168.1.202）上同样配置好 yum 和 OpenStack 软件环境，然后在控制节点配置免密登录：

```shell
[root@h1 ~]# ssh-keygen                                  # 生成密钥对（一路回车）
[root@h1 ~]# ssh-copy-id -i .ssh/id_rsa.pub h2           # 拷贝公钥到 h2
```

修改应答文件，把新节点加入计算主机列表：

```shell
vim he.txt
# 84  # List the servers on which to install the Compute service.
# 85  CONFIG_COMPUTE_HOSTS=192.168.1.201,192.168.1.202   # 追加上新节点即可

# 再次执行安装，packstack 是幂等的，不会覆盖已有配置，只会把新节点装好
packstack --answer-file=he.txt
```
