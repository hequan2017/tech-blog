## 1. 简介与对象转换

jQuery 是 DOM/BOM/JavaScript 的类库（模块 <=> 类库），官网 https://jquery.com 。

版本：1.x（1.12）、2.x、3.x。

jQuery 对象与 DOM 对象的转换：

- `jquery对象[0]` => DOM 对象
- `Dom对象` => `$(Dom对象)`

## 2. 查找元素

DOM 的查找方式有 10 个左右；jQuery 用选择器直接找到某个或某类标签：

```javascript
$('#id')        // 1. id
$(".c1")        // 2. class
$('a')          // 3. 标签
$('a,.c2,#i10') // 4. 组合
$('#i10 a')     // 5. 层级：子子孙孙
$('#i10>a')     // 5. 层级：儿子
:first          // 6. 基本
:last
:eq()
$('[alex]')          // 7. 属性：具有 alex 属性的所有标签
$('[alex="123"]')    // alex 属性等于 123 的标签
$("input[type='text']")  // 等价于 $(':text')
```

层级选择器对应的 HTML 结构示例：

```html
<div id='i10' class='c1'>
    <a>f</a>
    <a>f</a>
</div>
<div class='c1'>
    <a>f</a>
</div>
```

属性筛选对应的 input 示例：

```html
<input type='text'/>
<input type='text'/>
<input type='file'/>
<input type='password'/>
```

## 4. 筛选

```javascript
$('#i1').next()            // 下一个
$('#i1').nextAll()         // 下边所有的
$('#i1').nextUntil('#ii1') // 直到找到 ii1
$('#i1').prev()            // 上一个
$('#i1').prevAll()         // 上面所有
$('#i1').prevUntil('#ii1')
$('#i1').parent()          // 父标签
$('#i1').parents()         // 祖先的标签
$('#i1').parentsUntil()    // 找到哪里终止
$('#i1').children()        // 孩子
$('#i1').siblings()        // 兄弟
$('#i1').find()            // 子子孙孙中查找
```

筛选对应的 HTML 结构示例：

```html
<div>
    <a>asdf</a>
    <a>asdf</a>
    <a id='i1'>asdf</a>
    <a>asdf</a>
    <a id='ii1'>asdf</a>
    <a>asdf</a>
</div>
```

其他：`$('li:eq(1)')` 等价于 `$('li').eq(1)`；`first()`、`last()`、
`hasClass(class)`；PS：`index` 获取索引位置。

## 5. 文本、样式与属性操作

文本操作：

```javascript
$(..).text()               // 获取文本内容
$(..).text("<a>1</a>")     // 设置文本内容
$(..).html()
$(..).html("<a>1</a>")
$(..).val()                // input 设置值
$(..).val(..)
```

样式操作：

```javascript
addClass
removeClass
toggleClass    // 开关

$('#i1').click(function(){
    $('.c1').toggleClass('hide');
})
```

属性操作——`attr` 专门用于自定义属性：

```javascript
$(..).attr('n')       // 获取值
$(..).attr('n','v')   // 第一个是属性名，第二个是更新的值
$(..).removeAttr('n') // 删除
```

`prop` 专门用于 checkbox、radio：

```html
<input type='checkbox' id='i1'  />
```

```javascript
$(..).prop('checked')
$(..).prop('checked', true)
```

## 8. 事件

DOM 有三种绑定方式；jQuery 的写法：

```javascript
$('.c1').click()
$('.c1').bind('click', function(){ })
$('.c1').unbind('click', function(){ })

// ******************* 特殊的
$('.c').delegate('a', 'click', function(){ })     // 委托
$('.c').undelegate('a', 'click', function(){ })

$('.c1').on('click', function(){ })
$('.c1').off('click', function(){ })
```

阻止事件发生：`return false`。

当页面框架加载完成之后，自动执行：

```javascript
$(function(){
    $(...)
})
```

jQuery 扩展：

- `$.extend`：定义 `$.方法`
- `$.fn.extend`：定义 `$(..).方法`

```javascript
(function(){
    var status = 1;
    // 封装变量
})(jQuery)
```

### 4. 菜单切换

按属性匹配目标面板：

```javascript
$('.menu-item').click(function(){
    $(this).addClass('active').siblings().removeClass('active');
    var target = $(this).attr('a');
    $('.content').children("[b='"+ target+"']").removeClass('hide').siblings().addClass('hide');
});
```

按索引匹配目标面板：

```javascript
$('.menu-item').click(function(){
    $(this).addClass('active').siblings().removeClass('active');
    $('.content').children().eq($(this).index()).removeClass('hide').siblings().addClass('hide');
});
```

### 5. 登录验证

```javascript
$(function(){
    // 当页面所有元素完全加载完毕后，执行
    $(':submit').click(function () {
        $('.error').remove();
        var flag = true;
        $('#f1').find('input[type="text"],input[type="password"]').each(function () {
            var v = $(this).val();
            var n = $(this).attr('tex');
            if(v.length <= 0){
                flag = false;
                var tag = document.createElement('span');
                tag.className = "error";
                tag.innerHTML = n + "必填";
                $(this).after(tag);
                // return false;
            }
        });
        return flag;
    });
});
```
