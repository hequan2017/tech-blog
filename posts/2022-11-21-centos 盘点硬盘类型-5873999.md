> **内容介绍**
>
> CentOS 盘点硬盘类型的运维小脚本：从 /etc/pcdn/pcdn.conf 提取
> macs、bw 配置值；用 lsblk/pvs 定位系统盘设备名（兼容 LVM）；
> 判断 /pcdn_data/pcdn_index_data 是否落在 sda 上并读取其容量；
> 统计其余磁盘块数，并用 lsblk 的 rota 标志区分固态（0）与机械（1）。

> **技术备注**
>
> `lsblk -ar` 以 raw 格式列出全部块设备，最后两列为 TYPE 和 MOUNTPOINT，
> 所以 `$(NF-1)` 取到的是设备类型，`grep -w "/"` 可精确匹配根分区所在行；
> LVM 场景下根设备形如 centos-root，按 `-` 切出 VG 名后用 `pvs` 反查物理盘。
> `rota` 列来自内核 `/sys/block/<设备>/queue/rotational`，0 为固态、1 为机械，
> 也可用 `cat /sys/block/sda/queue/rotational` 直接查看；虚拟机磁盘（如 virtio）
> 或部分云盘该值可能不准，结果仅供参考。注意 `fdisk -l | grep sd | grep -v sda`
> 会把 sdb 的分区（如 sdb1）也计入，统计的是“非 sda 的 sd* 设备行数”而非纯磁盘数。

## 1. 读取 PCDN 配置项（macs / bw）

```shell
# 取 macs 值
cat /etc/pcdn/pcdn.conf | grep macs   | head -n 1 | awk -F" " '{print $2}'

# 取 bw 值
cat /etc/pcdn/pcdn.conf | grep  bw  | head -n 1 | awk -F" " '{print $2}'
```

## 2. 定位系统盘设备名

先用 `lsblk -ar` 找到挂载点为 `/` 的行，取倒数第二列（TYPE）与第一列（设备名）；若是 LVM，则按 `-` 切出 VG 名，用 `pvs` 反查物理盘并去掉分区号；否则直接去掉设备名中的分区号。找不到时输出 0 并退出。

```shell
root_type=`lsblk -ar 2>>/dev/null | grep -w "/" | awk '{print $(NF-1)}'`
root_name=`lsblk -ar 2>>/dev/null | grep -w "/" | awk '{print $1}'`
root_disk=""
if [ x"$root_type" == x"lvm" ];then
  root_vg_name=`echo $root_name | awk -F- '{print $1}'`
  root_disk=`pvs 2>>/dev/null | grep $root_vg_name | awk '{print $1}' | sed 's/[0-9]//;s/\/dev\///'`
else
  root_disk=`lsblk -ar 2>>/dev/null | grep -w "/" | awk '{print $1}' | sed 's/[0-9]//'`
fi

if [ -z "$root_disk" ];then
  echo "0"
  exit 1
else
  echo "$root_disk"
fi
```

## 3. 数据盘位置与容量

检查 `/pcdn_data/pcdn_index_data` 是否落在 sda 上，并读取其容量。

```shell
df -hT | grep  /pcdn_data/pcdn_index_data   | grep sda | wc -l
# 1 支持 / 0 不支持

df -hT | grep  /pcdn_data/pcdn_index_data   | awk -F" "  '{print  $5}'  | awk -F"G" '{print $1}'
# 支持的容量
```

## 4. 磁盘块数与机械/固态判断

```shell
# 系统盘块数
fdisk -l | grep sd | grep -v sda | wc -l

# 0 代表固态，1 代表机械
lsblk  -d -o name,rota | grep sda  | awk -F" "  '{print $2}'
```
