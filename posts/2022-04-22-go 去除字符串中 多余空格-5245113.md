> **内容介绍**
>
> 文章给出一个 Go 字符串清理函数 `StringStrip`：
> 先用 `strings.TrimSpace` 去掉首尾空白，再用正则
> `[\s\p{Zs}]{1,}` 把串内连续空白（含 Unicode 空格）
> 统一替换为一个 "-"，并非直接删除空白字符。
>
> **技术备注**
>
> Go 正则的 `\s` 只匹配 ASCII 空白，需配合 `\p{Zs}`
> 才能覆盖全角空格等 Unicode 空白分隔符；`{1,}` 等价于 `+`。
> 示例为代码片段，实际运行需导入 regexp、strings 两个包。

---

```go
func StringStrip(input string) string {
  if input == "" {
    return ""
  }
  reg := regexp.MustCompile(`[\s\p{Zs}]{1,}`)
  return reg.ReplaceAllString(input, "-")
}

a := StringStrip(strings.TrimSpace(v))
fmt.Println(a)
```
