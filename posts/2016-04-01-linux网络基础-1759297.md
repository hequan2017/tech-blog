> **内容介绍**
>
> 本文是一篇 Linux 网络基础速查笔记，涵盖主机名配置、本地 hosts 解析、禁止 ping、DNS 配置、路由查看与添加，以及 dig、nslookup、traceroute、telnet、nmap、tcpdump 等常用网络诊断命令的基本用法，并以 tcpdump 抓取 ICMP 报文为例展示了 ping 的请求/应答过程。

> **技术备注**
>
> 本文基于 CentOS 6 时代的网络配置方式（/etc/sysconfig/network、route 命令），在 2026 年的主流发行版（CentOS 7+/Rocky/Alma/Ubuntu 22.04+）中：主机名应使用 `hostnamectl set-hostname`；`route`/`ifconfig` 已被 `ip route`/`ip addr` 取代；`netstat` 被 `ss` 取代；NetworkManager（`nmcli`/`nmtui`）成为标准管理工具。tcpdump、dig（现属 bind-utils）、traceroute 仍通用。

## 1. 主机名配置

查看当前主机名：

```shell
hostname   # 查看当前主机名
```

永久修改主机名（CentOS 6 及以前）：

```shell
vi /etc/sysconfig/network
# 修改 HOSTNAME=your.hostname
```

> 注：CentOS 7 及以后请改用 `hostnamectl set-hostname your.hostname`，配置文件为 `/etc/hostname`（原文方式为旧写法）。

本地静态解析：

```shell
vi /etc/hosts
# 格式：IP地址  主机名  别名
```

## 2. 禁止/允许 ping

通过内核参数控制是否响应 ICMP echo：

```shell
vi /etc/sysctl.conf
```

```ini
# 1 表示忽略所有 ICMP echo（禁止 ping），0 表示响应
net.ipv4.icmp_echo_ignore_all = 0
```

```shell
sysctl -p   # 使配置立即生效
```

## 3. DNS 配置

```shell
cat /etc/resolv.conf   # 查看 DNS 服务器配置
# nameserver 8.8.8.8
```

## 4. 路由查看与添加

```shell
route -n   # 查看路由表（-n 以数字形式显示，不做域名解析）

route add default gw 网关IP   # 添加默认网关（原文 "defult" 为笔误，应为 default）
```

> 注：现代发行版推荐 `ip route show` 与 `ip route add default via 网关IP`。

## 5. 常用网络诊断命令

```shell
dig www.baidu.com        # 查询 DNS 解析记录
nslookup www.baidu.com   # 交互式 DNS 查询
traceroute www.baidu.com # 跟踪到目标的路由跳数

telnet 目标IP 80         # 测试 TCP 端口连通性（原文 "telnet ----- 80" 即此意）
nmap 目标IP              # 端口扫描（原文 "nmp" 为笔误，应为 nmap）
```

## 6. tcpdump 抓包示例

抓取 eth0 网卡上的 ICMP 报文：

```shell
tcpdump -n icmp -i eth0   # -n 不解析域名，只抓 icmp 协议
```

ping 一次产生的输出（请求 + 应答各一条）：

```text
19:13:33.470103 IP 192.168.10.5 > 192.168.10.10: ICMP echo request, id 1, seq 1, length 40
19:13:33.470258 IP 192.168.10.10 > 192.168.10.5: ICMP echo reply, id 1, seq 1, length 40
```

第一行为本机发出的 echo request，第二行为对端返回的 echo reply，说明网络层连通正常。
