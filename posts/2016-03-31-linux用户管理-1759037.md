> **内容介绍**
>
> 本文整理 Linux 用户与组管理：UID 分类（0 为 root、1-499 虚拟用户、
> 500-65535 普通用户）、/etc/passwd 与 /etc/shadow；useradd 默认值来自
> /etc/login.defs 与 /etc/default/useradd；useradd/passwd/chage/usermod
> 的常用参数（有效期、锁定解锁、密码老化、--stdin 非交互改密）；附批量
> 创建 100 个用户的 shell 脚本；最后详解 sudo/visudo 的授权格式与
> User/Host/Runas/Cmnd 四类别名定义。

> **技术备注**
>
> UID 1-499 为系统用户是 CentOS 6 的约定，CentOS 7+ 系统用户范围改为
> 1-999；/etc/sysconfig/i18n 在 CentOS 7+ 已被 /etc/locale.conf 取代；
> `passwd --stdin` 是 RHEL 系特有参数；sudoers 始终应通过 visudo 编辑并
> 用 `visudo -c` 校验。

## 1. 用户分类与关键文件

- 0：root
- 1-499：虚拟用户（系统用户）
- 500-65535：普通用户

```text
root:x:0:0:root:/root:/bin/bash
```

相关文件：/etc/passwd、/etc/shadow。

常用命令：useradd、userdel、passwd、chage、usermod、id、su、sudo、
visudo、pwck、finger。

家目录模板：/etc/skel 里的隐藏文件会拷到用户的家目录：

```shell
# ll /etc/skel/ -al
# cp -a .bash* /home/xx/
# chown xx:xx -R /home/xx
# rm -f .*
```

终端乱码时调整字符集：

```shell
# vi /etc/sysconfig/i18n
#LANG="zh_CN.UTF-8"
LANG="zh_CN.GB2312"
# . /etc/sysconfig/i18n
# source /etc/sysconfig/i18n
```

## 2. useradd 默认配置

/etc/login.defs（密码属性相关的内容）：

```shell
# less /etc/login.defs | grep -vE "^$|^#"
MAIL_DIR        /var/spool/mail
PASS_MAX_DAYS   99999
PASS_MIN_DAYS   0
PASS_MIN_LEN    5
PASS_WARN_AGE   7
UID_MIN                   500
UID_MAX                 60000
GID_MIN                   500
GID_MAX                 60000
CREATE_HOME     yes
UMASK           077
USERGROUPS_ENAB yes
ENCRYPT_METHOD SHA512
```

/etc/default/useradd：

```ini
# useradd defaults file
GROUP=100
HOME=/home
INACTIVE=-1
EXPIRE=
SHELL=/bin/bash
SKEL=/etc/skel
CREATE_MAIL_SPOOL=yes
```

## 3. useradd 常用参数

- -e：指定账号的有效期限，缺省表示永久有效
- -g：属组；-G：多个组
- -m：建立用户家目录；-M：不建立用户家目录
- -u：uid；-s：shell

`useradd -D` 直接修改参数，更改用户的默认配置（/etc/default/useradd）：

```shell
# useradd -u 808 -g sa -M -s /sbin/nologin old
# id
# useradd -D -s /bin/sh
SHELL=/bin/sh
# useradd -D -e "2017/04/01"
EXPIRE=2017/04/01
```

账号过期时的提示：

```text
Your account has expired; please contact your system administrator
```

调整系统时间验证有效期：

```shell
# date -s "2014/08/08 15:15"
2014年 08月 08日 星期五 15:15:00 CST
```

chage 查看有效期：

```shell
# chage -l xxx
# chage xxx -l
```

userdel -r 删除用户登入目录以及目录中所有文件：

```shell
# userdel -r heq3      # 删除家目录
```

可用的 shell：

```shell
# cat /etc/shells
/bin/sh
/bin/bash
/sbin/nologin
/bin/dash
/bin/tcsh
/bin/csh
```

组管理：

```shell
# groupadd -g gid
# tail -1 /etc/group
k1:x:1000:
```

## 4. passwd 密码管理

passwd 之所以能让普通用户改密码，靠的是 setuid 位：

```shell
# ls -l `which passwd`
-rwsr-xr-x. 1 root root 30768 2月 22 2012 /usr/bin/passwd
```

--stdin 非交互式改密：

```shell
# echo "123123" | passwd --stdin root
```

锁定与解锁：

```shell
# passwd -l hequan
锁定用户 hequan 的密码 。
passwd: 操作成功
$ passwd hequan
passwd： 只有根用户才能指定用户名称。
# passwd -u hequan
解锁用户 hequan 的密码 。
```

密码老化参数：

```shell
# passwd -n 7 -x 60 -w 10 -i 30 hequan
```

即 7 天不能更改密码、60 天以后必须改、过期前 10 天通知、30 天后禁止
登录（调整用户密码老化数据 hequan）。

echo -e 处理特殊字符，\t 插入 tab。

## 5. 批量创建 100 个用户

```bash
#!/bin/sh
userchars="heq"
for num in `seq 100`
do
    useradd $userchars$num;
    passwd=`date | md5sum | cut -c3-20`
    echo "$passwd" | passwd --stdin $userchars$num
    echo -e "user:$userchars$num\tpasswd:$passwd" >>/tmp/user.log
done
```

```shell
# which passwd
/usr/bin/passwd
```

## 6. usermod 与用户查询

usermod：-l 改登录用户名（其他不变）、-c 备注、-s /bin/bash、
-d 家目录、-e 过期时间、-L 冻结、-U 取消。

用户与登录查询（动态密码）：id、w、who、last、lastlog、groups。

su 以指定用户执行命令：

```shell
# su - hequan -c ls -l /home/hequan/
xx
```

开机以该用户启动脚本：

```shell
# vi /etc/rc.local
su - hequan -c /bin/sh /server/scripts/
```

## 7. sudo 与 visudo

/etc/sudoers 的授权格式：

```ini
root    ALL=(ALL)       ALL
hequan  ALL=(ALL)  NOPASSWD: /usr/sbin/useradd,/bin/rm
```

使用与验证：

```shell
# su - hequan
$ sudo useradd
[sudo] password for hequan:
# ll /var/db/sudo/hequan/
-rw------- 1 root hequan 48 3月  27 19:30 0
# man sudoers
$ sudo -l
用户 hequan 可以在该主机上运行以下命令：
(ALL) /usr/sbin/useradd, (ALL) /bin/rm
# visudo -c
/etc/sudoers：解析正确
# visudo
%组名    ALL=(ALL)         ALL      # \ 续行
```

sudoers 文件内容分两类：一类是别名定义，一类是授权规则。

```ini
# Host_Alias     FILESERVERS = fs1, fs2
# Host_Alias     MAILSERVERS = smtp, smtp2
```

授权行 `root（User_Alias）  ALL=(ALL)  ALL` 中，第一个 ALL 是
Host_Alias，第二个是 Runas_Alias，第三个是 Cmnd_Alias。

四类别名：

- User_Alias：用户
- Host_Alias：定义主机别名
- Runas_Alias：可以切换的用户角色
- Cmnd_Alias：命令别名

完整示例：

```ini
User_Alias    ADMINS = hequan
Host_Alias    SERS = f1,f2,localhost
Runas_Alias   OP = root
Cmnd_Alias    COMMMAND = /usr/sbin/useradd,/usr/sbin/userdel

ADMINS  SERS = (OP)  COMMMAND
```
