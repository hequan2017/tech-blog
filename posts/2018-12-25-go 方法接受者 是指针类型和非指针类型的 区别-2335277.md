> **内容介绍**
>
> 本文用 Tesla 结构体实现 Car 接口(GetName/Run)的同一组例子,对比 Go
> 方法值接收者与指针接收者的差异:值接收者 (t Tesla) 操作的是副本,
> GetName 里改名不影响原结构体,接口变量直接存值 `c = t`;指针接收者
> (t *Tesla) 可以修改原结构体字段,接口变量须存地址 `c = &t`。文末
> 结论:传指针才能在其他方法中修改并保留结构体的值。

> **技术备注**
>
> 原文代码中多处 `t.Name` / `return t.Name` / `t.Name` 参数被网页编辑器
> 吃掉,已补全;两个代码块语言标注由 python 更正为 go。非指针一节 `c = t`
> 处的注释原文误写成"用指针实现、要传地址",已按值传递更正;运行输出中
> 的笔误 "tes t" 更正为 "test"。补充:方法集规则是若 T 只有指针接收者
> 方法,则只有 *T 实现接口;值接收者方法则 T 与 *T 都实现接口。

## 1. 非指针类型(值接收者)

```go
package main

import "fmt"

// 定义接口
type Car interface {
	GetName() string
	Run()
}

// 定义结构体
type Tesla struct {
	Name string
}

// 实现接口的GetName()方法
func (t Tesla) GetName() string {
	t.Name = "test"
	return t.Name
}

// 实现接口的Run()方法
func (t Tesla) Run() {
	fmt.Printf("%s is running\n", t.Name)
}

func main() {
	var c Car
	var t Tesla = Tesla{"Tesla Model S"}
	c = t // 上面是用非指针 Tesla 实现了接口的方法，这里直接传值即可
	fmt.Println(c.GetName())
	c.Run()
}
```

运行输出:

```text
test
Tesla Model S is running
```

值接收者GetName()里虽然改了 Name,但改的是副本,原结构体和接口变量里的值不受影响,所以 Run() 打印的还是 "Tesla Model S"。

## 2. 指针类型(指针接收者)

```go
package main

import "fmt"

// 定义接口
type Car interface {
	GetName() string
	Run()
}

// 定义结构体
type Tesla struct {
	Name string
}

// 实现接口的GetName()方法
func (t *Tesla) GetName() string {
	t.Name = "test"
	return t.Name
}

// 实现接口的Run()方法
func (t *Tesla) Run() {
	fmt.Printf("%s is running\n", t.Name)
}

func main() {
	var c Car
	var t Tesla = Tesla{"Tesla Model S"}
	c = &t // 上面是用指针 *Tesla 实现了接口的方法，这里要传地址
	fmt.Println(c.GetName())
	c.Run()
}
```

运行输出:

```text
test
test is running
```

指针接收者GetName()修改的是结构体本体,后续 Run() 读到的就是改过的 "test"。

## 3. 结论

> 传递指针 可以 修改 传递的结构体的值,在其他方法中也生效。
