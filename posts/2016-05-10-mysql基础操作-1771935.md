> **内容介绍**
>
> 本文是 MySQL 日常运维的基础操作备忘:服务的启动与关闭(/etc/init.d/mysqld、
> mysqld_safe 手动启动、为什么不要用 kill -9 粗暴关库、mysqladmin 平滑关闭),
> 登录方式与 prompt 提示符自定义(临时生效及写入 /etc/my.cnf),help 帮助命令,
> root 密码的设置与修改(mysqladmin、update mysql.user、set password 三种
> 方式及 flush privileges),最后给出忘记 root 密码后的找回流程
> (--skip-grant-tables 跳过授权表、多实例需指定 --defaults-file),并附
> skip-networking 与 bind-address 的安全说明。

> **技术备注**
>
> MySQL 5.7 起 mysql.user 表的 `password` 列更名为 `authentication_string`,
> 8.0 已移除 `password()` 函数,`update mysql.user set password=...` 写法失效,
> 请改用 `ALTER USER ... IDENTIFIED BY ...`;`netstat` 在新系统可换用 `ss`。

## 1. 启动与关闭

```shell
/etc/init.d/mysqld start
netstat -lntup | grep 3306
ps -ef | grep mysql | grep -v grep
```

```text
root       1946      1  0 01:51 pts/1    00:00:00 /bin/sh /application/mysql/bin/mysqld_safe --datadir=/application/mysql/data --pid-file=/application/mysql/data/lnmp.com.pid
mysql      2187   1946  0 01:51 pts/1    00:00:00 /application/mysql/bin/mysqld --basedir=/application/mysql --datadir=/application/mysql/data --plugin-dir=/application/mysql/lib/plugin --user=mysql --log-error=/application/mysql/data/lnmp.com.err --pid-file=/application/mysql/data/lnmp.com.pid --socket=/tmp/mysql.sock --port=3306
```

启动过程(`vim /etc/init.d/mysqld` 可见):

```shell
$bindir/mysqld_safe --datadir="$datadir" --pid-file="$mysqld_pid_file_path" $other_args >/dev/null 2>&1 &
```

初始化时给出的启动方法:

```shell
mysqld_safe --user=mysql &
```

关闭:

```shell
/etc/init.d/mysqld stop
ss -lnt | grep 3306
```

```text
LISTEN     0      50                        *:3306
```

以下方式尽量不要用来粗鲁地关闭数据库:

```shell
killall mysqld
pkill mysqld
killall -9 mysqld    # 尽量不要粗鲁的关闭数据库
```

平滑关闭:

```shell
mysqladmin -uroot -p123456 shutdown
```

## 2. 登录与提示符

```shell
ifconfig    # 先看是测试还是正式环境,操作前备份数据库
mysql
mysql -uroot -p
```

修改提示符(临时):

```text
mysql> prompt \u@hequanS  \r:\m:\s->
root@hequanS 02:13:09->
```

永久生效,写入 `/etc/my.cnf`:

```ini
[mysql]
prompt=\u@hequanS  \r:\m:\s->
```

## 3. 帮助

```sql
mysql> help
mysql> exit
```

## 4. 密码设置与修改

```shell
mysqladmin -u root password '123456'        # 最常用,简单实用
mysqladmin -u root -p'123456' password '123123'
```

```sql
select user,host,password from mysql.user;

-- 要指定条件
update mysql.user set password=password(456) where user='root' and host='localhost';

set password=password('123123');
flush privileges;
```

## 5. 找回 MySQL root 用户密码

```shell
/etc/init.d/mysqld stop
mysqld_safe --skip-grant-tables --user=mysql &    # 忽略授权表
```

如果是编译安装,默认路径是 /usr/local/mysql,会有报错:

```shell
sed -i 's#/usr/local/mysql#/application/mysql#g' /application/mysql/bin/mysqld_safe
```

登录后设置新密码并刷新:

```sql
update user set password=password('新密码') where user='root' and host='localhost';   -- 设置新密码
flush privileges;   -- 刷新
```

新开窗口,用新密码测试关掉数据库,能成功关闭就证明修改成功:

```shell
mysqladmin -uroot -p shutdown
```

多实例要指定配置文件:

```shell
mysqld_safe --defaults-file=/data/3306/my.cnf --skip-grant-tables
```

更安全的做法,同时跳过网络登录:

```shell
mysqld_safe --skip-grant-tables --skip-networking &
```

skip-networking:开启该选项后就不能远程访问 MySQL。

为安全考虑,希望只让指定的 IP 访问 MySQL 时,可以在配置文件中增加 `bind-address=IP`,前提是关闭 skip-networking。
