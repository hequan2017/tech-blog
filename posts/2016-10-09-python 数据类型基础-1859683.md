## 1. Python3 六个标准数据类型

- Number（数字）
- String（字符串）
- List（列表）
- Tuple（元组，原文"元祖"为笔误）
- Set（集合）
- Dictionary（字典）

## 2. Number（数字）

Python 3 支持 **int、float、complex（复数）**。

在 Python 3 里，只有一种整数类型 `int`，表示为长整型，没有 Python 2 中的 `Long`。

**bool** 分为：`True`、`False`。

---

## 3. String（字符串）

Python 中的字符串用单引号（`'`）或双引号（`"`）括起来，同时使用反斜杠（`\`）转义特殊字符（原文"饭斜杠"为笔误）。

格式化字符串（老式 `%` 写法）：

```python
# %d 整数  %f 浮点  %s 字符串  %x 十六进制
'Hello, %s' % 'world'

>>> '%2d-%02d' % (3, 1)
' 3-01'

>>> '%.2f' % 3.1415926
'3.14'

s1 = 72
s2 = 85
r = (s2 - s1) * 100 / s1
print("%.1f%%" % (r))   # 输出增长率，保留 1 位小数
```

> 备注：Python 3.6+ 推荐使用 f-string，例如 `print(f"{r:.1f}%")`。

---

## 4. List（列表）

列表可以完成大多数集合类的数据结构实现。列表中元素的类型可以不相同，它支持数字、字符串，甚至可以包含列表（嵌套）。

列表写在方括号 `[]` 之间、用逗号分隔：

```python
list = ['he', 213]
```

**切片语法：`变量[头下标:尾下标]`**

索引值以 0 为开始值，-1 为从末尾的开始位置。`+` 是列表连接运算符，`*` 是重复操作。

常用操作：

```python
list.append(x)      # 末尾追加
list.insert(1, x)   # 在下标 1 处插入
list.pop(1)         # 弹出下标 1 的元素
list[1] = x         # 按下标赋值
```

## 5. Tuple（元组）

元组（tuple）与列表类似，不同之处在于元组的元素不能修改。元组写在小括号 `()` 里，元素之间用逗号隔开。

元素中的元素类型也可以不相同。

```python
tuple = ('he', 12345)

tup1 = ()      # 空元组
tup2 = (20,)   # 单元素元组，需要在元素后添加逗号（原文"子啊"为笔误）
```

---

## 6. Set（集合）

集合（set）是一个无序不重复元素的序列。

基本功能是进行成员关系测试和删除重复元素。

可以使用大括号 `{}` 或者 `set()` 函数创建集合：

```python
s = {1, 2, 3}
s.add(4)      # 添加元素
s.remove(2)   # 删除元素，不存在会抛 KeyError
```

## 7. Dictionary（字典）

字典（dictionary）是 Python 中非常有用的内置映射类型。

列表是有序的对象集合，字典在 Python 3.6 及更早版本中是无序的对象集合（3.7+ 起字典保持插入顺序）。两者区别在于：字典中的元素通过键来存取，而不是通过偏移存取。

字典用 `{}` 标识，是键（key）: 值（value）对集合：

```python
dictionary = {'name': 'hequan', 'age': 1, 'site': 'www.hequan.lol'}
```

键（key）必须使用不可变类型；在同一个字典中，键必须是唯一的。

补充说明：

- dict 和 set 都要求 key 不可变
- 元组 `(1, 2, 3)` 里 1、2、3 都不可变
- `(1, [2, 3])` 里的 `[2, 3]`（列表）的值是可变的

## 8. 运算符

1. 算术：`+  -  *  /  %  **  //`
2. 比较：`==  !=  >  <  >=  <=`
3. 赋值：`=  +=  -=  *=  /=  %=  **=  //=`（原文 `/+` 为笔误，应为 `/=`），例：`c += a` 等价于 `c = c + a`

### 位运算符（把数字看作二进制计算）

- `&` 按位与：两个相应位都为 1，则该位结果为 1，否则为 0
- `|` 按位或：对应二进制位有一个为 1 时，结果为 1
- `^` 按位异或：两对应二进位相异时，结果为 1
- `~` 按位取反：对数据的每个二进制位取反
- `<<` 左移：各二进位全部左移若干位，高位丢弃，低位补 0
- `>>` 右移：各二进位全部右移若干位

### 逻辑 / 成员 / 身份运算符

逻辑：`and`、`or`、`not`（与、或、非）。

成员（适用于字符串、列表或元组）：

- `in`：在指定序列中找到值返回 True，否则 False
- `not in`：未找到值返回 True，否则 False（原文此处漏掉 `in`，已补正）

身份（比较两个对象的存储单元）：

- `is`：判断两个标识符是否引用自同一对象
- `is not`：判断两个标识符是否引用自不同对象

优先级（由高到低，原文此处符号有乱码，已按 Python 官方优先级修正）：

```
**  →  ~ + -（一元） →  * / % //  →  + -  →  >> <<  →  &  →  ^ |  →
<= < > >=  →  == !=  →  = %= /= //= -= += *= **=  →  is / is not  →
in / not in  →  not  →  and  →  or
```

## 9. 条件判断与循环

```python
if <条件判断1>:
    <执行1>
else:
    <执行2>

for x in <可迭代对象>:
    <循环体>

while <条件>:
    <循环体>
```

循环控制语句：

1. `break`：跳出循环
2. `continue`：跳过当前循环块中的剩余语句
3. `pass`：空语句（占位）
