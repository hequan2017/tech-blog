> **内容介绍**
>
> 登录 Kubernetes Dashboard 或调用 API 需要一个高权限 token。本文演示如何创建一个名为 dashboard-admin 的 ServiceAccount 并绑定 cluster-admin 角色，再从自动生成的 Secret 中取出 token。三步：创建 YAML 并 apply、找到对应的 Secret 名字、describe 查看 token 内容。

> **技术备注**
>
> ① 文中 ClusterRoleBinding 的 apiVersion 采集时丢失，应为 `rbac.authorization.k8s.io/v1beta1`（该版本已在 K8s 1.22 移除，现用 `rbac.authorization.k8s.io/v1`）。② K8s 1.24 起 ServiceAccount 不再自动创建 token Secret，需手动创建 `kubernetes.io/service-account-token` 类型的 Secret，或用 `kubectl create token dashboard-admin -n kube-system` 获取短期 token。③ 绑定 cluster-admin 权限极大，生产环境应按最小权限原则授权。

---

### 1.先创建

```shell
vim k8s-admin.yaml
```

```yaml
apiVersion: v1
kind: ServiceAccount
metadata:
  name: dashboard-admin
  namespace: kube-system
---
kind: ClusterRoleBinding
apiVersion: rbac.authorization.k8s.io/v1beta1  # 注：原文此处采集时丢失了 apiGroup，K8s 1.22+ 应改用 rbac.authorization.k8s.io/v1
metadata:
  name: dashboard-admin
subjects:
  - kind: ServiceAccount
    name: dashboard-admin
    namespace: kube-system
roleRef:
  kind: ClusterRole
  name: cluster-admin
  apiGroup: rbac.authorization.k8s.io  # 注：原文此处采集时丢失，应补该值
```

```shell
kubectl apply -f k8s-admin.yaml
```

### 2.获取name

```shell
kubectl get secret -n kube-system
NAME                                             TYPE                                  DATA   AGE
dashboard-admin-token-dhhmc                      kubernetes.io/service-account-token   3      69s
```
