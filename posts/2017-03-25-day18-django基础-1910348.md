## 1. JS 正则:test 与 exec

test —— 判断字符串是否符合规定的正则,有就是 true:

```javascript
rep = /\d+/;
rep.test("asdfoiklfasdf89asdfasdf")     // true,字符串中包含数字

rep = /^\d+$/;
rep.test("asdfoiklfasdf89asdfasdf")     // false,不是纯数字(原文误注 true,已更正)
```

exec —— 获取匹配的数据:

```javascript
str = "wangshen_67_houyafa_20"
rep = /\d+/;
rep.exec(str)
// ["67"]

// JavaScript is more fun than Java or JavaBeans!
var pattern = /\bJava(\w*)\b/;
// ["JavaScript", "Script"]

// 全局模式 g:每次 exec 从上次匹配位置继续
// JavaScript is more fun than Java or JavaBeans!
var pattern = /\bJava\w*\b/g;
// 依次返回: ["JavaScript"]  ["Java"]  ["JavaBeans"]  null

// JavaScript is more fun than Java or JavaBeans!
var pattern = /\bJava(\w*)\b/g;
// 依次返回: ["JavaScript",'Script']  ["Java", ""]  ["JavaBeans", "Beans"]  null
```

多行匹配:默认就是多行匹配,`^$`。

## 4. Django 安装与工程结构

```shell
pip3 install django            # 安装后脚本位于 C:\Python35\Scripts
cd /d d:\Python\www
c:\Python35\Scripts\django-admin.exe startproject hello   # 创建Django工程
# django-admin startproject 【工程名称】
```

工程目录:

- mysite:对整个程序进行配置
  - settings:配置文件
  - url:URL 对应关系
  - wsgi:遵循 WSGI 规范,uwsgi + nginx
- manage.py:管理 Django 程序

```shell
python manage.py startapp xx             # 创建app
python manage.py makemigrations          ### 生成数据库
python manage.py migrate
python manage.py runserver 127.0.0.1:8001    # 运行Django
```

以 chouti(抽屉)为例,一个工程可同时包含:配置、主站 app、后台管理 app:

```shell
python manage.py startapp cmdb
python manage.py startapp openstack
python manage.py startapp xxoo....
```

app 目录各文件作用:

| 文件 | 作用 |
|------|------|
| migrations | 数据修改表结构记录 |
| admin | Django 为我们提供的后台管理 |
| apps | 配置当前 app |
| models | ORM,写指定的类,通过命令可以创建数据库结构 |
| tests | 单元测试 |
| views | 业务代码 |

```python
        'OPTIONS': {

                'django.template.context_processors.debug',
```

## 7. 模板语言

```python
from django.shortcuts import render, redirect
```

{{ 变量名 }}:

```python
def func(request):
    return render(request, "index.html", {'current_user': "alex"})
```

index.html:

```html
<html>
<body>
    <div>{{ current_user }}</div>
</body>
</html>
```

====> 最后生成的字符串:

```html
<html>
<body>
    <div>alex</div>
</body>
</html>
```

For 循环:

```python
def func(request):
    return render(request, "index.html",
                  {'current_user': "alex", 'user_list': ['alex', 'eric']})
```

```html
<html>
<body>
    <div>{{ current_user }}</div>
    <ul>
        {% for row in user_list %}
            {% if row == "alex" %}
                <li>{{ row }}</li>
            {% endif %}
        {% endfor %}
    </ul>
</body>
</html>
```

索引:

```python
def func(request):
    return render(request, "index.html", {
        'current_user': "alex",
        'user_list': ['alex', 'eric'],
        'user_dict': {'k1': 'v1', 'k2': 'v2'}})
```

```html
<html>
<body>
    <div>{{ current_user }}</div>
    <a> {{ user_list.1 }} </a>
    <a> {{ user_dict.k1 }} </a>
    <a> {{ user_dict.k2 }} </a>
</body>
</html>
```

条件:

```python
def func(request):
```
