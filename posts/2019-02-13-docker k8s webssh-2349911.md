```
下载可执行程序  gotty

https:///yudai/gotty/releases

执行这个命令
./gotty  -w -p 8081 -a 192.168.100.50  --permit-arguments    docker exec -it

浏览器访问

http://192.168.100.50:8081/?arg=mysql&arg=/bin/bash

arg 是 参数,   gotty 作为一个代理  去执行  docker exec -it mysql  /bin/bash

也可以把要执行的参数 都传进来。

k8s 也是同理
```
