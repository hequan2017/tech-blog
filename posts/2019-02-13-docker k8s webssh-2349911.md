> **内容介绍**
>
> 借助 gotty 把命令行终端搬到浏览器：gotty 作为代理执行 `docker exec -it <容器> /bin/bash`，通过 URL 参数传容器名，从而实现 Web 端进入 docker 容器的 webssh；Kubernetes 场景同理（对应 `kubectl exec`）。
>
> **技术备注**
>
> gotty 项目（yudai/gotty）已多年未更新，存在维护社区分支 sorenisanerd/gotty；若需进入 K8s 容器建议直接用 `kubectl exec -it`，或评估更现代的 webssh 方案（如 ttyd、自研 xterm.js + WebSocket）。

---

下载可执行程序 gotty：https://github.com/yudai/gotty/releases

执行命令：

```shell
./gotty -w -p 8081 -a 192.168.100.50 --permit-arguments docker exec -it
```

浏览器访问：

```text
http://192.168.100.50:8081/?arg=mysql&arg=/bin/bash
```

`arg` 是参数，gotty 作为一个代理去执行 `docker exec -it mysql /bin/bash`，也可以把要执行的参数都传进来。K8s 也是同理。
