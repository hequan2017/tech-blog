> **内容介绍**
>
> 本文通过两个小脚本演示 Bash 中 IFS（内部字段分隔符）的用法：先把 `A="aa:bb:cc:dd"` 按冒号切分，用循环计数取出第 4 个字段 `dd`；再把 `/etc/passwd` 格式的一行文本按冒号切分，取出用户名（第 1 个字段）和登录 shell（第 7 个字段），同时演示了先备份、后还原 IFS 的正确做法。

> **技术备注**
>
> IFS 机制在 Bash 5.x（2026 年主流版本）中依然有效，本文写法仍可运行。但更现代的做法是直接用 `IFS=: read -r a b c d <<< "$line"` 一次性拆分到变量，或用参数展开 `${line%%:*}` 取字段，避免修改全局 IFS 导致副作用；`let i++` 可用更通用的 `((i++))` 替代。

## 1. IFS 是什么

IFS（Internal Field Separator，内部字段分隔符）是 Shell 做字段切分时使用的分隔字符，默认值为空格、制表符和换行。修改变量 `IFS` 后，`for B in $A` 这类不带引号的变量展开就会按新分隔符把字符串拆成多个字段。

下面这个例子把 `aa:bb:cc:dd` 按冒号分开，循环计数到 `i=3` 时把第 4 个字段 `dd` 赋给变量 `b`（原文描述为 "$0 $1 $2 $3" 不准确，这里实际是 for 循环依次取值，用计数器 `i` 定位）：

```bash
# 脚本内容（文件 1）
#!/bin/bash
A="aa:bb:cc:dd"
IFS=":"           # 将字段分隔符改为冒号
i=0
for B in $A;      # 不带引号展开 $A，按 IFS 切分
do
        [ $i -eq 3 ] && b=$B;   # 取第 4 个字段（下标从 0 开始）
        let i++;
done;
echo $b;
```

执行结果：

```shell
[root@shell test]# sh 1
dd
```

## 2. 用 IFS 解析 /etc/passwd 格式的行

第二个例子更实用：把 `root:x:0:0:root:/root:/bin/bash` 这样的行按冒号切开，取第 1 个字段（用户名）和第 7 个字段（登录 shell）。注意脚本里先保存旧的 IFS、用完再恢复，这是避免影响脚本后续行为的好习惯：

```bash
#!/bin/bash
#Desc: Illustration of IFS
line="root:x:0:0:root:/root:/bin/bash"
oldIFS=$IFS;      # 备份原来的 IFS
IFS=":"
count=0
for item in $line;
do
     [ $count -eq 0 ] && user=$item;    # 第 1 个字段：用户名
     [ $count -eq 6 ] && shell=$item;   # 第 7 个字段：登录 shell
     let count++
done;
IFS=$oldIFS       # 恢复原来的 IFS
echo $user\'s shell is $shell;   # 转义单引号，输出：root's shell is /bin/bash
```

## 3. 现代替代写法（补充）

在现在的 Bash 中，上面两个例子都可以写得更简洁：

```bash
# 用 read 一次性按冒号拆分到多个变量
line="root:x:0:0:root:/root:/bin/bash"
IFS=: read -r user x uid gid gecos home shell <<< "$line"
echo "${user}'s shell is ${shell}"    # 输出：root's shell is /bin/bash
```

这种写法只在 `read` 这一条命令内临时改变 IFS，不会污染全局环境。
