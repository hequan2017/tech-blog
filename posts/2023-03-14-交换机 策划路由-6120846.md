> **内容介绍**
>
> 本文与《h3c 交换机 策划路由》为同一份配置，是交换机策略路由
> （PBR）片段：在 Vlan-interface2 上调用策略 aaa，由高级 ACL 3000
> 匹配指定源网段，命中流量强制走下一跳 192.168.1.1，实现按策略分流。
>
> **技术备注**
>
> - H3C Comware 风格命令：`ip address ... sub` 表示从地址（Cisco 用
>   `secondary`），192.168.1.2/30 与下一跳 192.168.1.1 同网段互联。
> - `0.0.0.255` 为反掩码，即匹配一个 C 类源网段；未命中策略的流量
>   仍按普通路由表转发。标题「策划路由」应为「策略路由」。

---

```shell
interface Vlan-interface2
ip address x.x.x.x 255.255.255.0
ip address 192.168.1.2 255.255.255.252 sub
ip policy-based-route aaa
#

acl number 3000
rule 0 permit ip source x.x.x.x 0.0.0.255
#

policy-based-route aaa permit node 2
if-match acl 3000
apply next-hop 192.168.1.1
#
```
