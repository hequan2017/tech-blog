> **内容介绍**
>
> 本文是一份 jQuery 常用方法速查表：文档就绪的两种写法与基本选择器；
> hide/show/toggle、fadeIn/fadeOut、slideDown/slideUp 等效果方法和 animate 动画；
> text/html/val 取值、attr/prop 属性操作、append/prepend/after/before 插入与
> remove/empty 删除等 DOM 操作；addClass/css 样式与 width/height 系列尺寸方法；
> parent/children/siblings/find 等树遍历和 first/filter 过滤；最后附 $.get/$.post
> AJAX、$.getJSON/$.noConflict 工具方法与常用原生 DOM 接口对照。

> **技术备注**
>
> jQuery 1.x / 2.x 分支已于 2019 年停止维护，新项目建议使用 jQuery 3.x（4.0 已于
> 2025 年发布）；
> 本文按主题整理方法名，均省略了参数与回调，实际使用请对照官方 API 文档。

---

## 1. 文档就绪与选择器

```javascript
$(document).ready(function(){
    // 开始写 jQuery 代码...
});

$(function(){
    // 开始写 jQuery 代码...
});

$("p")
$("#id")
$('.class')
$(this)
$('p#id')
```

## 2. 效果

```javascript
// 显示隐藏
.hide
.show
.toggle

// 淡入淡出
.fadeIn
.fadeOut
.fadeToggle

// 滑动
.slideDown
.slideUp
.slideToggle

// 动画
.animate
.stop
```

## 3. DOM 与属性操作

```javascript
// DOM 操作
.text
.html
.val

// 获取属性
.attr("href")
.prop

// 添加
// 元素内
.append
.prepend
// 元素外
.after
.before

// 删除元素
.remove(".需要指定的元素")
.empty("子元素")
```

## 4. CSS 与尺寸

```javascript
// 操作 css
.addClass()
.removeClass()
.toggleClass()
.css({"background-color":"yellow","font-size":"200%"});

// 尺寸
.width
.height
.innerWidth
.innerHeight
.outerWidth
.outerHeight
```

## 5. 遍历

```javascript
.parent    // 直接父元素
.parents   // 所有祖先元素
$("span").parentsUntil("div");   // 两个给定元素之间

.children   // 直接子元素
.find

.siblings   // 所有同胞元素
.next       // 下面
.nextAll
.nextUntil
.prev       // 上面
.prevAll
.prevUntil

.first
.last
.eq(下标)
.filter
.not
```
