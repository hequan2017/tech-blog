> **内容介绍**
>
> 本文介绍如何为 CentOS 更换国内 yum 镜像源：先备份默认的 `CentOS-Base.repo`，
> 再下载对应系统版本的 repo 文件放入 `/etc/yum.repos.d/`，最后执行
> `yum clean all && yum makecache` 重建缓存，从而显著提升软件包下载速度。

> **技术备注**
>
> 文中的网易 163 镜像源已停止对外服务，CentOS 5/6/7 也均已停止维护（EOL），
> 官方仓库已迁移至 vault.centos.org。实践中建议改用仍在维护的镜像站，例如
> 阿里云 `mirrors.aliyun.com`、清华 TUNA `mirrors.tuna.tsinghua.edu.cn`，
> 或直接迁移至 Rocky Linux / AlmaLinux 等活跃发行版。

## 使用说明

### 1. 备份默认源

首先备份 `/etc/yum.repos.d/CentOS-Base.repo`：

```shell
mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.backup
```

### 2. 下载对应版本的 repo 文件

下载对应系统版本的 repo 文件，放入 `/etc/yum.repos.d/`（操作前请做好相应备份）：

- [CentOS7](http://mirrors.163.com/.help/CentOS7-Base-163.repo)
- [CentOS6](http://mirrors.163.com/.help/CentOS6-Base-163.repo)
- [CentOS5](http://mirrors.163.com/.help/CentOS5-Base-163.repo)

下载示例（以 CentOS 7 为例）：

```shell
wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.163.com/.help/CentOS7-Base-163.repo
```

### 3. 生成缓存

运行以下命令清空旧缓存并重新生成：

```shell
yum clean all
yum makecache
```
