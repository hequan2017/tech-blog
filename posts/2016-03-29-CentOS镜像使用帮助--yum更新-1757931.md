> **内容介绍**
>
> 本文介绍如何为 CentOS 更换国内 yum 镜像源：先备份默认的 `CentOS-Base.repo`，
> 再下载对应系统版本的 repo 文件放入 `/etc/yum.repos.d/`，最后执行
> `yum clean all && yum makecache` 重建缓存，从而显著提升软件包下载速度。
> 全文步骤精简，适合作为快速换源的操作备忘。

> **技术备注**
>
> 截至 2026 年，文中的网易 163 镜像源（mirrors.163.com）已停止对外提供 CentOS repo 下载，
> CentOS 5/6/7/8 也均已停止维护（EOL），官方历史仓库迁移至 vault.centos.org。
> 实践中建议改用仍在维护的镜像站，例如阿里云 `mirrors.aliyun.com`、
> 清华 TUNA `mirrors.tuna.tsinghua.edu.cn`，或直接迁移至 Rocky Linux / AlmaLinux 等
> 活跃发行版（新系统使用 `dnf` 替代 `yum`，命令基本兼容）。

---

## 1. 备份默认源

首先备份 `/etc/yum.repos.d/CentOS-Base.repo`，以便换源失败时回滚：

```shell
mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.backup  # 重命名备份默认 repo
```

## 2. 下载对应版本的 repo 文件

下载对应系统版本的 repo 文件，放入 `/etc/yum.repos.d/`（操作前请做好相应备份）：

- CentOS 7：`http://mirrors.163.com/.help/CentOS7-Base-163.repo`
- CentOS 6：`http://mirrors.163.com/.help/CentOS6-Base-163.repo`
- CentOS 5：`http://mirrors.163.com/.help/CentOS5-Base-163.repo`

下载示例（以 CentOS 7 为例）：

```shell
# 下载 163 的 CentOS7 repo 并覆盖默认源（163 源已废弃，仅作历史参考）
wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.163.com/.help/CentOS7-Base-163.repo
```

> 备注：原文中的 163 镜像链接现已无法访问（已废弃）。如需给遗留的 CentOS 7 系统换源，
> 可改用阿里云：`wget -O /etc/yum.repos.d/CentOS-Base.repo https://mirrors.aliyun.com/repo/Centos-7.repo`。

## 3. 重建 yum 缓存

运行以下命令清空旧缓存并重新生成：

```shell
yum clean all   # 清空旧的软件包缓存与元数据
yum makecache   # 根据新源重新生成缓存
```

执行完成后即可正常使用 `yum install` 安装软件，下载速度将明显快于默认境外源。
