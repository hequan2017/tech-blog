> **内容介绍**
>
> 本文用一个 Shell 脚本批量处理本机网卡：先用 `ip a` 列出网卡名（排除 lo 与
> docker 接口），再对 `/etc/sysconfig/network-scripts/` 下缺少 ifcfg- 配置文件
> 的网卡，自动生成 DHCP 方式的最简配置（DEVICE/BOOTPROTO/ONBOOT/TYPE），
> 最后检查各网卡状态，把仍处于 DOWN 状态的网卡用 `ifup` 后台激活，并用
> `wait` 等待全部完成。

> **技术备注**
>
> ifcfg-* 是 RHEL/CentOS 系 `/etc/sysconfig/network-scripts/` 下的传统
> initscripts 配置格式：RHEL 8 起配套的 network-scripts 已弃用，RHEL 9 的
> NetworkManager 默认改用 keyfile，新系统需用 `nmcli` 或 keyfile 相应适配。
> 另注意 `ifup` 会按配置文件做完整激活（含 DHCP 取址），不同于仅置链路状态的
> `ip link set up`；脚本取 `ip link show` 输出的第 9 列作为 state，部分虚拟
> 接口该值为 UNKNOWN，会被脚本直接视为“已激活”。

## 1. 脚本：自动生成 ifcfg 配置文件并激活网卡

脚本通过两个循环完成：第一个循环补齐缺失的 `ifcfg-<网卡名>` 配置文件，
第二个循环把仍处于 DOWN 状态的网卡用 `ifup` 后台激活。

```shell
#!/bin/bash

# 获取所有网卡名称
interface_list=$(ip a | awk '/^[0-9]+: / {gsub(":", ""); print $2}' | grep -v lo | grep -v docker)

network_scripts_dir="/etc/sysconfig/network-scripts/"

for interface in $interface_list; do
  config_file="ifcfg-${interface}"
  config_file_path="${network_scripts_dir}${config_file}"

  # 检查是否存在配置文件
  if [ ! -f "$config_file_path" ]; then
    echo "生成配置文件: $config_file_path"

    # 创建配置文件
    touch "$config_file_path"

    # 将基本配置写入文件
    echo "DEVICE=${interface}" > "$config_file_path"
    echo "BOOTPROTO=dhcp" >> "$config_file_path"
    echo "ONBOOT=yes" >> "$config_file_path"
    echo "TYPE=Ethernet" >> "$config_file_path"
  fi
done

for interface in $interface_list; do
  # 检查网卡状态（UP 或 DOWN）
  interface_status=$(ip link show $interface | awk '/<.*>/ {print $9}')

  if [ "$interface_status" == "DOWN" ]; then
    echo "激活网卡：$interface"
    # 用root权限激活网卡
    ifup $interface &
  else
    echo "网卡已激活：$interface"
  fi
done

wait
```
