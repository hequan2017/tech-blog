> **内容介绍**
>
> 一个 pandas 小例子：把"名字相同的多条字典记录的 value 求和合并"——构造 DataFrame 后用 `groupby().sum()` 聚合，再转回字典。演示了 `df.ix` 选列和 `result.T.to_dict('list')` 的用法。

> **技术备注**
>
> 文中 `df.ix[:, cols]` 已在 pandas 1.0 中被移除（0.20 起弃用），现在应改用 `df.loc[:, cols]`。其余 groupby 聚合用法至今通用。

---

### 需求

计算  列表内  名字一样的  value 值

```python
name = [
    {'name': 'he', 'value': 100, 'ps': 'test1'},
    {'name': 'quan', 'value': 150, 'ps': 'test2'},
    {'name': 'he', 'value': 100, 'ps': 'test3'},
    {'name': 'quan', 'value': 200, 'ps': 'test4'}
]
```

### 代码

```shell
pip install pandas
```

```python
import pandas as pd

df = pd.DataFrame(name)
cols = ['name', 'value']
df = df.loc[:, cols]   # 原文用的 df.ix 已被 pandas 1.0 移除，改用 loc
result = df.groupby(['name']).sum()
dict_country = result.T.to_dict('list')
print(dict_country)
```

### 结果

```python
{'he': [200], 'quan': [350]}
```
