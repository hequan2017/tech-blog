> **内容介绍**
>
> 借助开源库 HyperLPR 识别车牌的最小示例：先用 pip 安装
> opencv-python、opencv-contrib-python 和 hyperlpr，再用 OpenCV
> 读入图片，调用 HyperLPR_plate_recognition 即可得到识别结果。

> **技术备注**
>
> 文中用法对应 2019 年 12 月发布的经典 hyperlpr 0.0.2，该包此后未再
> 更新；项目现以 HyperLPR3 为主线（pip install hyperlpr3，基于
> ONNX Runtime，API 有变化）。opencv-python==3.4.2.16 是当年教程常见
> 的固定版本写法，新版 Python 无对应 wheel，如今直接安装 4.x 即可。
> HyperLPR 针对中国大陆车牌（蓝牌、黄牌、新能源绿牌等）训练，仅适用
> 于中文车牌场景。

---

```shell
pip3 install opencv-python==3.4.2.16
pip3 install opencv-contrib-python==3.4.2.16
pip3 install hyperlpr
```

```python
from hyperlpr import *
# 导入OpenCV库
import cv2
# 读入图片
image = cv2.imread("1.png")
# 识别结果
print(HyperLPR_plate_recognition(image))
```
