> **内容介绍**
>
> CentOS 上从源码编译安装 Python 3.6.4 的一键脚本。流程：安装编译依赖、configure/make 编译、替换 /usr/bin/python 软链指向 3.6、修复 yum 和 urlgrabber 的 shebang 使其仍走系统 Python 2、配置动态链接库与 pip 镜像源。

> **技术备注**
>
> Python 3.6 已于 2021 年 12 月停止维护（EOL），且文中 sohu 镜像源（mirrors.sohu.com）现已关闭，编译安装请改用 python.org 官方源或国内高校镜像。直接把 `/usr/bin/python` 换成 python3 在新发行版（RHEL 8+/Rocky 8+）上风险更大，推荐使用 `alternatives` 或 `pyenv` 管理多版本。Python 3.6 至今的语法差异：3.8 海象运算符 `:=`、3.9 移除弃用别名、3.10 match/case 等。

---

```shell
cd /usr/local/src
wget http://mirrors.sohu.com/python/3.6.4/Python-3.6.4.tgz

yum -y install zlib*  python-devel mysql-devel zlib-devel openssl-devel

tar xf Python-3.6.4.tgz

cd Python-3.6.4/

./configure   --enable-shared --enable-loadable-sqlite-extensions --with-zlib
./configure --enable-optimizations

make
make install

rm -rf /usr/bin/python

ln -s /usr/local/bin/python3.6    /usr/bin/python

sed  -i    's/\#\!\/usr\/bin\/python/\#\!\/usr\/bin\/python2/'   /usr/bin/yum
sed  -i    's/\#\! \/usr\/bin\/python/\#\! \/usr\/bin\/python2/'   /usr/libexec/urlgrabber-ext-down

echo  "/usr/local/lib"  >> /etc/ld.so.conf

/sbin/ldconfig

mkdir -p  /root/.pip/

cat >  /root/.pip/pip.conf   <<EOF
[global]
index-url = http:///simple
trusted-host =
EOF

python -V
```
