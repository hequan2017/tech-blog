# 中文博客翻译为英文版 — 规范（agents 必读）

任务：把一篇中文技术/随笔博客完整翻译成英文，写入 `posts/en/` 下与源文件**完全同名**的新文件。
只创建这一个输出文件；不修改任何其他文件；严禁运行任何 git 命令。

## 步骤
1. 完整读取源文件（长文分段读完全部），把全部中文正文翻译成地道、简洁的技术英语（随笔类译成流畅英语散文）。不得增删内容或改写原意/技术含义。
2. front-matter 五字段：
   - `title`：翻译成简洁英文标题；
   - `date` / `category` / `source` 三行：逐字节原样保留；
   - 在 `source` 行后新增一行 `lang: "en"`。
3. 文首引用块：`> **内容介绍**` → `> **About this post**`；`> **技术备注**` → `> **Technical notes**`；内容翻译。
4. 分节标题全部翻译，保留 `## 1.` 等编号格式。
5. 代码块：代码逐字保留，不改逻辑、不改缩进；仅把代码中人类书写的注释（`#`、`//`、`<!-- -->`）译成英文并保持简短；程序输出/命令回显（text/plain 块）逐字保留不翻译。
6. 行内代码、命令、路径、URL、镜像名、专有名词不翻译。
7. 图片路径：所有 `assets/` 开头的引用改为 `../assets/` 开头（输出文件位于 posts/en/ 子目录）。
8. 中文标点（，、；：（）"" 等）在译文中改为英文标点。
9. 中国法规/国标名称：首次出现给出英文译名并括注中文原名，如 `Information Security Technology — Baseline (《信息安全技术 信息系统安全等级保护基本要求》)`。

## 自查（写完必须逐项确认）
- 围栏成对且语言标注与原文一致；无行尾空白；无 NBSP；
- 所有图片引用以 `../assets/` 开头；
- 除「程序输出」与「法规原名括注」外无残留中文。

## 交付
中文回复 ≤5 行：完成摘要 + 术语处理说明（如有）。
